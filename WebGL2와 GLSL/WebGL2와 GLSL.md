# WebGL2의 GLSL 쉽게 이해하기 (대상: 프로그래밍 입문자)

## 1. 핵심 요약 (1문장)

**GLSL은 WebGL2에서 GPU에게 "정점을 어디에 배치하고, 픽셀을 어떤 색으로 칠할지" 지시하는 작은 프로그램 언어입니다.**

---

## 2. 단계별 설명

### 2.1. 기본 정의: WebGL2와 GLSL은 무엇인가?

웹 브라우저에서 2D 또는 3D 그래픽을 그릴 때 WebGL2를 사용할 수 있습니다.

- **WebGL2**: 자바스크립트가 GPU를 사용하도록 도와주는 웹 기술
- **GLSL**: GPU에서 실행되는 그래픽 전용 프로그래밍 언어
- **GPU**: 같은 종류의 계산을 매우 많이, 동시에 처리하는 장치

일반적인 자바스크립트 코드는 주로 CPU에서 실행됩니다. 반면 GLSL 코드는 GPU에서 실행되므로 수많은 정점이나 픽셀을 동시에 처리하는 데 적합합니다.

**핵심 요약:** WebGL2가 GPU를 사용하는 통로라면, GLSL은 GPU에게 내리는 작업 지시서입니다.

---

### 2.2. 그래픽 처리 과정: 정점과 픽셀

WebGL2에서 그림 하나를 만들 때는 보통 다음 과정을 거칩니다.

1. 도형을 이루는 **정점(vertex)** 정보를 준비합니다.
2. 정점 셰이더가 정점의 위치를 계산합니다.
3. GPU가 정점들을 연결해 삼각형을 만듭니다.
4. 프래그먼트 셰이더가 삼각형 내부의 픽셀 색상을 계산합니다.
5. 계산된 색상이 화면에 표시됩니다.

여기서 GLSL 프로그램은 보통 두 부분으로 나뉩니다.

#### 정점 셰이더(Vertex Shader)

정점마다 실행됩니다.

주요 역할은 다음과 같습니다.

- 정점의 화면 위치 계산
- 정점의 크기나 방향 처리
- 색상, 텍스처 좌표 등의 정보 전달

```
#version 300 es

in vec2 a_position;

void main() {
    gl_Position = vec4(a_position, 0.0, 1.0);
}
```

이 코드는 2차원 위치를 받아서 화면에 사용할 4차원 위치로 바꿉니다.

`gl_Position`은 정점 셰이더가 반드시 설정해야 하는 특별한 변수입니다.

#### 프래그먼트 셰이더(Fragment Shader)

삼각형 내부의 픽셀마다 실행됩니다.

```
#version 300 es
precision highp float;

out vec4 outColor;

void main() {
    outColor = vec4(1.0, 0.0, 0.0, 1.0);
}
```

이 코드는 모든 픽셀을 빨간색으로 칠합니다.

색상은 보통 다음과 같은 순서입니다.

색상=(R,G,B,A)\text{색상} = (R, G, B, A)색상=(R,G,B,A)

각 값은 일반적으로 0.00.00.0부터 1.01.01.0 사이입니다.

- `(1.0, 0.0, 0.0, 1.0)` → 빨간색, 완전 불투명
- `(0.0, 1.0, 0.0, 1.0)` → 초록색
- `(0.0, 0.0, 1.0, 1.0)` → 파란색
- `(1.0, 1.0, 1.0, 1.0)` → 흰색

**핵심 요약:** 정점 셰이더는 "어디에 그릴지" 계산하고, 프래그먼트 셰이더는 "무슨 색으로 칠할지" 계산합니다.

### 2.3. WebGL2 GLSL의 중요한 문법

WebGL2에서는 GLSL 코드를 작성할 때 보통 파일 맨 위에 다음을 씁니다.

```
#version 300 es
```

이는 "WebGL2용 GLSL 문법을 사용하겠다"는 뜻입니다.

#### 변수 선언

```
float size = 3.0;
int count = 10;
bool enabled = true;
vec2 position = vec2(0.5, 0.2);
vec4 color = vec4(1.0, 0.0, 0.0, 1.0);
```

자주 사용하는 자료형은 다음과 같습니다.

|자료형|의미|예시|
|---|---|---|
|`float`|실수|`3.14`|
|`int`|정수|`10`|
|`bool`|참/거짓|`true`|
|`vec2`|숫자 2개 묶음|위치|
|`vec3`|숫자 3개 묶음|3차원 좌표, RGB 색상|
|`vec4`|숫자 4개 묶음|위치, RGBA 색상|
|`mat4`|4×4 행렬|3D 변환|

#### `in`, `out`, `uniform`

WebGL2와 GLSL 사이에서 데이터를 주고받을 때 사용하는 키워드입니다.

##### `in`

외부에서 GLSL 셰이더로 들어오는 데이터입니다.

```
in vec2 a_position;
```

정점 위치 데이터를 자바스크립트에서 받아옵니다.

##### `out`

셰이더가 다음 단계로 보내거나 최종적으로 출력하는 데이터입니다.

```
out vec4 outColor;
```

프래그먼트 셰이더에서 계산한 최종 색상을 출력합니다.

##### `uniform`

모든 정점이나 픽셀이 공유하는 값입니다.

```
uniform float u_time;
uniform vec4 u_color;
```

예를 들어 현재 시간, 전체 도형의 색상, 화면 크기 등을 전달할 때 사용합니다.

**핵심 요약:** `in`은 들어오는 데이터, `out`은 나가는 데이터, `uniform`은 전체가 공유하는 데이터입니다.

### 2.4. 정점 셰이더와 프래그먼트 셰이더 연결하기

정점의 색상을 프래그먼트 셰이더까지 전달할 수도 있습니다.

#### 정점 셰이더

```
#version 300 es

in vec2 a_position;
in vec3 a_color;

out vec3 v_color;

void main() {
    gl_Position = vec4(a_position, 0.0, 1.0);
    v_color = a_color;
}
```

#### 프래그먼트 셰이더

```
#version 300 es
precision highp float;

in vec3 v_color;
out vec4 outColor;

void main() {
    outColor = vec4(v_color, 1.0);
}
```

여기서 `v_color`가 두 셰이더 사이의 연결 통로입니다.

특히 삼각형의 세 정점에 서로 다른 색을 지정하면 GPU가 삼각형 내부의 색상을 자연스럽게 섞어 줍니다.

예를 들어:

- 왼쪽 위 정점: 빨간색
- 오른쪽 위 정점: 초록색
- 아래 정점: 파란색

그러면 삼각형 내부에는 여러 색이 부드럽게 섞여 나타납니다.

**핵심 요약:** 정점 셰이더의 `out`과 프래그먼트 셰이더의 `in`을 사용하면 정점 정보를 픽셀까지 전달할 수 있습니다.

---

### 2.5. 좌표의 특징: 화면 좌표와 다른 점

GLSL에서 정점 위치는 보통 클립 공간 좌표를 사용합니다.

화면의 위치는 대략 다음 범위입니다.

- 왼쪽: x=−1x=-1x=−1
- 오른쪽: x=1x=1x=1
- 아래쪽: y=−1y=-1y=−1
- 위쪽: y=1y=1y=1

즉, 화면 중앙은 다음과 같습니다.

(x,y)=(0,0)(x, y) = (0, 0)(x,y)=(0,0)

화면 오른쪽 위는 다음과 비슷합니다.

(x,y)=(1,1)(x, y) = (1, 1)(x,y)=(1,1)

예를 들어 다음 정점 세 개는 삼각형을 만듭니다.

```
vec2(-0.5, -0.5)
vec2( 0.5, -0.5)
vec2( 0.0,  0.5)
```

다만 실제 3D 게임에서는 물체를 이동하거나 회전하거나 확대해야 하므로 행렬을 사용합니다.

```
#version 300 es

in vec3 a_position;
uniform mat4 u_matrix;

void main() {
    gl_Position = u_matrix * vec4(a_position, 1.0);
}
```

`u_matrix`는 물체의 이동, 회전, 크기 조절, 카메라 효과 등을 계산한 행렬입니다.

**핵심 요약:** GLSL의 기본 화면 좌표는 보통 −1-1−1부터 111까지이며, 복잡한 3D 변환에는 행렬을 사용합니다.

## 3. 실생활 비유/예시

### GLSL을 "공장에서 일하는 로봇들에게 주는 작업 지시서"라고 생각해 봅시다.

- **자바스크립트**: 공장 관리자
- **WebGL2**: 관리자와 GPU를 연결하는 공장 시스템
- **GPU**: 동시에 많은 일을 처리하는 로봇 공장
- **정점 셰이더**: 각 부품을 어디에 놓을지 결정하는 로봇
- **프래그먼트 셰이더**: 각 부분을 어떤 색으로 칠할지 결정하는 로봇

삼각형을 그린다고 하면 다음과 같습니다.

1. 자바스크립트가 세 정점의 위치를 GPU에 전달합니다.
2. 정점 셰이더가 세 정점을 화면의 어느 위치에 놓을지 계산합니다.
3. GPU가 세 정점을 연결해 삼각형 영역을 만듭니다.
4. 프래그먼트 셰이더가 삼각형 안의 수많은 픽셀 색상을 결정합니다.
5. 완성된 삼각형이 화면에 나타납니다.

일반적인 프로그램은 명령을 하나씩 처리하는 경우가 많지만, GPU는 수많은 정점과 픽셀에 같은 셰이더를 동시에 적용합니다. 그래서 3D 장면, 애니메이션, 조명, 파티클 효과 같은 작업에 강합니다.

## 4. 초보자가 기억할 핵심 개념

### 4.1. 셰이더

GPU에서 실행되는 작은 프로그램입니다.

WebGL2에서는 주로 다음 두 셰이더를 사용합니다.

- **Vertex Shader**: 정점 위치 계산
- **Fragment Shader**: 픽셀 색상 계산

### 4.2. 속성 데이터와 공유 데이터

- `in`으로 받는 정점별 데이터: 위치, 색상, 텍스처 좌표
- `uniform`으로 받는 공통 데이터: 시간, 행렬, 전체 색상
- `out`으로 보내는 데이터: 다음 셰이더에 전달할 값

### 4.3. GLSL은 자바스크립트와 다르다

GLSL은 자바스크립트처럼 브라우저의 HTML 요소를 조작하는 언어가 아닙니다.

다음과 같은 그래픽 계산에 집중합니다.

- 좌표 계산
- 색상 계산
- 조명 계산
- 텍스처 처리
- 픽셀 효과

또한 GLSL에서는 변수의 자료형이 중요합니다. 예를 들어 `float`와 `int`를 함부로 섞어 계산하면 오류가 발생할 수 있습니다.

## 5. 한눈에 보는 전체 구조

text

```
자바스크립트
    │
    │ 정점 위치, 색상, 시간 등을 전달
    ▼
WebGL2
    │
    ├── 정점 셰이더
    │       └── 정점의 화면 위치 계산
    │
    ├── 삼각형 조립
    │
    └── 프래그먼트 셰이더
            └── 픽셀의 최종 색상 계산
                    │
                    ▼
                 화면 출력
```

처음에는 다음 순서로 공부하면 좋습니다.

1. 색이 하나인 삼각형 그리기
2. 정점마다 다른 색 주기
3. `uniform`으로 색상 바꾸기
4. 시간에 따라 움직이는 애니메이션 만들기
5. 텍스처와 조명 추가하기
6. 행렬을 사용해 3D 물체 다루기
