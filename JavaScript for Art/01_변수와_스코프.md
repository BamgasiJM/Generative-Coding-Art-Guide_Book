## 개념 설명

스코프(Scope)는 변수가 살아있는 유효 범위를 의미합니다. 현대 자바스크립트(ES6+)에서는 `var` 사용을 지양하고 `let`과 `const`를 사용하여 블록 스코프(Block Scope)를 따르는 것이 표준입니다.

1. **전역 스코프 (Global Scope)**: 코드 어디서든 접근할 수 있습니다. p5.js에서는 `setup`과 `draw`사이에서 상태를 공유하기 위해 사용되지만, 너무 많이 쓰면 변수 이름이 충돌하거나 오염될 수도 있습니다.
2. **블록 스코프 (Block Scope)**: 중괄호 `{...}` 내부에서만 유효합니다. `if`,`for`, `function`의 내부에서 선언된 `let` 변수는 밖으로 새어 나가지 않습니다.
3. `const` vs `let`
   * `const` : 선언 후 재할당이 불가능합니다. 이 변수의 값은 프로그램 실행 내내 바뀌지 않는다는 것을 보장합니다. 캔버스 크기, 최초 설정값, 불변 객체에 사용합니다.
   * `let` : 값이 바뀌어야 하는 경우에 사용합니다. 움직이는 좌표, 반복문의 카운터에 사용합니다.

## p5.js 예시: 상태 유지와 초기화 방지

* 애니메이션을 위해 계속 값을 기억해야 하는 변수(위치, 속도)는 `setup`의 바깥, 즉 **전역**에 선언합니다.
* `draw()`함수 안에 변수를 선언하면(`let x = 0`), 매 프레임마다 변수가 `0`으로 초기화되어 애니메이션이 되지 않습니다.

```javascript
// [전역 스코프]
// setup과 draw 함수 모두에서 접근해야 하며, 값이 유지되어야 합니다.
let x = 0; 
let speed = 2;

function setup() {
  createCanvas(400, 400);
}

function draw() {
  background(220);
  
  // [블록 스코프] - 잘못된 예시
  // let x = 0; // 만약 여기서 선언하면 매 프레임 0으로 초기화되어 움직이지 않습니다!
  
  // 원 그리기
  ellipse(x, height / 2, 50, 50);
  
  // 변수 업데이트 (전역 변수 수정)
  x += speed;
  
  // 경계 체크
  if (x > width || x < 0) {
    speed *= -1;
  }
  
  // [블록 스코프] - 올바른 예시
  // 이 for 루프의 'i'는 루프가 끝나면 즉시 메모리에서 사라집니다.
  // 다른 곳의 'i' 변수와 충돌하지 않습니다.
  for (let i = 0; i < 5; i++) {
    noFill();
    ellipse(x, height / 2, 50 + i * 10, 50 + i * 10);
  }
}
```

## three.js 예시: 메모리 관리와 임시 변수

* 초당 60회 실행하는 Three.js의 `animate`루프 안에서 변수를 `let`이나 `const`로 계속 선언하고 객체(`new Vector3`)를 생성하면 **Garbage Collector**가 찌꺼기를 치우느라 프레임 드랍이 발생할 수 있습니다.
* 계산용 임시 객체는 루프의 바깥, 즉 전역 또는 상위 스코프에 미리 만들어두고, 값만 바꿔 쓰는 것이 성능 측면에서 좋습니다.

```javascript
import * as THREE from 'three';

// [모듈/전역 스코프]
// 씬, 카메라, 렌더러는 애플리케이션 수명과 함께합니다.
// 재할당할 일이 없으므로 const를 사용합니다.
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
const renderer = new THREE.WebGLRenderer();

// 큐브 생성
const geometry = new THREE.BoxGeometry();
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

camera.position.z = 5;

// [중요!] 계산을 위한 임시 변수 미리 선언
// animate 함수 안에서 'new THREE.Vector3()'를 하지 않기 위함입니다.
const tempVector = new THREE.Vector3(); 

function animate() {
  requestAnimationFrame(animate);

  // 1. 상태 업데이트
  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;

  // 2. 임시 변수 활용 (메모리 효율적 방식)
  // 매 프레임 새로운 객체를 만들지 않고, tempVector의 값만 바꿉니다.
  tempVector.set(Math.sin(Date.now() * 0.001), 0, 0);
  cube.position.copy(tempVector);

  // 3. 렌더링
  renderer.render(scene, camera);
}

animate();
```

## 요약

* p5.js: 움직이는 물체의 변수는 `draw()` 밖에 선언하세요.
* Three.js: `animate()` 루프 안에서는 `new` 키워드 사용(변수 선언 포함)을 최대한 자제하고, 바깥에 만들어 둔 변수를 재활용하세요.
