## 개념 설명

자바스크립트의 데이터 타입은 크게 두 가지로 나뉩니다. 이 둘의 차이를 \*\*'종이 복사'\*\*와 \*\*'구글 문서 공유'\*\*로 비유할 수 있습니다.

1. 원시 타입 (Primitive Type) = 종이 복사:
   * `Number`, `String`, `Boolean` 등이 해당됩니다.
   * 변수에 값을 할당하면 그 값이 복사됩니다. 원본을 수정해도 복사본은 변하지 않습니다.
   * `a = 10`, `b = a` 에서 `a`를 20으로 바꾸어도 `b`는 여전히 10입니다.
2. 참조 타입 (Reference Type) = 구글 문서 공유:
   * `Object`, `Array`, 그리고 p5.js의 `p5.Vector`, three.js의 `THREE.Vector3`가 모두 여기에 해당합니다.
   * 변수에는 실제 값이 아니라 \*\*메모리 주소(참조)\*\*가 저장됩니다.
   * 다른 변수에 할당하면 주소만 복사됩니다. 즉, 두 변수가 하나의 실제 객체를 바라보게 되는 것입니다.

## p5.js 예시: 벡터의 함정

상황: 이 코드에서는 파티클 `v1`의 위치를 `v2`에 복사해서 `v2`만 다른 곳으로 이동시키고 싶습니다. 하지만 그냥 대입(`=`)하면 둘 다 같이 움직여버리게 됩니다.

```javascript
let v1, v2;

function setup() {
  createCanvas(400, 400);
  
  // v1 생성 (x: 100, y: 100)
  v1 = createVector(100, 100);
  
  // [❌ 잘못된 방법] 참조 할당
  // v2는 v1과 같은 '주소'를 가리킵니다. (동일한 객체)
  // v2 = v1; 
  
  // [✅ 올바른 방법] 값 복사 (Copy)
  // v1의 x, y 값을 복제하여 완전히 새로운 벡터 객체를 만듭니다.
  v2 = v1.copy(); 
}

function draw() {
  background(220);
  
  // 시각적 확인
  fill(255, 0, 0); // 빨간색: v1
  ellipse(v1.x, v1.y, 30, 30);
  
  fill(0, 0, 255); // 파란색: v2
  ellipse(v2.x, v2.y, 30, 30);
  
  // v2만 오른쪽으로 이동시키고 싶음
  v2.add(1, 0); 
  
  // 만약 위에서 'v2 = v1'을 했다면, 
  // v1도 같이 움직여서 빨간 원과 파란 원이 겹쳐서 다닐 것입니다.
  // .copy()를 했기 때문에 파란 원(v2)만 분리되어 움직입니다.
}
```

## three.js 예시: 불필요한 객체 생성 금지

상황: 이 코드에서는 3D 물체의 위치를 매 프레임 업데이트하려고 합니다. 이때 참조의 특성을 이용해 \*\*기존 객체를 재활용(Mutation)\*\*해야 좋은 성능을 낼 수 있습니다.

```javascript
import * as THREE from 'three';

const scene = new THREE.Scene();
const mesh = new THREE.Mesh(
    new THREE.BoxGeometry(), 
    new THREE.MeshBasicMaterial({ color: 0xffff00 })
);
scene.add(mesh);

// 목표 지점 벡터
const targetPos = new THREE.Vector3(5, 5, 5);

function updateObject() {
  // [❌ 비효율적인 방법]
  // 매번 새로운 객체를 생성하여 할당합니다.
  // 이전의 position 객체는 버려지고 가비지 컬렉터(GC)가 청소해야 합니다.
  // 또한, position에 연결된 내부 렌더링 최적화 연결이 끊길 수도 있습니다.
  // mesh.position = new THREE.Vector3(1, 2, 3); 

  // [✅ 올바른 방법 1] 값 설정 (Set)
  // mesh.position 객체는 그대로 두고, 내부의 x, y, z 숫자값만 바꿉니다.
  // 가장 빠르고 효율적입니다.
  mesh.position.set(1, 2, 3);

  // [✅ 올바른 방법 2] 값 복사 (Copy)
  // 다른 벡터(targetPos)의 값을 가져와서 내 값으로 덮어씁니다.
  mesh.position.copy(targetPos);
  
  // 참고: const로 선언된 객체도 내부 속성은 변경 가능합니다.
  // const myPos = new THREE.Vector3();
  // myPos.x = 10; // 가능! (참조 주소는 그대로이므로)
}

// 렌더 루프 등에서 updateObject() 호출...
```

## 요약

* p5.js: 벡터를 따로 쓰고 싶다면 반드시 `.copy()`를 기억하세요.
* Three.js: 기존 객체를 버리고(`= new`) 새로 만들지 마세요. 있는 객체의 값을 바꾸세요(`.set()`, `.copy()`). 이것이 초당 60프레임 성능 유지의 비결입니다.
