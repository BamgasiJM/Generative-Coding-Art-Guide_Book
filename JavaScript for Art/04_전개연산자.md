## 개념 설명

전개 연산자(`...`)(Spread Operator)는 뭉쳐 있는 데이터(배열, 객체)를 개별 요소로 **'펼쳐서(Spread)'** 줍니다. 주로 **데이터 복사, 병합, 함수의 인자 전달**에 사용됩니다.

## p5.js 예시 : 배열 병합과 인자 전달

상황: 기존 파티클 리스트에 새로운 파티클 그룹을 합치거나, 배열에 들어있는 색상 값(RGB)을 `fill()` 함수에 한 번에 넣고 싶을 때 사용합니다.

```javascript
let baseColors = [255, 100, 100]; // R, G, B
let particles = [];

function setup() {
  createCanvas(400, 400);

  let groupA = [new Particle(), new Particle()];
  let groupB = [new Particle(), new Particle()];

  // [배열 병합]
  // 기존 방식: for 루프나 particles.concat(groupA) 사용
  // 전개 연산자: 직관적으로 배열을 펼쳐서 넣습니다.
  particles = [...groupA, ...groupB];
}

function draw() {
  // [인자 전달]
  // fill(baseColors[0], baseColors[1], baseColors[2]) 대신 사용
  // 배열의 요소를 콤마로 구분된 인자로 펼쳐줍니다.
  fill(...baseColors); 
  
  // ... 생략
}
```

## Three.js 예시 : 옵션 객체 병합 (Override)

상황: 기본(Default) 머티리얼 설정을 만들어두고, 특정 물체만 색상을 바꾸고 싶을 때 설정 덮어쓰기 용도로 가장 많이 사용합니다.

```javascript
// 기본 설정 (모든 큐브가 공유할 베이스)
const baseSettings = {
  transparent: true,
  opacity: 0.5,
  wireframe: false
};

// [객체 병합]
// 1. baseSettings를 펼칩니다 (...baseSettings)
// 2. 그 뒤에 color 속성을 추가합니다.
// 3. 만약 baseSettings에 color가 있었다면, 뒤에 오는 값이 덮어씁니다.
const materialRed = new THREE.MeshBasicMaterial({
  ...baseSettings, 
  color: 0xff0000 
});

const materialBlue = new THREE.MeshBasicMaterial({
  ...baseSettings,
  color: 0x0000ff,
  opacity: 0.8 // 기본값 0.5를 0.8로 덮어씀
});
```
