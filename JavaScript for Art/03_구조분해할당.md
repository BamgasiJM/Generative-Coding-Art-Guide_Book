## 개념 설명

**구조 분해 할당(Destructuring Assignment)**은 객체나 배열이라는 "포장 박스"안에 들어있는 내용물을 꺼내서, 각각 별도의 변수에 담아주는 문법입니다.

* 기존 방식: `let x = player.position.x;` 매번 점(.)을 찍어서 접근
* 구조 분해: `const { x, y } = player.position;` 필요한 것만 뽑아서 변수로 선언
* 코드가 훨씬 짧아지고, `data.properties.attributes...`처럼 길어지는 접근 경로를 제거해 가독성을 높입니다.

## p5.js 예시 : 복잡한 데이터 다루기

상황: 날씨 API나 외부 JSON 데이터를 받아와서 시각화할 때 유용합니다. 데이터 구조가 깊을 때 빛을 발합니다.

```javascript
// 가상의 날씨 데이터 (외부 API에서 로드했다고 가정)
let weatherData = {
  coord: { lon: 139, lat: 35 },
  main: { temp: 25.5, humidity: 80 },
  wind: { speed: 5.1, deg: 180 },
  sys: { country: "JP", sunrise: 1620000000 }
};

function setup() {
  createCanvas(400, 400);
  noLoop();
}

function draw() {
  background(200);

  // [❌ 기존 방식]
  // 코드가 길어지고 'weatherData'를 계속 반복해서 써야 합니다.
  let t = weatherData.main.temp;
  let h = weatherData.main.humidity;
  let s = weatherData.wind.speed;
  
  text(`Temp: ${t}`, 50, 50);

  // [✅ 구조 분해 할당 사용]
  // 1. 필요한 객체만 먼저 꺼냅니다.
  const { main, wind } = weatherData;
  
  // 2. 더 깊숙이 들어가서 변수 이름을 바꿔서 꺼낼 수도 있습니다.
  // main.temp를 'temperature'라는 변수로 꺼냄
  const { temp: temperature, humidity } = main; 
  const { speed } = wind;

  // 훨씬 직관적으로 변수를 사용할 수 있습니다.
  fill(0);
  textSize(20);
  text(`Temperature: ${temperature}°C`, 50, 100);
  text(`Humidity: ${humidity}%`, 50, 130);
  text(`Wind Speed: ${speed}m/s`, 50, 160);
}
```

## Three.js 예시 : 설정 객체(Config Object) 패턴

상황: 나만의 3D 객체 생성 함수를 만들 때, 인자를 순서대로(`x, y, z, color, size...`)로 나열하면 순서를 외우기 힘듭니다. 대신 **하나의 객체**로 받고 함수 내부에서 구조 분해하는 패턴이 효율적입니다.

```javascript
import * as THREE from 'three';

// [✅ 구조 분해 할당을 활용한 함수 정의]
// 인자로 받은 객체에서 radius, color, x, y를 바로 추출합니다.
// '=' 기호를 통해 기본값(Default Value)도 설정할 수 있습니다.
function createPlanet({ 
  radius = 1, 
  color = 0xffffff, 
  x = 0, 
  y = 0 
} = {}) { // = {} 는 인자 없이 호출해도 에러가 안 나게 하는 안전장치입니다.
  
  const geometry = new THREE.SphereGeometry(radius, 32, 32);
  const material = new THREE.MeshBasicMaterial({ color }); // { color: color }의 단축 표현
  const mesh = new THREE.Mesh(geometry, material);
  
  mesh.position.set(x, y, 0);
  
  return mesh;
}

// 사용하는 쪽 (순서를 신경 쓸 필요가 없습니다!)
const sun = createPlanet({ 
  radius: 5, 
  color: 0xffff00 
});

const earth = createPlanet({ 
  color: 0x0000ff, 
  x: 10, 
  radius: 2 
});

// Three.js 내부에서도 벡터나 색상을 다룰 때 자주 씁니다.
const config = { width: 100, height: 200, depth: 50 };
const boxGeo = new THREE.BoxGeometry(config.width, config.height, config.depth);
// 위 코드를 구조 분해로 쓰면?
// const { width, height, depth } = config;
// new THREE.BoxGeometry(width, height, depth);
```
