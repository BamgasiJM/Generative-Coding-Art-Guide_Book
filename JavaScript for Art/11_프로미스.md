## 개념 설명

**프로미스**는 "지금은 없지만, 나중에 줄게"라는 약속을 담은 객체입니다. 이미지, 3D 모델, 사운드 등 **용량이 큰 파일**을 불러올 때, 코드가 멈추지 않고(Non-blocking) 백그라운드에서 로딩을 계속하게 해줍니다.

* **Pending** (대기) : 로딩 중
* **Fulfilled** (이행) : 로딩 성공! (데이터 도착)
* **Rejected** (거부) : 로딩 실패 (404 에러 등)

## p5.js 예시 : 외부 API 데이터 가져오기 (Fetch)

상황: `preload()`는 p5.js가 알아서 기다려주지만, `setup()` 이후에 버튼을 눌러서 데이터를 가져올 때는 \*\*`fetch` API(프로미스 기반)\*\*를 써야 합니다.

```javascript
function setup() {
  createCanvas(400, 200);
  background(200);
  
  let btn = createButton('고양이 사진 가져오기');
  btn.mousePressed(loadCatData);
}

function loadCatData() {
  // 1. fetch는 'Promise'를 반환합니다. (즉시 데이터를 주지 않음)
  fetch('https://api.thecatapi.com/v1/images/search')
    .then(response => response.json()) // 2. 서버 응답이 오면 JSON으로 변환
    .then(data => {
      // 3. 변환이 끝나면 실제 데이터를 사용
      console.log("데이터 도착!", data);
      let imgUrl = data[0].url;
      loadImage(imgUrl, img => {
        image(img, 0, 0, 100, 100); // 4. 이미지 그리기
      });
    })
    .catch(error => {
      // 5. 에러 처리 (인터넷 끊김 등)
      console.error("에러 발생:", error);
    });
    
  console.log("이 로그가 먼저 찍힙니다. 로딩은 백그라운드에서 진행되니까요!");
}
```

## Three.js 예시 : 비동기 로더 메서드

상황: Three.js의 로더들은 기본적으로 콜백(`onload`) 방식을 쓰지만, 최신 버전에서는 `.loadAsync()` 메서드를 제공합니다. 이는 프로미스를 반환하므로 콜백 지옥을 피할 수 있게 해줍니다.

```javascript
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';

const loader = new GLTFLoader();

// Promise 방식
const modelPromise = loader.loadAsync('robot.glb');

modelPromise
  .then((gltf) => {
    // 로딩 성공 시 실행
    scene.add(gltf.scene);
    console.log("로봇 로딩 완료!");
  })
  .catch((err) => {
    // 로딩 실패 시 실행
    console.error("로봇을 찾을 수 없습니다.", err);
  });
```
