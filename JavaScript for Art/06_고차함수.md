## 개념 설명

함수를 데이터처럼 다루는 기법입니다. 배열의 데이터를 변환(`map`), 필터링(`filter`), 순회(`forEach`)할 때 `for` 루프보다 의도가 훨씬 명확해집니다.

## p5.js 예시 : 파티클 시스템 관리

화면 밖으로 나간 파티클을 배열에서 제거하고, 살아있는 파티클만 업데이트합니다.

```javascript
let particles = [];

function draw() {
  background(0);
  
  // 1. 업데이트 및 그리기 (forEach)
  // "모든 파티클에 대해 update와 display를 수행하라"는 의도가 명확함
  particles.forEach(p => {
    p.update();
    p.display();
  });
  
  // 2. 죽은 파티클 제거 (filter)
  // "화면 안에 있는(y < height) 애들만 남겨라"
  // for 루프에서 배열 요소를 삭제할 때 생기는 인덱스 오류를 걱정할 필요가 없습니다.
  particles = particles.filter(p => p.y < height);
  
  // *성능 팁: 파티클이 수천 개일 때는 일반 for 루프가 더 빠를 수 있습니다.
  // 하지만 수백 개 수준에서는 가독성이 좋은 고차 함수를 추천합니다.
}
```

## Three.js 예시 : 씬 그래프 순회

상황: 로드된 3D 모델(집) 안에 있는 모든 자식 요소(창문, 문, 지붕 등)를 찾아서 그림자 설정을 켜야 하는 상황을 상정해 봅시다.

```javascript
const loader = new GLTFLoader();

loader.load('house.glb', (gltf) => {
  const model = gltf.scene;
  
  // [Three.js 내장 고차 함수: traverse]
  // 모델의 모든 하위 자식들을 재귀적으로 방문하며 함수를 실행합니다.
  model.traverse((child) => {
    // 만약 이 자식이 'Mesh(메쉬)'라면 그림자를 켭니다.
    if (child.isMesh) {
      child.castShadow = true;
      child.receiveShadow = true;
    }
  });
  
  scene.add(model);
});
```
