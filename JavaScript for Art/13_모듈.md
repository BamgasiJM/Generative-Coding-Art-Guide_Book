## 개념 설명

코드가 1,000줄이 넘어가면 파일 하나(`index.html` 또는 `script.js`)에 모든 걸 적는 건 관리가 불가능합니다. \*\*모듈(import/export)\*\*을 사용하면 기능별로 파일을 분리하여("캐릭터 파일", "맵 파일", "컨트롤 파일") 관리할 수 있습니다.

* **export**: 이 변수나 클래스를 다른 파일에서 쓸 수 있게 내보냅니다.
* **import**: 다른 파일에 있는 걸 가져옵니다.

## p5.js 예시 : 클래스 파일 분리

HTML 파일에서 스크립트를 불러올 때 `type="module"`을 써야 합니다.

```html
<script type="module" src="sketch.js"></script>`
```

**파일 1: Circle.js (부품)**

```javascript
// export default: 이 파일의 대표 선수는 이 클래스다!
export default class Circle {
  constructor(x, y) {
    this.x = x;
    this.y = y;
  }
  show(p) { // p5 인스턴스(p)를 받아서 그림
    p.ellipse(this.x, this.y, 50, 50);
  }
}
```

**파일 1: sketch.js (메인)**

```javascript
import Circle from './Circle.js'; // 분리된 파일 가져오기

// 모듈 모드에서는 전역 함수(setup, draw)가 자동으로 window에 안 붙습니다.
// 따라서 window 객체에 직접 붙여주거나, p5 Instance Mode를 써야 합니다.
let c;

window.setup = function() {
  createCanvas(400, 400);
  c = new Circle(200, 200);
};

window.draw = function() {
  background(220);
  // 전역 p5 객체를 인자로 넘겨줌 (p5 인스턴스 모드가 아닐 경우)
  c.show(window); 
};
```

## Three.js 예시 : 표준 개발 환경

Three.js는 사실상 모듈 시스템이 표준입니다. 라이브러리 자체를 임포트하고, 추가 기능(`OrbitControls` 등)도 따로 임포트합니다.

```javascript
// 1. Three.js 코어 가져오기
import * as THREE from 'three';

// 2. 추가 기능(애드온) 가져오기
import { OrbitControls } from 'three/examples/jsm/controls/OrbitControls.js';

// 3. 나만의 모듈 가져오기
import { createLighting } from './lights.js';

//======================================================//
const scene = new THREE.Scene();
// ...

const controls = new OrbitControls(camera, renderer.domElement);

createLighting(scene); // 다른 파일에 정의된 함수 사용
```
