## 개념 설명

* **Map**: "열쇠(Key)"와 "값(Value)"의 쌍입니다. 일반 객체(`{}`)와 비슷하지만, 키로 문자열뿐만 아니라 객체나 함수도 사용 가능하며 데이터 추가/삭제가 더 빈번할 때 성능이 좋습니다.
* **Set**: \*\*"중복을 허용하지 않는 주머니"\*\*입니다. 똑같은 값을 두 번 넣어도 하나만 남습니다. 고유한 값 관리나 빠른 존재 여부 확인(`has`)에 탁월합니다.

## p5.js 예시 : 공간 분할과 중복 방지 (Set)

상황: 랜덤하게 점을 찍는데, 이미 점이 있는 좌표에는 다시 찍고 싶지 않습니다. 배열을 `for`문으로 뒤지면 느리지만, `Set`을 쓰면 순식간에 확인합니다.

```javascript
let usedPositions = new Set(); // 방문 기록부

function setup() {
  createCanvas(400, 400);
  background(220);
  
  for (let i = 0; i < 1000; i++) {
    // 10픽셀 단위로 좌표를 정수로 만듦 (100, 200)
    let x = floor(random(width) / 10) * 10;
    let y = floor(random(height) / 10) * 10;
    
    // 고유 키 생성 (예: "100,200")
    let key = `${x},${y}`;
    
    // 이미 이 자리에 점을 찍었는지 확인 (O(1) 속도 - 엄청 빠름)
    if (!usedPositions.has(key)) {
      rect(x, y, 10, 10);
      usedPositions.add(key); // 기록 추가
    }
  }
}
```

## Three.js 예시 : 에셋 매니저 (Map)

상황: 게임이나 인터랙티브 웹사이트에서 이름으로 3D 모델이나 텍스처를 관리합니다.

```javascript
// 에셋 저장소
const assets = new Map();

// 로딩 함수 (가정)
function loadAssets() {
  const loader = new THREE.TextureLoader();
  
  // 로드 후 Map에 저장
  // 키: 'grass', 값: 텍스처 객체
  loader.load('grass.jpg', (texture) => {
    assets.set('grass', texture); 
    console.log("Grass loaded!");
    
    // 나중에 필요할 때 꺼내 쓰기
    applyTexture();
  });
}

function applyTexture() {
  // 'grass'라는 키가 있는지 확인
  if (assets.has('grass')) {
    const mat = new THREE.MeshBasicMaterial({ 
      map: assets.get('grass') // 텍스처 꺼내기
    });
    // ... 메쉬에 적용
  }
}
```
