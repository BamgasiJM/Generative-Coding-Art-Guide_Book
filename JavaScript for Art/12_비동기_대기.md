## 개념 설명

**async / await**는 프로미스를 더 쉽게 쓰기 위한 Syntactic Sugar입니다. `.then().then()` 체이닝이 길어지면 읽기 힘들어지는데, 이를 마치 동기 코드(순서대로 실행되는 코드)처럼 보이게 만들어줍니다. "기다려(`await`)!"라고 하면 로딩이 끝날 때까지 다음 줄로 넘어가지 않습니다.

## p5.js 예시 : 순차적 실행 보장

상황:"데이터 로드 -> 분석 -> 시각화" 순서를 명확하게 제어하고 싶을 때 사용합니다.

```javascript
// async 키워드를 붙여 비동기 함수로 선언
async function getDataAndDraw() {
  console.log("1. 데이터 요청 시작");
  
  try {
    // await: fetch가 끝날 때까지 여기서 멈춰서 기다립니다.
    let response = await fetch('https://api.coindesk.com/v1/bpi/currentprice.json');
    let data = await response.json();
    
    console.log("2. 데이터 도착 완료");
    
    // 데이터가 확실히 온 뒤에 실행됨
    let price = data.bpi.USD.rate_float;
    background(0);
    fill(255);
    text(`Bitcoin: $${price}`, 50, 50);
    
  } catch (error) {
    console.error("데이터를 못 가져왔어요:", error);
  }
}

function mousePressed() {
  getDataAndDraw();
}
```

## Three.js 예시 : 여러 모델 동시 로딩 (Promise.all)

상황: 주인공, 배경, 적 캐릭터 3개의 모델이 모두 로딩된 후에 게임을 시작하고 싶습니다. 하나씩 기다리면(`await` 3번) 너무 느리므로, 병렬로 동시에 시킵니다.

```javascript
async function initGame() {
  const loader = new GLTFLoader();
  
  console.log("로딩 시작...");

  try {
    // [병렬 처리] 3개를 동시에 로딩 시작하고, 다 끝날 때까지 기다림
    // Promise.all은 배열 안의 모든 Promise가 끝나면 결과를 배열로 줍니다.
    const [hero, enemy, environment] = await Promise.all([
      loader.loadAsync('hero.glb'),
      loader.loadAsync('enemy.glb'),
      loader.loadAsync('map.glb')
    ]);

    // 여기까지 오면 3개 다 로딩 성공한 것임
    scene.add(hero.scene);
    scene.add(enemy.scene);
    scene.add(environment.scene);
    
    console.log("모든 에셋 로딩 완료! 게임 시작!");
    animate(); // 렌더 루프 시작
    
  } catch (err) {
    console.error("로딩 중 하나라도 실패함:", err);
  }
}

initGame();
```
