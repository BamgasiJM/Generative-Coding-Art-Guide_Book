## 개념 설명

일반 자바스크립트 배열(`[]`)은 유연하지만 메모리를 많이 씁니다. 반면 \*\*Typed Array(형식화 배열)\*\*는 C언어의 배열처럼 연속된 메모리 공간에 숫자만 빽빽하게 저장합니다. WebGL(Three.js의 기반)과 데이터를 주고받을 때 필수적입니다.

## p5.js 예시 : 동적 배열 관리

상황: 클릭할 때마다 파티클을 추가하고, 너무 많아지면 오래된 것을 지웁니다. 일반 배열의 유연함(`push`, `splice`)을 활용합니다.

```javascript
let systems = [];

function mousePressed() {
  // 클릭한 위치에 새로운 시스템 추가 (배열 끝에 추가)
  systems.push(new ParticleSystem(mouseX, mouseY));
  
  // 10개가 넘어가면 가장 오래된 것(첫 번째) 삭제
  if (systems.length > 10) {
    systems.splice(0, 1); // 0번 인덱스부터 1개 삭제
  }
}
```

## Three.js 예시 : 버퍼 지오메트리와 Typed Array

상황: 수만 개의 점을 가진 지오메트리를 직접 만들거나 조작해야 합니다. 이때는 일반 배열을 쓰면 렌더링이 불가능할 정도로 느립니다. \*\*`Float32Array`\*\*를 써야 GPU에 고속도로처럼 데이터를 쏠 수 있습니다.

```javascript
// 삼각형 1개를 만들기 위한 커스텀 지오메트리
const geometry = new THREE.BufferGeometry();

// 3개의 점(Vertex) * 3개의 좌표(x, y, z) = 9개의 숫자
// Float32Array는 32비트 부동소수점 숫자를 저장하는 전용 배열입니다.
const vertices = new Float32Array([
  -1.0, -1.0,  1.0, // 점 1 (x, y, z)
   1.0, -1.0,  1.0, // 점 2
   1.0,  1.0,  1.0  // 점 3
]);

// Three.js에게 "이건 위치 데이터야"라고 알려줍니다. (3개씩 끊어 읽어라)
geometry.setAttribute('position', new THREE.BufferAttribute(vertices, 3));

const material = new THREE.MeshBasicMaterial({ color: 0xff0000 });
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

// 나중에 정점을 움직이고 싶을 때:
// vertices[0] += 0.01; // 배열 값을 직접 수정
// geometry.attributes.position.needsUpdate = true; // GPU에 "데이터 바꼈어!" 알림
```
