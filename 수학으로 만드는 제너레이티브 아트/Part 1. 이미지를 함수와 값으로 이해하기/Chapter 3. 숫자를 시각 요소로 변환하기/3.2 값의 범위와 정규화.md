# 3.2 값의 범위와 정규화

값을 다른 시각 요소에 연결하려면 먼저 그 값이 어느 범위에 있는지 알아야 한다. 거리값이 0에서 500 사이인지, 노이즈 값이 0에서 1 사이인지, 사인 함수의 결과가 -1에서 1 사이인지에 따라 변환 방식이 달라진다. 범위를 모른 채 값을 색이나 크기에 연결하면 출력이 너무 작거나, 허용 범위를 벗어나거나, 변화가 거의 보이지 않을 수 있다.

정규화는 어떤 범위의 값을 기준 범위로 옮기는 과정이다. 가장 흔한 기준은 0에서 1 사이다. 정규화된 값은 원래 단위에서 분리된 비율이므로 색, 크기, 위치 등 여러 출력 범위로 다시 변환하기 쉽다.

## 최솟값과 최댓값으로 범위 표현하기

값 $x$가 최솟값 $a$와 최댓값 $b$ 사이에 있다고 하자.

$$
x\in[a,b]
$$

이 범위의 폭은 $b-a$다. 현재 값이 최솟값에서 얼마나 떨어져 있는지는 $x-a$다. 두 값을 나누면 전체 범위에서 현재 값이 차지하는 비율을 얻는다.

$$
t=\frac{x-a}{b-a}
$$

$x=a$이면 $t=0$, $x=b$이면 $t=1$이다. $x$가 두 값의 중간이면 $t=0.5$가 된다. 이 계산을 최소-최대 정규화라고 부른다.

```text
function normalize(value, minimum, maximum):
    return (value - minimum) / (maximum - minimum)
```

이 함수는 특정 그래픽 라이브러리에 의존하지 않는다. 같은 식을 어떤 언어에서도 사용할 수 있다.

## 정규화는 위치를 비율로 바꾼다

정규화의 의미는 원래 범위 안의 위치를 비율로 표현하는 것이다. 예를 들어 온도 범위가 10도에서 30도이고 현재 온도가 15도라면 다음과 같다.

$$
t=\frac{15-10}{30-10}=0.25
$$

현재 값은 전체 범위의 25퍼센트 지점에 있다. 이 값을 밝기에 연결하면 25퍼센트 밝기, 막대 길이에 연결하면 전체 길이의 25퍼센트로 나타낼 수 있다.

좌표도 같은 방식으로 정규화할 수 있다. 화면 너비가 $W$이고 $x$좌표 범위가 0에서 $W$라면 다음 식은 앞 장의 정규화 좌표와 같다.

$$
u=\frac{x-0}{W-0}=\frac{x}{W}
$$

좌표 정규화와 데이터 정규화는 서로 다른 기술이 아니라 같은 범위 변환 원리를 사용한다.

## 대표적인 함수의 출력 범위

그래픽에서 자주 사용하는 함수의 범위를 알고 있으면 다음 변환을 설계하기 쉽다.

| 값 또는 함수 | 흔한 범위 | 주의할 점 |
| --- | --- | --- |
| 정규화 좌표 | $[0,1]$ | 영역 밖에서는 범위를 벗어날 수 있다. |
| 사인과 코사인 | $[-1,1]$ | 음수와 양수를 모두 포함한다. |
| 일반적인 노이즈 함수 | 구현에 따라 다름 | $[0,1]$ 또는 $[-1,1]$일 수 있다. |
| 벡터의 길이 | $[0,\infty)$ | 실제 최댓값은 공간 범위에 따라 정한다. |
| 내적 | 벡터가 단위 벡터라면 $[-1,1]$ | 정규화되지 않은 벡터에서는 범위가 달라진다. |
| 8비트 색상 채널 | 정수 $[0,255]$ | 부동소수점 색상은 보통 $[0,1]$이다. |

함수 이름만 보고 범위를 가정하지 않는 것이 중요하다. 노이즈, 텍스처 샘플, 센서 입력, 외부 데이터의 범위는 환경과 데이터에 따라 다르다.

## 음수와 양수를 포함하는 범위 정규화하기

사인 함수처럼 -1에서 1 사이의 값을 0에서 1로 옮겨 보자.

$$
t=\frac{x-(-1)}{1-(-1)}=\frac{x+1}{2}
$$

따라서 다음과 같이 간단히 쓸 수 있다.

$$
t=0.5x+0.5
$$

```text
signedValue = sin(angle)
normalizedValue = signedValue * 0.5 + 0.5
```

반대로 0에서 1 사이의 값을 -1에서 1 사이로 되돌리려면 다음 식을 사용한다.

$$
x=2t-1
$$

이 두 변환은 파동값을 밝기로 사용하거나, 정규화된 값을 양방향 변위로 사용할 때 자주 등장한다.

## 범위 밖의 값

정규화 식은 입력이 $[a,b]$ 안에 있을 때 $[0,1]$을 반환한다. 입력이 범위를 벗어나면 결과도 0보다 작거나 1보다 커진다.

예를 들어 $a=0$, $b=100$, $x=130$이면 다음과 같다.

$$
t=\frac{130}{100}=1.3
$$

이것이 반드시 오류인 것은 아니다. 범위 밖의 비율을 유지하면 외삽에 사용할 수 있다. 그러나 색상이나 투명도처럼 허용 범위를 지켜야 하는 출력에서는 값을 제한해야 할 수 있다.

```text
t = normalize(value, minimum, maximum)
tClamped = clamp(t, 0, 1)
```

정규화와 제한은 서로 다른 연산이다. 정규화는 범위를 비율로 바꾸고, 제한은 범위 밖의 값을 경계에 고정한다. 두 연산을 하나처럼 취급하면 범위 밖 정보가 필요한 경우를 놓칠 수 있다.

## 최솟값과 최댓값이 같은 경우

정규화 식의 분모는 $b-a$다. 두 경계가 같으면 0으로 나누게 된다.

$$
b-a=0
$$

모든 데이터가 같은 값이거나, 아직 표본이 하나뿐인 경우 이런 상황이 생길 수 있다. 이때 무엇을 반환할지는 용도에 따라 정해야 한다.

```text
function safeNormalize(value, minimum, maximum):
    range = maximum - minimum

    if abs(range) < epsilon:
        return 0

    return (value - minimum) / range
```

0 대신 0.5를 반환해 중간값으로 표시할 수도 있고, 계산을 건너뛰거나 오류 상태를 기록할 수도 있다. 중요한 것은 0으로 나누는 상황을 의도적으로 처리하는 것이다.

## 이론적 범위와 관측된 범위

정규화에 사용할 최솟값과 최댓값은 두 방식으로 정할 수 있다. 하나는 함수나 데이터 정의에서 알 수 있는 이론적 범위이고, 다른 하나는 실제 표본에서 측정한 범위다.

| 범위 선택 | 장점 | 주의할 점 |
| --- | --- | --- |
| 이론적 범위 | 여러 실행과 장면에서 기준이 일정하다. | 실제 값이 좁은 구간에 몰리면 대비가 약할 수 있다. |
| 관측된 범위 | 현재 데이터의 범위를 충분히 활용한다. | 데이터가 바뀌면 같은 값의 표현도 달라진다. |
| 고정된 설계 범위 | 시각적 의미를 직접 통제할 수 있다. | 범위 밖 입력의 처리 규칙이 필요하다. |

예를 들어 데이터 시각화에서 매 프레임 관측된 최솟값과 최댓값으로 정규화하면 그래프가 계속 늘어나고 줄어들 수 있다. 반면 고정 범위를 쓰면 서로 다른 시점의 값이 같은 시각 척도를 유지한다.

## 이상값이 범위에 미치는 영향

대부분의 값이 0에서 10 사이인데 하나의 값만 1000이라면, 전체 최솟값과 최댓값으로 정규화했을 때 일반 값들은 0 근처에 몰린다. 시각적 차이가 거의 보이지 않을 수 있다.

이럴 때는 다음과 같은 선택을 고려할 수 있다.

- 의미 있는 설계 범위를 직접 정한다.
- 상위와 하위 일부를 제외한 분위수 범위를 사용한다.
- 로그나 제곱근 같은 비선형 변환을 먼저 적용한다.
- 이상값을 별도의 시각 기호로 표시한다.

범위를 정하는 일은 단순한 전처리가 아니다. 무엇을 강조하고 무엇을 같은 척도로 비교할지 결정하는 표현상의 선택이다.

## 벡터와 색의 정규화

“정규화”라는 말은 문맥에 따라 다른 연산을 뜻한다. 값의 범위 정규화는 $[a,b]$를 $[0,1]$로 옮긴다. 벡터 정규화는 벡터의 방향을 유지하면서 길이를 1로 만든다.

$$
\hat{\mathbf{v}}=\frac{\mathbf{v}}{\lVert\mathbf{v}\rVert}
$$

두 연산은 목적과 결과가 다르다. 색상 값을 0에서 255 범위에서 0에서 1로 바꾸는 것은 범위 정규화이고, 방향 벡터를 단위 벡터로 만드는 것은 길이 정규화다. 문맥에 따라 어떤 의미인지 분명히 해야 한다.

## 정규화한 값을 확인하기

값 변환이 예상대로 작동하는지 확인하려면 몇 개의 기준값을 직접 대입해 보는 것이 좋다.

| 입력 $x$ | 정규화 결과 $t$ |
| --- | --- |
| $a$ | 0 |
| $(a+b)/2$ | 0.5 |
| $b$ | 1 |
| $a$보다 작은 값 | 0보다 작음 |
| $b$보다 큰 값 | 1보다 큼 |

최솟값, 중간값, 최댓값을 검사하면 경계와 방향이 맞는지 빠르게 알 수 있다. 출력이 뒤집혀야 한다면 $1-t$를 사용할 수 있고, 범위 밖 값을 허용하지 않는다면 제한 연산을 추가할 수 있다.

## 이 절의 핵심

값을 시각 요소에 연결하려면 원래 범위를 알아야 한다. 최소-최대 정규화는 $[a,b]$의 값을 0에서 1 사이의 비율로 바꾼다.

$$
t=\frac{x-a}{b-a}
$$

정규화된 값은 여러 출력 범위에 다시 사용하기 쉽지만, 범위 밖의 입력과 폭이 0인 범위를 별도로 처리해야 한다. 또한 이론적 범위, 관측된 범위, 설계 범위 중 무엇을 사용할지는 이미지의 비교 기준과 대비에 영향을 준다. 다음 절에서는 값이 범위를 벗어났을 때 고정하거나 반복하고 반사하는 여러 경계 처리 방식을 살펴본다.
