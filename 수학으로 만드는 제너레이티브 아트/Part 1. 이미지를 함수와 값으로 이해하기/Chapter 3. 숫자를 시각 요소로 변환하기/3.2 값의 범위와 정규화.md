# 3.2 값의 범위와 정규화

값을 시각 요소에 연결하려면 먼저 값의 범위를 알아야 한다. 거리값이 0~500인지, 노이즈 값이 0~1인지, 사인 함수의 결과가 -1~1인지에 따라 변환 방식이 달라진다. 범위를 모르면 출력이 지나치게 작거나 허용 범위를 벗어나고, 변화가 거의 드러나지 않을 수 있다.

정규화는 한 범위의 값을 기준 범위로 옮기는 과정이다. 가장 흔히 쓰는 기준 범위는 0~1이다. 정규화된 값은 원래 단위가 없는 비율이므로 색, 크기, 위치 등 다른 출력 범위에 연결하기 쉽다.

## 최솟값과 최댓값으로 범위 표현하기

값 $x$가 최솟값 $a$와 최댓값 $b$ 사이에 있다고 하자.

$$
x\in[a,b]
$$

범위의 폭은 $b-a$이고, $x-a$는 최솟값에서 현재 값까지의 거리다. 두 값을 나누면 전체 범위에서 $x$가 차지하는 비율을 얻는다.

$$
t=\frac{x-a}{b-a}
$$

$x=a$일 때 $t=0$, $x=b$일 때 $t=1$이다. 두 경계의 중간값에서는 $t=0.5$가 된다. 이를 최소-최대 정규화라고 한다.

```text
function normalize(value, minimum, maximum):
    return (value - minimum) / (maximum - minimum)
```

이 식은 특정 그래픽 라이브러리에 의존하지 않으며 어떤 언어에서도 사용할 수 있다.

## 정규화는 위치를 비율로 바꾼다

정규화는 원래 범위에서 값이 차지하는 위치를 비율로 나타낸다. 온도 범위가 10~30도이고 현재 온도가 15도라면 다음과 같다.

$$
t=\frac{15-10}{30-10}=0.25
$$

현재 온도는 범위의 25퍼센트 지점이다. 밝기에 연결하면 25퍼센트 밝기, 막대 길이에 연결하면 전체 길이의 25퍼센트로 표현할 수 있다.

좌표도 같은 방식으로 정규화한다. 화면 너비가 $W$이고 $x$의 범위가 0~$W$라면 다음 식은 앞 장에서 본 정규화 좌표와 같다.

$$
u=\frac{x-0}{W-0}=\frac{x}{W}
$$

좌표와 데이터의 정규화는 같은 범위 변환 원리를 사용한다.

## 대표적인 함수의 출력 범위

그래픽 함수의 출력 범위를 알면 다음 변환을 설계하기 쉽다.

| 값 또는 함수 | 흔한 범위 | 주의할 점 |
| --- | --- | --- |
| 정규화 좌표 | $[0,1]$ | 영역 밖에서는 범위를 벗어날 수 있다. |
| 사인과 코사인 | $[-1,1]$ | 음수와 양수를 모두 포함한다. |
| 일반적인 노이즈 함수 | 구현에 따라 다름 | $[0,1]$ 또는 $[-1,1]$일 수 있다. |
| 벡터의 길이 | $[0,\infty)$ | 실제 최댓값은 공간 범위에 따라 정한다. |
| 내적 | 벡터가 단위 벡터라면 $[-1,1]$ | 정규화되지 않은 벡터에서는 범위가 달라진다. |
| 8비트 색상 채널 | 정수 $[0,255]$ | 부동소수점 색상은 보통 $[0,1]$이다. |

함수 이름만 보고 출력 범위를 단정하지 말아야 한다. 노이즈, 텍스처 샘플, 센서 입력, 외부 데이터의 범위는 구현과 데이터에 따라 다르다.

## 음수와 양수를 포함하는 범위 정규화하기

사인 함수의 출력처럼 -1~1 범위에 있는 값을 0~1로 변환해 보자.

$$
t=\frac{x-(-1)}{1-(-1)}=\frac{x+1}{2}
$$

위 식은 다음과 같이 정리된다.

$$
t=0.5x+0.5
$$

```text
signedValue = sin(angle)
normalizedValue = signedValue * 0.5 + 0.5
```

반대로 0에서 1 사이의 값을 -1에서 1 사이로 되돌리려면 다음 식을 사용한다.

$$
x=2t-1
$$

두 변환은 파동값을 밝기에 연결하거나 정규화된 값을 양방향 변위로 바꿀 때 자주 쓴다.

## 범위 밖의 값

정규화 식은 입력이 $[a,b]$ 안에 있을 때 $[0,1]$ 범위의 결과를 낸다. 입력이 범위를 벗어나면 결과는 0보다 작거나 1보다 커진다.

예를 들어 $a=0$, $b=100$, $x=130$이면 다음과 같다.

$$
t=\frac{130}{100}=1.3
$$

이 결과가 반드시 오류는 아니다. 범위 밖 비율을 유지하면 외삽에 쓸 수 있다. 색상이나 투명도처럼 허용 범위를 지켜야 한다면 값을 제한한다.

```text
t = normalize(value, minimum, maximum)
tClamped = clamp(t, 0, 1)
```

정규화와 제한은 다른 연산이다. 정규화는 값을 비율로 바꾸고, 제한은 범위 밖 값을 경계에 고정한다. 둘을 같은 연산으로 취급하면 외삽처럼 범위 밖 정보가 필요한 경우를 놓칠 수 있다.

## 최솟값과 최댓값이 같은 경우

정규화 식의 분모는 $b-a$다. 두 경계가 같으면 0으로 나누게 된다.

$$
b-a=0
$$

모든 데이터가 같은 값이거나 표본이 하나뿐일 때 이런 상황이 생길 수 있다. 반환값은 용도에 맞게 정한다.

```text
function safeNormalize(value, minimum, maximum):
    range = maximum - minimum

    if abs(range) < epsilon:
        return 0

    return (value - minimum) / range
```

0 대신 0.5를 반환해 중간값으로 표시하거나 계산을 건너뛰고 오류 상태를 기록할 수 있다. 0으로 나누는 경우를 명시적으로 처리해야 한다.

## 이론적 범위와 관측된 범위

정규화에 사용할 최솟값과 최댓값은 이론적 범위나 실제 표본의 관측 범위에서 정할 수 있다. 이론적 범위는 함수나 데이터 정의에서 얻고, 관측 범위는 표본에서 측정한다.

| 범위 선택 | 장점 | 주의할 점 |
| --- | --- | --- |
| 이론적 범위 | 여러 실행과 장면에서 기준이 일정하다. | 실제 값이 좁은 구간에 몰리면 대비가 약할 수 있다. |
| 관측된 범위 | 현재 데이터의 범위를 충분히 활용한다. | 데이터가 바뀌면 같은 값의 표현도 달라진다. |
| 고정된 설계 범위 | 시각적 의미를 직접 통제할 수 있다. | 범위 밖 입력의 처리 규칙이 필요하다. |

데이터 시각화에서 매 프레임 관측된 최솟값과 최댓값을 사용하면 그래프가 계속 늘거나 줄 수 있다. 고정 범위는 시점이 달라도 같은 시각 척도를 유지한다.

## 이상값이 범위에 미치는 영향

대부분의 값이 0~10이고 하나만 1000이라면 전체 최솟값과 최댓값으로 정규화했을 때 나머지 값은 0 근처에 몰린다. 값 사이의 시각적 차이가 거의 드러나지 않을 수 있다.

이때는 다음 방법을 고려할 수 있다.

- 의미 있는 설계 범위를 직접 정한다.
- 상위와 하위 일부를 제외한 분위수 범위를 사용한다.
- 로그나 제곱근 같은 비선형 변환을 먼저 적용한다.
- 이상값을 별도의 시각 기호로 표시한다.

범위는 무엇을 강조하고 어떤 값을 같은 척도로 비교할지 정하는 표현상의 선택이다.

## 벡터와 색의 정규화

“정규화”는 문맥에 따라 다른 연산을 뜻한다. 범위 정규화는 $[a,b]$를 $[0,1]$로 옮기고, 벡터 정규화는 방향을 유지한 채 벡터의 길이를 1로 만든다.

$$
\hat{\mathbf{v}}=\frac{\mathbf{v}}{\lVert\mathbf{v}\rVert}
$$

두 연산은 목적과 결과가 다르다. 색상 값을 0~255에서 0~1로 바꾸는 것은 범위 정규화이고, 방향 벡터를 단위 벡터로 만드는 것은 길이 정규화다. 문맥에서 어느 의미인지 구분해야 한다.

## 정규화한 값을 확인하기

값 변환을 확인하려면 몇 가지 기준값을 대입해 본다.

| 입력 $x$ | 정규화 결과 $t$ |
| --- | --- |
| $a$ | 0 |
| $(a+b)/2$ | 0.5 |
| $b$ | 1 |
| $a$보다 작은 값 | 0보다 작음 |
| $b$보다 큰 값 | 1보다 큼 |

최솟값, 중간값, 최댓값을 검사하면 경계와 증가 방향을 확인할 수 있다. 출력을 뒤집을 때는 $1-t$를 사용하고, 범위 밖 값을 허용하지 않을 때는 제한 연산을 더한다.

## 이 절의 핵심

값을 시각 요소에 연결하려면 원래 범위를 알아야 한다. 최소-최대 정규화는 $[a,b]$의 값을 0~1 사이의 비율로 변환한다.

$$
t=\frac{x-a}{b-a}
$$

정규화한 값은 여러 출력 범위에 연결하기 쉽다. 다만 범위 밖 입력과 폭이 0인 범위는 별도로 처리해야 한다. 이론적·관측된·설계된 범위 중 무엇을 택하는지에 따라 이미지의 비교 기준과 대비도 달라진다. 다음 절에서는 범위를 벗어난 값을 고정하거나 반복·반사하는 경계 처리 방식을 살펴본다.
