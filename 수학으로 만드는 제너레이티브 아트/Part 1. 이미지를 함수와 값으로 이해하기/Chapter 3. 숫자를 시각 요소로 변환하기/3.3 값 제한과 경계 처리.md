# 3.3 값 제한과 경계 처리

그래픽을 계산하다 보면 값이 설정한 범위를 벗어나는 일이 잦다. 애니메이션의 진행도가 1보다 커지거나 사용자 입력이 예상 범위를 넘을 수 있고, 좌표 변형 뒤에는 UV가 0에서 1 바깥으로 나가기도 한다. 색상 계산 결과가 음수가 되거나 밝기가 1을 넘는 경우도 있다.

범위 밖의 값을 처리하는 방식에 따라 결과의 성격도 달라진다. 경계에 고정하면 값은 범위 안에 머물고, 반대편으로 되돌리면 반복되며, 경계에서 방향을 바꾸면 왕복 운동이 된다. 경계 처리는 오류를 막는 동시에 패턴과 움직임을 만드는 규칙이기도 하다.

## 값 제한하기

값 $x$를 최솟값 $a$와 최댓값 $b$ 사이에 고정하는 연산을 제한(clamp)이라고 한다.

$$
\operatorname{clamp}(x,a,b)=\min(\max(x,a),b)
$$

$x<a$이면 $a$, $x>b$이면 $b$, 그 사이에 있으면 $x$를 그대로 반환한다.

```text
function clamp(value, minimum, maximum):
    return min(max(value, minimum), maximum)
```

값을 0에서 1 사이로 제한하는 연산은 그래픽에서 자주 쓰인다.

$$
\operatorname{saturate}(x)=\operatorname{clamp}(x,0,1)
$$

일부 셰이딩 언어와 그래픽 도구는 이를 `saturate`라는 이름으로 제공하지만, GLSL에서는 보통 `clamp(x, 0.0, 1.0)`으로 쓴다.

## 제한이 필요한 경우

값 제한은 출력 범위가 명확할 때 유용하다.

| 값 | 일반적인 범위 | 범위를 벗어났을 때 생길 수 있는 일 |
| --- | --- | --- |
| 정규화된 진행도 | $[0,1]$ | 애니메이션이 목표를 지나친다. |
| 불투명도 | $[0,1]$ | 렌더러가 내부적으로 제한하거나 예상 밖 혼합이 생긴다. |
| 색상 채널 | 보통 $[0,1]$ | HDR이 아니라면 잘리거나 포화된다. |
| 도형 크기 | 보통 0 이상 | 음수 크기의 해석이 환경마다 달라진다. |
| 배열 인덱스 | 유효한 정수 범위 | 잘못된 데이터 접근이 발생한다. |

모든 값을 습관적으로 제한하면 중요한 정보가 사라질 수 있다. 속도가 상한을 넘었거나 데이터가 설계 범위를 벗어났다는 사실을 감추기 때문이다. 계산 중에는 원래 값을 유지하고, 출력 직전이나 경계 처리가 필요한 지점에서 제한해야 값의 의미를 파악하기 쉽다.

## 제한은 값을 잘라 낸다

클램프 함수는 범위 밖의 모든 값을 경계값 하나로 모은다. $b$보다 큰 값이 1만큼 벗어났는지 100만큼 벗어났는지 결과만 보고는 알 수 없다.

```text
clamp(1.2, 0, 1) = 1
clamp(5.0, 0, 1) = 1
```

이 성질은 출력 범위를 지키는 데 유용하지만, 입력의 변화가 경계에 도달한 뒤에는 결과에 반영되지 않는다. 움직이는 점의 x좌표를 화면 폭에 제한하면 점은 오른쪽 경계에 도달한 뒤 멈춘다. 반복이나 반사가 필요하면 다른 경계 처리를 사용해야 한다.

## 반복하기

값이 최댓값에 이르면 최솟값으로 돌아오게 하는 방식을 래핑이라고 한다. 0에서 1 사이에서는 값의 소수 부분으로 반복을 만들 수 있다.

$$
\operatorname{fract}(x)=x-\lfloor x\rfloor
$$

```text
wrapped = fract(value)
```

`0.2`는 그대로 `0.2`가 되고, `1.2`도 `0.2`, `2.2`도 `0.2`가 된다. 좌표에 반복 횟수를 곱한 뒤 `fract`를 적용하면 타일 패턴을 만들 수 있다.

```glsl
vec2 cellPosition = fract(uv * repeatCount);
```

임의의 범위 $[a,b)$에서 반복하려면 범위의 폭 $L=b-a$를 사용한다.

$$
x'=a+\operatorname{mod}(x-a,L)
$$

언어에 따라 음수에 대한 나머지 연산의 결과가 다를 수 있다. 좌표가 음수가 될 수 있다면 사용하는 `mod` 또는 `%` 연산의 정의를 확인해야 한다.

## 반사 반복하기

경계에 도달할 때 방향을 바꾸어 왕복하게 만들 수도 있다. 0에서 1 사이를 오가는 삼각파는 다음처럼 만들 수 있다.

$$
m=\operatorname{mod}(x,2)
$$

$$
y=1-|m-1|
$$

```text
function pingPong(value):
    phase = mod(value, 2)
    return 1 - abs(phase - 1)
```

입력이 0에서 1로 증가할 때 출력도 0에서 1로 증가하고, 입력이 1에서 2로 증가할 때 출력은 1에서 0으로 감소한다. 애니메이션의 왕복 이동이나 거울 반복 텍스처에 사용할 수 있다.

반사 반복에서는 일반 반복과 달리 경계 양쪽의 값이 이어진다. 다만 경계에서 이동 방향이 갑자기 바뀌어 속도의 미분값은 불연속적이다. 감속과 반전을 부드럽게 만들려면 보간 함수를 함께 사용할 수 있다.

## 범위를 벗어났는지 검사하기

경계 처리를 적용하기 전에 값이 범위 안에 있는지 판단할 수 있다.

```text
inside = minimum <= value and value <= maximum
below = value < minimum
above = value > maximum
```

이 결과를 마스크로 사용하면 범위 안과 밖에 다른 표현을 적용할 수 있다.

```text
if value < minimum:
    color = belowRangeColor
else if value > maximum:
    color = aboveRangeColor
else:
    color = normalColor
```

데이터 시각화에서는 값을 단순히 잘라 내는 대신 범위 밖의 값을 별도 색이나 기호로 표시하는 편이 정보를 더 정확히 전달할 수 있다.

## 구간의 끝값 처리

반복 구간은 보통 한쪽 끝을 포함하고 다른 쪽 끝은 제외하는 반열린 구간으로 표현한다.

$$
[a,b)
$$

$a$와 $b$를 동시에 포함하면 반복 경계에서 같은 위치를 두 번 표현하게 될 수 있다. 예를 들어 각도를 0에서 $2\pi$까지 반복할 때 0과 $2\pi$는 같은 방향이다. 원 위에 서로 다른 점을 균등하게 배치하려면 마지막 끝점을 제외하는 것이 자연스럽다.

```text
for index from 0 to count - 1:
    angle = index / count * 2 * PI
```

반면 선분의 양 끝점을 모두 샘플링하거나 그라데이션의 첫색과 끝색을 정확히 포함하려면 닫힌 구간을 사용할 수 있다. 경계 포함 여부는 자료 구조와 반복 규칙에 맞춰 선택해야 한다.

## 좌표 경계 처리와 텍스처

텍스처 좌표가 0에서 1 범위를 벗어날 때 샘플러는 제한, 반복, 거울 반복, 경계색 같은 정책을 적용할 수 있다. 경계 처리 방식은 좌표를 계산하는 코드와 별도로 샘플러에서 지정하기도 한다.

| 방식 | 범위 밖 좌표의 처리 | 시각적 결과 |
| --- | --- | --- |
| Clamp | 가장 가까운 가장자리 사용 | 가장자리 색이 늘어난다. |
| Repeat | 반대편부터 다시 시작 | 같은 이미지가 타일처럼 반복된다. |
| Mirror | 방향을 뒤집어 반복 | 이웃 타일의 경계가 대칭이 된다. |
| Border | 지정한 색 사용 | 이미지 바깥이 일정한 색이 된다. |

프로시저럴 패턴에서는 같은 방식을 수식으로 직접 구현할 수 있다. 이미지 텍스처에서는 샘플러 설정을 쓰는 편이 필터링과 미분 계산에 더 적합할 수 있다.

## 값 제한과 수치 안정성

일부 함수는 입력 범위에 제약이 있다. 제곱근의 실수 결과를 얻으려면 입력이 음수가 아니어야 하고, 역코사인의 입력은 -1에서 1 사이여야 한다. 부동소수점 계산 오차로 내적이 이론적인 최댓값 1보다 조금 커질 수도 있다.

```text
cosine = dot(normalizedA, normalizedB)
angle = arccos(clamp(cosine, -1, 1))
```

이런 제한은 시각적 범위를 정할 뿐 아니라 계산을 유효한 정의역 안에 둔다. 나눗셈의 분모에 작은 최솟값을 두거나 로그 입력을 0보다 크게 유지하는 것도 비슷한 수치 안정성 처리다.

## 경계에서 생기는 불연속

제한과 반복은 경계에서 값이 변하는 양상을 바꾼다. 클램프는 값이 연속이지만 경계 밖에서 기울기가 0이 된다. 반복은 최댓값 부근에서 최솟값으로 갑자기 이동해 값이 불연속일 수 있다. 반사 반복에서는 값이 이어지는 대신 방향이 갑자기 바뀐다.

이런 변화는 선명한 경계나 반복 패턴을 만들 때 유용하다. 애니메이션의 움직임이나 표면 법선 계산에서는 눈에 띄는 이음새를 만들 수도 있다. 경계의 성격을 살펴보고 부드러운 전환, 주기 함수, 이음새 없는 노이즈 가운데 필요한 방법을 선택해야 한다.

| 경계 방식 | 값의 연속성 | 대표적인 인상 |
| --- | --- | --- |
| Clamp | 대체로 연속 | 경계에서 멈춤 |
| Repeat | 경계값이 맞지 않으면 불연속 | 처음부터 다시 시작 |
| Mirror | 값은 연속 | 방향을 바꾸어 왕복 |
| Smooth transition | 값과 기울기를 부드럽게 설계 가능 | 완만한 진입과 이탈 |

## 어떤 경계 처리를 선택할 것인가

경계 처리는 표현하려는 관계에 맞춰 선택한다.

- 범위를 절대 벗어나면 안 된다면 제한한다.
- 주기적으로 반복되어야 한다면 래핑한다.
- 왕복 운동이나 대칭 반복이 필요하면 반사한다.
- 범위 밖의 정보가 중요하다면 별도로 표시한다.
- 이후 계산에서 외삽이 필요하다면 처리하지 않고 유지한다.

값을 제한하기 전에 범위가 필요한 이유부터 따져야 한다. 출력 장치의 제약인지, 미적 선택인지, 계산의 정의역 때문인지에 따라 적절한 방법이 달라진다.

## 이 절의 핵심

범위 밖의 값은 경계에 고정하거나, 반대편으로 반복하거나, 경계에서 반사하거나, 별도 상태로 표시할 수 있다. 클램프는 안정적이지만 범위 밖의 차이를 잃고, 반복과 반사는 패턴과 움직임을 계속 이어 준다.

경계 처리는 값의 연속성과 변화 속도에도 영향을 준다. 출력 범위와 계산 목적에 맞는 방식을 필요한 지점에 적용해야 한다. 다음 절에서는 한 범위의 값을 다른 범위로 옮기는 재매핑을 다룬다.
