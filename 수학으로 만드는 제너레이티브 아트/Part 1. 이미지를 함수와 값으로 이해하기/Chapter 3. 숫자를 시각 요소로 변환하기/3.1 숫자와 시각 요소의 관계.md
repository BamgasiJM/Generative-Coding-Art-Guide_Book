# 3.1 숫자와 시각 요소의 관계

컴퓨터 그래픽에서 화면 속성의 대부분은 숫자로 표현된다. 점의 위치는 좌표, 원의 크기는 지름이나 반지름, 선의 방향은 각도나 벡터로 나타낸다. 색은 여러 채널의 값으로 표현하며 투명도와 밝기도 수치로 다룬다. 애니메이션의 시간과 속도, 3차원 표면의 높이와 거칠기도 숫자다.

숫자만으로 이미지가 만들어지지는 않는다. 각 값을 어떤 범위로 해석해 어떤 시각 요소에 연결할지 정해야 한다. 같은 값도 밝기에 연결하면 명암, 위치에 연결하면 이동, 각도에 연결하면 회전이 된다. 이 장에서는 계산값을 시각 요소에 맞게 변환하는 방법을 다룬다.

## 숫자는 시각 요소의 상태를 나타낸다

그래픽 프로그램은 도형의 상태를 수치로 저장한다. 대표적인 대응 관계는 다음과 같다.

| 시각 요소 | 수치 표현의 예 | 해석할 때 필요한 정보 |
| --- | --- | --- |
| 위치 | $(x,y)$ 또는 $(x,y,z)$ | 좌표계, 원점, 단위 |
| 크기 | 반지름, 너비, 높이 | 기준점, 음수 허용 여부 |
| 회전 | 라디안 또는 도 | 회전 방향, 기준축 |
| 밝기 | 0에서 1, 또는 0에서 255 | 색 공간, 출력 범위 |
| 투명도 | 0에서 1 | 혼합 방식 |
| 색 | RGB, HSL, HSV 등의 채널 | 색 모델, 채널 범위 |
| 선 두께 | 픽셀 또는 공간 단위 | 해상도, 변환 배율 |
| 시간 | 초, 밀리초, 프레임 번호 | 시간 단위, 갱신 방식 |

숫자만으로는 의미를 알 수 없다. `0.5`는 정규화된 밝기, 반초, 반지름 또는 회전각일 수 있다. 값을 해석할 때는 의미와 단위, 범위를 함께 확인해야 한다.

```text
value: 0.5
meaning: normalized brightness
range: 0 to 1
unit: none
```

의미와 범위를 알면 다른 시각 요소에 연결하는 데 필요한 변환을 정할 수 있다.

## 입력값과 시각 출력값

제너레이티브 아트의 계산은 입력값, 중간값, 출력값으로 나눌 수 있다. 좌표, 시간, 데이터, 사용자 입력은 규칙의 출발점이다. 거리, 노이즈, 각도, 반복 인덱스는 계산 중에 얻는 중간값이고, 위치·색·크기 같은 출력값은 렌더링에 사용된다.

```text
position -> distance -> normalizedDistance -> brightness
time -> sineWave -> scale
dataValue -> normalizedValue -> color
noiseValue -> angle -> direction
```

각 단계의 출력이 다음 단계의 입력으로 이어진다. 이 흐름을 분명히 하면 복잡한 이미지도 작은 값 변환의 연쇄로 파악할 수 있다.

중심에서의 거리를 원의 크기에 연결하는 규칙을 살펴보자.

```text
distance = length(position - center)
normalizedDistance = normalize(distance, 0, maxDistance)
diameter = remap(normalizedDistance, 0, 1, maxDiameter, minDiameter)
```

거리의 단위는 좌표계와 같고, 정규화한 값은 단위가 없는 비율이다. 마지막 단계에서 이 비율을 도형 크기의 범위에 대응시킨다. 단계마다 범위를 분리해 두면 화면이나 도형의 크기를 바꾸기 쉽다.

## 스칼라와 벡터

하나의 수로 표현한 값을 스칼라라고 한다. 밝기, 온도, 거리, 반지름, 시간이 여기에 해당한다. 여러 성분으로 이루어진 값은 벡터로 다룬다. 2차원 위치는 두 성분, RGB 색은 세 성분을 갖는다.

$$
s\in\mathbb{R},\qquad \mathbf{p}=(x,y),\qquad \mathbf{c}=(r,g,b)
$$

스칼라 하나를 벡터의 여러 성분에 연결할 수도 있다. 밝기 $s$로 회색을 만들 때는 세 색상 채널에 같은 값을 넣는다.

$$
\mathbf{c}=(s,s,s)
$$

벡터에서 스칼라를 구할 수도 있다. 위치 벡터의 길이는 중심까지의 거리이고, 색상 채널의 가중합은 밝기에 해당하는 값으로 사용할 수 있다.

```text
distance = length(position)
luminance = dot(color, luminanceWeights)
```

계산 단계마다 스칼라와 벡터 중 무엇을 쓰는지 구분하면 값의 역할이 분명해진다.

## 연속값과 이산값

값은 연속값과 이산값으로 나눌 수 있다. 위치, 거리, 시간처럼 실수로 계산하는 값은 대개 연속적이다. 반복 인덱스, 팔레트 번호, 상태 번호처럼 셀 수 있는 값은 이산적이다.

| 값의 성격 | 예 | 시각적 연결 |
| --- | --- | --- |
| 연속값 | 거리, 시간, 노이즈 | 그라데이션, 부드러운 이동, 크기 변화 |
| 이산값 | 인덱스, 범주, 단계 | 반복 셀, 팔레트 선택, 상태 전환 |

연속값을 색이나 크기에 연결하면 부드럽게 변한다. 임계값을 적용하거나 정수로 양자화하면 단계가 생긴다. 두 이산 상태 사이를 보간하면 연속적인 전환을 만들 수 있다.

```text
continuous = noise(position)
binary = continuous >= threshold
steps = floor(continuous * levelCount)
```

연속과 이산은 입력의 성질에만 달린 것이 아니라 표현 방식을 선택하는 문제이기도 하다.

## 값의 방향

입력값이 커질수록 출력도 커지는 관계가 있다. 거리가 멀어질수록 밝아지는 규칙이 한 예다.

$$
x\uparrow\quad\Rightarrow\quad y\uparrow
$$

입력이 커질수록 출력이 작아질 수도 있다. 중심에서 멀어질수록 도형을 줄이거나 시간이 지날수록 투명도를 낮추는 경우다.

$$
x\uparrow\quad\Rightarrow\quad y\downarrow
$$

0에서 1 사이로 정규화된 값 $t$의 방향을 뒤집는 가장 간단한 식은 다음과 같다.

$$
t'=1-t
$$

값을 시각 요소에 연결할 때는 범위와 증가 방향을 함께 정한다. 중심과 가장자리 중 어디를 강조할지에 따라 거리값을 그대로 쓰거나 반전할 수 있다.

## 단위가 있는 값과 단위가 없는 값

픽셀, 초, 도, 미터처럼 단위가 다른 값은 직접 더할 수 없다. 100픽셀과 2초의 합은 의미가 없다. 서로 다른 종류의 값을 연결하려면 먼저 그 관계를 정의해야 한다.

정규화한 값은 특정 단위가 없는 비율이므로 여러 출력 범위에 연결하기 쉽다.

```text
normalizedTime = elapsedTime / duration
position = interpolate(startPosition, endPosition, normalizedTime)
opacity = 1 - normalizedTime
```

`elapsedTime`과 `duration`은 모두 시간 단위이므로 나눗셈 결과에는 단위가 없다. 이 `normalizedTime`을 위치 보간과 투명도에 함께 쓸 수 있다.

정규화해도 원래 값의 의미까지 사라지지는 않는다. `normalizedTime`은 여전히 전체 지속 시간 중 진행된 비율이다. 변수 이름과 문맥에서 이 의미를 드러내야 한다.

## 선형 관계와 비선형 관계

입력과 출력을 연결하는 가장 단순한 방식은 선형 관계다.

$$
y=ax+b
$$

입력이 일정하게 증가할 때 출력도 일정한 비율로 증가한다. 위치, 크기, 밝기의 기본 범위를 변환할 때 적합하다.

사람이 느끼는 밝기와 소리의 크기, 면적의 변화는 수치에 정확히 비례하지 않을 수 있다. 시각적으로 강조하려면 제곱, 제곱근, 지수, 로그, 삼각함수 같은 비선형 변환을 쓴다.

```text
linear = t
easeIn = t * t
easeOut = 1 - (1 - t) * (1 - t)
pulse = 0.5 + 0.5 * sin(time)
```

비선형 함수는 값의 범위보다 범위 안에서 값이 분포하는 방식을 바꾼다. 입력과 출력을 0~1로 유지하면서 중간 구간을 빠르게 지나거나 오래 머물게 할 수 있다.

## 값의 연결은 표현상의 결정이다

거리값을 반드시 밝기에 연결할 필요는 없다. 크기, 색상, 회전, 선 두께, 변위에도 연결할 수 있다. 선택한 연결에 따라 이미지가 강조하는 요소와 드러내는 관계가 달라진다.

| 입력 또는 중간값 | 가능한 출력 연결 |
| --- | --- |
| 중심에서의 거리 | 밝기, 크기, 색상, 밀도 |
| 각도 | 색상환 위치, 회전, 반복 인덱스 |
| 시간 | 위치, 위상, 투명도, 변형량 |
| 노이즈 | 높이, 방향, 색, 선 두께 |
| 외부 데이터 | 막대 길이, 점 크기, 색, 배치 |

한 값을 여러 출력에 연결하면 속성이 함께 변해 일관성이 생긴다. 모든 속성이 같은 값에 묶이면 변화가 지나치게 예측 가능해질 수 있다. 마지막 절에서 하나의 값을 여러 시각 속성에 연결할 때의 장점과 주의점을 다룬다.

## 이 절의 핵심

숫자는 위치, 크기, 색, 회전, 시간 같은 시각 요소의 상태를 나타낸다. 이미지를 만들려면 값의 의미와 단위, 범위, 증가 방향을 파악해 적절한 출력 속성에 연결해야 한다.

입력값은 중간 계산을 거쳐 출력값이 된다. 스칼라와 벡터, 연속값과 이산값, 단위가 있는 값과 정규화된 값을 구분하면 변환 과정을 안정적으로 설계할 수 있다. 다음 절에서는 서로 다른 범위의 값을 공통된 0~1 범위로 바꾸는 정규화를 다룬다.
