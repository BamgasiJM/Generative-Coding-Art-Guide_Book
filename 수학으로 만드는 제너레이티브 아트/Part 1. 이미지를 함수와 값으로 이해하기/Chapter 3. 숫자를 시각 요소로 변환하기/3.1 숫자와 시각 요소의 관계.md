# 3.1 숫자와 시각 요소의 관계

컴퓨터 그래픽에서 화면에 보이는 대부분의 속성은 숫자로 표현된다. 점의 위치는 좌표이고, 원의 크기는 지름이나 반지름이며, 선의 방향은 각도나 벡터다. 색은 여러 채널의 값으로 나타내고, 투명도와 밝기에도 수치가 사용된다. 애니메이션의 시간과 속도, 3차원 표면의 높이와 거칠기 역시 숫자다.

숫자가 곧 이미지인 것은 아니다. 숫자를 어떤 시각 요소에 연결하고 어떤 범위로 해석할지 정해야 이미지가 된다. 같은 값도 밝기에 연결하면 명암이 되고, 위치에 연결하면 이동이 되며, 각도에 연결하면 회전이 된다. 이 장에서는 계산으로 얻은 숫자를 시각 요소에 맞는 값으로 바꾸는 방법을 다룬다.

## 숫자는 시각 요소의 상태를 나타낸다

그래픽 프로그램은 도형의 상태를 수치로 저장한다. 다음 표는 대표적인 대응 관계를 보여 준다.

| 시각 요소 | 수치 표현의 예 | 해석할 때 필요한 정보 |
| --- | --- | --- |
| 위치 | $(x,y)$ 또는 $(x,y,z)$ | 좌표계, 원점, 단위 |
| 크기 | 반지름, 너비, 높이 | 기준점, 음수 허용 여부 |
| 회전 | 라디안 또는 도 | 회전 방향, 기준축 |
| 밝기 | 0에서 1, 또는 0에서 255 | 색 공간, 출력 범위 |
| 투명도 | 0에서 1 | 혼합 방식 |
| 색 | RGB, HSL, HSV 등의 채널 | 색 모델, 채널 범위 |
| 선 두께 | 픽셀 또는 공간 단위 | 해상도, 변환 배율 |
| 시간 | 초, 밀리초, 프레임 번호 | 시간 단위, 갱신 방식 |

숫자 하나만 보면 그 의미를 알 수 없다. `0.5`는 정규화된 밝기일 수도 있고, 반초일 수도 있으며, 반지름이나 회전각일 수도 있다. 따라서 값을 다룰 때는 값의 의미, 단위, 범위를 함께 알아야 한다.

```text
value: 0.5
meaning: normalized brightness
range: 0 to 1
unit: none
```

의미와 범위가 명확하면 값을 다른 시각 요소로 옮길 때 필요한 변환을 판단할 수 있다.

## 입력값과 시각 출력값

제너레이티브 아트의 계산은 크게 입력값, 중간값, 출력값으로 나눌 수 있다. 입력값은 좌표, 시간, 데이터, 사용자 입력처럼 규칙의 출발점이 된다. 중간값은 거리, 노이즈, 각도, 반복 인덱스처럼 계산 과정에서 만들어진다. 출력값은 위치, 색, 크기처럼 실제 렌더링에 사용된다.

```text
position -> distance -> normalizedDistance -> brightness
time -> sineWave -> scale
dataValue -> normalizedValue -> color
noiseValue -> angle -> direction
```

한 단계의 출력은 다음 단계의 입력이 된다. 이 연결을 명확하게 만들면 복잡한 이미지도 작은 값 변환의 연쇄로 이해할 수 있다.

예를 들어 중심에서의 거리를 원의 크기에 연결하는 규칙을 생각해 보자.

```text
distance = length(position - center)
normalizedDistance = normalize(distance, 0, maxDistance)
diameter = remap(normalizedDistance, 0, 1, maxDiameter, minDiameter)
```

거리의 원래 단위는 좌표계와 같지만, 정규화한 뒤에는 단위가 없는 비율이 된다. 마지막 단계에서 그 비율을 도형 크기의 범위로 옮긴다. 각 단계의 범위가 분리되어 있으므로 화면 크기나 도형 크기를 바꾸기 쉽다.

## 스칼라와 벡터

하나의 수로 표현되는 값을 스칼라라고 한다. 밝기, 온도, 거리, 반지름, 시간은 스칼라의 예다. 여러 성분을 묶은 값은 벡터로 다룰 수 있다. 2차원 위치는 두 성분, RGB 색은 세 성분을 가진다.

$$
s\in\mathbb{R},\qquad \mathbf{p}=(x,y),\qquad \mathbf{c}=(r,g,b)
$$

스칼라 하나를 벡터의 여러 성분에 동시에 연결할 수도 있다. 밝기 $s$로 회색을 만들면 세 색상 채널에 같은 값을 사용한다.

$$
\mathbf{c}=(s,s,s)
$$

반대로 벡터에서 스칼라를 얻을 수도 있다. 위치 벡터의 길이를 구하면 중심에서의 거리가 되고, 색상 채널을 가중합하면 밝기와 비슷한 값을 만들 수 있다.

```text
distance = length(position)
luminance = dot(color, luminanceWeights)
```

어떤 단계에서 스칼라를 사용하고 어떤 단계에서 벡터를 사용할지 구분하면 값의 역할이 분명해진다.

## 연속값과 이산값

값은 연속적일 수도 있고 이산적일 수도 있다. 위치, 거리, 시간처럼 실수로 계산하는 값은 대개 연속값이다. 반복 인덱스, 팔레트 번호, 상태 번호처럼 셀 수 있는 값은 이산값이다.

| 값의 성격 | 예 | 시각적 연결 |
| --- | --- | --- |
| 연속값 | 거리, 시간, 노이즈 | 그라데이션, 부드러운 이동, 크기 변화 |
| 이산값 | 인덱스, 범주, 단계 | 반복 셀, 팔레트 선택, 상태 전환 |

연속값을 그대로 색이나 크기에 연결하면 부드러운 변화가 만들어진다. 임계값을 적용하거나 정수로 양자화하면 단계적인 변화가 된다. 반대로 두 이산 상태 사이를 보간하면 연속적인 전환을 만들 수 있다.

```text
continuous = noise(position)
binary = continuous >= threshold
steps = floor(continuous * levelCount)
```

연속과 이산은 입력의 고정된 성질만이 아니라 표현 방식의 선택이기도 하다.

## 값의 방향

입력값이 커질 때 출력도 커지는 관계를 정방향 대응이라고 볼 수 있다. 거리가 멀어질수록 밝아지는 규칙이 그 예다.

$$
x\uparrow\quad\Rightarrow\quad y\uparrow
$$

반대로 입력이 커질수록 출력이 작아지는 관계도 있다. 중심에서 멀어질수록 도형을 작게 만들거나, 시간이 지날수록 투명도를 낮추는 경우다.

$$
x\uparrow\quad\Rightarrow\quad y\downarrow
$$

0에서 1 사이로 정규화된 값 $t$의 방향을 뒤집는 가장 간단한 식은 다음과 같다.

$$
t'=1-t
$$

값을 시각 요소에 연결할 때는 범위뿐 아니라 증가 방향도 결정해야 한다. 중심이 강조되어야 하는지, 가장자리가 강조되어야 하는지에 따라 같은 거리값을 그대로 쓰거나 뒤집어 쓸 수 있다.

## 단위가 있는 값과 단위가 없는 값

픽셀, 초, 도, 미터처럼 단위를 가진 값은 서로 직접 더하기 어렵다. 100픽셀과 2초를 더해도 의미 있는 결과가 되지 않는다. 서로 다른 종류의 값을 연결하려면 먼저 관계를 정의해야 한다.

정규화된 값은 특정 단위에서 분리된 비율이므로 여러 출력 범위에 다시 연결하기 좋다.

```text
normalizedTime = elapsedTime / duration
position = interpolate(startPosition, endPosition, normalizedTime)
opacity = 1 - normalizedTime
```

여기서 `elapsedTime`과 `duration`은 모두 시간 단위를 가지므로 나눗셈 결과에는 단위가 없다. 같은 `normalizedTime`을 위치 보간과 투명도에 사용할 수 있다.

단위를 없애는 과정에서 원래 값의 의미가 사라지는 것은 아니다. `normalizedTime`은 여전히 “전체 지속 시간 중 얼마나 진행되었는가”를 뜻한다. 변수 이름과 문맥으로 그 의미를 유지해야 한다.

## 선형 관계와 비선형 관계

입력값을 출력값에 연결하는 가장 단순한 방식은 선형 관계다.

$$
y=ax+b
$$

입력이 일정하게 증가하면 출력도 일정한 비율로 증가한다. 위치, 크기, 밝기의 기본적인 범위 변환에 적합하다.

하지만 사람이 느끼는 밝기나 소리의 크기, 면적의 변화는 수치와 정확히 비례하지 않을 수 있다. 시각적 강조를 위해 제곱, 제곱근, 지수, 로그, 삼각함수 같은 비선형 변환을 사용할 수 있다.

```text
linear = t
easeIn = t * t
easeOut = 1 - (1 - t) * (1 - t)
pulse = 0.5 + 0.5 * sin(time)
```

비선형 함수는 값의 범위를 바꾸기보다 범위 안에서 값이 분포하는 방식을 바꾼다. 0에서 1 사이의 입력과 출력을 유지하면서 중간 구간을 빠르게 지나거나 오래 머물게 할 수 있다.

## 값의 연결은 표현상의 결정이다

거리값을 밝기에 연결해야 한다는 규칙은 없다. 크기, 색상, 회전, 선 두께, 변위에 연결할 수도 있다. 어떤 연결을 선택하는가는 이미지가 무엇을 강조하고 어떤 관계를 드러낼지 결정한다.

| 입력 또는 중간값 | 가능한 출력 연결 |
| --- | --- |
| 중심에서의 거리 | 밝기, 크기, 색상, 밀도 |
| 각도 | 색상환 위치, 회전, 반복 인덱스 |
| 시간 | 위치, 위상, 투명도, 변형량 |
| 노이즈 | 높이, 방향, 색, 선 두께 |
| 외부 데이터 | 막대 길이, 점 크기, 색, 배치 |

같은 값을 여러 출력에 연결하면 속성들이 함께 변해 강한 일관성이 생긴다. 반면 모든 속성이 같은 값에 묶이면 변화가 지나치게 예측 가능해질 수 있다. 마지막 절에서는 하나의 값을 여러 시각 속성에 연결할 때의 장점과 주의점을 자세히 다룬다.

## 이 절의 핵심

숫자는 위치, 크기, 색, 회전, 시간 같은 시각 요소의 상태를 표현한다. 숫자를 이미지로 바꾸려면 값의 의미, 단위, 범위, 증가 방향을 알고 적절한 출력 속성에 연결해야 한다.

입력값은 여러 중간 계산을 거쳐 출력값이 된다. 스칼라와 벡터, 연속값과 이산값, 단위가 있는 값과 정규화된 값을 구분하면 이 변환 과정을 안정적으로 설계할 수 있다. 다음 절에서는 서로 다른 범위의 값을 공통된 0에서 1 사이로 바꾸는 정규화를 다룬다.
