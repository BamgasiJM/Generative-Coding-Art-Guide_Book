# 3.7 하나의 값을 색, 위치, 크기, 회전에 연결하기

앞 절에서는 값의 범위를 확인하고 정규화·제한·재매핑하는 방법, 보간과 임계값으로 변화를 조절하는 방법을 살펴보았다. 이런 연산은 계산값을 시각 요소에 연결하기 위해 사용한다.

입력값 하나로 여러 출력 속성을 동시에 조절할 수 있다. 노이즈 값으로 도형의 크기와 회전을 함께 바꾸거나, 데이터값으로 점의 높이와 색을 정할 수 있다. 같은 값에서 파생된 변화는 이미지에 일관성을 준다. 모든 속성을 똑같이 연결하면 결과가 단조롭거나 같은 의미를 반복할 수 있다. 이 절에서는 값과 시각 속성의 연결을 설계하는 방법을 살펴본다.

## 공통 입력을 먼저 정규화하기

각 시각 속성에서 원래 범위를 따로 처리하기보다, 먼저 값을 공통 비율인 0~1로 변환하면 구조가 단순해진다.

```text
t = normalize(value, inputMin, inputMax)
t = clamp(t, 0, 1)

color = colorFromValue(t)
position = positionFromValue(t)
size = sizeFromValue(t)
rotation = rotationFromValue(t)
```

$t$는 원래 입력 범위에서 현재 값이 차지하는 위치다. 각 출력 함수는 이 비율을 속성에 맞는 범위와 변화 곡선으로 변환한다.

입력 해석과 시각 디자인을 분리할 수 있다는 것이 이 구조의 장점이다. 데이터 범위가 바뀌면 정규화 단계를, 색이나 크기 범위가 바뀌면 해당 출력 함수를 수정하면 된다.

## 값을 위치에 연결하기

위치는 한 축의 스칼라값일 수도, 여러 성분을 가진 벡터일 수도 있다. $t$를 두 위치 사이의 보간 비율로 사용하면 다음과 같다.

$$
\mathbf{p}(t)=(1-t)\mathbf{p}_0+t\mathbf{p}_1
$$

```text
position = interpolate(startPosition, endPosition, t)
```

한 축은 $t$에 따라 바꾸고 다른 축은 별도의 규칙으로 정할 수도 있다.

```text
x = interpolate(left, right, columnRatio)
y = interpolate(bottom, top, t)
```

데이터 시각화에서는 위치가 대체로 정확한 비교를 돕는다. 같은 기준축에 값을 놓으면 서로 비교하기 쉽다. 자유로운 2차원 배치는 구성과 흐름을 만들기 좋지만 수치를 정확히 비교하기는 어렵다.

위치에 연결할 때는 좌표계의 축 방향도 확인한다. 화면의 $y$축이 아래로 증가한다면 큰 값을 위에 놓도록 출력 범위를 `bottom`에서 `top` 순서로 지정한다.

## 값을 크기에 연결하기

정규화된 값 $t$를 최소 크기와 최대 크기 사이에 대응시킬 수 있다.

$$
s(t)=s_{min}+t(s_{max}-s_{min})
$$

```text
diameter = interpolate(minDiameter, maxDiameter, t)
```

사람은 도형의 면적이나 부피를 크기로 지각한다. 따라서 단순 선형 연결은 수치 관계를 과장할 수 있다. 원의 면적을 값에 비례시키려면 반지름에 제곱근 관계를 적용한다.

$$
r(t)=\sqrt{r_{min}^2+t(r_{max}^2-r_{min}^2)}
$$

구의 부피를 값에 비례시키려면 세제곱근을 고려해야 한다. 예술적 표현에서는 정확한 비례보다 시각적 대비를 우선할 수도 있다. 다만 어떤 성질이 값에 비례하는지 알고 선택해야 한다.

크기가 0에 가까우면 요소가 사라지고, 지나치게 크면 다른 요소를 가린다. 최소·최대 크기는 데이터 범위와 함께 화면의 밀도와 겹침을 고려해 정한다.

## 값을 회전에 연결하기

0~1 범위를 한 바퀴 회전으로 대응시키면 다음과 같다.

$$
\theta=2\pi t
$$

```text
angle = t * 2 * PI
```

방향 데이터는 각도에 연결하기 자연스럽다. 반면 크기 데이터를 각도만으로 나타내면 어느 쪽이 더 큰지 바로 비교하기 어렵다. 각도는 방향, 위상, 주기적 상태를 표현할 때 적합하다.

각도에서 선이나 화살표의 방향 벡터를 다음과 같이 구한다.

$$
\mathbf{d}=(\cos\theta,\sin\theta)
$$

```text
direction = (cos(angle), sin(angle))
endPoint = center + direction * lineLength
```

값이 반복 범위를 넘더라도 회전은 이어질 수 있다. 두 각도를 보간할 때는 0과 $2\pi$가 만나는 경계를 처리해야 한다.

## 값을 밝기와 색에 연결하기

정규화된 값 $t$를 회색조 밝기에 연결하면 다음과 같다.

$$
\mathbf{c}=(t,t,t)
$$

두 색 사이를 보간하는 방법도 있다.

$$
\mathbf{c}(t)=(1-t)\mathbf{c}_0+t\mathbf{c}_1
$$

```text
color = interpolateColor(lowColor, highColor, t)
```

팔레트에 색이 여러 개라면 $t$가 속한 구간을 찾아 양옆의 색 사이를 보간한다. 단계적인 표현에는 가장 가까운 팔레트 색을 선택한다.

색은 값의 성격에 맞춰 선택한다.

| 값의 성격 | 적합한 색상 구조 |
| --- | --- |
| 낮음에서 높음으로 이어지는 값 | 밝기나 채도가 한 방향으로 변하는 순차 팔레트 |
| 기준값을 중심으로 음수와 양수로 나뉨 | 중앙색에서 양쪽으로 갈라지는 발산 팔레트 |
| 순환하는 각도나 위상 | 끝과 시작이 이어지는 순환 팔레트 |
| 서로 순서가 없는 범주 | 서로 구분되는 정성 팔레트 |

RGB 채널을 각각 재매핑하면 중간색의 밝기와 채도가 예상과 다를 수 있다. 중요한 정보를 색으로 전달할 때는 색 공간과 지각적 균일성도 고려한다.

## 값을 투명도와 선 두께에 연결하기

투명도는 요소의 존재감과 겹쳐 보이는 정도를 조절한다.

```text
opacity = interpolate(minOpacity, maxOpacity, t)
```

낮은 값을 완전히 투명하게 처리하면 데이터나 구조가 사라질 수 있다. 최소 투명도를 0보다 크게 설정하거나 중요한 값을 색과 크기 같은 다른 속성으로도 나타낸다.

선 두께는 흐름이나 힘, 빈도, 깊이를 나타낼 때 사용할 수 있다.

```text
lineWidth = interpolate(minWidth, maxWidth, shapedT)
```

아주 얇은 선은 출력 해상도에서 사라지고 굵은 선은 경로 사이 공간을 메울 수 있다. 화면과 인쇄물에서 같은 수치도 다르게 보일 수 있으므로 단위를 확인한다.

## 같은 값을 여러 속성에 연결하기

하나의 $t$를 크기, 색, 회전에 함께 연결해 보자.

```text
t = clamp(normalize(value, inputMin, inputMax), 0, 1)

radius = interpolate(minRadius, maxRadius, sqrt(t))
color = samplePalette(t)
angle = interpolate(minAngle, maxAngle, t)
opacity = interpolate(minOpacity, maxOpacity, t)
```

모든 속성이 입력값을 따라 변한다. 값이 큰 요소는 더 크고, 팔레트 끝색에 가까우며, 더 많이 회전하고, 더 불투명해진다. 여러 속성으로 표현하면 중요한 차이가 두드러질 수 있다.

같은 정보를 너무 많은 속성에 반복하면 하나의 변화가 이미지를 지배한다. 크기와 밝기, 투명도가 함께 커질 때는 작은 값이 거의 보이지 않을 수 있다. 주된 표현 채널과 보조 채널을 구분한다.

## 같은 입력에 서로 다른 곡선 적용하기

모든 속성이 같은 속도로 변할 이유는 없다. 공통 입력 $t$에 서로 다른 함수를 적용하면 속성 간 관계를 유지하면서 단조로움을 줄인다.

```text
sizeT = sqrt(t)
colorT = smoothStep(0, 1, t)
rotationT = t * t
opacityT = clamp(remap(t, 0.2, 0.8, 0, 1), 0, 1)
```

크기는 작은 입력에서도 비교적 빠르게 커지고, 회전은 큰 입력에서 더 빠르게 변한다. 투명도는 입력의 중간 구간에서만 달라진다. 같은 원천값을 써도 속성마다 민감도는 다르다.

함수나 변수 이름에 변환 목적을 드러내면 값을 조정하기 쉽다.

## 상관관계와 독립적인 변화

같은 값을 여러 속성에 연결하면 속성 사이에 완전한 상관관계가 생긴다. 큰 도형은 늘 같은 계열의 색과 방향을 갖는다. 일관성은 높아지지만 가능한 조합은 줄어든다.

다양성을 더하려면 입력을 변형하거나 속성별로 다른 입력을 사용한다.

```text
sizeValue = noise(position * sizeScale)
colorValue = noise(position * colorScale + colorOffset)
rotationValue = noise(position * rotationScale + rotationOffset)
```

속성이 서로 완전히 무관하면 이미지가 산만해질 수 있다. 공통값에 속성별 변형값을 섞는 방법도 있다.

```text
sizeT = commonValue
colorT = interpolate(commonValue, colorVariation, 0.3)
rotationT = interpolate(commonValue, rotationVariation, 0.6)
```

공통 흐름을 유지하면서 일부 속성에는 독립적인 변화를 줄 수 있다.

## 예제: 격자의 값을 여러 속성에 연결하기

격자 셀마다 0~1 범위의 값 $t$를 구해 원의 크기, 색, 회전에 연결한다. 특정 라이브러리에 종속되지 않는 의사코드로 구조를 나타내면 다음과 같다.

```text
for each cell in grid:
    position = cellCenter(cell)
    rawValue = noise(position * noiseScale)
    t = clamp(normalize(rawValue, noiseMin, noiseMax), 0, 1)

    radius = interpolate(minRadius, maxRadius, sqrt(t))
    color = samplePalette(smoothStep(0, 1, t))
    angle = interpolate(-maxAngle, maxAngle, t)
    opacity = interpolate(0.35, 1.0, t)

    drawOrientedCircleMark(
        position,
        radius,
        angle,
        color,
        opacity
    )
```

원은 회전해도 겉모양이 달라지지 않는다. 따라서 `drawOrientedCircleMark`는 원 안에 방향선이나 비대칭 표시를 그리는 함수라고 가정한다. 회전 대칭 도형에 회전값을 연결해도 시각적 변화가 없으므로, 출력 속성이 실제 도형에서 드러나는지 확인해야 한다.

## 픽셀 함수에서의 연결

프래그먼트 셰이더에서도 같은 구조를 현재 픽셀의 색 계산에 적용할 수 있다. 다음 GLSL 예제는 중심으로부터의 정규화된 거리를 색과 마스크에 연결한다.

```glsl
vec2 p = uv - 0.5;
p.x *= resolution.x / resolution.y;

float distanceValue = length(p);
float t = clamp(distanceValue / maxDistance, 0.0, 1.0);

vec3 innerColor = vec3(0.95, 0.30, 0.18);
vec3 outerColor = vec3(0.08, 0.20, 0.42);
vec3 color = mix(innerColor, outerColor, t);

float mask = 1.0 - smoothstep(radius, radius + edgeWidth, distanceValue);
vec3 outputColor = color * mask;
```

입력은 좌표에서 구한 거리 하나다. `t`는 색을 섞고 원래 거리값은 도형 마스크를 만드는 데 쓴다. 하나의 입력에서 파생된 값도 용도에 따라 다른 단계에서 사용한다.

## 연결을 평가하는 질문

값과 시각 요소의 연결을 설계한 뒤 다음을 점검한다.

- 입력값의 의미와 범위가 명확한가?
- 출력 속성의 범위가 실제 화면에서 충분히 구분되는가?
- 값이 커지는 방향과 시각적 변화의 방향이 의도와 맞는가?
- 크기, 면적, 밝기 가운데 무엇이 값에 비례해야 하는가?
- 같은 정보를 여러 속성으로 반복할 필요가 있는가?
- 낮은 값이나 범위 밖의 값이 완전히 사라지지 않는가?
- 색이나 각도처럼 주기적이거나 비선형적인 속성의 경계를 처리했는가?

제너레이티브 아트의 연결 방식에는 하나의 정답이 없지만, 선택한 방식과 그 결과를 설명할 수 있어야 한다. 의도한 관계를 알면 파라미터를 조절하고 변주하기도 쉽다.

## 이 장의 마무리

Chapter 3에서는 계산값을 시각 요소로 바꾸는 방법을 다루었다. 값의 의미와 단위, 범위를 구분하고, 서로 다른 범위를 연결하기 위해 정규화했다. 범위 밖 값은 제한·반복·반사로 처리하고, 재매핑으로 입력 범위에서의 상대적 위치를 출력 범위에 대응시켰다.

선형 보간은 두 상태를 연결하고, 비선형 곡선과 `smoothstep`은 변화 속도와 경계를 조절한다. 임계값은 연속값을 영역과 단계로 나누며, 마스크는 색과 형태의 적용 위치를 제어한다. 마지막으로 같은 값을 위치, 크기, 회전, 색, 투명도에 연결해 하나의 시각 시스템을 구성했다.

숫자를 바로 출력에 넣기보다 의미와 범위를 먼저 살펴야 한다. 입력 범위, 정규화된 비율, 변화 곡선, 출력 범위를 분리하면 규칙을 이해하고 조절하기 쉽다.

다음 Part에서는 값 변환을 형태 생성에 적용한다. 함수 그래프를 선과 패턴으로 바꾸고, 삼각함수와 파동으로 반복과 진동을 만든 뒤 여러 함수를 결합해 복잡한 형태를 구성한다.
