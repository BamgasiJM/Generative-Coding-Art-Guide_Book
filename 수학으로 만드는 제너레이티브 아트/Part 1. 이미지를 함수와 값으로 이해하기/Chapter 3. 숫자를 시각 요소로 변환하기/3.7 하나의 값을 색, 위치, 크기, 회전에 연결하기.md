# 3.7 하나의 값을 색, 위치, 크기, 회전에 연결하기

지금까지 값의 범위를 확인하고, 정규화하고, 제한하고, 다른 범위로 재매핑하고, 보간과 임계값으로 변화 방식을 조절하는 방법을 살펴보았다. 이 연산들의 목적은 계산된 값을 실제 시각 요소에 연결하는 것이다.

하나의 입력값은 여러 출력 속성을 동시에 조절할 수 있다. 노이즈 값 하나로 도형의 크기와 회전을 바꾸고, 데이터값 하나로 점의 높이와 색을 함께 정할 수 있다. 같은 값에서 나온 변화는 이미지에 일관성을 만든다. 그러나 모든 속성을 똑같이 연결하면 결과가 단조롭거나 의미가 중복될 수 있다. 이 절에서는 값과 시각 속성의 연결을 설계하는 방법을 정리한다.

## 공통 입력을 먼저 정규화하기

원래 값의 범위를 시각 속성마다 반복해서 처리하기보다, 먼저 0에서 1 사이의 공통 비율로 바꾸면 구조가 분명해진다.

```text
t = normalize(value, inputMin, inputMax)
t = clamp(t, 0, 1)

color = colorFromValue(t)
position = positionFromValue(t)
size = sizeFromValue(t)
rotation = rotationFromValue(t)
```

$t$는 원래 입력 범위 안에서 현재 값의 위치를 나타낸다. 각 출력 함수는 같은 비율을 자기 속성에 맞는 범위와 변화 곡선으로 바꾼다.

이 구조의 장점은 입력 해석과 시각 디자인이 분리된다는 점이다. 데이터 범위가 바뀌면 정규화 단계만 수정하고, 색이나 크기 범위가 바뀌면 해당 출력 함수만 수정할 수 있다.

## 값을 위치에 연결하기

위치는 한 축의 스칼라일 수도 있고 여러 성분을 가진 벡터일 수도 있다. 값 $t$를 두 위치 사이에 연결하면 다음과 같다.

$$
\mathbf{p}(t)=(1-t)\mathbf{p}_0+t\mathbf{p}_1
$$

```text
position = interpolate(startPosition, endPosition, t)
```

한 축만 바꾸고 다른 축은 별도의 규칙으로 정할 수도 있다.

```text
x = interpolate(left, right, columnRatio)
y = interpolate(bottom, top, t)
```

데이터 시각화에서 값의 위치는 일반적으로 읽기 정확도가 높다. 같은 기준축을 공유하면 여러 값을 비교하기 쉽다. 반면 자유로운 2차원 위치는 구성과 흐름을 만들기 좋지만 정확한 수치 비교는 어려울 수 있다.

값을 위치에 연결할 때는 좌표계의 방향도 확인해야 한다. 화면의 $y$축이 아래로 증가한다면 큰 값을 위쪽에 놓기 위해 출력 범위를 `bottom`에서 `top` 순서로 뒤집어야 한다.

## 값을 크기에 연결하기

정규화된 값 $t$를 최소 크기와 최대 크기 사이에 연결할 수 있다.

$$
s(t)=s_{min}+t(s_{max}-s_{min})
$$

```text
diameter = interpolate(minDiameter, maxDiameter, t)
```

도형의 면적이나 부피가 지각되는 크기에 영향을 준다면 단순 선형 연결이 수치 관계를 과장할 수 있다. 원의 면적을 값에 비례시키려면 반지름에 제곱근을 적용한다.

$$
r(t)=\sqrt{r_{min}^2+t(r_{max}^2-r_{min}^2)}
$$

구의 부피를 값에 비례시키려면 세제곱근 관계를 고려해야 한다. 예술적 표현에서는 정확한 비례보다 시각적 대비를 우선할 수 있지만, 어떤 성질이 값에 비례하는지는 알고 선택하는 것이 좋다.

크기가 0에 가까워지면 요소가 사실상 사라지고, 지나치게 커지면 다른 요소를 가린다. 최소·최대 크기는 데이터 범위뿐 아니라 구성의 밀도와 겹침을 고려해 정한다.

## 값을 회전에 연결하기

0에서 1 사이의 값을 한 바퀴 회전에 연결하면 다음과 같다.

$$
\theta=2\pi t
$$

```text
angle = t * 2 * PI
```

방향을 나타내는 데이터라면 각도 연결이 자연스럽다. 그러나 단순한 크기 데이터를 각도에만 연결하면 어느 방향이 더 큰지 즉시 비교하기 어려울 수 있다. 각도는 방향, 위상, 주기적 상태를 나타낼 때 특히 적합하다.

선이나 화살표의 방향 벡터는 각도에서 다음과 같이 구한다.

$$
\mathbf{d}=(\cos\theta,\sin\theta)
$$

```text
direction = (cos(angle), sin(angle))
endPoint = center + direction * lineLength
```

값이 반복 범위를 넘어도 회전은 자연스럽게 이어질 수 있다. 반면 두 각도를 보간할 때는 0과 $2\pi$가 만나는 경계를 고려해야 한다.

## 값을 밝기와 색에 연결하기

정규화된 값 $t$를 회색조 밝기로 사용하면 다음과 같다.

$$
\mathbf{c}=(t,t,t)
$$

두 색 사이를 보간할 수도 있다.

$$
\mathbf{c}(t)=(1-t)\mathbf{c}_0+t\mathbf{c}_1
$$

```text
color = interpolateColor(lowColor, highColor, t)
```

여러 색으로 이루어진 팔레트에서는 $t$가 속한 구간을 찾고 이웃한 두 색 사이를 보간한다. 단계적인 표현이 필요하면 가장 가까운 팔레트 색을 선택한다.

색을 선택할 때는 값의 성격을 고려한다.

| 값의 성격 | 적합한 색상 구조 |
| --- | --- |
| 낮음에서 높음으로 이어지는 값 | 밝기나 채도가 한 방향으로 변하는 순차 팔레트 |
| 기준값을 중심으로 음수와 양수로 나뉨 | 중앙색에서 양쪽으로 갈라지는 발산 팔레트 |
| 순환하는 각도나 위상 | 끝과 시작이 이어지는 순환 팔레트 |
| 서로 순서가 없는 범주 | 서로 구분되는 정성 팔레트 |

RGB 채널을 각각 임의로 재매핑하면 중간색의 밝기와 채도가 예상과 다를 수 있다. 중요한 정보를 전달하는 색상이라면 색 공간과 지각적 균일성도 고려해야 한다.

## 값을 투명도와 선 두께에 연결하기

투명도는 요소의 존재감과 겹침을 조절한다.

```text
opacity = interpolate(minOpacity, maxOpacity, t)
```

낮은 값을 완전히 투명하게 만들면 데이터나 구조가 사라질 수 있다. 최소 투명도를 0보다 크게 두거나, 중요한 값은 색과 크기 같은 다른 속성으로도 표시할 수 있다.

선 두께는 흐름, 힘, 빈도, 깊이를 나타내는 데 사용할 수 있다.

```text
lineWidth = interpolate(minWidth, maxWidth, shapedT)
```

아주 얇은 선은 출력 해상도에서 사라질 수 있고, 굵은 선은 경로 사이의 공간을 메울 수 있다. 화면용과 인쇄용 출력에서는 같은 수치도 다르게 보일 수 있으므로 단위를 확인해야 한다.

## 같은 값을 여러 속성에 연결하기

하나의 $t$를 크기, 색, 회전에 동시에 연결해 보자.

```text
t = clamp(normalize(value, inputMin, inputMax), 0, 1)

radius = interpolate(minRadius, maxRadius, sqrt(t))
color = samplePalette(t)
angle = interpolate(minAngle, maxAngle, t)
opacity = interpolate(minOpacity, maxOpacity, t)
```

모든 속성이 입력값과 함께 변하므로 값이 큰 요소는 더 크고, 팔레트의 끝색에 가까우며, 더 많이 회전하고, 더 불투명해진다. 이 중복된 표현은 중요한 차이를 강조할 수 있다.

그러나 같은 정보를 너무 많은 속성으로 반복하면 한 가지 변화가 전체 이미지를 지배한다. 특히 크기와 밝기와 투명도가 모두 동시에 커지면 작은 값은 거의 보이지 않을 수 있다. 무엇을 주된 표현 채널로 삼고 무엇을 보조 채널로 둘지 정하는 것이 좋다.

## 같은 입력에 서로 다른 곡선 적용하기

모든 속성이 같은 속도로 변할 필요는 없다. 공통 입력 $t$에 서로 다른 함수를 적용하면 관계는 유지하면서 단조로움을 줄일 수 있다.

```text
sizeT = sqrt(t)
colorT = smoothStep(0, 1, t)
rotationT = t * t
opacityT = clamp(remap(t, 0.2, 0.8, 0, 1), 0, 1)
```

크기는 작은 입력에서도 비교적 빨리 커지고, 회전은 큰 입력에서 더 빠르게 변한다. 투명도는 입력의 가운데 구간에서만 변화한다. 같은 원천값을 사용하지만 각 속성의 민감도는 다르다.

이때 함수의 이름이나 변수명으로 변환의 목적을 드러내면 조정하기 쉽다.

## 상관관계와 독립적인 변화

같은 값을 여러 속성에 사용하면 속성 사이에 완전한 상관관계가 생긴다. 큰 도형은 항상 같은 계열의 색과 같은 방향을 가진다. 일관성은 높지만 가능한 조합은 제한된다.

더 다양한 결과가 필요하면 입력을 변형하거나 별도의 입력을 사용한다.

```text
sizeValue = noise(position * sizeScale)
colorValue = noise(position * colorScale + colorOffset)
rotationValue = noise(position * rotationScale + rotationOffset)
```

각 속성이 완전히 무관하면 이미지가 산만해질 수 있다. 하나의 공통값과 속성별 변형값을 섞는 방법도 있다.

```text
sizeT = commonValue
colorT = interpolate(commonValue, colorVariation, 0.3)
rotationT = interpolate(commonValue, rotationVariation, 0.6)
```

이 구조는 공통된 흐름을 유지하면서 일부 독립적인 변화를 허용한다.

## 예제: 격자의 값을 여러 속성에 연결하기

격자의 각 셀에서 0에서 1 사이의 값 $t$를 얻고, 이를 원의 크기, 색, 회전에 연결해 보자. 특정 라이브러리에 종속되지 않은 의사코드로 전체 구조를 나타내면 다음과 같다.

```text
for each cell in grid:
    position = cellCenter(cell)
    rawValue = noise(position * noiseScale)
    t = clamp(normalize(rawValue, noiseMin, noiseMax), 0, 1)

    radius = interpolate(minRadius, maxRadius, sqrt(t))
    color = samplePalette(smoothStep(0, 1, t))
    angle = interpolate(-maxAngle, maxAngle, t)
    opacity = interpolate(0.35, 1.0, t)

    drawOrientedCircleMark(
        position,
        radius,
        angle,
        color,
        opacity
    )
```

원의 회전은 겉으로 보이지 않으므로 `drawOrientedCircleMark`는 원 안에 방향선이나 비대칭 표시가 있는 기호를 그린다고 가정한다. 회전 대칭인 도형에 회전값을 연결해도 시각적 변화는 나타나지 않는다. 출력 속성을 고를 때는 도형이 그 변화를 실제로 드러낼 수 있는지도 확인해야 한다.

## 픽셀 함수에서의 연결

같은 구조를 프래그먼트 셰이더에서는 현재 픽셀의 색 계산에 사용할 수 있다. 다음 GLSL 예제는 중심에서의 정규화된 거리를 색과 마스크에 연결한다.

```glsl
vec2 p = uv - 0.5;
p.x *= resolution.x / resolution.y;

float distanceValue = length(p);
float t = clamp(distanceValue / maxDistance, 0.0, 1.0);

vec3 innerColor = vec3(0.95, 0.30, 0.18);
vec3 outerColor = vec3(0.08, 0.20, 0.42);
vec3 color = mix(innerColor, outerColor, t);

float mask = 1.0 - smoothstep(radius, radius + edgeWidth, distanceValue);
vec3 outputColor = color * mask;
```

입력은 좌표에서 계산한 거리 하나지만, `t`는 색 혼합에 사용되고 원래 거리값은 도형의 마스크에 사용된다. 같은 입력에서 파생된 값이라도 목적에 맞는 단계에서 사용할 수 있다.

## 연결을 평가하는 질문

값과 시각 요소의 연결을 설계한 뒤에는 다음을 확인한다.

- 입력값의 의미와 범위가 명확한가?
- 출력 속성의 범위가 실제 화면에서 충분히 구분되는가?
- 값이 커지는 방향과 시각적 변화의 방향이 의도와 맞는가?
- 크기, 면적, 밝기 가운데 무엇이 값에 비례해야 하는가?
- 같은 정보를 여러 속성으로 반복할 필요가 있는가?
- 낮은 값이나 범위 밖의 값이 완전히 사라지지 않는가?
- 색이나 각도처럼 주기적이거나 비선형적인 속성의 경계를 처리했는가?

제너레이티브 아트에서는 정답이 하나로 정해져 있지 않지만, 연결의 결과와 이유는 설명할 수 있어야 한다. 의도한 관계를 알고 있을 때 파라미터를 바꾸고 변주하기도 쉬워진다.

## 이 장의 마무리

Chapter 3에서는 계산된 숫자를 시각 요소로 바꾸는 과정을 다루었다. 먼저 값의 의미, 단위, 범위를 구분하고, 서로 다른 범위를 비교하고 연결하기 위해 정규화했다. 범위 밖의 값은 제한, 반복, 반사 같은 방식으로 처리했으며, 재매핑을 통해 입력 범위의 상대적 위치를 출력 범위로 옮겼다.

선형 보간은 두 상태 사이를 연결하고, 비선형 곡선과 `smoothstep`은 변화의 속도와 경계를 부드럽게 만든다. 임계값은 연속값을 영역과 단계로 나누며, 그 결과인 마스크는 색과 형태가 적용될 위치를 제어한다. 마지막으로 같은 값을 위치, 크기, 회전, 색, 투명도에 연결해 하나의 시각 시스템으로 구성했다.

이 장의 핵심은 숫자를 곧바로 출력에 넣지 않고 그 의미와 범위를 먼저 살피는 것이다. 입력 범위, 정규화된 비율, 변화 곡선, 출력 범위를 분리하면 규칙을 이해하고 조절하기 쉬워진다.

다음 Part에서는 이 값 변환의 구조를 실제 형태 생성에 적용한다. 함수의 그래프를 선과 패턴으로 바꾸고, 삼각함수와 파동을 사용해 반복과 진동을 만들며, 여러 함수를 결합해 더 복잡한 형태를 구성한다.
