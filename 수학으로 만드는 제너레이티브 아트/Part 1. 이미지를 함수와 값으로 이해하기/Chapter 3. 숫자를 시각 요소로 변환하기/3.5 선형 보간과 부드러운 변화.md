# 3.5 선형 보간과 부드러운 변화

두 값 사이의 값을 계산하는 연산을 보간이라고 한다. 시작점에서 끝점으로 움직이거나 두 색을 섞을 때, 크기와 투명도를 서서히 바꿀 때 사용한다. 보간은 서로 다른 상태를 연속적인 변화로 잇는 기본 도구다.

가장 단순한 보간은 선형 보간이다. 시작값 $a$, 끝값 $b$, 보간 비율 $t$를 다음 식에 넣어 계산한다.

$$
\operatorname{lerp}(a,b,t)=a+t(b-a)
$$

`lerp`는 linear interpolation의 줄임말이며 여러 그래픽 환경에서 널리 쓰인다.

## 보간 비율의 의미

$t=0$이면 시작값, $t=1$이면 끝값을 반환한다. 그 사이의 값은 두 끝점 사이의 위치를 나타낸다.

| $t$ | 결과 |
| --- | --- |
| 0 | $a$ |
| 0.25 | $a$에서 $b$로 25퍼센트 이동한 값 |
| 0.5 | $(a+b)/2$ |
| 0.75 | $a$에서 $b$로 75퍼센트 이동한 값 |
| 1 | $b$ |

```text
function interpolate(start, end, t):
    return start + t * (end - start)
```

$t$를 0~1로 제한하지 않으면 양 끝 범위 밖의 값도 계산한다. $t<0$이면 시작값 이전으로, $t>1$이면 끝값 이후로 외삽한다.

## 재매핑과 선형 보간의 관계

앞 절의 재매핑은 두 단계로 표현할 수 있다. 입력값을 정규화해 비율 $t$를 구한 뒤, 그 비율로 출력 경계 사이를 보간한다.

$$
t=\frac{x-a}{b-a}
$$

$$
y=\operatorname{lerp}(c,d,t)
$$

```text
t = normalize(value, inputMin, inputMax)
output = interpolate(outputMin, outputMax, t)
```

정규화된 비율에 다른 함수를 적용하면 변화 속도를 조절할 수 있다.

## 스칼라, 벡터, 색 보간하기

선형 보간은 숫자뿐 아니라 벡터의 각 성분에도 적용된다. 두 점 $\mathbf{a}$와 $\mathbf{b}$ 사이의 점은 다음과 같이 쓴다.

$$
\mathbf{p}(t)=\mathbf{a}+t(\mathbf{b}-\mathbf{a})
$$

```text
position = interpolate(startPosition, endPosition, t)
```

RGB 색을 세 채널의 벡터로 보면 같은 식으로 보간할 수 있다.

$$
\mathbf{c}(t)=(1-t)\mathbf{c}_0+t\mathbf{c}_1
$$

색 보간의 결과는 색 공간에 따라 달라진다. 감마가 적용된 RGB에서 보간한 색과 선형 색 공간에서 보간한 색은 밝기가 다르게 보일 수 있다. HSL이나 HSV의 색상각을 보간하면 색상환을 따라 이동할 수 있지만, 360도와 0도 사이의 경계 처리가 필요하다.

## 선형 보간은 속도가 일정하다

시간에 따라 $t$를 일정하게 증가시키면 선형 보간의 출력도 일정한 속도로 변한다.

$$
t=\frac{\text{elapsed}}{\text{duration}}
$$

```text
t = clamp(elapsedTime / duration, 0, 1)
position = interpolate(startPosition, endPosition, t)
```

이 방식은 일정한 속도로 움직이지만 시작과 끝에서 갑자기 출발하거나 멈춘다. 자연스럽게 가속하고 감속하려면 보간 비율 $t$를 이징 함수로 바꾼다.

## 보간 비율을 변형하기

시작값과 끝값은 유지하면서 중간 변화만 조절하려면 $t$에 다른 함수를 적용한다.

```text
linearT = clamp(elapsedTime / duration, 0, 1)
easedT = easingFunction(linearT)
value = interpolate(startValue, endValue, easedT)
```

제곱 함수는 느리게 시작해 점차 빨라지는 변화를 만든다.

$$
f(t)=t^2
$$

끝에서 감속하는 변화는 다음 식으로 만든다.

$$
g(t)=1-(1-t)^2
$$

두 함수 모두 0과 1은 그대로 유지하고 중간값을 다르게 분포시킨다.

## smoothstep

`smoothstep`은 두 경계 사이의 값을 0~1로 부드럽게 연결한다. 먼저 입력 $x$를 경계 $e_0$, $e_1$ 사이에서 정규화하고 제한한다.

$$
t=\operatorname{clamp}\left(\frac{x-e_0}{e_1-e_0},0,1\right)
$$

정규화한 값에 다음 다항식을 적용한다.

$$
s(t)=t^2(3-2t)
$$

이 함수는 시작과 끝에서 기울기가 0이므로 선형 보간보다 경계에 부드럽게 진입하고 빠져나온다.

```text
function smoothStep(edge0, edge1, value):
    t = clamp((value - edge0) / (edge1 - edge0), 0, 1)
    return t * t * (3 - 2 * t)
```

GLSL에는 `smoothstep(edge0, edge1, x)`가 내장되어 있다. 경계의 순서를 뒤집어 전달하면 명세나 환경에 따라 결과가 정의되지 않을 수 있다. 출력을 반전하려면 다음처럼 식에 명시한다.

```glsl
float mask = 1.0 - smoothstep(innerEdge, outerEdge, distanceValue);
```

## 선형 변화와 부드러운 변화 비교

| 함수 | 시작과 끝 | 경계의 기울기 | 주된 용도 |
| --- | --- | --- | --- |
| $t$ | 0과 1 유지 | 일정 | 균일한 변화, 정확한 비례 |
| $t^2$ | 0과 1 유지 | 시작이 느림 | 가속하는 변화 |
| $1-(1-t)^2$ | 0과 1 유지 | 끝이 느림 | 감속하는 변화 |
| $t^2(3-2t)$ | 0과 1 유지 | 양 끝에서 0 | 부드러운 경계와 이징 |

부드러운 함수가 늘 적합한 것은 아니다. 데이터값의 비율을 정확히 비교하거나 기계적인 움직임, 일정한 스캔 효과를 표현할 때는 선형 보간이 알맞다. 함수는 표현하려는 관계에 맞춰 선택한다.

## 거리 경계를 부드럽게 만들기

거리 함수에 임계값을 적용해 원을 만들면 안과 밖이 급격히 나뉜다.

```glsl
float hardCircle = 1.0 - step(radius, distanceValue);
```

전환 구간을 정해 `smoothstep`을 적용하면 가장자리가 부드러워진다.

```glsl
float softCircle = 1.0 - smoothstep(
    radius - edgeWidth,
    radius + edgeWidth,
    distanceValue
);
```

`edgeWidth`는 전환 구간의 절반 폭이다. 너무 작으면 픽셀 격자에서 계단 현상이 남고, 너무 크면 원의 경계가 흐려진다. 셰이더에서는 화면 미분값으로 픽셀 크기에 맞는 경계 폭을 구하기도 한다.

```glsl
float edgeWidth = fwidth(distanceValue);
float mask = 1.0 - smoothstep(
    radius - edgeWidth,
    radius + edgeWidth,
    distanceValue
);
```

이 방식은 해상도와 확대 배율에 맞춰 경계 폭을 조절하는 안티앨리어싱에 쓰인다.

## 두 상태 사이를 계속 보간하기

0~1 사이를 반복하는 값을 보간 비율로 쓰면 두 상태를 오가는 변화를 만들 수 있다. 사인 함수의 출력은 -1~1이므로 먼저 0~1로 변환한다.

$$
t=\frac{\sin(\omega t_{time})+1}{2}
$$

시간 변수와 보간 비율에 같은 기호 $t$를 쓰면 혼동될 수 있으므로 코드에서는 변수명을 구분한다.

```text
phase = elapsedTime * angularSpeed
blend = sin(phase) * 0.5 + 0.5
size = interpolate(minSize, maxSize, blend)
```

사인 함수는 양 끝에서 부드럽게 방향을 바꾼다. 크기 변화, 밝기의 맥동, 왕복 운동에 적합하다.

## 현재값을 목표값 쪽으로 반복 보간하기

현재값을 매 프레임 목표값과 일정 비율로 보간하는 방식도 자주 쓴다.

```text
current = interpolate(current, target, 0.1)
```

이 방식은 매번 남은 거리의 10퍼센트만큼 이동하므로 목표에 가까워질수록 느려진다. 정해진 시간 안에 도착하는 선형 보간과는 다르다. 프레임마다 같은 비율을 적용하면 프레임 속도에 따라 실제 감쇠 속도도 달라진다.

시간 간격에 좌우되지 않는 지수 감쇠를 만들려면 초당 감쇠율을 각 프레임의 시간 간격에 맞게 변환한다.

$$
\alpha=1-e^{-k\Delta t}
$$

```text
alpha = 1 - exp(-response * deltaTime)
current = interpolate(current, target, alpha)
```

프레임 속도가 달라도 비슷한 반응 속도를 유지할 수 있다. `response`는 목표에 접근하는 속도를 조절한다.

## 여러 구간 보간하기

색상 팔레트나 여러 키프레임에는 기준값이 두 개보다 많다. 전체 비율을 구간 인덱스와 해당 구간 안의 비율로 나누어 보간한다.

```text
scaled = t * segmentCount
segment = min(floor(scaled), segmentCount - 1)
localT = scaled - segment

value = interpolate(keys[segment], keys[segment + 1], localT)
```

구간 길이가 서로 다르면 각 키의 위치를 저장하고 현재 값이 속한 구간을 찾아야 한다. 색상 그라데이션, 애니메이션 곡선, 데이터 보간에 이 구조를 적용할 수 있다.

## 각도 보간의 경계

각도는 주기적이어서 숫자만 그대로 보간하면 더 긴 방향으로 회전할 수 있다. 350도에서 10도로 이동할 때 선형 보간은 180도를 거치지만, 최단 회전은 20도다.

```text
difference = wrapToSignedAngle(targetAngle - currentAngle)
angle = currentAngle + difference * t
```

각도, 색상환의 색상각, 반복 좌표처럼 주기적인 값은 경계를 고려해 보간해야 한다. 3차원 회전에서는 오일러 각의 성분별 보간보다 쿼터니언 보간을 자주 사용한다.

## 이 절의 핵심

선형 보간은 비율 $t$에 따라 시작값과 끝값을 연결한다.

$$
\operatorname{lerp}(a,b,t)=a+t(b-a)
$$

성분별 연산이 가능한 스칼라, 벡터, 색에 적용할 수 있다. 보간 비율에 제곱 함수나 `smoothstep`을 적용하면 시작과 끝의 변화 속도를 조절한다. 거리 함수의 경계에 `smoothstep`을 쓰면 부드러운 마스크와 안티앨리어싱을 만들 수 있다.

보간에서는 외삽 여부, 색 공간, 각도의 주기성, 프레임 시간 의존성을 확인해야 한다. 다음 절에서는 연속값을 둘 이상의 영역으로 나누는 임계값과 마스크를 다룬다.
