# 3.5 선형 보간과 부드러운 변화

두 값 사이의 중간값을 구하는 연산을 보간이라고 한다. 시작 위치와 끝 위치 사이를 움직이거나, 두 색을 섞거나, 크기와 투명도를 서서히 바꿀 때 보간을 사용한다. 제너레이티브 아트에서 보간은 서로 떨어진 상태를 연속적인 변화로 연결하는 기본 도구다.

가장 단순한 형태는 선형 보간이다. 시작값 $a$, 끝값 $b$, 보간 비율 $t$가 있을 때 다음과 같이 계산한다.

$$
\operatorname{lerp}(a,b,t)=a+t(b-a)
$$

`lerp`는 linear interpolation의 줄임말로 여러 그래픽 환경에서 널리 사용하는 이름이다.

## 보간 비율의 의미

$t$가 0이면 시작값을, 1이면 끝값을 반환한다. 0과 1 사이에서는 두 값 사이의 위치를 나타낸다.

| $t$ | 결과 |
| --- | --- |
| 0 | $a$ |
| 0.25 | $a$에서 $b$로 25퍼센트 이동한 값 |
| 0.5 | $(a+b)/2$ |
| 0.75 | $a$에서 $b$로 75퍼센트 이동한 값 |
| 1 | $b$ |

```text
function interpolate(start, end, t):
    return start + t * (end - start)
```

$t$를 0에서 1 사이로 제한하지 않으면 범위 밖의 값도 계산할 수 있다. $t<0$이면 시작값 바깥으로, $t>1$이면 끝값 바깥으로 외삽한다.

## 재매핑과 선형 보간의 관계

앞 절의 재매핑은 두 단계로 나눌 수 있다. 먼저 입력값을 정규화해 비율 $t$를 구하고, 그 비율로 출력 경계 사이를 보간한다.

$$
t=\frac{x-a}{b-a}
$$

$$
y=\operatorname{lerp}(c,d,t)
$$

```text
t = normalize(value, inputMin, inputMax)
output = interpolate(outputMin, outputMax, t)
```

이 구조를 이해하면 정규화된 비율에 다른 함수를 적용해 변화의 속도를 조절할 수 있다.

## 스칼라, 벡터, 색 보간하기

선형 보간은 숫자 하나뿐 아니라 벡터의 각 성분에도 적용할 수 있다. 두 점 $\mathbf{a}$와 $\mathbf{b}$ 사이의 점은 다음과 같다.

$$
\mathbf{p}(t)=\mathbf{a}+t(\mathbf{b}-\mathbf{a})
$$

```text
position = interpolate(startPosition, endPosition, t)
```

RGB 색도 세 채널로 이루어진 벡터로 보면 같은 식을 적용할 수 있다.

$$
\mathbf{c}(t)=(1-t)\mathbf{c}_0+t\mathbf{c}_1
$$

다만 색 보간의 시각적 결과는 색 공간에 따라 달라진다. 감마가 적용된 RGB 값에서 직접 보간한 결과와 선형 색 공간에서 보간한 결과는 밝기가 다르게 보일 수 있다. 색상을 따라 이동하고 싶다면 HSL이나 HSV의 색상각을 보간할 수 있지만, 각도가 360도에서 0도로 이어지는 경계도 처리해야 한다.

## 선형 보간은 속도가 일정하다

$t$가 시간에 따라 일정하게 증가하면 선형 보간의 출력도 일정한 속도로 변한다.

$$
t=\frac{\text{elapsed}}{\text{duration}}
$$

```text
t = clamp(elapsedTime / duration, 0, 1)
position = interpolate(startPosition, endPosition, t)
```

이 움직임은 수치적으로 정확하지만 시작과 끝에서 갑자기 움직이거나 멈추는 느낌을 줄 수 있다. 자연스러운 진입과 이탈이 필요하면 보간 비율 $t$를 이징 함수로 변형한다.

## 보간 비율을 변형하기

시작과 끝값은 그대로 두고 중간 변화만 바꾸려면 $t$를 다른 함수에 통과시킨다.

```text
linearT = clamp(elapsedTime / duration, 0, 1)
easedT = easingFunction(linearT)
value = interpolate(startValue, endValue, easedT)
```

간단한 제곱 함수는 느리게 시작해 점점 빨라지는 변화를 만든다.

$$
f(t)=t^2
$$

끝에서 느려지는 변화는 다음처럼 만들 수 있다.

$$
g(t)=1-(1-t)^2
$$

두 함수 모두 0을 0으로, 1을 1로 보내지만 중간값의 분포가 다르다.

## smoothstep

`smoothstep`은 두 경계 사이를 0에서 1로 부드럽게 연결하는 함수다. 먼저 입력 $x$를 경계 $e_0$, $e_1$ 사이에서 정규화하고 제한한다.

$$
t=\operatorname{clamp}\left(\frac{x-e_0}{e_1-e_0},0,1\right)
$$

그다음 다음 다항식을 적용한다.

$$
s(t)=t^2(3-2t)
$$

이 함수는 시작과 끝에서 기울기가 0이다. 따라서 선형 보간보다 경계에 부드럽게 진입하고 빠져나온다.

```text
function smoothStep(edge0, edge1, value):
    t = clamp((value - edge0) / (edge1 - edge0), 0, 1)
    return t * t * (3 - 2 * t)
```

GLSL에는 `smoothstep(edge0, edge1, x)`가 내장되어 있다. 다만 두 경계의 순서를 반대로 넣는 방식은 명세나 환경에 따라 정의되지 않은 결과가 될 수 있으므로, 결과를 뒤집으려면 다음처럼 명시하는 편이 안전하다.

```glsl
float mask = 1.0 - smoothstep(innerEdge, outerEdge, distanceValue);
```

## 선형 변화와 부드러운 변화 비교

| 함수 | 시작과 끝 | 경계의 기울기 | 주된 용도 |
| --- | --- | --- | --- |
| $t$ | 0과 1 유지 | 일정 | 균일한 변화, 정확한 비례 |
| $t^2$ | 0과 1 유지 | 시작이 느림 | 가속하는 변화 |
| $1-(1-t)^2$ | 0과 1 유지 | 끝이 느림 | 감속하는 변화 |
| $t^2(3-2t)$ | 0과 1 유지 | 양 끝에서 0 | 부드러운 경계와 이징 |

부드러운 함수가 항상 더 좋은 것은 아니다. 데이터값을 정확한 비율로 비교해야 한다면 선형 보간이 적합하다. 기계적인 움직임이나 일정한 스캔 효과에도 선형 변화가 어울릴 수 있다. 함수의 선택은 표현하려는 관계에 따라 달라진다.

## 거리 경계를 부드럽게 만들기

거리 함수로 원을 만들 때 임계값만 사용하면 안과 밖이 갑자기 나뉜다.

```glsl
float hardCircle = 1.0 - step(radius, distanceValue);
```

경계 폭을 정하고 `smoothstep`을 적용하면 가장자리를 부드럽게 만들 수 있다.

```glsl
float softCircle = 1.0 - smoothstep(
    radius - edgeWidth,
    radius + edgeWidth,
    distanceValue
);
```

`edgeWidth`는 전환 구간의 절반 폭이다. 값이 너무 작으면 픽셀 격자에서 여전히 계단 현상이 보일 수 있고, 너무 크면 원의 경계가 흐려진다. 셰이더에서는 화면 미분값을 사용해 픽셀 크기에 맞는 경계 폭을 구하기도 한다.

```glsl
float edgeWidth = fwidth(distanceValue);
float mask = 1.0 - smoothstep(
    radius - edgeWidth,
    radius + edgeWidth,
    distanceValue
);
```

이 방식은 해상도와 확대 배율에 따라 경계 폭을 조절하는 안티앨리어싱에 활용된다.

## 두 상태 사이를 계속 보간하기

0에서 1 사이를 반복하는 값을 보간 비율로 사용하면 두 상태 사이를 계속 오가는 변화가 만들어진다. 사인 함수는 -1에서 1 사이이므로 먼저 0에서 1로 옮긴다.

$$
t=\frac{\sin(\omega t_{time})+1}{2}
$$

시간 변수와 보간 비율에 같은 글자 $t$를 쓰면 혼동될 수 있으므로 코드에서는 이름을 구분하는 것이 좋다.

```text
phase = elapsedTime * angularSpeed
blend = sin(phase) * 0.5 + 0.5
size = interpolate(minSize, maxSize, blend)
```

사인 함수는 양 끝에서 자연스럽게 방향을 바꾸므로 크기 변화, 호흡하는 밝기, 왕복 운동에 적합하다.

## 현재값을 목표값 쪽으로 반복 보간하기

매 프레임 현재값을 목표값과 일정 비율로 보간하는 코드도 자주 사용된다.

```text
current = interpolate(current, target, 0.1)
```

이 방식은 매번 남은 거리의 10퍼센트를 이동하므로 목표에 가까워질수록 느려진다. 정확히 일정한 시간에 도착하는 선형 보간과는 다르다. 또한 프레임마다 같은 비율을 사용하면 프레임 속도에 따라 실제 감쇠 속도가 달라진다.

시간 간격에 독립적인 지수 감쇠를 만들려면 초당 감쇠율을 시간 간격에 맞게 변환할 수 있다.

$$
\alpha=1-e^{-k\Delta t}
$$

```text
alpha = 1 - exp(-response * deltaTime)
current = interpolate(current, target, alpha)
```

이 방식은 프레임 속도가 달라도 비슷한 반응 속도를 유지한다. 여기서 `response`는 목표에 접근하는 빠르기를 조절한다.

## 여러 구간 보간하기

색상 팔레트나 여러 키프레임처럼 두 개보다 많은 기준값이 있을 수 있다. 이때 전체 비율을 구간 인덱스와 구간 내부 비율로 나눈다.

```text
scaled = t * segmentCount
segment = min(floor(scaled), segmentCount - 1)
localT = scaled - segment

value = interpolate(keys[segment], keys[segment + 1], localT)
```

각 구간의 길이가 같지 않다면 키마다 위치값을 저장하고 현재 값이 속한 구간을 찾아야 한다. 색상 그라데이션, 애니메이션 곡선, 데이터 보간은 모두 이 구조를 확장해 사용할 수 있다.

## 각도 보간의 경계

각도는 주기적인 값이므로 단순히 숫자만 보간하면 먼 방향으로 회전할 수 있다. 350도에서 10도로 이동할 때 선형 숫자 보간은 180도를 지나지만, 가장 짧은 회전은 20도만 이동하는 것이다.

```text
difference = wrapToSignedAngle(targetAngle - currentAngle)
angle = currentAngle + difference * t
```

각도, 색상환의 색상각, 반복 좌표처럼 주기적인 값은 경계를 고려한 보간이 필요하다. 3차원 회전은 오일러 각의 성분을 각각 보간하기보다 쿼터니언 보간을 사용하는 경우가 많다.

## 이 절의 핵심

선형 보간은 시작값과 끝값 사이를 비율 $t$로 연결한다.

$$
\operatorname{lerp}(a,b,t)=a+t(b-a)
$$

스칼라, 벡터, 색 등 성분별 연산이 가능한 값에 적용할 수 있다. 보간 비율에 제곱 함수나 `smoothstep`을 적용하면 시작과 끝에서 변화 속도를 조절할 수 있다. 거리 함수의 경계에는 `smoothstep`을 사용해 부드러운 마스크와 안티앨리어싱을 만들 수 있다.

보간을 사용할 때는 외삽 허용 여부, 색 공간, 각도의 주기성, 프레임 시간 의존성을 함께 확인해야 한다. 다음 절에서는 연속값을 두 영역이나 여러 단계로 나누는 임계값과 마스크를 다룬다.
