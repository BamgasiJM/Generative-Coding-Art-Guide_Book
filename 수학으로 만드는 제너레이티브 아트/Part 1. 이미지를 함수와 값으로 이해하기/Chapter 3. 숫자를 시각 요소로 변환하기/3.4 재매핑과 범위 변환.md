# 3.4 재매핑과 범위 변환

정규화는 어떤 범위의 값을 0에서 1 사이의 비율로 바꾼다. 실제 그래픽 작업에서는 그 비율을 다시 색상, 크기, 위치, 각도처럼 다른 범위로 옮겨야 한다. 예를 들어 0도에서 40도 사이의 온도를 2픽셀에서 20픽셀 사이의 원 반지름으로 표현하거나, 센서값 200에서 800을 0에서 1 사이의 밝기로 바꿀 수 있다.

한 범위의 값을 다른 범위로 옮기는 연산을 재매핑 또는 범위 변환이라고 한다. 핵심은 입력 범위에서의 상대적 위치를 구한 뒤, 그 위치를 출력 범위에 적용하는 것이다.

## 입력 범위에서 비율 구하기

입력값 $x$가 $[a,b]$에 있을 때 정규화된 비율 $t$는 다음과 같다.

$$
t=\frac{x-a}{b-a}
$$

이 값은 $x$가 입력 범위의 어디에 있는지 나타낸다. 이제 출력 범위 $[c,d]$에서 같은 비율에 해당하는 값을 구한다.

$$
y=c+t(d-c)
$$

두 식을 결합하면 일반적인 재매핑 식이 된다.

$$
y=c+\frac{x-a}{b-a}(d-c)
$$

```text
function remap(value, inputMin, inputMax, outputMin, outputMax):
    t = (value - inputMin) / (inputMax - inputMin)
    return outputMin + t * (outputMax - outputMin)
```

이 식은 특정 라이브러리의 함수가 아니라 선형 범위 변환 자체다. 그래픽 환경에 따라 `map`, `remap`, `fit`, `linearstep`과 비슷한 이름의 함수가 제공될 수 있지만, 범위 밖 값의 제한 여부나 인자 순서는 서로 다를 수 있다.

## 재매핑 예제

0에서 100 사이의 값 25를 10에서 50 사이로 옮겨 보자. 먼저 입력 범위에서의 비율을 구한다.

$$
t=\frac{25-0}{100-0}=0.25
$$

그 비율을 출력 범위에 적용한다.

$$
y=10+0.25(50-10)=20
$$

입력값 25는 입력 범위의 25퍼센트 지점에 있고, 출력값 20도 출력 범위의 25퍼센트 지점에 있다. 재매핑은 숫자 자체를 보존하는 것이 아니라 범위 안의 상대적 위치를 보존한다.

## 출력 범위의 방향 바꾸기

출력 최솟값이 출력 최댓값보다 작아야 하는 것은 아니다. 출력 경계를 반대로 지정하면 값의 방향을 뒤집을 수 있다.

$$
y=d+t(c-d)
$$

예를 들어 중심에서의 거리가 0에서 500 사이일 때, 원의 반지름을 40에서 4 사이로 재매핑하면 중심에 가까운 원은 크고 멀리 있는 원은 작다.

```text
radius = remap(distance, 0, maxDistance, 40, 4)
```

입력 범위의 방향을 뒤집는 것보다 출력 범위를 원하는 시각적 방향으로 적는 편이 의도를 읽기 쉽다.

## 재매핑과 값 제한

재매핑 식은 입력값이 입력 범위를 벗어나도 계속 계산된다. 이를 외삽이라고 한다.

```text
remap(120, 0, 100, 0, 1) = 1.2
```

외삽을 허용할지, 입력 또는 출력을 제한할지는 별도로 정해야 한다.

```text
function remapClamped(value, inputMin, inputMax, outputMin, outputMax):
    t = (value - inputMin) / (inputMax - inputMin)
    t = clamp(t, 0, 1)
    return outputMin + t * (outputMax - outputMin)
```

정규화된 비율 $t$를 제한하면 출력 범위의 방향이 뒤집혀 있어도 올바르게 동작한다. 출력 결과를 나중에 제한하는 방식도 가능하지만, 경계가 뒤집힌 경우 최솟값과 최댓값의 순서를 따로 처리해야 한다.

| 방식 | 범위 밖 입력 | 적합한 상황 |
| --- | --- | --- |
| 제한 없는 재매핑 | 출력 범위 밖으로 외삽 | 물리적 이동, 의도적인 초과 효과 |
| 제한된 재매핑 | 가까운 출력 경계에 고정 | 투명도, 진행률, 제한된 UI 값 |
| 범위 밖 별도 처리 | 경고나 다른 표현 사용 | 데이터 품질, 임계 상태 표시 |

## 여러 시각 범위로 옮기기

한 번 정규화한 값은 여러 출력 범위에 사용할 수 있다.

```text
t = normalize(dataValue, dataMin, dataMax)

radius = interpolate(4, 30, t)
opacity = interpolate(0.2, 1.0, t)
angle = interpolate(0, 2 * PI, t)
```

이 구조는 원래 데이터 범위와 시각적 표현 범위를 분리한다. 데이터 범위가 바뀌면 정규화 단계만 수정하고, 시각 디자인이 바뀌면 출력 범위만 수정할 수 있다.

반대로 각 속성마다 재매핑을 독립적으로 적으면 어떤 입력 범위를 사용했는지 반복해서 드러나지만 코드가 길어진다. 작업의 규모와 값의 의미에 따라 적절한 구조를 선택한다.

## 단위 변환과 재매핑의 차이

섭씨를 화씨로 바꾸거나 도를 라디안으로 바꾸는 것도 선형식으로 표현할 수 있다.

$$
F=\frac{9}{5}C+32
$$

$$
\theta_{rad}=\theta_{deg}\frac{\pi}{180}
$$

형태는 재매핑과 비슷하지만 목적은 다르다. 단위 변환은 같은 물리량을 다른 단위로 표현하며, 입력과 출력 사이의 의미가 고정되어 있다. 시각적 재매핑은 데이터값을 반지름이나 색처럼 다른 의미의 속성에 연결하는 표현상의 선택이다.

이 차이를 변수 이름으로 드러내면 계산을 이해하기 쉽다.

```text
angleRadians = degreesToRadians(angleDegrees)
circleRadius = remap(temperatureCelsius, cold, hot, small, large)
```

## 비선형 재매핑

선형 재매핑은 입력 범위의 중간값을 출력 범위의 중간값으로 보낸다. 그러나 시각적으로 중간값을 더 작게 보이게 하거나 큰 값의 차이를 강조하고 싶을 수 있다. 이때 정규화된 비율 $t$에 비선형 함수를 적용한 뒤 출력 범위에 사용한다.

```text
t = normalize(value, inputMin, inputMax)
t = clamp(t, 0, 1)
shaped = t * t
output = interpolate(outputMin, outputMax, shaped)
```

$t^2$은 0과 1을 그대로 유지하지만 중간값을 낮춘다. 예를 들어 $t=0.5$일 때 $t^2=0.25$다. 반대로 제곱근은 중간값을 높인다.

$$
f(t)=t^2,\qquad g(t)=\sqrt{t}
$$

| 변환 | 중간 구간의 효과 | 활용 예 |
| --- | --- | --- |
| $t$ | 균일한 변화 | 기본 범위 변환 |
| $t^2$ | 작은 값 쪽에 오래 머묾 | 큰 값 강조, 느린 시작 |
| $\sqrt{t}$ | 빠르게 큰 값으로 이동 | 작은 입력 차이 강조 |
| $t^\gamma$ | 지수에 따라 분포 조절 | 감마 형태의 대비 제어 |

비선형 변환은 입력과 출력의 순서는 유지하면서 값의 분포를 바꿀 수 있다. 다만 입력이 0에서 1 범위에 있다는 가정과 함수의 정의역을 확인해야 한다.

## 면적과 반지름의 관계

데이터값을 원의 크기로 표현할 때 반지름을 선형 재매핑하면 면적은 값의 제곱에 비례한다. 원의 면적은 다음과 같다.

$$
A=\pi r^2
$$

면적이 데이터값 $t$에 비례하게 만들고 싶다면 반지름은 제곱근에 비례해야 한다.

$$
r=\sqrt{\frac{A}{\pi}}
$$

정규화된 값 $t$를 최대 반지름 $r_{max}$에 연결하는 간단한 형태는 다음과 같다.

$$
r=r_{max}\sqrt{t}
$$

이 예는 어떤 수치 속성을 시각 요소의 어느 기하학적 성질에 대응시키는지 생각해야 함을 보여 준다. “크기”가 반지름을 뜻하는지 면적을 뜻하는지에 따라 적절한 변환이 달라진다.

## 로그 범위 다루기

값의 크기 차이가 매우 클 때 선형 재매핑을 사용하면 작은 값들이 한쪽에 몰릴 수 있다. 양수 데이터에는 로그 변환을 적용할 수 있다.

$$
x'=\log(x)
$$

```text
logValue = log(max(value, epsilon))
t = normalize(logValue, logMin, logMax)
```

로그는 0 이하에서 정의되지 않으므로 입력 범위를 확인해야 한다. 데이터에 0이나 음수가 있다면 작은 양의 값을 더하거나, 부호를 보존하는 별도의 변환을 설계해야 한다. 로그 변환을 사용할 때는 시각적 척도가 선형이 아님을 독자가 알 수 있도록 표현하는 것도 중요하다.

## 정수 범위로 변환하기

팔레트 인덱스나 단계 번호처럼 이산적인 출력이 필요하면 연속적인 재매핑 결과를 정수로 바꾼다.

```text
t = clamp(normalize(value, minimum, maximum), 0, 1)
index = floor(t * levelCount)
index = min(index, levelCount - 1)
```

$t=1$일 때 `floor(t * levelCount)`가 유효 범위를 하나 벗어나므로 마지막 제한이 필요하다. 또는 처음부터 $[0,1)$ 범위를 사용하거나 반올림 규칙을 명확히 정할 수 있다.

정수로 바꾸는 순간 연속적인 변화는 계단 형태가 된다. 이 단계의 위치와 개수는 이미지의 분할감과 리듬을 결정한다.

## 범위 변환을 확인하는 방법

재매핑이 올바른지 확인하려면 입력 범위의 시작, 중간, 끝을 대입한다.

| 입력 | 예상 출력 |
| --- | --- |
| $x=a$ | $y=c$ |
| $x=(a+b)/2$ | $y=(c+d)/2$ |
| $x=b$ | $y=d$ |

출력 범위를 반대로 지정했다면 중간값은 그대로 중간이지만 시작과 끝이 바뀐다. 범위 밖 입력도 하나씩 검사해 제한 또는 외삽이 의도대로 작동하는지 확인한다.

## 이 절의 핵심

재매핑은 입력 범위에서의 상대적 위치를 출력 범위의 같은 위치로 옮기는 연산이다.

$$
y=c+\frac{x-a}{b-a}(d-c)
$$

이 식은 정규화와 선형 보간의 결합으로 이해할 수 있다. 출력 경계의 순서를 바꾸면 변화 방향을 뒤집을 수 있고, 정규화된 비율을 제한하면 외삽을 막을 수 있다. 비선형 함수를 중간에 적용하면 범위는 유지하면서 값의 분포와 시각적 강조를 조절할 수 있다. 다음 절에서는 이 식의 두 번째 단계인 선형 보간과 부드러운 전환을 자세히 다룬다.
