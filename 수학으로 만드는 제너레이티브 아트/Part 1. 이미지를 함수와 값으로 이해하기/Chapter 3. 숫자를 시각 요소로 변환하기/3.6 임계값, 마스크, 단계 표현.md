# 3.6 임계값, 마스크, 단계 표현

연속적인 값은 그라데이션과 부드러운 움직임을 만들지만, 때로는 영역을 명확하게 나누어야 한다. 거리값으로 원의 안과 밖을 구분하거나, 밝기가 일정 수준 이상인 픽셀만 선택하거나, 높이에 따라 여러 색상 구간을 만들 수 있다. 이때 기준이 되는 값이 임계값이다.

임계값은 연속값을 조건에 따라 이산적인 상태로 바꾼다. 결과를 0과 1로 만들면 마스크로 사용할 수 있고, 여러 임계값을 사용하면 값의 범위를 여러 단계로 나눌 수 있다.

## 하나의 임계값으로 두 영역 나누기

값 $x$가 임계값 $e$보다 작은지 큰지에 따라 결과를 나누는 가장 단순한 함수는 단계 함수다.

$$
H(x-e)=
\begin{cases}
0, & x<e \\
1, & x\ge e
\end{cases}
$$

셰이딩 언어에서는 흔히 `step(edge, x)` 형태로 제공한다.

```glsl
float mask = step(threshold, value);
```

`value`가 `threshold`보다 작으면 0, 크거나 같으면 1이 된다. 결과를 뒤집고 싶다면 1에서 뺀다.

```glsl
float inverseMask = 1.0 - step(threshold, value);
```

함수의 인자 순서는 언어나 라이브러리에 따라 다를 수 있으므로 확인해야 한다. 의사코드에서는 조건을 직접 쓰면 의미가 더 분명하다.

```text
mask = 1 if value >= threshold else 0
```

## 거리값에서 도형 만들기

중심에서 현재 좌표까지의 거리 $d$를 반지름 $r$과 비교하면 원의 안과 밖을 구분할 수 있다.

$$
M(d)=
\begin{cases}
1, & d<r \\
0, & d\ge r
\end{cases}
$$

```glsl
float d = length(position - center);
float circleMask = 1.0 - step(radius, d);
```

마스크를 색에 곱하면 원 안에서만 색이 보인다.

```glsl
vec3 color = baseColor * circleMask;
```

이 계산에서는 원을 그리는 별도의 명령이 없다. 거리값을 임계값으로 나눈 결과가 도형이 된다. 사각형이나 선분의 거리 함수에도 같은 방식을 적용할 수 있다.

## 마스크란 무엇인가

마스크는 어떤 계산이나 색이 적용될 영역을 나타내는 값이다. 이진 마스크는 보통 0과 1만 사용한다. 0은 적용하지 않음, 1은 완전히 적용함을 뜻한다. 0과 1 사이의 값까지 허용하면 부분적인 적용과 부드러운 경계를 표현할 수 있다.

```text
output = foreground * mask + background * (1 - mask)
```

이 식은 마스크가 1이면 전경을, 0이면 배경을 선택한다. 중간값에서는 두 값을 섞는다. 선형 보간으로 쓰면 같은 의미다.

$$
\operatorname{mix}(B,F,M)=(1-M)B+MF
$$

GLSL에서는 `mix(background, foreground, mask)` 형태를 사용할 수 있다.

```glsl
vec3 color = mix(backgroundColor, foregroundColor, mask);
```

마스크는 색뿐 아니라 변위, 거칠기, 속도, 힘, 노이즈의 영향력 등 거의 모든 값에 적용할 수 있다.

## 마스크 결합하기

마스크를 값으로 다루면 여러 영역을 수학적으로 결합할 수 있다. 두 이진 마스크 $A$와 $B$가 있을 때 다음 연산은 논리 연산과 비슷하게 작동한다.

| 목적 | 수식의 예 | 의미 |
| --- | --- | --- |
| 합집합 | $\max(A,B)$ | 둘 중 하나라도 포함 |
| 교집합 | $\min(A,B)$ 또는 $AB$ | 둘 다 포함 |
| 차집합 | $A(1-B)$ | A에는 있고 B에는 없음 |
| 반전 | $1-A$ | 안과 밖 교환 |

```glsl
float unionMask = max(maskA, maskB);
float intersectionMask = min(maskA, maskB);
float differenceMask = maskA * (1.0 - maskB);
```

부드러운 마스크에서는 `min`, `max`, 곱셈의 결과가 서로 다르게 보일 수 있다. 곱셈은 중간값을 더 작게 만들고, `min`은 둘 중 약한 값을 선택한다. 어떤 결합이 적합한지는 원하는 경계와 혼합 방식에 따라 달라진다.

## 구간 마스크 만들기

값이 두 경계 $a$와 $b$ 사이에 있을 때만 1이 되는 마스크를 만들 수 있다.

```glsl
float lower = step(a, value);
float upper = 1.0 - step(b, value);
float band = lower * upper;
```

수학적으로는 다음 조건을 표현한다.

$$
a\le x<b
$$

거리값에 구간 마스크를 적용하면 채워진 원 대신 고리를 만들 수 있다.

```glsl
float inner = step(innerRadius, distanceValue);
float outer = 1.0 - step(outerRadius, distanceValue);
float ring = inner * outer;
```

구간의 어느 끝을 포함할지는 함수의 정의와 비교 연산에 따라 달라질 수 있다. 연속적인 그래픽 값에서는 한 점의 포함 여부가 잘 보이지 않지만 정수 데이터나 배열 인덱스에서는 중요하다.

## 부드러운 임계값

`step`은 임계값에서 0과 1이 갑자기 바뀐다. 픽셀 격자에서는 가장자리가 계단처럼 보이거나 애니메이션 중에 깜박일 수 있다. `smoothstep`을 사용하면 두 경계 사이에 전환 구간을 만들 수 있다.

```glsl
float softMask = smoothstep(
    threshold - softness,
    threshold + softness,
    value
);
```

반전된 마스크는 다음과 같다.

```glsl
float softInverseMask = 1.0 - smoothstep(
    threshold - softness,
    threshold + softness,
    value
);
```

`softness`가 0에 가까우면 단단한 경계에 가까워지고, 커질수록 넓은 구간에서 서서히 변한다. 이는 임계값 자체를 바꾸는 것이 아니라 경계 주변을 어떻게 해석할지 정하는 값이다.

## 여러 단계로 나누기

0에서 1 사이의 연속값을 일정한 개수의 단계로 나누려면 양자화를 사용할 수 있다. 단계 수를 $N$이라고 하면 다음과 같이 만들 수 있다.

$$
q=\frac{\lfloor tN\rfloor}{N}
$$

```text
t = clamp(normalizedValue, 0, 1)
quantized = floor(t * levelCount) / levelCount
```

$t=1$일 때 단계 인덱스가 범위를 벗어날 수 있으므로 용도에 따라 별도로 처리한다. 양 끝을 포함하는 $N$개의 값이 필요하다면 다음 식을 사용할 수 있다.

$$
q=\frac{\operatorname{round}(t(N-1))}{N-1}
$$

첫 번째 식은 $[0,1)$을 같은 폭의 구간으로 나누는 데 적합하고, 두 번째 식은 0과 1을 포함하는 정해진 레벨로 반올림하는 데 적합하다.

## 단계 수와 시각적 결과

단계가 두 개면 흑백 마스크처럼 보이고, 단계 수가 적으면 포스터라이즈 효과가 나타난다. 단계 수가 많아지면 연속적인 그라데이션에 가까워진다.

| 단계 수 | 결과의 성격 |
| --- | --- |
| 2 | 이진 구분, 강한 대비 |
| 3에서 8 | 명확한 층과 리듬 |
| 수십 단계 | 미세한 밴드 |
| 매우 많음 | 연속 변화에 가까움 |

단계 경계는 값의 분포를 드러내기도 한다. 높이장을 몇 개의 구간으로 나누면 등고선과 비슷한 구조가 나타나고, 노이즈를 단계화하면 얼룩이나 지형 구획 같은 패턴이 만들어진다.

## 균등하지 않은 임계값

항상 같은 폭으로 범위를 나눌 필요는 없다. 여러 임계값을 직접 지정하면 중요한 구간을 더 세밀하게 나눌 수 있다.

```text
if value < threshold0:
    level = 0
else if value < threshold1:
    level = 1
else if value < threshold2:
    level = 2
else:
    level = 3
```

데이터의 분위수로 임계값을 정하면 각 단계에 비슷한 수의 표본이 들어가게 할 수 있다. 반면 의미 있는 물리 기준이나 설계 기준으로 임계값을 정하면 단계마다 데이터 수는 달라도 해석이 일정해진다.

## 팔레트 인덱스로 연결하기

단계 번호를 색상 팔레트의 인덱스로 사용할 수 있다.

```text
t = clamp(normalize(value, minimum, maximum), 0, 1)
index = min(floor(t * paletteSize), paletteSize - 1)
color = palette[index]
```

이 방식은 연속적인 그라데이션 대신 명확한 색상 구간을 만든다. 팔레트의 색 순서는 값의 순서를 전달할 수도 있고, 범주를 구분할 수도 있다. 연속량을 표현할 때는 밝기나 채도가 대체로 한 방향으로 변하는 순차 팔레트가 읽기 쉽다.

## 디더링으로 단계 경계 완화하기

색상 단계 수가 제한되면 넓은 그라데이션에서 띠 모양의 밴딩이 보일 수 있다. 값에 아주 작은 패턴이나 노이즈를 더한 뒤 양자화하면 공간적으로 서로 다른 단계가 섞여 중간 밝기처럼 보이게 할 수 있다. 이를 디더링이라고 한다.

```text
dithered = normalizedValue + smallPattern(position)
quantized = quantize(dithered, levelCount)
```

디더링은 사용 가능한 단계 수를 늘리지 않는다. 대신 단계 선택을 공간적으로 분산해 경계를 덜 두드러지게 만든다. 노이즈의 세기와 분포가 너무 크면 원래 이미지의 질감을 해칠 수 있으므로 출력 단계 폭에 맞춰 조절해야 한다.

## 시간에 따라 변하는 임계값

임계값 자체를 시간이나 사용자 입력으로 바꾸면 영역이 나타나고 사라지는 애니메이션을 만들 수 있다.

```text
threshold = interpolate(minThreshold, maxThreshold, progress)
mask = value >= threshold
```

노이즈장에 움직이는 임계값을 적용하면 얼룩이 자라거나 줄어드는 것처럼 보인다. 거리장에 적용하면 도형이 안쪽에서 바깥쪽으로 드러난다. 경계가 떨리는 경우 부드러운 임계값이나 시간 필터링을 사용할 수 있다.

## 이 절의 핵심

임계값은 연속값을 두 상태 또는 여러 단계로 나눈다. 0과 1로 만든 결과는 마스크가 되어 색, 투명도, 변위 등 다른 계산이 적용될 영역을 제어한다. 마스크는 합집합, 교집합, 차집합, 반전으로 조합할 수 있다.

단단한 임계값은 선명한 경계를 만들고, `smoothstep`은 전환 폭을 가진 부드러운 경계를 만든다. 양자화는 값을 여러 단계로 나누며, 팔레트 선택과 포스터라이즈 표현에 사용할 수 있다. 다음 절에서는 같은 입력값을 색, 위치, 크기, 회전 같은 여러 출력 속성에 연결해 하나의 시각 시스템을 구성한다.
