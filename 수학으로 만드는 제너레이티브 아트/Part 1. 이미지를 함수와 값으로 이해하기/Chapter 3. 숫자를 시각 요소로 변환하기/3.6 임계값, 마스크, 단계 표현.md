# 3.6 임계값, 마스크, 단계 표현

연속값은 그라데이션과 부드러운 움직임을 만들지만, 영역을 분명하게 나눠야 할 때도 있다. 거리값으로 원의 안팎을 구분하거나 일정 밝기 이상의 픽셀을 선택하고, 높이에 따라 색상 구간을 나눌 수 있다. 이때 경계의 기준이 되는 값이 임계값이다.

임계값은 연속값을 조건에 따라 이산 상태로 바꾼다. 결과가 0 또는 1이면 마스크로 쓸 수 있고, 임계값을 여럿 두면 값을 여러 단계로 나눌 수 있다.

## 하나의 임계값으로 두 영역 나누기

값 $x$를 임계값 $e$와 비교해 두 영역으로 나누는 가장 간단한 함수가 단계 함수다.

$$
H(x-e)=
\begin{cases}
0, & x<e \\
1, & x\ge e
\end{cases}
$$

셰이딩 언어에서는 흔히 `step(edge, x)` 형태로 제공한다.

```glsl
float mask = step(threshold, value);
```

`value`가 `threshold`보다 작으면 0이고, 크거나 같으면 1이다. 결과를 반전하려면 1에서 뺀다.

```glsl
float inverseMask = 1.0 - step(threshold, value);
```

인자 순서는 언어나 라이브러리에 따라 다를 수 있으므로 확인한다. 의사코드에서는 조건을 직접 쓰면 동작이 명확하다.

```text
mask = 1 if value >= threshold else 0
```

## 거리값에서 도형 만들기

중심에서 현재 좌표까지의 거리 $d$를 반지름 $r$과 비교해 원의 안팎을 구분한다.

$$
M(d)=
\begin{cases}
1, & d<r \\
0, & d\ge r
\end{cases}
$$

```glsl
float d = length(position - center);
float circleMask = 1.0 - step(radius, d);
```

마스크를 색에 곱하면 원 안에서만 색이 출력된다.

```glsl
vec3 color = baseColor * circleMask;
```

이 계산에는 원을 그리는 별도 명령이 없다. 거리값을 임계값과 비교한 결과가 원의 형태를 만든다. 사각형이나 선분의 거리 함수에도 같은 방식을 적용할 수 있다.

## 마스크란 무엇인가

마스크는 계산이나 색을 적용할 영역을 나타낸다. 이진 마스크는 보통 0과 1을 사용하며, 0은 적용하지 않음, 1은 완전히 적용함을 뜻한다. 0과 1 사이의 값을 허용하면 부분 적용과 부드러운 경계를 표현할 수 있다.

```text
output = foreground * mask + background * (1 - mask)
```

이 식에서 마스크가 1이면 전경, 0이면 배경이 선택되고, 중간값에서는 두 색이 섞인다. 같은 계산을 선형 보간으로 표현할 수 있다.

$$
\operatorname{mix}(B,F,M)=(1-M)B+MF
$$

GLSL에서는 `mix(background, foreground, mask)` 형태를 사용할 수 있다.

```glsl
vec3 color = mix(backgroundColor, foregroundColor, mask);
```

마스크는 색 외에도 변위, 거칠기, 속도, 힘, 노이즈의 영향력 등 다양한 값에 적용할 수 있다.

## 마스크 결합하기

마스크를 값으로 다루면 영역을 수학적으로 결합할 수 있다. 두 이진 마스크 $A$, $B$에 다음 연산을 적용하면 논리 연산과 비슷한 결과를 얻는다.

| 목적 | 수식의 예 | 의미 |
| --- | --- | --- |
| 합집합 | $\max(A,B)$ | 둘 중 하나라도 포함 |
| 교집합 | $\min(A,B)$ 또는 $AB$ | 둘 다 포함 |
| 차집합 | $A(1-B)$ | A에는 있고 B에는 없음 |
| 반전 | $1-A$ | 안과 밖 교환 |

```glsl
float unionMask = max(maskA, maskB);
float intersectionMask = min(maskA, maskB);
float differenceMask = maskA * (1.0 - maskB);
```

부드러운 마스크에서는 `min`, `max`, 곱셈의 결과가 서로 다르다. 곱셈은 중간값을 더 낮추고 `min`은 두 값 중 작은 값을 선택한다. 원하는 경계와 혼합 방식에 맞춰 연산을 고른다.

## 구간 마스크 만들기

값이 두 경계 $a$와 $b$ 사이에 있을 때만 1인 마스크도 만들 수 있다.

```glsl
float lower = step(a, value);
float upper = 1.0 - step(b, value);
float band = lower * upper;
```

수식으로는 다음 조건에 해당한다.

$$
a\le x<b
$$

거리값에 구간 마스크를 적용하면 채워진 원이 아니라 고리가 만들어진다.

```glsl
float inner = step(innerRadius, distanceValue);
float outer = 1.0 - step(outerRadius, distanceValue);
float ring = inner * outer;
```

구간의 끝값 포함 여부는 함수 정의와 비교 연산에 달려 있다. 연속 그래픽 값에서는 한 점의 포함 여부가 눈에 띄지 않을 수 있지만 정수 데이터나 배열 인덱스에서는 중요하다.

## 부드러운 임계값

`step`은 임계값에서 0과 1을 갑자기 바꾼다. 픽셀 격자에서는 가장자리가 계단처럼 보이고 애니메이션 중에는 깜박일 수 있다. `smoothstep`은 두 경계 사이에 전환 구간을 만든다.

```glsl
float softMask = smoothstep(
    threshold - softness,
    threshold + softness,
    value
);
```

반전된 마스크는 다음과 같다.

```glsl
float softInverseMask = 1.0 - smoothstep(
    threshold - softness,
    threshold + softness,
    value
);
```

`softness`가 0에 가까우면 경계가 단단해지고, 값이 커지면 더 넓은 구간에서 서서히 전환된다. 임계값 자체가 아니라 경계 주변의 전환 폭을 정하는 값이다.

## 여러 단계로 나누기

0~1 연속값을 일정한 수의 단계로 나누는 연산을 양자화라고 한다. 단계 수가 $N$일 때 다음 식으로 계산한다.

$$
q=\frac{\lfloor tN\rfloor}{N}
$$

```text
t = clamp(normalizedValue, 0, 1)
quantized = floor(t * levelCount) / levelCount
```

$t=1$이면 단계 인덱스가 범위를 벗어날 수 있어 용도에 맞게 처리해야 한다. 0과 1을 포함한 $N$개의 값이 필요하면 다음 식을 쓴다.

$$
q=\frac{\operatorname{round}(t(N-1))}{N-1}
$$

첫 번째 식은 $[0,1)$을 같은 폭으로 나누고, 두 번째 식은 0과 1을 포함한 정해진 레벨로 반올림한다.

## 단계 수와 시각적 결과

두 단계는 흑백 마스크처럼 보이고, 단계 수가 적으면 포스터라이즈 효과가 난다. 단계가 많아질수록 연속 그라데이션에 가까워진다.

| 단계 수 | 결과의 성격 |
| --- | --- |
| 2 | 이진 구분, 강한 대비 |
| 3에서 8 | 명확한 층과 리듬 |
| 수십 단계 | 미세한 밴드 |
| 매우 많음 | 연속 변화에 가까움 |

단계 경계가 값의 분포를 드러낼 수도 있다. 높이장을 몇 구간으로 나누면 등고선 같은 구조가 생기고, 노이즈를 단계화하면 얼룩이나 지형 구획처럼 보이는 패턴을 얻는다.

## 균등하지 않은 임계값

범위를 늘 같은 폭으로 나눌 필요는 없다. 임계값을 직접 지정해 중요한 구간을 더 세밀하게 나눌 수 있다.

```text
if value < threshold0:
    level = 0
else if value < threshold1:
    level = 1
else if value < threshold2:
    level = 2
else:
    level = 3
```

데이터의 분위수로 임계값을 정하면 각 단계에 비슷한 수의 표본이 들어간다. 물리적·설계적 기준을 쓰면 단계별 표본 수는 달라도 해석 기준을 일정하게 유지한다.

## 팔레트 인덱스로 연결하기

단계 번호를 색상 팔레트의 인덱스로 연결할 수 있다.

```text
t = clamp(normalize(value, minimum, maximum), 0, 1)
index = min(floor(t * paletteSize), paletteSize - 1)
color = palette[index]
```

이 방식은 연속 그라데이션 대신 뚜렷한 색상 구간을 만든다. 팔레트의 색 순서로 값의 순서를 나타내거나 범주를 구분할 수 있다. 연속량에는 밝기나 채도가 한 방향으로 변하는 순차 팔레트가 읽기 쉽다.

## 디더링으로 단계 경계 완화하기

색상 단계가 적으면 넓은 그라데이션에서 띠 모양의 밴딩이 나타날 수 있다. 값에 작은 패턴이나 노이즈를 더한 뒤 양자화하면 서로 다른 단계가 공간적으로 섞여 중간 밝기처럼 보인다. 이를 디더링이라고 한다.

```text
dithered = normalizedValue + smallPattern(position)
quantized = quantize(dithered, levelCount)
```

디더링은 단계 수를 늘리는 대신 단계 선택을 공간적으로 분산해 경계를 덜 두드러지게 한다. 노이즈의 세기와 분포가 지나치면 이미지의 원래 질감을 해칠 수 있으므로 단계 폭에 맞춰 조절한다.

## 시간에 따라 변하는 임계값

시간이나 사용자 입력에 따라 임계값을 바꾸면 영역이 나타나고 사라지는 애니메이션을 만들 수 있다.

```text
threshold = interpolate(minThreshold, maxThreshold, progress)
mask = value >= threshold
```

노이즈장에서는 움직이는 임계값에 따라 얼룩이 자라거나 줄어드는 듯 보인다. 거리장에서는 도형이 안쪽에서 바깥쪽으로 드러난다. 경계가 떨리면 부드러운 임계값이나 시간 필터링을 적용한다.

## 이 절의 핵심

임계값은 연속값을 두 상태나 여러 단계로 나눈다. 0과 1로 구성한 마스크는 색, 투명도, 변위 등 다른 계산의 적용 영역을 제어한다. 마스크는 합집합, 교집합, 차집합, 반전으로 결합할 수 있다.

단단한 임계값은 선명한 경계를, `smoothstep`은 전환 폭이 있는 부드러운 경계를 만든다. 양자화한 단계는 팔레트 선택이나 포스터라이즈 표현에 쓸 수 있다. 다음 절에서는 하나의 입력값을 색, 위치, 크기, 회전 등 여러 출력 속성에 연결하는 방법을 다룬다.
