# 1.4 반복 가능한 규칙과 조절 가능한 파라미터

제너레이티브 아트의 규칙은 반복해서 실행할 수 있어야 하며, 필요한 부분을 조절할 수 있어야 한다. 같은 조건에서 다시 실행하면 같은 결과를 얻고, 특정 값을 바꾸면 다른 변주를 만들 수 있어야 한다.

반복 가능성은 작업을 재현하게 하고, 파라미터는 작업을 조절하고 탐색하게 한다. 두 요소를 함께 갖추면 결과를 설계하고 발전시킬 수 있는 시스템이 된다.

## 반복 가능한 규칙이란 무엇인가

반복 가능한 규칙은 같은 조건에서 같은 결과를 다시 만드는 규칙이다. 원 100개를 랜덤한 위치에 배치하는 코드를 생각해 보자. 실행할 때마다 결과가 달라지면 실험은 가능하지만 특정 이미지를 재현하기 어렵다. 같은 입력과 시드를 사용해 같은 결과를 얻으면 이미지를 보관하고 수정하거나 비교할 수 있다.

반복 가능성은 결과를 고정하는 데 그치지 않는다. 무엇을 고정하고 무엇을 바꿀 수 있는지 구분해 변화의 조건을 분명하게 한다.

| 요소 | 반복 가능한 규칙에서의 역할 |
| --- | --- |
| 입력값 | 결과를 결정하는 출발점 |
| 함수 | 입력을 변환하는 고정된 구조 |
| 파라미터 | 결과를 조절하는 값 |
| 시드 | 랜덤 결과를 재현하기 위한 기준값 |
| 출력 | 입력과 규칙에 의해 생성된 결과 |

같은 함수와 파라미터를 사용하면 같은 구조가 만들어진다. 랜덤이 포함된 경우에도 시드를 같게 설정하면 같은 결과를 얻는다. 마음에 드는 결과를 다시 불러와 조금씩 수정하려면 이 재현성이 필요하다.

## 랜덤과 재현 가능성

랜덤은 제너레이티브 아트에서 자주 쓰이지만, 실행할 때마다 결과가 달라지면 우연히 얻은 이미지를 다시 만들기 어렵다. 이를 위해 재현 가능한 랜덤 시드(random seed)를 사용한다. 시드는 난수 생성기의 시작 상태를 정하는 값으로, 같은 시드를 사용하면 같은 순서의 랜덤 값이 나온다.

**p5.js 예제**

```javascript
randomSeed(25);

for (let i = 0; i < 100; i++) {
  let x = random(width);
  let y = random(height);
  circle(x, y, 10);
}
```

이 코드는 원 100개를 랜덤한 위치에 배치한다. `randomSeed(25)`를 지정했으므로 실행할 때마다 원의 위치가 같다. 시드를 바꾸면 다른 배치를 얻고, 같은 시드를 유지하면 기존 배치를 재현한다.

시드는 작업의 버전처럼 기록할 수 있다. 예를 들어 `seed = 45`에서 마음에 드는 결과를 얻었다면 값을 남겨 둔다. 색이나 크기 규칙을 바꿀 때도 시드를 유지하면 기본 배치를 같게 둘 수 있다.

**p5.js 예제**

```javascript
let seed = 17;

function setup() {
  createCanvas(800, 800);
  randomSeed(seed);
  noLoop();
}
```

재현 가능한 랜덤을 사용하면 결과에 우연을 포함하면서도 같은 조건을 다시 불러올 수 있다.

## 파라미터는 조절 가능한 의도다

파라미터(parameter)는 규칙의 성격을 바꾸는 값이다. 원의 개수와 간격, 크기, 색상 범위, 노이즈 스케일, 회전 속도, 선의 두께, 반복 횟수 등이 파라미터가 된다.

**p5.js 예제**

```javascript
for (let i = 0; i < 50; i++) {
  circle(100 + i * 12, 300, 20);
}
```

이 코드는 원 50개를 간격 12로 배치하며 크기는 20으로 고정한다. 값을 하드코딩하는 대신 파라미터로 분리하면 규칙을 쉽게 조절할 수 있다.

**p5.js 예제**

```javascript
let count = 50;
let spacing = 12;
let diameter = 20;

for (let i = 0; i < count; i++) {
  circle(100 + i * spacing, 300, diameter);
}
```

코드 구조는 달라졌지만 결과는 같다. 이제 원의 개수와 간격, 크기를 각각 바꿀 수 있다. 숫자에 이름을 붙이는 데서 파라미터 설계가 시작되며, 이름이 붙은 값은 작업의 조절점이 된다. 파라미터가 너무 많으면 작업이 복잡해지고, 너무 적으면 변주가 제한된다. 어떤 값을 조절 가능하게 둘지도 설계의 일부다.

## 파라미터의 범위 정하기

파라미터는 값뿐 아니라 범위도 중요하다. 원의 개수나 선의 두께에는 정해진 상한이 없지만, 화면에서 의미 있는 범위는 있을 수 있다. 예를 들어 원의 개수는 20~50개, 선의 두께는 0.2~0.8 사이가 적절할 수 있다. 노이즈 스케일이 너무 작으면 값이 거의 균일해 보이고, 너무 크면 패턴이 불규칙한 잡음처럼 보인다. 범위를 정할 때는 다음을 살펴본다.

- 이 값은 어떤 시각적 성격을 바꾸는가?
- 너무 작을 때와 너무 클 때 어떤 문제가 생기는가?
- 선형적으로 바꾸는 것이 자연스러운가, 지수적으로 바꾸는 것이 자연스러운가?
- 다른 파라미터와 함께 변해야 하는가?
- 사용자가 직접 조절할 값인가, 내부 계산용 값인가?

**p5.js 예제**

```javascript
let noiseScale = 0.01;

for (let y = 0; y < height; y += 10) {
  for (let x = 0; x < width; x += 10) {
    let v = noise(x * noiseScale, y * noiseScale);
    let diameter = map(v, 0, 1, 2, 12);
    circle(x, y, diameter);
  }
}
```

`noiseScale`은 패턴의 공간적 크기를 결정한다. 값을 `0.005`로 낮추면 변화가 넓고 부드러워지고, `0.05`로 높이면 더 세밀하고 불규칙해진다. 같은 규칙도 파라미터에 따라 전체 인상이 달라진다.

## 하드코딩된 숫자를 의미 있는 이름으로 바꾸기

작업 코드에는 숫자가 직접 들어가는 경우가 많다. 이런 값을 하드코딩된 숫자라고 부른다. 빠른 실험에는 편리하지만, 코드가 커지면 수정하기 어려워진다.

**p5.js 예제**

```javascript
circle(100 + i * 18, 300, 24);
```

이 코드의 `100`, `18`, `300`, `24`가 각각 무엇을 뜻하는지 작성 직후에는 알 수 있어도 시간이 지나면 기억하기 어렵다. 값에 이름을 붙이면 역할이 드러난다.

**p5.js 예제**

```javascript
let startX = 100;
let centerY = 300;
let spacing = 18;
let diameter = 24;

circle(startX + i * spacing, centerY, diameter);
```

이름이 붙은 값은 조절 가능한 파라미터가 된다. `spacing`을 바꾸면 밀도가 달라지고, `diameter`를 바꾸면 형태의 무게가 달라진다. 파라미터를 통해 작가의 의도를 코드에 드러낼 수 있다.

## 파라미터 사이의 관계

파라미터는 서로 독립적일 수도 있고 연결될 수도 있다. 원의 개수가 늘면 화면에 들어오도록 간격을 줄여야 할 수 있다. 선이 두꺼워지면 격자 간격도 넓혀야 할 수 있다. 애니메이션 속도가 빨라질 때 잔상의 길이를 함께 조절하면 자연스러운 결과를 얻을 수 있다. 좋은 파라미터 설계는 값 사이의 관계를 유지한다.

격자에서는 셀 크기를 정한 뒤 그에 맞춰 원의 최대 반지름을 정할 수 있다.

**p5.js 예제**

```javascript
let cellSize = 40;
let maxRadius = cellSize * 0.45;

for (let y = 0; y < height; y += cellSize) {
  for (let x = 0; x < width; x += cellSize) {
    let r = random(maxRadius * 0.2, maxRadius);
    circle(x + cellSize / 2, y + cellSize / 2, r * 2);
  }
}
```

`maxRadius`는 `cellSize`에 따라 결정된다. 셀 크기를 바꾸면 원의 최대 크기도 함께 바뀌어 패턴의 비율이 유지된다.

## 탐색 가능한 시스템 만들기

파라미터를 바꾸면 하나의 규칙에서 여러 결과를 살펴볼 수 있고, 예상하지 못한 조합도 발견할 수 있다. 제너레이티브 아트 작업은 완성 이미지를 향해 직선으로 진행되기보다 파라미터 공간을 탐색하며 방향을 찾는 경우가 많다.

파라미터 공간은 가능한 파라미터 조합의 집합이다. `count`, `spacing`, `noiseScale`, `seed` 네 값의 조합마다 다른 이미지가 만들어진다. 작가는 이 공간을 탐색하며 작업의 방향을 찾는다.

제너레이티브 아트 작업은 흔히 다음 실험 사이클을 따른다. 시드를 정하고, 파라미터 값을 입력한 뒤, 이미지를 생성해 평가한다. 평가 결과에 따라 파라미터를 조절하고 다시 생성한다. 코드는 한 번 작성하고 끝나는 것이 아니라 파라미터를 조절하며 다듬어진다. 코드 구조가 좋으면 이 실험을 빠르게 진행할 수 있다.

## 이 절의 핵심

반복 가능한 규칙은 같은 조건에서 같은 결과를 만든다. 랜덤을 사용해도 시드를 설정하면 결과를 재현할 수 있어, 우연을 포함한 작업을 다시 불러올 수 있다.

파라미터는 규칙의 성격을 조절한다. 원의 개수와 간격, 크기, 노이즈 스케일, 색 범위, 시간 속도는 이미지의 인상을 바꾼다. 적절한 파라미터는 작업을 이해하기 쉽게 하고 변주와 탐색을 가능하게 한다.

다음 절에서는 객체, 입력, 함수, 출력, 도형 함수, 파라미터를 실제 작업 흐름에서 어떻게 사용하는지 정리한다. 제너레이티브 아트에서는 아이디어를 규칙으로 바꾸고 코드로 구현한 뒤, 결과를 관찰하고 다시 조절한다.
