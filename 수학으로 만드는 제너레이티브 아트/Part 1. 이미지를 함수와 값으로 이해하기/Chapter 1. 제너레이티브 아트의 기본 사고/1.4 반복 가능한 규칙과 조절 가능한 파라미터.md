# 1.4 반복 가능한 규칙과 조절 가능한 파라미터

제너레이티브 아트에서 좋은 규칙은 반복해서 실행할 수 있어야 하고, 필요한 부분을 조절할 수 있어야 한다. 규칙을 그대로 다시 실행했을 때 같은 결과를 얻을 수도 있어야 하고, 특정 값을 바꾸어 다른 변주를 만들 수도 있어야 한다.

이 절에서는 반복 가능성과 파라미터라는 두 가지 개념을 다룬다. 반복 가능성은 작업을 다시 만들 수 있게 해 준다. 파라미터는 작업을 조절하고 탐색할 수 있게 해 준다. 이 두 개념을 함께 사용해야 아트워크는 우연한 결과가 아니라 설계 가능한 시스템이 된다.

## 반복 가능한 규칙이란 무엇인가

반복 가능한 규칙은 같은 조건에서 같은 결과를 다시 만들 수 있는 규칙이다. 예를 들어 원 100개를 랜덤한 위치에 배치하는 코드를 작성했다고 하자. 실행할 때마다 전혀 다른 결과가 나온다면 흥미로운 실험은 될 수 있지만, 특정 결과를 다시 재현하기 어렵다. 하지만 같은 입력과 같은 시드를 사용했을 때 같은 결과가 나온다면, 우리는 그 이미지를 보관하고 수정하고 비교할 수 있다.

반복 가능성은 단순히 결과를 고정하는 것이 아니라 오히려 변화의 조건을 명확히 하는 일에 가깝다. 무엇이 고정되어 있고, 무엇이 바뀔 수 있는지 구분하는 것이다.

| 요소 | 반복 가능한 규칙에서의 역할 |
| --- | --- |
| 입력값 | 결과를 결정하는 출발점 |
| 함수 | 입력을 변환하는 고정된 구조 |
| 파라미터 | 결과를 조절하는 값 |
| 시드 | 랜덤 결과를 재현하기 위한 기준값 |
| 출력 | 입력과 규칙에 의해 생성된 결과 |

같은 함수와 같은 파라미터를 사용하면 같은 구조가 만들어진다. 여기에 같은 시드를 사용하면 랜덤이 포함되어 있어도 같은 결과를 다시 얻을 수 있는데 이 점은 제너레이티브 아트에서 매우 중요하다. 작업을 발전시키려면 마음에 드는 결과를 다시 불러오고, 그 상태에서 조금씩 수정할 수 있어야 하기 때문이다.

## 랜덤과 재현 가능성

랜덤은 제너레이티브 아트에서 자주 쓰이지만 무작정 사용하면 결과를 통제하기 어렵다. 실행할 때마다 완전히 다른 이미지가 나온다면 우연히 좋은 결과를 얻어도 다시 만들 수 없으므로 재현할 수 있는 랜덤 시드(random seed)라는 개념을 사용해야 한다. 많은 그래픽 환경에서는 랜덤 시드를 설정할 수 있는데 여기서 시드는 난수 생성기의 시작 상태를 정하는 값이다. 같은 시드를 사용하면 같은 순서의 랜덤 값이 나온다.

**p5.js 예제**

```javascript
randomSeed(25);

for (let i = 0; i < 100; i++) {
  let x = random(width);
  let y = random(height);
  circle(x, y, 10);
}
```

이 코드는 랜덤 위치에 원을 100개 배치한다. 하지만 `randomSeed(25)`를 사용했기 때문에 매번 같은 위치가 나온다. 시드를 바꾸면 다른 배치가 만들어지고, 시드를 유지하면 같은 배치를 다시 얻을 수 있다.

시드는 작업의 버전처럼 사용할 수 있다. 예를 들어 `seed = 45`의 결과가 마음에 들면 그 값을 기록해 둔다. 나중에 색이나 크기 규칙을 바꾸더라도 같은 시드를 사용하면 기본 배치 구조는 유지할 수 있다.

**p5.js 예제**

```javascript
let seed = 17;

function setup() {
  createCanvas(800, 800);
  randomSeed(seed);
  noLoop();
}
```

이처럼 재현 가능한 랜덤은 우연과 제어 사이의 균형을 만든다. 결과는 랜덤에서 나오지만 그 랜덤을 다시 호출할 수 있는 것이다.

## 파라미터는 조절 가능한 의도다

파라미터(parameter)는 규칙의 성격을 바꾸는 값이다. 원의 개수, 간격, 크기, 색상 범위, 노이즈 스케일, 회전 속도, 선의 두께, 반복 횟수 등이 모두 파라미터가 될 수 있다.

**p5.js 예제**

```javascript
for (let i = 0; i < 50; i++) {
  circle(100 + i * 12, 300, 20);
}
```

이 코드에서는 원 50개를 간격 12로 배치하고, 크기는 20으로 고정하고 있다. 이렇게 값을 하드코딩하여 쓰는 대신 파라미터로 분리하면 규칙을 더 쉽게 조절할 수 있다.

**p5.js 예제**

```javascript
let count = 50;
let spacing = 12;
let diameter = 20;

for (let i = 0; i < count; i++) {
  circle(100 + i * spacing, 300, diameter);
}
```

코드의 구조는 다르지만 결과는 같다. 이제 원의 개수와 간격과 크기를 쉽게 바꿀 수 있다. 파라미터는 코드 안의 숫자에 이름을 붙이는 일에서 시작하며 이렇게 이름이 붙은 값은 아트워크의 조절점이 된다. 너무 많은 값을 파라미터로 만들면 작업이 복잡해지고, 너무 적으면 변주가 어렵다. 따라서 어떤 값을 파라미터로 열어 둘지 선택하는 일도 설계의 일부다.

## 파라미터의 범위 정하기

파라미터는 값 자체만큼 범위가 중요하다. 예를 들어 원의 개수나 선의 두께의 상한선은 딱히 없지만 시각적으로 의미 있는 범위는 20에서 50개 사이, 0.2에서 0.8이 적절할 수 있다. 노이즈 스케일의 경우도 너무 작으면 거의 균일한 값처럼 보이고, 너무 크면 불규칙한 잡음처럼 보인다. 파라미터를 설계할 때는 아래와 같은 질문을 통해 값의 범위를 찾는 것이 중요하다.

- 이 값은 어떤 시각적 성격을 바꾸는가?
- 너무 작을 때와 너무 클 때 어떤 문제가 생기는가?
- 선형적으로 바꾸는 것이 자연스러운가, 지수적으로 바꾸는 것이 자연스러운가?
- 다른 파라미터와 함께 변해야 하는가?
- 사용자가 직접 조절할 값인가, 내부 계산용 값인가?

**p5.js 예제**

```javascript
let noiseScale = 0.01;

for (let y = 0; y < height; y += 10) {
  for (let x = 0; x < width; x += 10) {
    let v = noise(x * noiseScale, y * noiseScale);
    let diameter = map(v, 0, 1, 2, 12);
    circle(x, y, diameter);
  }
}
```

이 코드에서 `noiseScale`은 패턴의 공간적 크기를 결정한다. `0.005`로 바꾸면 변화가 더 넓고 부드러워지고, `0.05`로 바꾸면 더 세밀하고 불규칙해진다. 같은 규칙이라도 파라미터 하나가 전체 인상을 바꾼다.

## 하드코딩된 숫자를 의미 있는 이름으로 바꾸기

제너레이티브 작업을 할 때 코드 곳곳에 숫자가 직접 들어가는 경우가 많다. 이를 하드코딩된 숫자라고 부른다. 하드코딩은 빠른 실험에는 편리하지만, 작업이 커질수록 수정하기 어려워진다.

**p5.js 예제**

```javascript
circle(100 + i * 18, 300, 24);
```

이 예시 코드에서 `100`, `18`, `300`, `24`는 각각 무엇을 의미할까? 코드를 작성한 직후에는 알 수 있지만 시간이 지나서 다시 보면 정확한 의미가 생각이 나지 않을 수 있다. 그래서 다음처럼 이름을 붙이면 구조가 훨씬 분명해진다.

**p5.js 예제**

```javascript
let startX = 100;
let centerY = 300;
let spacing = 18;
let diameter = 24;

circle(startX + i * spacing, centerY, diameter);
```

이렇게 이름이 붙은 값은 조절 가능한 파라미터가 된다. `spacing`을 바꾸면 밀도가 바뀌고, `diameter`를 바꾸면 형태의 무게가 달라진다. 이제 작가가 의도하는 바는 파라미터라는 장치를 통해 코드 안에서도 표현이 된다.

## 파라미터 사이의 관계

파라미터는 서로 독립적일 수도 있지만, 서로 연결될 수도 있다. 예를 들어 원의 개수가 많아지면 간격이 줄어들어야 화면 안에 들어올 수 있다. 선의 두께가 커지면 격자 간격도 함께 커져야 할 수 있다. 애니메이션 속도가 빨라지면 잔상의 길이도 조절해야 자연스럽게 보일 수 있다. 좋은 파라미터 설계는 값들이 일정한 관계를 유지하도록 만든다.

예를 들어 격자의 셀 크기를 먼저 정하고, 그에 따라 원의 최대 반지름을 정할 수 있다.

**p5.js 예제**

```javascript
let cellSize = 40;
let maxRadius = cellSize * 0.45;

for (let y = 0; y < height; y += cellSize) {
  for (let x = 0; x < width; x += cellSize) {
    let r = random(maxRadius * 0.2, maxRadius);
    circle(x + cellSize / 2, y + cellSize / 2, r * 2);
  }
}
```

여기서 `maxRadius`는 `cellSize`에 의해 결정된다. 셀 크기를 바꾸면 원의 최대 크기도 함께 바뀐다. 이렇게 하면 패턴의 비율이 유지된다.

## 탐색 가능한 시스템 만들기

파라미터는 작업을 탐색 가능하게 만든다. 하나의 규칙을 만든 뒤 파라미터를 바꾸어 여러 결과를 살펴볼 수 있다. 이 과정에서 예상하지 못한 조합을 발견하기도 한다. 제너레이티브 아트에서 작업은 종종 완성 이미지를 향해 곧장 가는 것이 아니라, 파라미터 공간을 탐색하는 방식으로 진행된다.

파라미터 공간이란 가능한 파라미터 조합들의 집합이다. 예를 들어 `count`, `spacing`, `noiseScale`, `seed` 네 개의 값이 있다면, 이 값들의 조합마다 다른 이미지가 만들어진다. 작가는 이 공간을 탐색하며 작업의 방향을 찾는다.

제너레이티브 아트의 작업 과정은 흔히 1) 시드를 선정, 2) 파라미터 값 입력, 3) 이미지 생성 후 결과 평가, 4) 파라미터 조절 후 재생성이라는 실험 사이클을 기반으로 한다.  코드는 한 번 작성하고 끝나는 것이 아니라, 파라미터를 통해 계속 다듬어진다. 이때 좋은 구조는 실험을 빠르게 만든다. 

## 이 절의 핵심

반복 가능한 규칙은 같은 조건에서 같은 결과를 다시 만들 수 있는 규칙이다. 랜덤을 사용하더라도 시드를 설정하면 결과를 재현할 수 있다. 이는 우연을 작업 안에 포함하면서도, 그 우연을 다시 호출할 수 있게 해 준다.

파라미터는 규칙의 성격을 조절하는 값이다. 원의 개수, 간격, 크기, 노이즈 스케일, 색 범위, 시간 속도 같은 값은 이미지의 중요한 성격을 바꾼다. 좋은 파라미터는 작업을 이해하기 쉽게 만들고, 변주와 탐색을 가능하게 한다.

다음 절에서는 지금까지 다룬 객체, 입력, 함수, 출력, 도형 함수, 파라미터를 실제 작업 흐름 안에서 어떻게 사용하는지 정리한다. 제너레이티브 아트의 기본 작업은 아이디어를 규칙으로 바꾸고, 규칙을 코드로 구현하고, 결과를 관찰하며 다시 조절하는 과정으로 이루어진다.
