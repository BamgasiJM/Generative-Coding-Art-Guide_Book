# 1.5 제너레이티브 아트의 기본 작업 흐름

지금까지 제너레이티브 아트의 기본 관점을 살펴보았다. 그래픽 객체를 직접 배치하는 방식과 규칙으로 생성하는 방식의 차이를 보았고, 이미지를 입력, 함수, 출력의 관계로 이해했다. 도형을 함수로 정의하는 방법도 살펴보았으며, 반복 가능한 규칙과 조절 가능한 파라미터가 왜 중요한지도 다루었다.

이번 절에서는 이 개념들을 하나의 작업 흐름으로 묶는다. 제너레이티브 아트는 대개 한 번에 완성되지 않는다. 아이디어를 정하고, 규칙으로 바꾸고, 파라미터를 정하고, 코드를 작성하고, 결과를 관찰하고, 다시 수정하는 과정을 거친다. 이 반복적인 흐름을 이해하면 낯선 이미지나 복잡한 시스템도 차근차근 설계할 수 있다.

## 1단계: 시각적 아이디어를 정한다

작업은 보통 시각적 아이디어에서 시작한다. 만들고 싶은 이미지가 아주 구체적일 수도 있고, 막연한 느낌일 수도 있다. 예를 들어 다음과 같은 출발점이 있을 수 있다.

- 중심에서 바깥으로 퍼지는 원형 패턴
- 바람에 흔들리는 선들의 흐름
- 격자 안에서 조금씩 변형되는 도형
- 물결처럼 움직이는 밝기 패턴
- 유기적인 질감을 가진 표면
- 입자들이 보이지 않는 힘을 따라 움직이는 장면

이 단계에서 중요한 것은 완성된 이미지를 완벽하게 상상하는 것이 아니다. 오히려 어떤 관계가 흥미로운지 찾는 것이 중요하다. 중심과 거리의 관계인지, 반복과 변주의 관계인지, 시간과 움직임의 관계인지, 랜덤과 질서의 관계인지 생각해 본다.

시각적 아이디어를 규칙으로 바꾸기 위해 다음 질문을 던질 수 있다.

- 무엇이 반복되는가?
- 무엇이 변하는가?
- 변화는 무엇을 기준으로 일어나는가?
- 중심, 방향, 거리, 시간 같은 기준이 있는가?
- 결과를 조절할 수 있는 주요 값은 무엇인가?

예를 들어 “중심에서 바깥으로 퍼지는 원형 패턴”이라는 아이디어가 있다면, 핵심 기준은 중심점과 거리다. “바람에 흔들리는 선들의 흐름”이라면 방향장, 시간, 노이즈가 중요해질 수 있다. “격자 안에서 변형되는 도형”이라면 셀 인덱스, 반복 좌표, 랜덤 값이 핵심 입력이 된다.

## 2단계: 입력을 정한다

아이디어를 정했다면 다음은 입력을 정하는 일이다. 입력은 이미지가 의존하는 값이다. 제너레이티브 아트에서 가장 흔한 입력은 좌표다. 좌표는 화면 위의 위치를 나타내며, 거의 모든 그래픽 계산의 출발점이 된다.

하지만 좌표만 입력이 되는 것은 아니다. 시간, 반복 인덱스, 마우스 위치, 랜덤 시드, 노이즈 값, 외부 데이터도 입력이 될 수 있다. 어떤 입력을 선택하느냐에 따라 작업의 성격이 달라진다.

| 만들고 싶은 효과 | 적합한 입력 |
| --- | --- |
| 화면 위치에 따라 달라지는 패턴 | 좌표 |
| 반복되는 도형 배열 | 반복 인덱스, 셀 좌표 |
| 움직이는 패턴 | 시간 |
| 사용자 반응 | 마우스, 키보드, 센서 |
| 불규칙한 배치 | 랜덤 값, 시드 |
| 자연스러운 변화 | 노이즈 값 |
| 데이터 기반 이미지 | 외부 데이터 |

입력을 정할 때는 “무엇이 결과를 결정하는가?”라고 물어보면 좋다. 원의 위치가 격자에 의해 결정된다면 격자 좌표가 입력이다. 색이 중심에서의 거리로 결정된다면 거리값이 입력이다. 움직임이 시간에 따라 달라진다면 시간값이 입력이다.

입력을 명확히 정하면 이후의 함수 설계가 쉬워진다. 무엇을 계산해야 하는지, 어떤 값을 연결해야 하는지가 보이기 때문이다.

## 3단계: 규칙과 함수를 만든다

입력을 정했다면 이제 입력을 출력으로 바꾸는 규칙을 만든다. 이 규칙은 수식일 수도 있고, 조건문일 수도 있고, 반복문일 수도 있으며, 여러 함수의 조합일 수도 있다.

예를 들어 중심에서의 거리에 따라 원의 크기를 바꾸고 싶다면 다음과 같은 규칙을 생각할 수 있다.

```text
distance = distance(position, center)
size = map(distance, 0, maxDistance, largeSize, smallSize)
```

이 규칙은 중심에 가까울수록 큰 도형을 만들고, 멀어질수록 작은 도형을 만든다. 여기에 노이즈를 더하면 규칙적인 변화에 불규칙성을 넣을 수 있다.

```text
noiseValue = noise(position * noiseScale)
size = baseSize + noiseValue * variation
```

규칙을 만들 때는 처음부터 복잡하게 만들 필요가 없다. 단순한 규칙 하나를 만든 뒤, 결과를 보고 필요한 요소를 더하는 편이 좋다. 예를 들어 먼저 격자만 만든다. 그다음 각 셀의 크기를 바꾼다. 그다음 색을 바꾼다. 그다음 시간값을 넣어 움직인다. 이렇게 단계적으로 확장하면 어떤 규칙이 어떤 결과를 만드는지 이해하기 쉽다.

## 4단계: 출력을 시각 요소에 연결한다

함수의 결과는 숫자다. 이 숫자를 이미지로 만들려면 시각 요소에 연결해야 한다. 출력값은 위치, 크기, 색, 회전, 투명도, 선 두께, 속도, 밀도 등으로 연결될 수 있다.

같은 출력값이라도 어디에 연결하느냐에 따라 결과가 달라진다. 거리값을 밝기에 연결하면 그라데이션이 되고, 크기에 연결하면 중심에서 멀어질수록 도형의 크기가 변한다. 노이즈 값을 색에 연결하면 질감이 되고, 좌표에 연결하면 형태가 일그러진다.

```text
v = noise(x * noiseScale, y * noiseScale)

radius = remap(v, 0, 1, 4, 20)
gray = remap(v, 0, 1, 40, 220)
angle = remap(v, 0, 1, 0, 2 * PI)
```

여기서 `v`는 하나의 노이즈 값이다. 이 값은 반지름, 밝기, 각도로 모두 사용할 수 있다. 어떤 연결을 선택하느냐가 이미지의 성격을 결정한다.

출력을 연결할 때는 값의 범위를 확인해야 한다. 어떤 함수는 0에서 1 사이의 값을 반환하고, 어떤 함수는 음수와 양수를 모두 반환한다. 색은 보통 0에서 255 사이의 값이 필요하고, 회전각은 0에서 2π 사이의 값이 편리하다. 따라서 재매핑, 제한, 보간 같은 값 처리 과정이 자주 필요하다. 이 내용은 Chapter 3에서 자세히 다룬다.

## 5단계: 파라미터를 분리한다

작업이 어느 정도 보이기 시작하면 주요 값을 파라미터로 분리한다. 처음에는 코드 안에 직접 숫자를 넣어 실험해도 괜찮다. 하지만 작업을 계속 발전시키려면 조절해야 할 값에 이름을 붙여야 한다.

```text
count = 30
cellSize = 24
noiseScale = 0.02
minRadius = 3
maxRadius = 18
seed = 12
```

이런 값들은 작업의 조절 장치가 된다. `count`는 밀도를 바꾸고, `cellSize`는 구조의 크기를 바꾸며, `noiseScale`은 변화의 질감을 바꾼다. `seed`는 랜덤 배치를 다시 만들 수 있게 해 준다.

파라미터를 분리하면 여러 버전을 쉽게 비교할 수 있다. 예를 들어 같은 규칙에서 `noiseScale`만 바꾸어 결과를 비교하거나, 같은 색 체계를 유지한 채 `seed`만 바꾸어 다른 구성을 만들 수 있다.

좋은 파라미터 설계는 작업을 다루기 쉽게 만든다. 어떤 값을 바꾸면 어떤 시각적 변화가 생기는지 예측할 수 있기 때문이다.

## 6단계: 결과를 관찰하고 수정한다

제너레이티브 아트에서 결과 관찰은 단순한 확인이 아니다. 결과를 보면서 규칙을 이해하고, 수정할 방향을 찾는 과정이다. 코드가 의도한 대로 작동하더라도 이미지가 좋지 않을 수 있고, 예상하지 못한 오류가 흥미로운 방향을 열어 줄 수도 있다.

결과를 볼 때는 다음과 같은 질문을 해 볼 수 있다.

- 구조가 너무 규칙적인가, 너무 산만한가?
- 변화의 범위가 충분한가?
- 중심이 있는가, 흐름이 있는가?
- 중요한 요소가 잘 보이는가?
- 랜덤이 효과적으로 쓰였는가?
- 파라미터를 바꿨을 때 결과가 의미 있게 달라지는가?

이 질문들은 미적 판단과 구조적 판단을 함께 포함한다. 제너레이티브 아트에서는 결과가 마음에 드는지뿐 아니라, 왜 그런 결과가 나왔는지 이해하는 것이 중요하다. 그래야 다음 변주를 의도적으로 만들 수 있다.

## 7단계: 저장하고 비교한다

작업을 발전시키려면 결과를 저장하고 비교해야 한다. 제너레이티브 아트는 파라미터와 시드에 따라 많은 버전이 생긴다. 마음에 드는 이미지를 발견했을 때, 그 결과를 만든 파라미터를 함께 기록하지 않으면 다시 찾기 어렵다.

간단한 기록 방식은 다음과 같다.

```text
seed: 42
count: 180
cellSize: 32
noiseScale: 0.018
palette: blue-gray
note: center area has good density
```

이미지만 저장하는 것이 아니라, 이미지를 만든 조건을 저장하는 것이 중요하다. 나중에 같은 조건에서 다시 생성할 수 있어야 작업을 수정하고 확장할 수 있다.

프로젝트가 커지면 파라미터를 JSON 파일로 저장하거나, 파일 이름에 시드와 주요 값을 포함할 수도 있다. 중요한 것은 결과와 조건을 연결해 두는 습관이다.

## 기본 작업 흐름 요약

지금까지의 과정을 하나의 흐름으로 정리하면 다음과 같다.

| 단계 | 할 일 | 핵심 질문 |
| --- | --- | --- |
| 1 | 시각적 아이디어 정하기 | 어떤 관계나 변화가 흥미로운가? |
| 2 | 입력 정하기 | 무엇이 결과를 결정하는가? |
| 3 | 규칙과 함수 만들기 | 입력을 어떻게 변환할 것인가? |
| 4 | 출력 연결하기 | 계산된 값을 무엇으로 보이게 할 것인가? |
| 5 | 파라미터 분리하기 | 무엇을 조절할 수 있어야 하는가? |
| 6 | 결과 관찰과 수정 | 어떤 변화가 필요한가? |
| 7 | 저장과 비교 | 어떤 조건이 이 결과를 만들었는가? |

이 흐름은 항상 순서대로만 진행되지는 않는다. 실제 작업에서는 결과를 보고 아이디어를 바꾸기도 하고, 파라미터를 조정하다가 새로운 규칙을 발견하기도 한다. 그러나 어떤 단계에 있는지 알고 있으면 작업이 막혔을 때 돌아갈 지점을 찾기 쉽다.

## 작은 예제: 노이즈 격자 만들기

마지막으로 지금까지의 흐름을 작은 예제로 정리해 보자. 목표는 격자 위에 원을 배치하고, 각 원의 크기를 노이즈 값으로 조절하는 것이다.

시각적 아이디어는 “격자 구조 안에서 유기적으로 변하는 점 패턴”이다. 입력은 격자 좌표이고, 함수는 노이즈 함수이며, 출력은 원의 반지름이다. 파라미터는 셀 크기, 노이즈 스케일, 최소 반지름, 최대 반지름, 시드다. 다음은 이 구조를 p5.js로 구현한 완전한 예제다.

**p5.js 예제**

```javascript
let cellSize = 24;
let noiseScale = 0.03;
let minRadius = 2;
let maxRadius = 18;
let seed = 7;

function setup() {
  createCanvas(720, 720);
  randomSeed(seed);
  noiseSeed(seed);
  noLoop();
}

function draw() {
  background(250);
  noStroke();
  fill(20);

  for (let y = cellSize / 2; y < height; y += cellSize) {
    for (let x = cellSize / 2; x < width; x += cellSize) {
      let v = noise(x * noiseScale, y * noiseScale);
      let r = map(v, 0, 1, minRadius, maxRadius);
      circle(x, y, r * 2);
    }
  }
}
```

이 코드는 매우 단순하지만 기본 구조를 모두 포함한다. 격자 좌표가 입력이고, 노이즈가 함수이며, 원의 반지름이 출력이다. `cellSize`, `noiseScale`, `minRadius`, `maxRadius`, `seed`는 파라미터다. 이 값들을 바꾸면 같은 구조 안에서 다양한 결과를 만들 수 있다.

이 예제는 앞으로 다룰 많은 주제의 출발점이 된다. 좌표계를 바꾸면 패턴의 공간이 달라지고, 값의 범위를 바꾸면 시각적 대비가 달라지며, 노이즈를 시간에 따라 움직이면 애니메이션이 된다. 원 대신 선이나 사각형을 사용하면 다른 형태가 되고, 반지름 대신 색이나 회전에 연결하면 또 다른 이미지가 된다.

## 이 장의 마무리

Chapter 1에서는 제너레이티브 아트를 바라보는 기본 관점을 다루었다. 핵심은 이미지를 고정된 결과로만 보지 않고, 입력과 함수와 출력이 만들어 내는 구조로 보는 것이다. 그래픽 객체는 여전히 중요하지만, 그 객체를 만들어 내는 규칙이 작업의 중심이 된다.

이제 다음 장부터는 이 구조를 더 구체적인 수학적 도구로 확장한다. 먼저 좌표계를 다룬다. 좌표는 거의 모든 그래픽 계산의 출발점이다. 화면의 한 점을 어떻게 표현하는지, 중심과 방향과 범위를 어떻게 다루는지 이해해야 이후의 함수, 도형, 반복, 필드, 시간 구조를 안정적으로 만들 수 있다.
