# 1.5 제너레이티브 아트의 기본 작업 흐름

앞 절에서는 그래픽 객체를 직접 배치하는 방식과 규칙으로 생성하는 방식, 이미지를 입력·함수·출력의 관계로 이해하는 방법, 도형 함수, 반복 가능한 규칙과 파라미터를 살펴보았다.

이번 절에서는 이 개념들을 하나의 작업 흐름으로 연결한다. 제너레이티브 아트는 아이디어를 규칙으로 바꾸고, 파라미터를 정해 코드를 작성한 뒤, 결과를 관찰하고 수정하는 과정을 거친다. 이 흐름을 익히면 낯선 이미지나 복잡한 시스템도 단계별로 설계할 수 있다.

## 1단계: 시각적 아이디어를 정한다

작업은 구체적인 이미지나 막연한 느낌에서 출발할 수 있다. 예를 들면 다음과 같다.

- 중심에서 바깥으로 퍼지는 원형 패턴
- 바람에 흔들리는 선들의 흐름
- 격자 안에서 조금씩 변형되는 도형
- 물결처럼 움직이는 밝기 패턴
- 유기적인 질감을 가진 표면
- 입자들이 보이지 않는 힘을 따라 움직이는 장면

완성된 이미지를 처음부터 자세히 정하기보다 어떤 관계를 탐색할지 정한다. 중심과 거리, 반복과 변주, 시간과 움직임, 랜덤과 질서 중 무엇이 작업의 바탕이 되는지 살펴본다.

시각적 아이디어를 규칙으로 옮길 때는 다음 질문을 생각해 볼 수 있다.

- 무엇이 반복되는가?
- 무엇이 변하는가?
- 변화는 무엇을 기준으로 일어나는가?
- 중심, 방향, 거리, 시간 같은 기준이 있는가?
- 결과를 조절할 수 있는 주요 값은 무엇인가?

“중심에서 바깥으로 퍼지는 원형 패턴”에서는 중심점과 거리가 기준이 된다. “바람에 흔들리는 선들의 흐름”에는 방향장, 시간, 노이즈가 쓰일 수 있다. “격자 안에서 변형되는 도형”에서는 셀 인덱스, 반복 좌표, 랜덤 값이 핵심 입력이다.

## 2단계: 입력을 정한다

아이디어를 정한 뒤에는 아트워크의 결과를 결정하는 입력을 고른다. 가장 흔한 입력은 화면 위 위치를 나타내는 좌표다. 좌표는 거의 모든 그래픽 계산의 출발점이 된다.

입력은 좌표에 한정되지 않는다. 시간, 반복 인덱스, 마우스 위치, 랜덤 시드, 노이즈 값, 외부 데이터도 입력으로 사용할 수 있다. 선택한 입력에 따라 작업의 성격이 달라진다.

| 만들고 싶은 효과 | 적합한 입력 |
| --- | --- |
| 화면 위치에 따라 달라지는 패턴 | 좌표 |
| 반복되는 도형 배열 | 반복 인덱스, 셀 좌표 |
| 움직이는 패턴 | 시간 |
| 사용자 반응 | 마우스, 키보드, 센서 |
| 불규칙한 배치 | 랜덤 값, 시드 |
| 자연스러운 변화 | 노이즈 값 |
| 데이터 기반 이미지 | 외부 데이터 |

입력을 정할 때는 무엇이 결과를 결정하는지 묻는다. 원의 위치가 격자에 따라 정해진다면 격자 좌표가 입력이다. 색이 중심으로부터의 거리에 따라 달라진다면 거리값이 입력이고, 움직임이 시간에 따라 달라진다면 시간값이 입력이다.

입력이 분명하면 어떤 값을 계산하고 서로 어떻게 연결할지 정하기 쉬워진다.

## 3단계: 규칙과 함수를 만든다

입력을 정했으면 이를 출력으로 바꾸는 규칙을 만든다. 규칙은 수식, 조건문, 반복문 또는 여러 함수의 조합으로 표현할 수 있다.

중심에서의 거리에 따라 원의 크기를 바꾸려면 다음과 같이 정의할 수 있다.

```text
distance = distance(position, center)
size = map(distance, 0, maxDistance, largeSize, smallSize)
```

중심에 가까울수록 도형은 커지고, 멀어질수록 작아진다. 노이즈를 더하면 규칙적인 변화에 불규칙성을 섞을 수 있다.

```text
noiseValue = noise(position * noiseScale)
size = baseSize + noiseValue * variation
```

처음부터 복잡한 규칙을 만들 필요는 없다. 격자를 만든 뒤 셀마다 크기와 색을 바꾸고, 마지막에 시간값을 더해 움직이는 식으로 확장하면 각 규칙이 결과에 미치는 영향을 파악하기 쉽다.

## 4단계: 출력을 시각 요소에 연결한다

함수의 결과인 숫자를 이미지로 표현하려면 위치, 크기, 색, 회전, 투명도, 선 두께, 속도, 밀도 같은 시각 요소에 연결해야 한다.

하나의 출력값도 연결 대상에 따라 다른 결과를 만든다. 거리값을 밝기에 연결하면 그라데이션이 되고, 도형 크기에 연결하면 중심에서 멀어질수록 크기가 달라진다. 노이즈 값을 색에 연결하면 질감이 생기고, 좌표에 연결하면 형태가 일그러진다.

```text
v = noise(x * noiseScale, y * noiseScale)

radius = remap(v, 0, 1, 4, 20)
gray = remap(v, 0, 1, 40, 220)
angle = remap(v, 0, 1, 0, 2 * PI)
```

`v`는 하나의 노이즈 값이며 반지름, 밝기, 각도에 모두 연결할 수 있다. 연결 방식을 선택하면 이미지의 성격이 달라진다.

출력값의 범위도 확인해야 한다. 함수에 따라 0~1 사이의 값을 반환하기도 하고, 음수와 양수를 모두 반환하기도 한다. 색에는 보통 0~255 사이의 값이 필요하고, 회전각은 0~2π 범위로 다루기 편하다. 따라서 재매핑, 제한, 보간으로 값을 조정하는 일이 잦다. 이 내용은 Chapter 3에서 자세히 다룬다.

## 5단계: 파라미터를 분리한다

작업의 형태가 보이기 시작하면 주요 값을 파라미터로 분리한다. 초기 실험에서는 코드에 숫자를 직접 넣어도 되지만, 작업을 발전시키려면 조절할 값에 이름을 붙이는 편이 좋다.

```text
count = 30
cellSize = 24
noiseScale = 0.02
minRadius = 3
maxRadius = 18
seed = 12
```

각 값은 작업의 조절 장치가 된다. `count`는 밀도, `cellSize`는 구조의 크기, `noiseScale`은 변화의 질감을 조절한다. `seed`는 랜덤 배치를 다시 생성하는 기준이다.

파라미터를 분리하면 여러 버전을 비교하기 쉽다. 같은 규칙에서 `noiseScale`만 바꾸거나, 색 체계를 유지한 채 `seed`를 바꾸어 다른 구성을 만들 수 있다.

어떤 값을 바꾸면 어떤 시각적 변화가 일어나는지 예측할 수 있도록 파라미터를 설계하면 작업을 다루기 수월하다.

## 6단계: 결과를 관찰하고 수정한다

결과를 관찰하는 일은 이미지에서 규칙의 작동 방식을 읽고 수정 방향을 찾는 과정이다. 코드가 의도대로 작동해도 이미지가 원하는 모습과 다를 수 있다. 반대로 예상하지 못한 오류가 새로운 방향을 제안하기도 한다.

결과를 살펴볼 때는 다음 질문을 던져 볼 수 있다.

- 구조가 너무 규칙적인가, 너무 산만한가?
- 변화의 범위가 충분한가?
- 중심이 있는가, 흐름이 있는가?
- 중요한 요소가 잘 보이는가?
- 랜덤이 효과적으로 쓰였는가?
- 파라미터를 바꿨을 때 결과가 의미 있게 달라지는가?

이 질문에는 미적 판단과 구조적 판단이 모두 담겨 있다. 이미지가 마음에 드는지 살피는 데서 멈추지 않고, 결과가 나온 이유도 파악해야 다음 변주를 의도적으로 만들 수 있다.

## 7단계: 저장하고 비교한다

제너레이티브 아트는 파라미터와 시드에 따라 여러 버전을 만든다. 마음에 드는 이미지를 발견했을 때 생성 조건도 함께 기록해야 나중에 다시 찾을 수 있다.

간단한 기록 방식은 다음과 같다.

```text
seed: 42
count: 180
cellSize: 32
noiseScale: 0.018
palette: blue-gray
note: center area has good density
```

이미지와 함께 생성 조건을 저장하면 같은 결과를 다시 만들고 수정하거나 확장할 수 있다. 프로젝트가 커지면 파라미터를 JSON 파일에 저장하거나 파일 이름에 시드와 주요 값을 넣을 수도 있다.

## 기본 작업 흐름 요약

지금까지의 과정을 표로 정리하면 다음과 같다.

| 단계 | 할 일 | 핵심 질문 |
| --- | --- | --- |
| 1 | 시각적 아이디어 정하기 | 어떤 관계나 변화가 흥미로운가? |
| 2 | 입력 정하기 | 무엇이 결과를 결정하는가? |
| 3 | 규칙과 함수 만들기 | 입력을 어떻게 변환할 것인가? |
| 4 | 출력 연결하기 | 계산된 값을 무엇으로 보이게 할 것인가? |
| 5 | 파라미터 분리하기 | 무엇을 조절할 수 있어야 하는가? |
| 6 | 결과 관찰과 수정 | 어떤 변화가 필요한가? |
| 7 | 저장과 비교 | 어떤 조건이 이 결과를 만들었는가? |

작업이 언제나 이 순서대로 진행되지는 않는다. 결과를 보고 아이디어를 바꾸거나, 파라미터를 조정하다가 새 규칙을 발견할 수 있다. 그래도 현재 어느 단계에 있는지 알면 작업이 막혔을 때 돌아갈 지점을 찾기 쉽다.

## 작은 예제: 노이즈 격자 만들기

앞에서 살펴본 흐름을 작은 예제로 정리해 보자. 목표는 격자 위에 원을 배치하고 노이즈 값으로 각 원의 크기를 조절하는 것이다.

시각적 아이디어는 “격자 구조 안에서 유기적으로 변하는 점 패턴”이다. 입력은 격자 좌표, 함수는 노이즈 함수, 출력은 원의 반지름이다. 셀 크기, 노이즈 스케일, 최소 반지름, 최대 반지름, 시드가 파라미터다. 다음 p5.js 코드가 이 구조를 구현한다.

**p5.js 예제**

```javascript
let cellSize = 24;
let noiseScale = 0.03;
let minRadius = 2;
let maxRadius = 18;
let seed = 7;

function setup() {
  createCanvas(720, 720);
  randomSeed(seed);
  noiseSeed(seed);
  noLoop();
}

function draw() {
  background(250);
  noStroke();
  fill(20);

  for (let y = cellSize / 2; y < height; y += cellSize) {
    for (let x = cellSize / 2; x < width; x += cellSize) {
      let v = noise(x * noiseScale, y * noiseScale);
      let r = map(v, 0, 1, minRadius, maxRadius);
      circle(x, y, r * 2);
    }
  }
}
```

이 예제에서는 격자 좌표가 입력, 노이즈가 함수, 원의 반지름이 출력이다. `cellSize`, `noiseScale`, `minRadius`, `maxRadius`, `seed`를 바꾸면 같은 구조에서 여러 결과를 만들 수 있다.

이 구조는 이후 다룰 주제의 출발점이 된다. 좌표계를 바꾸면 패턴의 공간이 달라지고, 값의 범위를 바꾸면 시각적 대비가 달라진다. 노이즈를 시간에 따라 움직이면 애니메이션이 된다. 원을 선이나 사각형으로 바꾸거나 반지름 대신 색과 회전을 조절해도 다른 이미지를 얻는다.

## 이 장의 마무리

Chapter 1에서는 제너레이티브 아트를 바라보는 기본 관점을 다루었다. 이미지를 고정된 결과로만 보지 않고 입력, 함수, 출력이 만드는 구조로 이해한다. 그래픽 객체도 중요하지만, 작업의 중심에는 객체를 생성하는 규칙이 놓인다.

다음 장에서는 이 구조를 여러 수학 도구로 살펴본다. 그래픽 계산의 출발점인 좌표계부터 값의 연결, 함수, 패턴, 필드, 시간 구조까지 차례로 다룬다.
