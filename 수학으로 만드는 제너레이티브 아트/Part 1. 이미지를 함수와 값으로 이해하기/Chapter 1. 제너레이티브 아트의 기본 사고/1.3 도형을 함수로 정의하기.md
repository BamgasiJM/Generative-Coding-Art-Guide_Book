# 1.3 도형을 함수로 정의하기

앞 절에서는 이미지를 입력과 함수, 출력의 관계로 살펴봤다. 이번에는 그 관점을 도형에 적용한다. 원과 선, 사각형, 삼각형은 보통 화면에 그려지는 개별 그래픽 객체로 생각한다. 제너레이티브 아트에서는 도형을 함수로 정의하는 방법도 사용한다.

도형을 함수로 정의한다는 것은 화면의 한 점과 도형 사이의 관계를 계산한다는 뜻이다. 점이 원 안에 있는지, 선에서 얼마나 떨어져 있는지, 사각형의 경계에 가까운지를 함수로 판단한다. 도형은 좌표를 입력으로 받아 값을 내는 계산으로 표현된다.

처음에는 이 방식이 낯설 수 있다. p5.js에는 `circle(x, y, diameter)`처럼 원을 그리는 명령이 있다. 하지만 셰이더나 프로시저럴 재질에는 원을 직접 그리는 명령이 없는 경우가 많다. 현재 좌표와 원의 중심 사이의 거리를 구한 뒤 그 값에 따라 색을 정한다. 원은 그리기 명령으로 놓이는 객체가 아니라 거리 함수의 결과로 나타난다.

## 객체로서의 도형과 함수로서의 도형

객체로서의 도형은 그리기 명령을 통해 화면에 나타난다. 원은 중심 좌표와 반지름을 가진 객체이고, 사각형은 위치와 너비, 높이로 표현된다. 이런 명령은 도형을 배치하고 조작하기 쉽도록 해준다.

함수로서의 도형은 좌표에 대한 판단으로 표현된다. 화면의 한 점 `p`를 입력하면 함수는 그 점이 도형 안인지, 밖인지, 경계에서 얼마나 떨어져 있는지를 알려준다. 이 결과값에 따라 도형의 모양이 드러난다.

```text
value = shape(p)
```

여기서 `p`는 좌표이고 `shape`는 도형을 정의하는 함수다. `value`는 여러 방식으로 해석할 수 있다. 가장 간단한 경우에는 0이나 1을 반환해 안쪽과 바깥쪽을 나눈다. 거리값으로 나타낼 수도 있다. 이때 값이 0에 가까우면 경계에 가깝고, 값이 작거나 큰지는 안쪽과 바깥쪽 중 어디인지를 나타내는 기준이 된다.

| 관점       | 도형의 의미               | 주로 사용하는 곳             |
| -------- | -------------------- | --------------------- |
| 객체로서의 도형 | 화면에 배치되는 그래픽 요소      | 드로잉 API, 벡터 그래픽, 레이아웃 |
| 함수로서의 도형 | 좌표를 입력으로 받아 값을 내는 규칙 | 셰이더, 거리장, 프로시저럴 패턴    |

두 방식은 서로 배타적이지 않다. p5.js에서도 도형을 함수처럼 생각할 수 있고, 셰이더에서도 중심과 크기를 객체의 속성처럼 관리할 수 있다.

## 원을 함수로 정의하기

원을 이용하면 도형을 함수로 표현하는 원리를 이해하기 쉽다. 원은 중심점에서 같은 거리에 있는 점들의 집합이다. 어떤 점이 원 안에 있는지 확인하려면 그 점과 중심점 사이의 거리를 계산하면 된다.

```text
d = distance(p, center)
```

`p`는 현재 좌표, `center`는 원의 중심, `d`는 두 점 사이의 거리다. 반지름이 `r`일 때 `d < r`이면 점은 원 안에 있고, `d > r`이면 원 밖에 있다. 원을 그리는 명령 대신 각 좌표가 중심에서 반지름보다 가까운지 판단하는 함수로 표현하는 셈이다.

```glsl
float circle(vec2 p, vec2 center, float radius) {
    float d = distance(p, center);
    return step(d, radius);
}
```

이 셰이더 스타일의 함수는 좌표 `p`가 원 안에 있으면 1에 가까운 값을, 밖에 있으면 0에 가까운 값을 반환한다. 반환값을 색에 연결하면 원이 나타난다.

```glsl
float v = circle(p, vec2(0.5), 0.25);
vec3 color = vec3(v);
```

p5.js에서는 `circle(width / 2, height / 2, 200)`처럼 원을 객체로 그릴 수 있다. 함수로 정의하면 각 좌표가 원 안인지 밖인지 계산한다. 화면의 결과는 같아도 도형을 만드는 방식은 다르다.

## 경계는 값의 변화로 만들어진다

도형을 함수로 정의하면 경계를 세밀하게 조절할 수 있다. 원 안을 1, 바깥을 0으로 갑자기 나누면 경계가 딱딱하게 보인다. 거리값을 이용하면 경계 주변을 부드럽게 처리할 수 있다.

```glsl
float d = distance(p, center);
float v = smoothstep(radius, radius - softness, d);
```

`smoothstep`은 두 값 사이를 부드럽게 보간한다. 이 함수를 사용하면 원의 가장자리가 계단처럼 끊기지 않고 서서히 사라진다. 경계는 값이 변하는 구간으로 다룰 수 있다. 외곽선과 채움, 그림자, 글로우, 마스크, 블렌딩도 경계 주변의 값을 처리하는 방식과 관련된다. 도형을 함수로 보면 이런 효과를 같은 관점에서 설명할 수 있다.

## 선과 사각형도 함수가 될 수 있다

원뿐 아니라 선과 사각형, 다각형도 좌표와의 관계를 계산하는 함수로 표현할 수 있다.

선은 한 점에서 선까지의 거리를 계산해 정의할 수 있다. 선분이라면 점에서 선분까지의 최단 거리를 구한다. 그 값이 정한 두께보다 작으면 선이 보이고, 크면 보이지 않는다.

```text
d = distanceToSegment(p, a, b)
visible = d < thickness
```

`a`와 `b`는 선분의 양 끝점이다. 이렇게 보면 선은 두께가 없는 기하학적 대상이 아니라 일정한 두께를 가진 영역이 된다. 두께를 조절하면 선이 굵어지고, 거리값을 색에 연결하면 주변에 그라데이션을 만들 수 있다.

사각형은 좌표의 범위로 정의할 수 있다. 점의 x좌표가 왼쪽과 오른쪽 경계 사이에 있고 y좌표가 위쪽과 아래쪽 경계 사이에 있으면 사각형 안에 있다.

```text
insideX = left < x < right
insideY = top < y < bottom
inside = insideX and insideY
```

셰이더에서는 `step` 함수들을 조합해 이 조건을 만들 수 있다. 중심점과 크기를 기준으로 사각형의 거리 함수를 정의하면 둥근 사각형이나 부드러운 경계도 만들 수 있다. 자세한 내용은 뒤의 거리 함수와 SDF 장에서 다룬다.

## 함수로 정의한 도형은 조합하기 쉽다

도형을 함수값으로 표현하면 여러 도형을 조합하기 쉽다. 원 함수와 사각형 함수가 각각 0이나 1을 반환한다고 하자. 두 값을 더하거나 곱하고, 최댓값이나 최솟값을 취해 새로운 형태를 만들 수 있다.

```text
circleValue = circle(p)
boxValue = box(p)

union = max(circleValue, boxValue)
intersection = min(circleValue, boxValue)
difference = circleValue * (1 - boxValue)
```

레이어를 겹치는 것처럼 보이지만 실제로는 값들을 조합한다. 도형이 픽셀마다 계산되는 값이라면 그 값들을 수학적으로 합성할 수 있다. 합집합과 교집합, 차집합은 물론 부드러운 전환이나 마스크 효과도 만들 수 있다.

셰이더와 SDF에서는 간단한 거리 함수들을 조합해 새로운 형태를 만든다. 원과 사각형, 선, 반복 좌표, 회전 변환을 함께 사용하면 다양한 패턴으로 확장된다.

## 도형 함수의 출력은 여러 방식으로 사용할 수 있다

도형 함수의 출력을 색에만 연결할 필요는 없다. 원 안을 흰색, 밖을 검은색으로 표현할 수도 있고, 같은 값을 투명도와 크기, 변위, 입자의 힘, 재질 속성에 연결할 수도 있다.

원 함수가 안쪽에서 1, 바깥에서 0을 반환한다고 하자. 이 값을 알파에 연결하면 마스크가 된다. 입자의 속도에 곱하면 원 안에서만 입자가 움직인다. 3D 표면의 변위에 연결하면 원형으로 솟은 패턴을 만들 수 있다.

| 도형 함수의 출력 | 연결 대상 | 결과 |
| --- | --- | --- |
| 안/밖 값 | 색 | 채워진 도형 |
| 거리값 | 밝기 | 부드러운 그라데이션 |
| 경계 근처 값 | 알파 | 마스크와 페이드 |
| 거리 변화 | 변위 | 표면의 높낮이 |
| 도형 내부 여부 | 힘 또는 속도 | 특정 영역에서만 움직이는 입자 |

도형을 함수로 정의하면 보이는 모양을 넘어 다른 계산을 제어하는 값으로 사용할 수 있다. 이 방식은 뒤에서 다룰 필드와 마스크, 입자 시스템, 프로시저럴 재질의 기반이 된다.

## 드로잉 명령과 도형 함수의 선택

드로잉 명령과 도형 함수 중 무엇을 쓸지는 작업의 성격에 따라 달라진다.

도형을 명확히 배치하거나 많은 요소를 객체처럼 관리할 때는 드로잉 API의 명령이 적합하다. p5.js로 포스터형 구성이나 인터랙티브 스케치, 입자를 표현할 때 `circle()`, `line()`, `rect()`가 편리하다. 픽셀 단위 패턴이나 부드러운 경계, 마스크, 거리 기반 변형, 프로시저럴 텍스처에는 도형을 함수로 정의하는 방식이 유리하다. 셰이더에서는 대부분의 계산이 좌표를 입력으로 하는 함수로 이루어진다.

| 상황                    | 적합한 접근      |
| --------------------- | ----------- |
| 개별 도형을 배치하고 관리할 때     | 드로잉 명령      |
| 픽셀마다 색을 계산할 때         | 도형 함수       |
| 경계와 그라데이션을 섬세하게 제어할 때 | 거리 함수       |
| 여러 도형을 수학적으로 합성할 때    | 함수값 조합      |
| 3D 표면의 재질 패턴을 만들 때    | 좌표 기반 도형 함수 |

한 작업 안에서 객체로 그린 도형과 함수로 정의한 패턴을 함께 쓸 수도 있다. 객체는 작업을 구성하고, 함수는 그 내부의 색과 질감, 경계, 변화를 만든다.

## 이 절의 핵심

도형은 화면에 그리는 객체인 동시에 좌표를 입력받아 값을 내는 함수로 정의할 수도 있다. 원은 중심점까지의 거리로, 선은 선분까지의 거리로 나타낼 수 있다. 사각형은 좌표 범위나 거리 함수로 정의한다.

도형을 함수로 보면 경계와 마스크, 그라데이션, 조합, 변형을 유연하게 다룰 수 있다. 이 관점은 셰이더와 SDF, 프로시저럴 재질에서 특히 중요하며 일반적인 드로잉 API에도 적용된다.

다음 절에서는 이렇게 정의한 규칙을 반복 가능하게 만들고 파라미터로 조절하는 방법을 살펴본다. 제너레이티브 아트에서는 좋은 결과를 한 번 얻는 데 그치지 않고, 다시 만들고 변주할 수 있는 구조를 갖추는 일이 중요하다.
