# 2.3 정규화 좌표와 UV 좌표

픽셀 좌표는 화면상의 위치를 직접 나타내지만, 해상도가 달라지면 같은 숫자가 가리키는 상대적 위치도 달라진다. 너비 800픽셀 화면에서 $x=400$은 중앙이고, 너비 1600픽셀 화면에서는 왼쪽에서 4분의 1 지점이다. 해상도와 무관한 규칙을 만들려면 좌표를 일정한 범위로 변환해야 한다.

정규화 좌표는 좌표를 정해진 범위로 변환한 값이다. 그래픽에서는 화면이나 이미지의 가로와 세로를 각각 0~1로 나타내는 경우가 많고, UV 좌표도 이 범위를 자주 사용한다. 두 용어는 비슷하게 쓰이지만 뜻은 다르다. 정규화는 좌표 범위를 바꾸는 일반적인 개념이며, UV는 주로 표면의 위치와 텍스처의 위치를 연결한다.

## 픽셀 좌표 정규화하기

화면 좌표가 $(x,y)$이고 해상도가 $(W,H)$일 때 다음 식으로 정규화한다.

$$
u=\frac{x}{W},\qquad v=\frac{y}{H}
$$

왼쪽은 $u=0$, 오른쪽은 $u=1$에 가까워진다. 위쪽은 $v=0$, 아래쪽은 $v=1$에 가깝다. 벡터를 사용하면 성분별 나눗셈으로 간단히 계산할 수 있다.

```glsl
vec2 uv = fragCoord.xy / resolution.xy;
```

정규화 좌표를 밝기에 연결하면 해상도에 관계없이 왼쪽에서 오른쪽으로 변하는 그라데이션을 만들 수 있다.

```glsl
float brightness = uv.x;
vec3 color = vec3(brightness);
```

화면 크기가 달라져도 `uv.x`의 상대적 범위는 유지된다. 같은 규칙을 작은 미리보기나 큰 출력 이미지, 여러 화면 크기에 적용할 수 있다.

## 정규화는 단위를 없애는 과정이다

픽셀 좌표의 단위는 픽셀이다. 0~1 범위의 정규화 좌표는 전체 크기에 대한 비율을 나타낸다. $u=0.25$는 가로 길이의 25퍼센트 지점이며, 특정 픽셀 수를 뜻하지 않는다.

| 좌표 표현 | 예 | 의미 |
| --- | --- | --- |
| 픽셀 좌표 | $(400,300)$ | 특정 해상도에서의 위치 |
| 정규화 좌표 | $(0.5,0.5)$ | 영역의 상대적 중앙 |
| 중심 기준 좌표 | $(0,0)$ | 선택한 중심으로부터의 위치 |
| 물리 단위 좌표 | $(2.0\text{ m},1.0\text{ m})$ | 실제 또는 가상 공간의 크기 |

정규화 좌표가 늘 적합한 것은 아니다. 선 두께를 정확히 2픽셀로 유지하거나 출력 해상도에 맞춰 세부 묘사를 할 때는 픽셀 단위가 필요하다. 전체 구조는 정규화 좌표로 만들고 얇은 경계나 샘플링 폭은 픽셀 크기를 기준으로 삼는 식으로 두 단위를 함께 쓴다.

정규화 좌표에서 한 픽셀의 크기는 다음과 같다.

$$
\Delta u=\frac{1}{W},\qquad \Delta v=\frac{1}{H}
$$

이 값으로 정규화 공간에서 한 픽셀에 해당하는 두께를 계산할 수 있다.

## UV 좌표란 무엇인가

UV 좌표는 표면의 위치를 2차원으로 나타낸다. 3차원 위치에 $x$, $y$, $z$를 사용하므로 텍스처 좌표의 두 축에는 관례적으로 $u$와 $v$를 쓴다.

UV 좌표는 이미지나 프로시저럴 텍스처의 위치를 표면의 위치와 대응시킨다. 사각형 표면의 네 모서리에 $(0,0)$, $(1,0)$, $(1,1)$, $(0,1)$을 지정하면 중간 좌표가 보간되어 텍스처 전체가 표면에 놓인다.

```glsl
vec3 color = texture(inputTexture, uv).rgb;
```

`uv`는 텍스처에서 읽을 위치다. `uv`가 $(0.5,0.5)$이면 보통 이미지 중앙 부근을 샘플링한다. 세로축의 원점이 위인지 아래인지는 이미지 형식과 그래픽 API에 따라 다르다.

셰이더 예제에서는 정규화된 화면 좌표를 편의상 `uv`라고 부르는 경우가 많다. 화면 전체를 사각형 표면으로 보면 자연스러운 표현이다. 다만 모든 정규화 좌표가 UV인 것은 아니며, UV가 항상 0~1 범위에 머무는 것도 아니다. UV는 표면과 텍스처의 대응 관계를 나타내고, 정규화는 값의 범위를 변환한다.

## 0에서 1 사이 좌표를 중심 기준으로 바꾸기

0~1 좌표는 화면 비율을 다루기 좋지만 중앙 기준 대칭이나 회전에는 불편할 수 있다. 중앙 $(0.5,0.5)$을 원점으로 옮기면 좌표 범위는 대략 $-0.5$~$0.5$가 된다.

$$
\mathbf{p}=\mathbf{uv}-(0.5,0.5)
$$

범위를 $-1$~$1$로 확장하려면 2를 곱한다.

$$
\mathbf{p}=2\mathbf{uv}-1
$$

GLSL에서는 다음과 같이 쓸 수 있다.

```glsl
vec2 p = uv * 2.0 - 1.0;
```

화면 중앙이 $(0,0)$이 되어 중심으로부터의 거리와 각도, 대칭 패턴을 간단히 계산할 수 있다. 선택한 범위의 의미를 코드 전체에서 일관되게 유지해야 한다.

## 화면 비율 보정하기

$u$와 $v$를 각각 가로와 세로 크기로 나누면 두 축 모두 0~1 범위가 된다. 하지만 정사각형이 아닌 화면에서는 좌표의 한 단위가 가리키는 픽셀 길이가 축마다 다르다. 1600×900 화면에서 정규화 좌표의 가로 0.1은 160픽셀이고 세로 0.1은 90픽셀이다.

이 상태에서 중심까지의 거리를 계산하면 원이 타원처럼 보일 수 있다. 가로축에 화면 종횡비를 곱해 두 축의 공간적 척도를 맞춘다.

$$
a=\frac{W}{H},\qquad p_x=(u-0.5)a,\qquad p_y=v-0.5
$$

```glsl
vec2 p = uv - 0.5;
p.x *= resolution.x / resolution.y;

float d = length(p);
```

이 계산은 세로 길이를 기준 단위로 삼는다. 가로를 기준으로 세로축을 보정해도 된다. 거리와 각도를 계산하기 전에 두 축의 척도를 맞춰야 한다.

두 좌표를 처음부터 같은 값으로 나누는 방법도 있다.

$$
\mathbf{p}=\frac{(x,y)-\frac{1}{2}(W,H)}{\min(W,H)}
$$

짧은 축을 기준으로 중심 좌표를 정규화하는 방법이다. 해상도가 달라져도 원의 비율이 유지되고, 긴 축에는 더 넓은 좌표 범위가 생긴다.

## 범위 밖의 UV 처리

계산 중 UV 좌표가 0보다 작거나 1보다 커질 수 있다. 범위 밖 좌표를 텍스처에서 어떻게 처리할지는 샘플러 설정에 달려 있다.

| 처리 방식 | 동작 | 주된 용도 |
| --- | --- | --- |
| Clamp | 가장 가까운 가장자리 값을 유지한다. | 이미지 가장자리 고정 |
| Repeat | 소수 부분을 사용해 반복한다. | 타일 패턴, 반복 텍스처 |
| Mirrored Repeat | 방향을 번갈아 뒤집어 반복한다. | 경계가 덜 눈에 띄는 반복 |
| Border | 지정한 경계색을 사용한다. | 영역 밖을 명확히 구분 |

프로시저럴 패턴에서는 `fract`로 좌표의 소수 부분만 남겨 반복을 직접 만들 수 있다.

```glsl
vec2 repeatedUV = fract(uv * repeatCount);
```

`repeatCount`가 커지면 0~1 범위의 패턴이 더 많이 반복된다. 반복 경계에서 값이 갑자기 바뀔 수 있다는 점도 고려해야 한다.

## 좌표를 뒤집고 바꾸기

텍스처나 렌더 타깃을 연결한 뒤 이미지가 위아래로 뒤집힌다면, 대개 UV의 $v$축 방향이 서로 다르기 때문이다. 0~1 좌표는 다음 식으로 뒤집을 수 있다.

$$
v'=1-v
$$

```glsl
uv.y = 1.0 - uv.y;
```

가로축과 세로축을 교환하면 패턴의 방향도 달라진다.

```glsl
uv = uv.yx;
```

이 변환은 간단하고 여러 라이브러리와 파일 형식을 연결할 때 자주 쓰인다. 원본 데이터를 수정하기 전에 좌표 관례부터 확인하면 불필요한 뒤집기나 복사를 피할 수 있다.

## 이 절의 핵심

정규화 좌표는 픽셀 좌표를 전체 크기에 대한 비율로 바꾸어 해상도에 덜 의존하는 규칙을 만든다. UV 좌표는 표면과 텍스처의 위치를 연결하며 0~1 범위를 자주 사용한다. 두 개념은 겹쳐 쓰이지만 뜻은 다르다.

정규화 좌표에서는 원점과 세로축 방향, 화면 종횡비를 확인해야 한다. 다음 절에서는 목적에 맞게 원점을 옮기고 좌표 범위를 정하는 방법을 살펴본다.
