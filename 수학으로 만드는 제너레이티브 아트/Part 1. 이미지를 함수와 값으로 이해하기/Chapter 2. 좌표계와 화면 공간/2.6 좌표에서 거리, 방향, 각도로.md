# 2.6 좌표에서 거리, 방향, 각도로

좌표는 점의 위치를 나타낸다. 제너레이티브 아트에서는 위치 자체보다 점들 사이의 관계가 더 유용한 경우가 많다. 중심에서 얼마나 떨어져 있는지, 어느 방향에 있는지, 기준축과 어떤 각도를 이루는지 계산하면 방사형 패턴, 궤도 운동, 방향장, 조명, 충돌, 입자 이동을 만들 수 있다.

거리, 방향, 각도는 모두 두 좌표의 차이에서 구한다. 기준점 $\mathbf{a}$와 대상점 $\mathbf{b}$로 다음 벡터를 정의한다.

$$
\mathbf{v}=\mathbf{b}-\mathbf{a}
$$

$\mathbf{v}$는 $\mathbf{a}$에서 $\mathbf{b}$로 향하는 변위 벡터다. 벡터의 길이로 거리를 구하고, 길이를 1로 정규화해 방향을 얻는다. 성분을 이용하면 각도도 계산할 수 있다.

## 두 점 사이의 거리

피타고라스 정리를 사용하면 2차원 벡터 $\mathbf{v}=(v_x,v_y)$의 길이를 계산할 수 있다.

$$
\lVert\mathbf{v}\rVert=\sqrt{v_x^2+v_y^2}
$$

따라서 두 점 $\mathbf{a}=(a_x,a_y)$와 $\mathbf{b}=(b_x,b_y)$ 사이의 유클리드 거리는 다음과 같다.

$$
d(\mathbf{a},\mathbf{b})=\sqrt{(b_x-a_x)^2+(b_y-a_y)^2}
$$

대부분의 벡터 라이브러리와 셰이딩 언어는 벡터의 길이를 구하는 `length`와 두 점 사이의 거리를 구하는 `distance`를 제공한다.

```glsl
vec2 offset = point - center;
float d1 = length(offset);
float d2 = distance(point, center);
```

`d1`과 `d2`는 같은 값이다. 이후 방향이나 각도 계산에도 `offset`이 필요하다면 차이 벡터를 먼저 구하는 편이 효율적이고 의도도 분명하다.

## 거리로 이미지를 만들기

화면의 각 좌표에서 중심까지의 거리를 계산하면 중심에서 바깥으로 커지는 스칼라장이 생긴다. 거리를 밝기에 연결하면 방사형 그라데이션이 되고, 임계값과 비교하면 원을 만들 수 있다.

```glsl
vec2 p = centeredAspectCorrectedPosition;
float d = length(p);

float disk = 1.0 - step(radius, d);
```

거리를 주기 함수에 넣으면 동심원 패턴이 만들어진다.

```glsl
float rings = 0.5 + 0.5 * cos(d * frequency);
```

시간을 더하면 고리가 안팎으로 움직이는 효과를 낼 수 있다.

```glsl
float rings = 0.5 + 0.5 * cos(d * frequency - time * speed);
```

화면의 종횡비를 보정하지 않고 거리를 계산하면 원이 타원으로 보일 수 있다. 거리 함수는 각 축의 한 단위가 같은 길이라는 전제에서 작동하기 때문이다.

## 제곱 거리 사용하기

두 거리를 비교할 때는 제곱근을 계산하지 않아도 된다. 거리의 제곱은 다음과 같다.

$$
d^2=v_x^2+v_y^2
$$

반지름 $r$ 안에 있는지 확인하려면 $d<r$ 대신 $d^2<r^2$을 비교할 수 있다.

```text
offset = point - center
inside = dot(offset, offset) < radius * radius
```

제곱 거리는 실제 거리와 값의 변화가 다르므로 밝기나 물리식에 그대로 쓸 때는 주의해야 한다. 가장 가까운 점을 찾거나 범위 안에 있는지 판정할 때는 비교 결과의 순서가 같으면서 계산은 간단하다.

## 방향 벡터

변위 벡터에는 거리와 방향이 함께 담겨 있다. 방향만 남기려면 벡터를 길이로 나눈다.

$$
\hat{\mathbf{v}}=\frac{\mathbf{v}}{\lVert\mathbf{v}\rVert}
$$

길이가 1인 벡터를 단위 벡터라고 하며, 그래픽 라이브러리에서는 대개 `normalize`로 계산한다.

```glsl
vec2 offset = target - position;
vec2 direction = normalize(offset);
```

현재 위치에서 목표 방향으로 속도 $s$만큼 이동할 때는 방향 벡터에 속도를 곱한다.

$$
\mathbf{p}_{next}=\mathbf{p}+\hat{\mathbf{v}}s\Delta t
$$

```text
direction = normalize(target - position)
velocity = direction * speed
position = position + velocity * deltaTime
```

거리와 방향을 분리하면 목표까지의 거리에 관계없이 속도를 일정하게 유지한다. 변위 벡터 자체를 속도로 사용하면 목표가 멀수록 빠르고 가까울수록 느려진다.

벡터의 길이가 0이면 정규화에서 0으로 나누게 된다. 기준점과 대상점이 같을 수 있다면 벡터 길이를 먼저 확인하고, 영벡터를 라이브러리가 어떻게 처리하는지도 살펴야 한다.

## 각도 구하기

2차원 벡터 $(x,y)$와 양의 $x$축 사이의 각도는 `atan2`로 구한다.

$$
\theta=\operatorname{atan2}(y,x)
$$

`atan2`는 $x$와 $y$의 부호를 함께 살펴 벡터가 속한 사분면을 구분한다. 결과는 보통 $-\pi$에서 $\pi$ 사이의 값이다.

```glsl
vec2 offset = point - center;
float angle = atan(offset.y, offset.x);
```

함수 이름과 인자 순서는 언어마다 다를 수 있다. JavaScript, Python, C 계열에서는 흔히 `atan2(y, x)`를, GLSL에서는 두 인자를 받는 `atan(y, x)`를 쓴다. API 문서를 확인하지 않고 인자 순서를 바꾸면 패턴이 회전하거나 뒤집힐 수 있다.

화면에서 $y$축이 아래로 증가하면 각도의 시각적 방향은 수학 좌표와 달라진다. 수학적 반시계 방향 각도가 필요하다면 좌표를 먼저 $y$가 위로 증가하는 공간으로 변환한다.

## 각도를 위치로 바꾸기

거리와 각도에서 데카르트 좌표를 구하는 식은 다음과 같다.

$$
x=r\cos\theta,\qquad y=r\sin\theta
$$

중심점 $\mathbf{c}$를 중심으로 하는 원 위에 점을 배치할 때는 다음 식을 사용한다.

$$
\mathbf{p}=\mathbf{c}+r(\cos\theta,\sin\theta)
$$

```text
for i from 0 to count - 1:
    angle = i / count * 2 * PI
    position = center + (cos(angle), sin(angle)) * radius
    drawElement(position)
```

이 식은 원형 배치, 궤도 운동, 방사형 메뉴, 꽃잎 구조, 파형 생성에 쓰인다. 각도에 시간을 더하면 회전이 생기고, 반지름을 함수로 정하면 나선이나 물결 모양을 만들 수 있다.

## 데카르트 좌표와 극좌표

점의 위치를 중심 기준의 $(x,y)$ 대신 거리와 각도 $(r,\theta)$로 나타내는 좌표계를 극좌표라고 한다.

$$
r=\sqrt{x^2+y^2},\qquad \theta=\operatorname{atan2}(y,x)
$$

데카르트 좌표는 가로·세로 방향의 변화를, 극좌표는 중심에서 퍼지는 변화와 회전을 표현하기 편하다.

| 표현 | 구성 요소 | 적합한 구조 |
| --- | --- | --- |
| 데카르트 좌표 | $x$, $y$ | 격자, 직선 배치, 축 방향 변형 |
| 극좌표 | $r$, $\theta$ | 원, 나선, 방사형 반복, 각도 기반 색상 |

극좌표를 사용해도 렌더링 방식 자체가 바뀌지는 않는다. 현재 좌표에서 $r$과 $\theta$를 구해 함수의 입력으로 사용한다.

```glsl
float r = length(p);
float theta = atan(p.y, p.x);
float value = sin(theta * arms + r * twist);
```

`arms`는 각도 방향의 반복 횟수, `twist`는 거리에 따른 위상 변화를 조절한다. 두 값을 함께 사용하면 회전하는 팔이나 나선형 줄무늬를 만들 수 있다.

## 두 방향 사이의 관계

두 단위 방향 벡터 $\hat{\mathbf{a}}$와 $\hat{\mathbf{b}}$를 내적하면 두 방향 사이 각도의 코사인이 나온다.

$$
\hat{\mathbf{a}}\cdot\hat{\mathbf{b}}=\cos\theta
$$

내적값은 두 벡터가 같은 방향일 때 1, 수직일 때 0, 반대 방향일 때 -1이다. 각도 자체가 필요하면 역코사인을 적용한다.

$$
\theta=\arccos(\operatorname{clamp}(\hat{\mathbf{a}}\cdot\hat{\mathbf{b}},-1,1))
$$

밝기나 영향력을 계산할 때는 비용이 큰 역삼각함수 대신 내적값을 직접 쓰는 경우가 많다. 표면이 빛을 향하는 정도나 시야 방향과 진행 방향의 일치도를 구할 때 유용하다.

2차원에서 회전 방향까지 포함한 각도 차이를 구하려면 두 벡터의 행렬식에 해당하는 값과 내적을 `atan2`에 함께 넣는다.

$$
\theta=\operatorname{atan2}(a_xb_y-a_yb_x,\mathbf{a}\cdot\mathbf{b})
$$

결과의 부호는 한 방향에서 다른 방향으로 회전할 쪽을 나타낸다.

## 다른 거리 함수

거리 함수가 항상 유클리드 거리일 필요는 없다. 좌표 차이를 결합하는 방식에 따라 서로 다른 거리장을 얻는다.

| 거리 | 2차원 식 | 같은 거리의 경계 |
| --- | --- | --- |
| 유클리드 거리 | $\sqrt{x^2+y^2}$ | 원 |
| 맨해튼 거리 | $|x|+|y|$ | 마름모 |
| 체비쇼프 거리 | $\max(|x|,|y|)$ | 축에 평행한 사각형 |

```glsl
float euclidean = length(p);
float manhattan = abs(p.x) + abs(p.y);
float chebyshev = max(abs(p.x), abs(p.y));
```

거리 정의를 바꾸면 같은 임계값을 사용해도 도형의 성격이 달라진다. 거리 함수는 측정뿐 아니라 형태를 만드는 데도 쓰인다.

## 이 절의 핵심

두 좌표의 차이로 기준점에서 대상점으로 향하는 변위 벡터를 구한다. 벡터의 길이는 거리이고, 정규화하면 방향이 되며, `atan2`로 각도를 구할 수 있다. 거리와 각도로 위치를 나타내는 극좌표는 방사형 패턴과 나선 구조에 유용하다.

거리, 방향, 각도는 좌표에서 파생되며 도형, 장, 움직임, 조명 계산에 반복해서 쓰인다. 다음 절에서는 좌표에 깊이 성분을 더하고 3차원 위치가 2차원 화면에 표현되는 과정을 살펴본다.
