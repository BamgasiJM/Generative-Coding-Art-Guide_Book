# 6.6 보간과 블렌딩

보간은 두 값 사이의 중간값을 만든다. 블렌딩은 두 색, 두 패턴, 두 도형의 결과를 어떤 비율로 섞는 과정이다. 둘은 같은 선형식에서 출발하지만, 블렌딩에서는 색 공간과 알파, 마스크의 의미를 함께 고려해야 한다.

## 선형 보간

두 값 $a$, $b$와 혼합 비율 $t$가 있을 때 선형 보간은 다음과 같다.

$$
\operatorname{lerp}(a,b,t)=(1-t)a+tb
$$

```text
blended = interpolate(valueA, valueB, blendFactor)
```

$t=0$이면 A, $t=1$이면 B가 나온다. $t$가 거리 함수나 노이즈에서 나온 마스크라면, 마스크의 공간적 모양이 두 결과의 전환 모양을 결정한다.

## 색 블렌딩

RGB 색은 각 채널을 독립적으로 보간할 수 있다.

```glsl
vec3 color = mix(colorA, colorB, blendFactor);
```

그러나 RGB 값이 감마 보정된 색 공간에 있다면 단순 보간의 중간색이 지각적으로 어둡게 보일 수 있다. 물리적으로 자연스러운 빛의 혼합이 필요하면 선형 색 공간으로 변환해 보간한 뒤 출력 색 공간으로 되돌리는 과정이 필요하다.

색상환의 색조처럼 주기적인 값은 0과 1 또는 0도와 360도의 경계를 넘어 가장 짧은 방향으로 보간해야 한다.

## 패턴 블렌딩

두 패턴을 섞을 때는 각 패턴의 범위가 맞는지 먼저 확인한다.

```text
patternA = normalize(patternA, minA, maxA)
patternB = normalize(patternB, minB, maxB)
result = interpolate(patternA, patternB, blendFactor)
```

한 패턴이 0에서 1 사이이고 다른 패턴이 -1에서 1 사이라면, 같은 비율로 섞어도 한쪽의 영향이 더 커질 수 있다. 값의 의미가 다른 경우에는 정규화보다 의도적인 재매핑이 더 적합할 수 있다.

## 마스크가 만드는 전환

마스크를 보간 비율로 사용하면 두 레이어의 경계가 마스크 모양을 따른다.

```glsl
float blend = 1.0 - smoothstep(-edgeWidth, edgeWidth, shapeDistance);
vec3 color = mix(outsideColor, insideColor, blend);
```

SDF가 음수인 도형 안쪽에서는 `blend`가 1에 가까워지고, 바깥에서는 0에 가까워진다. 같은 마스크로 색뿐 아니라 재질 파라미터, 높이, 노이즈 스케일을 섞을 수 있다.

## 알파 블렌딩과 값 보간의 차이

알파 블렌딩은 전경의 불투명도와 레이어 순서를 포함한다. 반면 단순 보간은 두 값을 대칭적으로 섞는다. 두 색을 0.5로 보간하는 것과, 전경색의 알파를 0.5로 두고 배경 위에 합성하는 것은 색이 프리멀티플라이드인지에 따라 다르게 계산될 수 있다.

```text
// 값 보간
mixedValue = interpolate(a, b, 0.5)

// 전경을 배경 위에 알파 합성
outputColor = foregroundAlpha * foregroundColor
            + (1 - foregroundAlpha) * backgroundColor
```

두 연산을 구분하면 레이어 기반 렌더링과 필드 기반 함수 조합을 혼동하지 않게 된다.

## 블렌드 모드

그래픽 도구는 Multiply, Screen, Overlay, Add 같은 블렌드 모드를 제공한다. 이들은 채널별 수식으로 두 색을 결합한다.

| 방식 | 간단한 표현 | 경향 |
| --- | --- | --- |
| Normal | `mix(A, B, alpha)` | 전경 알파에 따른 기본 합성 |
| Add | $A+B$ | 밝은 부분 강화 |
| Multiply | $AB$ | 어두운 부분 강화 |
| Screen | $1-(1-A)(1-B)$ | 밝은 혼합 |
| Difference | $|A-B|$ | 차이 강조 |

실제 프로그램은 알파와 색 공간을 포함한 세부 규칙을 적용할 수 있다. 블렌드 모드는 시각 효과를 빠르게 만들기 좋지만, 수식 수준에서 어떤 관계를 만드는지 알면 결과를 더 의도적으로 조절할 수 있다.

## 시간에 따라 전환하기

보간 비율을 시간으로 만들면 두 상태 사이의 전환을 만든다.

```text
progress = clamp(elapsedTime / duration, 0, 1)
eased = smoothStep(0, 1, progress)
result = interpolate(stateA, stateB, eased)
```

마스크와 시간을 함께 사용하면 전환이 특정 도형이나 방향을 따라 진행되게 만들 수 있다.

```text
localProgress = progress - distanceToRevealOrigin / revealDistance
blend = smoothStep(0, 1, localProgress)
```

이 식은 중심에서 바깥으로 퍼지는 공개 효과처럼 읽힐 수 있다.

## 이 절의 핵심

보간과 블렌딩은 두 값 사이를 비율로 연결한다. 거리 함수나 마스크를 보간 비율로 쓰면 도형의 경계를 따라 색, 재질, 패턴을 전환할 수 있다.

색 블렌딩에서는 색 공간과 알파 규칙을, 패턴 블렌딩에서는 값의 범위와 의미를 확인해야 한다. 다음 절에서는 SDF의 날카로운 합집합을 부드럽고 유기적인 전환으로 바꾸는 방법을 다룬다.
