# 6.5 마스크와 레이어

도형 함수가 반환하는 값은 색을 칠할 영역을 정하는 마스크로 쓸 수 있다. 마스크의 역할은 도형의 실루엣을 보이는 데 그치지 않는다. 줄무늬, 노이즈, 이미지, 그라데이션, 변위 같은 값을 어느 위치에 얼마나 적용할지 조절하는 제어 신호다.

## 마스크로 값 제한하기

0에서 1 사이의 마스크 $M$과 패턴값 $P$가 있을 때, 곱셈으로 패턴의 세기를 마스크에 따라 조절할 수 있다. 이 방식은 마스크가 0인 곳에서 패턴을 없애고, 중간값에서는 패턴을 부분적으로 남긴다.

$$
R=PM
$$

```text
pattern = patternFunction(position)
mask = shapeMask(position)
result = pattern * mask
```

마스크가 1이면 패턴값이 그대로 유지되고, 0이면 결과가 0이 된다. 중간값은 패턴값에 곱해져 세기를 낮춘다. SDF를 부드러운 마스크로 변환하면 경계 부근에서 마스크가 연속적으로 바뀌어 패턴이 가장자리에서 페이드된다.

## 배경과 전경 섞기

마스크를 보간 비율로 사용하면 배경색과 전경색을 섞을 수 있다. 여기서는 마스크 0이 배경, 1이 전경을 선택하고, 중간값이 두 색을 선형 보간한다.

$$
\mathbf{C}=(1-M)\mathbf{B}+M\mathbf{F}
$$

```text
color = interpolate(backgroundColor, foregroundColor, mask)
```

GLSL의 `mix(a, b, t)`는 이 선형 보간을 제공한다. 이 예제에서 마스크는 두 색 사이의 비율이고, 불투명도와 레이어 순서를 포함하는 알파 합성과는 별도로 생각할 수 있다.

```glsl
vec3 color = mix(backgroundColor, foregroundColor, mask);
```

마스크가 이진값이면 둘 중 하나를 선택하고, 부드러운 값이면 경계에서 색이 섞인다.

## 여러 마스크의 역할 분리

복합 이미지는 하나의 마스크보다 여러 마스크를 역할에 따라 분리하면 다루기 쉽다.

```text
fillMask = shapeFill(signedDistance)
outlineMask = shapeOutline(signedDistance)
shadowMask = offsetShapeShadow(position)
textureMask = materialVariation(position)
```

각 마스크는 채움색, 선색, 그림자, 질감처럼 서로 다른 결과를 조절한다. 채움과 외곽선을 같은 SDF에서 계산하면 두 마스크가 같은 경계를 기준으로 만들어진다. 도형을 이동하거나 크기를 바꿔도 효과들이 같은 윤곽을 따른다.

| 마스크 | 주된 역할 |
| --- | --- |
| 채움 마스크 | 도형 내부 색과 질감 |
| 외곽선 마스크 | 경계 강조 |
| 그림자 마스크 | 깊이와 분리감 |
| 클리핑 마스크 | 다른 패턴의 적용 범위 |
| 전환 마스크 | 두 재질 또는 두 장면의 혼합 비율 |

## 레이어 순서

불투명한 색 레이어는 일반적으로 뒤에서 앞 순서로 쌓인다. 알파가 있는 레이어에서는 뒤쪽 색이 앞쪽 레이어를 통해 얼마나 보이는지가 합성 순서에 따라 달라진다. 다음 식은 불투명한 배경 위에 일반 알파를 사용하는 전경을 합성할 때의 출력 색을 나타낸다.

$$
\mathbf{C}_{out}=\alpha_F\mathbf{C}_F+(1-\alpha_F)\mathbf{C}_B
$$

배경도 투명하다면 출력 알파까지 함께 계산해야 하므로 색 식만으로 합성이 끝나지 않는다. 전경색에 알파를 미리 곱한 프리멀티플라이드 방식은 식의 형태도 달라진다. 두 알파 표현을 섞어 쓰면 투명한 경계에 색 번짐이 생길 수 있으므로 렌더링 파이프라인의 규칙을 확인한다.

## 마스크의 논리 조합

이진 마스크는 논리 연산처럼 조합할 수 있다. 부드러운 마스크에서는 같은 식이 각 위치의 0과 1 사이 값에 적용되어, 경계가 완만한 합집합·교집합·차집합을 만든다.

```text
union = max(maskA, maskB)
intersection = min(maskA, maskB)
difference = maskA * (1 - maskB)
inverse = 1 - maskA
```

부드러운 마스크에서 연산을 고르면 중간값을 어떤 방식으로 결합할지도 결정된다. 곱셈 교집합은 두 마스크가 모두 중간값일 때 결과를 더 낮춘다. `min`은 두 값 중 작은 쪽을 그대로 선택하므로 곱셈보다 완만한 감소를 만든다.

## 실제 라이브러리에서의 마스크

SVG는 `clipPath`, `mask`, `filter`를 제공하고, Canvas 2D는 `globalCompositeOperation`과 클리핑 경로를 제공한다. CSS의 `mask-image`도 요소의 표시 영역을 제한한다. 이 API들은 보통 미리 정의한 경로나 이미지의 알파값을 사용해 표시 범위와 합성 방식을 조절한다.

```javascript
// Canvas 2D 예제
context.save();
context.clip(shapePath);
drawPattern(context);
context.restore();
```

거리 함수 기반 마스크는 경로를 미리 만들지 않고 각 좌표에서 값을 계산한다. 거리값을 조절해 마스크의 폭과 경계를 연속적으로 바꿀 수 있고, 도형의 윤곽에 따라 패턴이나 효과를 제한할 수도 있다.

## 이 절의 핵심

마스크는 색과 패턴을 어디에 얼마나 적용할지 정하는 0에서 1 사이의 값이다. 곱셈은 패턴의 세기를 제한하고, 보간은 배경과 전경을 섞는다. 마스크를 역할별로 나누면 채움, 외곽선, 그림자, 질감을 각각 조절하면서도 같은 도형 경계에 맞출 수 있다.

다음 절에서는 두 값이나 두 색을 연속적으로 섞는 보간과 블렌딩을 더 자세히 다룬다.
