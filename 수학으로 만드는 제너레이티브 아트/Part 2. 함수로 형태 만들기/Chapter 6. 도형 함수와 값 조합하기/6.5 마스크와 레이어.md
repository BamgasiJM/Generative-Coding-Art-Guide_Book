# 6.5 마스크와 레이어

도형 함수가 반환하는 값은 색을 칠할 영역을 정하는 마스크가 될 수 있다. 마스크는 단순히 도형을 보이게 하는 용도에 그치지 않는다. 줄무늬, 노이즈, 이미지, 그라데이션, 변위처럼 어떤 값이 적용될 위치를 제한하는 제어 신호다.

## 마스크로 값 제한하기

0에서 1 사이의 마스크 $M$과 패턴값 $P$가 있을 때, 곱셈은 패턴을 마스크 영역 안으로 제한한다.

$$
R=PM
$$

```text
pattern = patternFunction(position)
mask = shapeMask(position)
result = pattern * mask
```

마스크가 1이면 패턴은 유지되고, 0이면 사라진다. 중간값이면 패턴이 부분적으로 적용된다. SDF를 마스크로 바꾸면 도형의 경계에서도 자연스럽게 페이드되는 제한 영역을 만들 수 있다.

## 배경과 전경 섞기

마스크를 알파처럼 사용하면 배경과 전경 사이를 섞을 수 있다.

$$
\mathbf{C}=(1-M)\mathbf{B}+M\mathbf{F}
$$

```text
color = interpolate(backgroundColor, foregroundColor, mask)
```

GLSL의 `mix(a, b, t)`는 이 선형 보간을 제공한다.

```glsl
vec3 color = mix(backgroundColor, foregroundColor, mask);
```

마스크가 이진값이면 둘 중 하나를 선택하고, 부드러운 값이면 경계에서 색이 섞인다.

## 여러 마스크의 역할 분리

복합 이미지는 하나의 마스크보다 여러 마스크를 역할에 따라 분리하면 다루기 쉽다.

```text
fillMask = shapeFill(signedDistance)
outlineMask = shapeOutline(signedDistance)
shadowMask = offsetShapeShadow(position)
textureMask = materialVariation(position)
```

각 마스크는 다른 색이나 효과에 연결된다. 같은 SDF에서 채움과 외곽선을 만들면 경계를 공유하므로 도형을 바꿔도 레이어가 어긋나지 않는다.

| 마스크 | 주된 역할 |
| --- | --- |
| 채움 마스크 | 도형 내부 색과 질감 |
| 외곽선 마스크 | 경계 강조 |
| 그림자 마스크 | 깊이와 분리감 |
| 클리핑 마스크 | 다른 패턴의 적용 범위 |
| 전환 마스크 | 두 재질 또는 두 장면의 혼합 비율 |

## 레이어 순서

불투명한 색 레이어는 일반적으로 뒤에서 앞 순서로 쌓인다. 알파가 있는 레이어는 순서에 따라 결과가 달라질 수 있다. 한 색의 알파 합성은 흔히 다음과 같이 표현한다.

$$
\mathbf{C}_{out}=\alpha_F\mathbf{C}_F+(1-\alpha_F)\mathbf{C}_B
$$

여기서 전경색이 미리 알파를 곱한 색인지에 따라 실제 식은 달라질 수 있다. 프리멀티플라이드 알파와 일반 알파를 섞어 쓰면 가장자리 색이 어색해질 수 있으므로 렌더링 파이프라인의 규칙을 확인해야 한다.

## 마스크의 논리 조합

이진 마스크는 논리 연산처럼 조합할 수 있고, 부드러운 마스크는 수치 연산으로 비슷한 관계를 만든다.

```text
union = max(maskA, maskB)
intersection = min(maskA, maskB)
difference = maskA * (1 - maskB)
inverse = 1 - maskA
```

부드러운 마스크에서 이 식들은 경계값을 어떻게 다룰지 선택하는 방법이다. 곱셈 교집합은 중간값을 더 어둡게 만들고, `min`은 둘 중 더 약한 영향을 그대로 선택한다.

## 실제 라이브러리에서의 마스크

SVG는 `clipPath`, `mask`, `filter`를 제공하고, Canvas 2D는 `globalCompositeOperation`과 클리핑 경로를 제공한다. CSS의 `mask-image`도 요소의 표시 영역을 제한하는 도구다. 이 API들은 대부분 완성된 경로·이미지·알파 채널을 마스크로 사용한다.

```javascript
// Canvas 2D 예제
context.save();
context.clip(shapePath);
drawPattern(context);
context.restore();
```

거리 함수 기반 마스크는 경로를 미리 만들지 않고 좌표에서 직접 계산하며, 마스크의 폭과 모양을 수식으로 연속적으로 조절할 수 있다.

## 이 절의 핵심

마스크는 색과 패턴이 적용될 영역을 제어하는 0에서 1 사이의 값이다. 곱셈으로 패턴을 제한하고, 보간으로 전경과 배경을 섞으며, 여러 마스크를 역할별 레이어로 분리하면 복합 이미지를 관리하기 쉬워진다.

다음 절에서는 두 값이나 두 색을 연속적으로 섞는 보간과 블렌딩을 더 자세히 다룬다.
