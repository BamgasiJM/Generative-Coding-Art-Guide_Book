# 6.8 복합 형태를 설계하는 방법

여러 도형 함수를 조합하면 복잡한 결과를 만들 수 있지만, 처음부터 많은 연산을 한 식에 넣으면 구조를 이해하고 수정하기 어렵다. 복합 형태는 기본 도형, 좌표 변환, 조합 연산, 시각 레이어를 분리해 단계적으로 설계하는 편이 좋다.

## 1단계: 기본 형태 정하기

먼저 결과를 이루는 가장 단순한 도형을 찾는다. 원, 사각형, 선분, 캡슐, 다각형 중 무엇이 기본 단위인지 정한다.

```text
body = roundedBoxSDF(localPosition, bodySize, cornerRadius)
hole = circleSDF(localPosition, holeCenter, holeRadius)
stem = capsuleSDF(localPosition, stemStart, stemEnd, stemRadius)
```

기본 형태는 가능한 한 표준 좌표계와 명확한 파라미터로 정의한다. 이후 위치나 회전이 필요하면 도형 함수 내부의 상수를 바꾸기보다 좌표 변환 또는 파라미터를 통해 처리한다.

## 2단계: 조합의 의미를 이름으로 표현하기

합성 결과에는 단순한 변수명보다 형태의 역할을 드러내는 이름을 붙인다.

```text
bodyWithHole = difference(body, hole)
mainSilhouette = union(bodyWithHole, stem)
clippedSilhouette = intersection(mainSilhouette, frame)
```

이름만 읽어도 어떤 도형이 남고 어떤 도형이 잘리는지 알 수 있다. 특히 차집합은 순서가 중요하므로 역할 중심의 이름이 오류를 줄인다.

## 3단계: 거리장을 먼저 확인하기

색과 질감을 바로 추가하기 전에 합성된 SDF 자체를 시각화한다. 음수와 양수 영역, 0 경계, 거리의 변화가 의도와 맞는지 확인한다.

```glsl
float d = composedShape(position);
float visualization = 0.5 + 0.5 * tanh(d * distanceScale);
vec3 color = vec3(visualization);
```

`tanh`는 큰 양수와 음수를 0과 1 근처로 압축해 거리의 부호와 변화 범위를 보기 쉽게 한다. 경계는 중간 회색 근처에 나타난다.

## 4단계: 채움과 외곽선 분리하기

형태가 맞으면 SDF에서 채움과 외곽선 마스크를 따로 만든다.

```text
fillMask = sdfToFill(signedDistance, edgeWidth)
outlineMask = sdfToOutline(signedDistance, strokeWidth, edgeWidth)
```

이 분리는 색을 바꾸거나 외곽선만 강조하거나, 내부와 외부에 다른 질감을 적용할 때 유용하다. 형태 함수와 표현 함수가 분리되어 있으므로 같은 도형을 다양한 스타일로 렌더링할 수 있다.

## 5단계: 패턴과 재질 적용하기

도형 내부에만 줄무늬·노이즈·그라데이션을 넣으려면 패턴값과 채움 마스크를 결합한다.

```text
texture = proceduralPattern(position)
interiorColor = colorFromTexture(texture)
color = interpolate(backgroundColor, interiorColor, fillMask)
```

외곽선, 그림자, 글로우는 별도의 마스크로 더한다. 모든 효과를 하나의 거대한 식으로 합치기보다 각 효과의 입력과 범위를 따로 확인하는 것이 좋다.

## 6단계: 파라미터 관계 설계하기

복합 형태의 파라미터는 서로 충돌할 수 있다. 예를 들어 구멍의 반지름이 몸체보다 커지거나, 둥근 모서리 반지름이 사각형의 반크기를 넘을 수 있다. 유효한 관계를 식으로 정의한다.

```text
cornerRadius = min(requestedCornerRadius, min(bodyHalfSize.x, bodyHalfSize.y))
holeRadius = min(requestedHoleRadius, bodyHalfSize.x * 0.8)
strokeWidth = min(requestedStrokeWidth, featureSize * 0.5)
```

좋은 파라미터는 독립적으로 조절되는 값만이 아니라, 형태가 무너지지 않도록 서로를 제한하는 관계까지 포함한다.

## 7단계: 좌표 공간을 분리하기

복합 형태가 여러 부분으로 이루어질 때는 각 부분을 로컬 좌표계에서 정의하는 편이 쉽다.

```text
bodyDistance = bodySDF(toBodyLocal(position))
ornamentDistance = ornamentSDF(toOrnamentLocal(position))
shapeDistance = union(bodyDistance, ornamentDistance)
```

각 부분의 이동·회전·반복 규칙이 분리되므로 형태를 수정하기 쉬워진다. 다음 Part에서 다룰 좌표 변환은 이 구조를 더 확장한다.

## 단계적 설계 예제

둥근 사각형 몸체에 원형 구멍과 캡슐형 손잡이가 있는 2차원 기호를 생각해 보자.

```text
body = roundedBoxSDF(position, bodyCenter, bodyHalfSize, cornerRadius)
hole = circleSDF(position, holeCenter, holeRadius)
handle = capsuleSDF(position, handleStart, handleEnd, handleRadius)

perforatedBody = max(body, -hole)
shape = min(perforatedBody, handle)

fill = sdfToFill(shape, edgeWidth)
outline = sdfToOutline(shape, strokeWidth, edgeWidth)

baseColor = patternColor(position)
color = interpolate(backgroundColor, baseColor, fill)
color = interpolate(color, outlineColor, outline)
```

각 줄은 하나의 역할만 가진다. 몸체를 만들고, 구멍을 빼고, 손잡이를 더하고, 그 결과를 채움과 외곽선으로 표현한다. 이 순서를 유지하면 형태를 바꾸거나 새 장식을 추가할 때 어느 단계에 넣어야 할지 판단하기 쉽다.

## 복잡도를 관리하는 기준

복합 형태가 어려워질 때는 다음 질문으로 구조를 점검한다.

- 이 값은 SDF인가, 마스크인가, 색인가?
- 이 연산은 형태를 바꾸는가, 표현만 바꾸는가?
- 좌표 변환은 어느 도형에만 적용되어야 하는가?
- 차집합에서 남아야 하는 도형은 무엇인가?
- 중간 결과를 시각화했을 때 부호와 경계가 맞는가?
- 파라미터가 유효 범위를 벗어날 때 어떻게 처리되는가?

이 질문들은 복잡한 수식을 작은 단계로 다시 나누는 기준이 된다.

## Chapter 6의 마무리

Chapter 6에서는 도형을 함수값으로 다루고, 산술 연산과 `min`, `max`, 부호 반전으로 도형을 조합하는 방법을 살펴보았다. 마스크와 레이어는 패턴과 색이 적용되는 영역을 정하고, 보간과 블렌딩은 두 값 또는 두 재질 사이의 전환을 만든다. 부드러운 최소값은 형태 자체를 유기적으로 연결한다.

이제 도형 함수와 값 조합의 기반이 마련되었다. 다음 Part에서는 도형 함수를 바꾸지 않고 입력 좌표를 이동·회전·확대·반복해 더 다양한 패턴과 구조를 만드는 방법을 다룬다.
