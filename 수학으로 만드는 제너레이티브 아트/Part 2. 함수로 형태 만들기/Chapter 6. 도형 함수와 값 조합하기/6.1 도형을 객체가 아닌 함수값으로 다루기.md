# 6.1 도형을 객체가 아닌 함수값으로 다루기

객체 중심 그래픽에서는 원, 선, 사각형을 독립적인 대상처럼 다룬다. 각 객체에 위치, 크기, 색을 주고 화면에 배치한다. 거리 함수와 마스크의 관점에서는 도형도 하나의 숫자 함수다. 현재 좌표를 입력받아 안쪽·바깥쪽·경계와의 관계를 값으로 반환한다.

$$
v=f(\mathbf{p})
$$

여기서 $\mathbf{p}$는 현재 좌표, $v$는 도형 함수의 출력이다. 출력은 이진 마스크, 부드러운 마스크, 일반 거리값, SDF일 수 있다.

## 같은 도형을 여러 값으로 표현하기

원의 경우 다음과 같은 서로 다른 함수 표현이 가능하다.

| 표현 | 출력 | 활용 |
| --- | --- | --- |
| 내부 판정 | 0 또는 1 | 이진 마스크 |
| 중심 거리 | 0 이상 | 방사형 그라데이션 |
| 경계 거리 | 0 이상 | 외곽선 |
| SDF | 음수·0·양수 | 채움, 외곽선, 합성 |

```text
centerDistance = length(position - center)
insideMask = centerDistance < radius
edgeDistance = abs(centerDistance - radius)
signedDistance = centerDistance - radius
```

어떤 표현을 선택할지는 만들고 싶은 결과에 따라 달라진다. 단순히 원 안에서만 색을 보이게 하려면 이진 마스크로 충분할 수 있다. 다른 도형과 합성하거나 경계의 거리로 여러 효과를 만들려면 SDF가 적합하다.

## 함수값은 조합할 수 있다

두 도형 함수를 $a(\mathbf{p})$, $b(\mathbf{p})$라고 하자. 두 값에 산술 연산이나 `min`, `max`, 보간을 적용하면 새로운 함수가 된다.

$$
c(\mathbf{p})=g(a(\mathbf{p}),b(\mathbf{p}))
$$

```text
valueA = shapeA(position)
valueB = shapeB(position)
combined = combine(valueA, valueB)
```

중요한 점은 두 함수가 같은 위치에서 평가된다는 것이다. 도형을 이미지로 먼저 렌더링한 뒤 합치는 방식과 달리, 함수값을 합성하면 합성 결과 자체가 새로운 좌표 함수가 된다.

## 값의 종류를 구분하기

조합하기 전에는 각 함수가 무엇을 반환하는지 확인해야 한다. 0과 1의 마스크, 0에서 1 사이의 알파, 실제 거리, SDF는 같은 방식으로 더하거나 비교할 수 없다.

| 값의 종류 | 대표 범위 | 주의할 점 |
| --- | --- | --- |
| 이진 마스크 | 0 또는 1 | 논리 연산처럼 해석 가능 |
| 부드러운 마스크 | 0에서 1 | 곱셈과 보간의 결과가 의미 있음 |
| 일반 거리 | 0 이상 | 안·밖 부호가 없음 |
| SDF | 음수·0·양수 | `min`, `max`로 CSG 가능 |
| 색 | 여러 채널 | 색 공간과 알파 처리 필요 |

예를 들어 SDF 두 개의 합집합은 `min`으로 만들 수 있지만, 이진 마스크의 합집합은 `max` 또는 논리 OR로 만드는 것이 자연스럽다.

## 좌표 변환과 함수 재사용

도형 함수는 보통 원점 근처의 표준 도형으로 작성한다. 위치와 회전, 크기 변경은 함수를 바꾸지 않고 입력 좌표를 변환해 처리한다.

```text
localPosition = inverseTransform(worldPosition, objectTransform)
distanceValue = standardShape(localPosition)
```

이 구조에서는 같은 원 SDF 하나를 여러 위치와 크기에 재사용할 수 있다. Chapter 7에서 좌표 변환을 다루면 이 방식이 더 자연스럽게 연결된다.

## 함수값과 객체 API의 역할

SVG, Canvas 2D, p5.js 같은 드로잉 API는 객체를 직접 배치하는 작업에 편리하다. 반면 GLSL 셰이더, Blender의 노드 기반 재질, Houdini의 볼륨·필드 작업에서는 좌표를 입력으로 한 함수값이 자연스러운 기본 단위가 된다.

```glsl
float circleValue = sdCircle(position, circleCenter, circleRadius);
float boxValue = sdBox(position, boxCenter, boxHalfSize);
```

두 접근은 함께 사용할 수 있다. 예를 들어 객체 API로 입자를 배치하고, 각 입자의 색이나 투명도는 거리 함수로 계산할 수 있다.

## 이 절의 핵심

도형을 함수값으로 다루면 위치마다 도형과의 관계를 숫자로 얻고, 이 숫자를 다른 함수와 조합해 새 형태와 효과를 만들 수 있다. 조합 전에 값이 마스크인지 거리인지 SDF인지 분명히 해야 한다.

다음 절에서는 가장 기본적인 산술 연산인 덧셈, 뺄셈, 곱셈이 패턴과 마스크에 어떤 결과를 만드는지 살펴본다.
