# 6.2 덧셈, 뺄셈, 곱셈으로 만드는 패턴

두 함수값을 더하고 빼고 곱하는 연산은 단순하지만, 제너레이티브 패턴의 구조를 빠르게 바꾼다. 이 연산은 거리값, 파동값, 노이즈, 마스크에 모두 적용할 수 있다. 다만 결과값의 범위와 의미가 바뀌므로, 어떤 종류의 값을 조합하는지 의식해야 한다.

## 덧셈

두 값을 더하면 두 변화가 함께 쌓인다.

$$
c=a+b
$$

```text
combined = valueA + valueB
```

파동을 더하면 여러 주파수가 함께 나타나고, 밝기장을 더하면 밝은 부분이 겹친 곳이 더 밝아진다. 마스크를 단순히 더하면 겹치는 부분이 1보다 커질 수 있으므로 출력 전에 제한하거나, 합집합 목적이라면 `max`를 사용하는 편이 낫다.

```text
brightness = clamp(waveA + waveB, 0, 1)
```

## 뺄셈

뺄셈은 한 값의 영향을 다른 값에서 제거하거나 차이를 강조한다.

$$
c=a-b
$$

두 밝기장의 차이는 어느 패턴이 더 강한지를 보여 주고, 두 거리값의 차이는 대칭이나 경계의 위치를 드러낼 수 있다. 하지만 단순 뺄셈이 SDF의 도형 차집합과 같은 것은 아니다. SDF 차집합에는 부호 반전과 `max`가 필요하며 6.4절에서 다룬다.

```text
contrast = abs(valueA - valueB)
```

절댓값을 취하면 두 값이 얼마나 다른지 나타내는 차이 패턴이 된다. 파동 간섭과 모아레 같은 시각 구조에서 자주 보이는 방식이다.

## 곱셈

곱셈은 두 값이 모두 큰 곳을 강조하고, 하나가 0인 곳을 제거한다.

$$
c=ab
$$

0에서 1 사이의 마스크에서는 곱셈이 부드러운 교집합처럼 작동한다.

```text
intersectionMask = maskA * maskB
```

두 줄무늬 함수를 곱하면 격자나 교차 무늬가 만들어진다.

```text
vertical = sin(position.x * frequencyX)
horizontal = sin(position.y * frequencyY)
pattern = vertical * horizontal
```

값이 -1에서 1 사이이면 곱의 부호도 패턴에 영향을 준다. 밝기에 연결하려면 다시 0에서 1 사이로 옮길 필요가 있다.

$$
b=0.5+0.5c
$$

## 스케일과 오프셋

함수를 조합하기 전에 각 값의 변화 폭과 기준값을 조절할 수 있다.

$$
c=\alpha a+\beta b+\gamma
$$

```text
combined = weightA * valueA + weightB * valueB + offset
```

`weightA`, `weightB`는 각 함수가 결과에 미치는 비중을 정한다. 서로 다른 범위의 값을 그냥 더하면 한 값이 결과를 지배할 수 있으므로, 정규화 또는 가중치를 먼저 고려해야 한다.

## 패턴을 마스크로 제한하기

곱셈은 패턴을 특정 도형 안에만 보이게 하는 데도 쓸 수 있다.

```text
shapeMask = shapeToMask(signedDistance)
stripeValue = stripePattern(position)
output = stripeValue * shapeMask
```

이 구조에서 줄무늬는 화면 전체에 정의되지만, 마스크가 0인 영역에서는 보이지 않는다. GLSL에서는 다음처럼 작성할 수 있다.

```glsl
float stripes = 0.5 + 0.5 * sin(position.x * frequency);
float disk = 1.0 - smoothstep(-edgeWidth, edgeWidth, sdCircle(position, center, radius));
float value = stripes * disk;
```

## 합과 곱의 순서

연산 순서는 결과를 바꾼다.

$$
(a+b)c\ne a+bc
$$

예를 들어 두 파동을 먼저 더한 뒤 마스크를 곱하면 두 파동 전체가 도형 안에 제한된다. 반면 한 파동에만 마스크를 곱한 뒤 다른 파동을 더하면 두 번째 파동은 도형 바깥에도 남는다.

```text
insideOnly = (waveA + waveB) * mask
partialMasking = waveA * mask + waveB
```

복잡한 규칙을 만들 때는 중간값에 이름을 붙여 연산 순서를 드러내는 것이 좋다.

## 실제 라이브러리에서의 대응

GLSL, OSL, Blender Shader Nodes, TouchDesigner의 TOP 연산은 값의 덧셈·곱셈·최솟값·최댓값을 직접 제공한다. 이미지 레이어 합성에서는 Add, Multiply, Subtract 같은 블렌드 모드가 비슷한 역할을 한다.

그러나 이미지 레이어의 블렌드 모드는 색 공간, 알파, 클리핑 규칙을 포함할 수 있다. 순수 함수값 연산과 결과가 항상 같다고 가정하지 말고, 실제 라이브러리의 블렌드 규칙을 확인해야 한다.

## 이 절의 핵심

덧셈은 값을 쌓고, 뺄셈은 차이를 만들며, 곱셈은 두 조건이 함께 만족되는 영역을 강조한다. 이 연산들은 파동과 패턴, 마스크를 조합하는 기본 재료다.

다음 절에서는 특히 SDF에서 중요한 `min`과 `max`를 사용해 도형 경계 자체를 합성하는 방법을 다룬다.
