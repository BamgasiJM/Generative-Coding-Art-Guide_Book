# 6.7 부드러운 합성과 전환

일반적인 SDF 합집합은 `min(dA, dB)`로 만든다. 이 연산은 합집합의 영역과 경계를 간결하게 정하지만, 두 경계가 만나는 부분에는 날카로운 접합선이 생긴다. 유기적인 형태나 액체처럼 이어지는 덩어리를 만들려면 두 거리값이 가까운 구간에서 부드럽게 섞을 수 있다.

## 부드러운 최소값

널리 쓰이는 다항식 기반 부드러운 최소값의 한 형태는 다음과 같다.

$$
h=\operatorname{clamp}\left(\frac{1}{2}+\frac{d_B-d_A}{2k},0,1\right)
$$

$$
d=\operatorname{lerp}(d_B,d_A,h)-kh(1-h)
$$

$d_A$와 $d_B$는 같은 좌표에서 평가한 두 도형의 거리값이고, $h$는 두 값의 차이를 0에서 1 사이로 제한한 혼합 비율이다. 두 거리값의 차이가 충분히 크면 작은 값이 선택되어 일반적인 `min`처럼 동작하고, 값이 가까우면 두 값이 함께 반영되어 접합부가 둥글어진다. $k$는 양수로 두며 부드러운 전환의 폭을 정한다. $k$가 0에 가까워질수록 일반적인 `min`에 가까워지고, 커질수록 전환 구간이 넓어진다.

```glsl
float smoothMin(float a, float b, float k) {
    float h = clamp(0.5 + 0.5 * (b - a) / k, 0.0, 1.0);
    return mix(b, a, h) - k * h * (1.0 - h);
}
```

```glsl
float blendedShape = smoothMin(circleDistance, boxDistance, blendRadius);
```

이 연산은 합집합의 부호와 경계를 부드럽게 바꾸지만, 결과값의 크기가 모든 위치에서 합성 경계까지의 정확한 최단 거리인 것은 아니다. 따라서 외곽선 폭이나 레이 마칭처럼 거리값의 크기를 직접 사용하는 경우에는 근사값이라는 점을 고려한다.

## 부드러운 합집합의 성격

부드러운 최소값은 두 경계가 가까운 구간에 새로운 경계를 만든다. 입력 거리값이 함께 반영되면서 합성된 함수의 0 경계가 한 형태에서 다른 형태로 이어진다.

| `k`의 크기 | 결과 |
| --- | --- |
| 작음 | 거의 날카로운 합집합 |
| 중간 | 접합부가 둥글게 이어짐 |
| 큼 | 원래 도형의 윤곽이 크게 섞임 |

`k`는 거리값과 같은 좌표 단위를 가진다. 따라서 정규화 좌표에서 쓰는 값과 픽셀 좌표에서 쓰는 값은 서로 다를 수 있다. 좌표 단위를 바꾸면 `k`도 같은 비율로 조정해야 비슷한 모양의 접합부를 얻는다.

## 부드러운 최대값과 차집합

부호 반전은 내부와 외부를 뒤집는다. 이 성질을 이용해 부드러운 최대값을 부드러운 최소값으로 표현할 수 있다.

$$
\operatorname{smoothMax}(a,b,k)=-\operatorname{smoothMin}(-a,-b,k)
$$

이를 사용하면 부드러운 교집합과 차집합을 정의할 수 있다. 합집합에서처럼 두 입력은 같은 위치에서 평가한 거리값이어야 하며, 전환 폭 $k$는 양수여야 한다.

```text
smoothIntersection = smoothMax(distanceA, distanceB, k)
smoothDifference = smoothMax(distanceA, -distanceB, k)
```

부드러운 차집합은 구멍의 경계가 날카롭게 잘리는 대신 둥글게 이어지거나 오목하게 파인 형태를 만든다. $k$가 커지면 이 둥근 전환이 구멍과 주변 경계에 더 넓게 나타난다.

## 마스크 전환과 SDF 전환의 차이

두 마스크를 `mix(maskA, maskB, t)`로 섞으면 두 이미지의 색이나 투명도가 바뀐다. 반면 두 SDF를 부드러운 최소값으로 합성하면 합성 결과의 0 경계와 내부 영역이 바뀐다.

```text
// 시각적 레이어 전환
maskBlend = interpolate(maskA, maskB, t)

// 기하학적 형태 전환
shapeBlend = smoothMin(distanceA, distanceB, k)
```

두 방식은 모두 부드럽게 보일 수 있지만 조절하는 대상이 다르다. 마스크 블렌딩은 이미 정의된 두 시각 결과의 혼합 비율을 바꾸고, SDF 합성은 새로운 도형 경계를 만든다.

## 시간에 따라 합성 폭 바꾸기

부드러운 합성의 폭 $k$를 시간에 따라 바꾸면 접합부가 넓어지거나 좁아져 도형이 녹았다 굳는 듯한 움직임을 만든다. 보간값 `wave01`은 0에서 1 사이로 두고, `minBlend`와 `maxBlend`도 유효한 양수 범위로 정한다.

```text
blendRadius = interpolate(minBlend, maxBlend, wave01)
shapeDistance = smoothMin(shapeA, shapeB, blendRadius)
```

합성 폭이 0이면 수식의 분모가 0이 되고, 매우 작은 값도 수치 오차를 키울 수 있다. 실제 구현에서는 입력을 양수인 최솟값 이상으로 제한한다.

```text
safeK = max(blendRadius, epsilon)
```

실제 호출에서는 원래 `blendRadius` 대신 이 `safeK`를 `smoothMin`의 세 번째 인자로 전달한다.

## 부드러운 전환 마스크

SDF 자체를 합성하지 않아도, 두 색이나 두 패턴 사이의 전환 마스크를 부드럽게 만들 수 있다.

```glsl
float blend = smoothstep(-transitionWidth, transitionWidth, distanceValue);
vec3 color = mix(insideColor, outsideColor, blend);
```

`transitionWidth`는 색이 섞이는 거리 범위를 정하며, 코드의 전환 구간은 그 값의 양쪽으로 뻗는다. 앞의 `k`는 두 SDF를 결합해 경계를 둥글게 만드는 거리 범위를 정한다. 둘 다 좌표 단위를 쓰지만 조절하는 결과는 다르다.

## 실제 라이브러리의 대응

Blender의 Metaball, Geometry Nodes의 볼륨·필드 연산, Houdini의 VDB SDF 연산은 부드럽게 합쳐지는 형태를 만들 때 자주 사용된다. 셰이더에서는 위와 같은 `smoothMin` 함수를 직접 구현하는 방식이 일반적이다.

SVG나 Canvas 2D의 기본 도형 합성은 보통 날카로운 경계를 유지한다. 부드러운 결합이 필요하면 블러·필터를 적용하거나, 거리장·마스크 기반 렌더링을 사용한다.

## 이 절의 핵심

부드러운 최소값은 두 SDF의 날카로운 합집합을 넓은 전환 구간으로 바꾼다. 이는 투명도 블렌딩이 아니라 도형 경계 자체를 연속적으로 합성하는 방법이다.

다음 절에서는 지금까지의 도형 함수와 합성 연산을 실제 복합 형태의 설계 절차로 정리한다.
