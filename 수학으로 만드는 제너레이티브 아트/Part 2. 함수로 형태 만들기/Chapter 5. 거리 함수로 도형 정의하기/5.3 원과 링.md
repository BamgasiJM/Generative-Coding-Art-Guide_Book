# 5.3 원과 링

원은 중심점에서 같은 거리에 있는 점들의 집합이다. 이 단순한 정의는 거리 함수의 기본 예제이면서, 방사형 패턴과 마스크, 고리, 글로우를 만드는 출발점이 된다.

## 원의 거리 함수

현재 위치 $\mathbf{p}$, 원의 중심 $\mathbf{c}$, 반지름 $r$가 있을 때 중심까지의 거리는 다음과 같다.

$$
d_{center}=\lVert\mathbf{p}-\mathbf{c}\rVert
$$

원 경계까지의 부호 있는 거리는 중심까지의 거리에서 반지름을 뺀 값이다.

$$
d_{circle}=\lVert\mathbf{p}-\mathbf{c}\rVert-r
$$

경계에서는 0이고, 원 안에서는 음수, 원 밖에서는 양수다.

```glsl
float sdCircle(vec2 position, vec2 center, float radius) {
    return length(position - center) - radius;
}
```

이 함수는 GLSL에서 바로 사용할 수 있는 SDF 형태다. 다른 셰이딩 언어에서도 `length`와 벡터 뺄셈이 있다면 같은 원리로 구현할 수 있다.

## 채워진 원

SDF가 0보다 작은 곳은 원 안쪽이다. 이를 마스크로 바꾸면 채워진 원이 된다.

```glsl
float d = sdCircle(position, center, radius);
float fillMask = 1.0 - smoothstep(-edgeWidth, edgeWidth, d);
```

`edgeWidth`가 작을수록 경계가 선명해진다. `step(d, 0.0)` 같은 단단한 비교로도 만들 수 있지만, 해상도 변화에 따라 가장자리가 거칠어질 수 있다.

## 원의 외곽선

SDF의 절댓값은 경계까지의 거리를 나타낸다.

$$
e=|d_{circle}|
$$

```glsl
float outline = 1.0 - smoothstep(
    strokeWidth,
    strokeWidth + edgeWidth,
    abs(d)
);
```

여기서 `strokeWidth`는 경계 중심에서 바깥과 안쪽으로 퍼지는 반폭이다. 화면에서 최종 선 두께를 일정하게 유지하려면 좌표계의 스케일과 픽셀 크기를 고려해야 한다.

## 링 만들기

링은 안쪽 반지름과 바깥쪽 반지름 사이의 영역이다. 두 원의 마스크를 조합해 만들 수 있다.

```glsl
float outer = 1.0 - smoothstep(outerRadius - w, outerRadius + w, centerDistance);
float inner = smoothstep(innerRadius - w, innerRadius + w, centerDistance);
float ring = outer * inner;
```

또는 중간 반지름과 두께를 사용해 SDF 형태로 정의할 수 있다.

$$
d_{ring}=\left|\lVert\mathbf{p}-\mathbf{c}\rVert-r_m\right|-h
$$

$r_m$은 링의 중심 반지름이고, $h$는 두께의 절반이다. 이 값이 0보다 작으면 링 내부에 있다.

```glsl
float sdRing(vec2 position, vec2 center, float midRadius, float halfWidth) {
    float centerDistance = length(position - center);
    return abs(centerDistance - midRadius) - halfWidth;
}
```

## 방사형 그라데이션

원 SDF는 경계뿐 아니라 중심에서 바깥으로 변하는 값도 제공한다. 중심 거리를 반지름으로 나누면 원 내부에서 대략 0에서 1 사이의 비율을 얻는다.

$$
t=\frac{\lVert\mathbf{p}-\mathbf{c}\rVert}{r}
$$

```glsl
float t = clamp(length(position - center) / radius, 0.0, 1.0);
vec3 color = mix(centerColor, edgeColor, t);
```

중심을 밝게 하거나 어둡게 만드는 것, 색을 여러 구간으로 나누는 것, 거리값을 제곱해 대비를 바꾸는 것은 모두 Chapter 3에서 다룬 값 변환으로 설명할 수 있다.

## 반복 고리와 파동

거리값에 사인 함수나 소수부 함수를 적용하면 원형으로 반복되는 고리를 만들 수 있다.

```glsl
float centerDistance = length(position - center);
float rings = 0.5 + 0.5 * sin(centerDistance * frequency - time * speed);
```

이 패턴은 원래 1차원 파동이었지만, 입력을 x좌표 대신 중심에서의 거리로 바꾸었기 때문에 동심원 파동이 된다. 이 원리는 Chapter 4의 2차원 파동과 직접 연결된다.

## 실제 라이브러리에서의 원

객체 중심 라이브러리에서는 원의 중심과 지름을 직접 전달한다. p5.js의 `circle(x, y, diameter)`, Canvas 2D의 `arc()`, SVG의 `<circle>`이 대표적이다. 이런 API는 원 하나를 빠르게 배치할 때 적합하다.

```javascript
// p5.js 예제
circle(centerX, centerY, radius * 2);
```

거리 함수 방식은 각 픽셀 또는 표면 위치에서 원과의 관계를 계산한다. 따라서 원 하나에 채움, 외곽선, 마스크, 거리 기반 색, 다른 SDF와의 합성을 자연스럽게 결합할 수 있다.

## 이 절의 핵심

원 SDF는 중심까지의 거리에서 반지름을 뺀 값이다. 음수는 안쪽, 0은 경계, 양수는 바깥쪽을 뜻한다.

$$
d_{circle}=\lVert\mathbf{p}-\mathbf{c}\rVert-r
$$

이 값으로 채움, 외곽선, 링, 방사형 그라데이션, 동심원 파동을 만들 수 있다. 다음 절에서는 점에서 선분까지의 최단 거리를 이용해 선과 캡슐을 정의한다.
