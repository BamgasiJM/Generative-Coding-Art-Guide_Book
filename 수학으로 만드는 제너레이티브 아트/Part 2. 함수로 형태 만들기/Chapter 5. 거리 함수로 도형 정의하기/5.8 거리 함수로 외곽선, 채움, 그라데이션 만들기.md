# 5.8 거리 함수로 외곽선, 채움, 그라데이션 만들기

거리 함수의 핵심 장점은 하나의 값에서 여러 시각 효과를 만들 수 있다는 점이다. 부호 있는 거리값은 안쪽과 바깥쪽을 구분하고, 절댓값은 경계까지의 거리를 알려 준다. 이 값을 채움 마스크, 외곽선 폭, 색과 투명도의 변화에 연결하면 서로 다른 효과가 같은 경계를 따르게 된다. 거리값과 직접 비교하는 폭·오프셋 파라미터는 같은 좌표 단위를 사용해야 한다.

이 절에서는 거리 함수 자체를 새로 정의하기보다, 계산한 거리값을 시각 요소에 연결하는 방법을 정리한다.

## 채움

SDF에서 음수 영역이 도형 내부다. 0 부근에 부드러운 전환 폭을 두면 채움 마스크를 만들 수 있다.

```glsl
float fillMask(float d, float edgeWidth) {
    return 1.0 - smoothstep(-edgeWidth, edgeWidth, d);
}
```

`d`가 `-edgeWidth`보다 작으면 마스크는 1에 가깝고, `edgeWidth`보다 크면 0에 가깝다. 그 사이에서 값이 부드럽게 바뀌어 경계가 픽셀 격자에 걸릴 때도 계단 현상을 줄인다.

단단한 채움이 필요하면 다음처럼 비교할 수 있다.

```text
fill = 1 if signedDistance < 0 else 0
```

부드러운 채움은 경계의 안티앨리어싱이나 안팎으로 사라지는 페이드에 유용하다. 단단한 채움은 값이 0 또는 1인 이진 마스크나 영역 판정에 적합하지만, 별도 처리가 없으면 화면 경계가 계단처럼 보일 수 있다.

## 외곽선

경계에서의 거리는 SDF의 절댓값이다. 부호를 없애면 경계 안쪽과 바깥쪽에서 같은 거리에 있는 점을 같은 거리값으로 다룰 수 있다.

$$
e=|d|
$$

`e`가 선의 반폭보다 작은 영역을 선택하면 외곽선이 된다.

```glsl
float outlineMask(float d, float halfStroke, float edgeWidth) {
    return 1.0 - smoothstep(
        halfStroke,
        halfStroke + edgeWidth,
        abs(d)
    );
}
```

`halfStroke`는 경계에서 안쪽과 바깥쪽으로 각각 뻗는 반폭이므로, 완전히 불투명한 띠의 전체 폭은 약 두 배다. `edgeWidth`는 그 띠 바깥에서 마스크가 부드럽게 사라지는 전이 폭이다.

외곽선 마스크만으로는 경계 양쪽에 띠가 생긴다. 안쪽에만 넣으려면 음수 영역 마스크와 곱하고, 바깥쪽에만 넣으려면 양수 영역 마스크와 곱한다.

```text
insideOutline = outlineMask * insideMask
outsideOutline = outlineMask * outsideMask
```

## 거리 기반 그라데이션

거리값을 원하는 폭으로 나누고 0에서 1 사이로 제한하면 경계에서 안쪽 또는 바깥쪽으로 퍼지는 그라데이션을 만들 수 있다. 아래 예제에서는 경계에서 `t=0`, `gradientWidth`만큼 떨어진 곳에서 `t=1`이 된다.

```glsl
float outsideDistance = max(d, 0.0);
float t = clamp(outsideDistance / gradientWidth, 0.0, 1.0);
vec3 color = mix(edgeColor, outerColor, t);
```

안쪽 그라데이션은 음수 거리의 부호를 뒤집어 사용한다.

```glsl
float insideDistance = max(-d, 0.0);
float t = clamp(insideDistance / gradientWidth, 0.0, 1.0);
vec3 color = mix(edgeColor, innerColor, t);
```

`gradientWidth`는 도형의 크기와 별도로 조절할 수 있다. 같은 SDF라도 폭이 좁으면 경계에 붙은 선명한 색 띠가 되고, 넓으면 안쪽이나 바깥쪽으로 천천히 번지는 색 변화가 된다. 색을 더 바깥까지 연장하거나 투명도에 연결하면 안개나 글로우 같은 효과도 만들 수 있다.

## 글로우

도형 바깥의 거리값을 사용하면 경계에서 멀어질수록 약해지는 빛을 만들 수 있다. 양수인 $k$가 클수록 글로우가 빠르게 약해지고, 작을수록 더 멀리 퍼진다. `glowDecay`의 단위는 거리의 역수여서 지수 안의 값이 단위 없는 수가 된다.

$$
g=e^{-kd_{out}}
$$

```glsl
float outsideDistance = max(d, 0.0);
float glow = exp(-glowDecay * outsideDistance);
vec3 color = baseColor + glowColor * glow;
```

`max(d, 0.0)`은 도형 안쪽에서 거리를 0으로 만들기 때문에 위 식의 `glow`는 안쪽 전체에서 1이 된다. 빛을 경계 바깥에만 보이게 하려면 결과에 바깥 영역 마스크를 곱한다.

글로우를 색에 더하면 채널 값이 1을 넘는 고휘도 색이 생길 수 있다. HDR 파이프라인에서는 이를 보존한 뒤 톤 매핑이나 블룸으로 표현할 수 있다. 출력이 0에서 1 범위로 제한된다면 색을 자르거나, 더하기 대신 알파 혼합처럼 범위를 관리하는 합성 방식을 선택한다.

## 그림자

도형의 SDF를 오프셋한 좌표에서 평가하면 단순한 드롭 섀도를 만들 수 있다. `position - shadowOffset`은 그림자를 `shadowOffset` 방향으로 옮긴 것과 같은 결과를 낸다.

```glsl
float shadowDistance = shapeSDF(position - shadowOffset);
float shadowMask = 1.0 - smoothstep(-softness, softness, shadowDistance);
```

`softness`는 SDF와 같은 거리 단위를 사용한다. 식은 `-softness`에서 `softness`까지, 매개변수의 두 배 폭에 걸쳐 그림자 마스크를 전환한다. 실제 그림자는 광원, 가림, 표면 방향을 포함한 더 복잡한 문제다. 여기서는 도형을 옮긴 마스크를 흐리게 만든 것이므로, 2차원 그래픽의 장식적인 그림자나 마스크 오프셋 효과에 적합하다.

## 반복 경계와 등고선

거리값에 반복 주파수를 곱한 뒤 소수 부분만 취하면 일정 간격으로 반복되는 띠를 만들 수 있다. `repeatFrequency`가 클수록 띠 간격이 좁아지고, `contourWidth`는 각 반복 구간 안에서 선이 차지하는 비율을 정한다.

```glsl
float repeated = fract(abs(d) * repeatFrequency);
float contour = 1.0 - smoothstep(0.0, contourWidth, repeated);
```

원 SDF에 적용하면 동심원, 사각형 SDF에 적용하면 사각형을 따라가는 등고선이 된다. 복잡한 SDF에서는 해당 도형의 경계를 따라 반복 무늬가 형성된다. 절댓값을 사용했으므로 이 예제는 경계 안쪽과 바깥쪽 양쪽에 띠를 만든다.

거리값의 절댓값 대신 부호를 유지하면 안쪽과 바깥쪽에 서로 다른 반복 규칙을 적용할 수 있다.

## 거리로 변위 만들기

거리값은 색뿐 아니라 표면의 높이를 정하는 값으로도 쓸 수 있다. 이 식에서는 경계에서 높이가 가장 크고, 안팎으로 멀어질수록 지수적으로 낮아진다.

```text
height = amplitude * exp(-decay * abs(signedDistance))
```

양수인 `amplitude`는 경계에서의 높이를, 양수인 `decay`는 안팎으로 높이가 줄어드는 속도를 조절한다. 현재 식은 경계 양쪽에서 솟은 띠를 만든다. 내부나 외부에만 효과를 제한하려면 부호로 적용 영역을 선택한다. 높이의 부호를 뒤집으면 릿지를 홈으로 바꿀 수 있고, 안쪽 높이를 일정하게 제한하면 평평한 판을 만들 수 있다. 3차원 재질에서 값이 너무 급하게 변하면 픽셀 수준의 계단 현상이 생길 수 있으며, 메시 변위에서는 메시가 충분히 조밀하지 않을 때 표면이 계단처럼 보일 수 있다.

## 하나의 SDF에서 여러 레이어 만들기

채움, 외곽선, 글로우를 같은 거리값에서 계산해 결합할 수 있다.

```glsl
float d = shapeSDF(position);
float fill = fillMask(d, edgeWidth);
float outline = outlineMask(d, strokeWidth, edgeWidth);
float glow = exp(-glowDecay * max(d, 0.0));

vec3 color = mix(backgroundColor, fillColor, fill);
color = mix(color, outlineColor, outline);
color += glowColor * glow;
```

`mix`의 세 번째 인자는 두 색 사이를 보간하는 마스크다. 따라서 채움과 외곽선은 각 마스크 값에 따라 배경·채움색·외곽선색을 섞고, 글로우는 더하기로 합성한다. 글로우를 도형 바깥에만 표시하려면 앞 절의 설명처럼 바깥 영역 마스크를 곱한다. 거리값 하나를 여러 레이어에 공유하면 도형의 위치나 크기를 바꿀 때 효과들이 경계에 맞춰 함께 움직여, 서로의 관계를 관리하기 쉽다.

## 실제 라이브러리의 대응 기능

SVG와 Canvas 2D는 채움, 선, 선형·방사형 그라데이션, 그림자를 API로 제공한다. SVG의 `fill`, `stroke`, `stroke-width`, `filter`는 여기서 만든 채움·외곽선·효과와 비슷한 시각 역할을 한다. 다만 이 API들은 보통 도형 객체를 그리며, 거리 함수처럼 임의의 좌표마다 경계까지의 거리를 반환하지는 않는다.

거리 함수 방식은 이 기능들을 대체하기보다, 기본 도형이 아닌 프로시저럴 형태에도 같은 효과를 적용하거나 픽셀 수준의 제어가 필요할 때 사용한다.
