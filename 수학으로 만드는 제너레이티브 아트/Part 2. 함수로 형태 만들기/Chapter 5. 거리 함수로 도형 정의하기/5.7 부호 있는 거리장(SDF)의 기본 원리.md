# 5.7 부호 있는 거리장(SDF)의 기본 원리

부호 있는 거리장(Signed Distance Field, SDF)은 공간의 각 위치에서 가장 가까운 도형 경계까지의 거리와 점이 경계의 안쪽인지 바깥쪽인지 함께 나타내는 함수다. 일반적인 거리값은 0 이상이지만, SDF는 음수와 양수로 위치 관계를 구분한다. 도형의 경계에서는 값이 0이다.

$$
d(\mathbf{p})
\begin{cases}
<0, & \text{도형 안쪽} \\
=0, & \text{경계 위} \\
>0, & \text{도형 바깥쪽}
\end{cases}
$$

좌표마다 이 값을 계산하면 채움, 외곽선, 그림자, 글로우를 만들고 도형을 합성할 수 있다. 거리값을 따라 광선을 이동시키는 레이 마칭에도 기초 정보로 쓰인다.

## SDF가 거리장인 이유

“장(field)”은 공간의 각 위치에 값을 대응시키는 함수를 뜻한다. 온도장은 위치마다 온도를, 방향장은 위치마다 방향 벡터를 갖는다. SDF는 위치마다 도형 경계까지의 부호 있는 거리를 대응시킨다. 모든 위치의 값을 미리 저장할 수도 있고, 필요한 위치에서 함수로 계산할 수도 있다.

```text
for each position p:
    field[p] = signedDistanceToShape(p)
```

SDF를 이미지로 나타내면 0인 점들의 집합이 경계가 된다. 2차원에서는 이 집합이 등고선, 즉 영등위선이고, 3차원에서는 등위면이 된다. 안쪽과 바깥쪽은 부호로 나뉘며, 값의 절댓값이 작을수록 경계에 가깝다.

## 정확한 SDF와 거리 추정 함수

일부 함수는 가장 가까운 경계까지의 유클리드 거리를 정확히 반환한다. 원과 축 정렬 사각형의 표준 SDF가 대표적이다. 반면 복잡한 변형이나 도형 합성에서는 부호와 경계 위치는 표현하더라도 모든 위치에서 정확한 최단 거리를 반환하지 않는 경우가 있다. 이런 함수를 거리 추정 함수라고 부른다.

경계 근처의 부호와 거리가 충분히 정확하다면 채움이나 외곽선에는 근사값도 쓸 수 있다. 레이 마칭에서는 현재 위치의 거리값만큼 광선을 전진시키므로, 거리를 실제로 안전하게 전진할 수 있는 양보다 크게 추정하면 경계를 건너뛸 수 있다. 추정 오차를 고려해 전진 거리에 안전 계수를 적용하거나, 경계를 넘지 않는 거리 추정 함수를 사용해야 한다.

## SDF의 기본 도형

원과 사각형의 SDF는 다음과 같다.

$$
d_{circle}(\mathbf{p})=\lVert\mathbf{p}-\mathbf{c}\rVert-r
$$

```glsl
float sdCircle(vec2 p, vec2 center, float radius) {
    return length(p - center) - radius;
}
```

원 공식은 중심까지의 거리에서 반지름을 뺀다. 따라서 반지름과 같은 거리에 있는 경계에서는 0, 원 안에서는 음수, 바깥에서는 양수를 반환한다.

```glsl
float sdBox(vec2 p, vec2 center, vec2 halfSize) {
    vec2 q = abs(p - center) - halfSize;
    return length(max(q, 0.0)) + min(max(q.x, q.y), 0.0);
}
```

사각형 함수는 5.5절에서 살펴본 것처럼 중심 기준 좌표에서 반크기를 뺀 뒤 바깥쪽 거리와 안쪽 거리를 결합한다. 두 함수 모두 음수는 내부, 0은 경계, 양수는 외부를 나타내므로 반환값을 같은 채움·외곽선 연산에 연결할 수 있다.

## 0값의 경계

SDF에서 도형의 윤곽은 $d(\mathbf{p})=0$을 만족하는 점들의 집합이다. 2차원에서는 이를 등위선 또는 영등위선이라고 한다. 부호 있는 거리의 값이 같은 점들을 모아도 경계 안팎의 여러 띠를 나타낼 수 있다.

```text
boundary if abs(signedDistance) is near zero
inside if signedDistance is negative
outside if signedDistance is positive
```

부동소수점 계산에서는 값이 정확히 0인지 검사하기보다 허용 오차를 둔다. 화면에 경계를 그릴 때는 이 범위를 선 두께나 픽셀 크기와 연결해, 좌표 단위와 출력 해상도에 맞춘다.

## SDF에서 마스크 만들기

SDF를 채움 마스크로 바꾸는 가장 기본적인 방식은 0을 경계로 값을 뒤집는 것이다.

```glsl
float fillMask = 1.0 - smoothstep(-edgeWidth, edgeWidth, distanceValue);
```

음수 쪽이 도형 안이므로 `distanceValue`가 작을수록 마스크는 1에 가깝고, 양수 쪽에서는 0에 가까워진다. `smoothstep`은 `-edgeWidth`에서 `edgeWidth`까지 마스크를 부드럽게 전환한다. 화면 미분값으로 `edgeWidth`를 정하면 이 전환 폭을 대략 한 픽셀에 맞출 수 있어 확대와 축소에도 경계가 비교적 안정적이다.

```glsl
float edgeWidth = fwidth(distanceValue);
float fillMask = 1.0 - smoothstep(-edgeWidth, edgeWidth, distanceValue);
```

`fwidth`는 GLSL의 화면 미분 함수로, 인접 픽셀 사이에서 값이 얼마나 변하는지 추정한다. 따라서 거리값의 변화량을 화면상의 픽셀 폭에 맞춘 전환 폭으로 사용할 수 있다. CPU 기반 드로잉 API에서는 직접 이 계산을 구현하기보다 렌더러의 안티앨리어싱이나 고해상도 렌더링을 사용하는 편이 보통 간단하다.

## SDF의 장점

| 장점 | 설명 |
| --- | --- |
| 해상도 독립성 | 함수로 계산하면 여러 해상도에서 같은 형태를 평가할 수 있다. |
| 경계 정보 | 안·밖·경계까지의 거리를 한 값으로 얻는다. |
| 합성 가능성 | `min`, `max`, 부호 반전으로 도형을 조합할 수 있다. |
| 효과 확장성 | 채움, 외곽선, 글로우, 그림자, 변위를 같은 값에서 만든다. |
| 셰이더 적합성 | 픽셀마다 독립적으로 계산하기 좋다. |

`min`, `max`, 부호 반전으로 도형의 합집합·교집합·차집합을 표현할 수 있다. 이 연산은 합성된 도형의 안팎과 경계를 나타내지만, 겹치는 부분을 포함한 모든 위치에서 결과가 실제 최단 거리와 같다고 보장하지는 않는다. 그런 경우 결과를 정확한 SDF가 아니라 거리 추정값으로 다뤄야 한다.

SDF가 항상 객체 드로잉보다 좋은 것은 아니다. 복잡한 벡터 경로나 텍스트를 정밀하게 편집하거나 수많은 독립 객체를 관리할 때는 기존 그래픽 API와 벡터 도구가 더 적합할 수 있다.

## SDF와 이미지 거리장

SDF는 수식으로 필요한 좌표에서 계산할 수도 있고, 이미지 텍스처에 미리 저장할 수도 있다. 폰트 렌더링에서는 글리프 윤곽의 거리장을 텍스처에 저장해 여러 크기에서 글자를 표시하는 데 활용한다. 텍스처 해상도와 저장한 거리 범위 안에서 가장 잘 동작하므로, 어떤 크기에서나 원본 윤곽을 완벽하게 복원하는 것은 아니다.

이미지 SDF를 샘플링할 때는 텍스처 값이 실제 거리인지, 특정 범위로 정규화된 거리인지 확인해야 한다. 정규화된 값은 좌표 단위의 거리로 되돌린 뒤 외곽선 폭이나 글로우 범위와 비교해야 한다. 다중 채널 거리장(MSDF)은 모서리와 복잡한 윤곽을 선명하게 보존하기 위해 채널마다 다른 경계 구간의 거리 정보를 저장한다. 샘플링한 채널 값의 중간값을 사용해 거리값을 복원하는 방식이 일반적이다.

## 이 절의 핵심

SDF는 경계까지의 거리와 도형 안팎 정보를 하나의 부호 있는 값에 담는다. 음수는 안쪽, 0은 경계, 양수는 바깥쪽이다. 이 공통된 표현으로 도형마다 별도의 채움·외곽선 규칙을 만들지 않고 같은 연산을 적용할 수 있으며, 거리값은 그림자나 글로우 같은 효과에도 연결된다.

다음 절에서는 SDF와 일반 거리값을 채움, 외곽선, 그라데이션으로 연결하는 구체적인 표현 방법을 정리한다.
