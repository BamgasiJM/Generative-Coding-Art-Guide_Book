# 5.7 부호 있는 거리장(SDF)의 기본 원리

부호 있는 거리장(Signed Distance Field, SDF)은 공간의 각 위치에 “가장 가까운 경계까지의 거리”와 “경계의 안쪽·바깥쪽” 정보를 함께 저장하거나 계산하는 함수다. 일반 거리값이 항상 0 이상인 데 비해, SDF는 부호로 위치 관계를 표현한다.

$$
d(\mathbf{p})
\begin{cases}
<0, & \text{도형 안쪽} \\
=0, & \text{경계 위} \\
>0, & \text{도형 바깥쪽}
\end{cases}
$$

이 하나의 값으로 채움, 외곽선, 그림자, 글로우, 도형 합성, 레이 마칭의 기초를 만들 수 있다.

## SDF가 거리장인 이유

“장(field)”은 공간의 각 위치에 값을 부여하는 함수를 뜻한다. 온도장에서는 위치마다 온도가 있고, 방향장에서는 위치마다 방향 벡터가 있다. SDF에서는 위치마다 경계까지의 부호 있는 거리가 있다.

```text
for each position p:
    field[p] = signedDistanceToShape(p)
```

SDF를 이미지로 시각화하면 경계는 0값의 등고선이 되고, 안쪽과 바깥쪽은 서로 다른 부호의 영역이 된다. 값의 절댓값이 작을수록 경계에 가깝다.

## 정확한 SDF와 거리 추정 함수

어떤 함수는 실제 최단 거리를 정확히 반환한다. 원과 축 정렬 사각형의 표준 SDF가 대표적이다. 반면 일부 복잡한 변형 함수는 경계까지의 정확한 거리 대신 부호와 대략적인 거리를 반환한다. 이를 거리 추정 함수라고 부르기도 한다.

채움과 외곽선만 만들 때는 근사값도 충분할 수 있다. 하지만 레이 마칭처럼 거리값만큼 이동하는 알고리즘에서는 거리를 과대평가하면 경계를 건너뛸 수 있으므로, 정확도와 안전 계수를 고려해야 한다.

## SDF의 기본 도형

원과 사각형의 SDF는 다음과 같다.

$$
d_{circle}(\mathbf{p})=\lVert\mathbf{p}-\mathbf{c}\rVert-r
$$

```glsl
float sdCircle(vec2 p, vec2 center, float radius) {
    return length(p - center) - radius;
}
```

```glsl
float sdBox(vec2 p, vec2 center, vec2 halfSize) {
    vec2 q = abs(p - center) - halfSize;
    return length(max(q, 0.0)) + min(max(q.x, q.y), 0.0);
}
```

두 함수 모두 반환값의 부호를 같은 방식으로 해석할 수 있다. 이 공통 인터페이스 덕분에 서로 다른 도형을 같은 연산으로 합성할 수 있다.

## 0값의 경계

SDF에서 실제 도형의 윤곽은 $d(\mathbf{p})=0$을 만족하는 점들의 집합이다. 이를 등위선 또는 영등위선이라고 부를 수 있다.

```text
boundary if abs(signedDistance) is near zero
inside if signedDistance is negative
outside if signedDistance is positive
```

컴퓨터의 부동소수점 계산에서는 정확히 0이 되는지에 의존하기보다, 선 두께나 픽셀 크기를 기준으로 작은 범위를 사용한다.

## SDF에서 마스크 만들기

SDF를 채움 마스크로 바꾸는 가장 기본적인 방식은 0을 경계로 값을 뒤집는 것이다.

```glsl
float fillMask = 1.0 - smoothstep(-edgeWidth, edgeWidth, distanceValue);
```

음수 쪽이 도형 안이라면 `distanceValue`가 작을수록 마스크는 1에 가까워진다. `edgeWidth`를 화면 미분값으로 정하면 확대와 축소에 비교적 안정적인 경계를 만들 수 있다.

```glsl
float edgeWidth = fwidth(distanceValue);
float fillMask = 1.0 - smoothstep(-edgeWidth, edgeWidth, distanceValue);
```

`fwidth`는 GLSL의 화면 미분 함수다. CPU 기반 드로잉 API에서는 렌더러가 제공하는 안티앨리어싱이나 고해상도 렌더링을 사용하는 편이 보통 더 간단하다.

## SDF의 장점

| 장점 | 설명 |
| --- | --- |
| 해상도 독립성 | 함수로 계산하면 여러 해상도에서 같은 형태를 평가할 수 있다. |
| 경계 정보 | 안·밖·경계까지의 거리를 한 값으로 얻는다. |
| 합성 가능성 | `min`, `max`, 부호 반전으로 도형을 조합할 수 있다. |
| 효과 확장성 | 채움, 외곽선, 글로우, 그림자, 변위를 같은 값에서 만든다. |
| 셰이더 적합성 | 픽셀마다 독립적으로 계산하기 좋다. |

SDF가 항상 객체 드로잉보다 좋은 것은 아니다. 복잡한 벡터 경로나 텍스트를 정밀하게 편집하거나 수많은 독립 객체를 관리할 때는 기존 그래픽 API와 벡터 도구가 더 적합할 수 있다.

## SDF와 이미지 거리장

SDF는 수식으로 매 프레임 계산할 수도 있고, 이미지 형태로 미리 저장할 수도 있다. 폰트 렌더링에서는 글리프 윤곽의 거리장을 텍스처에 저장해 다양한 크기에서 선명하게 표시하는 기법이 쓰인다.

이미지 SDF를 샘플링할 때는 텍스처 값이 실제 거리인지, 특정 범위로 정규화된 거리인지 확인해야 한다. 다중 채널 거리장(MSDF)은 모서리와 복잡한 윤곽을 더 선명하게 보존하기 위해 여러 채널에 거리 정보를 저장한다.

## 이 절의 핵심

SDF는 도형 경계까지의 거리와 안·밖 정보를 부호 하나에 담는다. 음수는 안쪽, 0은 경계, 양수는 바깥쪽이다. 이 공통 표현 덕분에 다양한 도형에서 채움과 외곽선을 같은 방식으로 만들고, 다음 장의 합성 연산에도 사용할 수 있다.

다음 절에서는 SDF와 일반 거리값을 채움, 외곽선, 그라데이션으로 연결하는 구체적인 표현 방법을 정리한다.
