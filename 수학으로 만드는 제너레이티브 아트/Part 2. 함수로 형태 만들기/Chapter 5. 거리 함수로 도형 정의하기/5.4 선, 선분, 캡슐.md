# 5.4 선, 선분, 캡슐

무한히 이어지는 직선까지의 거리와 양 끝점이 있는 선분까지의 거리는 다르다. 제너레이티브 아트에서 선을 거리 함수로 표현할 때는 보통 선분까지의 최단 거리를 구한 뒤 그 거리에 따라 두께를 정한다. 선분의 양 끝을 둥글게 처리하면 캡슐 모양이 된다.

## 무한 직선까지의 거리

2차원 직선 위의 한 점을 $\mathbf{a}$, 직선 방향의 단위 벡터를 $\hat{\mathbf{d}}$라고 하자. 벡터 $\mathbf{p}-\mathbf{a}$를 직선 방향과 수직 방향의 성분으로 나누면 직선까지의 거리를 구할 수 있다. 내적으로 직선 방향 성분을 구해 $\mathbf{p}-\mathbf{a}$에서 빼면 수직 성분이 남고, 그 길이가 점 $\mathbf{p}$에서 직선까지의 거리다. 실제 도형을 만들 때는 끝점이 있는 선분을 다루는 경우가 많아 다음 절차를 사용한다.

무한 직선은 화면 경계를 넘어 이어지는 줄무늬나 절단 평면을 만들 때 유용하다. 화면 안에 길이가 정해진 선을 만들려면 시작점과 끝점이 있는 선분을 사용한다.

## 선분의 가장 가까운 점

선분의 시작점을 $\mathbf{a}$, 끝점을 $\mathbf{b}$, 현재 위치를 $\mathbf{p}$라고 하자. 선분 방향 벡터는 다음과 같다.

$$
\mathbf{ab}=\mathbf{b}-\mathbf{a}
$$

현재 점을 선분 방향에 투영한 비율은 다음과 같다. 분자는 $\mathbf{p}-\mathbf{a}$가 선분 방향으로 얼마나 뻗는지 나타내고, 분모는 선분 길이의 제곱이다. 이를 나누면 선분 전체 길이에 대한 상대 위치 $t$를 얻는다.

$$
t=\frac{(\mathbf{p}-\mathbf{a})\cdot\mathbf{ab}}{\mathbf{ab}\cdot\mathbf{ab}}
$$

$t$는 선분 밖으로도 나올 수 있다. $t<0$이면 시작점보다 앞에, $t>1$이면 끝점 너머에 투영된 경우다. 선분 위에서 가장 가까운 점을 찾으려면 $t$를 0에서 1 사이로 제한한다.

$$
t'=\operatorname{clamp}(t,0,1)
$$

$$
\mathbf{q}=\mathbf{a}+t'\mathbf{ab}
$$

$t'=0$이면 가장 가까운 점은 시작점 $\mathbf{a}$이고, $t'=1$이면 끝점 $\mathbf{b}$다. 그 사이에서는 $\mathbf{q}$가 선분 위에 놓인다.

마지막으로 현재 점에서 선분 위의 가장 가까운 점 $\mathbf{q}$까지의 거리를 구한다.

$$
d=\lVert\mathbf{p}-\mathbf{q}\rVert
$$

```text
function distanceToSegment(position, start, end):
    segment = end - start
    denominator = dot(segment, segment)

    if denominator is nearly zero:
        return length(position - start)

    t = dot(position - start, segment) / denominator
    t = clamp(t, 0, 1)
    closest = start + t * segment
    return length(position - closest)
```

시작점과 끝점이 같으면 선분의 길이가 0이므로 분모도 0이 된다. 길이가 매우 짧은 선분에서도 분모가 불안정해질 수 있어, 코드에서는 이를 검사해 선분을 점처럼 처리한다.

## 선분을 두께 있는 선으로 만들기

선분까지의 거리가 선 두께의 절반보다 작으면 선 내부다. 끝점까지의 거리도 함께 계산하므로 양 끝이 둥근 캡슐 모양이 된다.

```text
distanceValue = distanceToSegment(position, start, end)
mask = distanceValue < halfWidth
```

GLSL에서는 다음처럼 구현할 수 있다.

```glsl
float sdSegment(vec2 p, vec2 a, vec2 b) {
    vec2 ab = b - a;
    float lengthSquared = dot(ab, ab);
    float t = lengthSquared > 0.0
        ? clamp(dot(p - a, ab) / lengthSquared, 0.0, 1.0)
        : 0.0;
    return length(p - (a + t * ab));
}
```

이 함수가 반환하는 값은 선분 중심선까지의 부호 없는 거리다. 선의 반폭 $h$를 빼면 캡슐의 SDF가 된다. 중심선에서 거리가 $h$인 곳이 경계이고, 그보다 가까운 곳에서는 결과가 음수다.

$$
d_{capsule}=d_{segment}-h
$$

## 캡슐

캡슐은 선분의 양 끝에 반원을 붙인 모양이다. 선분 거리에서 반지름을 빼면 직선 구간과 둥근 끝을 한 식으로 표현할 수 있다. 굵은 선, 둥근 막대, 연결선, 관절형 구조를 거리 함수로 만들 때 유용하다.

```glsl
float sdCapsule(vec2 p, vec2 a, vec2 b, float radius) {
    return sdSegment(p, a, b) - radius;
}
```

`radius`는 캡슐의 반지름이자 중심선에서 경계까지의 거리다. 반환값이 0보다 작으면 캡슐 안쪽이고, 0이면 외곽선이다. `smoothstep`을 적용하면 선의 경계를 부드럽게 표현할 수 있다.

```glsl
float d = sdCapsule(position, start, end, radius);
float mask = 1.0 - smoothstep(-edgeWidth, edgeWidth, d);
```

## 선의 방향에 따라 값 바꾸기

선분 투영 비율 $t'$는 가장 가까운 점을 찾는 데 쓰이며, 시작점에서 끝점까지의 상대 위치도 나타낸다. $t'=0$은 시작점, $t'=1$은 끝점에 해당한다. 이 값을 색, 두께, 반복 무늬에 연결할 수 있다.

```text
t = clamped projection onto segment
color = interpolate(startColor, endColor, t)
width = interpolate(startWidth, endWidth, t)
```

이 방식으로 선을 따라 색을 바꾸거나 한쪽은 굵고 다른 쪽은 얇게 만들 수 있다. 거리값은 선에서 옆으로 떨어진 정도를, 투영값은 선을 따라 진행한 정도를 나타낸다.

## 실제 라이브러리에서의 선

p5.js의 `line(x1, y1, x2, y2)`, Canvas 2D의 `moveTo()`와 `lineTo()`, SVG의 `<line>`은 선을 객체로 그린다. 선 끝의 모양은 `stroke-linecap`이나 API의 선 캡 설정으로 정할 수 있다.

```javascript
// Canvas 2D 예제
context.lineCap = "round";
context.lineWidth = width;
context.beginPath();
context.moveTo(startX, startY);
context.lineTo(endX, endY);
context.stroke();
```

거리 함수는 선의 두께와 색을 좌표마다 다르게 하거나, 선을 다른 SDF와 합성할 때 유용하다.

## 이 절의 핵심

선분까지의 거리는 현재 점을 선분에 투영하고, 그 비율을 0에서 1 사이로 제한해 가장 가까운 점을 찾은 뒤 계산한다. 거리에서 선의 반폭을 빼면 양 끝이 둥근 캡슐 SDF가 된다.

선분 방향의 투영 비율은 색, 두께, 반복 패턴을 선을 따라 변화시키는 입력으로도 쓸 수 있다. 다음 절에서는 사각형과 둥근 사각형의 거리 함수를 다룬다.
