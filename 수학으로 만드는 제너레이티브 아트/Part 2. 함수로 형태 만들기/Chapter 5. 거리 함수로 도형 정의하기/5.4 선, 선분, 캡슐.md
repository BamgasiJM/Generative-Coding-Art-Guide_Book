# 5.4 선, 선분, 캡슐

점에서 무한히 뻗는 직선까지의 거리와, 양 끝점이 있는 선분까지의 거리는 다르다. 제너레이티브 아트에서 선을 거리 함수로 다룰 때는 보통 선분까지의 최단 거리를 계산하고, 그 거리로 두께를 만든다. 선분의 끝을 둥글게 처리하면 캡슐 모양이 된다.

## 무한 직선까지의 거리

2차원 직선 위의 한 점을 $\mathbf{a}$, 직선 방향의 단위 벡터를 $\hat{\mathbf{d}}$라고 하자. 점 $\mathbf{p}$에서 직선까지의 수직 거리는 투영을 이용해 구할 수 있다. 실무에서는 선분 공식을 사용해 함께 처리하는 경우가 더 많다.

무한 직선은 화면 경계를 넘어 계속 이어지는 줄무늬나 절단 평면을 만들 때 유용하다. 그러나 도형으로 보이는 짧은 선을 만들려면 시작점과 끝점을 가진 선분이 필요하다.

## 선분의 가장 가까운 점

선분의 시작점을 $\mathbf{a}$, 끝점을 $\mathbf{b}$, 현재 위치를 $\mathbf{p}$라고 하자. 선분 방향 벡터는 다음과 같다.

$$
\mathbf{ab}=\mathbf{b}-\mathbf{a}
$$

현재 점을 선분 방향에 투영한 비율은 다음과 같다.

$$
t=\frac{(\mathbf{p}-\mathbf{a})\cdot\mathbf{ab}}{\mathbf{ab}\cdot\mathbf{ab}}
$$

선분 내부의 가장 가까운 점을 얻으려면 $t$를 0에서 1 사이로 제한한다.

$$
t'=\operatorname{clamp}(t,0,1)
$$

$$
\mathbf{q}=\mathbf{a}+t'\mathbf{ab}
$$

마지막으로 현재 점과 $\mathbf{q}$의 거리를 구한다.

$$
d=\lVert\mathbf{p}-\mathbf{q}\rVert
$$

```text
function distanceToSegment(position, start, end):
    segment = end - start
    denominator = dot(segment, segment)

    if denominator is nearly zero:
        return length(position - start)

    t = dot(position - start, segment) / denominator
    t = clamp(t, 0, 1)
    closest = start + t * segment
    return length(position - closest)
```

시작점과 끝점이 같으면 선분의 길이가 0이므로 분모도 0이 된다. 이 경우 선분은 점으로 처리해야 한다.

## 선분을 두께 있는 선으로 만들기

선분까지의 거리가 선 두께의 절반보다 작으면 선 내부다.

```text
distanceValue = distanceToSegment(position, start, end)
mask = distanceValue < halfWidth
```

GLSL에서는 다음처럼 구현할 수 있다.

```glsl
float sdSegment(vec2 p, vec2 a, vec2 b) {
    vec2 ab = b - a;
    float lengthSquared = dot(ab, ab);
    float t = lengthSquared > 0.0
        ? clamp(dot(p - a, ab) / lengthSquared, 0.0, 1.0)
        : 0.0;
    return length(p - (a + t * ab));
}
```

이 함수가 반환하는 값은 선분의 중심선까지의 거리다. 여기에 반폭을 빼면 캡슐의 SDF가 된다.

$$
d_{capsule}=d_{segment}-h
$$

## 캡슐

캡슐은 선분의 양 끝에 반원을 붙인 모양이다. 굵은 선, 둥근 막대, 연결선, 관절형 구조를 거리 함수로 만들 때 자연스럽게 나온다.

```glsl
float sdCapsule(vec2 p, vec2 a, vec2 b, float radius) {
    return sdSegment(p, a, b) - radius;
}
```

반환값이 0보다 작으면 캡슐 안쪽이고, 0이면 외곽선이다. `smoothstep`과 결합하면 끝이 부드러운 선을 만들 수 있다.

```glsl
float d = sdCapsule(position, start, end, radius);
float mask = 1.0 - smoothstep(-edgeWidth, edgeWidth, d);
```

## 선의 방향에 따라 값 바꾸기

선분 투영 비율 $t'$는 단순히 가장 가까운 점을 찾는 값만이 아니다. 선분의 시작에서 끝까지의 상대 위치를 나타낸다. 이를 색, 두께, 반복 무늬에 연결할 수 있다.

```text
t = clamped projection onto segment
color = interpolate(startColor, endColor, t)
width = interpolate(startWidth, endWidth, t)
```

이 방식으로 한 선 안에서 색이 변하거나 한쪽이 굵고 다른 쪽이 얇아지는 형태를 만들 수 있다. 거리값은 선에서 가로로 떨어진 정도를, 투영값은 선을 따라 진행한 정도를 제공한다.

## 실제 라이브러리에서의 선

p5.js의 `line(x1, y1, x2, y2)`, Canvas 2D의 `moveTo()`와 `lineTo()`, SVG의 `<line>`은 선을 객체로 그린다. 선 끝의 모양은 `stroke-linecap`이나 API의 선 캡 설정으로 정할 수 있다.

```javascript
// Canvas 2D 예제
context.lineCap = "round";
context.lineWidth = width;
context.beginPath();
context.moveTo(startX, startY);
context.lineTo(endX, endY);
context.stroke();
```

거리 함수는 선의 두께와 색이 좌표마다 달라지거나, 선을 다른 SDF와 합성해야 할 때 특히 유용하다.

## 이 절의 핵심

선분까지의 거리는 현재 점을 선분에 투영하고, 투영 비율을 0에서 1 사이로 제한해 가장 가까운 점을 찾는 방식으로 계산한다. 이 거리에서 반폭을 빼면 양 끝이 둥근 캡슐 SDF가 된다.

선분 방향의 투영 비율은 색, 두께, 반복 패턴을 선을 따라 변화시키는 입력으로도 쓸 수 있다. 다음 절에서는 사각형과 둥근 사각형의 거리 함수를 다룬다.
