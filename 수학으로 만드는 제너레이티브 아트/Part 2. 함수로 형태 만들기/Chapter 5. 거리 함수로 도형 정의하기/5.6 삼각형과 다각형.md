# 5.6 삼각형과 다각형

삼각형과 다각형은 변이 여러 개지만, 거리 함수를 만드는 원리는 단순하다. 현재 점에서 경계의 각 선분까지 거리를 구해 최솟값을 찾고, 점이 내부에 있는지 판정한다. 최솟값이 경계까지의 거리 크기를 주고 내부 판정이 부호를 정하므로, 두 결과를 결합해 다각형의 SDF를 얻는다.

## 삼각형의 내부 판정

삼각형의 세 꼭짓점을 $\mathbf{a}$, $\mathbf{b}$, $\mathbf{c}$, 판정할 점을 $\mathbf{p}$라고 하자. 점이 내부에 있는지 판정하는 방법에는 변에 대한 방향을 검사하는 방법과 바리센트릭 좌표를 사용하는 방법이 있다. 바리센트릭 좌표는 세 꼭짓점에 대한 가중치로 점의 위치를 나타낸다.

삼각형이 일직선으로 납작해지지 않은 경우, 점은 세 꼭짓점의 가중합으로 표현된다.

$$
\mathbf{p}=u\mathbf{a}+v\mathbf{b}+w\mathbf{c}
$$

$$
u+v+w=1
$$

$u$, $v$, $w$의 합이 1이면 꼭짓점 위치의 가중 평균이 점 $\mathbf{p}$를 나타낸다. 세 가중치가 모두 0 이상이면 점은 삼각형 안이나 경계 위에 있고, 하나라도 음수면 삼각형 바깥에 있다. 가중치 하나가 0인 경우 점은 나머지 두 꼭짓점을 잇는 변 위에 놓인다. 래스터라이저도 이 가중치로 삼각형 꼭짓점에 지정한 색이나 UV 좌표를 내부 위치에 보간한다.

## 삼각형까지의 거리

삼각형 경계까지의 거리는 세 변을 선분으로 보고, 각 선분까지의 거리 중 최솟값을 취한다. 각 거리는 5.4절에서 다룬 것처럼 투영점을 선분 양끝 사이로 제한해 구한다.

$$
d_{edge}=\min\left(d_{ab},d_{bc},d_{ca}\right)
$$

```text
distanceAB = distanceToSegment(position, a, b)
distanceBC = distanceToSegment(position, b, c)
distanceCA = distanceToSegment(position, c, a)
edgeDistance = min(distanceAB, distanceBC, distanceCA)
```

최솟값은 항상 0 이상이어서 그 자체로는 안쪽과 바깥쪽을 구분하지 못한다. 내부 판정 결과에 따라 안쪽에서 음수, 바깥쪽에서 양수가 되도록 부호를 붙이면 SDF가 된다. 경계 위에서는 거리가 0이므로 내부 판정의 세부 규칙과 관계없이 결과는 0이다.

```text
signedDistance = -edgeDistance if pointIsInsideTriangle else edgeDistance
```

## 일반 다각형의 거리

$n$개의 꼭짓점으로 이루어진 다각형도 모든 변까지의 선분 거리를 계산해 가장 작은 값을 선택한다. 꼭짓점은 다각형의 둘레를 따라 순서대로 저장되어 있어야 하며, 마지막 꼭짓점 다음에는 첫 번째 꼭짓점이 이어져 닫힌 경계를 이룬다.

```text
minimumDistance = infinity

for each edge from vertex[i] to vertex[(i + 1) mod vertexCount]:
    minimumDistance = min(
        minimumDistance,
        distanceToSegment(position, edge.start, edge.end)
    )
```

부호를 정하려면 점이 다각형 내부인지 판정해야 한다. 일반적인 방법인 광선 교차 검사는 점에서 한 방향으로 반직선을 그어 다각형의 경계와 몇 번 만나는지 센다. 교차 횟수가 홀수면 안쪽, 짝수면 바깥쪽이다. 오목한 다각형도 이 규칙으로 판정할 수 있다.

```text
crossingCount = countRayEdgeIntersections(position, polygonEdges)
isInside = crossingCount mod 2 equals 1
```

광선이 꼭짓점을 정확히 지나면 인접한 두 변을 교차 두 번으로 셀 수 있으므로, 꼭짓점에서는 한 번만 세도록 경계 규칙을 정해야 한다. 점이 경계 위에 있는 경우도 별도로 판정하거나 일관된 교차 규칙으로 처리한다.

## 볼록 다각형과 반평면

볼록 다각형은 각 변이 만드는 내부 반평면들의 교집합이다. 꼭짓점이 둘레를 따라 같은 방향으로 나열되어 있다면 내부는 모든 변의 같은 쪽에 놓인다. 각 변의 방향과 점의 위치를 비교해 어느 한 변의 바깥쪽에라도 놓이면 다각형 바깥이다. 이 비교에는 변에 대한 부호 있는 거리나 2차원 외적의 부호를 사용할 수 있다.

```text
for each directed edge:
    if position lies outside the edge's interior half-plane:
        return outside

return inside
```

볼록 다각형에서는 모든 변의 내부 반평면을 확인하면 되므로 이 방식이 간단하고 빠르다. 오목 다각형은 내부가 모든 변의 같은 쪽에 있지 않아 이 검사를 그대로 적용할 수 없다. 도형이 볼록한지에 따라 내부 판정 방법을 선택해야 한다.

## 정다각형의 거리 함수

정다각형은 꼭짓점을 하나씩 순회하는 대신 중심에서의 거리와 각도로 정의할 수 있다. 중심 기준 좌표를 극좌표로 바꾸면 각도는 꼭짓점 수에 따라 반복되는 같은 부채꼴 구간들로 나뉜다. 각도를 한 구간 안으로 접고 대칭을 적용하면 한 변까지의 거리 계산을 반복해 전체 정다각형에 사용할 수 있다.

```text
radius = length(localPosition)
angle = atan2(localPosition.y, localPosition.x)
foldedAngle = repeatAndMirror(angle, sectorAngle)
distanceValue = distanceToOnePolygonSide(radius, foldedAngle)
```

이 방식은 꼭짓점이 많은 정다각형도 일정한 대칭 규칙으로 표현하므로 셰이더에서 효율적이다. 다만 극좌표 변환과 각도 접기의 원리를 알아야 한다. 이 내용은 Chapter 9의 방사형 패턴에서 다시 다룬다.

## 다각형을 마스크와 외곽선으로 사용하기

다각형 SDF도 원이나 사각형과 같은 방식으로 마스크를 만든다. 부호 있는 거리를 `smoothstep`에 넣으면 경계 주변에 부드러운 채움 전환을 만들고, 절댓값을 사용하면 경계 양쪽에 걸친 띠 모양 외곽선을 얻는다.

```glsl
float fillMask = 1.0 - smoothstep(-edgeWidth, edgeWidth, signedDistance);
float outlineMask = 1.0 - smoothstep(
    strokeWidth,
    strokeWidth + edgeWidth,
    abs(signedDistance)
);
```

절댓값을 사용하므로 외곽 띠는 경계에서 안쪽과 바깥쪽으로 각각 `strokeWidth`만큼 뻗는다. `edgeWidth`는 띠 바깥쪽에서 마스크가 흐려지는 폭이다. 도형의 꼭짓점 수가 달라도 채움과 외곽선을 처리하는 코드는 그대로 쓸 수 있다. 도형별 계산이 하나의 부호 있는 거리값으로 정리되기 때문이다.

## 실제 라이브러리에서의 다각형

대부분의 벡터·캔버스 라이브러리는 꼭짓점 목록으로 다각형을 그리는 API를 제공한다. Canvas 2D에서는 `moveTo()`로 첫 꼭짓점에 이동한 뒤 `lineTo()`로 나머지 꼭짓점을 잇고, `closePath()`로 마지막 점과 첫 점을 연결한다. `fill()`은 내부를 채우고 `stroke()`는 경계를 그린다. SVG에서는 `<polygon>`과 `<path>`를 사용할 수 있다.

```javascript
// Canvas 2D 예제
context.beginPath();
context.moveTo(vertices[0].x, vertices[0].y);
for (const vertex of vertices.slice(1)) {
  context.lineTo(vertex.x, vertex.y);
}
context.closePath();
context.fill();
```

거리 함수는 다각형 마스크로 픽셀 기반 질감의 범위를 제한하거나, 다각형과 다른 도형을 수학적으로 합성할 때 유용하다. 일반적인 그리기 API와 달리 좌표마다 경계까지의 거리를 제공하므로, 경계에서의 효과도 거리값에 연결할 수 있다.

## 이 절의 핵심

삼각형과 다각형의 SDF는 각 변까지의 최단 거리와 내부 판정을 결합해 만든다. 가장 가까운 변까지의 거리가 경계까지의 크기를, 내부 여부가 부호를 정한다. 삼각형에는 바리센트릭 좌표를, 일반 다각형에는 광선 교차 검사를 사용할 수 있으며 볼록 다각형은 반평면 검사로 간단히 판정할 수 있다.

다음 절에서는 이 원리를 일반화한 부호 있는 거리장, 즉 SDF의 기본 성질과 장점을 정리한다.
