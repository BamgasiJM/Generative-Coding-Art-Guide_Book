# 5.6 삼각형과 다각형

삼각형과 다각형은 원이나 사각형보다 경계가 복잡하지만, 기본 원리는 같다. 현재 점에서 각 변까지의 최단 거리를 구하고, 점이 도형 내부에 있는지 판정한다. 최단 거리의 크기와 내부 판정의 부호를 결합하면 다각형의 SDF를 만들 수 있다.

## 삼각형의 내부 판정

삼각형의 세 꼭짓점을 $\mathbf{a}$, $\mathbf{b}$, $\mathbf{c}$라고 하자. 점 $\mathbf{p}$가 삼각형 안에 있는지 알아내는 방법은 여러 가지다. 대표적으로 각 변에 대한 점의 방향을 검사하거나, 바리센트릭 좌표를 사용할 수 있다.

바리센트릭 좌표는 점을 세 꼭짓점의 가중합으로 표현한다.

$$
\mathbf{p}=u\mathbf{a}+v\mathbf{b}+w\mathbf{c}
$$

$$
u+v+w=1
$$

$u$, $v$, $w$가 모두 0 이상이면 점은 삼각형 안 또는 경계 위에 있다. 래스터라이저가 삼각형 내부의 색과 UV를 보간할 때도 이와 비슷한 원리를 사용한다.

## 삼각형까지의 거리

삼각형 경계까지의 거리는 세 선분까지의 거리 중 최솟값이다.

$$
d_{edge}=\min\left(d_{ab},d_{bc},d_{ca}\right)
$$

```text
distanceAB = distanceToSegment(position, a, b)
distanceBC = distanceToSegment(position, b, c)
distanceCA = distanceToSegment(position, c, a)
edgeDistance = min(distanceAB, distanceBC, distanceCA)
```

이 값만으로는 안쪽과 바깥쪽을 구분할 수 없다. 내부 판정 결과에 따라 부호를 붙이면 SDF가 된다.

```text
signedDistance = -edgeDistance if pointIsInsideTriangle else edgeDistance
```

## 일반 다각형의 거리

$n$개의 꼭짓점으로 이루어진 다각형은 모든 변에 대해 선분 거리를 계산한 뒤 가장 작은 값을 선택한다.

```text
minimumDistance = infinity

for each edge from vertex[i] to vertex[(i + 1) mod vertexCount]:
    minimumDistance = min(
        minimumDistance,
        distanceToSegment(position, edge.start, edge.end)
    )
```

부호를 정하려면 점이 다각형 안에 있는지 판정해야 한다. 널리 쓰이는 방법 중 하나는 광선 교차 검사다. 점에서 한 방향으로 반직선을 쏘았을 때 다각형 변과 교차하는 횟수가 홀수면 안쪽, 짝수면 바깥쪽으로 판단한다.

```text
crossingCount = countRayEdgeIntersections(position, polygonEdges)
isInside = crossingCount mod 2 equals 1
```

이 방법은 오목 다각형에도 사용할 수 있지만, 꼭짓점을 정확히 지나는 광선과 같은 경계 사례를 일관되게 처리해야 한다.

## 볼록 다각형과 반평면

볼록 다각형은 모든 변의 같은 쪽에 있는 점들의 교집합으로 볼 수 있다. 각 변에 대한 부호 있는 거리 또는 2차원 외적의 부호를 사용하면 내부를 판정할 수 있다.

```text
for each directed edge:
    if position lies outside the edge's interior half-plane:
        return outside

return inside
```

볼록 다각형에서는 이 방식이 간단하고 빠르다. 그러나 오목 다각형에는 그대로 적용할 수 없다. 도형의 성질에 따라 적합한 내부 판정 방식을 선택해야 한다.

## 정다각형의 거리 함수

정다각형은 꼭짓점을 하나씩 순회하지 않고, 중심에 대한 각도와 반지름을 이용해 정의할 수 있다. 좌표를 극좌표로 바꾸고 각도를 한 조각으로 접으면, 정삼각형·정육각형 같은 반복 대칭 구조를 만들 수 있다.

```text
radius = length(localPosition)
angle = atan2(localPosition.y, localPosition.x)
foldedAngle = repeatAndMirror(angle, sectorAngle)
distanceValue = distanceToOnePolygonSide(radius, foldedAngle)
```

이 방식은 셰이더에서 정다각형 패턴을 만들 때 효율적이다. 다만 극좌표 변환과 각도 접기의 이해가 필요하므로, Chapter 9의 방사형 패턴에서 다시 확장한다.

## 다각형을 마스크와 외곽선으로 사용하기

다각형 SDF의 부호와 절댓값은 원·사각형과 같은 방식으로 사용한다.

```glsl
float fillMask = 1.0 - smoothstep(-edgeWidth, edgeWidth, signedDistance);
float outlineMask = 1.0 - smoothstep(
    strokeWidth,
    strokeWidth + edgeWidth,
    abs(signedDistance)
);
```

도형의 꼭짓점이 많아져도 채움과 외곽선을 만드는 코드는 바뀌지 않는다. 거리 함수의 인터페이스가 일관되기 때문이다.

## 실제 라이브러리에서의 다각형

대부분의 벡터·캔버스 라이브러리는 꼭짓점 목록으로 다각형을 그리는 API를 제공한다. Canvas 2D에서는 `moveTo()`와 `lineTo()`로 경로를 만들고 `fill()` 또는 `stroke()`를 호출한다. SVG에서는 `<polygon>`과 `<path>`를 사용할 수 있다.

```javascript
// Canvas 2D 예제
context.beginPath();
context.moveTo(vertices[0].x, vertices[0].y);
for (const vertex of vertices.slice(1)) {
  context.lineTo(vertex.x, vertex.y);
}
context.closePath();
context.fill();
```

거리 함수는 다각형을 마스크로 사용해 픽셀 기반 질감을 제한하거나, 도형을 수학적으로 합성하는 작업에서 유용하다.

## 이 절의 핵심

삼각형과 다각형의 거리 함수는 각 변까지의 최단 거리와 내부 판정을 결합해 만든다. 가장 가까운 변까지의 거리는 크기를, 내부 여부는 부호를 제공한다.

다음 절에서는 이 원리를 일반화한 부호 있는 거리장, 즉 SDF의 기본 성질과 장점을 정리한다.
