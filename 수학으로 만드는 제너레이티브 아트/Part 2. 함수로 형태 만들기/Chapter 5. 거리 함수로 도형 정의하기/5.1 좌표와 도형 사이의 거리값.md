# 5.1 좌표와 도형 사이의 거리값

도형을 그리는 가장 직접적인 방법은 원, 선, 사각형 같은 그래픽 객체를 화면에 배치하는 것이다. 그러나 화면의 각 좌표와 도형 사이의 거리를 계산하는 방식으로도 도형을 정의할 수 있다. 이때 도형은 그리기 명령이 아니라, 좌표를 입력받아 거리값을 반환하는 함수가 된다.

점 $\mathbf{p}$와 기준점 $\mathbf{c}$의 차이는 기준점에서 현재 점으로 향하는 벡터다.

$$
\mathbf{v}=\mathbf{p}-\mathbf{c}
$$

이 벡터의 길이가 두 점 사이의 거리다.

$$
d=\lVert\mathbf{p}-\mathbf{c}\rVert
$$

중심점에서 같은 거리에 있는 점들의 집합은 원이 된다. 따라서 거리값은 원형 경계와 방사형 그라데이션을 만드는 가장 기본적인 도구다.

## 거리는 좌표에 대한 함수다

현재 위치 $\mathbf{p}$마다 거리값을 계산하면, 화면 전체에 연속적인 값의 장이 만들어진다.

```text
for each position p:
    distanceValue = length(p - center)
    store distanceValue
```

중심에서는 거리가 0이고, 중심에서 멀어질수록 값이 커진다. 이 값을 밝기로 연결하면 중심이 밝고 바깥이 어두운 방사형 그라데이션이 된다.

```glsl
vec2 local = position - center;
float distanceValue = length(local);
vec3 color = vec3(distanceValue);
```

이 GLSL 예제에서 `position`은 현재 픽셀 또는 표면 위의 좌표다. 실제 출력에 사용하려면 거리의 범위를 0에서 1 사이로 정규화하거나 원하는 색 범위로 재매핑해야 한다.

## 점, 도형, 거리값

거리의 기준은 항상 점일 필요가 없다. 선분, 사각형, 다각형, 곡면처럼 다양한 도형에 대해 “현재 점에서 가장 가까운 도형 위의 점까지의 거리”를 정의할 수 있다.

| 기준 도형 | 거리의 의미 | 같은 거리를 갖는 영역 |
| --- | --- | --- |
| 점 | 중심점까지의 거리 | 원 |
| 무한 직선 | 직선까지의 수직 거리 | 평행선 |
| 선분 | 선분의 가장 가까운 점까지의 거리 | 끝이 둥근 띠 |
| 사각형 | 경계까지의 최단 거리 | 사각형을 따라가는 띠 |
| 다각형 | 변과 꼭짓점까지의 최단 거리 | 다각형 윤곽을 따르는 영역 |

이 관점에서 도형은 하나의 경계선이 아니라, 주변 모든 위치에 값을 부여하는 구조다. 경계에서 가까운지 먼지, 안쪽인지 바깥쪽인지 같은 정보를 거리값으로 얻을 수 있다.

## 거리값을 시각 요소에 연결하기

같은 거리값도 어디에 연결하는가에 따라 다른 결과가 나온다.

```text
distanceValue = distanceToShape(position)
brightness = distanceToBrightness(distanceValue)
opacity = distanceToOpacity(distanceValue)
displacement = distanceToDisplacement(distanceValue)
```

| 거리값의 연결 | 결과 |
| --- | --- |
| 임계값 비교 | 도형의 안과 밖 |
| 밝기 | 경계에서 퍼지는 그라데이션 |
| 투명도 | 페이드 마스크 |
| 색상 | 거리 기반 팔레트 |
| 변위 | 도형 주위가 솟거나 꺼지는 표면 |
| 입자 힘 | 도형 근처에서 달라지는 움직임 |

이후 절에서 다룰 도형 함수는 대부분 거리값을 반환한다. 먼저 그 값을 그대로 관찰한 뒤, 임계값과 보간을 적용해 형태로 바꾸는 흐름을 익히는 것이 좋다.

## 거리 단위와 좌표계

거리값의 단위는 입력 좌표계의 단위와 같다. 픽셀 좌표를 입력으로 쓰면 거리는 픽셀 단위이고, 정규화 좌표를 쓰면 화면 비율에 대한 단위가 된다. 정규화 좌표에서 원을 만들 때 종횡비를 보정하지 않으면 원이 타원처럼 보일 수 있다.

```glsl
vec2 p = uv - 0.5;
p.x *= resolution.x / resolution.y;
float d = length(p);
```

이 코드는 세로 길이를 기준으로 가로축의 척도를 맞춘다. 이제 `d`의 같은 값은 화면에서 원형 경계를 만든다.

## 거리의 제곱

원 안에 있는지처럼 거리의 크기만 비교하면 되는 경우에는 제곱근을 생략할 수 있다.

$$
\lVert\mathbf{p}-\mathbf{c}\rVert<r
\quad\Longleftrightarrow\quad
(\mathbf{p}-\mathbf{c})\cdot(\mathbf{p}-\mathbf{c})<r^2
$$

```text
offset = position - center
inside = dot(offset, offset) < radius * radius
```

하지만 제곱 거리는 실제 거리와 값의 변화 방식이 다르다. 그라데이션이나 선 두께처럼 거리값을 직접 출력에 연결할 때는 보통 실제 거리를 사용한다.

## 드로잉 API와 거리 함수

p5.js, Canvas 2D, SVG 같은 드로잉 API에서는 원을 그리는 명령이 제공된다. 예를 들어 p5.js의 `circle(x, y, diameter)`는 객체를 직접 그린다. 반면 프래그먼트 셰이더나 프로시저럴 재질에서는 각 픽셀의 색을 계산하므로 거리 함수를 사용하는 방식이 자연스럽다.

```glsl
float d = length(uv - vec2(0.5));
float disk = 1.0 - step(0.25, d);
```

두 방식은 경쟁하지 않는다. 객체를 배치하는 작업에서는 드로잉 API가 간결하고, 픽셀 단위 마스크·경계·질감·합성을 다룰 때는 거리 함수가 강력하다.

## 이 절의 핵심

거리 함수는 현재 좌표와 도형 사이의 관계를 숫자로 반환한다. 점까지의 거리는 원형 구조를 만들고, 다른 도형까지의 최단 거리도 경계와 그라데이션을 만드는 입력이 된다.

다음 절에서는 거리값을 임계값과 보간에 연결해 도형의 경계를 만드는 방법을 다룬다.
