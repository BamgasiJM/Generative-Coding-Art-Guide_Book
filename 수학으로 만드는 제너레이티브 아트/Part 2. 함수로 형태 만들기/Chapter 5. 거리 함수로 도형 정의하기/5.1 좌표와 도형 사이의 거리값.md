# 5.1 좌표와 도형 사이의 거리값

원, 선, 사각형 같은 그래픽 객체를 화면에 배치하는 것이 도형을 그리는 가장 직접적인 방법이다. 화면의 각 좌표에서 도형까지의 거리를 계산해도 도형을 정의할 수 있다. 이렇게 표현하면 도형은 좌표를 입력받아 거리값을 반환하는 함수가 된다.

점 $\mathbf{p}$에서 기준점 $\mathbf{c}$를 뺀 벡터는 기준점에서 현재 점으로 향한다.

$$
\mathbf{v}=\mathbf{p}-\mathbf{c}
$$

벡터의 길이는 두 점 사이의 거리다.

$$
d=\lVert\mathbf{p}-\mathbf{c}\rVert
$$

중심점에서 같은 거리에 있는 점들은 원을 이룬다. 거리값은 원형 경계와 방사형 그라데이션을 만드는 기본 도구다.

## 거리는 좌표에 대한 함수다

각 위치 $\mathbf{p}$에서 거리를 계산하면 화면 전체에 연속적인 값의 장이 생긴다.

```text
for each position p:
    distanceValue = length(p - center)
    store distanceValue
```

중심점에서 거리값은 0이며, 중심에서 멀어질수록 커진다. 이 값을 밝기에 연결하면 중심은 밝고 바깥은 어두운 방사형 그라데이션이 된다.

```glsl
vec2 local = position - center;
float distanceValue = length(local);
vec3 color = vec3(distanceValue);
```

이 GLSL 예제의 `position`은 현재 픽셀이나 표면 위의 좌표다. 출력에 사용하려면 거리 범위를 0에서 1 사이로 정규화하거나 원하는 색 범위로 재매핑해야 한다.

## 점, 도형, 거리값

거리의 기준이 항상 점일 필요는 없다. 선분, 사각형, 다각형, 곡면에서도 현재 점과 도형 위 가장 가까운 점 사이의 거리를 정의할 수 있다.

| 기준 도형 | 거리의 의미 | 같은 거리를 갖는 영역 |
| --- | --- | --- |
| 점 | 중심점까지의 거리 | 원 |
| 무한 직선 | 직선까지의 수직 거리 | 평행선 |
| 선분 | 선분의 가장 가까운 점까지의 거리 | 끝이 둥근 띠 |
| 사각형 | 경계까지의 최단 거리 | 사각형을 따라가는 띠 |
| 다각형 | 변과 꼭짓점까지의 최단 거리 | 다각형 윤곽을 따르는 영역 |

이렇게 보면 도형은 주변 모든 위치에 값을 부여하는 구조다. 거리값으로 경계까지 가까운지 먼지, 안쪽인지 바깥쪽인지 표현할 수 있다.

## 거리값을 시각 요소에 연결하기

같은 거리값도 연결하는 시각 요소에 따라 결과가 달라진다.

```text
distanceValue = distanceToShape(position)
brightness = distanceToBrightness(distanceValue)
opacity = distanceToOpacity(distanceValue)
displacement = distanceToDisplacement(distanceValue)
```

| 거리값의 연결 | 결과 |
| --- | --- |
| 임계값 비교 | 도형의 안과 밖 |
| 밝기 | 경계에서 퍼지는 그라데이션 |
| 투명도 | 페이드 마스크 |
| 색상 | 거리 기반 팔레트 |
| 변위 | 도형 주위가 솟거나 꺼지는 표면 |
| 입자 힘 | 도형 근처에서 달라지는 움직임 |

이후 절에서 다룰 도형 함수는 대부분 거리값을 반환한다. 먼저 값을 살펴보고 임계값과 보간을 적용해 형태로 바꾸는 흐름을 익힌다.

## 거리 단위와 좌표계

거리값의 단위는 입력 좌표계의 단위와 같다. 픽셀 좌표를 입력하면 거리는 픽셀 단위이고, 정규화 좌표를 입력하면 화면 비율을 기준으로 한 값이다. 정규화 좌표에서 종횡비를 보정하지 않으면 원이 타원처럼 보일 수 있다.

```glsl
vec2 p = uv - 0.5;
p.x *= resolution.x / resolution.y;
float d = length(p);
```

이 코드는 세로 길이를 기준으로 가로축의 척도를 보정한다. 따라서 `d`가 같은 점들을 이으면 화면에서 원형 경계가 된다.

## 거리의 제곱

원 안팎을 판별하는 것처럼 거리의 크기만 비교할 때는 제곱근 계산을 생략할 수 있다.

$$
\lVert\mathbf{p}-\mathbf{c}\rVert<r
\quad\Longleftrightarrow\quad
(\mathbf{p}-\mathbf{c})\cdot(\mathbf{p}-\mathbf{c})<r^2
$$

```text
offset = position - center
inside = dot(offset, offset) < radius * radius
```

제곱 거리는 실제 거리와 값의 변화 방식이 다르다. 그라데이션이나 선 두께처럼 거리값을 출력에 직접 연결할 때는 보통 실제 거리를 사용한다.

## 드로잉 API와 거리 함수

p5.js, Canvas 2D, SVG 같은 드로잉 API에는 원을 그리는 명령이 있다. 예를 들어 p5.js의 `circle(x, y, diameter)`는 원 객체를 직접 그린다. 프래그먼트 셰이더나 프로시저럴 재질은 각 픽셀의 색을 계산하므로 거리 함수를 자연스럽게 활용한다.

```glsl
float d = length(uv - vec2(0.5));
float disk = 1.0 - step(0.25, d);
```

객체 배치에는 드로잉 API가 간결하다. 픽셀 단위의 마스크, 경계, 질감, 합성을 세밀하게 다룰 때는 거리 함수가 유용하다.

## 이 절의 핵심

거리 함수는 현재 좌표와 도형 사이의 관계를 숫자로 나타낸다. 점까지의 거리는 원형 구조를 만들며, 다른 도형까지의 최단 거리도 경계와 그라데이션을 정의하는 입력으로 쓸 수 있다.

다음 절에서는 거리값에 임계값과 보간을 적용해 도형의 경계를 만드는 방법을 다룬다.
