# 5.5 사각형과 둥근 사각형

사각형은 각 축에서 좌표가 일정 범위에 들어오는지 비교해 정의할 수 있다. 거리 함수로 표현하면 채움과 외곽선뿐 아니라 경계까지의 거리도 얻을 수 있어, 둥근 모서리를 만들거나 다른 도형과 합성할 때 같은 구조를 활용할 수 있다.

## 중심과 반크기로 사각형 정의하기

사각형의 중심을 $\mathbf{c}$, 가로와 세로의 반크기를 $\mathbf{h}=(h_x,h_y)$, 거리를 구할 좌표를 $\mathbf{p}$라고 하자. 중심에서 좌표까지의 변위를 절댓값으로 접어 대칭인 네 방향을 하나의 사분면에서 계산한다.

$$
\mathbf{q}=|\mathbf{p}-\mathbf{c}|-\mathbf{h}
$$

벡터 $\mathbf{q}$의 각 성분은 해당 축에서 사각형 경계까지 얼마나 안쪽이나 바깥쪽에 있는지를 나타낸다. 두 성분이 모두 0보다 작으면 점은 사각형 안에 있고, 하나라도 양수면 그 축 방향으로 사각형을 벗어난 상태다. 이 벡터로 축에 평행한 사각형의 SDF를 계산한다.

$$
d=\lVert\max(\mathbf{q},0)\rVert+\min(\max(q_x,q_y),0)
$$

```glsl
float sdBox(vec2 p, vec2 center, vec2 halfSize) {
    vec2 q = abs(p - center) - halfSize;
    return length(max(q, 0.0)) + min(max(q.x, q.y), 0.0);
}
```

`max(q, 0.0)`은 사각형 바깥으로 벗어난 성분만 남긴다. 그 길이는 바깥 점에서 가장 가까운 변이나 모서리까지의 거리다. 사각형 안에서는 이 항이 0이 되고, 두 번째 항이 가장 가까운 변까지의 거리를 음수로 반환한다. 따라서 결과는 경계에서 0, 내부에서 음수, 외부에서 양수다.

## 왜 절댓값을 사용하는가

사각형은 중심을 기준으로 좌우와 상하가 대칭이다. `abs(p - center)`는 좌표의 부호를 없애 네 방향을 같은 계산으로 처리하게 한다. 반크기를 빼면 각 축에서 경계 안쪽인지 바깥쪽인지, 경계에서 얼마나 떨어져 있는지 나타난다.

```text
local = abs(position - center)
outsideAmount = local - halfSize
```

절댓값은 사각형의 네 방향을 하나의 경우로 줄여 계산을 간결하게 만든다. 원은 모든 방향에서 같은 반지름을 쓰지만, 사각형은 x축과 y축의 반크기를 각각 비교한다.

## 채움과 외곽선

사각형 SDF를 얻은 뒤의 처리 방식은 원과 같다.

```glsl
float d = sdBox(position, center, halfSize);
float fillMask = 1.0 - smoothstep(-edgeWidth, edgeWidth, d);
float outlineMask = 1.0 - smoothstep(
    strokeWidth,
    strokeWidth + edgeWidth,
    abs(d)
);
```

도형의 종류가 달라도 `d<0`은 안쪽, `d=0`은 경계라는 뜻이다. 경계 양쪽의 외곽선을 만들 때는 `abs(d)`를 사용해 경계에서 떨어진 거리를 구한다. 이 공통된 해석 덕분에 서로 다른 SDF를 같은 채움·외곽선 처리에 사용할 수 있다.

## 둥근 사각형

둥근 사각형은 사각형의 네 모서리를 같은 반지름으로 둥글게 만든 형태다. 반크기에서 반지름만큼 줄인 사각형의 SDF에서 반지름을 빼면, 원래 사각형 크기를 유지하면서 모서리가 원호로 이어진다.

$$
d_{roundBox}=d_{box}-r
$$

이 식에서 $d_{box}$는 가로와 세로 반크기가 각각 $r$만큼 줄어든 사각형의 거리값이다. 그 경계를 반지름 $r$만큼 바깥으로 확장해 둥근 모서리를 만든다.

```glsl
float sdRoundBox(vec2 p, vec2 center, vec2 halfSize, float radius) {
    vec2 reducedHalfSize = halfSize - vec2(radius);
    vec2 q = abs(p - center) - reducedHalfSize;
    return length(max(q, 0.0)) + min(max(q.x, q.y), 0.0) - radius;
}
```

`radius`는 가로와 세로 반크기 중 작은 값보다 클 수 없다. 반지름이 이 한계를 넘으면 짧은 축 방향의 직선 구간이 사라져 캡슐이나 원에 가까운 형태가 된다. 사각형의 형태를 유지하려면 요청된 반지름을 작은 축의 반크기 이하로 제한한다.

```text
radius = min(requestedRadius, min(halfSize.x, halfSize.y))
```

## 비균일한 모서리 반지름

모서리마다 반지름을 다르게 지정할 수도 있다. 중심 기준 좌표의 부호를 살펴 현재 점이 어느 모서리 쪽에 있는지 판단하고, 그 모서리에 해당하는 반지름을 선택한다.

```text
if local.x < 0 and local.y < 0:
    cornerRadius = topLeftRadius
else if local.x >= 0 and local.y < 0:
    cornerRadius = topRightRadius
...
```

사용자 인터페이스처럼 모서리별 반지름이 고정된 사각형은 라이브러리의 둥근 사각형 API로 간단히 그릴 수 있다. SDF는 반지름을 좌표나 노이즈에 따라 바꾸거나, 모서리를 다른 도형과 합성할 때 유용하다.

## 회전한 사각형

앞의 공식은 사각형의 변이 좌표축에 평행한 경우를 다룬다. 사각형을 각도 $\theta$만큼 돌린 효과를 내려면, 중심 기준 좌표를 반대 방향인 $-\theta$만큼 회전해 원점 중심의 사각형 SDF에 넣는다. 도형을 움직이는 대신 샘플 좌표를 역변환하는 방식이다.

```text
local = position - center
local = rotate(local, -angle)
distanceValue = sdBox(local, origin, halfSize)
```

회전은 길이를 보존하므로 좌표를 역회전한 뒤 구한 거리는 원래 회전된 사각형까지의 거리와 같다. 이 좌표 변환 원리는 다음 Part에서 더 자세히 다룬다.

## 실제 라이브러리에서의 사각형

SVG의 `<rect>`, Canvas 2D의 `fillRect()`와 `roundRect()`, p5.js의 `rect()`는 사각형 객체를 직접 그린다. 둥근 모서리는 각 API의 반지름 인자로 지정할 수 있다.

```javascript
// p5.js 예제
rect(x, y, width, height, cornerRadius);
```

거리 함수는 사각형 내부에 경계로부터의 거리를 이용한 질감을 넣거나, 외곽선 폭을 정하거나, 원·선분과 매끄럽게 합성할 때 적합하다.

## 이 절의 핵심

사각형 SDF는 중심 기준 좌표의 절댓값에서 반크기를 빼고, 바깥으로 벗어난 양과 안쪽에서 가장 가까운 경계까지의 거리를 결합해 만든다. 경계에서는 0, 바깥에서는 양수, 안쪽에서는 음수를 반환한다.

둥근 사각형은 사각형 거리값에서 모서리 반지름을 빼며, 반지름은 작은 축의 반크기 이하로 제한한다. 다음 절에서는 삼각형과 다각형의 경계까지 거리를 계산하는 방법을 살펴본다.
