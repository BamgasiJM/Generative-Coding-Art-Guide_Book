# 5.5 사각형과 둥근 사각형

사각형은 축에 평행한 범위 비교로 쉽게 정의할 수 있다. 하지만 거리 함수로 사각형을 다루면 채움뿐 아니라 경계까지의 거리, 부드러운 외곽선, 둥근 모서리, 다른 도형과의 합성을 같은 구조로 표현할 수 있다.

## 중심과 반크기로 사각형 정의하기

사각형의 중심을 $\mathbf{c}$, 가로·세로 반크기를 $\mathbf{h}=(h_x,h_y)$라고 하자. 현재 좌표를 중심 기준으로 옮기고 절댓값을 취한다.

$$
\mathbf{q}=|\mathbf{p}-\mathbf{c}|-\mathbf{h}
$$

각 성분이 0보다 작으면 현재 점은 각 축에서 사각형 범위 안에 있다. 이 벡터를 사용하면 축 정렬 사각형의 SDF를 만들 수 있다.

$$
d=\lVert\max(\mathbf{q},0)\rVert+\min(\max(q_x,q_y),0)
$$

```glsl
float sdBox(vec2 p, vec2 center, vec2 halfSize) {
    vec2 q = abs(p - center) - halfSize;
    return length(max(q, 0.0)) + min(max(q.x, q.y), 0.0);
}
```

이 식은 사각형 바깥에서는 가장 가까운 모서리 또는 변까지의 실제 거리를 계산하고, 안쪽에서는 가장 가까운 경계까지의 음의 거리를 반환한다.

## 왜 절댓값을 사용하는가

사각형 중심의 오른쪽과 왼쪽, 위쪽과 아래쪽은 대칭이다. `abs(p - center)`를 사용하면 네 방향을 첫 사분면의 문제로 접을 수 있다. 이후 반크기를 빼면 각 축에서 경계를 얼마나 넘었는지 알 수 있다.

```text
local = abs(position - center)
outsideAmount = local - halfSize
```

절댓값은 대칭 도형의 거리 함수를 간단히 만드는 도구다. 원은 회전 대칭이라 길이 하나로 충분하지만, 사각형은 x축과 y축의 범위를 따로 비교해야 한다.

## 채움과 외곽선

사각형 SDF를 얻은 뒤의 처리 방식은 원과 같다.

```glsl
float d = sdBox(position, center, halfSize);
float fillMask = 1.0 - smoothstep(-edgeWidth, edgeWidth, d);
float outlineMask = 1.0 - smoothstep(
    strokeWidth,
    strokeWidth + edgeWidth,
    abs(d)
);
```

도형의 종류가 바뀌어도 `d<0`이 안쪽, `d=0`이 경계, `abs(d)`가 외곽선 거리라는 해석은 유지된다. 이것이 SDF가 여러 도형을 같은 방식으로 다루게 하는 이유다.

## 둥근 사각형

둥근 사각형은 사각형의 모서리를 일정 반지름만큼 둥글게 만든 형태다. 사각형 SDF에서 둥근 반지름을 빼면 된다.

$$
d_{roundBox}=d_{box}-r
$$

```glsl
float sdRoundBox(vec2 p, vec2 center, vec2 halfSize, float radius) {
    vec2 reducedHalfSize = halfSize - vec2(radius);
    vec2 q = abs(p - center) - reducedHalfSize;
    return length(max(q, 0.0)) + min(max(q.x, q.y), 0.0) - radius;
}
```

`radius`는 반크기보다 클 수 없다. 너무 큰 값을 허용하면 안쪽 직선 구간이 사라져 캡슐이나 원과 비슷한 형태가 된다. 의도한 모양을 유지하려면 반지름을 작은 축의 반크기 이하로 제한한다.

```text
radius = min(requestedRadius, min(halfSize.x, halfSize.y))
```

## 비균일한 모서리 반지름

각 모서리마다 다른 둥근 반지름을 주는 것은 가능하지만, 현재 점이 어느 사분면에 있는지에 따라 반지름을 선택해야 한다. 이때도 중심 기준 좌표의 부호를 사용한다.

```text
if local.x < 0 and local.y < 0:
    cornerRadius = topLeftRadius
else if local.x >= 0 and local.y < 0:
    cornerRadius = topRightRadius
...
```

사용자 인터페이스처럼 각 모서리를 다르게 처리해야 하는 경우에는 실제 라이브러리의 둥근 사각형 API가 더 간단할 수 있다. SDF 방식은 반지름이 좌표나 노이즈에 따라 변하거나, 모서리를 다른 거리 함수와 합성할 때 장점이 있다.

## 회전한 사각형

앞의 사각형 공식은 축에 평행한 경우를 가정한다. 사각형 자체를 회전시키기보다 현재 좌표를 반대 방향으로 회전한 뒤 같은 SDF에 넣으면 된다.

```text
local = position - center
local = rotate(local, -angle)
distanceValue = sdBox(local, origin, halfSize)
```

도형을 회전시키는 것과 샘플 좌표를 역회전시키는 것은 같은 결과를 만든다. 이 좌표 변환 원리는 다음 Part에서 더 자세히 다룬다.

## 실제 라이브러리에서의 사각형

SVG의 `<rect>`, Canvas 2D의 `fillRect()`와 `roundRect()`, p5.js의 `rect()`는 사각형 객체를 직접 그린다. 둥근 모서리는 각 API의 반지름 인자로 지정할 수 있다.

```javascript
// p5.js 예제
rect(x, y, width, height, cornerRadius);
```

거리 함수는 사각형 내부에 거리 기반 질감을 넣거나, 외곽선 폭을 계산하거나, 원·선분과 매끄럽게 합성할 때 특히 적합하다.

## 이 절의 핵심

사각형 SDF는 중심 기준 좌표의 절댓값과 반크기를 비교해 만든다. 바깥에서는 경계까지의 양의 거리, 안쪽에서는 가장 가까운 변까지의 음의 거리를 반환한다.

둥근 사각형은 사각형 거리값에서 모서리 반지름을 빼는 방식으로 만들 수 있다. 다음 절에서는 더 일반적인 삼각형과 다각형의 경계까지 거리를 계산하는 방법을 살펴본다.
