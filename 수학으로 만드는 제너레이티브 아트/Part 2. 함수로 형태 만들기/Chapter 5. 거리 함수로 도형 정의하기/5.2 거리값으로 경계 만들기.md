# 5.2 거리값으로 경계 만들기

거리 함수는 좌표마다 연속적인 값을 반환한다. 이 값을 도형의 안과 밖으로 나누려면 기준이 필요하다. 가장 간단한 방법은 거리와 임계값을 비교하는 것이다. 원에서는 반지름이 그 기준이다.

## 거리와 반지름 비교하기

중심에서 현재 점까지의 거리가 반지름보다 작으면 점은 원 안에 있다.

$$
M(\mathbf{p})=
\begin{cases}
1, & \lVert\mathbf{p}-\mathbf{c}\rVert<r \\
0, & \text{otherwise}
\end{cases}
$$

```text
distanceValue = length(position - center)
mask = 1 if distanceValue < radius else 0
```

결과는 0과 1로 이루어진 이진 마스크다. 마스크를 색이나 투명도에 연결하면 원 안쪽만 표시할 수 있다.

```glsl
float d = length(position - center);
float mask = 1.0 - step(radius, d);
vec3 color = baseColor * mask;
```

GLSL의 `step(edge, x)`는 `x`가 `edge`보다 작으면 0을, 크거나 같으면 1을 반환한다. 원 안을 1로 표시하려고 결과를 1에서 뺀다.

## 경계는 값이 바뀌는 위치다

도형의 경계는 거리값이 임계값과 같아지는 곳이다.

$$
d(\mathbf{p})=r
$$

원에서는 이 식을 만족하는 점들이 원주를 이룬다. 다른 거리 함수도 같은 방식으로 경계를 정의한다. 선분까지의 거리가 선 두께의 절반인 지점은 선의 외곽선이며, 사각형까지의 거리가 0인 지점은 사각형의 경계다.

거리 함수에서 도형 안쪽과 바깥쪽은 경계를 기준으로 값이 달라지는 두 영역이다.

## 단단한 경계와 부드러운 경계

임계값을 한 번 비교하면 경계가 갑자기 바뀐다. 선명한 픽셀 아트나 이진 마스크에는 적합하지만 화면을 확대하면 계단 현상이 드러날 수 있다. 전환 구간을 두면 경계를 부드럽게 표현할 수 있다.

```glsl
float softMask = 1.0 - smoothstep(
    radius - edgeWidth,
    radius + edgeWidth,
    distanceValue
);
```

`edgeWidth`는 경계가 양쪽으로 퍼지는 폭이다. 거리값이 `radius - edgeWidth`보다 작으면 결과는 1에 가깝고, `radius + edgeWidth`보다 크면 0에 가깝다.

| 경계 방식 | 계산 | 시각적 결과 |
| --- | --- | --- |
| 단단한 경계 | `step` | 선명한 마스크 |
| 부드러운 경계 | `smoothstep` | 페이드, 안티앨리어싱 |
| 좁은 띠 | 두 경계의 차 | 외곽선 |
| 반복 임계값 | 거리의 주기화 | 고리, 등고선 |

## 외곽선 만들기

경계 주변의 좁은 영역만 표시하면 외곽선이 된다. 거리와 반지름의 차에 절댓값을 취해 경계까지 떨어진 거리를 구한다.

$$
e=|d-r|
$$

```glsl
float edgeDistance = abs(distanceValue - radius);
float outline = 1.0 - smoothstep(
    lineWidth,
    lineWidth + edgeWidth,
    edgeDistance
);
```

선 두께를 좌표 단위가 아닌 픽셀 단위로 일정하게 유지하려면 현재 픽셀의 크기를 고려해야 한다. 프래그먼트 셰이더에서는 `fwidth`로 거리값의 화면 미분을 구해 경계 폭에 반영할 수 있다.

```glsl
float pixelWidth = fwidth(distanceValue);
float outline = 1.0 - smoothstep(lineWidth, lineWidth + pixelWidth, edgeDistance);
```

## 채움과 외곽선을 함께 사용하기

채움 마스크와 외곽선 마스크는 서로 다른 색으로 조합할 수 있다.

```glsl
float fillMask = 1.0 - smoothstep(radius - edgeWidth, radius + edgeWidth, d);
float outlineMask = 1.0 - smoothstep(lineWidth, lineWidth + edgeWidth, abs(d - radius));

vec3 color = mix(backgroundColor, fillColor, fillMask);
color = mix(color, outlineColor, outlineMask);
```

레이어 기반 도구는 SVG의 `fill`과 `stroke`, Canvas 2D의 `fill()`과 `stroke()`처럼 채움과 외곽선을 나누어 제공한다. 거리 함수에서는 두 마스크를 직접 계산해 같은 효과를 구성한다.

## 범위가 있는 경계

두 반지름 사이에 있는 거리값만 표시하면 고리나 띠가 된다.

$$
r_{in}\le d<r_{out}
$$

```text
insideOuter = d < outerRadius
outsideInner = d >= innerRadius
ringMask = insideOuter and outsideInner
```

부드러운 고리는 안쪽과 바깥쪽 경계를 각각 부드럽게 만든 다음 두 마스크를 곱해 표현한다.

```glsl
float outerMask = 1.0 - smoothstep(outerRadius - w, outerRadius + w, d);
float innerMask = smoothstep(innerRadius - w, innerRadius + w, d);
float ringMask = outerMask * innerMask;
```

## 거리의 부호가 필요한 이유

일반 거리값은 0 이상이다. 이 값으로 경계와 외곽선을 만들 수 있다. 안쪽과 바깥쪽을 구분하려면 별도로 비교하거나, 부호 있는 거리 함수를 사용한다. 부호 있는 거리 함수는 안쪽을 음수, 바깥쪽을 양수로 정해 이 정보를 값에 담는다.

$$
d(\mathbf{p})
\begin{cases}
<0, & \text{inside} \\
=0, & \text{on boundary} \\
>0, & \text{outside}
\end{cases}
$$

부호 있는 거리장(SDF)은 5.7절에서 자세히 다룬다. SDF 하나로 채움, 외곽선, 바깥 그라데이션을 만들 수 있다.

## 이 절의 핵심

거리값과 임계값을 비교해 도형의 안과 밖을 나눈다. `step`은 단단한 경계를, `smoothstep`은 폭이 있는 부드러운 경계를 만든다. 거리와 반지름의 차이로 외곽선을, 두 임계값 사이의 영역으로 고리를 만들 수 있다.
