# 5.2 거리값으로 경계 만들기

거리 함수는 연속적인 숫자를 반환한다. 도형으로 보이게 하려면 이 값에서 어디가 안쪽이고 어디가 바깥인지 정해야 한다. 가장 간단한 방법은 거리와 임계값을 비교하는 것이다. 원의 경우 기준은 반지름이 된다.

## 거리와 반지름 비교하기

중심에서의 거리가 반지름보다 작으면 현재 점은 원 안에 있다.

$$
M(\mathbf{p})=
\begin{cases}
1, & \lVert\mathbf{p}-\mathbf{c}\rVert<r \\
0, & \text{otherwise}
\end{cases}
$$

```text
distanceValue = length(position - center)
mask = 1 if distanceValue < radius else 0
```

0과 1로 이루어진 이 결과는 이진 마스크다. 마스크를 색이나 투명도에 연결하면 원 안의 영역만 보인다.

```glsl
float d = length(position - center);
float mask = 1.0 - step(radius, d);
vec3 color = baseColor * mask;
```

GLSL의 `step(edge, x)`는 `x`가 `edge`보다 작으면 0, 크거나 같으면 1을 반환한다. 따라서 원 안을 1로 만들기 위해 1에서 뺀다.

## 경계는 값이 바뀌는 위치다

도형의 경계는 거리값이 기준값과 같아지는 지점이다.

$$
d(\mathbf{p})=r
$$

원에서는 이 식을 만족하는 점들이 원주를 이룬다. 다른 거리 함수에서도 같은 방식으로 경계를 정의할 수 있다. 선분까지의 거리가 선 두께의 절반과 같은 위치는 선의 외곽선이 되고, 사각형까지의 거리가 0인 위치는 사각형의 경계가 된다.

거리 함수를 보면 “도형 안쪽”과 “도형 바깥쪽”은 경계를 기준으로 값이 달라지는 두 영역으로 이해할 수 있다.

## 단단한 경계와 부드러운 경계

임계값을 한 번 비교하면 경계가 갑자기 바뀐다. 선명한 픽셀 아트나 이진 마스크에는 적합하지만, 확대된 화면에서는 계단 현상이 보일 수 있다. 전환 구간을 두면 경계를 부드럽게 만들 수 있다.

```glsl
float softMask = 1.0 - smoothstep(
    radius - edgeWidth,
    radius + edgeWidth,
    distanceValue
);
```

`edgeWidth`는 경계 양쪽으로 퍼지는 폭이다. 거리값이 `radius - edgeWidth`보다 작으면 1에 가깝고, `radius + edgeWidth`보다 크면 0에 가깝다.

| 경계 방식 | 계산 | 시각적 결과 |
| --- | --- | --- |
| 단단한 경계 | `step` | 선명한 마스크 |
| 부드러운 경계 | `smoothstep` | 페이드, 안티앨리어싱 |
| 좁은 띠 | 두 경계의 차 | 외곽선 |
| 반복 임계값 | 거리의 주기화 | 고리, 등고선 |

## 외곽선 만들기

경계 주변의 좁은 영역만 보이게 하면 외곽선을 만들 수 있다. 거리와 반지름의 차이의 절댓값을 사용하면 경계에서 얼마나 떨어져 있는지 구할 수 있다.

$$
e=|d-r|
$$

```glsl
float edgeDistance = abs(distanceValue - radius);
float outline = 1.0 - smoothstep(
    lineWidth,
    lineWidth + edgeWidth,
    edgeDistance
);
```

선 두께를 좌표 단위가 아니라 픽셀 단위로 일정하게 유지하려면 현재 픽셀의 크기를 고려해야 한다. 프래그먼트 셰이더에서는 `fwidth`로 거리값의 화면 미분을 얻어 경계 폭에 사용할 수 있다.

```glsl
float pixelWidth = fwidth(distanceValue);
float outline = 1.0 - smoothstep(lineWidth, lineWidth + pixelWidth, edgeDistance);
```

## 채움과 외곽선을 함께 사용하기

채움 마스크와 외곽선 마스크는 서로 다른 색으로 조합할 수 있다.

```glsl
float fillMask = 1.0 - smoothstep(radius - edgeWidth, radius + edgeWidth, d);
float outlineMask = 1.0 - smoothstep(lineWidth, lineWidth + edgeWidth, abs(d - radius));

vec3 color = mix(backgroundColor, fillColor, fillMask);
color = mix(color, outlineColor, outlineMask);
```

실제 레이어 기반 도구에서는 SVG의 `fill`과 `stroke`, Canvas 2D의 `fill()`과 `stroke()`처럼 채움과 외곽선을 분리해 제공한다. 거리 함수에서는 두 영역의 마스크를 직접 계산해 같은 효과를 만든다.

## 범위가 있는 경계

거리값이 두 반지름 사이에 있을 때만 보이게 하면 고리나 띠가 된다.

$$
r_{in}\le d<r_{out}
$$

```text
insideOuter = d < outerRadius
outsideInner = d >= innerRadius
ringMask = insideOuter and outsideInner
```

부드러운 고리는 안쪽 경계와 바깥쪽 경계를 각각 부드럽게 만든 뒤 곱할 수 있다.

```glsl
float outerMask = 1.0 - smoothstep(outerRadius - w, outerRadius + w, d);
float innerMask = smoothstep(innerRadius - w, innerRadius + w, d);
float ringMask = outerMask * innerMask;
```

## 거리의 부호가 필요한 이유

지금까지의 일반 거리값은 0 이상이다. 이 값만으로도 경계와 외곽선은 만들 수 있지만, 안쪽과 바깥쪽을 구분하려면 별도의 비교가 필요하다. 부호 있는 거리 함수는 안쪽을 음수, 바깥쪽을 양수로 정의해 이 정보를 값 자체에 담는다.

$$
d(\mathbf{p})
\begin{cases}
<0, & \text{inside} \\
=0, & \text{on boundary} \\
>0, & \text{outside}
\end{cases}
$$

부호 있는 거리장(SDF)은 5.7절에서 자세히 다룬다. SDF를 사용하면 채움, 외곽선, 바깥 그라데이션을 같은 함수 하나에서 자연스럽게 만들 수 있다.

## 이 절의 핵심

거리값과 임계값을 비교하면 도형의 안과 밖을 나눌 수 있다. `step`은 단단한 경계를, `smoothstep`은 폭을 가진 부드러운 경계를 만든다. 거리와 기준 반지름의 차이를 사용하면 외곽선을 만들 수 있고, 두 임계값 사이를 선택하면 고리를 만들 수 있다.
