# 4.1 함수 그래프에서 시각 패턴으로

앞 파트에서는 좌표를 입력해 값을 계산하고, 그 결과를 색, 크기, 위치, 회전 같은 시각 요소에 연결하는 방법을 다루었다. 이 절에서는 계산의 중심에 함수를 놓는다. 함수는 입력값과 출력값의 관계를 정하는 규칙이다. 제너레이티브 아트에서는 이 규칙이 선, 곡선, 밝기 변화, 반복 패턴, 움직임의 구조를 만든다.

가장 익숙한 함수 표기는 다음과 같다.

$$
y=f(x)
$$

$x$를 입력하면 함수 $f$는 출력값 $y$를 반환한다. 수학에서는 이 관계를 좌표평면에 그래프로 그린다. 제너레이티브 아트에서는 같은 관계를 점의 위치, 도형의 크기, 색상, 회전각에 연결할 수 있다. 함수 그래프는 시각 규칙을 설계하는 출발점으로 활용된다.

## 함수 그래프를 좌표의 관계로 읽기

그래프의 한 점은 입력 $x$와 출력 $y$가 이루는 좌표 $(x,y)$다. 여러 $x$값을 선택해 각각의 $y$값을 계산하고 점들을 이어 주면 함수의 그래프가 나타난다.

```text
for each x in inputRange:
    y = f(x)
    drawPoint(x, y)
```

그래프에서는 $x$를 입력으로, $y$를 출력으로 읽는다. 같은 두 변수를 사용해도 관계를 $x=f(y)$로 바꾸면 다른 곡선이 될 수 있다. 제너레이티브 작업에서도 어떤 값을 입력과 출력으로 선택하는지에 따라 이미지 구조가 달라진다.

예를 들어 화면의 가로 위치를 입력으로, 세로 위치를 출력으로 쓰면 선의 경로를 만들 수 있다.

$$
y=f(x)
$$

같은 함숫값을 밝기로 쓰면 가로 방향의 명암 패턴이 된다.

$$
B(x,y)=f(x)
$$

여기서는 $y$좌표가 함수의 입력이 아니므로 같은 $x$ 위치의 픽셀은 모두 같은 밝기를 갖는다. 선 그래프와 세로 줄무늬는 같은 함수에서 출발하며, 함수값을 위치와 밝기 중 어디에 연결하는지에 따라 달라진다.

## 그래프를 화면 좌표에 맞추기

수학 좌표와 화면 좌표는 원점과 $y$축 방향이 다를 수 있다. 수학 좌표에서는 $y$가 커질수록 위로, 많은 화면 좌표계에서는 아래로 향한다. 수학 그래프와 같은 방향으로 화면에 표시하려면 세로축을 뒤집어야 한다.

화면 중심을 $(W/2,H/2)$로 두고 수학 좌표의 한 단위를 $s$픽셀로 표현하자. 수학 좌표 $(x_m,y_m)$를 화면 좌표 $(x_s,y_s)$로 옮기는 식은 다음과 같다.

$$
x_s=\frac{W}{2}+sx_m
$$

$$
y_s=\frac{H}{2}-sy_m
$$

음수 부호가 화면의 세로축 방향을 보정한다. 좌표 변환을 함수 계산과 분리하면 수학 좌표계에서 함수를 정의하고, 화면에 그릴 때만 화면 좌표계로 옮기면 된다.

```text
for each mathX in range:
    mathY = f(mathX)
    screenX = screenCenterX + mathX * scale
    screenY = screenCenterY - mathY * scale
    drawPoint(screenX, screenY)
```

## 입력 범위와 출력 범위

함수 그래프를 화면에 알맞게 표시하려면 입력과 출력의 범위를 정해야 한다. $x$를 너무 넓은 범위에서 샘플링하면 세부 구조가 압축되고, 너무 좁은 범위만 보면 함수 전체의 성격을 파악하기 어렵다. 출력값이 화면 범위를 크게 벗어나면 곡선 대부분이 잘린다.

따라서 그래프를 그릴 때는 보통 다음 세 범위를 분리한다.

| 범위 | 역할 | 예 |
| --- | --- | --- |
| 함수의 입력 범위 | 어떤 $x$값을 계산할지 정한다. | $-\pi$에서 $\pi$ |
| 함수의 출력 범위 | 함수가 낼 수 있는 값의 범위다. | $-1$에서 $1$ |
| 화면의 표시 범위 | 값을 몇 픽셀 또는 어떤 좌표 범위로 보일지 정한다. | 화면 높이의 80퍼센트 |

입력 범위와 출력 범위는 함수의 성질에 속하고, 표시 범위는 화면 구성에 따라 정한다. 이를 구분하면 같은 함수를 크기가 다른 캔버스나 장면에서도 재사용하기 쉽다.

## 점, 선, 도형으로 그래프 나타내기

함수 출력은 여러 방식으로 화면에 나타낼 수 있다. 계산한 좌표에 점을 찍는 것이 가장 직접적이며, 이웃한 점을 선분으로 연결하면 연속적인 곡선처럼 보인다.

```text
previousPoint = none

for each x in inputRange:
    y = f(x)
    point = toScreenSpace(x, y)

    if previousPoint exists:
        drawLine(previousPoint, point)

    previousPoint = point
```

같은 값을 도형의 크기나 색으로 연결할 수도 있다.

```text
for each x in inputRange:
    value = f(x)
    position = (x, baseline)
    diameter = remap(value, outputMin, outputMax, minDiameter, maxDiameter)
    color = colorFromNormalizedValue(value)
    drawCircle(position, diameter, color)
```

함수 그래프는 곡선뿐 아니라 도형의 크기와 색이 변하는 구조로도 나타낼 수 있다.

## 샘플링 간격이 만드는 차이

컴퓨터는 연속 함수를 유한한 위치에서 계산하며, 이 과정을 샘플링이라고 한다. $x$를 얼마나 촘촘히 선택하는지에 따라 곡선이 부드럽게 보이거나 꺾이고 왜곡될 수 있다.

```text
for x from inputMin to inputMax with step sampleStep:
    y = f(x)
    record(x, y)
```

`sampleStep`이 크면 계산량은 줄지만 급격히 변하는 구간을 놓칠 수 있다. 주파수가 높은 파동은 샘플 간격이 충분히 작지 않을 때 실제보다 느린 파동처럼 보이는 앨리어싱이 생길 수 있다.

| 샘플 간격 | 장점 | 주의할 점 |
| --- | --- | --- |
| 큼 | 계산이 적고 구조를 빠르게 확인 | 곡선의 세부 변화가 사라질 수 있음 |
| 작음 | 부드러운 곡선과 세부 패턴 | 계산량 증가, 출력 해상도 이상의 샘플은 효과가 작음 |
| 적응형 | 급한 구간에 샘플을 더 배치 | 구현이 복잡해짐 |

화면에 선을 그릴 때는 보통 픽셀 간격보다 조금 더 촘촘히 샘플링하면 충분하다. 함수의 변화 속도와 확대 배율에 따라 필요한 간격은 달라진다.

## 하나의 함수, 여러 시각 표현

다음 함수는 입력이 커질수록 출력도 커지는 단순한 관계다.

$$
f(x)=x
$$

이 함수를 서로 다른 속성에 연결하면 서로 다른 결과가 나온다.

| 함수의 출력 연결 | 시각적 결과 |
| --- | --- |
| 점의 세로 위치 | 대각선 그래프 |
| 점의 가로 위치 | 수평 방향 이동 |
| 밝기 | 왼쪽에서 오른쪽으로 변하는 그라데이션 |
| 원의 지름 | 점점 커지는 도형 배열 |
| 회전각 | 차례로 회전하는 기호들 |
| 선 두께 | 굵기가 변하는 선 |

같은 함수도 어떤 시각 요소에 연결하는지에 따라 다르게 읽힌다. 함수와 출력의 연결 방식을 함께 설계해야 한다.

## 여러 입력을 받는 함수로 확장하기

1차원 함수는 입력이 하나다.

$$
y=f(x)
$$

화면은 2차원 공간이므로 두 좌표를 입력으로 받는 함수도 자주 쓰인다.

$$
v=f(x,y)
$$

이 함수는 화면의 각 위치에서 하나의 값을 반환한다. 이 값을 밝기에 연결하면 2차원 패턴이나 필드가 된다. 예를 들어 $f(x,y)=x+y$는 대각선 방향으로 변하는 그라데이션을, $f(x,y)=\sin(x)+\sin(y)$는 가로와 세로 파동이 겹친 패턴을 만든다.

이 장의 앞부분에서는 1차원 함수가 만드는 선과 값의 변화를 다루고, 마지막 절에서는 이를 2차원 좌표 전체로 확장한다.

## 함수 그래프는 규칙을 관찰하는 도구다

제너레이티브 작업에서 그래프는 결과물에 앞서 규칙을 살펴보는 중간 표현으로도 쓰인다. 노이즈의 분포, 이징 함수의 속도 변화, 거리값의 범위, 데이터 재매핑이 예상대로 작동하는지 확인할 수 있다.

값이 한쪽에 몰린다면 그래프를 보고 정규화나 비선형 변환이 필요한지 판단할 수 있다. 경계에서 값이 갑자기 끊기는 모습은 단계 함수나 클램프가 적용된 위치를 드러낸다. 함수를 이미지에 연결하기 전에 그래프로 살펴보면 계산 규칙을 더 분명히 확인할 수 있다.

## 이 절의 핵심

함수 그래프는 입력과 출력의 관계를 좌표로 나타낸 것이다. 제너레이티브 아트에서는 같은 관계를 선의 경로, 밝기, 크기, 색, 회전처럼 여러 시각 속성에 연결할 수 있다.

그래프를 화면에 표시할 때는 수학 좌표와 화면 좌표의 차이, 입력·출력 범위, 샘플링 간격을 함께 고려한다. 다음 절에서는 가장 단순한 함수인 직선과 비례 관계가 시각 패턴에서 하는 역할을 살펴본다.
