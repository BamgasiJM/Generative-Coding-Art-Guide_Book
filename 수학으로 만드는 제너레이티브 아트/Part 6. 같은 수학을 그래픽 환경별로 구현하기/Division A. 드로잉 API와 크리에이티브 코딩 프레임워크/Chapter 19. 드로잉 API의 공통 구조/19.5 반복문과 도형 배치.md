# 19.5 반복문과 도형 배치

드로잉 API에서 반복문은 같은 도형을 여러 번 호출하는 문법이지만, 제너레이티브 아트에서는 좌표와 관계를 생성하는 장치다. 반복 인덱스 $i$, $j$는 단순한 순번이 아니라 위치, 크기, 회전, 색, 시간차를 계산하는 입력이 된다. 점 하나를 그리는 명령과 반복 규칙이 결합될 때 격자, 파동, 방사형 구조, 입자군, 타일 패턴이 만들어진다.

```text
for each index i:
    position = positionFrom(i)
    style = styleFrom(i)
    drawShape(position, style)
```

이 구조에서 중요한 것은 `drawShape`보다 `positionFrom`과 `styleFrom`이다. 원이라는 도형은 같아도 인덱스를 어떤 좌표로 바꾸고 어떤 함수로 속성을 정하는지에 따라 전혀 다른 이미지를 만든다.

## 선형 배치

가장 단순한 반복은 한 축을 따라 요소를 배치하는 것이다. 인덱스 $i$에 간격 $s$를 곱하면 등간격 위치를 얻는다.

$$
x_i=x_0+i\,s
$$

```text
for i from 0 to count - 1:
    x = margin + i * spacing
    drawCircle(x, centerY, radius)
```

화면 크기가 바뀔 수 있는 작업에서는 간격을 고정 픽셀이 아니라 사용 가능한 폭을 기준으로 계산할 수 있다.

$$
s=\frac{W-2m}{N-1}
$$

여기서 $m$은 바깥 여백, $N$은 요소 수다. 요소가 하나뿐인 경우에는 $N-1$로 나누지 않도록 따로 처리한다. 이러한 작은 경계 조건은 제너레이티브 패턴에서 자주 나타난다. 인덱스가 0부터 시작하는지, 끝값을 포함하는지도 화면의 여백과 개수에 영향을 준다.

선형 배치는 파동을 보여 주기 좋은 구조다. x 위치는 일정하게 두고 y 위치나 크기를 함수로 바꾸면, 반복 인덱스가 연속 변수의 표본이 된다.

$$
y_i=y_c+A\sin(ki+\phi)
$$

```text
for i from 0 to count - 1:
    x = map(i, 0, count - 1, left, right)
    y = centerY + amplitude * sin(i * frequency + phase)
    drawCircle(x, y, radius)
```

## 중첩 반복과 격자

두 개의 반복문을 중첩하면 행과 열을 가진 격자를 만들 수 있다. 열 인덱스 $i$와 행 인덱스 $j$는 2차원 좌표의 자연스러운 이산 표현이다.

$$
\mathbf{p}_{ij}=\left(m_x+i\,s_x,\;m_y+j\,s_y\right)
$$

```text
for row from 0 to rows - 1:
    for col from 0 to cols - 1:
        x = marginX + col * cellWidth
        y = marginY + row * cellHeight
        drawRectangle(x, y, cellWidth, cellHeight)
```

격자 전체를 화면 크기에 맞출 때는 셀 크기와 여백의 관계를 먼저 결정한다. 셀 수를 고정하고 셀 크기를 계산할지, 셀 크기를 고정하고 화면에 들어가는 셀 수를 계산할지는 다른 선택이다. 전자는 반응형 레이아웃에, 후자는 인쇄물이나 픽셀 격자에 적합하다.

각 셀의 중심에서 화면 중심까지의 거리나 각도를 계산하면 단순한 격자가 방사형·파동·대칭 패턴의 표본 집합이 된다.

```text
offset = cellCenter - canvasCenter
radius = length(offset)
angle = atan2(offset.y, offset.x)
size = baseSize + amount * sin(radius * frequency)
rotation = angle
```

이처럼 반복문은 도형을 배치하고, 함수는 배치된 각 도형의 속성을 결정한다. 격자 자체는 규칙적이지만 거리·각도·노이즈를 사용하면 중심에서 퍼지는 변화나 부드러운 지역 차이를 만들 수 있다.

## 인덱스와 정규화된 매개변수

반복 인덱스 $i$는 정수지만, 이를 $[0,1]$ 범위의 매개변수 $t$로 바꾸면 함수에 연결하기 편하다.

$$
t=\frac{i}{N-1}
$$

```text
t = i / max(count - 1, 1)
size = interpolate(minSize, maxSize, t)
color = interpolate(colorA, colorB, t)
```

정규화한 인덱스는 요소 수가 바뀌어도 같은 변화의 흐름을 유지하게 한다. 예를 들어 첫 요소는 항상 작은 원, 마지막 요소는 항상 큰 원이 되며, 중간 요소는 매끄럽게 보간된다. 인덱스 자체를 사인 함수에 넣는 것과 $t$를 넣는 것은 다르다. 요소 수가 변해도 같은 파형 횟수를 유지하고 싶다면 $t$에 주파수를 곱한다.

$$
v_i=\sin(2\pi k t)
$$

여기서 $k$는 전체 배열에서 반복할 파형의 횟수다. `sin(i * k)`처럼 쓰면 요소 수가 늘어날 때 파동의 전체 모습도 달라진다.

## 극좌표를 이용한 반복 배치

반복 인덱스를 각도로 바꾸면 원 위에 요소를 배치할 수 있다. $N$개 요소에 대한 각도 간격은 $2\pi/N$이다.

$$
\theta_i=\frac{2\pi i}{N},\qquad
x_i=c_x+r\cos\theta_i,\quad y_i=c_y+r\sin\theta_i
$$

```text
for i from 0 to count - 1:
    angle = TAU * i / count
    position = center + radius * vector(cos(angle), sin(angle))
    drawCircle(position, dotRadius)
```

각 요소를 접선 방향으로 회전하려면 `angle + PI / 2`를 회전값으로 쓸 수 있다. 반지름을 인덱스에 따라 늘리면 나선이 되고, 각도에 다른 주파수의 함수를 더하면 꽃잎이나 별 모양의 분포가 된다. Part 3에서 다룬 극좌표 규칙은 드로잉 API의 반복문 안에서 바로 도형 배치로 번역된다.

## 변환 스택으로 반복하기

반복문에서 각 요소의 모든 꼭짓점을 새로 계산할 필요는 없다. 로컬 좌표로 도형 하나를 정의하고, 반복마다 변환 상태만 바꿔 그리면 된다. 이는 같은 모티프를 다른 위치·크기·회전으로 배치할 때 특히 유용하다.

```text
for each item:
    pushTransform()
    translate(item.position)
    rotate(item.angle)
    scale(item.size)
    drawUnitMotif()
    popTransform()
```

`drawUnitMotif()`는 원점 근처에 있는 작은 선이나 다각형을 그린다. 배치 규칙과 모티프의 기하를 분리하면 모티프를 바꾸어도 전체 구조는 유지되고, 전체 배치 규칙을 바꾸어도 개별 도형 코드는 유지된다. 중첩 변환은 프랙탈 분기, 회전 대칭, 계층적 패턴에도 자연스럽게 확장된다.

## 규칙적 반복에 변화 더하기

모든 요소가 같으면 반복 구조가 선명하게 보인다. 여기에 변화가 필요할 때는 무엇을 고정하고 무엇을 바꿀지 정한다. 위치를 고정한 채 색과 크기만 바꾸면 격자의 질서가 유지된다. 위치까지 무작위로 흔들면 더 유기적이지만 셀 간의 관계가 약해진다.

```text
seedValue = hash(col, row, seed)
size = baseSize * interpolate(0.6, 1.4, seedValue)
rotation = seedValue * TAU
```

셀 좌표와 시드에서 얻는 고정 난수는 프레임마다 결과가 바뀌지 않는다. 시간에 따라 움직임을 더하고 싶다면 `noise(col, row, time)`처럼 연속적인 값이나 별도의 시간 함수를 사용한다. 랜덤 값을 도형 속성마다 새로 뽑는 대신, 하나의 값을 크기·색·회전에 함께 연결하면 셀마다 읽을 수 있는 성격이 생긴다.

## 반복의 비용과 표현 밀도

반복 횟수가 늘면 화면의 밀도뿐 아니라 렌더링 비용도 증가한다. 한 프레임에 100개의 원을 그리는 것과 100만 개의 선을 그리는 것은 매우 다르다. 먼저 필요한 시각 밀도를 정하고, 보이지 않는 작은 요소나 화면 밖 요소는 건너뛴다.

```text
if position is outside viewport plus margin:
    continue
```

밀도가 높은 패턴에서는 모든 요소를 개별 도형 호출로 그리는 대신, 오프스크린 이미지에 한 번 렌더링해 재사용하거나, 인스턴싱·셰이더 기반 표현으로 옮기는 방법도 있다. 하지만 성능 최적화 전에 구조를 단순하게 유지하는 것이 중요하다. 보통은 셀 수, 선분 수, 입자 수를 단계적으로 올려 실제 병목을 확인하는 편이 낫다.

## 반복문을 공간 규칙으로 읽기

반복문은 컴퓨터에게 같은 일을 여러 번 시키는 문법이다. 제너레이티브 아트에서는 더 나아가, 인덱스를 공간으로 바꾸고 공간의 값을 도형 속성으로 바꾸는 변환 장치다. 선형 인덱스, 행·열 인덱스, 각도 인덱스, 재귀 깊이는 각각 다른 종류의 공간 구조를 만든다.

반복문을 작성할 때는 먼저 다음을 정한다. 반복의 단위가 무엇인지, 인덱스가 어떤 좌표가 되는지, 각 요소에서 어떤 함수가 평가되는지, 그 결과가 어떤 시각 속성에 연결되는지다. 이 네 가지가 분명하면 환경의 반복 문법이 달라도 같은 패턴 규칙을 옮길 수 있다.

## 이 절의 핵심

반복문은 도형을 늘리는 도구이면서 인덱스를 좌표와 시각 속성으로 바꾸는 공간 규칙이다. 선형·격자·극좌표 반복을 사용해 구조를 만들고, 정규화한 인덱스·함수·변환 스택·고정 난수를 결합하면 반복의 질서를 유지하며 풍부한 변화를 만들 수 있다.
