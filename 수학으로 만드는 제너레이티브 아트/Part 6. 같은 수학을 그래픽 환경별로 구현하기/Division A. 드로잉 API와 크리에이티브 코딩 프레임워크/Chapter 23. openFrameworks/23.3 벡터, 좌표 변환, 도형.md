# 23.3 벡터, 좌표 변환, 도형

제너레이티브 아트에서 점의 위치와 이동 방향을 계산하고, 도형을 다른 위치와 방향에 배치하는 일은 모두 좌표를 다루는 작업이다. openFrameworks는 C++의 벡터 자료형과 드로잉 API, 변환 행렬을 함께 사용해 이 계산을 화면으로 옮긴다. 이 절에서는 현대 openFrameworks 코드에서 사용하는 `glm::vec2`를 중심으로 벡터 계산과 좌표 변환, 기본 도형 API를 살펴본다.

## 2D 좌표와 벡터

기본적인 2D 창 좌표계에서는 원점 `(0, 0)`이 왼쪽 위에 있고, x값은 오른쪽으로 증가하며 y값은 아래쪽으로 증가한다. 수학 교과서에서 흔히 쓰는 y축 방향과 반대이므로, 위쪽으로 이동하려면 화면 좌표의 y값을 줄여야 한다. 화면 크기와 좌표는 보통 픽셀 단위로 다룬다.

openFrameworks는 벡터 계산에 GLM 자료형을 사용한다. `glm::vec2`는 두 개의 실수 성분을 가진 벡터로, x와 y 좌표뿐 아니라 속도와 방향도 표현할 수 있다. 구형 예제에서 자주 보이는 `ofVec2f` 대신 새 코드에서는 `glm::vec2`를 기준으로 익히는 것이 좋다.

```cpp
glm::vec2 position(120.0f, 180.0f);
glm::vec2 velocity(90.0f, -35.0f);

position += velocity * dt;
```

벡터의 성분이 같아도 문맥에 따라 의미가 다르다. `position`은 원점에서 측정한 위치이고, `velocity`는 한 초 동안 이동할 방향과 크기를 가진 변화량이다. 위 코드에서 `dt`가 초 단위라면 `velocity * dt`는 이번 갱신에서 이동할 거리다. C++에서는 `glm::vec2`의 덧셈, 뺄셈, 스칼라 곱셈으로 이러한 계산을 간결하게 표현한다.

두 위치의 차를 구하면 한 점에서 다른 점을 향하는 변위 벡터가 된다. 그 길이는 두 점 사이의 거리이며, 정규화하면 길이가 1인 방향 벡터를 얻는다.

```cpp
glm::vec2 toTarget = target - position;
float distance = glm::length(toTarget);

glm::vec2 direction(0.0f, 0.0f);
if (distance > 0.0001f) {
    direction = toTarget / distance;
}
```

거리로 나누는 것은 벡터를 정규화하는 계산이다. 두 위치가 같으면 `distance`가 0이 되므로 나눗셈을 할 수 없다. 이런 경계 상황을 확인한 뒤 정규화하는 습관은 추적, 조향, 힘 계산 등에서 중요하다. `glm::dot(a, b)`는 두 벡터의 내적을 구해 방향의 유사성이나 각도 관계를 계산할 때 사용할 수 있다.

## 좌표 변환의 의미

도형을 실제 캔버스 좌표에 맞춰 매번 다시 계산하는 대신, 도형 자체는 원점 근처의 로컬 좌표(local coordinates)에 두고 좌표계에 변환을 적용할 수 있다. 기본적인 2D 변환은 이동(translation), 회전(rotation), 크기 조절(scaling)이다.

$$
\begin{aligned}
\text{이동:}\quad &(x', y') = (x + t_x, y + t_y) \\
\text{크기 조절:}\quad &(x', y') = (s_x x, s_y y) \\
\text{회전:}\quad &\begin{bmatrix}x' \\ y'\end{bmatrix}
= \begin{bmatrix}\cos\theta & -\sin\theta \\
\sin\theta & \cos\theta\end{bmatrix}
\begin{bmatrix}x \\ y\end{bmatrix}
\end{aligned}
$$

행렬을 쓰면 이 변환들을 합성해 하나의 좌표 변환으로 표현할 수 있다. 이동, 회전, 크기 조절의 순서는 결과를 바꾼다. 예를 들어 도형을 원점에서 회전한 뒤 화면 중심으로 옮기면 제자리에서 방향만 바뀌고, 화면 중심으로 옮긴 뒤 원점을 기준으로 회전하면 중심 주위를 공전하는 경로가 될 수 있다. 어떤 좌표계를 기준으로 변환하는지 먼저 생각해야 한다.

openFrameworks의 `ofTranslate()`, `ofRotateDeg()`, `ofScale()`은 이후 드로잉 호출에 적용될 변환 상태를 구성한다. 회전 함수 이름에 `Deg`가 붙은 API는 각도를 도(degree) 단위로 받는다. 코드에 각도를 넣을 때 라디안과 도를 혼동하지 않도록 주의한다. 화면의 y축이 아래쪽을 향하므로 양의 회전 방향도 수학의 y축을 위로 두고 볼 때와 시각적으로 다르게 느껴질 수 있다.

## 변환 스택으로 반복 배치하기

다음 코드는 같은 직사각형 모티프를 캔버스 중심 주위에 여러 번 배치한다. 각 사각형은 자기 중심을 로컬 원점에 두고, 회전과 이동으로 고리의 한 위치에 놓인다.

```cpp
void ofApp::draw() {
    ofBackground(248);

    const glm::vec2 center(ofGetWidth() * 0.5f,
                           ofGetHeight() * 0.5f);
    const int count = 16;

    for (int index = 0; index < count; ++index) {
        const float angle = 360.0f * index / count;

        ofPushMatrix();
        ofTranslate(center.x, center.y);
        ofRotateDeg(angle, 0.0f, 0.0f, 1.0f);
        ofTranslate(0.0f, -130.0f);

        ofSetColor(index % 2 == 0 ? 40 : 215,
                   index % 2 == 0 ? 125 : 105,
                   index % 2 == 0 ? 170 : 65);
        ofDrawRectangle(-10.0f, -24.0f, 20.0f, 48.0f);
        ofPopMatrix();
    }
}
```

`ofPushMatrix()`는 현재 변환 상태를 저장하고, `ofPopMatrix()`는 저장해둔 상태로 되돌린다. 반복마다 이 쌍을 사용하면 한 사각형에 적용한 회전과 이동이 다음 사각형으로 누적되지 않는다. 변환을 적용한 뒤에는 로컬 좌표에서 그리므로 직사각형의 기준점을 원점에 맞추기 위해 x와 y에 음수 절반 크기를 사용했다.

이 예제의 변환은 사각형의 로컬 위치를 궤도 반지름만큼 옮기고, 각도만큼 회전시킨 뒤, 캔버스 중심으로 배치하는 구조다. `ofTranslate(center.x, center.y)`가 전체 배치의 기준을 만들고, 이어지는 회전과 내부 이동이 그 기준에 종속된다. 행렬 API는 현재 변환 상태에 연속해서 적용되므로, 명령 순서와 로컬 도형의 원점이 어떤 결과를 만드는지 작은 예제로 확인하는 것이 좋다.

`ofPushMatrix()`와 `ofPopMatrix()`는 짝을 이루어야 한다. `ofPopMatrix()`를 빠뜨리면 뒤이어 그리는 도형까지 변환된 좌표계의 영향을 받을 수 있다. 색이나 선 스타일도 드로잉 상태로 유지될 수 있으므로, 반복 중 스타일이 의도치 않게 이어지지 않게 하려면 필요한 값을 명시하거나 `ofPushStyle()`과 `ofPopStyle()`로 스타일 상태를 저장하고 복구한다.

## 도형 API와 복잡한 경로

openFrameworks는 점·선·원·타원·사각형·삼각형 같은 기본 프리미티브(primitive)를 제공한다. `ofDrawCircle(x, y, radius)`는 중심 좌표와 반지름을 받고, `ofDrawEllipse(x, y, width, height)`는 중심 좌표와 가로·세로 크기를 받는다. `ofDrawRectangle(x, y, width, height)`은 기본적으로 좌상단 위치와 크기를 지정한다. 도형마다 기준점의 규약이 다를 수 있으므로 함수의 인자 의미를 확인하고, 로컬 좌표에서 중심을 맞출 때는 예제처럼 음수 시작 좌표를 사용할 수 있다.

복잡한 다각형이나 이어지는 선은 `ofPolyline` 또는 `ofPath` 같은 경로 자료형으로 구성할 수 있다. 여러 점으로 윤곽을 만들고, 닫힌 형태인지 선만 표현할지 결정한 뒤 화면에 그린다. 점을 수식이나 반복문으로 생성해 경로에 넣으면 곡선, 파형, 불규칙한 외곽선처럼 기본 도형만으로 만들기 어려운 형태로 확장할 수 있다.

기본 도형 함수는 그릴 때마다 좌표를 직접 전달하는 방식이고, 변환 행렬은 여러 드로잉 호출의 좌표계를 한꺼번에 바꾸는 방식이다. 개별 점마다 다른 좌표가 필요하면 벡터 계산을, 같은 모티프를 반복·회전·확대하려면 변환 스택을 활용하면 코드의 의도가 분명해진다. 실제 작품에서는 두 접근을 함께 사용한다.

## 이 절의 핵심

`glm::vec2`는 위치, 방향, 속도를 표현하고 벡터 연산으로 거리와 변위를 계산하는 데 쓰인다. `ofTranslate()`, `ofRotateDeg()`, `ofScale()`은 로컬 좌표의 도형을 다른 좌표계에 배치하며, 변환 순서가 결과를 바꾼다. 기본 도형 API와 `ofPolyline`, `ofPath`를 벡터 계산 및 변환 스택과 결합하면 반복 가능한 기하 패턴을 구성할 수 있다.
