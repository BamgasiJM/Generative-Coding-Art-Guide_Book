# 20.5 랜덤, 노이즈, 벡터

p5.js와 Processing은 무작위 선택, 연속적으로 변하는 노이즈, 방향과 크기를 함께 표현하는 벡터를 위한 API를 제공한다. 세 도구의 역할은 서로 다르다. 랜덤은 개별 요소 사이에 차이를 만들고, 노이즈는 공간이나 시간에 걸친 부드러운 변화를 만들며, 벡터는 위치 변화나 방향을 계산한다. 이 절에서는 앞서 배운 개념을 두 환경의 최신 일반 API 문법으로 옮겨 본다. 난수와 노이즈의 개념적 차이는 11.8절, 벡터와 힘은 16장에서 자세히 다루었다.

## 개별 요소에 랜덤 값 주기

두 환경의 `random()`은 기본적으로 균일하게 뽑힌 값을 반환한다. 인자 없이 호출하면 0과 1 사이의 값, 상한 하나를 주면 0부터 그 값까지, 하한과 상한을 주면 지정 범위의 값을 얻는다.

| 호출 | 결과의 의미 |
| --- | --- |
| `random()` | 0 이상 1 미만의 값 |
| `random(max)` | 0 이상 `max` 미만의 값 |
| `random(min, max)` | `min` 이상 `max` 미만의 값 |

Processing의 Java 모드에서는 결과가 `float`이고 `randomSeed()`는 정수 시드를 받는다. p5.js의 `randomSeed()`도 시드로 난수열을 다시 만들 수 있게 한다. 같은 환경·버전에서 같은 시드와 같은 호출 순서를 사용하면 같은 난수열을 재현할 수 있다. 하지만 p5.js와 Processing이 같은 시드를 받았다고 해서 서로 똑같은 숫자열을 낸다고 보장되지는 않는다. 각 라이브러리의 난수 생성 방식과 호출 순서가 다를 수 있다.

다음 예제는 난수 시드를 한 번 설정한 뒤 원의 위치와 크기를 생성한다. `noLoop()`로 한 번만 그려 무작위 값이 프레임마다 새로 뽑혀 깜빡이는 일을 막는다.

```javascript
function setup() {
  createCanvas(480, 280);
  randomSeed(17);
  noLoop();
}

function draw() {
  background(248);
  noStroke();
  fill(35, 105, 150, 180);

  for (let i = 0; i < 40; i++) {
    const x = random(width);
    const y = random(height);
    const diameter = random(4, 16);
    circle(x, y, diameter);
  }
}
```

Processing Java 모드에서는 정수 시드를 사용한다.

```java
void settings() {
  size(480, 280);
}

void setup() {
  randomSeed(17);
  noLoop();
}

void draw() {
  background(248);
  noStroke();
  fill(35, 105, 150, 180);

  for (int i = 0; i < 40; i++) {
    float x = random(width);
    float y = random(height);
    float diameter = random(4, 16);
    ellipse(x, y, diameter, diameter);
  }
}
```

애니메이션에서 매 프레임 같은 개체의 색이나 크기가 유지되어야 한다면 해당 값을 처음 생성할 때 뽑아 상태에 저장한다. 반대로 `draw()` 안에서 매번 `random()`을 호출하면 그 속성이 프레임마다 다시 바뀌어 깜빡임처럼 보일 수 있다. `randomSeed()`를 매 프레임 다시 호출하는 것도 피한다. 시드 설정은 난수열의 출발점을 초기화하므로, 반복해서 재설정하면 계속 같은 부분의 값이 나오거나 의도와 다른 패턴이 만들어질 수 있다. 시드와 재현성에 관한 설계는 11.2절과 11.3절을 참고한다.

## 공간과 시간에 이어지는 노이즈

`noise()`는 독립적인 난수 하나를 뽑는 대신 좌표를 입력받아 그 위치의 값을 반환한다. 가까운 입력 좌표에서는 값도 대체로 부드럽게 이어진다. p5.js와 Processing 모두 1차원, 2차원, 3차원 좌표를 입력할 수 있으며 결과는 보통 0과 1 사이에 놓인다. 이 값은 확률 자체라기보다 색, 크기, 높이, 방향처럼 다른 속성으로 변환해 쓰는 연속적인 제어값이다.

```javascript
const frequency = 0.01;
const n = noise(x * frequency, y * frequency);
const angle = map(n, 0, 1, -PI, PI);
```

좌표에 곱하는 `frequency`는 노이즈 공간에서 얼마나 빠르게 입력을 변화시킬지 정한다. 작은 값을 쓰면 화면에서 넓은 영역에 걸쳐 천천히 변하고, 큰 값을 쓰면 짧은 거리 안에서 값이 빠르게 바뀐다. `noiseDetail(octaves, falloff)`는 더 세밀한 층을 얼마나 더할지와 각 층의 영향이 얼마나 줄어들지 조절한다. 좌표 배율은 큰 얼룩의 크기, `noiseDetail()`은 여러 규모의 잔결을 조절한다고 생각하면 두 설정을 구분하기 쉽다.

같은 좌표와 같은 설정의 노이즈 값은 반복 호출해도 유지된다. `noiseSeed(seed)`를 사용하면 특정 노이즈 필드를 다시 만들 수 있다. 난수와 마찬가지로 같은 시드라도 라이브러리나 버전이 다르면 완전히 같은 결과가 나오리라고 가정하지 않는다. 재현할 때는 시드뿐 아니라 사용한 환경과 설정도 기록한다.

세 번째 입력을 시간으로 사용하면 노이즈 필드가 부드럽게 변하는 애니메이션을 만들 수 있다.

```javascript
const n = noise(x * frequency, y * frequency, time * timeScale);
```

여기서 `time`은 초처럼 일정한 단위로 증가시키는 편이 좋다. `frameCount`를 그대로 입력하면 시간 변화가 프레임률에 묶인다. 실제 경과 시간으로 애니메이션을 움직이는 방법은 20.4절의 `deltaTime`과 `millis()` 설명을 따른다. 노이즈의 입력 좌표계와 주파수가 시각 패턴에 미치는 더 깊은 원리는 11.8절과 Part 4의 노이즈 설명을 참고한다.

## 벡터 API로 방향 다루기

벡터는 크기와 방향을 함께 가진 값이다. 위치를 다른 위치로 옮기거나, 속도와 힘을 합치거나, 길이를 제한할 때 좌표 두 개를 따로 계산하는 것보다 벡터 연산을 사용하면 의도가 분명해진다. 두 환경의 생성 문법은 다르지만 기본 연산은 비슷하다.

| 작업 | p5.js | Processing Java 모드 |
| --- | --- | --- |
| 2차원 벡터 생성 | `createVector(x, y)` | `new PVector(x, y)` |
| 성분 읽기 | `v.x`, `v.y` | `v.x`, `v.y` |
| 길이 | `v.mag()` | `v.mag()` |
| 길이 제곱 | `v.magSq()` | `v.magSq()` |
| 단위 길이로 정규화 | `v.normalize()` | `v.normalize()` |
| 길이 제한 | `v.limit(max)` | `v.limit(max)` |

예를 들어 현재 위치에서 목표 위치를 향하는 방향은 목표 좌표에서 현재 좌표를 뺀 벡터다. 정규화하면 방향은 유지하면서 길이가 1이 되므로, 원하는 속도를 곱해 일정한 이동 크기를 만들 수 있다.

```javascript
const direction = createVector(targetX - position.x, targetY - position.y);
if (direction.magSq() > 0) {
  direction.normalize();
  direction.mult(speed);
}
```

Processing에서는 벡터를 `PVector`로 선언한다.

```java
PVector direction = new PVector(targetX - position.x, targetY - position.y);
if (direction.magSq() > 0) {
  direction.normalize();
  direction.mult(speed);
}
```

`normalize()`, `mult()`, `add()` 같은 인스턴스 연산은 호출한 벡터 자체를 바꾼다. 원래 값도 보존해야 한다면 `copy()`로 복사한 뒤 연산한다. 길이가 0인 벡터는 방향이 없으므로 정규화하지 않도록 예외를 처리한다. `limit()`은 벡터의 각 성분을 따로 자르는 것이 아니라 전체 길이를 제한한다.

## 노이즈로 방향 벡터 만들기

노이즈는 숫자 하나만 반환하므로, 방향 벡터를 만들려면 그 값을 각도로 바꾼 뒤 코사인과 사인으로 벡터를 구성할 수 있다. 이 계산을 위치마다 적용하면 공간에 이어지는 벡터 필드(vector field)를 만든다.

```javascript
function fieldAt(x, y, frequency, strength) {
  const n = noise(x * frequency, y * frequency);
  const angle = map(n, 0, 1, -PI, PI);
  const direction = createVector(cos(angle), sin(angle));
  direction.mult(strength);
  return direction;
}
```

Processing Java 모드의 대응 함수는 반환형과 인자의 자료형을 선언한다.

```java
PVector fieldAt(float x, float y, float frequency, float strength) {
  float n = noise(x * frequency, y * frequency);
  float angle = map(n, 0, 1, -PI, PI);
  PVector direction = new PVector(cos(angle), sin(angle));
  direction.mult(strength);
  return direction;
}
```

이 함수는 각 위치에서 노이즈값을 각도로 바꾸고, 그 방향에 `strength`만큼의 길이를 부여한다. 가까운 위치의 노이즈값이 비슷하므로 벡터 방향도 대체로 서서히 바뀐다. 이후 입자의 위치에서 `fieldAt(position.x, position.y, frequency, strength)`를 계산하면 그 위치의 흐름 방향을 얻는다. 입자 갱신에 적용할 때 속도, 가속도, `deltaTime` 중 무엇으로 해석할지는 작품의 운동 모델에 맞춰 결정한다.

이 함수의 각도 범위와 `cos()`, `sin()`은 기본 라디안 모드를 전제로 한다. p5.js에서 `angleMode(DEGREES)`를 사용했다면 `angleMode(RADIANS)`로 되돌리거나, 각도 변환을 도 단위에 맞춰야 한다. Processing의 삼각 함수는 기본적으로 라디안을 사용한다.

## 이 절의 핵심

`random()`은 개별 요소의 차이를, `noise()`는 좌표와 시간에 이어지는 부드러운 변화를 만든다. 시드 함수는 각각 `randomSeed()`와 `noiseSeed()`이며, 두 라이브러리 사이에서 같은 시드가 같은 숫자열이나 필드를 보장하지는 않는다. p5.js는 `createVector()`, Processing은 `PVector`로 벡터를 만들고, 두 환경 모두 길이·정규화·합산 같은 연산을 제공한다. 노이즈값을 각도로 바꾸고 벡터로 구성하면 부드러운 흐름 필드를 만들 수 있다.
