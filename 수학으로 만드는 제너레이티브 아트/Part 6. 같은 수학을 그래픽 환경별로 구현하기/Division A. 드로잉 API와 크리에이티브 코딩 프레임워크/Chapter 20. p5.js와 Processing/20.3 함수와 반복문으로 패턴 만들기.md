# 20.3 함수와 반복문으로 패턴 만들기

화면에 같은 종류의 도형을 여러 번 배치할 때 도형마다 그리기 명령을 직접 쓰면 코드가 길어지고 수정도 번거롭다. 반복문(loop)은 여러 위치에서 같은 계산을 되풀이하고, 함수(function)는 그 계산에 이름을 붙여 입력만 바꾸어 다시 사용할 수 있게 한다. 두 도구를 함께 쓰면 짧은 규칙으로 행과 격자, 크기가 변하는 패턴을 만들 수 있다.

## 반복문으로 규칙적인 배치 만들기

가로 방향으로 $n$개의 도형을 일정한 간격으로 놓는다고 하자. 첫 중심의 위치를 $x_0$, 간격을 $\Delta x$라 하면 $i$번째 중심은 다음처럼 계산한다.

$$
x_i=x_0+i\Delta x,\qquad i=0,1,\ldots,n-1
$$

루프 변수 $i$는 도형의 순서를 나타낸다. 코드는 보통 0부터 시작하고 `i < count` 조건으로 반복하므로, `count`가 9이면 인덱스는 0부터 8까지 총 9회 실행된다. 조건에 `i <= count`를 쓰면 한 번 더 실행되어 예상보다 도형이 많아지는 범위 오류(off-by-one error)가 생길 수 있다.

캔버스 양쪽에 같은 여백을 두고 배치하려면 전체 너비에서 여백을 뺀 뒤 도형 사이 간격을 구한다. 다음 두 반복문 예제는 캔버스를 만든 뒤 `setup()` 또는 `draw()` 안에서 실행하는 코드 조각이다.

```javascript
const count = 9;
const margin = 40;
const spacing = count > 1 ? (width - 2 * margin) / (count - 1) : 0;

for (let i = 0; i < count; i++) {
  const x = count > 1 ? margin + i * spacing : width / 2;
  circle(x, height / 2, 12);
}
```

같은 계산을 Processing의 Java 문법으로 쓰면 자료형을 함께 적는다.

```java
int count = 9;
float margin = 40;
float spacing = count > 1 ? (width - 2 * margin) / (count - 1) : 0;

for (int i = 0; i < count; i++) {
  float x = count > 1 ? margin + i * spacing : width / 2;
  ellipse(x, height / 2, 12, 12);
}
```

간격을 `count - 1`로 나누는 것은 첫 번째와 마지막 도형의 중심을 양쪽 여백 위치에 놓기 위해서다. 도형이 하나뿐이면 나눌 구간이 없으므로 코드는 그 도형을 화면 가운데에 둔다. 이런 경계 조건을 처리하지 않으면 `count - 1`이 0이 되어 잘못된 간격이 계산될 수 있다.

## 중첩 반복문으로 격자 만들기

행과 열을 각각 반복하면 2차원 격자를 만들 수 있다. 바깥쪽 반복문이 행을, 안쪽 반복문이 열을 순회한다. 각 도형의 위치는 다음과 같이 나타낼 수 있다.

$$
x_{col}=x_0+col\,\Delta x,\qquad y_{row}=y_0+row\,\Delta y
$$

다음 예제는 9열 5행의 점 격자를 만들고, 열 번호에 따라 점의 지름을 작게부터 크게 바꾼다.

```javascript
function setup() {
  createCanvas(640, 400);
  noStroke();
}

function draw() {
  background(248);

  const columns = 9;
  const rows = 5;
  const margin = 36;
  const gapX = columns > 1 ? (width - 2 * margin) / (columns - 1) : 0;
  const gapY = rows > 1 ? (height - 2 * margin) / (rows - 1) : 0;

  for (let row = 0; row < rows; row++) {
    for (let col = 0; col < columns; col++) {
      const x = columns > 1 ? margin + col * gapX : width / 2;
      const y = rows > 1 ? margin + row * gapY : height / 2;
      const diameter = diameterAt(col, columns);
      drawDot(x, y, diameter);
    }
  }
}

function diameterAt(index, count) {
  if (count <= 1) return 12;
  return map(index, 0, count - 1, 8, 28);
}

function drawDot(x, y, diameter) {
  circle(x, y, diameter);
}
```

Processing에서는 같은 패턴을 다음처럼 작성할 수 있다.

```java
void settings() {
  size(640, 400);
}

void setup() {
  noStroke();
}

void draw() {
  background(248);

  int columns = 9;
  int rows = 5;
  float margin = 36;
  float gapX = columns > 1 ? (width - 2 * margin) / (columns - 1) : 0;
  float gapY = rows > 1 ? (height - 2 * margin) / (rows - 1) : 0;

  for (int row = 0; row < rows; row++) {
    for (int col = 0; col < columns; col++) {
      float x = columns > 1 ? margin + col * gapX : width / 2;
      float y = rows > 1 ? margin + row * gapY : height / 2;
      float diameter = diameterAt(col, columns);
      drawDot(x, y, diameter);
    }
  }
}

float diameterAt(int index, int count) {
  if (count <= 1) return 12;
  return map(index, 0, count - 1, 8, 28);
}

void drawDot(float x, float y, float diameter) {
  ellipse(x, y, diameter, diameter);
}
```

안쪽 반복문은 행 하나를 채우고, 바깥쪽 반복문은 다음 행으로 이동한다. 전체 도형 수는 `rows * columns`다. 두 방향의 개수를 각각 $n$으로 늘리면 계산과 그리기 횟수는 $n^2$에 비례해 증가한다. 격자를 크게 만들 때는 한 프레임에 그릴 도형 수와 픽셀 해상도가 함께 늘어난다는 점을 고려한다.

## 함수를 만들어 규칙에 이름 붙이기

함수는 반복되는 작업을 이름이 있는 단위로 묶는다. 예제의 `drawDot()`은 점을 그리는 역할을, `diameterAt()`은 열의 위치에서 지름을 계산하는 역할을 맡는다. 그리기와 계산을 나누면 모양을 바꾸고 싶을 때 해당 함수만 수정할 수 있고, 같은 함수를 다른 격자나 장면에서도 재사용할 수 있다.

p5.js 함수는 매개변수(parameter)를 받고 값을 반환(return)할 수 있다. Processing의 Java 모드에서는 매개변수와 반환값의 자료형을 선언한다. `void`는 함수가 계산값을 반환하지 않고 동작만 수행한다는 뜻이다. 값을 반환하는 함수에는 `float`, `int`처럼 결과의 자료형을 적는다.

`map()`은 입력 범위의 값을 출력 범위에 선형으로 대응시키는 함수다. 위 예제에서는 열 인덱스가 0에서 `columns - 1`까지 변할 때 지름이 8에서 28까지 변한다. 개념적으로는 다음 계산이다.

$$
v_{out}=out_{min}+\frac{v-in_{min}}{in_{max}-in_{min}}(out_{max}-out_{min})
$$

예제는 `count`가 1일 때 `map()`의 입력 범위가 0이 되지 않도록 별도로 처리한다. 또한 `map()`은 결과를 출력 범위 안으로 자동 제한하지 않는다. 입력이 범위를 벗어날 수 있다면 `constrain()` 같은 제한을 추가하거나, 먼저 입력 범위를 확인해야 한다.

## `for` 반복과 `draw()` 반복은 다르다

`for` 반복문은 현재 호출된 함수 안에서 정해진 횟수만큼 순서대로 실행된다. 위 격자 예제라면 한 번의 `draw()` 호출 안에서 모든 행과 열을 방문하고 45개의 점을 그린다. 반면 p5.js와 Processing의 `draw()`는 환경이 프레임마다 다시 호출하는 함수다. 즉 내부의 `for`문은 한 화면을 구성할 도형을 배치하고, 바깥의 `draw()` 반복은 그 화면을 시간에 따라 다시 계산하고 그린다.

정적인 격자 예제에서는 각 프레임의 결과가 같으므로 `background()`로 화면을 지운 뒤 같은 점들을 다시 그려도 모양은 변하지 않는다. 프레임의 갱신 시점과 시간에 따른 상태 변화는 다음 절에서 자세히 다룬다.

## 이 절의 핵심

반복문은 인덱스를 좌표와 크기 계산에 연결해 많은 도형을 배치하고, 함수는 그 계산과 그리기 규칙을 이름 붙은 재사용 단위로 묶는다. 중첩 반복문은 행과 열을 만들며, `map()`은 인덱스를 크기 같은 시각 속성으로 바꾼다. p5.js와 Processing은 개념은 같지만 변수 선언과 함수 반환 자료형의 문법이 다르며, `for` 반복과 프레임마다 호출되는 `draw()`의 반복도 구분해야 한다.
