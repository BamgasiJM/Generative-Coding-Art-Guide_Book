# 22.7 랜덤, 노이즈, 반복 구조

반복문은 하나의 규칙을 여러 요소에 적용하고, 랜덤은 요소마다 차이를 만들며, 노이즈는 그 차이를 부드럽게 이어 준다. Quil에서는 Clojure의 시퀀스 연산과 반복 구조로 요소를 순회하고, `quil.core`의 난수·노이즈 함수를 이용해 좌표와 속성을 변형할 수 있다. 이 세 가지를 함께 사용하면 규칙은 유지하면서도 기계적으로 똑같지 않은 패턴을 만들 수 있다.

## 반복으로 규칙 적용하기

패턴을 구성하는 기본 단위는 반복할 요소와 각 요소의 인덱스다. `range`로 인덱스를 만들고 `mapv`로 좌표 데이터를 계산하면, 그리기와 분리된 형태로 반복 규칙을 표현할 수 있다.

```clojure
(def points
  (mapv
   (fn [index]
     {:x (* index 12.0)
      :y 120.0})
   (range 40)))
```

이 코드는 인덱스 0부터 39까지를 x좌표로 바꾸어 40개의 점 데이터를 만든다. 각 요소에 같은 함수를 적용하되 인덱스에 따라 좌표가 달라진다. `mapv`는 결과를 벡터로 만들어 이후 여러 번 사용할 수 있게 하고, 렌더링 단계에서는 `doseq`로 각 데이터를 순회하며 드로잉 호출을 할 수 있다.

반복 구조는 격자처럼 차원이 둘 이상인 배치에도 쓰인다.

```clojure
(for [row (range 8)
      column (range 12)]
  {:row row
   :column column
   :x (+ 40.0 (* column 36.0))
   :y (+ 40.0 (* row 36.0))})
```

`for`의 두 바인딩은 모든 행과 열 조합을 만든다. 여기에 인덱스 기반의 크기·색상 규칙이나 조건을 추가하면 격자 구조를 유지하면서 변화가 있는 장면을 만들 수 있다. `mapv`와 `for`는 데이터를 계산할 때, `doseq`는 화면 그리기처럼 결과값을 모으기보다 반복 실행 자체가 목적인 부수 효과에 적합하다.

## 시드가 있는 난수

난수는 위치, 크기, 방향, 색상 등에 불규칙한 차이를 더한다. Quil의 `q/random`은 난수 값을 돌려주며, 하나의 상한을 주면 0부터 그 값 사이에서, 최소값과 최대값을 주면 해당 범위에서 값을 얻을 수 있다.

```clojure
(q/random 640.0)
(q/random 2.0 8.0)
```

일반적인 컴퓨터 난수는 의사 난수(pseudorandom number)다. 난수 생성기는 내부 상태를 바탕으로 값을 차례로 내놓으므로, 같은 시드와 같은 호출 순서를 사용하면 같은 결과를 다시 얻을 수 있다. Quil에서는 `q/random-seed`로 난수열의 시작점을 설정한다.

```clojure
(q/random-seed 2026)
(q/random 100.0)
```

시드를 고정하면 결과를 저장하고 비교하거나, 특정 구성을 다시 불러오는 데 유용하다. 단, 난수는 순서대로 생성되므로 앞부분에 난수 호출을 하나 추가하면 뒤에서 만들어지는 값들이 달라질 수 있다. 작품의 배치를 안정적으로 유지하려면 매 프레임 `draw` 안에서 난수를 다시 뽑기보다 `setup`에서 한 번 생성해 상태나 데이터에 저장하는 편이 낫다. 매 프레임 `q/random`으로 좌표를 결정하면 의도적으로 깜박이는 효과가 아니라면 형태가 불안정해 보일 수 있다.

## 노이즈로 부드러운 변화 만들기

`q/noise`는 입력 좌표에 따라 연속적으로 변하는 값을 돌려준다. 서로 가까운 입력에는 대체로 비슷한 값이 나오므로, 독립적인 난수처럼 갑자기 튀기보다 부드럽게 이어지는 변화에 적합하다. 같은 위치를 다시 샘플링하면 같은 값이 나오며, 노이즈 시드와 좌표를 고정하면 패턴도 재현할 수 있다.

```clojure
(q/noise 0.2)
(q/noise 0.2 0.7)
```

노이즈 입력은 화면 픽셀 좌표와 반드시 같을 필요는 없다. 예를 들어 점의 인덱스를 `0.03`처럼 작은 비율로 늘려 입력하면, 이웃한 점들이 노이즈 공간에서도 가까운 곳을 샘플링한다. 비율을 더 크게 하면 같은 화면 거리 안에서 노이즈 값이 더 빠르게 변하고, 더 작게 하면 완만하고 큰 흐름이 나타난다. 이 입력 좌표의 배율이 패턴의 공간 주파수(spatial frequency)에 영향을 준다. 값의 배율만으로 세부 묘사의 종류가 자동으로 추가되는 것은 아니며, 노이즈를 어디서 얼마나 촘촘히 샘플링할지를 바꾸는 것이다.

애니메이션에서는 시간도 노이즈 좌표의 한 축으로 사용할 수 있다. 공간 좌표는 고정하고 시간 좌표를 조금씩 전진시키면 프레임마다 독립적인 값을 새로 뽑는 대신, 이전 프레임과 이어지는 변화가 만들어진다. 예를 들어 `q/noise (* index 0.03) phase`에서 `phase`를 천천히 증가시키면 곡선이 부드럽게 변형된다.

## 난수와 노이즈를 반복에 결합하기

다음 예제는 시드가 고정된 난수 점무리와 시간에 따라 부드럽게 움직이는 노이즈 곡선을 함께 그린다. 점무리는 `setup`에서 한 번 생성하므로 프레임마다 위치가 바뀌지 않고, 곡선은 `update`에서 시간 좌표를 조금씩 움직여 갱신한다.

```clojure
(ns generative-art.noise-and-random
  (:require [quil.core :as q]
            [quil.middleware :as m]))

(defn random-dots [count width height]
  (mapv
   (fn [_]
     {:x (q/random width)
      :y (q/random height)
      :diameter (q/random 2.0 5.0)})
   (range count)))

(defn noise-curve [phase]
  (mapv
   (fn [index]
     (let [x (* index 5.0)
           value (q/noise (* index 0.035) phase)]
       {:x x
        :y (+ 330.0 (* (- value 0.5) 150.0))}))
   (range 128)))

(defn setup []
  (q/random-seed 2026)
  (q/noise-seed 73)
  {:dots (random-dots 120 (q/width) (q/height))
   :phase 0.0
   :last-ms (q/millis)
   :curve (noise-curve 0.0)})

(defn update-state [state]
  (let [now-ms (q/millis)
        dt (min (/ (- now-ms (:last-ms state)) 1000.0) 0.05)
        phase (+ (:phase state) (* dt 0.18))]
    (assoc state
           :phase phase
           :last-ms now-ms
           :curve (noise-curve phase))))

(defn draw-state [{:keys [dots curve]}]
  (q/background 248)

  (q/no-fill)
  (q/stroke 35 125 165)
  (q/stroke-weight 2)
  (q/begin-shape)
  (doseq [{:keys [x y]} curve]
    (q/vertex x y))
  (q/end-shape)

  (q/no-stroke)
  (doseq [{:keys [x y diameter]} dots]
    (q/fill 220 105 65)
    (q/ellipse x y diameter diameter)))

(q/defsketch noise-and-random
  :title "Noise and random"
  :size [640 480]
  :setup setup
  :update update-state
  :draw draw-state
  :middleware [m/fun-mode])
```

`q/random-seed`와 `q/noise-seed`는 서로 다른 생성기의 시드를 설정한다. 같은 Quil 환경에서 같은 시드와 같은 호출 순서를 사용하면 점무리 배치와 노이즈 형태를 재현할 수 있다. `random-dots`는 `range`로 120번 반복하고 각 반복에서 위치와 지름을 생성한다. 그 결과를 `mapv`로 저장하므로 `draw-state`에서는 이미 만들어진 데이터를 순회하기만 한다.

`noise-curve`는 128개 인덱스를 화면의 x좌표와 노이즈 입력으로 바꾸고, 노이즈 값 `[0, 1]`의 중심을 화면의 기준선에 맞춰 y좌표로 변환한다. `0.035`는 이웃한 샘플의 입력 간격을 정한다. 이 값을 키우면 곡선이 짧은 거리에서 더 빠르게 흔들리고, 줄이면 더 넓고 부드러운 흐름이 된다. `phase`는 노이즈 공간의 두 번째 좌표이며, `update-state`가 경과 시간 `dt`에 비례해 천천히 증가시킨다. 따라서 각 점의 위치에 새 난수를 대입하는 것과 달리, 곡선은 시간에 걸쳐 연속적으로 변한다.

`draw-state`에서 `doseq`는 각 점과 곡선 꼭짓점마다 Quil의 그리기 함수를 호출한다. 반복 횟수가 너무 많거나 매 프레임 복잡한 데이터를 새로 만들면 성능이 떨어질 수 있다. 변하지 않는 난수 배치는 `setup`에서 한 번 계산하고, 매 프레임 변해야 하는 노이즈 곡선의 샘플 수만 필요한 만큼 유지하는 식으로 반복 작업의 범위를 조절한다.

## 세 요소의 역할을 나누기

반복은 몇 개의 요소를 어떤 순서와 구조로 만들지 정한다. 난수는 각 요소에 서로 다른 값을 부여하고, 노이즈는 위치에 따라 부드럽게 달라지는 값을 제공한다. 예를 들어 격자의 셀마다 독립 난수로 색을 고르면 얼룩처럼 흩어진 배치가 되고, 셀의 행·열을 노이즈 좌표로 사용하면 이웃한 셀끼리 비슷한 색을 갖는 덩어리가 만들어진다.

어떤 방식을 택할지는 원하는 시각적 성격에 따라 달라진다. 무질서하고 분리된 차이가 필요하면 난수를, 흐르는 변형이나 자연스러운 편차가 필요하면 노이즈를 사용한다. 두 방법 모두 반복 구조 안에서 샘플링 위치와 적용 범위를 조절할 수 있다. 시드를 고정하고 데이터를 생성 단계에 보관하면 결과를 다시 만들 수 있고, 생성 규칙과 렌더링을 나누면 시각적 표현만 교체하기도 쉽다.

## 이 절의 핵심

Quil의 `q/random`은 독립적인 편차를, `q/noise`는 입력 좌표가 가까울수록 부드럽게 이어지는 편차를 만드는 데 적합하다. 시드로 결과를 재현하고, `range`와 `mapv`로 그릴 데이터를 계산하며, `doseq`로 화면에 표현할 수 있다. 정적인 난수 데이터와 시간에 따라 변하는 노이즈 데이터를 구분하면 안정성과 움직임을 함께 설계할 수 있다.
