# 24.7 시간, 랜덤, 노이즈 기반 애니메이션

애니메이션은 프레임마다 임의의 값을 바꾸는 것만으로 만들어지지 않는다. 움직임이 프레임률에 좌우되지 않게 시간을 사용하고, 어떤 요소에 무작위 변화를 줄지 정하고, 변화가 부드럽게 이어져야 한다면 노이즈 함수를 사용할 수 있다. nannou 0.20 계열에서는 `Update`의 경과 시간, 난수 유틸리티, `nannou::noise`의 노이즈 함수를 `Model`과 `update()`·`view()` 구조에 연결한다.

## 프레임 수 대신 경과 시간 사용하기

`update()`는 이전 업데이트 이후의 간격을 `Update` 값으로 전달한다. `since_last`는 `Duration`이므로 `as_secs_f32()` 또는 `as_secs_f64()`로 초 단위 값을 얻을 수 있다. 위치와 위상을 프레임마다 일정량 바꾸는 대신 속도에 경과 시간을 곱하면, 프레임률이 달라져도 초당 변화량을 일정하게 유지하기 쉽다.

```rust
fn update(_app: &App, model: &mut Model, update: Update) {
    let dt = update.since_last.as_secs_f32();
    model.position += model.velocity * dt;
    model.phase += model.angular_speed * dt;
}
```

여기서 `velocity`는 초당 위치 변화량이고 `angular_speed`는 초당 각도 변화량이다. `dt`를 곱하지 않고 매 업데이트 같은 수를 더하면 초당 업데이트 횟수가 많을수록 애니메이션이 빨라진다. 프레임률은 디스플레이와 처리 부하에 따라 변할 수 있으므로 시간 단위를 명시하는 편이 안정적이다. 큰 지연이 발생할 때 시뮬레이션이 한 번에 크게 움직이는 것을 막으려면 `dt`를 제한하거나 고정 시간 단계(fixed timestep)를 사용한다.

시간에 따라 반복되는 움직임은 사인과 코사인으로 만들 수 있다.

$$
x(t)=c_x+A\cos(\omega t+\phi),\qquad
y(t)=c_y+B\sin(\omega t+\phi)
$$

`(c_x,c_y)`는 중심, `A`와 `B`는 각 축의 진폭, `ω`는 각속도, `φ`는 시작 위상이다. 주기는 `T=2π/ω`이므로 각속도를 낮추면 한 주기를 도는 데 더 오래 걸린다. 주기 함수는 명확한 리듬과 반복 가능한 움직임에 적합하고, 관람객이 예측하기 어려운 자연스러운 움직임에는 노이즈가 더 잘 맞을 수 있다.

## 난수로 변화를 만들기

nannou 프렐류드에서 `random_range(min, max)`를 사용하면 지정한 범위의 난수를 얻을 수 있다.

```rust
let x = random_range(-300.0_f32, 300.0);
let radius = random_range(2.0_f32, 7.0);
```

난수는 매번 새로 추출할 때 서로 독립적인 값에 가까운 불규칙한 변화를 만든다. 입자가 처음 생성될 때 위치와 크기를 정하거나, 고정된 점 배열에 색상 변화를 주거나, 이벤트가 들어왔을 때 새로운 구조를 선택하는 데 유용하다. 반면 `view()`가 호출될 때마다 난수를 새로 뽑아 도형 위치를 정하면 같은 프레임을 다시 그려도 장면이 달라져 깜박임이 생긴다. 한 번 정한 무작위 속성은 `Model`에 저장하고 이후 프레임에서는 저장된 값을 그린다.

```rust
struct Particle {
    position: Point2,
    radius: f32,
    phase: f32,
}

fn make_particle() -> Particle {
    Particle {
        position: pt2(
            random_range(-300.0_f32, 300.0),
            random_range(-200.0_f32, 200.0),
        ),
        radius: random_range(2.0_f32, 7.0),
        phase: random_range(0.0_f32, std::f32::consts::TAU),
    }
}
```

이 함수는 입자를 만들 때 한 번 호출해 각 입자의 고유한 시작 상태를 정한다. 저장한 `phase`를 시간에 따라 증가시키면 입자마다 다른 위상으로 움직이면서도, 각 입자의 변화는 매끄럽게 이어진다. 모든 입자에 같은 위상을 사용하면 움직임이 동시에 맞춰지는 경향이 생긴다.

난수는 실행할 때마다 다른 배열을 만드는 것이 기본이다. 특정 작품의 결과를 다시 만들거나 실험을 비교하려면 고정된 시드(seed)를 가진 난수 생성기를 사용하고, 입자를 생성한 순서와 생성기 상태를 재현 가능하게 관리한다. nannou는 `nannou::rand`를 통해 Rust 난수 생태계에 접근할 수 있다. 또한 아래에서 사용하는 `Perlin::new(seed)`처럼 시드를 받는 노이즈 생성기는 같은 시드와 좌표에서 같은 값을 돌려준다. 단, 난수 생성 순서가 달라지면 이후의 값도 달라질 수 있으므로 독립적인 작품 요소마다 별도 생성기를 두는 방법도 고려한다.

## 노이즈가 만드는 연속적인 변화

노이즈는 좌표를 입력받아 값 하나를 반환하는 함수다. 난수처럼 좌표마다 서로 무관한 값을 주는 대신, 가까운 좌표에는 가까운 값이 나오도록 설계되어 있다. 따라서 노이즈 공간을 조금씩 이동하며 값을 읽으면 갑작스러운 점프 없이 부드럽게 변하는 제어 신호를 만들 수 있다.

| 방법 | 값의 특징 | 잘 맞는 용도 |
| --- | --- | --- |
| 난수(random) | 각 추출값이 불규칙하고 서로 독립적 | 초기 배치, 선택, 입자별 고정 속성 |
| 주기 함수(periodic function) | 규칙적인 리듬으로 반복 | 회전, 왕복, 맥동 |
| 노이즈(noise) | 입력 좌표가 가까우면 출력도 대체로 부드럽게 변함 | 흔들림, 유기적인 이동, 지형과 흐름 변화 |

nannou는 `nannou::noise`를 통해 노이즈 함수를 제공한다. 다음처럼 `Perlin` 생성기에 시드를 주고 `NoiseFn` 트레이트의 `get()`으로 2차원 입력 좌표를 샘플링할 수 있다.

```rust
use nannou::noise::{NoiseFn, Perlin};

let field = Perlin::new(2025);
let value = field.get([0.35_f64, 1.2_f64]);
```

`Perlin`은 공간적으로 연속적이고 부드러운 변화가 필요한 경우에 자주 쓰는 노이즈 함수다. 같은 생성기와 좌표를 사용하면 결과도 같으므로 장면을 재현하기 쉽다. 반환값은 보통 `-1`과 `1` 부근의 범위에 놓이며, 작품에서 필요한 크기와 기준값으로 매핑해 사용한다.

노이즈의 공간 주파수는 좌표에 곱하는 배율로 조절한다. `field.get([x * 0.01, y * 0.01])`처럼 좌표를 작게 만들면 화면에서 더 넓고 완만한 변화가 나타나고, 큰 배율을 사용하면 짧은 거리 안에서 세밀하게 변한다. 결과의 진폭은 출력값에 곱하는 크기로 조절한다. 주파수는 무늬의 크기와 변화 밀도, 진폭은 화면에서 관찰되는 변화량을 주로 결정한다.

## 시간을 노이즈 좌표로 사용하기

노이즈를 시간과 함께 샘플링하면 변화가 매끄럽게 이어지는 애니메이션을 만들 수 있다. 2차원 노이즈의 첫 축에는 화면의 가로 위치를, 두 번째 축에는 시간을 넣으면 각 위치가 시간에 따라 부드럽게 바뀌는 선을 만들 수 있다.

```rust
use nannou::noise::{NoiseFn, Perlin};
use nannou::prelude::*;

struct Model {
    elapsed: f64,
    field: Perlin,
}

fn model(app: &App) -> Model {
    app.new_window()
        .size(900, 600)
        .view(view)
        .build()
        .expect("창을 만들지 못했습니다");

    Model {
        elapsed: 0.0,
        field: Perlin::new(2025),
    }
}

fn update(_app: &App, model: &mut Model, update: Update) {
    model.elapsed += update.since_last.as_secs_f64();
}

fn view(app: &App, model: &Model, frame: Frame) {
    let draw = app.draw();
    draw.background().color(rgb(0.04, 0.06, 0.08));

    let bounds = app.window_rect();
    let segments = 160;
    let points = (0..=segments).map(|i| {
        let u = i as f32 / segments as f32;
        let x = bounds.left() + u * bounds.w();
        let noise_value = model.field.get([
            u as f64 * 4.0,
            model.elapsed * 0.22,
        ]) as f32;
        let y = noise_value * 135.0;
        pt2(x, y)
    });

    draw.polyline()
        .weight(2.0)
        .points(points)
        .color(rgb(0.25, 0.72, 0.80));

    draw.to_frame(app, &frame)
        .expect("프레임을 렌더링하지 못했습니다");
}
```

`elapsed`는 실제 경과 시간을 초 단위로 누적한다. 화면의 가로 위치를 `u`로 정규화해 노이즈의 첫 번째 축에 넣고, 시간이 두 번째 축을 따라 이동하게 한다. 같은 x 위치도 시간이 흐르면 다른 노이즈 값을 얻지만, 이 변화는 시간 좌표의 인접성을 따라 부드럽게 이어진다. `0.22`는 시간 좌표의 이동 속도, `4.0`은 가로 방향의 노이즈 주파수, `135.0`은 선의 세로 진폭에 해당한다.

시간을 `f64`로 누적한 것은 오랜 실행에서 `f32`보다 작은 시간 간격을 더 잘 보존하기 위해서다. 노이즈 입력 좌표와 상태의 숫자 타입을 맞추면 불필요한 변환을 줄일 수 있다. 움직임이 너무 빠르면 시간 좌표의 배율을 낮추고, 선의 굴곡이 너무 촘촘하면 공간 좌표의 배율을 낮춘다. 반대로 더 복잡한 잔물결이 필요하면 공간 주파수를 높이거나 여러 주파수의 노이즈를 합친다.

여러 옥타브의 노이즈를 더하는 프랙털 브라운 운동(fBm)은 큰 흐름 위에 작은 변화를 겹치는 방법이다.

$$
f(\mathbf{x},t)=\sum_{k=0}^{m-1} a^k\,N(\lambda^k\mathbf{x},\lambda^k t)
$$

`N`은 기본 노이즈 함수, `a`는 옥타브가 높아질 때 진폭을 줄이는 감쇠 비율, `λ`는 주파수를 높이는 비율이다. 낮은 주파수 항은 큰 형태를 만들고, 높은 주파수 항은 더 작은 세부를 추가한다. 옥타브 수를 늘리면 계산량도 커지므로, 화면 해상도와 필요한 세부 수준에 맞춰 조절한다.

## 난수, 노이즈, 시간의 조합

세 방법은 서로 대체재라기보다 서로 다른 시간 구조를 제공한다. 난수는 입자의 초기 위치와 반지름을 정하고, 주기 함수는 일정한 진동을 만들며, 노이즈는 각 입자의 속도나 방향을 서서히 흔들 수 있다. 난수로 선택한 입자별 위상이나 노이즈 시드가 `Model`에 저장되어 있으면 매 프레임 같은 기반 설정을 유지하면서 시간에 따른 변화를 만들 수 있다.

예를 들어 입자 생성 시 난수로 초기 위치와 시드를 선택하고, 업데이트할 때는 시간 간격을 곱해 위치를 이동시키며, 속도 방향에는 노이즈 값을 조금씩 더할 수 있다. 이렇게 하면 매 프레임 완전히 새로운 값을 뽑지 않고도 개체마다 다른 움직임을 만들 수 있다. `update()`는 시간과 상태를 관리하고, `view()`는 그 순간의 상태나 노이즈 샘플을 화면에 표현한다.

노이즈를 벡터 필드로 사용할 때는 위치마다 두 개 이상의 노이즈 값을 샘플링해 x와 y 방향 성분으로 해석할 수 있다. 좌표 입력과 시간 입력의 스케일, 출력 진폭, 시드가 흐름의 성격을 결정한다. 입자에 필드를 적용하는 방법과 힘의 누적은 16.6과 23.6의 입자 시스템 구조에 연결된다.

## 이 절의 핵심

시간 기반 움직임은 `Update::since_last`를 초 단위로 사용해 프레임률과 분리한다. 난수는 독립적인 초기 변이와 선택에 적합하고, `random_range()` 결과를 계속 다시 뽑기보다 필요한 상태를 `Model`에 저장해야 깜박임을 피할 수 있다. `Perlin` 같은 노이즈 함수는 좌표와 시간에 따라 연속적으로 변하므로, 공간 주파수와 시간 속도, 출력 진폭을 조절해 부드러운 애니메이션과 유기적인 기하 변화를 만들 수 있다.
