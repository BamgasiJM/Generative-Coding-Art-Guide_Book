# 18.5 2D 캔버스, 3D 공간, 표면 셰이딩

제너레이티브 아트의 수학은 2차원 화면에서 시작해도, 같은 규칙을 3차원 장면이나 물체의 표면으로 옮길 수 있다. 이때 달라지는 것은 사인파나 노이즈 자체보다 그 함수에 어떤 좌표를 입력하고, 계산 결과를 무엇에 연결하는가다.

2D 캔버스 작업에서 기본 입력은 화면 위치다. 픽셀 좌표 $(x,y)$ 또는 정규화한 좌표 $(u,v)$에서 색을 계산하거나, 그 위치에 도형을 배치한다. 화면은 하나의 평면이므로 깊이와 카메라를 우선 고려하지 않아도 된다.

$$
\mathbf{p}=(x,y),\qquad \mathbf{C}=F(\mathbf{p})
$$

```text
for each pixel position p:
    brightness = noise(p * frequency)
    setPixel(p, grayscale(brightness))
```

2D 캔버스는 좌표와 출력의 관계를 직접 관찰하기 좋다. 거리 함수는 도형의 윤곽이 되고, 반복 좌표는 타일이 되며, 시간에 따른 좌표 이동은 패턴의 흐름이 된다. 레이어의 순서와 알파 합성은 있지만, 보통 원근 투영과 깊이 검사는 작업의 중심이 아니다.

3D 공간에서는 위치가 $(x,y,z)$가 되고, 카메라가 그 공간을 어떤 화면 이미지로 투영하는지까지 포함해야 한다. 같은 구나 입방체라도 카메라 위치, 시야각, 조명, 물체의 회전에 따라 전혀 다른 화면 결과를 만든다.

$$
\mathbf{p}_{world}=(x,y,z),\qquad
\mathbf{p}_{screen}=P\,V\,M\,\mathbf{p}_{local}
$$

여기서 $M$은 물체의 로컬 좌표를 월드 좌표로 옮기는 모델 변환, $V$는 카메라 기준 좌표로 옮기는 뷰 변환, $P$는 3차원 위치를 2차원 화면으로 투영하는 프로젝션 변환이다. 행렬의 세부는 이후 그래픽 환경별 구현에서 다시 만나지만, 중요한 점은 같은 도형도 여러 좌표 공간을 거친다는 사실이다.

```text
worldPosition = modelMatrix * localPosition
cameraPosition = viewMatrix * worldPosition
clipPosition = projectionMatrix * cameraPosition
```

3D 제너레이티브 아트에서 함수는 기하를 만드는 데 직접 사용될 수 있다. 노이즈로 정점의 높이를 바꾸면 지형이나 유기적인 표면이 되고, 거리 함수로 물체의 내부와 외부를 정의할 수 있다. 또한 함수 결과를 색·거칠기·발광량 같은 재질 속성으로 연결할 수도 있다.

```text
height = noise(x * frequency, z * frequency)
vertex.y += height * amplitude
```

하지만 3D 장면에서 계산한 값이 곧바로 보이는 것은 아니다. 표면이 빛을 어떻게 반사하는지, 어느 방향을 향하는지, 카메라에서 보이는지에 따라 최종 픽셀의 색이 결정된다. 이 지점에서 표면 셰이딩(surface shading)이 등장한다.

표면 셰이딩은 물체 표면의 한 점에서 재질과 조명을 바탕으로 색을 계산하는 일이다. 이때 입력은 보통 표면 위치, 법선 벡터, 관찰 방향, 광원 방향, UV 좌표, 재질 파라미터다.

$$
\mathbf{C}=S(\mathbf{p},\mathbf{n},\mathbf{v},\mathbf{l},\text{material})
$$

여기서 $\mathbf{n}$은 표면의 바깥 방향을 나타내는 법선이다. 가장 단순한 확산 조명은 법선과 광원 방향의 내적으로 밝기를 구한다.

$$
I=\max(0,\mathbf{n}\cdot\mathbf{l})
$$

```glsl
float diffuse = max(0.0, dot(normalize(normal), normalize(lightDirection)));
vec3 color = baseColor * diffuse;
```

2D의 색상 필드가 화면 위치에서 색을 돌려준다면, 표면 셰이더의 색상 필드는 물체 표면의 위치에서 재질 값을 돌려준다. 예를 들어 노이즈는 화면 전체의 구름 같은 배경이 될 수도 있고, 구 표면의 얼룩·거칠기·변위가 될 수도 있다. 수학은 같아도 입력 공간과 출력 연결이 달라진다.

UV 좌표는 3D 표면에 2D 좌표를 부여하는 방법이다. 모델의 각 표면점은 $(u,v)$ 값을 가질 수 있고, 이 값을 이용해 이미지 텍스처나 절차적 패턴을 표면에 입힌다.

```glsl
vec3 stripes = vec3(step(0.5, fract(uv.x * stripeCount)));
```

UV 공간에서 만든 체커보드나 방사형 패턴은 모델의 형상과 무관하게 2D 함수로 쉽게 정의할 수 있다. 하지만 UV가 잘리지 않고 펼쳐진 지도는 아니다. 모델의 이음새에서 좌표가 끊기거나, 어떤 부분이 다른 부분보다 크게 늘어날 수 있다. 따라서 대규모 표면의 연속적인 노이즈에는 UV 대신 오브젝트 공간이나 월드 공간 좌표를 쓰기도 한다.

| 입력 공간 | 주로 쓰는 대상 | 장점 | 주의할 점 |
| --- | --- | --- | --- |
| 화면 공간 | 후처리, 2D 패턴, 프래그먼트 효과 | 화면 전체를 직접 다룸 | 카메라 이동과 무관하지 않을 수 있음 |
| UV 공간 | 이미지 텍스처, 표면 타일 | 2D 패턴을 표면에 쉽게 적용 | 이음새와 늘어남 |
| 오브젝트 공간 | 물체에 붙는 절차적 재질 | 물체를 움직여도 패턴이 함께 이동 | 객체마다 좌표 기준이 다름 |
| 월드 공간 | 여러 물체를 가로지르는 필드 | 장면 전체에서 연속적 | 물체가 움직이면 패턴을 통과함 |

공간 선택은 표현의 일부다. 대리석 무늬가 조각상에 붙어 있어야 한다면 오브젝트 공간 노이즈가 어울린다. 안개나 빛의 장처럼 장면 전체를 채우는 변화라면 월드 공간 필드가 자연스럽다. 카메라 렌즈에 붙은 필름 그레인이나 비네트는 화면 공간에서 계산해야 한다.

표면 셰이딩에는 색 이외에도 여러 출력이 있다. 법선을 미세하게 바꾸면 실제 기하를 늘리지 않고도 요철처럼 빛이 반응하는 노멀 매핑을 만들 수 있다. 거칠기를 바꾸면 반사의 퍼짐이 달라지고, 금속성·투명도·발광량을 바꾸면 같은 색도 다른 재질로 읽힌다. OSL과 Blender Shader Nodes는 이런 표면 속성을 함수와 노드로 조합하는 작업에 적합하다.

```text
noise value -> base color
noise value -> roughness
noise gradient -> normal perturbation
distance field -> mask for material mixing
```

마지막으로 2D와 3D, 표면 셰이딩을 분리된 분야로 볼 필요는 없다. 3D 장면도 결국 2D 프레임 버퍼로 렌더링되고, 2D 거리 필드도 3D 표면의 재질 마스크가 될 수 있다. 차이는 어느 단계에서 좌표를 해석하고, 함수의 결과를 위치·기하·색·빛 가운데 어디에 연결하는가에 있다. 이 관점을 유지하면 동일한 패턴 규칙을 Canvas, GLSL, HLSL, OSL, Blender 노드 환경 사이에서 옮길 수 있다.

## 이 절의 핵심

2D 캔버스는 화면 좌표에서 색과 도형을 계산하고, 3D 공간은 위치·카메라·투영을 거쳐 화면을 만든다. 표면 셰이딩은 표면 위치, 법선, UV, 조명, 재질 값을 입력으로 받아 색과 재질 반응을 계산한다. 같은 함수라도 화면·UV·오브젝트·월드 공간 가운데 어느 좌표를 입력으로 쓰는지에 따라 전혀 다른 결과가 된다.
