# 29.6 반복 패턴과 표면 타일링

절차적 타일링은 좌표를 일정한 크기의 셀로 나눈 다음, 각 셀 안에서 같은 규칙을 반복해 평가하는 방법이다. 이미지 텍스처를 만들어 표면에 붙이지 않아도 줄무늬, 점무늬, 격자, 타일 경계를 계산할 수 있다. 핵심은 좌표에서 셀 번호와 셀 내부 좌표를 분리하는 것이다.

좌표 `u`에 타일 수 `n`을 곱한 값을 `q`라 하자. `floor(q)`는 현재 셀의 정수 번호를, `q - floor(q)`는 셀 안에서 반복되는 위치를 돌려준다.

$$
q = nu, \qquad k = \lfloor q \rfloor, \qquad f = q - \lfloor q \rfloor
$$

`f`는 $[0,1)$ 범위의 값을 반복하므로, 셀마다 같은 도형이나 색 규칙을 적용할 수 있다. 두 좌표에 각각 이 계산을 하면 평면을 직사각형 격자로 나눌 수 있다. `fract()` 대신 `q - floor(q)`를 쓰면 음수 좌표에서도 셀 내부 값이 같은 범위로 정리된다.

## UV 타일에 원형 점 배치하기

다음 셰이더는 UV 표면을 행과 열로 나누고, 각 셀의 중심에 원형 점을 그린다. 홀수 행은 반 칸 이동시켜 벽돌처럼 엇갈린 배열을 만든다. 점의 경계는 거리값과 `smoothstep()`으로 부드럽게 처리한다.

```c
shader tiled_dots(
    float tiles_u = 12.0,
    float tiles_v = 8.0,
    float radius = 0.32,
    float edge_width = 0.015,
    color background_color = color(0.025, 0.07, 0.12),
    color dot_color = color(0.95, 0.38, 0.12),
    output closure color BSDF = 0)
{
    float q_v = v * tiles_v;
    float row = floor(q_v);
    float row_parity = row - 2.0 * floor(row * 0.5);

    float q_u = u * tiles_u + 0.5 * row_parity;
    float col = floor(q_u);
    float local_u = q_u - col - 0.5;
    float local_v = q_v - row - 0.5;

    float d = length(vector(local_u, local_v, 0.0)) - radius;
    float mask = 1.0 - smoothstep(0.0, edge_width, d);
    color pigment = mix(background_color, dot_color, mask);

    BSDF = diffuse(N) * pigment;
}
```

`local_u`, `local_v`는 각 타일 중심을 원점으로 하는 좌표다. 따라서 타일 중심은 `(0, 0)`, 셀의 모서리는 두 축에서 대략 `-0.5`부터 `0.5`까지 놓인다. `length()`로 중심에서의 거리를 구하고 반지름을 빼면 원의 경계에서 `d = 0`이 된다. `mask`는 점 안에서 1에 가깝고 바깥에서 0에 가까우며, 이 값을 두 색의 보간에 사용한다.

`radius`와 `edge_width`는 UV 전체가 아니라 한 타일 안의 좌표 단위다. 반지름이 `0.5`보다 작아야 원이 셀 경계를 넘어 이웃 점과 겹치지 않는다. 타일 수는 UV가 $[0,1]$로 매핑된다는 전제에서 표면을 가로·세로로 몇 칸 나눌지를 정한다. 코드의 `BSDF`는 색을 기록하는 출력이 아니라, 계산한 색을 확산 반사 클로저에 연결해 렌더러가 조명에 반응하도록 한다.

행의 홀짝은 `row - 2 * floor(row / 2)`로 구한다. 이 값은 `row`가 짝수일 때 0, 홀수일 때 1이므로 홀수 행의 `q_u`를 반 칸 이동한다. UV의 가로 경계에서 반복하려면 `tiles_u`가 정수여야 한다. 세로 경계에서도 반복하려면 `tiles_v`도 정수여야 하며, 이 코드처럼 행을 엇갈리게 배치할 때는 `tiles_v`를 짝수로 둔다. 마지막 행과 첫 행의 홀짝이 다르면 세로 이음새에서 점 배열이 어긋날 수 있다.

## 셀 번호로 패턴 바꾸기

셀 내부 좌표는 각 칸에 반복되는 도형을 만들고, 셀 번호는 칸마다 다른 선택을 하는 데 쓸 수 있다. 예를 들어 짝수·홀수 셀의 배경색을 다르게 하거나, 행과 열 번호에 따라 줄무늬 방향과 크기를 바꿀 수 있다. 타일링 셰이더는 보통 다음 두 질문을 나누어 계산한다.

| 값 | 계산 | 활용 |
| --- | --- | --- |
| 셀 번호 | `floor(q)` | 타일별 색, 방향, 변형 선택 |
| 셀 내부 좌표 | `q - floor(q)` | 타일 안의 원, 선, 다이아몬드 경계 |
| 중심 기준 좌표 | `q - floor(q) - 0.5` | 중심 정렬 도형과 거리 계산 |

같은 셀 내부 좌표에서 `abs(local_u)`를 경계 조건으로 쓰면 세로 띠나 사각형을 만들 수 있고, 두 축의 절댓값 중 큰 값을 사용하면 정사각형에 가까운 경계를 얻는다. 각 셀의 중심까지 거리를 계산하면 원형 점을, 축에 따른 거리를 조합하면 십자나 마름모 형태를 만들 수 있다. 이런 경계 계산은 29.5에서 설명한 거리 기반 마스크를 타일마다 반복 적용하는 경우다. 여기서는 거리 함수의 합성보다 좌표를 반복시키는 단계가 핵심이다.

셀 번호로 색을 바꾸려면 번호를 정수 기반의 주기 규칙에 연결하거나, 셀 번호를 시드로 하는 해시를 사용한다. 이때 무작위성은 픽셀마다 다시 뽑는 값이 아니라 셀마다 일정한 값이어야 한다. 그래야 표면의 시점이나 샘플링이 바뀌어도 한 타일의 색과 형태가 프레임마다 깜박이지 않는다. 해시 함수의 구현은 렌더러와 OSL 버전에 의존하지 않도록 셰이더 안에 직접 정의하거나, 호스트가 제공하는 함수인지 확인한다.

## UV 반복과 공간 반복

UV 타일링은 펼쳐진 표면 좌표를 기준으로 패턴을 만든다. 텍스처처럼 표면의 특정 영역에 무늬를 고정하기 쉽지만, UV 배치의 늘어남과 이음새를 그대로 따른다. UV가 좁게 압축된 곳에서는 같은 UV 크기의 타일이 실제 표면에서 작아지고, UV가 늘어난 곳에서는 커진다. 곡면에 패턴을 붙였을 때 타일이 찌그러지는 것도 이 매핑의 결과다. 코드의 원은 타일 단위 좌표에서 원형이다. 가로·세로의 타일 크기나 UV의 표면 밀도가 다르면 실제 표면에서는 타원처럼 보일 수 있으므로, 타일 수와 UV 배치를 함께 조정한다.

반대로 `P`를 오브젝트 공간이나 월드 공간으로 변환한 뒤 각 성분을 타일 크기로 나누면 3차원 격자를 만들 수 있다. 각 축에서 `q - floor(q)`를 계산해 셀 내부 좌표를 얻으면 UV 이음새와 무관하게 공간 전체에 반복 필드를 정의할 수 있다. 오브젝트 공간 좌표는 오브젝트에 붙어 움직이고, 월드 공간 좌표는 장면의 고정된 격자에 놓인다. 따라서 월드 공간 패턴을 사용하는 오브젝트가 움직이면 표면이 그 격자를 통과하는 것처럼 보일 수 있다. 좌표 변환의 의미와 공간 선택은 29.3의 기준을 따른다.

타일 크기 역시 기준 공간의 단위다. 오브젝트 공간에서 `0.2` 간격의 셀은 오브젝트를 비균일하게 확대하면 화면과 월드에서 늘어나 보일 수 있다. 월드에서 일정한 크기의 무늬가 필요하면 월드 좌표를 사용하고, 메시의 로컬 디자인을 유지하려면 오브젝트 좌표를 선택한다. 공간 반복은 메시의 경계를 가로질러 연속적인 패턴을 만들기 쉽지만, 셰이더가 기존 표면점에서 재질을 평가한다는 점은 변하지 않는다. 색 마스크만으로 메시의 실루엣이나 실제 타일의 두께가 생성되지는 않는다.

## 타일 크기와 필터링

타일 수를 높일수록 무늬의 주파수가 높아진다. 멀리 있는 표면이나 작은 렌더 해상도에서는 한 픽셀 안에 타일 경계가 여러 개 들어갈 수 있고, 그 결과 모아레나 깜박임이 생긴다. 고정된 `edge_width`는 각 타일 좌표에서의 전이 폭이므로, 화면상의 픽셀 크기에 맞춘 필터링과 동일하지 않다.

먼저 타일 수를 낮추거나 렌더 해상도와 샘플 수를 늘려 패턴이 화면에서 충분히 표현되는지 확인한다. 더 촘촘한 패턴이 필요하면 렌더러가 지원하는 셰이딩 미분과 필터 폭을 활용해 타일 경계의 전이를 표본 크기에 맞춰야 한다. 관련 기능과 OSL 구현별 차이는 29.5의 경계 필터링 설명을 참고한다. 주파수가 너무 높은 패턴은 셰이더만으로 세부를 보존할 수 없으므로, 필요한 경우에는 멀리서 패턴을 단순화하거나 서로 다른 스케일의 패턴을 섞는다.

## 이 절의 핵심

표면 타일링은 좌표에 빈도를 곱하고 `floor()`로 셀 번호를 구한 뒤, 셀 내부 좌표를 반복해 도형과 색을 계산한다. UV 좌표는 표면에 패턴을 고정하기 편하지만 매핑 왜곡과 이음새를 따르며, 오브젝트·월드 공간 좌표는 3차원 필드를 만든다. 셀 번호와 내부 좌표를 별도로 활용하면 규칙적인 격자와 타일별 변형을 함께 설계할 수 있다. 패턴 주파수가 화면 표본보다 높아지면 필터링과 렌더 설정을 고려해야 하고, 재질 마스크만으로 실제 기하가 생기는 것은 아니다.
