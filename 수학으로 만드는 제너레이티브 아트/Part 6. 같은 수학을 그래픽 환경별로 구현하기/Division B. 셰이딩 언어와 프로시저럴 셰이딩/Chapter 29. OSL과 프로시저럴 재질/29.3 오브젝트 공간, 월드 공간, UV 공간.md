# 29.3 오브젝트 공간, 월드 공간, UV 공간

OSL에서 절차적 재질을 만들 때는 함수보다 먼저 입력 좌표의 기준을 정해야 한다. 같은 사인파나 노이즈라도 오브젝트를 따라 움직이게 할지, 장면에 고정할지, UV를 따라갈지에 따라 서로 다른 재질이 된다. 26.3에서 좌표 공간의 일반적인 관계를 살펴보았다. 여기서는 OSL의 표면 입력과 `transform()`을 중심으로 이 선택을 구체화한다.

## 셰이딩 지점의 위치와 UV

OSL의 전역 입력 `P`는 현재 셰이딩 지점의 3차원 위치다. 셰이딩 시스템은 이를 현재 또는 공통 좌표계에서 제공하며, 렌더러가 등록한 명명된 공간으로 변환할 수 있다. `u`와 `v`는 표면에 연결된 2차원 텍스처 좌표다. 이 입력은 화면 픽셀 좌표가 아니라 렌더러가 광선과 표면의 교차를 계산한 지점의 값이다.

오브젝트 공간 좌표로 줄무늬를 만드는 OSL 텍스처 셰이더는 다음과 같이 쓸 수 있다.

```c
shader object_stripes(
    float frequency = 4.0,
    output color pattern = color(0.0))
{
    point p_object = transform("object", P);
    float stripe = 0.5 + 0.5 * sin(6.2831853 * frequency * p_object[0]);
    pattern = color(stripe);
}
```

이 코드는 현재 셰이딩 위치 `P`를 `"object"` 공간으로 바꾼 뒤 x 성분을 주기 함수에 넣는다. `frequency`는 오브젝트 공간의 한 단위에서 반복되는 주기의 수다. 출력은 최종 조명 결과가 아니라 머티리얼 네트워크에서 색이나 마스크 입력으로 연결할 수 있는 절차적 값이다. 표면의 빛 반응으로 만들려면 렌더러의 머티리얼 네트워크에서 이 값을 서피스 셰이더의 입력에 연결한다.

## 오브젝트 공간: 물체에 붙는 패턴

오브젝트 공간은 각 메시의 로컬 기준을 따른다. `transform("object", P)`로 얻은 좌표를 사용하면 물체가 장면에서 이동하거나 회전해도 패턴이 물체 표면에 붙어 있는 것처럼 보인다. 페인트 자국, 나무결, 표면의 미세한 요철처럼 재질이 물체와 함께 움직여야 하는 경우에 적합하다.

오브젝트 공간 좌표의 스케일은 모델의 제작 단위와 오브젝트 변환에 영향을 받는다. 서로 크기가 다른 모델에 같은 `frequency` 값을 적용해도 월드 공간에서 보이는 무늬 크기는 달라질 수 있다. 물체를 월드에서 크게 확대하면 물체와 함께 패턴도 커지는 것이 보통의 오브젝트 공간 동작이다. 여러 에셋에서 비슷한 물리적 크기의 패턴을 원한다면 모델 크기를 정규화하거나, 월드 공간을 쓰거나, 오브젝트별 스케일 매개변수를 둔다.

## 월드 공간: 장면에 고정된 필드

월드 공간은 장면의 오브젝트가 공유하는 좌표계다. `P`를 월드 공간으로 변환해 같은 함수를 평가하면 서로 다른 메시 위에서도 하나의 연속적인 필드를 만들 수 있다.

같은 줄무늬를 월드 공간 기준으로 만들 때 바꾸는 계산부는 다음과 같다. 이 조각은 앞의 셰이더가 선언한 `frequency` 입력을 사용한다.

```c
point p_world = transform("world", P);
float value = 0.5 + 0.5 * sin(6.2831853 * frequency * p_world[0]);
```

오브젝트 공간 예제의 `p_object`를 `p_world`로 바꾸면 패턴은 각 물체에 고정되지 않고 장면에 남는다. 물체가 움직이면 물체가 월드 공간의 줄무늬나 노이즈를 통과하는 것처럼 보인다. 바닥과 여러 오브젝트에 걸쳐 이어지는 지층, 높이에 따른 색 변화, 공간에 분포한 먼지와 같은 효과에 적합하다.

월드 좌표의 주파수는 장면 단위와 연결되므로 물체 크기가 달라도 같은 공간 간격을 공유할 수 있다. 단, 장면의 단위 체계가 프로젝트마다 다르면 `frequency`의 숫자만 복사해서 같은 크기의 패턴을 얻을 수 없다. 렌더러가 `"world"`라는 좌표계를 제공하는지, 그리고 어떤 공간을 월드로 정의하는지도 확인한다.

## UV 공간: 표면 파라미터를 따라가는 패턴

UV 공간은 표면을 2차원 좌표로 펼친 파라미터 영역이다. OSL의 `u`, `v`를 그대로 사용하면 줄무늬의 위상을 표면의 텍스처 매핑에 맞출 수 있다.

같은 패턴을 UV 기준으로 평가하는 계산 조각은 다음과 같다. `frequency`는 앞 예제와 같은 입력이다.

```c
float stripe_uv = 0.5 + 0.5 * sin(6.2831853 * frequency * u);
```

UV는 표면의 각 지점을 텍스처 영역의 위치와 연결한다. 이미지 텍스처뿐 아니라 사인파, 타일, 노이즈, 마스크 같은 2차원 절차 함수도 같은 좌표에서 평가할 수 있다. UV를 기준으로 한 패턴은 물체가 움직여도 매핑된 위치에 남지만 패턴의 크기는 모델의 UV 펼침과 텍스처 밀도에 좌우된다.

이 좌표가 유효한 표면 매핑이 되려면 렌더러가 사용할 UV 맵을 셰이딩 시스템에 전달해야 한다. 어떤 맵을 선택하는지와 UV가 없는 경우의 처리는 렌더러와 호스트 설정에 따라 확인한다.

UV는 물리적인 거리 좌표가 아니다. 모델을 펼치는 과정에서 섬마다 방향이 달라질 수 있고, UV 이음새에서 값이 끊기거나 표면의 일부에서 늘어나고 압축될 수 있다. UV 영역이 반드시 $[0,1]$에 한정되는 것도 아니다. 범위를 벗어난 좌표를 타일링할지, 반복할지, 잘라낼지는 렌더러와 셰이더 네트워크의 텍스처 처리 규칙을 확인한다. 타일링과 이음새의 효과는 29.6에서 더 다룬다.

## 세 공간을 같은 함수로 비교하기

줄무늬 함수의 형태를 바꾸지 않고 입력 좌표만 바꾸면 패턴이 고정되는 기준이 바뀐다.

| 입력 좌표 | OSL에서 얻는 값 | 패턴의 기준 | 적합한 용도 |
| --- | --- | --- | --- |
| 오브젝트 공간 | `transform("object", P)` | 개별 물체의 로컬 위치 | 물체에 붙는 페인트·결·요철 |
| 월드 공간 | `transform("world", P)` | 장면의 공통 위치 | 여러 물체를 잇는 필드·환경 패턴 |
| UV 공간 | `u`, `v` | 표면의 2D 파라미터화 | 이미지 매핑·타일·표면을 따라가는 패턴 |

결과를 진단할 때는 오브젝트를 이동·회전·스케일하고 카메라를 움직여 본다. 패턴이 물체와 함께 움직여야 하는데 표면 위에서 미끄러진다면 월드 공간을 사용했을 수 있다. 여러 물체 사이에서 필드가 끊기고 각각의 로컬 원점부터 반복된다면 오브젝트 공간일 가능성이 있다. UV 패턴이 특정 부분에서 늘어나거나 이음새가 드러난다면 셰이더보다 UV 펼침이 원인일 수 있다.

## 좌표 변환에서 자료형을 구분하기

OSL의 `transform()`은 점, 벡터, 노멀처럼 의미가 다른 자료형에 사용할 수 있다. 점은 위치이므로 변환의 평행 이동 성분을 포함한다. 벡터는 방향이나 변위이므로 평행 이동을 적용하지 않는다. 노멀은 변환 뒤에도 표면 접선에 수직이어야 하므로 일반 벡터와 같은 방식으로 처리하면 안 된다.

```c
point p_world = transform("world", P);
vector direction_world = transform("world", direction_object);
normal normal_world = transform("world", normal_object);
```

특히 비균일 스케일이 있을 때 노멀에는 역전치 변환이 필요하다. 언어와 렌더러가 자료형에 맞는 변환을 제공하더라도 입력이 실제로 `normal`인지 `vector`인지 정확히 선언해야 한다. 노멀 변환과 셰이딩에서의 용도는 29.4에서 이어서 살펴본다.

`transform("object", P)`처럼 목적 공간만 지정한 형태는 현재 셰이딩 공간에서 지정된 공간으로 바꾸는 표현이다. 두 좌표계를 직접 지정하는 `transform(from, to, value)` 형태도 사용할 수 있다. 좌표계 이름은 렌더러가 장면에 등록한 공간과 일치해야 하므로, 임의의 이름을 문자열로 넣는 것만으로 변환이 만들어지는 것은 아니다.

## 패턴을 어느 공간에서 평가할까

절차 함수에 들어가는 공간을 선택할 때는 그 패턴을 무엇에 고정하고 싶은지 먼저 묻는다.

1. 개별 오브젝트에 무늬가 붙어야 한다면 오브젝트 공간을 사용한다.
2. 여러 물체를 하나의 연속된 장면 필드로 덮고 싶다면 월드 공간을 사용한다.
3. 표면의 매핑과 이미지 좌표를 따라야 한다면 UV 공간을 사용한다.
4. 실제 길이와 주파수가 중요하면 좌표 공간의 단위와 오브젝트 스케일을 함께 조정한다.
5. 렌더러가 해당 공간 이름과 변환을 지원하는지 확인한다.

같은 셰이더 안에서 공간을 섞을 수도 있다. 작은 색상 무늬는 UV로 만들고 큰 얼룩은 월드 노이즈로 더하는 식이다. 다만 변수 이름에 `_object`, `_world`, `_uv`처럼 좌표 기준을 드러내면 서로 다른 공간의 값을 실수로 직접 더하거나 비교하는 일을 줄일 수 있다.

## 이 절의 핵심

OSL의 `P`는 셰이딩 지점의 3차원 위치이고 `u`, `v`는 표면의 UV 좌표다. `transform()`으로 `P`를 오브젝트 공간이나 월드 공간으로 바꾸면 같은 패턴 함수를 물체에 고정하거나 장면 전체에 이어지게 할 수 있다. UV 공간은 표면의 매핑을 따르지만 물리적 거리와 같지 않고 이음새와 왜곡에 영향을 받는다. 좌표 변환에서는 점·벡터·노멀의 의미를 구분하고 렌더러가 제공하는 공간 이름과 단위를 확인한다.
