# 29.7 노이즈와 표면 변화

노이즈는 표면의 좌표를 입력받아 위치마다 조금씩 다른 값을 만드는 연속적인 필드다. 그 값을 색상, 밝기, 거칠기, 범프 높이처럼 재질의 여러 속성에 연결하면 반복 타일의 규칙성을 깨고 넓은 얼룩부터 미세한 결까지 표현할 수 있다. OSL에서는 직접 노이즈 알고리즘을 구현하는 대신 `noise()` 계열의 내장 함수를 호출해 셰이더가 실행되는 표면 위치에서 필드를 평가할 수 있다.

무작위 값과 연속 노이즈는 역할이 다르다. 픽셀이나 셰이딩 표본마다 독립적으로 뽑은 무작위 값은 이웃 위치에서 갑자기 달라져 점 형태의 잡음을 만든다. Perlin 계열 노이즈는 입력 좌표가 조금 변하면 결과도 부드럽게 변하므로 얼룩과 흐름에 적합하다. OSL의 `cellnoise()`처럼 격자 셀마다 일정한 값을 내는 함수는 셀 안에서는 안정적이지만 셀 경계에서 불연속이 생긴다. 어떤 계열을 선택할지는 표면에 필요한 변화가 매끄러운지, 알갱이처럼 분리되어야 하는지에 달려 있다.

## 표면 좌표에서 필드 평가하기

OSL은 셰이딩 위치 `P`에서 노이즈를 평가한다. `P`를 어느 공간의 좌표로 해석할지에 따라 무늬가 물체를 따라가는지, 장면에 고정되는지가 달라진다. 오브젝트 공간의 노이즈는 메시와 함께 움직이고 UV 노이즈는 UV 배치와 이음새를 따른다. 월드 공간 노이즈는 장면에 고정되므로 오브젝트가 움직이면 무늬 위를 지나가는 것처럼 보인다. 좌표 공간의 선택은 29.3에서 다룬 기준을 따른다.

입력 좌표에 주파수를 곱하면 노이즈 특징의 크기를 조절할 수 있다. 주파수가 낮으면 넓고 완만한 얼룩이, 높으면 작고 촘촘한 결이 나타난다. 여기에 서로 다른 주파수와 진폭의 노이즈를 더하면 큰 형태와 작은 세부가 함께 있는 프랙탈 브라운 운동(fBm)을 만들 수 있다. 다음 예제는 오브젝트 공간에서 다섯 옥타브의 노이즈를 합쳐 두 색 사이를 부드럽게 바꾸는 표면 셰이더다.

```c
shader mottled_surface(
    float frequency = 2.5,
    color dark_color = color(0.08, 0.12, 0.16),
    color light_color = color(0.72, 0.48, 0.25),
    output closure color BSDF = 0)
{
    point p = transform("object", P);
    float current_frequency = frequency;
    float amplitude = 0.5;
    float total = 0.0;
    float weight = 0.0;

    for (int octave = 0; octave < 5; ++octave) {
        total += amplitude * noise("perlin", p * current_frequency);
        weight += amplitude;
        current_frequency *= 2.0;
        amplitude *= 0.5;
    }

    float field = total / weight;
    float mask = smoothstep(0.38, 0.62, field);
    color pigment = mix(dark_color, light_color, mask);

    BSDF = diffuse(N) * pigment;
}
```

각 반복에서 공간 주파수는 두 배, 진폭은 절반이 된다. 첫 옥타브가 큰 얼룩을 만들고 뒤의 옥타브가 점차 작은 세부를 더한다. `weight`로 합을 정규화해 옥타브 수가 늘어날 때 전체 밝기 범위가 함께 커지는 것을 막는다. `smoothstep()`은 필드값의 중간 구간을 색상 전이로 사용한다. 임계값을 좁히면 얼룩의 경계가 또렷해지고 넓히면 색이 더 완만하게 섞인다.

여기서 `frequency`는 오브젝트 공간 좌표에 곱해지는 값이다. 물체를 확대하거나 축소하면 오브젝트 공간 무늬도 물체와 함께 확대·축소된다. 물체의 크기와 무관하게 월드에서 일정한 무늬 크기를 유지하려면 월드 공간 좌표를 사용한다. UV 공간은 특정 표면 영역에 얼룩을 고정하기 편하지만, UV가 늘어나거나 갈라지는 곳에서는 무늬도 같은 방식으로 변형된다.

## 하나의 필드를 여러 속성에 연결하기

노이즈를 계산하는 단계와 그 결과를 재질 속성으로 해석하는 단계를 분리하면 같은 필드를 일관된 재질 변화에 사용할 수 있다. 다만 속성마다 적절한 범위와 의미가 다르므로 원시 노이즈값을 모든 입력에 그대로 연결하지 않는다.

| 재질 속성 | 노이즈 필드의 사용 | 조절할 점 |
| --- | --- | --- |
| 베이스 컬러 | 팔레트의 두 색이나 여러 색 사이를 보간 | 임계값과 전이 폭으로 얼룩의 대비 조절 |
| 밝기·방출량 | 넓은 스케일의 필드로 영역별 강도 변화 | 음수나 과도한 값이 생기지 않도록 범위 확인 |
| 거칠기 | 필드를 재질의 거칠기 입력 범위로 재매핑 | 입력 범위와 에너지 반응은 렌더러의 재질 모델에 맞춤 |
| 범프 높이 | 높이 필드의 변화가 조명 노멀에 영향을 주도록 사용 | 주파수와 진폭이 지나치면 표면이 거칠고 불안정해짐 |
| 디스플레이스먼트 | 높이 필드로 표면 위치를 변형 | 렌더러의 변위 평가와 메시 세분화가 필요 |

마지막 두 항목은 시각적 효과가 비슷해 보여도 결과가 다르다. 범프는 조명에 사용하는 표면 방향을 바꾸어 요철처럼 보이게 하지만 메시의 실루엣이나 광선 교차 위치는 바꾸지 않는다. 디스플레이스먼트는 렌더러가 실제 표면 위치를 평가하는 단계에서 적용되어야 실루엣과 교차 결과까지 달라질 수 있다. OSL의 서피스 클로저에 노이즈를 곱하는 것만으로 변위가 발생하는 것은 아니다. 자세한 셰이더 종류와 역할은 29.2를 참고한다.

## 스케일과 출력 범위 조절

노이즈를 색상 마스크로 쓸 때는 노이즈의 출력 구간과 원하는 재질 구간을 맞춘다. `noise("perlin", ...)`의 결과를 그대로 색으로 쓰기보다 예제처럼 팔레트 사이에 보간하면 색을 통제하기 쉽다. 거칠기처럼 범위가 정해진 입력에는 `mix(min_value, max_value, mask)` 또는 `clamp()`를 사용해 의도한 범위로 변환한다. OSL의 노이즈 종류와 반환 형태에 따라 값의 범위와 시각적 분포가 달라질 수 있으므로, 다른 노이즈 함수로 교체할 때는 마스크 임계값도 다시 조정한다.

fBm에서 옥타브 수를 늘리면 계산량도 함께 증가한다. 또한 미세한 옥타브가 렌더 픽셀보다 작아지면 안정적인 세부 대신 앨리어싱과 깜박임이 생길 수 있다. 최종 카메라 거리와 해상도에서 보이지 않는 옥타브는 생략하고, 큰 형태와 미세한 결의 진폭을 따로 조절한다. 렌더러가 제공하는 필터링이나 셰이딩 미분을 사용할 수 있는지는 구현마다 다르며, 관련 주의점은 29.5의 경계 필터링 설명과 같다.

노이즈 값을 더해 다른 노이즈의 입력 좌표를 휘게 하는 방법은 단순한 재질 변화와 다른 단계의 작업이다. 이 좌표 왜곡은 29.8에서 다룬다. 이 절에서는 노이즈 좌표를 고정한 채 필드의 스케일과 진폭, 재질로의 매핑을 조정하는 데 집중한다.

## 이 절의 핵심

OSL의 연속 노이즈는 셰이딩 위치에서 평가하는 필드이며, 좌표 공간이 무늬의 기준을 결정한다. 주파수는 특징의 크기, 진폭은 변화의 폭을 정하고 여러 옥타브를 합하면 큰 얼룩과 미세한 결을 함께 만들 수 있다. 필드 하나를 컬러·거칠기·범프·변위에 연결할 수 있지만, 각 속성에 맞게 범위를 조정해야 한다. 특히 범프는 조명 방향을, 디스플레이스먼트는 렌더러의 표면 위치 평가를 바꾸는 서로 다른 작업이다.
