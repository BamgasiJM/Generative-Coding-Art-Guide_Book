# 29.5 거리 함수 기반 재질

부호 있는 거리 함수(Signed Distance Function, SDF)는 한 점이 어떤 영역의 안쪽인지 바깥쪽인지, 경계에서 얼마나 떨어져 있는지를 나타낸다. 화면 셰이더에서는 SDF로 도형을 직접 그릴 수 있지만, OSL은 보통 렌더러가 이미 찾은 표면점에서 실행된다. 따라서 OSL의 거리 함수는 우선 표면의 색·거칠기·마스크 같은 재질 값을 만드는 필드로 쓰인다. OSL 셰이더만으로 새로운 광선 교차 기하가 자동 생성되는 것은 아니다.

## 거리 부호를 재질 마스크로 바꾸기

거리 함수의 기본 부호 규칙은 다음과 같다.

- $d<0$: 영역의 내부
- $d=0$: 경계
- $d>0$: 영역의 외부

대표적인 구 함수는 점 `p`에서 중심 `c`까지의 거리에서 반지름 `r`을 뺀다.

$$
d(\mathbf{p}) = \lVert \mathbf{p} - \mathbf{c} \rVert - r
$$

거리 함수는 현재 표면점에서 평가한다. 다음 OSL 셰이더는 오브젝트 공간의 평면을 구의 중심 높이와 일치시키면, 평면 위에 원형 색 영역을 만든다.

```c
shader sdf_material(
    point center = point(0.0, 0.0, 0.0),
    float radius = 0.35,
    float edge_width = 0.01,
    color inside_color = color(0.9, 0.28, 0.08),
    color outside_color = color(0.025, 0.08, 0.16),
    output closure color BSDF = 0)
{
    point p_object = transform("object", P);
    float d = length(p_object - center) - radius;
    float mask = 1.0 - smoothstep(-edge_width, edge_width, d);
    color base_color = mix(outside_color, inside_color, mask);

    BSDF = diffuse(N) * base_color;
}
```

`P`를 오브젝트 공간으로 바꾼 뒤 구의 거리를 계산하므로 패턴은 물체의 로컬 기준에 붙는다. `d`가 충분히 음수인 곳은 `inside_color`, 양수인 곳은 `outside_color`에 가까워진다. `smoothstep()`은 경계 주변을 부드럽게 섞는다. `edge_width`는 오브젝트 공간 단위이며, 값을 줄이면 경계가 선명해지고 키우면 색 전이가 넓어진다.

이 셰이더의 SDF는 표면에 색을 배치하는 데 사용된다. 평면이 구의 중심을 지나지 않거나 곡면에 적용되면 표면과 구가 만나는 위치에 따라 마스크 모양이 달라진다. 같은 셰이더를 다른 오브젝트에 적용할 때에도 오브젝트 원점, 스케일, 반지름이 서로 같은 관계인지 확인한다.

## SDF로 다른 재질 속성 만들기

거리값은 색 선택뿐 아니라 여러 재질 입력을 만드는 공통 마스크가 될 수 있다. 예를 들어 부호를 기준으로 바깥 영역을 거칠게 하고, 경계에 가까울수록 발광을 높이거나, 거리의 절댓값으로 얇은 테두리를 만들 수 있다.

$$
m_{\text{inside}} = 1 - \operatorname{smoothstep}(-w, w, d)
$$

$$
m_{\text{edge}} = 1 - \operatorname{smoothstep}(t-a, t+a, |d|)
$$

여기서 `w`는 채움 경계의 전이 폭, `t`는 경계에서 떨어진 테두리 중심 거리, `a`는 테두리 폭이다. `m_inside`는 내부와 외부를 나누고, `m_edge`는 SDF의 0 경계 주변에 띠를 만든다. 같은 마스크를 베이스 컬러, 거칠기, 범프 높이, 방출량에 서로 다른 세기로 연결하면 형태와 재질이 하나의 규칙에서 함께 변한다.

오브젝트 전체에 적용할 SDF와 표면 UV에 적용할 SDF도 구분할 수 있다. `P`를 오브젝트나 월드 공간으로 바꾸면 3차원 필드를 표면에 샘플링한다. `u`, `v`에서 거리를 계산하면 UV 펼침 위에 2차원 도형을 만든다. UV 방식은 매핑의 이음새와 왜곡을 따르고, 3차원 좌표 방식은 메시에 걸쳐 공간적으로 연속될 수 있다. 좌표 선택의 동작은 29.3에서 설명한 기준을 따른다.

## 여러 영역을 조합하기

같은 부호 규칙을 가진 거리 함수는 `min`과 `max`로 합성할 수 있다. 합집합은 두 거리의 최솟값, 교집합은 최댓값, 차집합은 두 번째 거리의 부호를 뒤집은 뒤 최댓값으로 표현한다.

| 영역 조합 | 거리값 | 재질 마스크에서의 용도 |
| --- | --- | --- |
| 합집합 | `min(d1, d2)` | 두 형태 중 하나에 해당하는 영역 |
| 교집합 | `max(d1, d2)` | 두 조건을 모두 만족하는 영역 |
| 차집합 | `max(d1, -d2)` | 한 영역에서 다른 영역을 제외한 부분 |

예를 들어 겹치는 원형 무늬를 합치거나, 큰 영역에서 작은 원을 빼 구멍처럼 보이는 마스크를 만들 수 있다. 이 연산은 마스크의 모양을 결합할 뿐, 실제 기하를 생성하거나 재질 레이어의 광학적 상호작용까지 자동으로 구현하지는 않는다. 거리 함수의 합성과 정확도는 27.5에서 더 자세히 설명했으며, OSL에서는 그 결과를 표면의 재질 입력에 연결한다.

앞의 단일 구 셰이더에서 두 구의 영역을 합치려면 각각의 거리를 계산하고 `min()`을 적용한다. 다음은 두 구의 영역을 하나의 표면 색 마스크로 합성하는 완결된 OSL 재질 예제다.

```c
shader sdf_union_material(
    point center_a = point(-0.2, 0.0, 0.0),
    point center_b = point(0.2, 0.0, 0.0),
    float radius_a = 0.32,
    float radius_b = 0.28,
    float edge_width = 0.01,
    color inside_color = color(0.9, 0.28, 0.08),
    color outside_color = color(0.025, 0.08, 0.16),
    output closure color BSDF = 0)
{
    point p_object = transform("object", P);
    float d_a = length(p_object - center_a) - radius_a;
    float d_b = length(p_object - center_b) - radius_b;
    float d_union = min(d_a, d_b);

    float mask = 1.0 - smoothstep(-edge_width, edge_width, d_union);
    color base_color = mix(outside_color, inside_color, mask);
    BSDF = diffuse(N) * base_color;
}
```

각 `center`와 `radius`는 같은 오브젝트 공간 기준으로 해석한다. `d_union`을 앞의 단일 구 예제처럼 마스크에 연결했기 때문에 겹친 두 영역이 하나의 색 영역으로 나타난다. `min()`은 여기서 합집합의 부호와 윤곽을 만드는 데 쓰이며, 두 형태가 겹치는 내부의 모든 점에서 정확한 최단 거리값을 보장하는 것은 아니다. 따라서 이 결과를 일정한 실제 거리나 변위량으로 해석하기보다, 표면 색 마스크로 쓰는 것이 적절하다.

`min`·`max`는 경계에서 날카로운 접합을 만든다. 경계를 부드럽게 섞는 smooth minimum을 사용하면 마스크 모양을 둥글게 바꿀 수 있지만, 이것은 재질 색의 보간과 같은 작업이 아니다. 어떤 수학적 필드를 만들고 있는지와 그 필드를 어떤 재질 값에 연결하는지를 따로 생각한다.

## 경계 필터링과 렌더 품질

고정된 `edge_width`는 재질 공간의 단위로 경계를 부드럽게 한다. 하지만 카메라에서 매우 멀어지거나 SDF 패턴을 촘촘히 반복하면 한 픽셀보다 작은 경계가 생겨 깜빡임이나 모아레가 나타날 수 있다. 이는 단순히 폭을 일정하게 정하는 문제를 넘어, 렌더러가 한 번의 셰이딩 표본에서 얼마나 넓은 표면 영역을 대표하는지와 관련된다.

OSL 렌더러는 셰이딩 입력의 미분 또는 필터 폭을 제공할 수 있다. 지원되는 환경에서는 `Dx(d)`, `Dy(d)`, `filterwidth(d)`와 같은 기능을 활용해 화면 표본 크기에 맞춘 전이 폭을 구성할 수 있다. 정확한 이름과 유효한 셰이더 문맥은 OSL 구현과 렌더러에 따라 확인해야 한다. GLSL 프래그먼트 단계의 `fwidth()`를 OSL에 그대로 옮기기보다 렌더러가 전달하는 표면 미분과 텍스처 필터링 규칙을 사용한다.

경계를 흐리게 하면 앨리어싱은 줄어들지만 재질 경계도 넓어진다. 따라서 스타일상 날카로운 경계가 필요하면 렌더러 샘플 수와 필터링을 조절하고, 부드러운 경계가 의도라면 전이 폭을 재질 단위에 맞춰 설정한다. 특정 거리 함수가 실제 최단 거리를 반환하지 않는 좌표 변형을 거쳤다면 필터 폭과 마스크 폭도 그 거리 근사에 맞춰야 한다.

## 재질 무늬와 실제 SDF 기하의 차이

OSL의 서피스 셰이더에서 SDF를 계산하면 기존 표면점에서 재질 값을 바꾼다. 그래서 표면 위에 원이나 절개 모양의 색을 만들더라도 광선은 여전히 원래 메시와 교차한다. 재질 무늬는 오브젝트 실루엣이나 실제 가림 관계를 바꾸지 않는다.

디스플레이스먼트에 거리값을 연결하면 기존 표면의 위치를 바꿀 수 있다. 다만 표현 가능한 세부 수준은 메시 세분화와 렌더러의 변위 방식에 제한된다. 변위는 기존 표면을 움직이는 작업이며, 일반적인 표면 재질 SDF만으로 새 메시를 만들거나 임의의 내부·외부 부피를 광선 추적하는 것과는 다르다. 3차원 SDF 자체를 형상으로 렌더링하려면 렌더러의 전용 SDF 기능이나 별도의 레이 마칭·볼륨 경로가 필요하다. 변위와 볼륨 셰이더의 차이는 29.2를 참고한다.

## 이 절의 핵심

OSL에서 SDF는 우선 표면의 셰이딩 위치에 평가하는 수학적 필드다. 그 부호와 경계까지의 거리를 색, 거칠기, 발광, 범프 등의 마스크로 바꾸면 절차적 재질 영역을 만들 수 있다. `P` 기반의 3차원 필드와 UV 기반의 2차원 필드는 표면에 붙는 방식이 다르며, `min`·`max`로 여러 영역을 조합할 수 있다. SDF 기반 재질은 그 자체로 기하를 만들지 않으므로, 실루엣까지 바꾸려면 디스플레이스먼트나 별도의 SDF 렌더링 기법을 선택해야 한다.
