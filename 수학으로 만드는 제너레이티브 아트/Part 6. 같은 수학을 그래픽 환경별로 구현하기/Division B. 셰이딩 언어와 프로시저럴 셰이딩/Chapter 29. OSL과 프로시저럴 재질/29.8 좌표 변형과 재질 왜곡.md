# 29.8 좌표 변형과 재질 왜곡

절차적 재질은 표면 좌표에서 색이나 노이즈를 평가한다. 좌표 자체를 다른 위치로 바꾼 뒤 재질 함수를 평가하면, 함수의 규칙을 바꾸지 않고도 줄무늬와 얼룩을 휘거나 늘일 수 있다. 이 방식을 좌표 워핑 또는 도메인 워핑(domain warping)이라 한다. 29.7이 노이즈 결과를 재질 속성으로 매핑하는 데 초점을 두었다면, 여기서는 노이즈를 좌표 이동량으로 사용한다.

원래 좌표를 $\mathbf{p}$, 좌표에 따라 달라지는 변위 필드를 $\mathbf{w}$라고 하면 워프된 위치는 다음과 같다.

$$
\mathbf{q} = \mathbf{p} + A\mathbf{w}(f_w\mathbf{p})
$$

여기서 $A$는 이동량의 크기, $f_w$는 변위 필드의 공간 주파수다. 최종 패턴 $F$는 원래 좌표가 아니라 이 위치에서 평가한다.

$$
F_{\text{warp}}(\mathbf{p}) = F(f_p\mathbf{q})
$$

따라서 패턴의 주파수 $f_p$와 좌표 변위의 주파수 $f_w$는 서로 다른 역할을 한다. $f_w$는 휨의 크기와 간격을, $f_p$는 워프된 패턴의 줄 간격이나 세부 크기를 정한다.

## 변환과 워핑 구분하기

좌표의 이동·회전·스케일은 비교적 단순한 좌표 변환이다. 좌표 워핑은 위치마다 다른 변위를 적용하는 비선형 매핑이다.

| 변환 | 좌표 계산의 예 | 재질에서 보이는 변화 |
| --- | --- | --- |
| 이동 | `q = p + offset` | 패턴의 위치나 위상 이동 |
| 회전 | `q = R * p` | 패턴 방향 회전 |
| 스케일 | `q = p * frequency` | 패턴 특징 크기 변화 |
| 도메인 워핑 | `q = p + warp(p)` | 위치에 따라 패턴이 구부러지고 늘어남 |

선형 변환은 패턴 전체에 같은 규칙을 적용하지만 워핑은 한 표면 안에서도 좌표가 서로 다른 방향과 크기로 이동한다. 노이즈로 격자를 흐르게 하거나, 줄무늬를 굽이치게 하거나, 색 얼룩의 윤곽을 불규칙하게 만드는 데 유용하다.

## 노이즈로 줄무늬 휘기

다음 OSL 셰이더는 오브젝트 공간의 각 좌표축을 세 번 샘플링해 변위 벡터를 만든다. 노이즈 입력에 서로 다른 오프셋을 주어 세 성분이 똑같은 값으로 움직이는 것을 줄이고, 이동된 좌표에서 비스듬한 줄무늬를 계산한다.

```c
shader warped_stripes(
    float warp_frequency = 0.8,
    float warp_amplitude = 0.25,
    float pattern_frequency = 12.0,
    color dark_color = color(0.025, 0.07, 0.12),
    color light_color = color(0.9, 0.42, 0.12),
    output closure color BSDF = 0)
{
    point p = transform("object", P);

    float nx = 2.0 * noise("perlin", p * warp_frequency
                          + vector(17.0, 0.0, 0.0)) - 1.0;
    float ny = 2.0 * noise("perlin", p * warp_frequency
                          + vector(0.0, 43.0, 0.0)) - 1.0;
    float nz = 2.0 * noise("perlin", p * warp_frequency
                          + vector(0.0, 0.0, 91.0)) - 1.0;

    vector offset = vector(nx, ny, nz) * warp_amplitude;
    point q = p + offset;

    float phase = (q[0] + 0.35 * q[1]) * pattern_frequency;
    float bands = 0.5 + 0.5 * sin(phase);
    float mask = smoothstep(0.42, 0.58, bands);
    color pigment = mix(dark_color, light_color, mask);

    BSDF = diffuse(N) * pigment;
}
```

`noise()`의 스칼라 결과는 좌표를 양방향으로 움직일 수 있도록 `2n - 1`로 중심을 옮긴다. 세 성분에 서로 다른 오프셋을 사용해도 완전히 독립적인 벡터장이 보장되는 것은 아니지만, 동일한 노이즈 신호를 세 축에 그대로 복제하는 것보다 다양한 변형을 얻기 쉽다. `offset`은 위치 `p`에 더하는 벡터이고, `q`는 이후 패턴을 평가할 좌표다.

마지막의 `phase`와 `bands`는 변형의 결과를 보여주기 위한 단순한 주기 패턴이다. 줄무늬를 만드는 `sin()`에 `q`를 넣었으므로 노이즈는 색값에 직접 더해지는 것이 아니라 줄무늬가 놓인 좌표계를 휜다. `BSDF`는 변형된 패턴 색을 확산 반사 재질에 연결한다. 표면 자체의 위치는 변경하지 않는다.

## 진폭과 주파수 조절

`warp_amplitude`는 좌표를 얼마나 이동할지 정한다. 코드에서는 오브젝트 공간 단위의 거리이며, 벡터의 각 성분에 적용되므로 벡터 전체의 길이와 같지는 않다. `warp_frequency`를 낮추면 넓고 완만한 휨이 생기고, 높이면 작은 규모의 물결이나 뒤틀림이 반복된다. `pattern_frequency`는 워프된 공간에서 줄무늬가 얼마나 촘촘한지를 결정하며, 여기서는 사인 함수의 위상에 곱해지므로 공간 단위당 위상 변화량으로 작용한다.

변형의 시각적 강도는 진폭 하나만으로 결정되지 않는다. 좌표장의 급격한 변화는 대략 `warp_amplitude * warp_frequency`에, 그 이동이 줄무늬 위상에 미치는 크기는 `warp_amplitude * pattern_frequency`에 함께 좌우된다. 촘촘한 줄무늬는 같은 좌표 이동에도 크게 휘어 보인다. 따라서 먼저 낮은 `pattern_frequency`에서 `warp_amplitude`를 정하고, 그다음 패턴 주파수를 올려 세부를 조정한다. 고주파 워프와 큰 진폭을 함께 쓰면 좌표가 급격히 접히고, 가느다란 띠가 겹치거나 사라지는 듯 보일 수 있다. 시작점으로는 큰 규모의 약한 변형을 사용하고 필요할 때만 더 작은 스케일을 추가한다.

한 번 워프한 좌표를 다시 다른 워프에 넣거나, 서로 다른 주파수의 워프를 더해 복합적인 흐름을 만들 수도 있다. 다만 각 단계마다 노이즈 계산이 추가되고 왜곡의 결과를 예측하기 어려워진다. 저주파 변형부터 차례로 더하며 각 단계가 실제 출력에서 어떤 역할을 하는지 확인한다. 일반적인 노이즈 변형의 원리와 진폭 중심 조정은 12.9를, OSL 노이즈의 표면 평가와 비용은 29.7을 참고한다.

## 좌표 공간과 표면 연속성

예제는 오브젝트 공간의 `P`에서 좌표 워핑을 시작하므로 무늬가 물체에 붙어 움직인다. 월드 공간 좌표를 쓰면 패턴이 장면에 고정되어 물체가 그 안을 이동하는 것처럼 보인다. UV에서 좌표를 변형하면 무늬를 표면의 매핑에 맞추기 쉽지만, UV 이음새에서는 워프된 값이 양쪽에서 일치하지 않아 경계가 드러날 수 있다. 필요한 연결 방식에 따라 좌표 공간을 선택하는 기준은 29.3과 같다.

오브젝트나 월드 공간에서 계산하면 UV 이음새를 피할 수 있지만, 무늬의 크기와 방향은 선택한 공간의 축과 단위에 묶인다. 비균일 스케일이 있는 물체에서는 오브젝트 공간 패턴이 늘어나 보일 수 있고, 월드 공간 패턴은 물체를 움직일 때 표면을 가로질러 흐른다. 좌표 공간은 단순한 구현 선택이 아니라 패턴이 표면에 붙는 방식을 결정한다.

워프된 좌표를 사용해야 하는 계산은 같은 `q`에서 평가해야 시각 요소가 서로 어긋나지 않는다. 예를 들어 줄무늬 색은 `q`로 평가하면서 다른 표면 효과는 `p`로 평가하면, 두 효과가 서로 다른 공간 변형을 따를 수 있다. 반대로 하나의 필드만 왜곡하려는 의도라면 원본 좌표와 워프된 좌표를 구분해 사용한다.

## 재질 왜곡과 실제 표면 변위

좌표 워핑은 표면의 재질을 평가하는 위치만 바꾼다. 코드에서 새로 만든 `q`는 절차적 줄무늬를 샘플링하기 위한 좌표이며, OSL의 기본 셰이딩 위치 `P`나 메시 정점을 옮기지 않는다. 따라서 무늬는 휘어도 실루엣과 실제 광선 교차 위치는 그대로다.

실제 표면을 바꾸려면 렌더러가 디스플레이스먼트 결과를 기하 평가에 반영해야 한다. 노이즈를 이용한 좌표 왜곡과 표면 위치의 디스플레이스먼트는 함께 사용할 수 있지만 서로 다른 단계다. 또한 워프된 SDF 값을 마스크로 쓰는 경우 그 값은 보통 더 이상 정확한 최단 거리값이 아니다. 일정한 외곽선 폭이나 거리 기반 계산이 중요하다면 변형의 크기와 거리값의 해석을 점검한다. OSL 셰이더 종류와 실제 변위의 차이는 29.2, SDF 거리값의 특성은 29.5를 참고한다.

## 이 절의 핵심

도메인 워핑은 노이즈를 색이나 재질값에 더하는 대신, 그 값을 좌표 이동량으로 사용해 패턴을 다른 위치에서 평가하는 방법이다. 변위 주파수는 휨의 공간 규모를, 진폭은 좌표 이동량을, 최종 패턴 주파수는 왜곡된 무늬의 크기를 정한다. 워핑은 재질 좌표를 바꿀 뿐 실제 표면을 변형하지 않으며, 좌표 공간 선택에 따라 무늬가 물체에 붙거나 장면에 고정된다.
