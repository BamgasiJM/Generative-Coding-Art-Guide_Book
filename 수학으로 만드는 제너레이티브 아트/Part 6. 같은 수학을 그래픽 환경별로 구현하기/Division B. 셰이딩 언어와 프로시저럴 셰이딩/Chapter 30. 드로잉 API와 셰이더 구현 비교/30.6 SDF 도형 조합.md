# 30.6 SDF 도형 조합

부호 있는 거리 함수(Signed Distance Function, SDF)는 경계 안팎을 음수와 양수로 나누고, 경계까지의 거리도 값으로 표현한다. 이 공통 부호 규칙을 이용하면 여러 도형을 합집합·교집합·차집합으로 조합할 수 있다. 여기서는 겹치는 두 원의 합집합을 p5.js의 도형 명령과 GLSL의 거리 필드로 나란히 만든다.

원 중심을 $\mathbf{c}$, 반지름을 $r$라고 할 때 원의 거리는 다음과 같다.

$$
d_{\text{circle}}(\mathbf{p}) = \lVert \mathbf{p} - \mathbf{c} \rVert - r
$$

`d < 0`은 내부, `d = 0`은 경계, `d > 0`은 외부다. 두 거리 함수가 같은 부호 규칙을 사용하면 그 값을 최소·최댓값 연산으로 결합할 수 있다.

| 영역 조합 | 거리 필드 연산 | 부호가 뜻하는 영역 |
| --- | --- | --- |
| 합집합 $A \cup B$ | `min(dA, dB)` | A 또는 B 안쪽이면 내부 |
| 교집합 $A \cap B$ | `max(dA, dB)` | A와 B 모두 안쪽인 부분만 내부 |
| 차집합 $A \setminus B$ | `max(dA, -dB)` | A 안쪽이면서 B 바깥쪽인 부분이 내부 |

이 연산은 부호와 의도한 0 경계를 보존해 영역을 조합한다. 다만 겹치는 도형의 내부를 포함한 모든 점에서 결과가 합성 도형 경계까지의 정확한 최단 거리인 것은 아니다. 2D 채움이나 경계 마스크처럼 부호와 경계가 중요한 용도에는 실용적이지만, 결과값을 정확한 거리로 가정하는 후속 알고리즘에는 별도 검토가 필요하다.

## p5.js: 같은 색 도형으로 실루엣 만들기

p5.js에서 불투명하고 같은 색으로 두 원을 겹쳐 채우면, 내부 겹침 경계는 보이지 않고 바깥 실루엣만 남는다. 이는 화면에 보이는 합집합을 그리는 방법이다. 경계를 따로 그리고 싶지 않으므로 `noStroke()`를 사용한다.

```javascript
function setup() {
  createCanvas(640, 480);
  pixelDensity(1);
  noLoop();
}

function draw() {
  const shortSide = Math.min(width, height);
  const radius = shortSide * 0.22;
  const offset = shortSide * 0.12;

  background(14, 22, 34);
  noStroke();
  fill(236, 92, 46);

  ellipse(width * 0.5 - offset, height * 0.5, radius * 2, radius * 2);
  ellipse(width * 0.5 + offset, height * 0.5, radius * 2, radius * 2);
}
```

두 원의 중심은 수학 좌표에서 각각 $(-0.12, 0)$, $(0.12, 0)$이며 반지름은 0.22다. p5.js의 화면 좌표에서는 중심을 캔버스 가운데에 두고 x축 오프셋에 짧은 변을 곱해 픽셀 위치로 옮겼다. 두 원의 내부를 같은 불투명 색으로 덮어쓰므로 겹친 부분에 경계선이 나타나지 않는다. 스트로크를 켜거나 반투명 채우기를 사용하면 각각 내부 윤곽이나 겹침에 따른 색 변화가 보일 수 있어, 외곽 실루엣만 만드는 합집합과 결과가 달라진다.

## GLSL: 거리값의 최솟값으로 합집합 만들기

프래그먼트 셰이더에서는 현재 위치에서 두 원까지의 거리를 각각 구하고, 그중 작은 값을 합집합의 필드로 사용한다. 그 값이 음수인 부분을 채우고 0 경계 주변은 `fwidth()`로 부드럽게 처리한다.

```glsl
#version 460 core

uniform vec4 uViewport;
uniform vec2 uCenterA;
uniform vec2 uCenterB;
uniform float uRadius;
uniform vec3 uBackground;
uniform vec3 uShapeColor;

layout(location = 0) out vec4 outColor;

float sdCircle(vec2 p, vec2 center, float radius) {
    return length(p - center) - radius;
}

void main() {
    vec2 size = uViewport.zw;
    vec2 pixel = gl_FragCoord.xy - uViewport.xy;
    float shortSide = min(size.x, size.y);
    vec2 p = (pixel - 0.5 * size) / shortSide;

    float dA = sdCircle(p, uCenterA, uRadius);
    float dB = sdCircle(p, uCenterB, uRadius);
    float dUnion = min(dA, dB);

    float aa = max(fwidth(dUnion), 1e-5);
    float mask = 1.0 - smoothstep(-aa, aa, dUnion);
    vec3 color = mix(uBackground, uShapeColor, mask);
    outColor = vec4(color, 1.0);
}
```

호스트는 `uViewport`를 실제 프레임버퍼 픽셀 단위의 `(x, y, width, height)`로 설정하고 전체 화면을 덮는 도형을 렌더링한다. `uCenterA = vec2(-0.12, 0.0)`, `uCenterB = vec2(0.12, 0.0)`, `uRadius = 0.22`를 전달하면 p5.js 예제와 같은 정규화 위치와 크기가 된다. p5.js의 기본 RGB 입력은 0~255이고 GLSL 색상 유니폼은 보통 0~1 범위를 사용하므로, 색상 채널을 255로 나누어 같은 팔레트를 전달한다. 비교할 때는 호스트의 색 공간과 출력 변환도 맞춘다.

`min(dA, dB)`는 두 원 중 적어도 하나의 내부에 있는 점에 음수 값을 준다. 따라서 그 부호로 채움 마스크를 만들면 두 원의 합집합 실루엣이 나타난다. `fwidth(dUnion)`과 `smoothstep()`은 0 경계의 전이를 프래그먼트 크기에 맞춰 부드럽게 한다. p5.js는 도형을 각각 래스터화하고 셰이더는 각 프래그먼트에서 두 거리와 최솟값을 평가하므로, 경계 픽셀의 피복 결과가 완전히 같지는 않을 수 있다.

## 부호 조합과 경계의 의미

교집합과 차집합도 같은 거리 함수를 재사용할 수 있다. 두 원의 경우 GLSL에서 필드를 다음처럼 바꾸면 영역을 조합한다.

```glsl
float dUnion = min(dA, dB);
float dIntersection = max(dA, dB);
float dDifference = max(dA, -dB);
```

세 식은 같은 경계 마스크 계산에 넣을 수 있지만, 의미하는 채움 영역은 다르다. 합집합은 두 도형 중 어느 하나의 내부, 교집합은 양쪽 모두의 내부, 차집합은 A 내부에서 B 내부를 뺀 부분이다. 도형을 뒤집는 `-dB`가 차집합의 핵심이다. 부호가 뒤집히면서 B 안쪽이 양수가 되어 제거할 영역으로 바뀐다.

p5.js의 `ellipse()` 두 번 호출은 불투명 합집합을 화면에 그리는 데 간단하지만, 교집합이나 차집합을 다른 그리기 호출로 표현하려면 클리핑, 마스크, 지우기 또는 경로 조합이 필요하다. 이 경우 도형의 기하 자체를 조합하는 것과 캔버스에 그린 픽셀을 합성하는 것은 구별해야 한다. SDF는 도형의 영역을 하나의 함수식으로 결합하므로 그 결과에 다시 윤곽선이나 부드러운 경계를 적용하기 쉽다.

`min`과 `max`는 경계를 날카롭게 결합한다. 경계가 둥글게 이어지는 효과는 smooth minimum 같은 연산으로 만들 수 있지만, 단순히 같은 합집합을 더 부드럽게 표시하는 것이 아니라 경계 형상을 바꾸는 별도 조합이다. 또한 합성된 필드가 내부 모든 위치에서 정확한 유클리드 거리를 보장하지 않으므로, 이 값을 채움과 화면 경계 처리 외의 계산에 쓸 때는 거리에 대한 가정을 확인한다.

| 비교 항목 | p5.js 도형 명령 | GLSL 거리 필드 |
| --- | --- | --- |
| 두 원의 합집합 | 같은 불투명 색의 원을 겹쳐 그림 | `min(dA, dB)`로 필드를 결합 |
| 내부 표현 | 그리기 순서와 채우기 합성 | 부호 있는 거리값 하나로 영역 표시 |
| 교집합·차집합 | 클립·마스크·지우기 등 추가 단계가 필요 | `max(dA, dB)`, `max(dA, -dB)`로 표현 가능 |
| 경계 처리 | 도형별 래스터화와 피복 규칙 | 결합 필드의 0 경계와 `fwidth()` |
| 재사용성 | 픽셀 결과를 다시 마스크로 만들 수 있음 | 필드를 다른 연산의 입력으로 계속 결합 가능 |

단순한 불투명 합집합은 p5.js의 도형 명령이 직관적이다. 여러 도형을 이어 붙이거나, 구멍·교집합·윤곽선·글로우처럼 경계 주변의 값을 조합해야 하면 거리 필드가 편리하다. 어느 쪽이 빠른지는 도형 수와 화면 크기, 셰이더 계산량에 따라 다르므로 구현 방식만으로 성능을 단정하지 않는다.

## 이 절의 핵심

같은 부호 규칙을 가진 거리 함수는 `min`과 `max`를 통해 합집합·교집합·차집합으로 조합할 수 있다. p5.js는 기본 도형을 겹쳐 화면 실루엣을 만들고, GLSL은 각 프래그먼트에서 거리 필드를 결합해 영역과 경계를 계산한다. 조합 연산은 의도한 부호와 0 경계를 보존하지만 내부 전체에서 항상 정확한 최단 거리를 제공하는 것은 아니므로, 후속 계산에서 값의 거리적 의미를 따져야 한다.
