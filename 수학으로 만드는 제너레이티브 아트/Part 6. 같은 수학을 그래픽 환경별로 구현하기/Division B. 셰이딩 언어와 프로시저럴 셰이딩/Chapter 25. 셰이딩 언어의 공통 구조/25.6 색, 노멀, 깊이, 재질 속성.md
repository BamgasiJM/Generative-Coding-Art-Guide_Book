# 25.6 색, 노멀, 깊이, 재질 속성

셰이더의 계산 결과는 화면 색 하나로 끝나지 않는다. 위치에서 계산한 거리, 노이즈, 마스크, 벡터는 색상뿐 아니라 표면의 방향, 깊이, 거칠기, 금속성, 투명도, 발광량 같은 여러 출력으로 이어질 수 있다. 같은 수학적 필드를 어디에 연결하는지에 따라 평면 패턴은 입체적인 재질이나 공간 효과로 확장된다.

## 색: 가장 직접적인 출력

프래그먼트 셰이더의 대표 출력은 RGB 또는 RGBA 색이다. 스칼라 필드 $v(\mathbf{p})$를 $[0,1]$ 범위로 정규화한 뒤 두 색 사이의 보간값으로 쓰는 방식이 기본이다.

$$
\mathbf{C}(\mathbf{p})=(1-t)\mathbf{C}_0+t\mathbf{C}_1
$$

```glsl
float t = clamp(fieldValue, 0.0, 1.0);
vec3 color = mix(colorA, colorB, t);
```

색은 하나의 값만으로 정할 필요가 없다. 거리 필드는 마스크와 윤곽을, 노이즈는 색 변화와 재질의 불균일함을, 시간 함수는 발광 강도의 맥동을 만들 수 있다. 색을 계산할 때는 출력 범위를 명확히 관리한다. HDR 렌더링에서는 1보다 큰 값이 빛의 강도로 의미를 가질 수 있지만, 일반 8비트 출력에서는 값이 잘리거나 톤 매핑된다.

```glsl
vec3 emission = glowColor * max(0.0, fieldValue) * intensity;
```

## 법선: 표면이 향하는 방향

법선(normal)은 표면의 바깥 방향을 나타내는 단위 벡터다. 조명은 표면이 광원을 얼마나 향하는지에 반응하므로, 법선은 입체감의 핵심 입력이다. 가장 단순한 확산 조명은 법선 $\mathbf{n}$과 광원 방향 $\mathbf{l}$의 내적으로 계산한다.

$$
I_d=\max(0,\mathbf{n}\cdot\mathbf{l})
$$

```glsl
vec3 n = normalize(normal);
vec3 l = normalize(lightPosition - worldPosition);
float diffuse = max(0.0, dot(n, l));
```

버텍스 셰이더에서 메시를 변위하면 원래 법선은 더 이상 정확하지 않을 수 있다. 실제 기하의 방향을 다시 계산하거나, 프래그먼트 단계에서 미분을 이용해 근사한 법선을 만들 수 있다. 또한 실제 정점을 움직이지 않고도 법선을 조금 흔들어 표면이 울퉁불퉁해 보이게 하는 범프 매핑과 노멀 매핑이 있다.

스칼라 높이 필드 $h(x,y)$가 있을 때, 주변 변화율로 기울기를 구해 법선을 근사할 수 있다.

$$
\mathbf{n}\approx\operatorname{normalize}\left(-\frac{\partial h}{\partial x},-\frac{\partial h}{\partial y},1\right)
$$

```glsl
float hx = height(p + vec2(epsilon, 0.0)) - height(p - vec2(epsilon, 0.0));
float hy = height(p + vec2(0.0, epsilon)) - height(p - vec2(0.0, epsilon));
vec3 bumpNormal = normalize(vec3(-hx, -hy, normalStrength));
```

높이 필드의 주파수와 법선 강도를 높이면 세밀하고 거친 재질처럼 보이지만, 실제 실루엣은 바뀌지 않는다. 가까운 거리에서 뚜렷한 돌출이 필요하다면 정점 변위나 디스플레이스먼트가 필요하다.

## 깊이: 앞뒤 관계와 공간 효과

깊이(depth)는 카메라에서 볼 때 프래그먼트가 얼마나 앞 또는 뒤에 있는지를 나타낸다. 일반적인 3D 렌더링에서는 래스터화와 깊이 버퍼가 이 값을 관리하며, 더 가까운 표면이 먼 표면을 가리도록 한다. 프래그먼트 셰이더가 깊이 값을 직접 바꿀 수도 있지만, 이는 깊이 검사와 초기 깊이 최적화에 영향을 줄 수 있어 신중히 사용한다.

깊이는 안개, 심도, 윤곽 강조, 거리 기반 색 변화에 유용한 입력이다.

$$
\mathbf{C}_{fog}=(1-f)\mathbf{C}_{surface}+f\mathbf{C}_{fog}
$$

```glsl
float fogAmount = smoothstep(nearDistance, farDistance, viewDistance);
vec3 finalColor = mix(surfaceColor, fogColor, fogAmount);
```

전체 화면 후처리에서 깊이 텍스처를 읽으면, 화면 좌표만으로도 장면의 앞뒤 구조에 반응할 수 있다. 예를 들어 가까운 물체의 경계를 강조하거나, 먼 곳에만 노이즈와 색 변화를 적용할 수 있다. 다만 깊이 텍스처의 값은 종종 원근 투영에 의해 선형 거리가 아니므로, 실제 거리로 쓸 때는 투영 행렬과 카메라 설정에 맞춰 복원해야 한다.

## 재질 속성: 빛과 만나는 방식

현대 렌더러의 재질은 기본 색 외에도 표면이 빛을 반사·투과·발광하는 방식을 나타내는 여러 속성을 가진다. 물리 기반 렌더링(PBR)에서는 기본 색(base color), 거칠기(roughness), 금속성(metallic), 법선, 발광(emission), 투명도 같은 값을 조합하는 일이 흔하다.

| 속성 | 주된 역할 | 필드 연결의 예 |
| --- | --- | --- |
| Base color | 표면의 기본 색 | 팔레트, 마스크, 노이즈 |
| Roughness | 반사가 퍼지는 정도 | 거친 노이즈, 거리 기반 변화 |
| Metallic | 금속성 반사 성격 | 영역 마스크, 재질 구분 |
| Normal | 빛에 대한 표면 방향 | 높이 필드의 그래디언트 |
| Emission | 자체 발광 | 파동, 시간 펄스, 밝은 마스크 |
| Opacity/alpha | 투명·불투명 정도 | 거리 필드 경계, 밀도 필드 |

예를 들어 하나의 노이즈 필드를 기본 색에만 연결하면 표면의 얼룩처럼 보인다. 같은 값을 거칠기에도 조금 연결하면 밝은 부분과 어두운 부분이 반사를 다르게 가져, 더 물질적인 인상을 준다.

```text
noise -> base color blend
noise -> roughness variation
distance mask -> metallic region
time wave -> emission intensity
```

속성을 모두 같은 필드에 강하게 연결하면 재질이 과장되거나 인공적으로 보일 수 있다. 큰 스케일의 필드는 색과 재질 구역을 정하고, 작은 스케일의 필드는 거칠기와 법선에 약하게 더하는 식으로 역할을 나누면 조절하기 쉽다.

## 색 공간과 빛의 합성

색을 재질과 조명에 연결할 때는 색의 숫자와 빛의 양을 구분할 필요가 있다. 대부분의 화면 이미지는 sRGB처럼 사람이 보기 좋도록 비선형 인코딩된 상태로 저장·표시된다. 하지만 가산 조명과 블렌딩은 보통 선형 공간에서 계산해야 물리적인 빛의 합에 가까운 결과를 얻는다.

```text
texture in sRGB
    -> convert to linear values
    -> lighting and blending calculations
    -> tone mapping and display conversion
```

많은 엔진과 렌더러는 이 과정을 자동으로 처리하거나 설정으로 제공한다. 직접 셰이더를 작성할 때 결과가 지나치게 어둡거나, 두 빛을 합쳤는데 기대와 다른 색이 나온다면 색 공간과 텍스처의 sRGB 설정을 점검한다. 제너레이티브 아트에서도 특히 가산 합성, 발광, HDR 후처리에서 차이가 눈에 띈다.

## 마스크로 재질을 합성하기

거리 필드나 노이즈에서 만든 마스크는 색뿐 아니라 두 재질 사이의 선택값이 될 수 있다. 마스크 $m\in[0,1]$로 두 재질 파라미터를 각각 보간하면, 하나의 표면에서 영역별로 다른 재질 반응을 만든다.

$$
R=(1-m)R_0+mR_1
$$

```glsl
float mask = smoothstep(low, high, fieldValue);
vec3 baseColor = mix(colorA, colorB, mask);
float roughness = mix(roughnessA, roughnessB, mask);
float metallic = mix(metallicA, metallicB, mask);
```

여기서 색·거칠기·금속성을 같은 마스크로 보간하면 한 재질이 다른 재질로 바뀌는 영역이 일관되게 보인다. 각 속성에 다른 마스크를 쓰면 더 복잡한 결과를 만들 수 있지만, 어느 규칙이 어떤 표면 변화를 만들었는지 추적하기 어려워진다.

## 재질과 기하의 경계

법선·거칠기·색 변화는 평평한 메시도 풍부하게 보이게 하지만, 실제 기하를 바꾸지는 않는다. 실루엣, 그림자 형태, 다른 물체와의 충돌은 원래 메시의 형태를 따른다. 이 차이를 이해하면 언제 프래그먼트 재질로 충분하고, 언제 버텍스 변위·테셀레이션·실제 모델링이 필요한지 판단할 수 있다.

| 목표 | 우선 검토할 방법 |
| --- | --- |
| 표면의 미세한 질감과 빛 반응 | 노멀·범프·거칠기 |
| 색상·발광·마스크 변화 | 프래그먼트 또는 서피스 셰이딩 |
| 윤곽과 그림자까지 변하는 큰 형태 | 버텍스 변위, 디스플레이스먼트, 기하 수정 |
| 화면 전체의 거리·색 효과 | 깊이 텍스처 기반 후처리 |

## 이 절의 핵심

셰이더의 함수 결과는 색뿐 아니라 법선, 깊이 관련 효과, 거칠기·금속성·발광·투명도 같은 재질 속성으로 연결될 수 있다. 거리·노이즈·마스크 필드를 여러 출력에 일관되게 연결하면 표면의 색과 빛 반응이 하나의 규칙을 공유한다. 다만 재질 변화는 실제 실루엣을 바꾸지 않으므로, 필요한 표현의 규모에 따라 기하 변형과 구분해야 한다.
