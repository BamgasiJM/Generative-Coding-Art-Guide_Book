# 27.6 좌표 변형과 타일링

GLSL에서 패턴의 위치와 방향을 바꾸는 기본 방법은 이미 만들어진 색을 옮기는 것이 아니라, 패턴을 평가할 좌표를 변형하는 것이다. 좌표를 먼저 이동·회전·확대하고 그 결과를 도형 함수에 넣으면 하나의 규칙을 다양한 위치와 크기로 재사용할 수 있다. 변형한 좌표를 격자 단위로 접으면 같은 규칙을 화면이나 표면에 반복할 수도 있다. 변환의 일반 원리는 Part 3에서 다루었으며, 이 절에서는 GLSL 4.60에서 그 연산을 함수로 구성하는 방법에 초점을 둔다.

## 좌표를 되돌려 패턴을 움직이기

프래그먼트 셰이더는 출력할 각 위치에서 색을 계산한다. 도형이나 패턴을 화면에서 오른쪽으로 옮기고 싶다면, 현재 샘플 좌표에서 이동량을 빼고 원래 위치에서 패턴을 평가한다. 이것은 패턴을 앞으로 옮기는 변환의 역변환이다.

```glsl
vec2 q = p - offset;
float value = pattern(q);
```

`p`는 화면 또는 렌더 영역에서 얻은 좌표이고 `q`는 패턴 함수가 사용할 로컬 좌표다. `offset`을 더하면 출력 위치에서 패턴을 왼쪽으로 읽게 되어 화면상으로는 패턴이 오른쪽으로 움직인다. 좌표에서 무엇을 빼는지가 화면에서 어떤 방향으로 움직이는지 헷갈리면, 원점에서 벗어난 표식 하나를 놓고 이동 방향을 확인한다.

회전과 확대도 같은 역변환 원리를 따른다. 먼저 GLSL에서 2D 회전 함수를 정의한다.

```glsl
vec2 rotate2D(vec2 p, float angle) {
    float c = cos(angle);
    float s = sin(angle);
    return vec2(c * p.x - s * p.y, s * p.x + c * p.y);
}
```

이 함수는 양의 각도에서 좌표를 반시계 방향으로 회전한다. 각도는 라디안 단위다. 화면 위에서 패턴을 양의 각도로 돌리려면 샘플 좌표에는 반대 각도를 적용한다. 균일 확대 계수 `scale`을 적용한 전체 역변환은 다음과 같다.

```glsl
vec2 q = p - offset;
q = rotate2D(q, -angle);
q /= scale;
float value = pattern(q);
```

여기서는 `scale`이 0보다 큰 균일한 배율이라고 가정한다. 패턴 좌표를 배율로 나누면 패턴이 화면에서 커지고, 좌표에 배율을 곱하면 화면에서 작아진다. 순방향으로 `scale -> rotate -> translate`를 적용한 도형을 평가하려면 현재 좌표에서 이동을 되돌리고, 회전을 되돌리고, 마지막으로 배율을 나누므로 역순이 된다. 변환 순서와 기준점의 일반 원리는 7.7과 7.8을 참고한다.

## 기준점을 옮겨 회전하기

원점이 아닌 패턴 중심을 기준으로 변환하려면 먼저 기준점을 원점으로 옮긴다. 변형 후 기준점을 다시 되돌린다.

```glsl
vec2 local = p - pivot;
local = rotate2D(local, -angle);
local /= scale;
vec2 q = local + pivot;
```

이 흐름을 사용하면 중심 `pivot`은 회전과 확대 중에도 고정된다. 중심을 생략하고 화면 원점 기준으로 회전하면 패턴의 방향뿐 아니라 원점에서 떨어진 위치까지 함께 회전하여 공전처럼 보일 수 있다. 화면 전체를 돌릴지, 타일 하나를 돌릴지, 각 셀 내부 도형만 돌릴지에 따라 변환을 적용할 좌표 단계를 구분한다.

좌표 변환은 행렬로도 표현할 수 있지만, 간단한 패턴은 단계별 벡터 연산이 읽기 쉽다. 행렬을 사용할 때는 GLSL의 행렬 생성자와 벡터 곱의 열 우선 규약, 호스트 라이브러리의 행렬 규약을 확인한다. 코드에 쓴 연산 순서가 직관과 다르게 보일 수 있으므로 먼저 명시적인 단계로 검증한 뒤 행렬로 합치는 편이 안전하다.

## `floor`와 `fract`로 타일 좌표 만들기

반복 개수만큼 좌표를 확대하고 정수 부분과 소수 부분을 분리하면 셀 인덱스와 셀 내부 좌표를 함께 얻는다.

```glsl
vec2 grid = q * tileCount;
vec2 cellId = floor(grid);
vec2 cellLocal = fract(grid) - 0.5;
```

`cellId`는 어느 반복 셀인지, `cellLocal`은 그 셀의 중심을 원점으로 보았을 때 현재 위치가 어디인지 나타낸다. `cellLocal`의 각 성분은 대략 `[-0.5, 0.5)` 범위다. 셀마다 같은 원을 그리고 싶다면 이 로컬 좌표에서 거리를 계산한다.

```glsl
float d = length(cellLocal) - radius;
```

이 거리에 채움 마스크를 적용하면 한 셀의 원이 모든 셀에 반복된다. 반대로 셀마다 색이나 크기를 달리하려면 `cellId`를 별도의 입력으로 사용한다. 예를 들어 인덱스의 짝홀성으로 색을 교대하거나, 셀 좌표를 해시 함수에 전달해 고정된 변주값을 만들 수 있다. `cellId`와 `cellLocal`의 역할 분리는 8.3의 반복 구조와 같으며, GLSL의 `floor`와 `fract`도 같은 방식으로 동작한다.

완성된 단일 프래그먼트 예제는 화면 좌표를 변형한 뒤 셀마다 원을 배치한다. `p`는 27.3에서 만든 화면 중심 기준·종횡비 보정 좌표이고, 색과 배율은 호스트가 유니폼으로 전달한다고 가정한다.

```glsl
#version 460 core

uniform vec4 u_viewport;
uniform vec2 u_offset;
uniform vec2 u_tileCount;
uniform float u_angle;
uniform float u_scale;
uniform float u_radius;
uniform vec3 u_background;
uniform vec3 u_foreground;
layout(location = 0) out vec4 outColor;

vec2 rotate2D(vec2 p, float angle) {
    float c = cos(angle);
    float s = sin(angle);
    return vec2(c * p.x - s * p.y, s * p.x + c * p.y);
}

void main() {
    vec2 size = u_viewport.zw;
    vec2 pixel = gl_FragCoord.xy - u_viewport.xy;
    vec2 p = (pixel - 0.5 * size) / size.y;

    vec2 q = rotate2D(p - u_offset, -u_angle) / u_scale;
    vec2 grid = q * u_tileCount;
    vec2 cellLocal = fract(grid) - 0.5;

    float d = length(cellLocal) - u_radius;
    float aa = max(fwidth(d), 1e-5);
    float mask = 1.0 - smoothstep(-aa, aa, d);
    vec3 color = mix(u_background, u_foreground, mask);
    outColor = vec4(color, 1.0);
}
```

`u_scale`은 0보다 커야 하고, `u_tileCount`의 두 성분은 각 축의 반복 밀도를 정한다. 이 예제는 화면을 가로질러 같은 원을 반복한다. 각 원의 반지름은 셀 내부 좌표 단위이므로, 예를 들어 `u_radius`를 0.2로 두면 셀 중앙에 여백을 남긴 원이 만들어진다. 화면 좌표의 단위와 프레임버퍼 크기는 27.3에서 설명한 기준을 따른다.

## 셀마다 방향을 뒤집는 미러 타일링

일반 타일링은 모든 셀에 같은 방향의 좌표를 적용한다. 인접 셀에서 좌표 방향을 번갈아 뒤집으면 반복 경계의 일부를 자연스럽게 감추는 미러 타일링을 만들 수 있다.

```glsl
vec2 mirroredLocal(vec2 grid) {
    vec2 id = floor(grid);
    vec2 local = fract(grid);
    vec2 oddCell = mod(id, vec2(2.0));
    return mix(local, 1.0 - local, oddCell);
}
```

각 축에서 홀수 셀일 때 `local`을 뒤집으므로 결과는 일반 반복처럼 매 타일 시작점에서 같은 방향으로 되돌아가지 않는다. 셀 단위 변환을 적용하고 싶을 때도 `cellId`를 이용해 셀의 짝홀에 따라 회전이나 반사를 선택할 수 있다. 미러링은 값이 경계에서 이어지도록 도울 수 있지만, 기울기까지 항상 매끄럽게 이어지는 것은 아니다. 방향 변화가 강한 패턴은 경계에서 꺾임이 보일 수 있다.

## 이음새와 앨리어싱 점검

`fract`는 정수 경계를 지날 때 셀 내부 좌표를 끝에서 시작으로 접는다. 각 셀 안에서 계산하는 함수가 셀 경계의 양쪽에서 서로 다른 값을 가지면 이음새가 생긴다. 원이 셀 중앙에 완전히 들어가는 예제는 경계에서 마스크가 0에 가까워 이음새가 잘 드러나지 않는다. 반면 셀 가장자리까지 이어지는 그라디언트나 줄무늬는 경계 양쪽의 색과 방향이 맞는지 확인해야 한다.

또한 타일 수를 너무 높이면 하나의 셀이 화면에서 몇 픽셀보다 작아져 깜빡이거나 모아레가 생길 수 있다. 거리 경계에는 `fwidth` 기반 안티앨리어싱을 적용할 수 있지만, 이것이 모든 고주파 패턴을 복구하지는 않는다. 반복 수를 줄이거나, 낮은 해상도에서 패턴을 렌더링하거나, 밉맵이 있는 타일 텍스처를 사용하는 방법을 검토한다. 텍스처 샘플러의 반복 모드는 26.7에서 다루었으며, 이 절의 `fract`는 수식으로 셀 좌표를 직접 접는 방식이다.

## 이 절의 핵심

패턴을 이동·회전·확대할 때는 각 출력 위치의 좌표를 역변환한 뒤 로컬 패턴을 평가한다. `floor`와 `fract`는 전체 좌표를 셀 인덱스와 타일 내부 좌표로 나누어 반복 구조를 만들고, 셀 ID는 셀마다 다른 변주를 부여하는 데 쓸 수 있다. 타일 경계에서 함수값이 맞는지, 반복 빈도가 화면 픽셀에 비해 지나치게 높지 않은지 확인해야 한다.
