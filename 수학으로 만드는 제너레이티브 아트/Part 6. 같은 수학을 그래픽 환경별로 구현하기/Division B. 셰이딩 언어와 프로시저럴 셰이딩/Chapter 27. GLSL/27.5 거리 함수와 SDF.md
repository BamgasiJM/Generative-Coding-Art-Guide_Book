# 27.5 거리 함수와 SDF

프래그먼트 셰이더에서는 화면의 각 위치에서 같은 거리 함수를 평가해 채움, 윤곽, 마스크를 만들 수 있다. 부호 있는 거리 함수(Signed Distance Function, SDF)는 한 점이 도형의 안쪽인지 바깥쪽인지와 경계에서 얼마나 떨어져 있는지를 하나의 값으로 표현한다. 거리 함수의 수학적 정의와 기본 도형별 공식은 5장에서 다루었으므로, 여기서는 그 값을 GLSL 4.60 프래그먼트 셰이더에서 화면으로 바꾸는 방법에 집중한다.

## 거리값 하나로 경계를 표현하기

SDF에서 `d < 0.0`은 도형 내부, `d == 0.0`은 경계, `d > 0.0`은 외부를 뜻한다. 프래그먼트 셰이더는 각 위치 `p`에서 `d = sdf(p)`를 계산한다. 그 뒤 부호를 마스크로 바꾸거나, `abs(d)`를 경계까지의 거리로 사용해 외곽선을 만든다.

원과 축 정렬 박스의 대표 함수는 다음과 같다.

```glsl
float sdCircle(vec2 p, vec2 center, float radius) {
    return length(p - center) - radius;
}

float sdBox(vec2 p, vec2 center, vec2 halfSize) {
    vec2 q = abs(p - center) - halfSize;
    return length(max(q, 0.0)) + min(max(q.x, q.y), 0.0);
}
```

두 함수는 서로 다른 모양을 만들지만 반환값의 부호 규칙이 같으므로, 이후의 채움과 윤곽 계산을 공통 함수처럼 재사용할 수 있다. GLSL의 벡터 함수는 성분마다 작동한다. 예를 들어 `max(q, 0.0)`은 `q.x`, `q.y` 각각과 0의 최댓값을 구한다.

## 거리값을 프래그먼트 마스크로 바꾸기

가장 직접적인 채움은 `d < 0.0`인지 비교하는 것이다. 하지만 경계가 픽셀 사이를 지나면 픽셀 단위의 급격한 전환이 계단처럼 보인다. 프래그먼트 셰이더의 `fwidth()`를 사용하면 화면에서 거리값이 한 픽셀에 걸쳐 얼마나 변하는지 추정해 경계 폭을 조절할 수 있다.

```glsl
float aa = max(fwidth(d), 1e-5);
float fill = 1.0 - smoothstep(-aa, aa, d);
```

`fwidth(d)`는 대략 `abs(dFdx(d)) + abs(dFdy(d))`에 해당하는 화면 미분값이다. 경계 근처에서 `smoothstep()`이 0과 1 사이의 부분적인 피복률을 만들고, 그 값으로 배경색과 도형색을 섞으면 가장자리가 부드러워진다. `1e-5`는 미분값이 0에 가까운 경우에도 `smoothstep` 경계가 같아지지 않도록 두는 작은 하한이다.

다음 프래그먼트 셰이더는 27.3에서 다룬 뷰포트 기준 좌표를 사용해 원을 그린다. `u_viewport`는 `(x, y, width, height)`이며, 원점과 크기는 프레임버퍼 픽셀 단위라고 가정한다.

```glsl
#version 460 core

uniform vec4 u_viewport;
uniform vec3 u_background;
uniform vec3 u_shapeColor;
layout(location = 0) out vec4 outColor;

float sdCircle(vec2 p, vec2 center, float radius) {
    return length(p - center) - radius;
}

void main() {
    vec2 size = u_viewport.zw;
    vec2 pixel = gl_FragCoord.xy - u_viewport.xy;
    vec2 p = (pixel - 0.5 * size) / size.y;

    float d = sdCircle(p, vec2(0.0), 0.32);
    float aa = max(fwidth(d), 1e-5);
    float fill = 1.0 - smoothstep(-aa, aa, d);

    vec3 color = mix(u_background, u_shapeColor, fill);
    outColor = vec4(color, 1.0);
}
```

좌표 `p`는 화면 중심이 원점이 되도록 이동했고, x와 y를 뷰포트 높이로 나누어 종횡비를 보정했다. 따라서 창의 가로세로 비율이 달라져도 화면에서 원이 타원으로 늘어나지 않는다. 각 픽셀에서 계산한 `d`가 음수면 `fill`은 1에 가까워지고, 양수면 0에 가까워져 두 색의 혼합을 결정한다.

`fwidth()`는 프래그먼트 단계에서 사용해야 한다. 버텍스 셰이더나 컴퓨트 셰이더에는 같은 화면 미분 의미가 없다. 또한 이 미분값은 인접 실행의 값을 이용하므로 프래그먼트마다 서로 다른 분기 안에서 호출하면 정의되지 않은 결과가 생길 수 있다. 특별한 이유가 없다면 거리값을 먼저 계산하고 `fwidth(d)`를 균일한 실행 경로에서 구한다.

## 같은 거리값에서 윤곽과 띠 만들기

외곽선을 만들 때는 경계까지의 거리인 `abs(d)`를 사용한다. `halfWidth`를 선의 반폭으로 두면 경계 안팎에 같은 두께의 띠를 만들 수 있다.

```glsl
float outline = 1.0 - smoothstep(
    halfWidth - aa,
    halfWidth + aa,
    abs(d)
);
```

`d` 자체에 부호 조건을 적용하면 안쪽에만 있거나 바깥쪽에만 있는 윤곽을 만들 수 있다. 거리값은 경계에서 멀어질수록 변하므로, 외곽선만이 아니라 경계 주변의 색 변화나 바깥쪽 글로우에도 활용할 수 있다. 채움·윤곽·그라데이션을 만드는 기본 패턴은 5.8에서 다루었고, 여기서는 그 경계 폭을 화면 픽셀 크기에 맞추는 `fwidth()`의 역할이 핵심이다.

## SDF의 부호 규칙으로 도형 합성하기

두 함수가 같은 부호 규칙을 따른다면 `min`과 `max`로 영역을 조합할 수 있다. 두 거리값을 `d1`, `d2`라고 할 때 기본적인 연산은 다음과 같다.

| 형태 연산 | 거리 표현 | 의미 |
| --- | --- | --- |
| 합집합 | `min(d1, d2)` | 두 영역 중 하나라도 내부인 부분 |
| 교집합 | `max(d1, d2)` | 두 영역 모두 내부인 부분 |
| 차집합 | `max(d1, -d2)` | 첫 영역에서 두 번째 영역을 뺀 부분 |

예를 들어 원에서 작은 원을 빼는 계산은 다음처럼 작성할 수 있다.

```glsl
float dOuter = sdCircle(p, vec2(-0.12, 0.0), 0.42);
float dCutout = sdCircle(p, vec2(0.12, 0.0), 0.32);
float dShape = max(dOuter, -dCutout);
```

그 다음 `dShape`에 채움과 윤곽 공식을 그대로 적용하면 구멍이 있는 형태를 그릴 수 있다. `min`과 `max`의 경계는 날카롭게 만난다. 둥글게 이어지는 smooth union 같은 연산은 추가적인 거리 근사와 매개변수를 사용하며, 구체적인 도형 조합 방식과 드로잉 API의 차이는 30.6에서 비교한다.

## 거리의 정확도와 좌표 변형

기본 원과 박스 공식은 정의된 좌표 공간의 유클리드 거리다. 평행 이동과 회전처럼 길이를 보존하는 변환은 거리 해석을 유지한다. 좌표에 비균일한 스케일을 적용하면 x축과 y축의 단위가 달라져 `d`가 더 이상 실제 최단 거리와 일치하지 않을 수 있다. 화면에서 형태와 경계를 그리는 용도라면 거리 추정값도 충분할 때가 있지만, 거리값 자체로 안전한 이동량을 결정하는 레이 마칭에서는 과대평가가 문제를 일으킬 수 있다.

안티앨리어싱은 현재 화면에 투영된 거리 변화로 경계 폭을 추정하므로, 함수가 반환하는 값이 경계 주변에서 일관되게 변해야 안정적이다. 좌표를 변형하거나 복잡한 근사 함수를 합성한 뒤 가장자리 두께가 달라 보이면 좌표 스케일과 거리 단위를 먼저 확인한다. 좌표를 회전·반복·왜곡하는 방법은 27.6에서, SDF를 전체 화면 생성 규칙으로 구성하는 예는 27.8에서 이어서 살펴본다.

`min`·`max` 기반 합성은 일반적으로 원하는 영역의 부호와 0 경계를 보존하지만, 겹친 도형의 안쪽을 포함해 모든 위치에서 실제 최단 거리를 반환한다고 보장하지는 않는다. 2D 채움과 윤곽처럼 경계 주변만 사용하는 경우에는 대개 문제가 적다. 거리값만큼 광선을 전진시키는 레이 마칭에서는 이 값이 안전한 거리 추정인지 따로 확인해야 한다.

## 이 절의 핵심

GLSL의 SDF 함수는 각 프래그먼트 위치에서 부호 있는 거리값을 계산하고, 그 부호로 영역을 정하며 `abs(d)`로 경계까지의 거리를 얻는다. `fwidth()`와 `smoothstep()`을 결합하면 해상도와 화면 배율에 반응하는 부드러운 경계를 만들 수 있다. 공통 부호 규칙은 `min`·`max` 기반 조합을 가능하게 하지만, 좌표 스케일과 거리 함수의 정확도는 윤곽 품질과 후속 계산에 영향을 준다.
