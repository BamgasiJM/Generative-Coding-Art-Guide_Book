# 7.4 회전

2차원 회전은 원점 기준 좌표를 각도 $\theta$만큼 돌리는 변환이다. 회전은 길이를 보존하므로 원은 여전히 원이고, 거리도 유지된다.

$$
\begin{aligned}
x'&=x\cos\theta-y\sin\theta \\
y'&=x\sin\theta+y\cos\theta
\end{aligned}
$$

```text
function rotate(p, angle):
    return (
        p.x * cos(angle) - p.y * sin(angle),
        p.x * sin(angle) + p.y * cos(angle)
    )
```

## 함수에서 회전하기

회전한 도형을 평가할 때는 입력 좌표를 반대 각도로 돌린다.

```text
local = position - center
local = rotate(local, -angle)
distanceValue = shape(local)
```

회전은 중심을 기준으로 해야 하므로 먼저 중심을 빼고, 회전한 뒤 표준 도형 함수에 넣는다. 중심을 빼지 않으면 도형은 자기 자리에서 돌지 않고 원점을 중심으로 공전한다.

## 실제 라이브러리

Canvas 2D의 `rotate()`, p5.js의 `rotate()`, SVG의 `rotate()`는 현재 좌표계를 회전한다. GLSL에서는 위 식이나 2×2 행렬을 사용한다.

```glsl
mat2 rotation2D(float a) {
    float c = cos(a);
    float s = sin(a);
    return mat2(c, -s, s, c);
}
```

## 각도의 단위와 회전 방향

수식과 GLSL의 삼각함수는 라디안을 사용한다. 한 바퀴는 $2\pi$이고, 90도는 $\pi/2$다. 도 단위 값을 받는 인터페이스에서는 변환을 한 번 명시적으로 수행한다.

$$
\theta_{rad}=\theta_{deg}\frac{\pi}{180}
$$

일반적인 수학 좌표계에서 양의 각도는 반시계 방향 회전이다. 화면 좌표계는 y축이 아래로 증가하는 경우가 많아 같은 식이 시계 방향처럼 보일 수 있다. 좌표계를 뒤집었는지, 각도 부호를 바꾸었는지를 한 규약으로 유지한다.

회전은 길이를 보존하므로 거리 함수와 궁합이 좋다. 원 자체보다 원 안의 줄무늬·노이즈 좌표를 회전시킬 때 효과가 더 분명하다.

## 이 절의 핵심

회전은 사인과 코사인으로 좌표 성분을 섞는 변환이다. 패턴 자체를 돌리는 대신 입력 좌표를 반대 방향으로 회전하면 같은 표준 함수로 회전한 형태를 만들 수 있다.
