# 7.4 회전

2차원 회전은 원점 기준 좌표를 각도 $\theta$만큼 돌리는 변환이다. 회전은 길이를 보존하므로 원은 여전히 원이고, 거리도 유지된다.

$$
\begin{aligned}
x'&=x\cos\theta-y\sin\theta \\
y'&=x\sin\theta+y\cos\theta
\end{aligned}
$$

이 식은 $x$와 $y$를 각각 따로 돌리는 것이 아니라, 두 성분을 사인과 코사인으로 섞어 새로운 방향을 만드는 계산이다. 원점에서의 거리는 다음처럼 회전 전후에 같다.

$$
x'^2+y'^2=x^2+y^2
$$

따라서 원점에서 같은 거리에 있던 점들은 회전한 뒤에도 같은 거리에 남는다. 정사각형이나 선처럼 방향을 가진 도형은 기울어 보이지만, 도형 내부의 길이와 원래 비율은 변하지 않는다. 이 성질 때문에 회전은 거리 함수의 값을 왜곡하지 않으며, 7.3의 비균일 확대처럼 거리의 의미를 별도로 보정할 필요가 없다.

```text
function rotate(p, angle):
    return (
        p.x * cos(angle) - p.y * sin(angle),
        p.x * sin(angle) + p.y * cos(angle)
    )
```

`angle = 0`이면 $\cos 0=1$, $\sin 0=0$이므로 함수는 원래 좌표를 그대로 반환한다. $\theta=\pi/2$이면 $(x,y)$는 $(-y,x)$가 된다. 간단한 점 하나를 이 값으로 직접 확인해 보면, 식의 성분 순서나 부호를 바꾸었을 때 회전 방향이 달라진다는 점을 이해하기 쉽다.

## 함수에서 회전하기

회전한 도형을 평가할 때는 입력 좌표를 반대 각도로 돌린다.

```text
local = position - center
local = rotate(local, -angle)
distanceValue = shape(local)
```

음의 각도를 쓰는 이유는 7.2의 이동에서 좌표를 반대 방향으로 옮긴 것과 같다. 화면에서 도형이 $\theta$만큼 회전해 보이려면, 현재 화면 위치가 회전 전 표준 도형의 어디에 해당하는지 $-\theta$만큼 되돌아가 찾는다. 즉 도형을 앞으로 돌리는 대신, 표본 좌표를 뒤로 돌려 표준 함수에 넣는다.

예를 들어 회전한 사각형의 모서리 근처에 있는 화면 위치를 검사한다고 하자. 그 위치를 반대 방향으로 돌리면, 원래 축에 정렬된 사각형의 대응 위치가 된다. 표준 사각형 함수는 그 로컬 위치만 평가하면 되므로, 함수 자체에 회전한 사각형을 위한 별도 조건을 추가할 필요가 없다.

회전은 중심을 기준으로 해야 하므로 먼저 중심을 빼고, 회전한 뒤 표준 도형 함수에 넣는다. 중심을 빼지 않으면 도형은 자기 자리에서 돌지 않고 원점을 중심으로 공전한다.

중심 $\mathbf{c}$를 기준으로 한 전체 좌표 계산은 다음처럼 쓸 수 있다.

$$
\mathbf{p}_{\text{local}}=
R(-\theta)(\mathbf{p}-\mathbf{c})
$$

여기서 먼저 $\mathbf{p}-\mathbf{c}$로 회전 중심을 원점으로 옮기고, 그다음 역회전을 적용한다. 도형 함수가 원점 중심의 표준 형태라고 가정하면 다시 중심을 더할 필요 없이 이 로컬 좌표를 바로 함수에 넣으면 된다. 반대로 회전한 점의 실제 월드 좌표를 직접 구해야 한다면 회전 뒤에 중심을 다시 더한다.

```text
# 표준 도형을 평가하는 로컬 좌표
local = rotate(position - center, -angle)
distanceValue = shape(local)

# 로컬 점을 회전해 월드 좌표로 보내는 경우
worldPoint = center + rotate(localPoint, angle)
```

## 실제 라이브러리

Canvas 2D의 `rotate()`, p5.js의 `rotate()`, SVG의 `rotate()`는 현재 좌표계를 회전한다. GLSL에서는 위 식이나 2×2 행렬을 사용한다.

```glsl
mat2 rotation2D(float a) {
    float c = cos(a);
    float s = sin(a);
    return mat2(c, -s, s, c);
}
```

## 각도의 단위와 회전 방향

수식과 GLSL의 삼각함수는 라디안을 사용한다. 한 바퀴는 $2\pi$이고, 90도는 $\pi/2$다. 도 단위 값을 받는 인터페이스에서는 변환을 한 번 명시적으로 수행한다.

$$
\theta_{rad}=\theta_{deg}\frac{\pi}{180}
$$

일반적인 수학 좌표계에서 양의 각도는 반시계 방향 회전이다. 화면 좌표계는 y축이 아래로 증가하는 경우가 많아 같은 식이 시계 방향처럼 보일 수 있다. 좌표계를 뒤집었는지, 각도 부호를 바꾸었는지를 한 규약으로 유지한다.

실제로 사용하는 환경이 각도를 도 단위로 받는지 라디안으로 받는지도 확인해야 한다. `90`을 그대로 삼각함수에 넣는 것은 보통 $90$라디안을 뜻하므로 의도한 직각 회전이 아니다. 반대로 p5.js처럼 각도 모드를 바꿀 수 있는 환경에서는 코드 전체가 어떤 단위를 쓰는지 통일하는 편이 좋다.

회전은 길이를 보존하므로 거리 함수와 궁합이 좋다. 원 자체보다 원 안의 줄무늬·노이즈 좌표를 회전시킬 때 효과가 더 분명하다.

원은 어느 방향으로 돌려도 같은 모습이므로, 원만 그린다면 회전의 결과가 보이지 않는다. 하지만 원 안의 줄무늬, 비대칭 마스크, 텍스트, 노이즈처럼 방향성을 가진 내용을 함께 회전하면 좌표 변환의 효과를 확인할 수 있다. 회전이 제대로 적용되었는지 점검할 때는 대칭적인 도형보다 방향이 분명한 삼각형이나 격자를 먼저 쓰는 편이 좋다.

## 이 절의 핵심

회전은 사인과 코사인으로 좌표 성분을 섞는 변환이다. 패턴 자체를 돌리는 대신 입력 좌표를 반대 방향으로 회전하면 같은 표준 함수로 회전한 형태를 만들 수 있다.
