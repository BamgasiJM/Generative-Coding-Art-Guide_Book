# 7.4 회전

2차원 회전은 원점을 기준으로 좌표를 각도 $\theta$만큼 돌리는 변환이다. 회전 전후에 점 사이의 거리가 유지되므로 원은 원으로 남고, 도형의 크기도 달라지지 않는다.

$$
\begin{aligned}
x'&=x\cos\theta-y\sin\theta \\
y'&=x\sin\theta+y\cos\theta
\end{aligned}
$$

회전한 좌표의 각 성분은 원래 좌표의 $x$, $y$를 사인과 코사인으로 조합해 얻는다. 회전 전후 원점까지의 거리가 같다는 것은 다음 등식으로 확인할 수 있다.

$$
x'^2+y'^2=x^2+y^2
$$

원점에서 같은 거리에 있던 점들은 회전한 뒤에도 그 거리를 유지한다. 정사각형이나 선처럼 방향이 드러나는 도형은 기울어지지만, 내부 길이와 비율은 그대로다. 회전은 거리 함수의 값도 보존하므로 7.3의 비균일 확대처럼 거리값을 별도로 보정할 필요가 없다.

```text
function rotate(p, angle):
    return (
        p.x * cos(angle) - p.y * sin(angle),
        p.x * sin(angle) + p.y * cos(angle)
    )
```

`angle = 0`이면 $\cos 0=1$, $\sin 0=0$이므로 함수는 입력 좌표를 그대로 반환한다. $\theta=\pi/2$이면 $(x,y)$는 $(-y,x)$로 옮겨진다. 예를 들어 $(1,0)$은 $(0,1)$이 된다. 이 대응으로 성분의 순서와 부호가 회전 방향을 어떻게 정하는지 확인할 수 있다.

## 함수에서 회전하기

회전한 도형을 평가할 때는 입력 좌표를 반대 각도로 돌린다.

```text
local = position - center
local = rotate(local, -angle)
distanceValue = shape(local)
```

음의 각도를 쓰는 이유는 7.2에서 이동된 도형을 평가할 때 샘플 좌표를 반대 방향으로 옮긴 것과 같다. 화면에서 도형이 $\theta$만큼 회전해 보이게 하려면, 현재 화면 위치에 해당하는 표준 도형의 좌표를 $-\theta$만큼 되돌려 구한다. 도형 함수를 직접 회전시키는 대신 표본 좌표를 역회전해 표준 함수에 넣는 방식이다.

예를 들어 회전한 사각형의 모서리 근처에 있는 화면 위치를 검사한다고 하자. 그 좌표를 반대 방향으로 돌리면 회전 전 사각형의 내부 좌표를 얻는다. 표준 사각형 함수는 이 로컬 좌표만 평가하면 되므로 회전한 형태를 위한 별도 도형 함수를 만들 필요가 없다.

원점이 아닌 점을 중심으로 회전하려면 먼저 그 중심을 빼서 원점으로 옮긴 뒤 회전한다. 중심을 빼지 않으면 도형은 제자리에서 방향만 바뀌는 대신 원점을 중심으로 궤도를 그리며 돈다.

중심 $\mathbf{c}$를 기준으로 한 전체 좌표 계산은 다음처럼 쓸 수 있다.

$$
\mathbf{p}_{\text{local}}=
R(-\theta)(\mathbf{p}-\mathbf{c})
$$

먼저 $\mathbf{p}-\mathbf{c}$로 회전 중심을 원점으로 옮긴 뒤 역회전한다. 도형 함수가 원점 중심의 표준 형태라면 이 로컬 좌표를 그대로 함수에 넣는다. 회전한 점의 월드 좌표를 구할 때는 회전한 뒤 중심 $\mathbf{c}$를 다시 더한다.

```text
# 표준 도형을 평가하는 로컬 좌표
local = rotate(position - center, -angle)
distanceValue = shape(local)

# 로컬 점을 회전해 월드 좌표로 보내는 경우
worldPoint = center + rotate(localPoint, angle)
```

## 실제 라이브러리

Canvas 2D와 p5.js의 `rotate()`는 현재 좌표계에 회전을 적용하고, SVG에서는 `transform`의 `rotate()`로 요소를 회전한다. GLSL에서는 위 식이나 2×2 행렬로 좌표를 직접 계산한다.

```glsl
mat2 rotation2D(float a) {
    float c = cos(a);
    float s = sin(a);
    return mat2(c, -s, s, c);
}
```

GLSL의 `mat2` 생성자는 열을 차례로 받는다. 따라서 `mat2(c, -s, s, c)`를 열 벡터에 곱하면 일반적인 수학 좌표계에서 각도 $-a$의 회전이 된다. 표준 도형을 평가할 때 원하는 회전의 역변환으로 쓸 수 있다. 점을 직접 $+a$만큼 회전하려면 두 비대각 성분의 부호를 바꿔야 한다.

## 각도의 단위와 회전 방향

수학식과 GLSL의 삼각함수는 라디안을 사용한다. 한 바퀴는 $2\pi$이고, 90도는 $\pi/2$다. Canvas 2D의 `rotate()`도 라디안을 받는다. p5.js는 `angleMode()` 설정을 따르며 기본값은 라디안이고, SVG의 `rotate()` 값은 도 단위다. 도 단위 값을 받는 인터페이스에서 라디안을 사용하려면 변환을 명시한다.

$$
\theta_{rad}=\theta_{deg}\frac{\pi}{180}
$$

일반적인 수학 좌표계에서는 양의 각도가 반시계 방향을 뜻한다. 화면 좌표계는 $y$축이 아래로 증가하는 경우가 많으므로, 같은 식을 적용해도 화면에서는 시계 방향으로 보일 수 있다. 좌표계의 축 방향과 각도 부호를 함께 확인하고 한 규약으로 일관되게 사용한다.

삼각함수에 `90`을 그대로 넣으면 보통 90도가 아니라 $90$라디안으로 해석된다. p5.js에서 각도 모드를 바꾸었다면 다른 삼각함수 계산도 같은 단위를 따르는지 확인한다.

회전은 길이를 보존하므로 거리 함수의 도형을 회전할 때 별도의 거리 보정이 필요하지 않다. 원처럼 회전 대칭인 형태보다 줄무늬나 노이즈처럼 방향성이 있는 좌표를 회전할 때 효과가 눈에 잘 띈다.

원은 어느 방향으로 회전해도 모양이 같아 회전 결과를 알아보기 어렵다. 원 안의 줄무늬, 비대칭 마스크, 텍스트, 노이즈처럼 방향이 있는 요소를 함께 회전하면 변화를 확인할 수 있다. 회전 방향을 점검할 때는 대칭 도형보다 방향이 뚜렷한 삼각형이나 격자를 사용한다.

## 이 절의 핵심

회전은 사인과 코사인으로 좌표 성분을 조합하며 길이와 거리를 보존한다. 함수로 회전한 형태를 평가할 때는 중심을 원점으로 옮긴 뒤 입력 좌표를 반대 각도로 돌려 같은 표준 함수를 사용한다. 회전 방향을 해석할 때는 각도 단위와 좌표계의 축 방향도 함께 확인한다.
