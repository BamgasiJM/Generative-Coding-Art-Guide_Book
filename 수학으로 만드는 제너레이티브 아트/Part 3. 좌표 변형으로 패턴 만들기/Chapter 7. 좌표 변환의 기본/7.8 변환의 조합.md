# 7.8 변환의 조합

실제 패턴은 하나의 변환보다 여러 변환을 조합해 만드는 경우가 많다. 예를 들어 표준 원을 확대하고 회전한 뒤 화면의 특정 위치로 이동할 수 있다. 변환을 단계별로 작성하면 각 단계의 역할을 확인하기 쉽다.

```text
local = position
local = local - translation
local = rotate(local, -rotation)
local = local / scale
value = basePattern(local)
```

위 코드는 화면 위치를 표준 패턴의 로컬 좌표로 되돌리는 역변환 흐름이다.

## 지역 변환과 전역 변환

전역 변환은 장면 전체의 좌표계에 적용되고, 지역 변환은 특정 도형이나 패턴에만 적용된다. 같은 반복 무늬 안에서 각 셀을 독립적으로 회전시키려면 먼저 셀 내부 좌표를 만들고 지역 변환을 적용해야 한다.

```text
cellLocal = tileLocalPosition(position)
rotatedCell = rotate(cellLocal, cellAngle)
value = cellPattern(rotatedCell)
```

전역 좌표에 회전을 적용하면 전체 타일 배열이 함께 회전한다. 어느 단계에 변환을 적용하는지가 패턴의 구조를 결정한다.

## 변환 파라미터의 관계

변환을 조합할 때는 크기·회전·이동이 서로 어떤 기준을 공유하는지 정한다. 예를 들어 원을 크기 $s$로 확대한 뒤 $t$만큼 이동할 때, 이동값이 로컬 단위인지 화면 단위인지에 따라 결과가 달라진다.

```text
// 이동이 화면 단위
world = rotate(local * scale, angle) + worldOffset

// 이동이 로컬 단위
world = rotate((local + localOffset) * scale, angle)
```

변수 이름에 `local`, `world`, `screen` 같은 공간 정보를 넣으면 단위 혼동을 줄일 수 있다.

## 조합을 디버깅하는 순서

여러 변환이 한꺼번에 들어가면 결과만 보고 어느 단계가 문제인지 판단하기 어렵다. 표준 도형 하나와 x·y축 방향이 드러나는 비대칭 표식을 준비하고, 이동·회전·확대를 한 단계씩 활성화한다. 중간 좌표를 격자나 색으로 시각화하면 변환이 기대한 공간에서 일어나는지 확인할 수 있다.

반복 좌표와 변환의 순서도 구별한다. `tile(rotate(p))`는 전체 좌표계를 회전한 뒤 타일로 자르는 방식이고, `rotate(tile(p))`는 각 타일 내부를 독립적으로 회전하는 방식이다. 비슷한 코드 길이에도 대칭과 이음새는 크게 달라진다.

## 이 절의 핵심

변환을 조합할 때는 각 단계를 분리하고, 전역 변환과 지역 변환의 적용 위치를 구분해야 한다. 같은 변환이라도 반복 좌표 전후 어느 단계에 적용하는지에 따라 패턴 전체 또는 개별 셀이 달라진다.
