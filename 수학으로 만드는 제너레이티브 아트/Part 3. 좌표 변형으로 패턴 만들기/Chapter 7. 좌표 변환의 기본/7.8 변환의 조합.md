# 7.8 변환의 조합

실제 패턴은 여러 변환을 조합해 만든다. 예를 들어 표준 원을 확대하고 회전한 뒤 화면의 특정 위치에 둘 수 있다. 도형의 점을 옮기는 순방향 변환과 함수 평가용 샘플 좌표를 되돌리는 역변환을 구분하면, 각 단계가 어느 좌표에 작용하는지 명확해진다.

```text
local = position
local = local - translation
local = rotate(local, -rotation)
local = local / scale
value = basePattern(local)
```

위 코드에서 `position`은 화면 또는 월드 공간의 샘플 위치이고, `translation`, `rotation`, `scale`은 도형에 적용한 이동·회전·균일 배율이다. 코드는 샘플 좌표에서 이동을 되돌리고, 역회전하고, 배율을 나눠 표준 패턴의 로컬 좌표를 구한다.

순방향에서는 표준 패턴을 확대하고 회전한 뒤 화면의 위치로 옮긴다. 함수 평가에서는 각 화면 위치가 표준 패턴의 어디에 해당하는지 찾아야 하므로 순방향의 마지막 단계부터 되돌린다. 따라서 `translation`을 빼고, 반대 방향으로 회전하고, 배율로 나눈다. 이는 7.7에서 다룬 역순 원칙의 적용이다.

## 지역 변환과 전역 변환

전역 변환은 장면 전체의 좌표계에 적용되고, 지역 변환은 특정 도형이나 패턴에만 적용된다. 반복 무늬에서 셀마다 따로 회전하려면 먼저 위치를 셀 내부 좌표로 바꾼 뒤 그 좌표에 변환을 적용한다.

```text
cellLocal = tileLocalPosition(position)
rotatedCell = rotate(cellLocal, cellAngle)
value = cellPattern(rotatedCell)
```

여기서 `tileLocalPosition`은 각 샘플 위치를 해당 타일의 중심 기준 좌표로 바꾼다고 가정한다. 이 좌표에 회전을 적용하면 타일 배열은 그대로 두고 각 셀의 패턴만 회전한다. 다만 코드는 샘플 좌표를 `cellAngle`만큼 회전하므로, 화면에 보이는 패턴의 회전 방향은 반대다. 셀 안의 패턴을 화면에서 양의 `cellAngle`만큼 돌리려면 샘플 좌표에는 음의 각도를 적용한다.

반대로 타일로 나누기 전에 `position`을 회전하면 전체 타일 배열과 경계의 방향이 바뀐다. 두 방식은 회전을 적용하는 좌표 공간이 다르므로 반복 방향과 이음새도 달라진다. 이때도 샘플 좌표를 회전하는 코드와 화면 도형을 회전하는 순방향 변환의 각도 부호가 반대라는 점을 고려한다.

## 변환 파라미터의 관계

변환을 조합할 때는 크기·회전·이동이 어느 좌표 공간의 값인지 구분한다. 원을 크기 $s$로 확대한 뒤 $t$만큼 이동하더라도, 이동값이 로컬 단위인지 월드 단위인지에 따라 화면에서의 위치가 달라진다.

```text
// 이동이 화면 단위
world = rotate(local * scale, angle) + worldOffset

// 이동이 로컬 단위
world = rotate((local + localOffset) * scale, angle)
```

두 식은 로컬 좌표의 점을 월드 좌표로 보내는 순방향 변환이다. 첫 번째 식에서는 확대와 회전 뒤에 `worldOffset`을 더하므로 이동량은 출력 좌표 공간의 단위로 유지된다. 두 번째 식은 `localOffset`을 확대와 회전 전에 더하므로 그 오프셋도 함께 확대되고 회전한다. 변수 이름에 `local`, `world`, `screen`처럼 좌표 공간을 표시하면 어떤 변환이 그 값을 바꾸는지 파악하기 쉽다.

`offset`처럼 범위가 불분명한 이름만 쓰면 값이 확대 전 로컬 단위인지, 확대 뒤 월드 단위인지 알기 어렵다. 같은 숫자도 어느 단계에서 더하는지에 따라 화면에서 차지하는 거리가 달라지므로, 좌표 공간을 변수 이름과 계산 위치에 함께 드러낸다.

## 조합을 디버깅하는 순서

여러 변환이 한꺼번에 들어가면 결과만으로 어느 단계가 잘못됐는지 찾기 어렵다. 표준 도형과 x·y축 방향이 드러나는 비대칭 표식을 준비하고, 이동·회전·확대를 한 단계씩 적용한다. 중간 좌표를 격자나 색으로 표시하면 변환이 의도한 공간에서 일어나는지 확인할 수 있다.

반복 좌표와 변환의 순서도 구분한다. `tile(rotate(p))`는 샘플 좌표를 회전한 뒤 타일 좌표를 구하므로 반복 배열의 방향이 바뀐다. `rotate(tile(p))`는 타일 내부 좌표를 구한 뒤 회전하므로 배열은 유지되고 각 셀의 내용이 바뀐다. 두 경우 모두 회전은 샘플 좌표에 적용되므로 화면에 보이는 회전 방향은 사용한 각도와 반대다. 코드 모양이 비슷해도 대칭과 이음새는 달라진다.

조합을 처음 만들 때는 완성된 패턴보다 원점에서 벗어난 점이나 방향이 있는 화살표로 각 단계를 확인한다. 대칭적인 원이나 균일한 노이즈만으로는 회전 순서와 기준점의 차이가 드러나지 않을 수 있다.

## 이 절의 핵심

변환을 조합할 때는 각 단계를 분리하고, 전역 좌표와 로컬 좌표 중 어디에 적용하는지 확인한다. 같은 연산도 반복 좌표 전후 어느 단계에 두는지에 따라 타일 배열 전체 또는 각 셀의 내용이 달라진다. 함수 평가용 샘플 좌표의 변환은 보이는 도형의 순방향 변환과 역관계이므로 회전 각도와 적용 순서도 뒤집어 해석한다.
