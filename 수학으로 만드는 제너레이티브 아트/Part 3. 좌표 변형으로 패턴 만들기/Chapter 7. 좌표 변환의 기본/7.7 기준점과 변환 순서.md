# 7.7 기준점과 변환 순서

같은 이동, 확대, 회전도 어느 점을 기준으로 적용하고 어떤 순서로 적용하는가에 따라 결과가 달라진다. 좌표 변환에서 예상하지 못한 공전이나 위치 변화가 생기는 이유는 대개 기준점 또는 순서에 있다.

## 기준점 바꾸기

원점이 아닌 점 $\mathbf{c}$를 기준으로 회전하려면 세 단계를 사용한다.

$$
\mathbf{p}'=\mathbf{c}+R(\mathbf{p}-\mathbf{c})
$$

```text
local = position - pivot
rotated = rotate(local, angle)
result = rotated + pivot
```

확대도 같은 구조를 쓴다.

$$
\mathbf{p}'=\mathbf{c}+S(\mathbf{p}-\mathbf{c})
$$

도형의 중심, 선분의 끝점, 화면 중앙 등 작업의 관계에 맞는 기준점을 선택한다.

## 순서는 교환되지 않는다

일반적으로 이동 후 회전과 회전 후 이동은 다르다.

$$
R(T(\mathbf{p}))\ne T(R(\mathbf{p}))
$$

먼저 이동하고 원점 기준으로 회전하면 이동 벡터까지 함께 돌아간다. 먼저 회전하고 이동하면 도형의 방향만 바뀐 뒤 지정한 위치에 놓인다.

```text
orbiting = rotate(position + offset, angle)
oriented = rotate(position, angle) + offset
```

첫 번째는 공전에, 두 번째는 위치가 고정된 회전에 해당한다.

## 역변환 순서

함수 평가에서 순방향 변환의 역변환을 적용할 때는 순서도 반대가 된다. 도형에 순서대로 확대, 회전, 이동을 적용했다면, 현재 샘플 좌표에는 이동을 되돌리고, 회전을 되돌리고, 확대를 되돌린다.

```text
local = position - translation
local = rotate(local, -angle)
local = local / scale
value = shape(local)
```

이 순서를 지키면 표준 도형 함수는 로컬 공간에서 변하지 않는다.

## 이 절의 핵심

변환은 기준점을 중심으로 적용해야 하며, 순서를 바꾸면 일반적으로 결과도 바뀐다. 함수 평가에서는 순방향 변환의 역변환을 역순으로 적용한다.
