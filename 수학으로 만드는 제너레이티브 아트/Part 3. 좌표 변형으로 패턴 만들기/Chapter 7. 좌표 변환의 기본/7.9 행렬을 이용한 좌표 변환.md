# 7.9 행렬을 이용한 좌표 변환

행렬은 여러 좌표 변환을 하나의 수학적 객체로 표현하고 조합하는 방법이다. 2차원 벡터에 2×2 행렬을 곱하면 회전, 확대, 반사, 기울이기 같은 선형 변환을 만들 수 있다.

$$
\begin{bmatrix}x'\\y'\end{bmatrix}
=
\begin{bmatrix}a&b\\c&d\end{bmatrix}
\begin{bmatrix}x\\y\end{bmatrix}
$$

## 회전 행렬

각도 $\theta$의 회전 행렬은 다음과 같다.

$$
R(\theta)=
\begin{bmatrix}
\cos\theta&-\sin\theta\\
\sin\theta&\cos\theta
\end{bmatrix}
$$

GLSL에서는 `mat2`로 표현할 수 있다.

```glsl
mat2 rotation2D(float a) {
    float c = cos(a);
    float s = sin(a);
    return mat2(c, -s, s, c);
}
```

## 이동과 동차 좌표

이동은 단순한 2×2 행렬 곱으로 표현할 수 없다. 이를 행렬 안에 포함하려면 좌표에 세 번째 성분 1을 추가한 동차 좌표와 3×3 행렬을 사용한다.

$$
\begin{bmatrix}x'\\y'\\1\end{bmatrix}
=
\begin{bmatrix}
a&b&t_x\\
c&d&t_y\\
0&0&1
\end{bmatrix}
\begin{bmatrix}x\\y\\1\end{bmatrix}
$$

3차원에서는 같은 이유로 4×4 행렬과 $(x,y,z,1)$을 사용한다.

## 행렬 곱과 순서

변환 행렬을 곱하면 여러 변환을 하나의 행렬로 합칠 수 있다.

$$
M=T R S
$$

벡터를 어느 쪽에 곱하는지에 따라 표기와 코드 순서는 달라질 수 있다. 사용하는 라이브러리의 행렬·벡터 관례를 확인해야 한다. 중요한 것은 실제 적용 순서가 유지되는지다.

## 실제 라이브러리

Canvas 2D의 변환 상태, SVG의 `transform`, WebGL·Three.js의 모델 행렬, Blender의 오브젝트 변환은 모두 행렬 기반으로 동작한다. 고수준 API가 행렬을 숨기더라도, 기준점과 순서의 원리는 같다.

## Chapter 7의 마무리
