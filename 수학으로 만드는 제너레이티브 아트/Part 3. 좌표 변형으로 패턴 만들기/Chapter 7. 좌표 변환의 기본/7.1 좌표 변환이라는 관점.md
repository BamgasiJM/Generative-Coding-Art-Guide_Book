# 7.1 좌표 변환이라는 관점

도형 함수나 패턴 함수를 바꾸지 않고도 결과를 이동, 회전, 확대할 수 있다. 방법은 함수에 들어가는 좌표를 먼저 바꾸는 것이다. 이를 좌표 변환이라고 한다.

```text
transformedPosition = transform(position)
value = pattern(transformedPosition)
```

이 구조에서 `pattern`은 항상 원점 근처의 같은 형태를 정의한다. 위치, 방향, 크기는 `transform`이 결정한다. 제너레이티브 아트에서는 결과 이미지를 변형하는 것보다 입력 좌표를 변형하는 편이 함수의 구조를 재사용하기 쉽다.

## 순방향과 역방향

객체의 점을 새 위치로 보내는 순방향 변환은 다음처럼 생각할 수 있다.

$$
\mathbf{p}'=T(\mathbf{p})
$$

그러나 셰이더나 거리 함수에서는 현재 화면 위치가 변환된 도형 안에 있는지 계산해야 한다. 이때 현재 위치를 도형의 원래 좌표로 되돌리는 역변환을 사용한다.

$$
\mathbf{p}=T^{-1}(\mathbf{p}')
$$

```text
localPosition = inverseTransform(worldPosition)
distanceValue = standardShape(localPosition)
```

도형을 오른쪽으로 이동해 보이게 하려면 샘플 좌표를 왼쪽으로 옮겨 표준 도형 함수에 넣는다. 처음에는 직관에 반해 보이지만, 각 화면 위치에서 “이 위치가 이동된 도형의 어느 로컬 위치에 해당하는가”를 묻는 방식이다.

## 변환의 기본 유형

| 변환 | 좌표에서 하는 일 | 시각적 결과 |
| --- | --- | --- |
| 이동 | 일정한 벡터를 더하거나 뺌 | 위치 변경 |
| 확대·축소 | 성분에 배율을 곱하거나 나눔 | 크기 변경 |
| 회전 | 좌표축을 각도만큼 돌림 | 방향 변경 |
| 반사 | 한 축의 부호를 바꿈 | 거울 대칭 |
| 기울이기 | 한 성분에 다른 성분을 더함 | 평행사변형 변형 |

여러 변환은 차례로 적용할 수 있다. 다만 일반적으로 순서를 바꾸면 결과가 달라진다.

## 실제 라이브러리의 대응

Canvas 2D와 p5.js는 변환 상태를 쌓아 도형 그리기 명령에 적용한다. SVG는 `transform` 속성으로, CSS는 `transform` 속성으로 비슷한 기능을 제공한다.

```javascript
// Canvas 2D 예제
context.save();
context.translate(centerX, centerY);
context.rotate(angle);
context.scale(scaleX, scaleY);
drawLocalShape(context);
context.restore();
```

셰이더에서는 보통 좌표를 직접 계산하거나 행렬을 곱한다. 이 장에서는 각 변환을 먼저 성분 단위 식으로 이해하고, 마지막 절에서 행렬로 묶는다.

## 이 절의 핵심

좌표 변환은 패턴 함수를 바꾸지 않고 그 함수에 들어가는 좌표를 바꾸는 방법이다. 이 관점은 같은 도형을 여러 위치와 크기와 방향으로 재사용하게 하며, 반복·대칭·왜곡 패턴의 기반이 된다.
