# 7.1 좌표 변환이라는 관점

도형 함수나 패턴 함수를 다시 정의하지 않아도 결과의 위치와 방향, 크기를 바꿀 수 있다. 함수에 넣을 좌표를 변환하면 된다. 입력 좌표를 다른 좌표에 대응시키는 연산을 좌표 변환이라고 한다.

```text
transformedPosition = transform(position)
value = pattern(transformedPosition)
```

이 구조에서 `pattern`은 원점 근처의 표준 형태를 정의하고, `transform`은 각 위치에서 함수를 평가할 좌표를 결정한다. 이 좌표를 조정하면 표준 형태를 여러 위치와 방향, 크기로 배치할 수 있다. 이미 계산한 픽셀을 옮기는 대신 각 위치에서 원래 함수를 평가하므로, 함수의 정의를 여러 결과에 재사용하기 쉽다.

## 순방향과 역방향

객체의 점을 새 위치로 보내는 순방향 변환은 다음처럼 나타낸다. $\mathbf{p}$는 변환 전 좌표이고, $\mathbf{p}'$는 변환 뒤 좌표다.

$$
\mathbf{p}'=T(\mathbf{p})
$$

반면 셰이더나 거리 함수는 화면의 각 위치에서 도형 함수의 값을 평가한다. 이때는 변환된 좌표에서 출발해 원래 함수가 정의된 좌표를 찾아야 하므로 역변환을 사용한다. 역변환은 변환을 되돌릴 수 있을 때 정의된다. 예를 들어 한 축의 배율이 0이면 그 축의 좌표 정보가 사라져 일반적인 역변환을 할 수 없다.

$$
\mathbf{p}=T^{-1}(\mathbf{p}')
$$

```text
localPosition = inverseTransform(worldPosition)
distanceValue = standardShape(localPosition)
```

도형을 오른쪽으로 이동한 결과를 평가할 때는 각 화면 위치에서 이동량을 뺀 좌표를 표준 도형 함수에 넣는다. 이는 각 위치가 옮기기 전 도형의 기준점을 원점으로 둔 좌표계에서 어디에 해당하는지 찾는 과정이다. 이동에 적용하는 구체적인 식은 다음 절에서 다룬다.

## 변환의 기본 유형

| 변환 | 좌표에서 하는 일 | 시각적 결과 |
| --- | --- | --- |
| 이동 | 일정한 벡터를 더하거나 뺌 | 위치 변경 |
| 확대·축소 | 성분에 배율을 곱하거나 나눔 | 크기 변경 |
| 회전 | 좌표축을 각도만큼 돌림 | 방향 변경 |
| 반사 | 한 축의 부호를 바꿈 | 거울 대칭 |
| 기울이기 | 한 성분에 다른 성분을 더함 | 평행사변형 변형 |

여러 변환은 차례로 적용할 수 있지만, 일반적으로 순서를 바꾸면 결과가 달라진다. 예를 들어 이동한 뒤 회전하면 이동 벡터도 회전하고, 회전한 뒤 이동하면 회전된 도형을 별도로 옮긴다.

## 실제 라이브러리의 대응

Canvas 2D와 p5.js에서는 변환 상태를 설정한 뒤 도형 그리기 명령을 실행한다. SVG와 CSS도 `transform` 속성으로 좌표 변환을 지정한다. 이 API들은 도형 좌표를 일일이 다시 계산하는 대신 변환 적용을 관리해 준다.

```javascript
// Canvas 2D 예제
context.save();
context.translate(centerX, centerY);
context.rotate(angle);
context.scale(scaleX, scaleY);
drawLocalShape(context);
context.restore();
```

셰이더에서는 보통 좌표를 직접 계산하거나 행렬을 곱한다. 이 장에서는 각 변환을 먼저 성분 단위 식으로 이해하고, 마지막 절에서 행렬로 묶는다.

## 이 절의 핵심

좌표 변환은 패턴 함수의 정의를 유지하면서 함수에 넣을 좌표를 바꾸는 방법이다. 같은 표준 도형이나 패턴을 여러 위치와 크기, 방향에 적용할 수 있어 반복·대칭·왜곡 패턴의 기반이 된다.
