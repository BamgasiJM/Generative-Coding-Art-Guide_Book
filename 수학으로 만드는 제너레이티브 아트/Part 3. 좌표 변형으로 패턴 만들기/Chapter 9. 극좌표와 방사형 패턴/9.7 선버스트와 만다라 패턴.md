# 9.7 선버스트와 만다라 패턴

선버스트와 만다라는 중심을 공유하는 반복 구조다. 각도를 일정한 개수의 구간으로 나누고, 각 구간 안에 같은 또는 변형된 패턴을 배치하면 만들 수 있다.

격자 패턴이 가로와 세로 방향의 반복으로 질서를 만든다면, 이 패턴들은 중심을 기준으로 한 회전 방향의 반복으로 질서를 만든다. 화면의 모든 점은 하나의 반지름과 하나의 각도를 가지므로, 각도에 반복을 주면 중심에서 바깥으로 이어지는 구조가 자연스럽게 생긴다. 여기에 반지름에 따른 선, 띠, 색 변화를 더하면 단순한 광선에서 여러 겹의 만다라까지 같은 관점으로 다룰 수 있다.

## 선버스트

각도에 높은 주파수의 임계값을 적용하면 중심에서 뻗는 광선을 만들 수 있다.

```glsl
float wave = 0.5 + 0.5 * sin(angle * rayCount);
float rays = smoothstep(threshold, threshold + softness, wave);
```

`sin(angle * rayCount)`는 각도를 한 바퀴 도는 동안 반복해서 오르내린다. `rayCount`를 늘리면 한 바퀴 안의 파동 수가 늘어나고, 밝은 구간과 어두운 구간이 번갈아 나타난다. 임계값을 넘는 부분만 남기면 밝은 구간은 광선이 되고, 나머지는 광선 사이의 빈 공간이 된다. 이 식의 사인파는 한 주기 안에서 양수와 음수의 영역을 모두 가지므로, `rayCount`를 바꿀 때 화면에서 보이는 광선의 수는 원하는 인상에 맞게 직접 확인하는 편이 좋다.

`threshold`를 높이면 파동의 꼭대기 부근만 남아 광선이 가늘어지고, 낮추면 밝은 영역이 넓어진다. `softness`는 `smoothstep`이 0에서 1로 넘어가는 폭이다. 값이 아주 작으면 날카로운 경계의 광선이 되고, 값을 키우면 가장자리가 부드럽게 번진다. 광선의 개수, 폭, 경계의 부드러움은 서로 다른 역할을 하므로 한 값으로 모두 해결하려 하기보다 분리해 두는 편이 조절하기 쉽다.

반지름 기반 감쇠를 곱하면 중심에서 밝고 바깥으로 약해지는 광선이 된다.

```text
sunburst = rays * exp(-decay * radius)
```

`radius`가 커질수록 지수 항은 0에 가까워진다. 따라서 `decay`가 클수록 광선은 중심에 모여 보이고, 작을수록 화면의 바깥까지 오래 유지된다. 이 감쇠는 광선의 방향을 바꾸지 않는다. 각도에서 만든 밝고 어두운 구분은 그대로 두고, 반지름 방향의 밝기만 조절하는 것이다. 감쇠 대신 일정한 값을 사용하면 보다 평면적인 방사형 줄무늬가 되고, 다른 반지름 함수와 곱하면 고리와 광선을 함께 가진 패턴으로 이어진다.

## 만다라

만다라는 회전 대칭, 반사 대칭, 반지름 방향 반복을 함께 사용한다. 먼저 각도를 한 섹터로 접고, 그 섹터 안에 선·원·SDF 패턴을 정의한다.

```text
sectorAngle = 2 * PI / sectorCount
foldedAngle = foldAngle(angle, sectorAngle)
local = polarToCartesian(radius, foldedAngle)
value = motif(local)
```

`sectorCount`가 $n$이면 한 섹터의 폭은 $2\pi/n$이다. 원래 각도가 어느 섹터에 있었든 `foldedAngle`은 같은 작은 각도 범위로 돌아온다. 그러므로 `motif`는 화면 전체를 알 필요 없이 한 섹터 안의 국소 좌표만 받으면 된다. 각 섹터에 도형을 실제로 여러 번 그려 넣는 대신, 화면의 각 점이 같은 모티프 좌표를 참조하게 만드는 방식이다.

접기 전에는 섹터마다 모티프의 방향이 회전한 상태로 반복된다. 여기에 섹터의 중앙선을 기준으로 각도를 반사해 접으면, 한 섹터의 왼쪽과 오른쪽도 서로 거울 대칭이 된다. 이 두 단계는 각각 회전 대칭과 반사 대칭을 만든다. `foldAngle`의 구체적인 구현은 Chapter 10에서 다루지만, 여기서 중요한 점은 반복과 반사가 도형을 복제하는 명령이 아니라 좌표를 다시 해석하는 규칙이라는 점이다.

`local = polarToCartesian(radius, foldedAngle)`은 접힌 극좌표를 다시 평면 좌표로 바꾸는 단계다. 그 뒤의 `motif(local)`에는 작은 선, 원호, 거리 함수로 만든 도형처럼 평소의 2차원 패턴 함수를 넣을 수 있다. 반지름을 그대로 쓰면 같은 모티프가 중심에서 바깥까지 이어지고, 반지름을 반복하거나 구간별로 나누면 동심원 방향의 층도 생긴다. 이때 중심 부근에서는 같은 각도 폭이 매우 짧은 호 길이를 가지므로, 섹터 수가 많거나 모티프가 너무 가늘면 무늬가 과하게 빽빽해 보일 수 있다.

## 복잡도를 관리하는 방법

방사형 패턴에서는 반복 수, 반지름별 모티프 크기, 선 두께, 색상 위상을 한꺼번에 바꾸기보다 하나씩 분리한다. 특히 섹터 수를 올리면 같은 선 두께도 더 조밀하게 보이므로, 반복 수를 먼저 정하고 그에 맞춰 모티프의 폭을 조정하는 순서가 안정적이다.

| 파라미터 | 주된 효과 |
| --- | --- |
| 섹터 수 | 회전 대칭 횟수와 각도 방향의 밀도 |
| 반지름 반복 수 | 동심 구조의 개수와 반지름 방향의 밀도 |
| 모티프 크기 | 각 섹터 안에서 차지하는 면적과 중심·가장자리의 무게 |
| 선 두께 | 대칭 경계와 세부 무늬가 읽히는 정도 |
| 위상 | 패턴의 시작 각도, 전체 회전, 시간에 따른 이동 |

모든 값을 동시에 복잡하게 만들 필요는 없다. 먼저 섹터 하나에서 모티프가 잘 읽히는지 확인하고, 그다음 섹터 수를 늘려 전체 대칭을 만든다. 마지막으로 반지름 방향의 반복이나 색 위상을 더하면, 어떤 값이 형태의 변화를 만들었는지 잃지 않으면서 복잡도를 쌓을 수 있다.

## 이 절의 핵심

선버스트와 만다라는 각도 방향의 반복을 기반으로 한다. 각도를 섹터로 나누고 접으면 하나의 모티프 함수로 복잡한 방사형 대칭을 만들 수 있다.
