# 9.7 선버스트와 만다라 패턴

선버스트와 만다라는 중심을 공유하는 반복 구조다. 각도를 일정한 개수의 구간으로 나누고, 각 구간 안에 같은 또는 변형된 패턴을 배치하면 만들 수 있다.

## 선버스트

각도에 높은 주파수의 임계값을 적용하면 중심에서 뻗는 광선을 만들 수 있다.

```glsl
float wave = 0.5 + 0.5 * sin(angle * rayCount);
float rays = smoothstep(threshold, threshold + softness, wave);
```

반지름 기반 감쇠를 곱하면 중심에서 밝고 바깥으로 약해지는 광선이 된다.

```text
sunburst = rays * exp(-decay * radius)
```

## 만다라

만다라는 회전 대칭, 반사 대칭, 반지름 방향 반복을 함께 사용한다. 먼저 각도를 한 섹터로 접고, 그 섹터 안에 선·원·SDF 패턴을 정의한다.

```text
sectorAngle = 2 * PI / sectorCount
foldedAngle = foldAngle(angle, sectorAngle)
local = polarToCartesian(radius, foldedAngle)
value = motif(local)
```

`foldAngle`의 구체적인 구현은 Chapter 10에서 다룬다. 중요한 점은 하나의 모티프를 중심 주위에 복사하는 대신, 각도를 반복·반사해 같은 함수 입력을 만들 수 있다는 점이다.

## 복잡도를 관리하는 방법

방사형 패턴에서는 반복 수, 반지름별 모티프 크기, 선 두께, 색상 위상을 한꺼번에 바꾸기보다 하나씩 분리한다.

| 파라미터 | 주된 효과 |
| --- | --- |
| 섹터 수 | 회전 대칭 횟수 |
| 반지름 반복 수 | 동심 구조의 밀도 |
| 모티프 크기 | 중심과 가장자리의 무게 |
| 위상 | 전체 회전과 시간 변화 |

## 이 절의 핵심

선버스트와 만다라는 각도 방향의 반복을 기반으로 한다. 각도를 섹터로 나누고 접으면 하나의 모티프 함수로 복잡한 방사형 대칭을 만들 수 있다.
