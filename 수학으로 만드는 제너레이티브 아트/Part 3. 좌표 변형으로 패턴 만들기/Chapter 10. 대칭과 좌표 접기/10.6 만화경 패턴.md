# 10.6 만화경 패턴

만화경 패턴은 회전 대칭과 거울 대칭을 결합한 구조다. 중심 기준 좌표를 극좌표로 바꾸고, 각도를 한 섹터 안으로 반복·접은 뒤, 그 접힌 좌표에 모티프 함수를 적용한다.

```text
local = position - center
radius = length(local)
angle = atan2(local.y, local.x)

sectorAngle = 2 * PI / sectorCount
angle = mod(angle + sectorAngle * 0.5, sectorAngle) - sectorAngle * 0.5
angle = abs(angle)

folded = radius * (cos(angle), sin(angle))
value = motif(folded)
```

## 모티프 선택

접힌 섹터 안의 모티프는 점, 선, 원, SDF, 노이즈, 줄무늬 등 어떤 함수도 될 수 있다.

```text
motif = sdCircle(folded, motifCenter, motifRadius)
motif += stripePattern(folded)
```

모티프가 섹터 경계에 걸리면 인접 섹터에서 거울상으로 자연스럽게 이어진다. 대칭축이 눈에 띄는 것은 이음새가 아니라 패턴 설계의 일부가 된다.

## 파라미터

| 파라미터 | 역할 |
| --- | --- |
| `sectorCount` | 회전·반사 대칭의 횟수 |
| `motifCenter` | 섹터 내부 모티프의 위치 |
| `motifRadius` | 모티프의 크기 |
| `rotationOffset` | 전체 패턴의 회전 |
| `radialScale` | 중심과 가장자리의 밀도 |

섹터 수가 많아질수록 중심 근처는 매우 촘촘해진다. 선 두께와 모티프 크기를 반지름에 따라 조절하면 중심의 과밀을 완화할 수 있다.

## 이 절의 핵심

만화경은 하나의 섹터 좌표에 정의한 모티프를 각도 반복과 접기로 중심 주위에 확장한 패턴이다. 복사보다 좌표 접기를 사용하면 대칭 관계가 함수 수준에서 유지된다.
