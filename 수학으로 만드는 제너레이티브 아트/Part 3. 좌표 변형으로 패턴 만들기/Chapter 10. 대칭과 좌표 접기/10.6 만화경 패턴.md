# 10.6 만화경 패턴

만화경 패턴은 회전 대칭과 거울 대칭을 함께 사용하는 방사형 구조다. 각 화면 좌표를 중심 기준으로 옮기고 극좌표로 바꾼 뒤, 각도를 반복하고 절반 섹터로 접는다. 마지막으로 접힌 좌표에 모티프 함수를 적용하면 하나의 쐐기에서 정의한 모양이 중심 주위로 확장된다.

```text
local = position - center
radius = length(local) * radialScale
angle = atan2(local.y, local.x)

sectorAngle = 2 * PI / sectorCount
localAngle = positiveMod(
    angle + rotationOffset + sectorAngle * 0.5,
    sectorAngle
) - sectorAngle * 0.5
foldedAngle = abs(localAngle)

folded = radius * (cos(foldedAngle), sin(foldedAngle))
value = motif(folded)
```

`sectorCount`는 회전 반복의 수를 정한다. 한 반복 각도는 $2\pi/\text{sectorCount}$이고, 접힌 뒤 모티프를 정의하는 기본 쐐기의 폭은 그 절반이다. 각 반복 구간 안의 좌우 반쪽이 서로 거울상으로 대응한다. 그러므로 `sectorCount`는 반복 주기를 세는 값이지, 접힌 쐐기의 폭을 직접 세는 값은 아니다. `positiveMod`는 음수 각도에서도 결과를 0 이상 주기 미만으로 반환해야 한다.

`rotationOffset`은 쐐기의 방향을 조절하고, `radialScale`은 반지름 좌표의 밀도를 조절한다. 반지름 스케일이 커지면 같은 화면 거리 안에서 모티프 좌표가 더 많이 변하므로, 반지름에 따라 반복되는 무늬는 더 촘촘해진다. 회전 오프셋을 샘플 좌표에 더할 때 화면에서 보이는 회전 방향은 오프셋 부호와 반대가 될 수 있으므로, 사용하는 각도와 화면 좌표계에 맞춰 확인한다.

## 모티프 선택과 결합

접힌 좌표는 항상 대표 쐐기 안에 놓인다. 이 좌표를 입력으로 받는 모티프는 점, 선, 원, SDF, 노이즈, 줄무늬 등 여러 형태로 정의할 수 있다. `motifCenter` 같은 모티프의 위치도 원래 화면 좌표가 아니라 접힌 좌표계에서 정한다. 중심에서 멀어질수록 쐐기의 폭이 커지므로, 같은 모티프라도 중심 쪽과 바깥쪽에서 차지하는 인상이 다를 수 있다.

SDF로 도형을 여러 개 조합할 때는 거리값의 의미를 유지하는 연산을 사용한다. 예를 들어 두 원의 합집합은 두 거리 중 작은 값을 선택한다.

```text
d1 = sdCircle(folded, centerA, radiusA)
d2 = sdCircle(folded, centerB, radiusB)
shapeDistance = min(d1, d2)
```

반면 노이즈나 줄무늬가 색과 밝기 값을 반환한다면, 그 값을 SDF에 무조건 더하는 것은 합집합을 뜻하지 않는다. 거리로 형태를 만든 뒤 노이즈나 줄무늬로 색을 정하거나, 두 값의 역할을 따로 정해 결합한다. 무엇을 반환하는 함수인지, 그리고 결과값이 거리인지 색·밝기인지 구분하면 조합 결과를 예측하기 쉽다.

## 경계에서 모티프 이어 붙이기

각도 접기는 섹터 경계 양쪽의 위치를 같은 접힌 좌표로 보낸다. 따라서 접힌 좌표를 입력으로 하는 연속적인 스칼라 함수는 경계에서 같은 값을 낸다. 모티프가 경계에 닿을 때 생기는 이음선은 보통 두 쪽의 값 차이보다 모양의 방향이나 기울기가 급히 꺾여 보이는 데서 나타난다.

경계에 걸쳐 모티프를 배치하면 거울상으로 이어지는 효과를 의도적으로 만들 수 있다. 이때 선이나 곡선이 대칭축에서 자연스럽게 만나도록 끝점과 접선 방향을 살핀다. 모티프를 쐐기 내부에만 두면 축에서 떨어진 반복 형태가 되고, 축을 가로지르게 두면 맞닿은 부분이 연결되거나 뾰족한 모서리를 만들 수 있다. SDF의 값이 이어져도 표면의 기울기나 법선은 경계에서 달라질 수 있다.

## 파라미터 조절

| 파라미터 | 역할 |
| --- | --- |
| `sectorCount` | 회전 반복 주기와 반복 횟수 |
| `motifCenter` | 접힌 쐐기 안에서 모티프를 놓을 위치 |
| `motifRadius` | 모티프의 크기 |
| `rotationOffset` | 대칭 패턴의 기준 방향 |
| `radialScale` | 반지름 방향 무늬의 크기와 밀도 |

먼저 섹터 수와 모티프 하나를 정하고, 경계에서 형태가 어떻게 만나는지 확인한다. 그 다음 전체 방향을 돌리고 모티프의 크기나 위치를 조절하면 각 파라미터가 만드는 변화를 구분하기 쉽다.

## 중심부 밀도

섹터 수가 늘어날수록 각 반복 각도는 좁아진다. 반지름 $r$에서 각도 폭 $\Delta\theta$가 차지하는 호의 길이는 $r\Delta\theta$이므로, 중심에 가까울수록 여러 방향의 무늬가 짧은 거리 안에 모인다. 가는 선이나 높은 주파수의 노이즈는 중심부에서 겹치거나 픽셀보다 작은 간격을 만들 수 있다.

중심의 과밀함을 줄이려면 중심 가까이에서 세부 무늬의 강도나 주파수를 낮추고, 선 두께와 모티프 크기를 반지름에 따라 조절한다. 중심을 비우고 싶다면 최소 반지름 마스크를 사용할 수 있지만, 마스크 경계를 부드럽게 처리해야 갑작스러운 원형 테두리가 덜 드러난다. 정확한 중심에서는 반지름이 0이라 각도가 정해지지 않으므로, 모든 방향의 모티프가 한 점에서 일관된 값을 갖는지도 확인한다.

## 이 절의 핵심

만화경 패턴은 각도를 회전 주기로 반복하고 절반 섹터로 접어 모티프 하나를 대칭 확장한다. 모티프는 접힌 좌표계 안에서 설계하고, 거리·색·밝기처럼 반환값의 의미에 맞게 결합한다. 섹터 경계와 중심부의 밀도도 함께 조절해야 한다.
