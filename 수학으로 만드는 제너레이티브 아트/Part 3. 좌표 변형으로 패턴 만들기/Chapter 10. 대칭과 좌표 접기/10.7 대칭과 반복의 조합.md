# 10.7 대칭과 반복의 조합

대칭과 반복은 좌표를 다시 매핑하지만 역할은 다르다. 반복은 공간을 여러 셀로 나누어 각 위치의 셀 번호와 셀 안 좌표를 구한다. 대칭은 서로 다른 위치를 접어 같은 대표 좌표에 대응시킨다. 따라서 접기를 셀을 나누기 전이나 후에 적용하느냐에 따라 대칭의 기준과 모티프의 방향이 달라진다.

## 셀 안에서 대칭 만들기

먼저 좌표를 `gridCount`만큼 확대하면 셀 단위의 공간이 된다. `floor`는 각 위치가 속한 셀 번호를, `fract`는 셀 안의 좌표를 구한다. 다음 예시는 셀 안 좌표에서 0.5를 빼 셀 중심을 원점으로 옮긴 뒤 두 축으로 접는다.

```text
scaled = position * gridCount
cellIndex = floor(scaled)
local = fract(scaled) - 0.5
local = abs(local)
value = motif(local, cellIndex)
```

`fract`는 각 셀 안의 좌표를 0 이상 1 미만으로 만든다. 여기서 0.5를 빼면 각 축의 범위가 셀 중심 기준으로 이동하고, `abs`를 적용하면 네 사분면이 한 사분면으로 접힌다. 그 결과 각 셀의 중심을 기준으로 대칭인 모티프가 만들어진다. `cellIndex`에는 `floor`로 구한 셀 번호가 남아 있으므로 셀마다 다른 색이나 크기를 정할 수 있다. 이를 모티프 계산에 사용하지 않으면 모든 셀에 같은 형태가 반복된다.

이 방법에서 대칭축은 각 타일의 중심을 지난다. 각 셀을 독립적인 작은 공간으로 보고, 그 안에서 좌우·상하 대칭을 만든 다음 같은 모티프를 반복 배치하는 구조다.

## 대칭 공간에서 반복 만들기

이번에는 셀을 나누기 전에 전체 좌표를 원점 기준으로 먼저 접는다. 그 다음 접힌 좌표에서 셀 번호와 셀 안 좌표를 계산한다.

```text
folded = abs(position)
scaled = folded * gridCount
cellIndex = floor(scaled)
local = fract(scaled) - 0.5
value = motif(local, cellIndex)
```

원점 양쪽의 대칭 위치는 먼저 접혀 같은 `folded` 좌표가 된다. 따라서 양쪽은 같은 셀 번호와 셀 안 좌표를 얻고, 셀별 색이나 크기도 서로 짝을 이룬다. 대칭축은 반복 배열 전체를 기준으로 삼는다. 셀 내부 좌표에는 절댓값을 적용하지 않았으므로, 각 타일 안의 모티프는 비대칭이어도 된다.

두 순서의 차이는 셀 안 좌표를 비교하면 분명해진다. 한 축의 좌표가 0.1이고 `gridCount`가 4일 때, 먼저 셀 안 좌표를 만든 뒤 접으면 `abs(fract(0.1 * 4) - 0.5)`는 0.1이다. 전체 좌표를 먼저 접고 셀을 나누면 `fract(abs(0.1) * 4) - 0.5`는 -0.1이다. 두 값은 셀 중심의 반대편을 가리키므로, 비대칭 모티프에서는 방향이 달라진다. 대칭을 타일마다 적용할지 배열 전체에 적용할지에 따라 순서를 정한다.

## 반복과 대칭을 함께 적용하기

전체 배열을 대칭으로 맞추면서 각 셀 안에도 대칭 모티프를 둘 수 있다. 먼저 전역 좌표를 접고, 셀 좌표를 계산한 다음, 셀 내부 좌표도 접는다.

```text
folded = abs(position)
scaled = folded * gridCount
cellIndex = floor(scaled)
local = abs(fract(scaled) - 0.5)
value = motif(local, cellIndex)
```

첫 번째 `abs`는 배열 전체를 원점 기준으로 접고, 두 번째 `abs`는 각 셀의 중심을 기준으로 접는다. 같은 연산도 서로 다른 좌표 공간에서 적용하면 기준과 결과가 다르다. 셀 번호를 `motif`에 전달하면 전체 대칭을 유지하면서 셀마다 색이나 크기에 변화를 줄 수 있다. 난수로 셀별 값을 정할 때 대칭 위치끼리 같은 값을 가져야 한다면, 전역 좌표를 접은 뒤 구한 `cellIndex`를 난수 입력으로 사용한다.

## 극좌표 반복과 대칭

극좌표에서는 반지름과 각도를 별도로 반복하거나 접을 수 있다. 반지름을 일정한 간격의 구간으로 나누면 동심 고리가 생기고, 각도를 섹터로 접으면 각 고리에 회전·거울 대칭 모티프가 배치된다.

```text
ringPosition = radius * ringCount
ringIndex = floor(ringPosition)
ringPhase = fract(ringPosition)

foldedAngle = foldAngle(angle, sectorCount)
motifPosition = polarToCartesian(ringPhase, foldedAngle)
value = motif(motifPosition, ringIndex)
```

`ringCount`는 반지름 좌표에 곱하는 양의 반복 배율이다. `ringPhase`는 각 고리 안에서 0 이상 1 미만으로 변하는 반지름 좌표이고, `ringIndex`는 현재 고리의 번호다. 모든 고리를 같은 모양으로 만들려면 번호를 무시하고 `ringPhase`만 사용한다. 고리마다 색이나 모티프를 바꾸려면 `ringIndex`를 함께 전달한다. `foldAngle`은 앞 절의 각도 접기를 나타내며, `sectorCount`에 맞는 대표 쐐기 안의 각도를 반환한다고 가정한다. 각도 접기는 모든 고리에 같은 방사형 대칭을 적용한다. `motifPosition`의 반지름은 고리 안에서 정규화된 좌표다. 실제 화면의 반지름이나 거리로 색·크기를 정하려면 접기 전의 원래 반지름도 별도로 전달한다.

`ringPhase`는 고리 경계에서 1에 가까운 값에서 다음 고리의 0으로 돌아간다. 따라서 고리 경계에 이음선이 생기지 않으려면 모티프의 안쪽과 바깥쪽 경계가 같은 값이나 형태로 이어져야 한다. 고리마다 다른 모양을 쓰는 경우에는 인접한 `ringIndex` 사이의 연결도 확인한다.

셀 반복과 극좌표 반복은 모두 인덱스와 내부 좌표를 분리하는 구조다. 반복 위치를 식별하는 인덱스는 셀마다 다른 속성을 정하고, 내부 좌표는 반복되는 모티프의 형태를 계산한다. 좌표 접기는 이 중 내부 좌표나 인덱스를 만들기 전후의 어느 단계에도 적용할 수 있지만, 적용 위치에 따라 대칭의 기준이 달라진다.

## Chapter 10의 마무리

Chapter 10에서는 절댓값, 반사, 각도 반복과 접기를 사용해 좌우·상하·회전·거울 대칭을 만들었다. 대칭은 도형을 복사하는 작업이 아니라 서로 다른 위치가 같은 함수 입력을 공유하게 하는 변환이다. 반복과 결합할 때는 접는 단계와 셀을 나누는 단계의 순서가 모티프의 방향과 배열을 결정한다.
