# 10.7 대칭과 반복의 조합

대칭과 반복은 모두 좌표 공간을 다시 사용하는 연산이지만 역할이 다르다. 반복은 공간을 여러 셀로 나누고, 대칭은 여러 위치를 하나의 대표 위치로 접는다. 두 연산의 순서를 바꾸면 다른 결과가 나온다.

## 셀 안에서 대칭 만들기

먼저 반복 좌표를 만든 뒤 셀 내부 좌표를 접으면, 각 타일이 독립적인 대칭 모티프를 가진다.

```text
local = fract(uv * gridCount) - 0.5
local = abs(local)
value = motif(local)
```

결과는 대칭 도형이 반복되는 타일 패턴이다.

## 대칭 공간에서 반복 만들기

먼저 전역 좌표를 접한 뒤 반복하면, 대칭축을 기준으로 반복 구조 자체가 거울 대칭이 된다.

```text
folded = abs(position)
local = fract(folded * gridCount)
value = motif(local)
```

첫 번째와 달리 중앙 대칭축에서 타일 인덱스와 배열 방향까지 맞물린다.

## 극좌표 반복과 대칭

반지름 방향의 반복, 각도 방향의 반복, 각도 접기를 함께 사용하면 만다라·선버스트·방사형 격자를 만들 수 있다.

```text
radiusBand = fract(radius * ringCount)
foldedAngle = foldAngle(angle, sectorCount)
motifPosition = polarToCartesian(radiusBand, foldedAngle)
value = motif(motifPosition)
```
