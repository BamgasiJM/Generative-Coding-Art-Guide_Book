# 10.7 대칭과 반복의 조합

대칭과 반복은 모두 좌표 공간을 다시 사용하는 연산이지만 역할이 다르다. 반복은 공간을 여러 셀로 나누고, 각 위치가 속한 셀과 셀 안의 좌표를 구한다. 대칭은 좌표의 일부를 접어 여러 위치가 하나의 대표 좌표를 공유하게 한다. 두 연산을 어느 단계에 적용하는지에 따라 셀의 배열과 모티프의 방향이 달라진다.

## 셀 안에서 대칭 만들기

먼저 반복 좌표를 만들면 각 셀의 위치와 셀 안 좌표를 구할 수 있다. 다음 예시는 셀 내부 좌표를 중심 기준 범위로 옮긴 뒤 두 축으로 접는다.

```text
scaled = position * gridCount
cellIndex = floor(scaled)
local = fract(scaled) - 0.5
local = abs(local)
value = motif(local, cellIndex)
```

`fract`는 각 셀 안의 좌표를 0 이상 1 미만으로 만들고, 0.5를 빼면 셀 중심이 원점인 범위가 된다. `abs`를 적용하면 셀 내부의 네 사분면이 한 사분면으로 접힌다. 따라서 각 셀마다 중심이 같은 모티프가 생긴다. `cellIndex`는 셀마다 다른 색이나 크기를 부여할 때 쓸 수 있고, 사용하지 않으면 모든 셀의 모티프가 동일하게 반복된다.

이 방법에서 대칭축은 각 타일의 중심을 지난다. 각 셀을 독립적인 작은 공간으로 보고, 그 안에서 좌우·상하 대칭을 만든 다음 같은 모티프를 반복 배치하는 구조다.

## 대칭 공간에서 반복 만들기

이번에는 반복 좌표를 만들기 전에 전체 좌표를 먼저 접는다. 접힌 위치를 기준으로 셀 인덱스와 셀 내부 좌표를 계산한다.

```text
folded = abs(position)
scaled = folded * gridCount
cellIndex = floor(scaled)
local = fract(scaled) - 0.5
value = motif(local, cellIndex)
```

이 경우 원점의 양쪽 위치는 접은 뒤 같은 `folded` 좌표를 가지므로, 타일의 인덱스와 모티프 방향까지 짝을 이룬다. 대칭축은 전체 반복 배열의 기준이 되고, 타일 안의 모티프 자체는 별도로 접지 않았으므로 비대칭일 수 있다.

두 순서의 차이는 한 셀 안의 좌표를 비교하면 분명해진다. 예를 들어 한 축의 좌표가 0.1이고 셀 수가 4일 때, 먼저 셀을 만든 뒤 접으면 `abs(fract(0.1 * 4) - 0.5)`는 0.1이다. 먼저 전체 좌표를 접고 셀을 만들면 `fract(abs(0.1) * 4) - 0.5`는 -0.1이다. 두 좌표는 셀 중심의 반대편에 있으므로, 비대칭 모티프를 넣으면 결과의 방향이 달라진다. 대칭을 셀마다 만들지, 배열 전체에 만들지에 따라 알맞은 순서를 선택한다.

## 반복과 대칭을 함께 적용하기

전체 배열을 대칭으로 맞추면서 각 셀 안에도 대칭 모티프를 둘 수 있다. 먼저 전역 좌표를 접고, 셀 좌표를 계산한 다음, 셀 내부 좌표도 접는다.

```text
folded = abs(position)
scaled = folded * gridCount
cellIndex = floor(scaled)
local = abs(fract(scaled) - 0.5)
value = motif(local, cellIndex)
```

첫 번째 `abs`는 전체 배열을 원점 기준으로 대칭시키고, 두 번째 `abs`는 각 셀을 셀 중심 기준으로 대칭시킨다. 같은 연산을 반복해서 적용해도 기준이 되는 좌표 공간이 다르면 역할이 다르다. 셀 인덱스를 `motif`에 전달하면 대칭 배열을 유지하면서도 셀별 색이나 크기에 변화를 줄 수 있다. 이때 셀 인덱스에서 난수를 만들더라도 양쪽 대칭 셀이 같은 값을 가져야 한다면, 접은 좌표에서 인덱스를 구한 뒤 값을 결정한다.

## 극좌표 반복과 대칭

극좌표에서는 반지름과 각도를 각각 반복하거나 접을 수 있다. 반지름을 여러 구간으로 나누면 동심 고리가 생기고, 각도를 섹터로 접으면 각 고리 안에 회전·거울 대칭 모티프가 배치된다.

```text
ringPosition = radius * ringCount
ringIndex = floor(ringPosition)
ringPhase = fract(ringPosition)

foldedAngle = foldAngle(angle, sectorCount)
motifPosition = polarToCartesian(ringPhase, foldedAngle)
value = motif(motifPosition, ringIndex)
```

`ringPhase`는 각 고리 안에서의 반지름 좌표이고, `ringIndex`는 현재 고리의 번호다. 모든 고리를 같은 모양으로 만들려면 번호를 무시하고 `ringPhase`만 사용한다. 고리마다 색이나 모티프를 바꾸려면 `ringIndex`를 함께 사용한다. 각도 접기는 모든 고리에 동일한 방사형 대칭을 적용한다. 다만 `motifPosition`은 각 고리의 국소 좌표로 정의한 값이므로, 실제 화면의 반지름이나 거리가 필요하다면 원래 반지름 정보도 별도로 전달한다.

셀 반복과 극좌표 반복은 모두 인덱스와 내부 좌표를 분리하는 구조다. 반복 위치를 식별하는 인덱스는 셀마다 다른 속성을 정하고, 내부 좌표는 반복되는 모티프의 형태를 계산한다. 좌표 접기는 이 중 내부 좌표나 인덱스를 만들기 전후의 어느 단계에도 적용할 수 있지만, 적용 위치에 따라 대칭의 기준이 달라진다.

## Chapter 10의 마무리
