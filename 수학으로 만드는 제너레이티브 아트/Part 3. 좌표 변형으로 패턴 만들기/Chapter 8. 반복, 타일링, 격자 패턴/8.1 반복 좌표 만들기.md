# 8.1 반복 좌표 만들기

반복 좌표는 넓은 공간의 위치를 하나의 작은 셀 안의 위치로 되돌리는 좌표 변환이다. 같은 도형 함수를 셀마다 다시 평가하면 타일링과 격자 패턴을 만들 수 있다.

정규화 좌표 $\mathbf{uv}$에 반복 횟수 $\mathbf{n}$을 곱한 뒤 소수 부분을 취하면 셀 내부 좌표가 된다.

$$
\mathbf{p}_{local}=\operatorname{fract}(\mathbf{uv}\,\mathbf{n})
$$

이 식은 좌표를 두 단계로 해석한다. 먼저 $\mathbf{uv}\,\mathbf{n}$은 전체 화면을 $\mathbf{n}$개의 셀 단위로 확대한 좌표다. 예를 들어 가로 방향 좌표가 $0.37$이고 가로 반복 수가 $4$라면 값은 $1.48$이 된다. 여기서 정수 부분 $1$은 두 번째 셀에 있다는 뜻이고, 소수 부분 $0.48$은 그 셀 안에서 가로로 48% 지점에 있다는 뜻이다. `fract`는 정수 부분을 버리고 이 셀 내부 위치만 남긴다.

따라서 서로 다른 셀에 있더라도 같은 상대 위치는 같은 `cellLocal` 값을 갖는다. 각 셀의 20% 지점에 놓인 점들은 모두 같은 좌표 입력으로 도형 함수를 평가한다. 이것이 한 번 정의한 원, 선, 거리 함수, 노이즈 무늬가 모든 셀에서 반복되는 이유다.

```glsl
vec2 cellLocal = fract(uv * gridCount);
```

`cellLocal`은 모든 셀에서 0에서 1 사이를 반복한다. 따라서 한 셀 안에 원이나 선을 정의하면 모든 셀에 같은 형태가 나타난다.

반복 좌표는 셀의 위치 정보를 완전히 없애는 것이 아니라, 이 단계에서는 잠시 사용하지 않는 것이다. 셀마다 같은 도형을 그릴 때는 로컬 좌표만 있으면 충분하다. 반대로 셀마다 다른 색이나 회전값을 주려면 이후 절에서 다룰 셀 인덱스를 따로 보관해야 한다.

```text
cellPosition = uv * gridCount
cellIndex = floor(cellPosition)
cellLocal = fract(cellPosition)
```

`cellIndex`는 몇 번째 셀인지, `cellLocal`은 그 셀 안의 어디인지 나타낸다. 두 값을 분리해 두면 반복되는 공통 형태와 셀별 변화를 함께 다룰 수 있다.

## 셀 중심 기준 좌표

셀의 중심을 원점으로 삼으면 대칭 도형을 만들기 쉽다.

```glsl
vec2 local = fract(uv * gridCount) - 0.5;
float d = length(local);
```

이 좌표에서 같은 길이를 갖는 점은 셀 중심을 기준으로 한 원이 된다.

`fract`만 적용한 좌표의 범위는 $[0,1)$이므로 셀의 원점은 왼쪽 아래 또는 왼쪽 위 모서리에 놓인다. 여기서 $0.5$를 빼면 좌표 범위가 대략 $[-0.5,0.5)$가 되고, 셀 중심이 $(0,0)$이 된다. 원, 방사형 선, 회전, 대칭 도형처럼 중심을 기준으로 정의하는 함수는 이 좌표에서 훨씬 간단하게 쓸 수 있다.

예를 들어 `length(local) < 0.25`는 셀 중심에서 반지름 0.25 안에 있는 영역을 뜻한다. 모든 셀에서 같은 중심 좌표계를 쓰기 때문에 도트는 각 셀의 정확한 중앙에 반복된다.

## 반복은 입력 변환이다

반복 패턴은 도형을 복사하는 명령이 아니라 좌표를 반복 범위로 접는 변환으로 볼 수 있다.

```text
local = repeat(position, cellSize)
value = pattern(local)
```

이 관점은 이후 셀마다 다른 값, 오프셋 타일링, 반복과 대칭의 조합을 만들 때 중요하다.

도형을 실제로 여러 번 복제한다고 생각하면 셀 수가 늘어날수록 개별 도형을 관리해야 할 것처럼 보인다. 좌표를 반복 범위로 접는 방식에서는 화면의 현재 위치 하나를 셀 내부 위치 하나로 바꾼 뒤, 표준 패턴 함수를 한 번 평가할 뿐이다. 특히 셰이더처럼 픽셀마다 함수를 계산하는 환경에서 반복 좌표가 자연스러운 이유다.

## 셀의 크기와 화면 비율

`gridCount`가 하나의 수이면 가로와 세로에 같은 반복 수를 적용한다. 직사각형 화면에서는 셀이 화면 픽셀 기준으로 직사각형이 될 수 있으므로, 원형 도트나 거리 함수를 쓸 때는 종횡비를 보정한다. 반복 횟수 자체와 셀의 실제 화면 크기는 다른 값이라는 점을 구분한다.

예를 들어 화면 비율이 $W:H$인데 가로와 세로 모두 `gridCount = 10`을 사용하면, 화면 너비와 높이가 다른 만큼 한 셀의 픽셀 너비와 높이도 달라진다. `length(local)`으로 만든 원은 화면에서는 타원처럼 보일 수 있다. 원형을 유지하려면 좌표의 한 축을 화면 또는 셀의 종횡비로 보정한 뒤 거리를 계산한다.

```text
local = fract(uv * gridCount) - 0.5
local.x *= cellWidth / cellHeight
distanceValue = length(local)
```

어느 축에 비율을 곱할지는 사용하는 좌표계와 원하는 기준에 따라 달라질 수 있다. 중요한 것은 `gridCount`가 반복 횟수를 정하는 값이고, 종횡비 보정은 그 반복 단위가 화면에서 어떤 물리적 비율로 보일지를 정하는 별도 단계라는 점이다.

## 이 절의 핵심

반복 좌표는 공간의 위치를 셀 내부의 위치로 바꾼다. 같은 패턴 함수를 반복 좌표에 적용하면 격자 전체에 같은 도형과 질감을 만들 수 있다.
