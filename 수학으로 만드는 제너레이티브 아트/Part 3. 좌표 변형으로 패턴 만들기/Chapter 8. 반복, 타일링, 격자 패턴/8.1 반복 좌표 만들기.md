# 8.1 반복 좌표 만들기

반복 좌표는 넓은 공간의 위치를 작은 셀 안의 좌표로 접는 변환이다. 각 셀에서 같은 도형 함수를 평가하면 타일링과 격자 패턴을 만들 수 있다.

정규화 좌표 $\mathbf{uv}$의 각 성분에 해당 축의 반복 횟수 $\mathbf{n}$을 곱한 뒤 소수 부분을 취하면 셀 내부 좌표가 된다. 두 축의 반복 횟수가 같으면 하나의 수를, 다르면 축별 횟수를 담은 벡터를 사용한다.

$$
\mathbf{p}_{local}=\operatorname{fract}(\mathbf{uv}\,\mathbf{n})
$$

이 식은 두 단계로 작동한다. 먼저 $\mathbf{uv}\,\mathbf{n}$은 전체 화면 좌표를 축별 셀 수만큼 늘린 값이다. 예를 들어 가로 좌표가 $0.37$이고 가로 반복 수가 $4$라면 곱한 결과는 $1.48$이다. 정수 부분 $1$은 두 번째 셀을, 소수 부분 $0.48$은 그 셀 안에서 가로로 48% 지점을 나타낸다. `fract`는 정수 부분을 버리고 셀 안의 상대 위치만 남긴다.

서로 다른 셀에 있어도 같은 상대 위치에 놓인 점은 같은 `cellLocal` 값을 갖는다. 예를 들어 각 셀의 20% 지점은 모두 같은 좌표로 도형 함수를 평가한다. 그래서 한 번 정의한 원, 선, 거리 함수, 노이즈 무늬를 모든 셀에서 반복할 수 있다.

```glsl
vec2 cellLocal = fract(uv * gridCount);
```

`cellLocal`의 각 성분은 모든 셀에서 $[0,1)$ 범위를 반복한다. 이 좌표에 원이나 선을 정의하면 같은 형태가 모든 셀에 나타난다.

`cellLocal`만 사용하면 각 셀의 위치 정보는 평가에 반영되지 않는다. 셀마다 같은 도형을 그릴 때는 이 로컬 좌표로 충분하지만, 셀마다 다른 색이나 회전값을 주려면 이후 절에서 다룰 셀 인덱스도 함께 보관해야 한다.

```text
cellPosition = uv * gridCount
cellIndex = floor(cellPosition)
cellLocal = fract(cellPosition)
```

`cellIndex`는 셀의 주소를, `cellLocal`은 그 셀 안의 위치를 나타낸다. 두 값을 분리하면 공통 형태를 반복하면서도 셀별 차이를 줄 수 있다.

## 셀 중심 기준 좌표

셀의 중심을 원점으로 삼으면 대칭 도형을 만들기 쉽다.

```glsl
vec2 local = fract(uv * gridCount) - 0.5;
float d = length(local);
```

이 좌표에서 같은 길이를 갖는 점은 셀 중심을 기준으로 한 원이 된다.

`fract`를 적용한 좌표의 범위는 $[0,1)$이므로 셀의 원점은 한쪽 모서리에 있다. 여기서 $0.5$를 빼면 범위가 $[-0.5,0.5)$가 되고 셀 중심이 $(0,0)$이 된다. 원, 방사형 선, 회전, 대칭 도형처럼 중심을 기준으로 하는 함수는 이 좌표에서 간단히 정의할 수 있다.

예를 들어 `length(local) < 0.25`는 셀 중심에서 반지름 0.25 안쪽의 영역을 뜻한다. 모든 셀이 같은 중심 좌표계를 사용하므로 도트가 각 셀의 중앙에 반복된다.

## 반복은 입력 변환이다

반복 패턴은 도형을 실제로 복제하는 대신 좌표를 셀 범위로 접고, 그 결과를 표준 패턴 함수에 넣는 방식으로 만들 수 있다.

```text
local = repeat(position, cellSize)
value = pattern(local)
```

이 관점은 이후 셀마다 다른 값, 오프셋 타일링, 반복과 대칭의 조합을 만들 때 중요하다.

이 방식에서는 화면의 각 위치를 셀 내부 좌표로 바꿔 표준 함수를 평가한다. 셰이더처럼 픽셀마다 값을 계산하는 환경에서는 셀별 도형을 따로 관리하지 않고도 같은 규칙을 반복할 수 있다.

## 셀의 크기와 화면 비율

`gridCount`가 하나의 수이면 가로와 세로에 같은 반복 수를 적용한다. 서로 다른 횟수가 필요하면 축별 값을 지정한다. 직사각형 화면에서 같은 반복 수를 사용하면 셀의 픽셀 너비와 높이가 달라질 수 있으므로, 원형 도트나 거리 함수를 쓸 때는 종횡비를 보정한다. 반복 횟수와 셀의 실제 화면 크기는 별개의 값이다.

예를 들어 화면 비율이 $W:H$이고 가로·세로 모두 `gridCount = 10`이면, 한 셀의 픽셀 너비와 높이는 화면 비율에 따라 달라진다. `length(local)`로 만든 원은 화면에서 타원처럼 보일 수 있다. 원형을 유지하려면 거리 계산 전에 한 축을 화면 또는 셀의 종횡비에 맞게 보정한다.

```text
local = fract(uv * gridCount) - 0.5
local.x *= cellWidth / cellHeight
distanceValue = length(local)
```

어느 축에 비율을 곱할지는 좌표계의 축 방향과 원하는 기준에 따라 달라진다. `gridCount`는 셀의 개수를 정하고, 종횡비 보정은 각 셀이 화면에서 어떤 모양으로 보일지를 정하는 별도 단계다.

## 이 절의 핵심

반복 좌표는 위치를 셀 내부 좌표로 바꾼다. `floor`로 셀 인덱스도 함께 보관하면 공통 패턴을 반복하면서 셀마다 다른 값을 줄 수 있다. 종횡비 보정은 셀의 화면 모양을 조절한다.
