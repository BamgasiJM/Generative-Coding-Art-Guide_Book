# 8.1 반복 좌표 만들기

반복 좌표는 넓은 공간의 위치를 하나의 작은 셀 안의 위치로 되돌리는 좌표 변환이다. 같은 도형 함수를 셀마다 다시 평가하면 타일링과 격자 패턴을 만들 수 있다.

정규화 좌표 $\mathbf{uv}$에 반복 횟수 $\mathbf{n}$을 곱한 뒤 소수 부분을 취하면 셀 내부 좌표가 된다.

$$
\mathbf{p}_{local}=\operatorname{fract}(\mathbf{uv}\,\mathbf{n})
$$

```glsl
vec2 cellLocal = fract(uv * gridCount);
```

`cellLocal`은 모든 셀에서 0에서 1 사이를 반복한다. 따라서 한 셀 안에 원이나 선을 정의하면 모든 셀에 같은 형태가 나타난다.

## 셀 중심 기준 좌표

셀의 중심을 원점으로 삼으면 대칭 도형을 만들기 쉽다.

```glsl
vec2 local = fract(uv * gridCount) - 0.5;
float d = length(local);
```

이 좌표에서 같은 길이를 갖는 점은 셀 중심을 기준으로 한 원이 된다.

## 반복은 입력 변환이다

반복 패턴은 도형을 복사하는 명령이 아니라 좌표를 반복 범위로 접는 변환으로 볼 수 있다.

```text
local = repeat(position, cellSize)
value = pattern(local)
```

이 관점은 이후 셀마다 다른 값, 오프셋 타일링, 반복과 대칭의 조합을 만들 때 중요하다.

## 셀의 크기와 화면 비율

`gridCount`가 하나의 수이면 가로와 세로에 같은 반복 수를 적용한다. 직사각형 화면에서는 셀이 화면 픽셀 기준으로 직사각형이 될 수 있으므로, 원형 도트나 거리 함수를 쓸 때는 종횡비를 보정한다. 반복 횟수 자체와 셀의 실제 화면 크기는 다른 값이라는 점을 구분한다.

## 이 절의 핵심

반복 좌표는 공간의 위치를 셀 내부의 위치로 바꾼다. 같은 패턴 함수를 반복 좌표에 적용하면 격자 전체에 같은 도형과 질감을 만들 수 있다.
