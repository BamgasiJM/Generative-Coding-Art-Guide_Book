# 8.7 셀마다 다른 값 부여하기

반복 패턴이 지나치게 기계적으로 보이지 않게 하려면 셀마다 다른 값을 줄 수 있다. 셀 내부 좌표는 같은 도형을 반복하게 하고, 셀 인덱스는 각 셀의 변주를 결정한다.

```text
cellId = floor(uv * gridCount)
local = fract(uv * gridCount)
variation = cellValue(cellId)
```

## 해시 함수

셰이더에서는 셀 인덱스를 입력으로 받아 0에서 1 사이의 의사 난수 값을 만드는 해시 함수를 자주 쓴다.

```glsl
float hash21(vec2 p) {
    p = fract(p * vec2(123.34, 456.21));
    p += dot(p, p + 45.32);
    return fract(p.x * p.y);
}
```

이 함수는 같은 `cellId`에 항상 같은 값을 반환하므로 반복 실행해도 패턴이 유지된다. 난수 시드를 바꾸고 싶다면 인덱스에 시드값을 더하거나 해시 상수를 바꾼다.

## 변주 연결하기

셀 값은 색, 반지름, 회전, 오프셋 등에 연결할 수 있다.

```text
v = hash(cellId)
radius = interpolate(minRadius, maxRadius, v)
angle = v * 2 * PI
color = palette(v)
```

하나의 값에 모든 속성을 연결하면 셀 간 상관관계가 강해진다. 색과 크기를 독립적으로 바꾸려면 서로 다른 해시 입력 또는 다른 시드를 사용한다.

```text
sizeValue = hash(cellId + seedA)
colorValue = hash(cellId + seedB)
```

해시는 연속 노이즈와 달리 이웃 셀 사이의 관계를 보장하지 않는다. 이웃한 셀이 비슷하게 변해야 한다면 셀 인덱스를 노이즈 입력으로 쓰거나, 전역 필드 값을 셀 중심에서 표본화한다. 독립성에는 해시, 공간적 연속성에는 노이즈라는 역할 구분이 중요하다.

## 이 절의 핵심

셀 인덱스는 반복 구조의 변주를 위한 안정적인 입력이다. 해시나 시드 기반 값을 연결하면 셀마다 달라지면서도 재현 가능한 패턴을 만들 수 있다.
