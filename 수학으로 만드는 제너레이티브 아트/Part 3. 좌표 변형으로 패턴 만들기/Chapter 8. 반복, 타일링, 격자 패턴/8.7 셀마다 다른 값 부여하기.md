# 8.7 셀마다 다른 값 부여하기

반복 패턴이 지나치게 기계적으로 보이지 않게 하려면 셀마다 다른 값을 줄 수 있다. 셀 내부 좌표는 같은 도형을 반복하게 하고, 셀 인덱스는 각 셀의 변주를 결정한다. 이 두 역할을 분리하면 격자의 질서는 유지하면서도 색, 크기, 방향, 표시 여부에 안정적인 차이를 만들 수 있다.

```text
cellId = floor(uv * gridCount)
local = fract(uv * gridCount)
variation = cellValue(cellId)
```

여기서 `local`은 어느 셀에 있든 같은 범위 $[0,1)$를 반복하므로, 원이나 선 같은 표준 도형을 만드는 입력이다. 반면 `cellId`는 셀마다 다른 정수 좌표다. 예를 들어 $(2,1)$ 셀과 $(2,2)$ 셀은 내부 중심 좌표가 모두 $(0.5,0.5)$일 수 있지만, 서로 다른 `cellId`를 갖는다. 이 차이가 셀마다 다른 값을 부여할 수 있는 주소 역할을 한다.

## 셀 인덱스는 안정적인 주소다

셀 인덱스는 화면의 현재 프레임이나 셀 내부의 미세한 위치와 달리, 같은 셀 안에서는 변하지 않는다. 따라서 `cellId`에서 값을 계산하면 셀 안의 모든 픽셀이 같은 변주 값을 공유한다.

```text
for each position in a cell:
    cellId = floor(position * gridCount)
    value = hash(cellId)
```

이 규칙에서 `value`는 셀의 왼쪽 위와 오른쪽 아래에서 동일하다. 그래서 하나의 셀 안에서는 도트의 크기나 색이 일정하게 유지된다. 만약 `local` 또는 원래 `uv`를 해시에 넣으면 셀 내부에서도 값이 계속 달라져, 셀 단위의 변주가 아니라 점묘나 잡음 질감에 가까운 결과가 된다.

`cellId`는 셰이더에서 흔히 `vec2` 실수 형태로 저장되지만, `floor`로 얻은 값이므로 정수 좌표처럼 사용할 수 있다. 해시의 입력으로 쓰기 전에 `cellLocal`과 섞거나 다시 보간하지 않는 편이 좋다. 셀 주소와 셀 내부 좌표의 역할을 분리하는 것이 반복 구조를 읽기 쉽게 만드는 기본이다.

## 해시 함수

셰이더에서는 셀 인덱스를 입력으로 받아 0에서 1 사이의 의사 난수 값을 만드는 해시 함수를 자주 쓴다.

```glsl
float hash21(vec2 p) {
    p = fract(p * vec2(123.34, 456.21));
    p += dot(p, p + 45.32);
    return fract(p.x * p.y);
}
```

해시 함수는 난수 생성기의 상태를 한 번씩 진행시키는 방식이 아니다. 입력 좌표에서 곧바로 값을 계산하는 결정적인 함수다. 따라서 `hash21(vec2(2.0, 1.0))`를 언제, 몇 번 호출하든 같은 결과를 돌려준다. 반면 $(2,1)$과 $(2,2)$처럼 다른 셀 인덱스에는 대체로 서로 다른 값을 돌려준다.

해시값은 완전히 무작위인 값이라기보다, 일정한 수식으로 만들어 낸 난수처럼 보이는 값이다. 가까운 셀의 값이 어느 정도 독립적으로 흩어져 보이면 반복 도형의 크기나 색을 바꾸는 용도로는 충분하다. 암호학적 안전성이나 엄밀한 확률 분포가 목적이 아니라, 빠르게 계산되며 같은 입력에 같은 결과를 주는 것이 여기서의 중요한 성질이다.

```text
v = hash(cellId)
```

이 한 줄을 먼저 회색조로 표시해 보면 해시가 셀마다 고정된 값인지, 인덱스 대신 로컬 좌표를 잘못 넣어 셀 내부가 얼룩지지는 않았는지 쉽게 확인할 수 있다.

```text
color = grayscale(hash(cellId))
```

## 시드로 같은 규칙의 다른 변형 만들기

같은 `cellId`에 항상 같은 값이 나온다는 것은 재현성에는 좋지만, 다른 버전의 패턴을 만들고 싶을 때는 입력을 바꿀 방법이 필요하다. 가장 단순한 방법은 고정 시드값을 해시 입력에 섞는 것이다.

```text
variation = hash(cellId + seed)
```

시드를 바꾸면 모든 셀의 값 배열은 달라지지만, 같은 시드 안에서는 패턴이 프레임마다 흔들리지 않는다. 즉 시드는 매 프레임 새 난수를 얻기 위한 값이 아니라, 하나의 반복 패턴이 어떤 변주 배열을 사용할지 선택하는 값이다.

시드가 스칼라 하나일 때는 두 좌표에 같은 값을 더해도 되지만, 더 분명한 분리를 위해 두 성분을 가진 시드나 서로 다른 오프셋을 사용할 수도 있다.

```text
seedOffset = (seedA, seedB)
variation = hash(cellId + seedOffset)
```

이 방식은 패턴의 구조를 유지한 채 다른 판본을 만들고, 특정 결과를 시드값으로 기록해 다시 재현하는 데 유용하다.

## 해시값을 시각 속성으로 바꾸기

해시 함수의 출력이 $[0,1)$ 범위라면, 그 값은 색상 보간 비율이나 확률처럼 바로 사용할 수 있다. 하지만 반지름, 회전, 위치처럼 다른 단위를 가진 속성에는 원하는 범위로 변환해야 한다.

```text
v = hash(cellId)

radius = mix(minRadius, maxRadius, v)
angle = v * TAU
color = palette(v)
```

`radius`는 `minRadius`와 `maxRadius` 사이에, `angle`은 $0$에서 한 바퀴 사이에, `color`는 팔레트의 입력 범위 안에 놓인다. 해시값을 그대로 크기로 쓰면 값이 작을 때 도형이 거의 보이지 않거나, 로컬 좌표 단위와 맞지 않는 범위를 만들 수 있다. 해시의 출력 범위와 실제 시각 속성의 단위를 분리하는 것이 중요하다.

모든 셀을 표시하지 않고 일부만 남기고 싶다면 해시값을 임계값과 비교할 수 있다.

```text
isVisible = hash(cellId) < fillProbability

if isVisible:
    drawCellPattern(local)
```

`fillProbability`가 0.3이면 셀의 약 30%가 표시되는 분포를 기대할 수 있다. 실제 한 화면에서는 정확히 30%가 아닐 수 있지만, 셀 수가 늘어나면 평균적으로 그 비율에 가까워진다. 이 역시 시간에 따라 바뀌지 않는 셀별 선택이다.

## 하나의 값과 여러 개의 값

하나의 값에 모든 속성을 연결하면 셀 간 상관관계가 강해진다. 예를 들어 값이 큰 셀은 항상 큰 도트, 밝은 색, 큰 회전을 동시에 갖게 된다.

```text
v = hash(cellId)
radius = mix(minRadius, maxRadius, v)
color = palette(v)
angle = v * TAU
```

이런 상관관계는 의도적으로 계층을 만들 때 유용하다. 큰 도트를 밝게 하고 같은 방향으로 회전시키면 각 셀의 성격이 하나의 값으로 묶인다. 반대로 색과 크기를 독립적으로 바꾸려면 서로 다른 해시 입력 또는 다른 시드를 사용한다.

```text
sizeValue = hash(cellId + seedA)
colorValue = hash(cellId + seedB)
rotationValue = hash(cellId + seedC)
```

여기서 `seedA`, `seedB`, `seedC`는 서로 다른 고정 오프셋이다. 같은 `cellId`라도 각 속성은 다른 값을 얻는다. 다만 모든 속성을 독립적인 난수로 만들면 전체 패턴의 질서가 약해질 수 있다. 먼저 하나의 값으로 만들고 싶은 상관관계가 있는지 정한 뒤, 꼭 필요한 속성만 분리하는 편이 좋다.

## 해시와 연속적인 필드의 차이

해시는 인접한 셀의 관계를 보장하지 않는다. $(2,1)$ 셀의 값이 크다고 해서 $(3,1)$ 셀의 값도 비슷하리라는 보장은 없다. 그래서 해시는 타일마다 독립적인 변주, 점의 표시 여부, 불규칙한 색 선택에 잘 맞는다.

이웃한 셀이 비슷하게 변해야 한다면 셀 인덱스를 노이즈 입력으로 쓰거나, 전역 필드 값을 셀 중심에서 표본화한다.

```text
cellCenter = (cellId + 0.5) / gridCount
variation = noise(cellCenter * fieldScale)
```

이 경우 가까운 셀은 가까운 노이즈 입력을 사용하므로 값도 대체로 비슷하게 이어진다. 해시가 셀 주소에서 독립적인 값을 얻는 도구라면, 노이즈나 전역 필드는 셀 배열 전체에 큰 흐름을 만드는 도구다. 두 방식을 모두 쓸 수 있지만, 독립적인 변주가 필요한지 공간적 연속성이 필요한지 먼저 구분해야 한다.

## 점검할 기준

셀별 변주가 의도와 다르게 보일 때는 도형 속성보다 먼저 입력을 점검한다.

- 해시에 `cellId`를 넣었는지, `cellLocal`이나 시간값을 넣지는 않았는지 확인한다.
- 해시값을 회색조로 표시해 셀 안에서 값이 일정한지 확인한다.
- 크기와 각도의 범위가 셀의 로컬 좌표 단위에 맞는지 확인한다.
- 속성들이 함께 변해야 하는지, 독립적으로 변해야 하는지 확인한다.
- 해시 대신 노이즈가 필요한 공간적 흐름을 기대하고 있지는 않은지 확인한다.

셀 인덱스는 반복 구조의 변주를 위한 안정적인 입력이다. 공통 도형은 `cellLocal`에서 계산하고, 셀별 성격은 `cellId`에서 계산하면 반복은 유지하면서도 화면이 한결 덜 기계적으로 보인다. 다음 절에서는 이러한 변주를 전역 규칙과 함께 사용해 반복 구조 전체에 더 큰 흐름을 만드는 방법을 정리한다.

## 이 절의 핵심

셀 인덱스는 반복 구조의 변주를 위한 안정적인 주소다. 해시나 시드 기반 값을 연결하면 셀마다 달라지면서도 재현 가능한 패턴을 만들 수 있다. 해시값은 실제 속성의 범위로 변환해 사용하고, 하나의 값이 만드는 상관관계와 여러 값이 만드는 독립성을 구분한다. 이웃 셀 사이의 연속성이 필요할 때는 해시 대신 노이즈나 전역 필드를 셀 중심에서 표본화한다.
