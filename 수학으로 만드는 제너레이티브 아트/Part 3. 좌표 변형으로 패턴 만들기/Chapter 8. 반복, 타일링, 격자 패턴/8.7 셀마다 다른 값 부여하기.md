# 8.7 셀마다 다른 값 부여하기

반복 패턴이 지나치게 기계적으로 보이면 셀마다 다른 값을 줄 수 있다. `cellLocal`은 같은 도형을 반복하는 좌표이고, 셀 인덱스 `cellId`는 각 셀의 변주를 정하는 주소다. 두 역할을 분리하면 격자의 질서를 유지하면서 색, 크기, 방향, 표시 여부에 셀별 차이를 줄 수 있다.

```text
cellId = floor(uv * gridCount)
local = fract(uv * gridCount)
variation = cellValue(cellId)
```

`local`은 셀마다 $[0,1)$ 범위를 반복하므로 원이나 선 같은 공통 도형의 입력으로 쓴다. `cellId`는 셀마다 다른 정수 좌표다. 예를 들어 $(2,1)$ 셀과 $(2,2)$ 셀의 중심에서 `local`은 모두 $(0.5,0.5)$지만, 두 셀의 `cellId`는 다르다. 따라서 로컬 좌표로는 공통 형태를 만들고 인덱스로는 셀을 구별할 수 있다.

## 셀 인덱스는 안정적인 주소다

`floor`로 얻은 셀 인덱스는 같은 셀 안에서 변하지 않는다. 따라서 `cellId`를 입력으로 값을 계산하면 그 셀의 모든 픽셀이 같은 변주 값을 공유한다.

```text
for each position in a cell:
    cellId = floor(position * gridCount)
    value = hash(cellId)
```

한 셀 안의 왼쪽 위와 오른쪽 아래는 같은 `cellId`를 가지므로 `value`도 같다. 이 값을 쓰면 셀 안에서 도트의 크기나 색이 일정하게 유지된다. 반대로 `local`이나 원래 `uv`를 해시에 넣으면 입력이 셀 안에서도 달라져 값이 픽셀마다 변한다. 이때 결과는 셀별 변주보다 점묘나 잡음 질감에 가까워진다.

셰이더에서 `cellId`는 흔히 `vec2` 실수형으로 저장되지만, `floor`의 결과이므로 각 성분은 정수값이다. 배열 인덱스로 사용할 때는 필요한 정수형으로 변환하고, 해시 입력을 만들 때는 `cellLocal`과 섞거나 보간하지 않는 편이 좋다. 셀 주소와 셀 내부 좌표를 분리하면 반복 구조를 읽고 조절하기 쉽다.

## 해시 함수

셰이더에서는 셀 인덱스를 입력으로 받아 $[0,1)$ 범위의 의사 난수 값을 만드는 해시 함수를 자주 쓴다.

```glsl
float hash21(vec2 p) {
    p = fract(p * vec2(123.34, 456.21));
    p += dot(p, p + 45.32);
    return fract(p.x * p.y);
}
```

해시 함수는 난수 생성기의 상태를 갱신하는 대신 입력 좌표에서 바로 값을 계산하는 결정적인 함수다. 따라서 `hash21(vec2(2.0, 1.0))`은 언제, 몇 번 호출해도 같은 결과를 돌려준다. 다른 셀 인덱스에는 대체로 다른 값이 나오지만, 해시값이 충돌해 같아질 가능성까지 없애지는 않는다.

해시값은 무작위 표본이 아니라 고정된 수식으로 계산한 의사 난수다. 인접한 셀의 값이 서로 비슷해야 한다는 조건은 없으며, 빠르게 계산되고 같은 입력에 같은 결과를 준다는 점이 반복 패턴에 유용하다. 이 값은 도형의 크기나 색을 변주하기에는 충분하지만, 암호학적 안전성이나 엄밀한 확률 분포를 보장하지 않는다.

```text
v = hash(cellId)
```

먼저 해시값을 회색조로 표시하면 셀마다 값이 일정한지 확인할 수 있다. 셀 내부가 얼룩져 보인다면 `cellId` 대신 로컬 좌표를 입력했는지 살펴본다.

```text
color = grayscale(hash(cellId))
```

## 시드로 같은 규칙의 다른 변형 만들기

같은 `cellId`에서 늘 같은 값이 나오므로 결과를 재현하기 쉽다. 다른 변주를 만들려면 고정 시드값을 해시 입력에 더한다.

```text
variation = hash(cellId + seed)
```

시드를 바꾸면 셀별 값의 배열도 달라진다. 같은 시드를 유지하는 동안에는 패턴이 프레임마다 흔들리지 않는다. 시드는 매 프레임 새 난수를 얻는 값이 아니라 반복 패턴이 사용할 변주 배열을 선택하는 값이다.

스칼라 시드를 두 좌표에 똑같이 더해도 변주를 만들 수 있다. 좌표별 이동을 다르게 주려면 두 성분으로 된 오프셋을 사용한다.

```text
seedOffset = (seedA, seedB)
variation = hash(cellId + seedOffset)
```

이 방식으로 패턴의 구조는 유지하면서 다른 판본을 만들 수 있다. 원하는 결과의 시드값을 기록하면 나중에 같은 변주를 재현할 수 있다.

## 해시값을 시각 속성으로 바꾸기

해시 함수의 출력이 $[0,1)$이면 색상 보간 비율이나 표시 확률로 바로 사용할 수 있다. 반지름, 회전, 위치처럼 단위나 범위가 다른 속성에는 먼저 적절한 값 범위로 변환한다.

```text
v = hash(cellId)

radius = mix(minRadius, maxRadius, v)
angle = v * TAU
color = palette(v)
```

`radius`는 `minRadius`와 `maxRadius` 사이에 놓이고, `angle`은 0에서 한 바퀴까지의 라디안 범위를 돈다. 코드의 `TAU`는 $2\pi$ 라디안, 즉 한 바퀴를 뜻한다. 한 바퀴 끝과 시작은 같은 방향이므로 각도는 값에 따라 순환한다. `color`는 팔레트의 입력 범위에 대응한다. 해시값을 크기에 그대로 쓰면 도형이 거의 보이지 않거나 셀 내부 좌표와 맞지 않는 크기가 될 수 있다. 해시 출력 범위와 시각 속성의 실제 단위는 구분한다.

모든 셀을 표시하지 않고 일부만 남기고 싶다면 해시값을 임계값과 비교할 수 있다.

```text
isVisible = hash(cellId) < fillProbability

if isVisible:
    drawCellPattern(local)
```

`fillProbability`는 0에서 1 사이의 임계값이다. 해시값이 $[0,1)$에 대략 고르게 분포한다면 값이 0.3일 때 셀의 약 30%가 표시된다. 0이면 아무 셀도 선택되지 않고 1이면 모든 셀이 선택된다. 셀 수가 적은 화면에서는 실제 비율이 크게 다를 수 있지만, 셀 수가 늘수록 평균적으로 임계값에 가까워진다. 이 선택도 같은 셀 인덱스와 시드에서는 시간에 따라 바뀌지 않는다.

## 하나의 값과 여러 개의 값

하나의 값을 여러 속성에 함께 연결하면 셀 간 속성에 상관관계가 생긴다. 예를 들어 값이 커질수록 도트가 커지고 팔레트의 뒤쪽 색을 선택하도록 만들 수 있다. 회전각도 같은 값에서 나오지만, 각도는 한 바퀴를 돌면 처음 방향으로 이어지므로 회전 방향이 값에 따라 계속 커지는 것은 아니다.

```text
v = hash(cellId)
radius = mix(minRadius, maxRadius, v)
color = palette(v)
angle = v * TAU
```

이런 상관관계는 여러 속성을 하나의 규칙으로 묶어 시각적 계층을 만들 때 유용하다. 예를 들어 큰 도트에 밝은 색을 연결할 수 있다. 색과 크기를 서로 덜 연관되게 바꾸려면 다른 해시 입력이나 시드를 사용한다.

```text
sizeValue = hash(cellId + seedA)
colorValue = hash(cellId + seedB)
rotationValue = hash(cellId + seedC)
```

여기서 `seedA`, `seedB`, `seedC`는 서로 다른 고정 오프셋이다. 같은 `cellId`에서도 각 속성은 보통 서로 다른 값 배열을 얻는다. 해시값이 엄밀히 독립된 난수라는 뜻은 아니다. 모든 속성을 서로 덜 연관되게 만들면 전체 패턴의 질서가 약해질 수 있으므로, 함께 변할 속성을 정한 뒤 필요한 값만 분리한다.

## 해시와 연속적인 필드의 차이

해시는 인접한 셀 사이의 연속성을 보장하지 않는다. $(2,1)$ 셀의 값이 크더라도 $(3,1)$ 셀의 값이 비슷하리라는 보장은 없다. 그래서 해시는 셀별 크기 변주, 표시 여부, 불규칙한 색 선택에 잘 맞는다.

이웃한 셀이 비슷하게 변해야 한다면 셀 인덱스를 노이즈 입력으로 쓰거나, 전역 필드 값을 셀 중심에서 표본화한다.

```text
cellCenter = (cellId + 0.5) / gridCount
variation = noise(cellCenter * fieldScale)
```

이 경우 이웃한 셀은 가까운 노이즈 입력을 사용해 값도 대체로 부드럽게 달라진다. `fieldScale`이 커지면 입력 좌표 사이의 거리가 커져 셀별 변화도 빠르게 일어난다. 해시는 셀마다 들쭉날쭉한 값을 만드는 데, 노이즈나 전역 필드는 셀 배열을 따라 이어지는 큰 흐름을 만드는 데 적합하다. 필요한 결과가 독립적인 변주인지 공간적 연속성인지 먼저 구분한다.

## 점검할 기준

셀별 변주가 의도와 다르게 보이면 도형 속성을 조절하기 전에 어떤 값을 해시에 넣었는지 확인한다.

- 해시에 `cellId`를 넣었는지, `cellLocal`이나 시간값을 넣지는 않았는지 확인한다.
- 해시값을 회색조로 표시해 셀 안에서 값이 일정한지 확인한다.
- 크기와 각도의 범위가 셀의 로컬 좌표 단위에 맞는지 확인한다.
- 속성들이 함께 변해야 하는지, 독립적으로 변해야 하는지 확인한다.
- 해시 대신 노이즈가 필요한 공간적 흐름을 기대하고 있지는 않은지 확인한다.

셀 인덱스는 반복 구조에 재현 가능한 변주를 주는 입력이다. 공통 도형은 `cellLocal`에서 계산하고 셀별 속성은 `cellId`에서 얻으면 반복을 유지하면서 각 셀에 차이를 줄 수 있다. 다음 절에서는 이런 지역 변주를 전역 규칙과 결합해 반복 구조 전체에 흐름을 만드는 방법을 다룬다.

## 이 절의 핵심

셀 인덱스는 반복 구조의 변주를 위한 안정적인 주소다. 해시나 시드 기반 값을 연결하면 셀마다 달라지면서도 재현 가능한 패턴을 만들 수 있다. 해시값은 실제 속성의 범위로 변환해 사용하고, 하나의 값이 만드는 상관관계와 여러 값이 만드는 독립성을 구분한다. 이웃 셀 사이의 연속성이 필요할 때는 해시 대신 노이즈나 전역 필드를 셀 중심에서 표본화한다.
