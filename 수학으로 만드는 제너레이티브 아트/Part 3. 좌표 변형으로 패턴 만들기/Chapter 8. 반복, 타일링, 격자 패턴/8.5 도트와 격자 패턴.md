# 8.5 도트와 격자 패턴

반복 좌표의 중심에서 거리를 계산하면 모든 셀에 같은 도트를 만들 수 있다. 이는 원 SDF를 타일 내부 좌표에 적용하는 가장 직접적인 예다.

```glsl
vec2 local = fract(uv * gridCount) - 0.5;
float d = length(local);
float dotMask = 1.0 - smoothstep(radius - edgeWidth, radius + edgeWidth, d);
```

## 도트 크기와 셀 크기

반지름은 셀 내부 좌표 범위에서 정한다. 중심 기준 좌표가 -0.5에서 0.5 사이라면 반지름 0.5는 셀 경계에 닿는다. 도트가 겹치지 않게 하려면 보통 0.5보다 작은 값을 사용한다.

```text
radius = cellSize * fillRatio
```

실제 화면 픽셀 단위의 크기가 필요하면 셀의 화면 크기와 해상도를 함께 고려해야 한다.

## 격자선

셀 경계에서의 거리를 사용하면 격자선을 만들 수 있다.

```glsl
vec2 local = fract(uv * gridCount);
float edge = min(min(local.x, 1.0 - local.x), min(local.y, 1.0 - local.y));
float gridLine = 1.0 - smoothstep(lineWidth, lineWidth + edgeWidth, edge);
```

도트와 격자선을 더하거나 보간하면 인쇄 망점, 차트 배경, 픽셀형 텍스처 같은 구조를 만들 수 있다.

## 실제 라이브러리

Canvas 2D나 p5.js에서는 중첩 반복문으로 셀 중심마다 원을 그릴 수 있다. 셰이더에서는 위처럼 각 픽셀에서 반복 좌표를 계산하므로 많은 도트를 하나의 함수로 표현할 수 있다.

## 이 절의 핵심

셀 내부의 중심 기준 좌표에 원 거리 함수를 적용하면 반복 도트를 만들 수 있다. 셀 경계까지의 거리는 격자선과 테두리를 만드는 입력이 된다.
