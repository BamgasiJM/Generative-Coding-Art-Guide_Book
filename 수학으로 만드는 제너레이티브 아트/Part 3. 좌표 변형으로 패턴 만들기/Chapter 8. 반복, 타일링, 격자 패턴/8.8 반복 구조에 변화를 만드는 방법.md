# 8.8 반복 구조에 변화를 만드는 방법

반복은 구조를 만들지만, 모든 셀이 완전히 같으면 단조롭게 보일 수 있다. 변화를 넣을 때는 반복의 공통 규칙을 유지하면서 무엇을 달리할지 선택해야 한다.

## 변화를 넣는 위치

| 바꾸는 대상 | 결과 |
| --- | --- |
| 셀 내부 도형의 크기 | 밀도와 리듬 변화 |
| 회전 | 방향성의 변주 |
| 색과 밝기 | 계층과 강조 |
| 셀 위치 | 흔들리는 격자 |
| 셀의 가로세로 비율 | 압축과 확장 |
| 반복 주기 | 큰 구조와 작은 구조의 대비 |

변화는 셀 인덱스, 전역 거리, 시간, 노이즈, 외부 데이터에서 얻을 수 있다.

```text
local = fract(uv * gridCount)
id = floor(uv * gridCount)
globalValue = length(uv - 0.5)
cellValue = hash(id)
timeValue = sin(time + id.x * phaseSpacing)
```

이 코드에서 `local`은 모든 셀이 공유하는 도형의 좌표이고, `id`는 셀의 주소다. `globalValue`는 화면 중심에서 얼마나 떨어져 있는지처럼 전체 화면을 가로지르는 값을 나타내며, `cellValue`는 각 셀에 고정된 차이를 만든다. `timeValue`는 모든 셀에 변화를 주되, `id.x`에 따라 시작 위상을 달리해 행이나 열을 따라 변화가 전파되는 것처럼 보이게 할 수 있다.

변화를 넣을 때는 먼저 "무엇을 바꿀 것인가"와 "그 변화를 어디에서 얻을 것인가"를 분리해 생각하는 편이 좋다. 예를 들어 도트의 반지름을 바꾸려는 경우, 반지름은 바뀌는 대상이고 `globalValue`, `cellValue`, `timeValue`는 그 변화를 결정하는 입력이다. 이 구분이 없으면 서로 다른 역할의 값을 한 식에 섞어 두고 나중에 결과를 조절하기 어려워진다.

## 반복의 공통 구조를 먼저 남기기

변화를 많이 넣을수록 반복은 덜 기계적으로 보이지만, 모든 셀이 서로 무관하게 바뀌면 격자라는 공통 구조도 읽기 어려워질 수 있다. 보통은 셀의 경계, 기본 도형, 기본 크기 또는 색상 체계 중 적어도 하나를 공통으로 유지하고, 일부 속성에만 변화를 주는 것이 안정적이다.

```text
local = fract(uv * gridCount) - 0.5
baseShape = circle(local, baseRadius)

cellScale = localScale(hash(id))
shape = circle(local, baseRadius * cellScale)
```

두 번째 식에서는 모든 셀이 같은 중심 좌표계와 같은 원 함수를 사용한다. 달라지는 것은 각 셀의 반지름뿐이다. 이처럼 공통 규칙을 먼저 정한 뒤 변주를 곱하거나 더하면, 변화의 원인을 추적하기 쉽고 패턴도 하나의 계열로 읽힌다.

반대로 도형의 종류, 중심 위치, 회전, 색, 셀 크기를 모두 독립적인 난수로 바꾸면 각 셀은 개별적이지만 전체 구조는 쉽게 산만해진다. 이 결과가 목표라면 유효하지만, 반복에서 출발한 리듬을 유지하고 싶다면 한두 가지 속성부터 변화시키는 편이 좋다.

## 전역 규칙과 지역 규칙 함께 쓰기

전역 거리값은 패턴 전체에 중심성이나 그라데이션을 만들고, 셀 값은 지역적인 변주를 만든다.

```text
radius = baseRadius
       * globalScale(globalValue)
       * localScale(cellValue)
```

`globalScale`은 중심에서 멀어질수록 도트를 작게 하거나 크게 하는 것처럼, 화면 전체에 걸친 큰 흐름을 만든다. `localScale`은 같은 거리대에 있는 셀도 조금씩 다르게 만들어 완전히 매끈한 규칙성을 깨뜨린다. 곱셈을 사용하면 어느 한 값이 0에 가까울 때 도트도 자연스럽게 작아지고, 기본 크기에서 비율로 조절하기 쉽다.

두 값을 각각 시각화해 보면 역할 차이가 더 잘 보인다.

```text
showGrayscale(globalScale(globalValue))
showGrayscale(localScale(cellValue))
```

첫 번째 이미지는 넓은 그라데이션이나 중심성을 보이고, 두 번째 이미지는 셀 단위의 얼룩 같은 분포를 보일 것이다. 두 결과를 곱한 뒤에야 큰 구조 안에 작은 변주가 들어간 패턴이 된다. 전역 규칙과 지역 규칙을 분리하면, 셀들이 제각각이 되지 않으면서도 전체 이미지의 흐름을 유지할 수 있다.

시간값도 같은 방식으로 더할 수 있다. 다만 매 프레임 해시를 새로 계산하는 것이 아니라, `id`에서 얻은 고정값이나 위상을 시간 함수에 더해야 각 셀의 성격이 유지된다.

```text
phase = hash(id) * TAU
pulse = 0.5 + 0.5 * sin(time * pulseSpeed + phase)
radius = baseRadius * globalScale(globalValue) * mix(minPulse, maxPulse, pulse)
```

이 코드에서 모든 셀은 같은 속도로 맥동하지만 각자 다른 시작 위상을 가진다. 시간에 따라 변해도 셀별 차이가 매 프레임 새로 바뀌지 않으므로, 깜빡임 대신 연속적인 리듬으로 읽힌다.

이 구조를 사용하면 모든 셀이 제각각이 되지 않으면서도 전체 이미지의 흐름을 유지할 수 있다.

## 반복 좌표 자체를 변형하기

도형 속성만 바꾸지 않고 셀 내부 좌표를 회전·이동·왜곡할 수도 있다.

```text
local = local - 0.5
local = rotate(local, cellValue * 2 * PI)
local += offsetFromCell(id)
value = pattern(local)
```

속성만 바꾸는 경우와 달리 좌표 자체를 바꾸면 셀 안의 도형 규칙이 변한다. `rotate`는 셀 중심을 기준으로 내부 방향을 바꾸고, `offsetFromCell(id)`는 셀마다 도형의 중심을 조금씩 이동시킨다. 이때 `local`을 먼저 `- 0.5`하여 셀 중심을 원점으로 옮겨야 회전이 각 셀의 중심을 기준으로 일어난다.

좌표 변형의 크기는 셀 내부 좌표의 범위와 함께 정한다. 예를 들어 중심 기준 로컬 좌표가 대략 $[-0.5,0.5)$일 때 큰 이동량을 더하면 도형이 셀 밖으로 나가 인접 셀의 도형과 겹치거나 경계에서 잘릴 수 있다. 겹침 자체가 표현의 일부라면 괜찮지만, 각 타일을 독립적인 단위로 보이게 하고 싶다면 오프셋과 도형 크기를 셀 여백 안에 제한해야 한다.

같은 변환을 전체 `uv`에 적용하면 배열 전체가 움직이거나 기울어지고, `local`에 적용하면 각 셀의 내부만 바뀐다. Chapter 7의 전역·로컬 변환 구분이 반복 좌표에서도 그대로 적용되는 이유다.

## 변화를 조절하는 순서

반복 구조가 의도와 다르게 보일 때는 변화값을 한꺼번에 줄이기보다, 다음 순서로 분리해 확인하는 편이 좋다.

1. `cellLocal`만 사용해 모든 셀에 같은 기본 도형을 만든다.
2. `cellId` 기반의 고정 변주 하나를 크기나 색 중 한 속성에만 연결한다.
3. `globalValue`를 더해 화면 전체의 흐름을 만든다.
4. 필요한 경우 고정 위상을 이용해 시간 변화를 추가한다.
5. 마지막에 셀 내부 좌표의 회전이나 이동 같은 변형을 더한다.

이 순서를 따르면 구조를 무너뜨리는 원인이 반복 좌표, 셀별 값, 전역 필드, 시간, 좌표 변형 중 어디에 있는지 구분하기 쉽다. 특히 셀이 너무 불규칙해 보일 때는 해시값의 범위를 줄이거나, 변화량을 기본값에 곱하는 비율로 바꾸는 것부터 시도할 수 있다.

이 방식은 Chapter 7의 변환과 Chapter 8의 반복을 결합한 것이다. 다음 장의 극좌표와 Chapter 10의 대칭도 같은 방식으로 반복 좌표에 적용할 수 있다.

## Chapter 8의 마무리

반복 좌표는 공간을 셀 내부 좌표와 셀 인덱스로 나눈다. `fract`와 `floor`를 사용하면 스트라이프, 체커보드, 도트, 격자, 벽돌 패턴을 만들고, 셀 인덱스로 각 반복 단위에 변주를 줄 수 있다.

Chapter 8의 좌표 흐름은 다음처럼 요약할 수 있다.

```text
gridPosition = uv * gridCount
cellId = floor(gridPosition)
cellLocal = fract(gridPosition)

localShape = pattern(cellLocal)
cellVariation = valueFrom(cellId)
result = combine(localShape, cellVariation, globalValue)
```

`cellLocal`은 모든 셀에서 반복되는 공통 구조를 만들고, `cellId`는 반복 단위마다 다른 값을 만들며, `globalValue`는 셀들을 하나의 전체 화면 구성으로 묶는다. 이 세 역할을 분리하면 규칙적인 격자부터 부분적으로 흔들리는 타일, 중심성을 가진 도트 패턴까지 같은 좌표 구조에서 발전시킬 수 있다.

반복은 단순히 같은 도형을 많이 그리는 방법이 아니다. 넓은 공간을 작은 로컬 좌표계들의 배열로 나누고, 각 로컬 규칙과 셀 주소를 조합하는 방법이다. 이후의 좌표 변환, 노이즈, 시간 함수도 이 셀 내부 좌표 또는 셀 인덱스 중 어디에 적용하는지에 따라 전혀 다른 패턴을 만들게 된다.

다음 장에서는 데카르트 좌표를 거리와 각도로 바꾸어 동심원, 방사형 선, 나선, 만다라 같은 패턴을 만드는 방법을 다룬다.
