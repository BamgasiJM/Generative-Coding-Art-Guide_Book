# 8.8 반복 구조에 변화를 만드는 방법

반복은 구조를 만들지만 모든 셀이 같으면 단조롭게 보일 수 있다. 변화를 더할 때는 먼저 어떤 속성을 바꿀지 정하고, 반복의 공통 규칙은 어디까지 유지할지 결정한다.

## 변화를 넣는 위치

| 바꾸는 대상 | 결과 |
| --- | --- |
| 셀 내부 도형의 크기 | 밀도와 리듬 변화 |
| 회전 | 방향성의 변주 |
| 색과 밝기 | 계층과 강조 |
| 셀 위치 | 흔들리는 격자 |
| 셀의 가로세로 비율 | 압축과 확장 |
| 반복 주기 | 큰 구조와 작은 구조의 대비 |

변화는 셀 인덱스, 전역 거리, 시간, 노이즈, 외부 데이터에서 얻을 수 있다.

```text
local = fract(uv * gridCount)
id = floor(uv * gridCount)
globalValue = length(uv - 0.5)
cellValue = hash(id)
timeValue = sin(time + id.x * phaseSpacing)
```

이 코드에서 `local`은 각 셀의 도형을 계산하는 내부 좌표이고, `id`는 셀의 주소다. `globalValue`는 화면 중심에서의 거리처럼 전체 화면에 걸친 값을 나타내며, `cellValue`는 셀마다 고정된 차이를 만든다. `timeValue`는 시간에 따라 변하는 값이다. 예시에서는 `id.x`에 따라 위상이 달라지므로 같은 행에서 열마다 변화 시점이 다르다. 행마다 위상을 달리하려면 `id.y`를 사용할 수 있다.

변화의 대상과 값을 제공하는 입력은 구분해서 설계한다. 도트의 반지름을 바꾼다면 반지름이 대상이고 `globalValue`, `cellValue`, `timeValue`는 반지름을 정하는 입력이다. 역할을 나누면 각 입력이 결과에 미치는 영향을 따로 조절할 수 있다.

## 반복의 공통 구조를 먼저 남기기

변화를 많이 넣으면 반복이 덜 기계적으로 보일 수 있지만, 모든 셀이 서로 무관하게 달라지면 격자의 공통 구조를 알아보기 어렵다. 셀 경계, 기본 도형, 기본 크기, 색상 체계 중 하나 이상은 공통으로 두고 일부 속성에만 변화를 주면 반복의 질서를 유지하기 쉽다.

```text
local = fract(uv * gridCount) - 0.5
baseShape = circle(local, baseRadius)

cellScale = localScale(hash(id))
shape = circle(local, baseRadius * cellScale)
```

두 번째 식에서도 모든 셀은 같은 중심 좌표계와 원 함수를 사용한다. 달라지는 속성은 각 셀의 반지름뿐이다. 먼저 공통 규칙을 정한 뒤 변주를 곱하거나 더하면 변화의 원인을 추적하기 쉽고 결과도 하나의 패턴 계열로 읽힌다.

도형의 종류, 중심 위치, 회전, 색, 셀 크기를 모두 서로 관련 없이 바꾸면 각 셀은 개별적으로 보이지만 전체 구조는 산만해질 수 있다. 그런 결과가 목표라면 사용할 수 있지만, 반복의 리듬을 유지하려면 한두 가지 속성부터 바꾸는 편이 좋다.

## 전역 규칙과 지역 규칙 함께 쓰기

전역 거리값은 패턴 전체에 중심성이나 그라데이션을 만들고, 셀 값은 지역적인 변주를 만든다.

```text
radius = baseRadius
       * globalScale(globalValue)
       * localScale(cellValue)
```

`globalScale`은 중심에서 멀어질수록 도트를 작게 하거나 크게 하는 등 화면 전체에 걸친 흐름을 만든다. `localScale`은 같은 거리대의 셀에도 차이를 주어 규칙성을 완화한다. 두 값은 기본 크기에 곱하는 배율이므로, 결과가 의도한 크기 범위에 들도록 각 함수의 출력 범위를 정한다. 어느 한 배율이 0에 가까우면 도트도 작아진다.

두 값을 각각 시각화해 보면 역할 차이가 더 잘 보인다.

```text
showGrayscale(globalScale(globalValue))
showGrayscale(localScale(cellValue))
```

첫 번째 이미지는 넓은 그라데이션이나 중심성을, 두 번째 이미지는 셀 단위의 변주를 보여 준다. 두 값을 곱하면 큰 흐름 안에 작은 변주가 들어간다. 이처럼 전역 규칙과 지역 규칙을 분리하면 셀별 차이를 주면서 화면 전체의 흐름도 유지할 수 있다.

시간에 따른 변화도 이 구조에 더할 수 있다. 매 프레임 새로운 해시값을 만들면 셀의 성격이 계속 바뀌어 깜빡인다. `id`에서 얻은 고정 위상을 시간 함수에 더하면 셀별 차이는 유지한 채 부드럽게 움직인다.

```text
phase = hash(id) * TAU
pulse = 0.5 + 0.5 * sin(time * pulseSpeed + phase)
radius = baseRadius * globalScale(globalValue) * mix(minPulse, maxPulse, pulse)
```

모든 셀은 같은 속도로 맥동하고 시작 위상만 다르다. 따라서 시간에 따라 크기가 변해도 셀별 성격은 유지되며 깜빡임 대신 연속적인 리듬으로 보인다.

크기나 색의 값만 바꾸는 것으로 충분하지 않다면 셀 내부 좌표 자체를 변형할 수 있다.

## 반복 좌표 자체를 변형하기

도형 속성만 바꾸지 않고 셀 내부 좌표를 회전·이동·왜곡할 수도 있다.

```text
local = local - 0.5
local = rotate(local, cellValue * 2 * PI)
local += offsetFromCell(id)
value = pattern(local)
```

속성값만 바꾸는 것과 달리 좌표를 변형하면 셀 안에서 도형의 위치와 방향이 달라진다. `local`에서 0.5를 빼면 셀 중심이 원점에 놓이므로 `rotate`가 각 셀의 중심을 기준으로 작동한다. `cellValue`가 $[0,1)$이면 `cellValue * 2 * PI`는 한 바퀴 범위의 회전각을 만든다. `offsetFromCell(id)`는 셀 주소에 따라 도형의 중심을 이동시킨다.

좌표 변형의 크기는 셀 내부 좌표의 범위를 기준으로 정한다. 중심 기준 좌표가 $[-0.5,0.5)$일 때 이동량이 크면 도형이 셀 경계를 넘어 이웃 셀의 영역과 겹치거나 경계에서 잘릴 수 있다. 겹침을 의도한 효과로 쓸 수도 있지만, 각 타일을 독립적으로 보이게 하려면 도형 크기와 오프셋을 셀 안의 여백에 맞춘다.

같은 변환을 전체 `uv`에 적용하면 배열 전체가 움직이거나 기울어진다. `local`에 적용하면 배열은 그대로 두고 각 셀 내부만 바뀐다. Chapter 7에서 다룬 전역·로컬 변환의 구분이 반복 좌표에도 적용된다.

## 변화를 조절하는 순서

반복 구조가 의도와 다르게 보이면 변화를 한꺼번에 조절하지 말고 다음 순서로 하나씩 확인한다.

1. `cellLocal`만 사용해 모든 셀에 같은 기본 도형을 만든다.
2. `cellId` 기반의 고정 변주 하나를 크기나 색 중 한 속성에만 연결한다.
3. `globalValue`를 더해 화면 전체의 흐름을 만든다.
4. 필요한 경우 고정 위상을 이용해 시간 변화를 추가한다.
5. 마지막에 셀 내부 좌표의 회전이나 이동 같은 변형을 더한다.

이 순서를 따르면 원인이 반복 좌표, 셀별 값, 전역 필드, 시간, 좌표 변형 중 어디에 있는지 찾기 쉽다. 셀이 지나치게 불규칙해 보이면 해시값이 만드는 범위를 줄이거나 변화량을 기본값에 곱하는 배율로 조절한다.

이 순서는 Chapter 7의 좌표 변환과 Chapter 8의 반복을 결합한다. 다음 장의 극좌표와 Chapter 10의 대칭에도 같은 원리를 적용할 수 있다.

## Chapter 8의 마무리

반복 좌표는 공간을 셀 내부 좌표와 셀 인덱스로 나눈다. `fract`는 셀 안의 위치를, `floor`는 셀의 주소를 만든다. 이 둘을 사용해 스트라이프, 체커보드, 도트, 격자, 벽돌 패턴을 구성하고 셀마다 변주를 줄 수 있다.

Chapter 8의 좌표 흐름은 다음처럼 요약할 수 있다.

```text
gridPosition = uv * gridCount
cellId = floor(gridPosition)
cellLocal = fract(gridPosition)

localShape = pattern(cellLocal)
cellVariation = valueFrom(cellId)
result = combine(localShape, cellVariation, globalValue)
```

`cellLocal`은 모든 셀에 공통된 형태를 만들고, `cellId`는 셀별 값을 정하며, `globalValue`는 각 셀을 화면 전체의 구성에 연결한다. 세 역할을 분리하면 규칙적인 격자에 셀별 변주를 더하거나, 일부 타일을 흔들고 화면 중심을 강조하는 도트 패턴으로 발전시킬 수 있다.

반복은 같은 도형을 많이 그리는 데 그치지 않는다. 넓은 공간을 작은 로컬 좌표계의 배열로 나누고, 각 셀의 규칙과 주소를 조합하는 방식이다. 좌표 변환, 노이즈, 시간 함수도 `cellLocal`과 `cellId` 중 어디에 적용하는지에 따라 서로 다른 패턴을 만든다.

다음 장에서는 데카르트 좌표를 거리와 각도로 바꾸어 동심원, 방사형 선, 나선, 만다라 같은 패턴을 만드는 방법을 다룬다.
