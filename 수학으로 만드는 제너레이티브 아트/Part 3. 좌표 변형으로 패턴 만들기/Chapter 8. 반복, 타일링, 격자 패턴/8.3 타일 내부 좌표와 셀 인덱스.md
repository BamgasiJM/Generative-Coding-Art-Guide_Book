# 8.3 타일 내부 좌표와 셀 인덱스

반복 좌표는 한 셀 안의 위치를 알려 주지만, 어느 셀인지 알려 주지는 않는다. 전체 좌표를 격자 크기로 곱한 뒤 정수 부분과 소수 부분을 분리하면 셀 인덱스와 셀 내부 좌표를 동시에 얻을 수 있다.

$$
\mathbf{g}=\mathbf{uv}\,\mathbf{n}
$$

$$
\mathbf{id}=\lfloor\mathbf{g}\rfloor,\qquad \mathbf{local}=\operatorname{fract}(\mathbf{g})
$$

예를 들어 가로·세로에 각각 4개의 셀이 있고, $\mathbf{uv}=(0.62,0.31)$이라고 하자. 이때 $\mathbf{g}=(2.48,1.24)$가 된다. `floor`를 적용한 $\mathbf{id}=(2,1)$은 가로 세 번째, 세로 두 번째 셀을 뜻하고, `fract`를 적용한 $\mathbf{local}=(0.48,0.24)$는 그 셀 안에서의 상대 위치를 뜻한다. 하나의 화면 위치를 "어느 셀인가"와 "그 셀 안의 어디인가"라는 두 정보로 나누어 읽는 셈이다.

```glsl
vec2 gridPosition = uv * gridCount;
vec2 cellId = floor(gridPosition);
vec2 cellLocal = fract(gridPosition);
```

`cellId`는 셀마다 고유한 정수 좌표이고, `cellLocal`은 모든 셀에서 반복되는 0에서 1 사이의 좌표다.

`cellLocal`만 남기면 $(0,0)$ 셀의 중앙과 $(5,3)$ 셀의 중앙은 모두 같은 좌표 $(0.5,0.5)$가 된다. 따라서 표준 원이나 선 같은 공통 도형을 반복하기에는 적합하지만, 두 셀을 서로 다르게 다룰 근거는 사라진다. 반대로 `cellId`만 있으면 셀이 어느 위치에 있는지는 알 수 있지만, 셀 안에서 원의 경계나 선의 모양을 계산할 수 없다. 두 값은 같은 원래 좌표에서 나오지만 서로 다른 질문에 답한다.

## 역할 분리

셀 내부 좌표는 도형의 모양을 정의하고, 셀 인덱스는 셀마다 다른 색·회전·크기를 정하는 입력이 된다.

```text
shape = circle(cellLocal - 0.5)
variation = hash(cellId)
color = palette(variation)
```

같은 원을 반복하면서도 셀마다 다른 변주를 만들 수 있다. 이 구조는 Chapter 11의 시드 기반 랜덤과도 연결된다.

이 예에서 `circle(cellLocal - 0.5)`는 모든 셀에서 같은 원을 계산한다. `hash(cellId)`는 셀 주소를 입력으로 받아 셀마다 고정된 값을 만든다. 중요한 점은 `variation`이 프레임마다 새로 바뀌는 난수가 아니라, 같은 `cellId`에서는 항상 같은 값이라는 것이다. 따라서 반복의 공통 구조는 유지하면서도 각 셀의 색이나 크기에 안정적인 차이를 줄 수 있다.

## 셀 중심과 실제 위치

셀 중심의 전체 좌표가 필요하면 셀 인덱스에 0.5를 더한 뒤 격자 크기로 나눈다.

```text
cellCenterUV = (cellId + 0.5) / gridCount
```

`cellLocal`은 셀 안의 상대 위치이므로, 서로 다른 셀의 중심 사이 거리나 화면 전체를 가로지르는 그라디언트에는 직접 사용할 수 없다. `cellCenterUV`는 다시 전체 $[0,1]$ UV 공간에 놓인 좌표다. 그래서 중심에서 가까운 셀일수록 다른 색을 주거나, 화면의 한쪽에서 다른 쪽으로 셀 크기를 바꾸는 전역 규칙과 연결할 수 있다.

예를 들어 화면 중심에서 각 셀 중심까지의 거리는 다음처럼 계산할 수 있다.

```text
distanceFromScreenCenter = length(cellCenterUV - 0.5)
```

이 값은 원을 그리는 셀 내부 좌표와는 별개로, 각 셀이 전체 배열에서 어느 위치에 놓였는지를 나타낸다.

이 값은 셀 사이의 관계, 거리장, 다른 전역 패턴과 연결할 때 유용하다.

셀 인덱스는 보통 정수처럼 다루지만 셰이더에서는 `vec2` 실수로 표현되는 경우가 많다. 해시나 짝홀 계산 전에 `floor` 결과를 유지하고, 셀 내부 좌표와 섞지 않는 편이 좋다. 하나는 반복되는 도형의 좌표이고, 다른 하나는 반복 단위의 주소다.

정규화 UV의 끝값 $1$은 이론적으로 `gridCount`에 해당해 마지막 셀 다음의 인덱스로 해석될 수 있다. 실제 픽셀 중심을 표본화하는 대부분의 상황에서는 정확히 1에 닿는 경우가 드물지만, 경계 값을 직접 계산하거나 격자 인덱스를 배열 접근에 사용할 때는 범위를 확인해야 한다. 필요한 경우 인덱스를 $0$부터 `gridCount - 1` 사이로 제한하거나, UV의 상한을 아주 조금 낮춰 경계를 처리한다.

## 이 절의 핵심

`floor`는 셀 인덱스를, `fract`는 셀 내부 좌표를 만든다. 이 둘을 분리하면 반복되는 공통 구조와 셀마다 달라지는 변주를 함께 설계할 수 있다.
