# 8.3 타일 내부 좌표와 셀 인덱스

`cellLocal`처럼 반복 좌표만 남기면 한 점이 어느 셀에 속하는지 알 수 없다. 전체 좌표를 격자 크기에 맞춰 늘린 뒤 정수 부분과 소수 부분을 나누면 셀의 인덱스와 셀 안의 상대 위치를 함께 얻는다.

$$
\mathbf{g}=\mathbf{uv}\,\mathbf{n}
$$

$$
\mathbf{id}=\lfloor\mathbf{g}\rfloor,\qquad \mathbf{local}=\operatorname{fract}(\mathbf{g})
$$

여기서 $\mathbf{uv}$는 정규화된 화면 좌표이고, $\mathbf{n}$은 가로와 세로의 셀 개수다. 곱은 각 축의 성분끼리 계산한다. 예를 들어 두 축에 각각 4개의 셀이 있고 $\mathbf{uv}=(0.62,0.31)$이면 $\mathbf{g}=(2.48,1.24)$다. `floor`를 적용한 $\mathbf{id}=(2,1)$은 가로 세 번째, 세로 두 번째 셀을 가리킨다. `fract`를 적용한 $\mathbf{local}=(0.48,0.24)$는 그 셀 안에서의 상대 위치다. 이렇게 한 화면 위치를 “어느 셀인가”와 “그 셀 안의 어디인가”라는 두 정보로 나눠 읽는다.

```glsl
vec2 gridPosition = uv * gridCount;
vec2 cellId = floor(gridPosition);
vec2 cellLocal = fract(gridPosition);
```

코드의 `gridCount`는 수식의 $\mathbf{n}$에 해당한다. `cellId`는 셀마다 고유한 정수 좌표이고, `cellLocal`은 각 셀에서 반복되는 $[0,1)$ 범위의 좌표다.

`cellLocal`만 보면 $(0,0)$ 셀과 $(5,3)$ 셀의 중심은 모두 $(0.5,0.5)$다. 같은 로컬 좌표가 모든 셀에서 반복되기 때문에 `cellLocal`만으로는 셀을 서로 구별할 수 없다. 대신 원이나 선 같은 도형을 모든 셀에 같은 모양으로 반복하는 데 적합하다. 반대로 `cellId`는 셀의 위치를 알려 주지만 셀 안에서 원의 경계나 선의 모양을 계산하지는 못한다. 두 값은 같은 좌표에서 만들어지지만 서로 다른 정보를 담는다.

## 역할 분리

셀 내부 좌표로 각 셀의 도형 모양을 계산하고, 셀 인덱스를 입력으로 삼아 셀마다 색·회전·크기를 달리할 수 있다.

```text
shape = circle(cellLocal - 0.5)
variation = hash(cellId)
color = palette(variation)
```

로컬 좌표로 공통 형태를 유지하고 셀 인덱스로 변주를 정하는 방식은 Chapter 11의 시드 기반 랜덤과도 연결된다.

`cellLocal - 0.5`는 셀 내부 좌표의 범위를 중심 기준 $[-0.5,0.5)$로 옮긴다. 따라서 `circle(cellLocal - 0.5)`는 각 셀의 중심을 기준으로 같은 원을 계산한다. `hash(cellId)`는 셀 주소를 입력으로 받아 셀마다 값을 만든다. 같은 `cellId`에서는 프레임이 달라져도 같은 값이 나오므로 `variation`은 시간에 따라 흔들리는 난수가 아니다. 이 값을 색이나 크기에 연결하면 공통된 반복 구조를 유지하면서 셀마다 안정적인 차이를 줄 수 있다.

## 셀 중심과 실제 위치

셀 중심의 전체 좌표가 필요하면 셀 인덱스에 0.5를 더해 셀 중심의 격자 좌표를 구하고, 이를 격자 크기로 나눈다.

```text
cellCenterUV = (cellId + 0.5) / gridCount
```

`cellLocal`은 셀 안의 상대 위치라 서로 다른 셀 중심 사이의 거리나 화면 전체를 가로지르는 그라디언트를 표현하지 못한다. `cellCenterUV`는 전체 $[0,1]$ UV 공간의 좌표이므로, 화면 중심에서의 거리나 화면을 가로지르는 전역 규칙에 연결할 수 있다. 예를 들어 중심에 가까운 셀의 색을 바꾸거나 화면 위치에 따라 셀 크기를 조정할 수 있다.

예를 들어 화면 중심에서 각 셀 중심까지의 거리는 다음처럼 계산할 수 있다.

```text
distanceFromScreenCenter = length(cellCenterUV - 0.5)
```

이 거리는 정규화된 UV 공간에서 계산한 거리다. 도형을 정의하는 셀 내부 좌표와 구별되며 셀 배열 전체에 적용하는 거리장이나 전역 패턴에 사용할 수 있다. 픽셀 기준의 실제 거리가 필요하면 화면 종횡비를 보정해야 한다.

셀 인덱스는 정수 좌표지만 셰이더에서는 `vec2` 실수형으로 저장되는 경우가 많다. 해시나 짝홀 계산에는 `floor`로 얻은 셀 인덱스를 사용하고, 셀 내부 좌표와 섞지 않는 편이 좋다. `cellLocal`은 반복 도형의 위치를, `cellId`는 반복 단위의 주소를 나타낸다.

각 축의 정규화 UV가 정확히 $1$이면 그 축의 곱한 값은 `gridCount`가 되고, `cellId`는 마지막 셀 다음의 인덱스를 가리키며 `cellLocal`은 0으로 돌아간다. 픽셀 중심을 표본화하면 정확히 1에 닿는 경우가 드물지만, 경계 좌표를 직접 계산하거나 인덱스로 배열에 접근할 때는 범위를 확인해야 한다. 배열 주소만 유효하게 만들려면 인덱스를 $0$부터 `gridCount - 1` 사이로 제한할 수 있다. 경계 좌표 자체를 마지막 셀 안에 두려면 UV의 상한을 1보다 조금 작게 제한한다.

## 이 절의 핵심

`floor`는 셀 인덱스를, `fract`는 셀 내부 좌표를 만든다. 이 둘을 분리하면 반복되는 공통 구조와 셀마다 달라지는 변주를 함께 설계할 수 있다.
