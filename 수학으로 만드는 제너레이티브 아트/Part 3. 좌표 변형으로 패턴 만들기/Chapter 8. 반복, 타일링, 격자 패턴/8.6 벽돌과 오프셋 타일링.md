# 8.6 벽돌과 오프셋 타일링

벽돌 패턴은 모든 행이 같은 x좌표에서 시작하는 격자와 달리, 한 행씩 가로로 어긋난 반복 구조다. 행 인덱스의 짝홀 여부에 따라 x좌표에 오프셋을 더하면 만들 수 있다.

```glsl
vec2 grid = uv * gridCount;
float row = floor(grid.y);
grid.x += 0.5 * mod(row, 2.0);

vec2 local = fract(grid);
vec2 cellId = floor(grid);
```

짝수 행은 그대로 두고 홀수 행만 반 셀만큼 이동한다. 이 오프셋은 `fract`로 셀 내부 좌표를 구하기 전에 적용해야 반복 경계가 함께 이동한다.

## 타일의 가로세로 비율

벽돌은 보통 가로가 세로보다 길다. 타일 좌표의 한 축에 배율을 적용해 비율을 바꿀 수 있다.

```text
gridPosition = uv * (columnCount, rowCount)
```

도형을 셀 내부에서 정의할 때는 실제 셀의 화면 비율을 고려해야 원과 둥근 모서리가 늘어나지 않는다.

## 경계와 모르타르

셀 내부 좌표에서 각 변까지의 거리를 구하면 타일 사이의 빈 공간이나 모르타르 선을 만들 수 있다.

```glsl
float edge = min(min(local.x, 1.0 - local.x), min(local.y, 1.0 - local.y));
float tileMask = smoothstep(gapWidth, gapWidth + edgeWidth, edge);
```

`tileMask`가 1인 곳에만 타일 색과 질감을 적용하면 셀 경계가 남는다.

## 이 절의 핵심

행 또는 열 인덱스에 따른 오프셋을 반복 좌표 계산 전에 적용하면 벽돌, 육각형에 가까운 배열, 엇갈린 패턴을 만들 수 있다. 반복 구조의 규칙을 바꾸는 가장 단순한 방법 중 하나다.
