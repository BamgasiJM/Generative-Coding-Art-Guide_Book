# 14.8 시간과 사용자 입력 연결하기

시간은 자동으로 흐르는 입력이고, 마우스·터치·키보드·오디오·센서는 외부에서 들어오는 입력이다. 둘을 연결하면 관람객이 변화의 속도나 방향, 시작 조건에 개입하는 시스템을 만들 수 있다.

```text
targetSpeed = map(pointerX, 0, width, 0, maxSpeed)
speed = lerp(speed, targetSpeed, response)
phase += speed * deltaTime
```

입력을 값에 바로 연결하면 즉각적이지만 흔들릴 수 있다. 위 예제처럼 목표값과 현재값 사이를 보간하면 관람객의 움직임이 부드럽게 번역된다. 입력 범위를 정규화하고, 화면 비율이나 장치 해상도에 독립적인 단위로 바꾸는 과정도 필요하다.

사용자 입력은 시간 자체를 멈추거나 되감는 제어로도 쓸 수 있다. 다만 상태 기반 시뮬레이션을 되감으려면 과거 상태를 저장해야 한다. 시간 함수만으로 만든 장면은 임의의 $t$를 바로 평가할 수 있으므로, 스크러빙과 반복 재생에 특히 유리하다.

상호작용에는 기본 상태가 필요하다. 입력이 없을 때도 화면이 의미 있게 보이는지, 입력이 극단값일 때 파라미터가 안정적인 범위를 지키는지 확인한다.

## 이 절의 핵심

사용자 입력은 시간 함수의 속도, 위상, 진폭, 시작 조건을 조절할 수 있다. 원시 입력을 정규화하고 완화해 읽기 좋은 반응으로 바꾼다.
