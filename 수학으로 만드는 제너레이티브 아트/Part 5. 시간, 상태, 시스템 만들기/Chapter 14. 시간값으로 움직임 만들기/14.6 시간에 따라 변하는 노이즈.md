# 14.6 시간에 따라 변하는 노이즈

시간에 비례한 값을 입력 좌표에 더하거나 시간을 별도 차원으로 넣으면 노이즈를 움직일 수 있다. 핵심은 매 프레임 새로운 값을 뽑는 것이 아니라, 시간상 가까운 순간에 서로 비슷한 값을 내는 연속 함수를 평가하는 데 있다. 프레임마다 시드를 바꾸면 연속 노이즈 대신 값이 깜빡이는 난수가 만들어진다.

정적인 노이즈는 공간의 각 위치에 값을 대응시킨 필드다. 시간 기반 노이즈는 여기에 시간까지 입력으로 받아 위치와 시각의 조합마다 값을 정한다. 화면의 한 프레임은 이 높은 차원의 필드에서 특정 시각의 단면을 보는 결과다. 시간이 조금 달라지면 장면도 변하지만, 인접한 프레임의 변화는 이어져 보인다.

## 시간축을 가진 노이즈

2차원 위치 $(x,y)$와 시간 $t$를 입력으로 받는 3차원 노이즈를 생각해 보자.

$$
n_t(x,y)=n(x,y,t\omega_t)
$$

여기서 $\omega_t$는 노이즈의 시간 좌표에 곱하는 배율이다. 값이 작으면 시간 좌표가 천천히 변해 질감도 느리게 바뀌고, 값이 크면 변화가 빨라진다.

```text
value = noise(
    x * spatialFrequency,
    y * spatialFrequency,
    time * temporalFrequency
)
```

`spatialFrequency`와 `temporalFrequency`는 서로 다른 값을 조절한다. 전자는 화면에 무늬가 얼마나 촘촘하게 나타날지를, 후자는 그 무늬가 시간에 따라 얼마나 빨리 변할지를 정한다. 세밀한 무늬가 천천히 움직일 수도 있고, 큰 얼룩이 빠르게 변할 수도 있다.

$$
n_t(x,y)=n(ax,ay,bt)
$$

이 식에서 $a$는 공간 주파수, $b$는 시간 주파수다. 두 값을 하나의 `noiseSpeed`에 묶지 않는 편이 좋다. 작업 중에 "무늬는 더 크게, 움직임은 그대로" 또는 "무늬 크기는 유지하고 변화만 느리게" 조절할 수 있기 때문이다.

## 프레임마다 랜덤을 다시 뽑으면 왜 깜빡이는가

다음 코드는 매 프레임 새로운 난수를 사용한다.

```text
for each point:
    offset = random(-amount, amount)
    drawPoint(point.position + offset)
```

시간 $t$와 이전 프레임의 값 사이에 관계가 없으므로, 점은 연속적으로 움직이지 않고 매 프레임 다른 위치로 순간 이동한다. 글리치나 점멸을 의도할 때는 쓸 수 있지만, 구름이나 액체, 유기적인 흔들림에는 대개 맞지 않는다.

반면 좌표와 시간에서 노이즈를 평가하면 같은 점은 가까운 시간에 가까운 값을 얻는다.

```text
for each point:
    offsetX = noise(point.id, 0, time * temporalFrequency)
    offsetY = noise(point.id, 1, time * temporalFrequency)
    drawPoint(point.position + (offsetX, offsetY) * amount)
```

`point.id`처럼 점마다 고정된 입력을 사용하면 모든 점이 같은 방향으로 흔들리는 일을 줄이고, 각자 연속적으로 변하게 할 수 있다. 두 좌표에 같은 노이즈 값을 쓰면 점들이 한 대각선 방향으로만 움직일 수 있으므로 서로 다른 상수나 표본 좌표를 사용한다.

## 3차원 노이즈와 좌표 이동 노이즈

시간에 따라 노이즈를 바꾸는 방법은 크게 두 가지다. 노이즈 함수의 세 번째 차원에 시간을 넣거나, 2차원 노이즈의 입력 좌표를 일정한 방향으로 이동시킨다.

### 시간 차원을 추가하는 방법

```text
value = noise(x * scale, y * scale, time * speed)
```

이 방식은 시간축을 따라 노이즈의 단면을 바꾼다. 질감이 한 방향으로 흐르기보다 얼룩이 자라거나 갈라지고 합쳐지는 듯 보일 수 있다. 3차원 Perlin noise, Simplex noise, OpenSimplex 계열처럼 다차원 입력을 지원하는 함수에 적용할 수 있다.

### 좌표를 이동하는 방법

3차원 노이즈를 지원하지 않는 환경에서는 2차원 입력을 시간에 따라 일정 방향으로 옮길 수 있다.

$$
n_t(x,y)=n(x+v_x t,y+v_y t)
$$

```text
q.x = x * scale + time * velocity.x
q.y = y * scale + time * velocity.y
value = noise(q.x, q.y)
```

이 방식은 카메라가 고정된 노이즈 지형 위를 지나는 것과 비슷하다. 흐르는 구름이나 연기, 바람에 밀리는 질감, 옆으로 움직이는 물결에 잘 맞는다. 이동 방향은 기본적으로 일정하므로, 질감 자체가 변하기보다 기존 패턴이 흐르는 인상이 강하다.

두 방식을 결합할 수도 있다. 큰 흐름에는 좌표 이동을 적용하고, 작은 세부에는 시간 차원을 넣으면 구조가 움직이면서 표면도 살아 움직이는 듯 보인다.

```text
drifted = p * largeScale + flowDirection * time * driftSpeed
large = noise(drifted.x, drifted.y)
detail = noise(p.x * detailScale, p.y * detailScale, time * detailSpeed)
value = large * 0.75 + detail * 0.25
```

## 시간 노이즈를 시각 속성에 연결하기

시간 노이즈는 색, 크기, 위치, 회전, 투명도, 밀도, 좌표 변위 등 다양한 속성에 연결할 수 있다. 같은 노이즈도 어떤 속성에 연결하는지에 따라 움직임이 달라진다.

```text
n = noise(p.x * scale, p.y * scale, time * speed)

brightness = mix(dark, light, n)
radius = mix(minRadius, maxRadius, n)
angle = n * maxAngle
offset = (n - 0.5) * displacementAmount
```

노이즈 함수가 $[0,1]$ 범위를 반환한다고 하면 `n - 0.5`는 $[-0.5,0.5]$ 범위의 중심이 0인 값을 만든다. 위치를 변위하려면 방향도 정해야 한다. 하나의 스칼라 노이즈를 $x$, $y$에 똑같이 더하기보다 서로 다른 표본을 쓰거나, 13장에서 다룬 벡터 필드로 방향과 크기를 나누는 편이 자연스럽다.

$$
\mathbf{d}(\mathbf{p},t)=
\begin{pmatrix}
n_1(\mathbf{p},t)-0.5\\
n_2(\mathbf{p},t)-0.5
\end{pmatrix}
$$

```text
dx = noise(p.x * scale, p.y * scale, time * speed)
dy = noise(p.x * scale + 31.7, p.y * scale - 12.4, time * speed)
offset = (dx - 0.5, dy - 0.5) * displacementAmount
```

## 부드러움, 세부, 깜빡임

시간 노이즈가 연속적이어도 화면에서는 거칠거나 깜빡이는 것처럼 보일 수 있다. 시간 변화가 너무 빠르거나 공간 세부가 픽셀 해상도에 비해 지나치게 작거나, 변위 진폭이 큰 경우에 이런 현상이 나타난다.

작은 점이나 얇은 선을 빠르게 변위하면 한 프레임 사이에 여러 픽셀을 건너뛸 수 있다. 이때는 연속적인 움직임보다 떨림이 두드러진다. 다음과 같은 방법으로 완화할 수 있다.

- `temporalFrequency`를 낮춰 시간 변화를 늦춘다.
- 높은 옥타브의 노이즈 비중을 줄여 미세한 변화량을 제한한다.
- 좌표 변위의 `displacementAmount`를 줄인다.
- 작은 도형에는 위치 대신 색, 크기, 투명도의 미세한 변화로 노이즈를 연결한다.
- 고해상도 렌더링 후 축소하거나, 환경이 제공한다면 적절한 필터링을 사용한다.

특히 fBm처럼 여러 옥타브를 합친 노이즈는 고주파 성분이 시간축에도 영향을 준다. 정지 화면에서 아름다운 질감도 애니메이션에서는 빠르게 흔들릴 수 있다. 움직이는 질감에는 옥타브 수를 줄이거나 높은 옥타브의 진폭을 더 많이 낮추는 편이 안정적이다.

## 시간에 따라 변하는 필드와 흐름

시간 노이즈는 색을 바꾸는 질감에만 쓰이지 않는다. 노이즈를 높이 필드로 해석하면 지형이 시간에 따라 변하고, 그래디언트를 구하면 방향장도 함께 바뀐다.

$$
h(\mathbf{p},t)=\operatorname{noise}(ax,ay,bt)
$$

$$
\mathbf{v}(\mathbf{p},t)=
\operatorname{rotate90}\left(
\frac{\nabla h(\mathbf{p},t)}{\|\nabla h(\mathbf{p},t)\|}
\right)
$$

입자를 $\mathbf{v}(\mathbf{p},t)$ 방향으로 이동시키면 고정된 흐름 필드와 달리 시간에 따라 흐름 경로가 바뀐다. 필드가 입자의 이동에 비해 너무 빠르게 변하면 궤적이 불안정하게 꺾일 수 있다. 입자가 움직이는 동안 필드가 크게 바뀌지 않도록 시간 변화율을 낮게 설정하는 편이 좋다.

```text
height = noise(p.x * fieldScale, p.y * fieldScale, time * fieldSpeed)
direction = tangentOfGradient(heightField, p, time)
particle.position += direction * particleSpeed * deltaTime
```

이 예의 `height`는 설명을 위한 값이다. 실제 `tangentOfGradient`는 주변 위치에서 같은 시각의 노이즈를 다시 평가해 그래디언트를 구해야 한다. 먼저 짧은 선으로 벡터 필드를 그려 방향이 부드럽게 바뀌는지 확인하면 입자 궤적을 조정하기 쉽다.

## 루프 가능한 시간 노이즈

일반적인 3차원 노이즈에 선형 시간 $t$를 넣으면 시작과 끝의 값이 보통 일치하지 않는다. 정해진 길이의 애니메이션을 매끄럽게 반복하려면 시간축을 원형 경로로 바꾸어 노이즈 공간을 표본화할 수 있다.

루프 길이를 $L$, 시간에 따른 각도를 $\theta$라고 하자.

$$
\theta(t)=2\pi\frac{t}{L}
$$

4차원 노이즈를 지원한다면 시간 대신 원 위의 두 좌표를 넣는다.

$$
n_{\text{loop}}(x,y,t)=
n\left(ax,ay,r\cos\theta(t),r\sin\theta(t)\right)
$$

$t=0$과 $t=L$에서 코사인과 사인 좌표가 같으므로 노이즈 입력과 출력도 처음 값으로 돌아온다. 4차원 노이즈를 지원하지 않는다면 두 시간 단면을 보간하거나, 처음과 끝이 이어지도록 만든 반복 타일 노이즈를 쓸 수 있다. `time % loopDuration`만 적용해서는 마지막 값과 첫 값이 일치하지 않아 이음새가 남는다.

## 작업 순서와 점검 방법

시간 노이즈는 다음 순서로 확인하면 다루기 쉽다.

1. 정지된 노이즈를 회색조로 렌더링해 공간 주파수와 값 범위를 정한다.
2. 시간 주파수를 매우 낮게 둔 뒤, 실제 재생에서 변화의 연속성을 확인한다.
3. 색이나 밝기처럼 안전한 속성 하나에만 먼저 연결한다.
4. 위치 변위나 벡터 필드처럼 민감한 출력에는 작은 진폭부터 적용한다.
5. 루프가 필요하다면 시작 프레임과 마지막 프레임을 나란히 비교한다.

노이즈가 멈춰 보이면 시간값이 실제 입력에 포함되어 있는지 확인한다. 화면 전체가 같은 밝기로 흔들리면 공간 좌표를 입력했는지 살핀다. 매 프레임 값이 튄다면 프레임마다 난수 시드를 바꾸거나 프레임 번호를 입력으로 쓰고 있지 않은지 확인한다. 시간 변화와 공간 세부를 별도 매개변수로 두면 노이즈를 예측 가능하게 조절할 수 있다.

## 이 절의 핵심

연속적인 노이즈 애니메이션은 시간을 노이즈 입력으로 사용한다. 3차원 노이즈는 질감 자체를 시간에 따라 바꾸고, 이동하는 2차원 노이즈는 질감을 한 방향으로 흐르게 한다. 공간 주파수, 시간 주파수, 변위 진폭을 따로 조절하고 고주파 변화로 인한 떨림과 루프 경계의 이음새를 점검한다.
