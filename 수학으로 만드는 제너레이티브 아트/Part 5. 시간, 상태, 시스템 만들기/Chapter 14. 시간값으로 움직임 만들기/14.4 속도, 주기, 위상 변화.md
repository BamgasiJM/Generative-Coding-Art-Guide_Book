# 14.4 속도, 주기, 위상 변화

주기 함수에서 속도는 각속도 $\omega$, 주기는 $T$, 위상은 시작 위치를 뜻한다. 이 셋의 관계는 다음과 같다.

$$
\omega=\frac{2\pi}{T},\qquad f=\frac{1}{T}
$$

위상 $\phi$를 더하면 같은 파형을 시간축에서 옮길 수 있다. 격자의 각 셀에 위치 기반 위상을 주면 하나의 물결이 화면을 통과하는 것처럼 보인다.

```text
phase = dot(cellPosition, travelDirection) * phaseDensity
value = sin(time * angularSpeed + phase)
```

속도를 높이는 것과 주기를 짧게 하는 것은 같은 효과를 낸다. 하지만 코드에서는 초당 회전 수, 초당 라디안, 루프 전체의 횟수 가운데 어느 단위를 쓰는지 일관되게 정해야 한다. 모호한 `speed` 하나에 여러 뜻을 담으면 조절하기 어려워진다.

서로 다른 주기를 겹치면 복잡한 리듬이 생긴다. 단, 주기 비율이 유리수일 때는 결국 반복되고, 무리수에 가까운 비율은 매우 긴 시간 동안 같은 모양이 돌아오지 않는다. 내보낼 루프가 목적이라면 주기를 정수비로 정하는 편이 낫다.

## 이 절의 핵심

속도, 주기, 위상은 같은 파동을 다른 관점에서 조절하는 값이다. 여러 리듬을 겹칠 때는 최종 루프 가능 여부도 함께 계산한다.
