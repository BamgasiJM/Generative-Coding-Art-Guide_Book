# 17.3 L-System과 분기 구조

L-System(Lindenmayer system, 린덴마이어 시스템)은 기호열을 반복해 다시 쓰는 문법이다. 만들어진 기호열을 터틀 그래픽(turtle graphics)의 명령으로 해석하면 단순한 규칙으로 식물의 가지나 눈송이 같은 계층 구조를 그릴 수 있다. 재귀가 함수 호출로 부모와 자식의 관계를 표현한다면, L-System은 기호열에 적용하는 재작성 규칙으로 형태를 만든다.

## 문법의 구성요소

간단한 L-System은 시작 문자열, 생산 규칙, 반복 횟수로 정할 수 있다.

| 구성요소 | 뜻 |
| --- | --- |
| 알파벳 또는 기호 집합 | 다시 쓸 기호와 이동·회전 같은 명령 기호 |
| 공리(axiom) | 0세대의 시작 문자열 |
| 생산 규칙(production rule) | 기호 하나를 다음 세대의 기호열로 바꾸는 규칙 |
| 세대(generation) | 모든 생산 규칙을 한 차례 적용한 결과 |

예를 들어 공리가 `F`이고 생산 규칙이 `F -> F+F--F+F`라면 0세대는 `F`, 1세대는 `F+F--F+F`가 된다. 다음 세대에서는 현재 문자열의 각 `F`를 규칙의 오른쪽 문자열로 바꾸고, 규칙이 없는 `+`와 `-`는 그대로 둔다.

L-System의 재작성은 보통 현재 문자열의 기호를 한꺼번에 읽고 바꾸는 병렬 치환이다. 새로 만들어진 기호를 같은 세대 안에서 다시 바꾸지는 않는다. 한 세대의 결과를 별도 문자열에 모으고, 다음 세대에서 그 문자열을 다시 읽는다.

```text
current = axiom

repeat generationCount times:
    next = ""
    for symbol in current:
        next += production.get(symbol, symbol)
    current = next
```

여기서 `current`는 현재 세대, `next`는 다음 세대의 문자열이다. 생산 규칙이 없는 기호는 그대로 복사한다. 규칙 적용 순서를 섞거나 생성 중인 `next`를 다시 읽으면 병렬 치환과는 다른 재작성 방식이 된다.

## 기호열을 그림으로 해석하기

터틀 그래픽에서 터틀은 화면 위를 움직이는 가상의 펜이다. 터틀은 현재 위치와 진행 방향을 기억하고, 앞으로 이동해 선을 그리거나 방향을 바꾸며, 분기 뒤에는 저장해 둔 상태로 돌아온다. 재작성된 기호열은 터틀이 차례로 따르는 이동 명령이다. 2차원에서 사용하는 기본 명령은 다음과 같다.

| 기호 | 터틀 동작 |
| --- | --- |
| `F` | 현재 방향으로 한 걸음 이동하며 선을 그린다. |
| `f` | 현재 방향으로 이동하지만 선은 그리지 않는다. |
| `+` | 정한 각도만큼 왼쪽으로 회전한다. |
| `-` | 정한 각도만큼 오른쪽으로 회전한다. |
| `[` | 현재 위치와 방향을 스택에 저장한다. |
| `]` | 스택에서 위치와 방향을 꺼내 복원한다. |

`[`는 분기 시작점의 상태를 저장하고, `]`는 가지를 그린 뒤 부모 줄기의 위치와 방향을 복원한다. 따라서 대괄호 안의 가지를 그린 뒤에도 이후 명령은 부모 줄기에서 이어진다. 대괄호는 짝이 맞아야 하며, 비어 있는 스택에서 `]`를 처리하지 않도록 확인한다. 2차원에서는 보통 위치와 방향각을 저장하고, 3차원에서는 방향을 나타내는 회전 상태도 함께 저장한다.

```text
position = startPosition
heading = startHeading
stack = empty

for symbol in instructionString:
    if symbol == "F":
        nextPosition = position + direction(heading) * stepLength
        drawLine(position, nextPosition)
        position = nextPosition
    else if symbol == "f":
        position += direction(heading) * stepLength
    else if symbol == "+":
        heading += turnAngle
    else if symbol == "-":
        heading -= turnAngle
    else if symbol == "[":
        stack.push((position, heading))
    else if symbol == "]":
        position, heading = stack.pop()
```

`heading`과 `turnAngle`은 같은 각도 단위로 표현한다. 보통 라디안을 쓰지만, 도 단위를 사용한다면 삼각 함수와 회전 계산도 그 단위에 맞춰야 한다. 화면 좌표의 y축이 아래쪽을 향하면 수학 좌표에서의 왼쪽·오른쪽 회전이 화면에서는 반대로 보일 수 있다.

## 코흐 곡선으로 보는 재작성

코흐 곡선의 규칙은 공리 `F`, 생산 규칙 `F -> F+F--F+F`, 회전각 60도다. 한 번 재작성하면 `F` 하나가 네 개의 전진 명령과 회전 명령으로 바뀐다. 터틀은 각 `F`에서 선분을 그리고 `+`, `-`에서 방향을 바꾸므로 한 직선이 네 선분으로 된 꺾인 경로가 된다.

다음 세대에서는 새 문자열의 네 `F`를 각각 다시 네 개의 `F`로 바꾼다. 따라서 $n$세대의 `F` 수는 $4^n$이며, 세대가 하나 늘 때마다 선분 수는 네 배가 된다. 전체 문자열에는 회전 기호도 늘어나므로 문자열 길이와 선분 수는 같지 않다. 원래 선분과 비슷한 전체 크기를 유지해 비교하려면 세대에 맞춰 터틀의 `stepLength`를 줄인다. 축소 비율과 반복 수에 따른 선분 수와 총 길이의 관계는 17.2절의 코흐 곡선 설명과 연결된다.

## 분기 식물의 규칙

식물형 L-System에서는 그리는 기호와 재작성만 담당하는 기호를 구분하면 편리하다. 다음은 간단한 분기 규칙이다.

```text
axiom: X
X -> F[+X]F[-X]+X
F -> FF
turnAngle: 25 degrees
```

`X`는 다음 세대에서 가지 구조를 만들지만 터틀이 직접 그리지는 않는 기호다. 따라서 0세대의 `X`에서는 선을 그리지 않고, 첫 치환에서 줄기 선분이 나타난다. 이후 `X`를 다시 치환하면서 실제 가지 구조를 만든다. `F`는 줄기를 그리는 명령이며, 다음 세대에 `FF`로 늘어나 줄기가 계속 자라게 한다. `+`와 `-`는 좌우로 방향을 바꾸고, 대괄호는 곁가지를 그린 뒤 부모 줄기로 돌아오게 한다. 모든 `X`와 `F`에 규칙을 적용하므로 세대가 늘수록 줄기와 가지가 함께 길어지고 복잡해진다.

`turnAngle`은 가지가 벌어지는 정도를, `F`의 길이는 가지의 크기를, 세대 수는 구조의 세부 정도를 정한다. 단계마다 선분 길이를 일정한 비율로 줄이거나 선을 가늘게 하면 멀리 뻗는 가지를 만들 수 있다. 규칙에 작은 무작위 각도나 길이 변화를 더하면 반복적인 모양을 완화할 수 있다. 시드와 가지별 고유 ID를 고정하면 다시 실행해도 같은 구조를 얻는다. 이런 변형은 기본 규칙의 형태를 확인한 뒤 조금씩 추가해야 결과의 원인을 파악하기 쉽다.

## 규칙의 종류와 확장

하나의 기호에 생산 규칙 하나만 대응하면 결정적 L-System이다. 같은 공리와 반복 횟수에서는 늘 같은 문자열과 그림이 나온다. 확률적 L-System(stochastic L-System)은 한 기호에 여러 규칙을 두고 각각의 선택 확률을 지정한다. 예를 들어 `X`에 긴 가지와 짧은 가지를 만드는 규칙을 함께 두고 선택할 수 있다. 확률은 변이가 나타나는 빈도를 조절하며, 난수 시드를 고정하면 같은 변형을 다시 만들 수 있다.

기호에 길이나 굵기 같은 수치를 붙이는 매개변수형 L-System도 있다. 가지 기호가 현재 길이를 가지고 다음 세대에서 `length * ratio`로 줄어들게 하면 단계별 선분 크기를 직접 조절할 수 있다. 이웃 기호나 매개변수 조건에 따라 규칙을 고르는 문맥 의존형 규칙도 있지만, 기본적인 식물형 구조는 대개 문맥 없는 규칙으로 표현할 수 있다.

이 분류들은 프랙탈의 이름과 서로 배타적인 도형 종류가 아니다. 코흐 곡선처럼 하나의 도형을 기하학적 치환 규칙으로 설명할 수도 있고, L-System 문자열을 재작성한 뒤 터틀로 그릴 수도 있다. L-System은 특히 기호열의 생산 규칙과 분기 상태를 명시적으로 다루는 데 강점이 있다.

## 문자열 증가와 실용적인 제한

생산 규칙이 기호 하나를 여러 기호로 바꾸면 문자열은 세대마다 빠르게 길어진다. 분기 구조의 문자열에는 실제 선분뿐 아니라 그리지 않는 `X`, 회전 기호, 상태를 저장하고 복원하는 대괄호도 포함된다. 따라서 선분 수만 보고 메모리와 계산량을 예상하면 실제 비용을 과소평가할 수 있다.

먼저 낮은 세대에서 문자열 길이, 선분 수, 최대 스택 깊이를 확인한 뒤 필요한 만큼 반복 횟수를 늘린다. 최대 세대 수와 문자열 길이를 제한하고, 픽셀에서 구분되지 않을 만큼 짧은 가지는 더 만들지 않는다. 높은 세대에서 문자열 저장 비용이 부담된다면 규칙을 해석하며 바로 그리는 방법도 고려할 수 있다. 이때도 낮은 반복 수에서 규칙이 의도한 형태를 만드는지 먼저 확인한다.

## 이 절의 핵심

L-System은 공리에서 시작해 각 세대의 기호를 생산 규칙으로 병렬 치환하고, 완성된 문자열을 터틀 명령으로 해석한다. 생산 규칙은 어떤 기호가 늘거나 분기할지 정하고, `+`, `-`, 대괄호는 터틀의 방향과 분기 상태를 제어한다. 세대 수와 규칙의 확장률이 형태와 계산량을 함께 키우므로, 먼저 낮은 세대에서 확인한 뒤 화면 해상도와 예산에 맞춰 확장한다.
