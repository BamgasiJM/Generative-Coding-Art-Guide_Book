# 17.1 재귀와 반복 구조

재귀는 규칙이 자기 자신을 다시 호출하는 구조이고, 반복은 같은 규칙을 여러 번 적용하는 구조다. 둘 다 작은 규칙에서 계층적 형태를 만든다.

```text
branch(length):
    if length < minimum: return
    draw(length)
    branch(length * ratio)
```

재귀는 트리와 분기처럼 깊이가 자연스러운 형태에 맞고, 반복은 격자·입자·버퍼처럼 많은 요소에 적합하다. 종료 조건이 없으면 계산과 형태가 모두 무한히 커진다.

## 이 절의 핵심

재귀와 반복은 규칙을 누적해 구조를 만든다. 깊이, 감소율, 종료 조건이 복잡도의 범위를 정한다.
