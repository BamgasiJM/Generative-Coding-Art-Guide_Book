# 16.1 입자의 구성 요소

입자는 독립적으로 갱신되는 작은 상태 단위다. 보통 위치, 속도, 가속도, 나이, 수명, 크기, 색을 가진다. 모든 값을 처음부터 넣기보다 표현에 필요한 값만 둔다.

```text
particle = { position, velocity, age, lifetime, color }
```

위치는 어디에 있는지, 속도는 다음 위치로 얼마나 이동할지, 나이는 생애의 어느 지점인지 뜻한다. 렌더 속성은 운동 상태와 분리하면 같은 궤적을 점·선·도형으로 다양하게 보일 수 있다.

## 이 절의 핵심

입자는 최소한의 상태와 갱신 규칙으로 구성한다. 운동 데이터와 표시 데이터를 구분한다.
