# 16.7 입자의 생성과 소멸

입자는 일정한 비율로 생성하거나, 마우스·오디오·충돌 같은 사건에 반응해 방출한다. 수명이 끝난 입자를 삭제하거나 재사용하면 개수가 안정된다.

```text
if random() < emissionRate * dt: spawn()
if particle.age > particle.lifetime: recycle(particle)
```

객체 풀(pool)은 매 프레임 새 객체를 만들고 버리는 비용을 줄인다. 생성 위치와 초기 속도 분포를 제한하면 같은 방출기에서도 폭발, 연기, 선형 흐름처럼 다른 인상을 만든다.

## 이 절의 핵심

생성률, 초기 분포, 수명은 입자군의 밀도와 성격을 정한다. 많은 입자에는 재사용 구조가 유용하다.
