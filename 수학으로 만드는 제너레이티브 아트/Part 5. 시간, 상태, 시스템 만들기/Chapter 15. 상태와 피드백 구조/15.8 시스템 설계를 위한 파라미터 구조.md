# 15.8 시스템 설계를 위한 파라미터 구조

상태 시스템의 파라미터는 시간, 생성, 운동, 피드백, 렌더링처럼 역할별로 묶는다. 그래야 값 하나를 바꿨을 때 어떤 현상을 조절했는지 알 수 있다.

```text
motion: { speed, damping }
emission: { rate, lifetime }
feedback: { fade, blur }
```

기본값과 범위를 함께 정의하고, 0이 효과 없음이 되도록 설계하면 비교가 쉽다. 시드, 해상도, 고정 시간 단계도 결과를 바꾸는 파라미터이므로 프리셋에 함께 저장한다.

## 이 절의 핵심

파라미터를 역할과 단위로 구조화하면 복잡한 시스템도 재현하고 탐색할 수 있다.
