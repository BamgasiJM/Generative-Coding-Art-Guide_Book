# 12.2 Value Noise

Value Noise는 격자의 꼭짓점마다 난수 값을 놓고, 그 사이를 보간해 만드는 노이즈다. 2차원 입력 $\mathbf{p}$에 대해 먼저 포함된 격자 셀을 찾고, 네 꼭짓점 값을 보간한다.

$$
\mathbf{i}=\lfloor\mathbf{p}\rfloor,\qquad \mathbf{f}=\operatorname{fract}(\mathbf{p})
$$

보간에 선형 함수 대신 부드러운 곡선 $s(t)=t^2(3-2t)$를 사용하면 셀 경계에서 변화율이 덜 꺾인다.

```text
i = floor(p)
f = fract(p)
u = smoothstep(0, 1, f)
a = hash(i)
b = hash(i + (1, 0))
c = hash(i + (0, 1))
d = hash(i + (1, 1))
return lerp(lerp(a, b, u.x), lerp(c, d, u.x), u.y)
```

Value Noise는 원리가 단순하고, 타일별 난수에서 연속적인 표면으로 넘어가는 과정을 이해하기 좋다. 다만 값의 봉우리와 골이 격자에 정렬된 인상을 줄 수 있다. 더 자연스러운 방향 변화가 필요할 때는 Gradient Noise를 사용한다.

## 보간이 만드는 연속성

Value Noise의 꼭짓점 값은 이웃 셀이 공유한다. 예를 들어 한 셀의 오른쪽 위 값은 오른쪽 셀의 왼쪽 위 값과 같다. 따라서 셀 경계를 넘을 때도 양쪽 셀이 같은 경계 값을 향해 보간되며, 값 자체는 끊기지 않는다.

1차원에서는 이 구조를 더 쉽게 볼 수 있다. 정수 위치 $i$와 $i+1$에 해시값 $a$, $b$가 있을 때, 셀 내부 위치 $f$에서의 값은 다음과 같다.

$$
n(x)=(1-u)a+ub,\qquad u=s(f)
$$

여기서 $s(f)$는 보간 곡선이다. 단순 선형 보간 $s(f)=f$도 값은 이어 주지만, 셀 경계에서 기울기가 갑자기 바뀔 수 있다. $s(t)=t^2(3-2t)$ 같은 smoothstep 곡선은 양 끝에서 기울기가 0이 되어 이 꺾임을 줄인다.

$$
s(0)=0,\quad s(1)=1,\quad s'(0)=s'(1)=0
$$

개선된 Perlin Noise에서 자주 쓰는 $6t^5-15t^4+10t^3$은 2차 미분의 연속성까지 고려한 fade 함수다. 모든 작업에 이 다항식이 필요한 것은 아니지만, 좌표 변위나 법선처럼 변화율이 눈에 보이는 출력에는 더 부드러운 보간이 유리할 수 있다.

## 두 번의 1차원 보간으로 이해하기

2차원 셀에서는 네 꼭짓점 값을 한 번에 복잡하게 섞는 대신, x방향으로 두 번 보간한 뒤 그 결과를 y방향으로 한 번 더 보간한다고 생각하면 된다.

$$
v_0=\operatorname{lerp}(a,b,u_x),\qquad
v_1=\operatorname{lerp}(c,d,u_x),\qquad
v=\operatorname{lerp}(v_0,v_1,u_y)
$$

이 구조를 이중 선형 보간(bilinear interpolation)이라고 한다. 셀 내부의 위치가 오른쪽으로 갈수록 $a$보다 $b$의 영향이 커지고, 위쪽으로 갈수록 아래 행의 보간값보다 위 행의 보간값이 커진다. 해시 함수는 격자 꼭짓점에 난수 값을 결정하고, 보간은 그 이산적인 값을 연속적인 표면으로 바꾼다.

## 주파수, 시드, 반복 가능한 타일

입력 좌표에 주파수를 곱하면 격자 셀의 크기가 바뀐다.

```text
largeFeatures = valueNoise(p * 0.5)
smallFeatures = valueNoise(p * 8.0)
```

해시 입력에 시드 값을 넣으면 같은 좌표에서도 다른 노이즈 구조를 만들 수 있다. 다만 단순 해시로 만든 Value Noise는 입력 범위의 끝에서 자동으로 이어지지 않는다. 정확하게 반복되는 타일이 필요하다면 격자 인덱스를 정해진 주기로 나눈 뒤 해시에 전달해야 한다.

```text
wrappedId = mod(cellId, tilePeriod)
cornerValue = hash(wrappedId, seed)
```

이때 타일의 양 끝이 같은 격자 꼭짓점 값을 공유하도록 x와 y 방향의 주기를 모두 맞춘다. 단순히 최종 노이즈 값에 `fract`를 적용하는 것은 매끄러운 타일링을 보장하지 않는다.

## Value Noise의 시각적 성질

Value Noise는 값의 높낮이가 격자 꼭짓점에 의해 정해지므로, 높은 주파수에서 사각 셀의 흔적이나 완만한 봉우리가 보일 수 있다. 이 성질은 종이의 얼룩, 픽셀형 지형, 낮은 해상도 구름처럼 의도적인 스타일이 될 수 있다. 반대로 방향 벡터나 자연스러운 지형의 미세한 흐름을 만들고 싶다면, 다음 절의 Gradient Noise 또는 여러 스케일을 합친 fBm을 고려한다.

Value Noise를 단독으로 쓰기보다 마스크, 색상 보간, 도형 크기, 약한 좌표 변위에 연결해 보는 것이 좋다. 먼저 회색조로 값을 확인하고, 출력 범위와 주파수를 정한 뒤 다른 시각 속성에 연결하면 과도한 대비와 왜곡을 피할 수 있다.

## 이 절의 핵심

Value Noise는 격자 난수값을 보간한 함수다. 해시, 셀 좌표, 보간이라는 세 요소가 노이즈 구성의 기본이 된다.
