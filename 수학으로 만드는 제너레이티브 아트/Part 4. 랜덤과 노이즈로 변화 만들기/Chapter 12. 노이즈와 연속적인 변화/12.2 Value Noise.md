# 12.2 Value Noise

Value Noise는 격자의 꼭짓점마다 난수 값을 놓고, 그 사이를 보간해 만드는 노이즈다. 화면의 각 픽셀에서 새 난수를 뽑는 것이 아니라, 정수 격자 좌표마다 재현 가능한 값을 하나씩 두고 그 사이의 값을 계산한다. 2차원 입력 $\mathbf{p}$에 대해 먼저 포함된 격자 셀을 찾고, 네 꼭짓점 값을 보간한다.

$$
\mathbf{i}=\lfloor\mathbf{p}\rfloor,\qquad \mathbf{f}=\operatorname{fract}(\mathbf{p})
$$

보간에 선형 함수 대신 부드러운 곡선 $s(t)=t^2(3-2t)$를 사용하면 셀 경계에서 변화율이 덜 꺾인다.

```text
i = floor(p)
f = fract(p)
u = smoothstep(0, 1, f)
a = hash(i)
b = hash(i + (1, 0))
c = hash(i + (0, 1))
d = hash(i + (1, 1))
return lerp(lerp(a, b, u.x), lerp(c, d, u.x), u.y)
```

`i`는 입력점이 속한 셀의 정수 좌표이고, `f`는 그 셀 안에서 입력점이 차지하는 위치다. `hash`는 셀의 꼭짓점 좌표를 입력으로 받아 꼭짓점마다 하나의 고정된 값을 만든다. 이 값이 호출할 때마다 달라지면 같은 좌표를 다시 평가해도 표면이 유지되지 않으므로, 보통 좌표 해시와 시드를 이용해 값을 재현한다. `smoothstep`은 셀 안의 비율을 보간에 사용할 값으로 부드럽게 바꾸고, `lerp`는 네 꼭짓점의 영향을 차례로 섞는다.

간단한 숫자 예로 입력이 $\mathbf{p}=(2.25,1.6)$이면 셀은 $\mathbf{i}=(2,1)$이고, 셀 안의 위치는 $\mathbf{f}=(0.25,0.6)$이다. cubic smoothstep $s(t)=t^2(3-2t)$를 적용하면 $u_x=0.15625$, $u_y=0.648$이 된다. 네 꼭짓점 값이 $a=hash(2,1)=0.2$, $b=hash(3,1)=0.8$, $c=hash(2,2)=0.5$, $d=hash(3,2)=0.4$라면 먼저 x방향으로

$$
v_0=\operatorname{lerp}(a,b,u_x)=0.29375,\qquad
v_1=\operatorname{lerp}(c,d,u_x)=0.484375
$$

를 얻고, 두 결과를 y방향으로 보간해 약 $0.417$을 얻는다. 이 예는 노이즈의 출력이 새로운 난수가 아니라 네 꼭짓점 값의 가중 평균임을 보여 준다.

Value Noise는 원리가 단순하고, 타일별 난수에서 연속적인 표면으로 넘어가는 과정을 이해하기 좋다. 다만 값의 봉우리와 골이 격자에 정렬된 인상을 줄 수 있다. 더 자연스러운 방향 변화가 필요할 때는 Gradient Noise를 사용한다.

## 보간이 만드는 연속성

Value Noise의 꼭짓점 값은 이웃 셀이 공유한다. 예를 들어 한 셀의 오른쪽 위 값은 오른쪽 셀의 왼쪽 위 값과 같다. 따라서 셀 경계를 넘을 때도 양쪽 셀이 같은 경계 값을 향해 보간되며, 값 자체는 끊기지 않는다. 이 성질을 얻으려면 꼭짓점의 값은 현재 셀 안에서 따로 생성하는 것이 아니라, 격자의 정수 좌표를 기준으로 한 번 정해져야 한다.

1차원에서는 이 구조를 더 쉽게 볼 수 있다. 정수 위치 $i$와 $i+1$에 해시값 $a$, $b$가 있을 때, 셀 내부 위치 $f$에서의 값은 다음과 같다.

$$
n(x)=(1-u)a+ub,\qquad u=s(f)
$$

여기서 $s(f)$는 보간 곡선이다. 단순 선형 보간 $s(f)=f$도 값은 이어 주지만, 셀 경계에서 기울기가 갑자기 바뀔 수 있다. $s(t)=t^2(3-2t)$ 같은 smoothstep 곡선은 양 끝에서 기울기가 0이 되어 이 꺾임을 줄인다. 인접 셀도 같은 규칙을 사용하면 경계 양쪽의 기울기가 0으로 맞아 값의 변화가 한결 매끄럽게 이어진다. 다만 이 곡선은 2차 미분까지 경계에서 부드럽게 맞추지는 않으므로, 기울기 변화가 특히 민감한 용도에는 다른 보간 곡선을 고려할 수 있다.

$$
s(0)=0,\quad s(1)=1,\quad s'(0)=s'(1)=0
$$

개선된 Perlin Noise에서 자주 쓰는 $6t^5-15t^4+10t^3$은 2차 미분의 연속성까지 고려한 fade 함수다. 모든 작업에 이 다항식이 필요한 것은 아니지만, 좌표 변위나 법선처럼 변화율이 눈에 보이는 출력에는 더 부드러운 보간이 유리할 수 있다.

## 두 번의 1차원 보간으로 이해하기

2차원 셀에서는 네 꼭짓점 값을 한 번에 복잡하게 섞는 대신, x방향으로 두 번 보간한 뒤 그 결과를 y방향으로 한 번 더 보간한다고 생각하면 된다.

$$
v_0=\operatorname{lerp}(a,b,u_x),\qquad
v_1=\operatorname{lerp}(c,d,u_x),\qquad
v=\operatorname{lerp}(v_0,v_1,u_y)
$$

이 구조를 이중 선형 보간(bilinear interpolation)이라고 한다. 셀 안에서 $u_x$가 커질수록 $a$보다 $b$, $c$보다 $d$의 영향이 커진다. $u_y$가 커지면 첫 번째 행의 보간값 $v_0$에서 두 번째 행의 보간값 $v_1$ 쪽으로 이동한다. 어느 행이 화면에서 위쪽인지는 좌표계의 y축 방향에 따라 달라진다. 해시 함수는 격자 꼭짓점에 난수 값을 결정하고, 보간은 그 이산적인 값을 연속적인 표면으로 바꾼다.

보간 과정에서 결과는 주변 꼭짓점 값의 범위 안에 놓인다. 네 값이 모두 $[0,1]$에 있으면 셀의 출력도 그 범위를 벗어나지 않지만, 출력값이 $[0,1]$에 균등하게 분포한다는 뜻은 아니다. 여러 꼭짓점의 평균에 가까운 값이 자주 나타날 수 있어 중간 회색이 넓게 보인다. 따라서 밝기나 임계값에 연결할 때는 노이즈가 실제로 어떤 분포를 갖는지 확인해야 한다.

Value Noise의 셀 구조는 3차원 이상으로도 확장할 수 있다. 3차원에서는 셀의 여덟 꼭짓점 값을 구한 뒤 x, y, z 방향으로 차례로 보간한다. 차원이 하나 늘 때마다 셀의 꼭짓점 수가 두 배가 되어 $d$차원 셀에는 $2^d$개의 꼭짓점이 필요하다. 원리는 같지만 차원이 높아질수록 계산량과 관리할 해시값이 빠르게 늘어난다.

## 주파수, 시드, 반복 가능한 타일

입력 좌표에 주파수를 곱하면 격자 셀의 크기가 바뀐다.

```text
largeFeatures = valueNoise(p * 0.5)
smallFeatures = valueNoise(p * 8.0)
```

노이즈 입력이 픽셀 좌표라면 한 셀을 화면에서 크게 보이게 하고 싶을수록 좌표에 곱하는 배율을 작게 한다. 예를 들어 픽셀 좌표를 `cellSize`로 나누어 입력하면 격자 단위 하나가 대략 `cellSize` 픽셀에 해당한다.

```text
noisePosition = pixelPosition / cellSize
value = valueNoise(noisePosition, seed)
```

해시 입력에 시드 값을 넣으면 같은 좌표에서도 다른 노이즈 구조를 만들 수 있다. 시드는 꼭짓점의 값을 바꾸지만, 한 번 정한 시드에 대해서는 같은 격자 좌표가 항상 같은 값을 반환해야 한다. 여러 프레임이나 여러 픽셀을 그리는 동안 해시 시드를 계속 바꾸면 공간적·시간적 연속성이 깨진다. 다만 단순 해시로 만든 Value Noise는 입력 범위의 끝에서 자동으로 이어지지 않는다. 정확하게 반복되는 타일이 필요하다면 격자 인덱스를 정해진 주기로 나눈 뒤 해시에 전달해야 한다.

```text
wrappedId = mod(cellId, tilePeriod)
cornerValue = hash(wrappedId, seed)
```

이때 타일의 양 끝이 같은 격자 꼭짓점 값을 공유하도록 x와 y 방향의 주기를 모두 맞춘다. 단순히 최종 노이즈 값에 `fract`를 적용하는 것은 매끄러운 타일링을 보장하지 않는다.

## Value Noise의 시각적 성질

Value Noise는 값의 높낮이가 격자 꼭짓점에 의해 정해지므로, 높은 주파수에서 사각 셀의 흔적이나 완만한 봉우리가 보일 수 있다. 셀의 모서리와 축을 따라 비슷한 모양이 반복되거나, 보간된 언덕이 격자 방향으로 늘어져 보이기도 한다. 이 성질은 종이의 얼룩, 픽셀형 지형, 낮은 해상도 구름처럼 의도적인 스타일이 될 수 있다. 격자 방향성이 눈에 거슬린다면 입력 좌표를 회전하거나 여러 방향의 필드를 약하게 조합할 수 있지만, 방향성 있는 변화를 더 직접 제어하려면 다음 절의 Gradient Noise를 고려한다. 여러 스케일을 합치는 fBm은 이후 절에서 다룬다.

다음 의사 코드는 계산된 Value Noise를 회색조로 표시해 격자 크기와 표면의 봉우리·골을 확인하는 간단한 미리보기다.

```text
cellSize = 8
for y from 0 to imageHeight - 1:
    for x from 0 to imageWidth - 1:
        p = vec2(x, y) / cellSize
        raw = valueNoise(p, seed)
        level = clamp(remap(raw, noiseMin, noiseMax, 0, 1), 0, 1)
        drawGrayscalePixel(x, y, level)
```

여기서 `cellSize`는 한 격자 단위가 화면에서 차지하는 픽셀 크기다. 값을 크게 하면 격자 셀이 커져 봉우리와 골도 넓어지고, 작게 하면 더 촘촘한 특징이 나타난다. `noiseMin`과 `noiseMax`는 해시값과 보간 방식으로 정해지는 출력 범위에 맞춘다. 실제 표본의 최솟값과 최댓값을 매 프레임 다시 구해 대비를 맞추면 시간에 따라 화면의 밝기가 출렁일 수 있으므로, 애니메이션에서는 고정된 범위나 고정된 기준값을 쓰는 편이 안정적이다. 먼저 회색조로 값과 셀 구조를 확인한 뒤 마스크, 색상 보간, 도형 크기, 약한 좌표 변위에 연결하면 과도한 대비와 왜곡을 조절하기 쉽다.

간단한 영역 분할은 같은 필드에 임계값을 적용해 확인할 수 있다.

```text
value = valueNoise(pixelPosition / cellSize, seed)
region = smoothstep(threshold - softness,
                    threshold + softness,
                    value)
```

`softness`를 0에 가깝게 하면 거의 단단한 경계가 생기고, 키우면 경계 주변에 완만한 중간값이 생긴다. 정확히 0인 경계 폭은 `smoothstep`의 두 끝점이 같아지므로, 단단한 경계를 원하면 `value >= threshold`처럼 직접 비교한다. 이 방식으로 연속적인 값이 마스크나 형태의 선택으로 바뀌는 과정을 관찰할 수 있다.

## 이 절의 핵심

Value Noise는 고정된 격자 난수값을 보간해 연속적인 스칼라 필드로 바꾸는 함수다. 꼭짓점 값을 재현 가능하게 정하고 셀 경계를 공유해야 표면이 이어진다. 해시, 셀 좌표, 보간이라는 세 요소가 노이즈 구성의 기본이 된다.
