# 12.3 Gradient Noise와 Perlin Noise

Gradient Noise는 격자 꼭짓점에 스칼라 값 대신 기울기를 나타내는 방향 벡터를 둔다. 각 꼭짓점에서 입력점까지의 변위와 방향 벡터의 내적을 구하고, 그 기여를 보간해 하나의 스칼라 값을 만든다. 꼭짓점의 기울기들이 셀 안에서 값이 어떻게 변할지 정하므로 Value Noise보다 방향이 이어지는 표면을 만들기 쉽다. Perlin Noise는 이 계열을 널리 알린 대표적인 알고리즘이다.

이름에 `Gradient`가 들어가도 결과가 곧바로 벡터 필드가 된다는 뜻은 아니다. 격자에는 방향 벡터를 저장하지만, 최종 출력은 높이·밝기처럼 사용할 수 있는 스칼라 노이즈 값이다. 여기서 방향 벡터는 각 꼭짓점 주변의 변화 경향을 정하기 위한 정보다.

$$
g_{ij}(\mathbf{p})=\mathbf{d}_{ij}\cdot(\mathbf{p}-\mathbf{c}_{ij})
$$

여기서 $\mathbf{d}_{ij}$는 꼭짓점의 의사 난수 기울기, $\mathbf{c}_{ij}$는 꼭짓점 좌표다. 변위 $\mathbf{p}-\mathbf{c}_{ij}$는 꼭짓점에서 입력점까지의 방향과 거리를 나타낸다. 내적은 그 변위가 꼭짓점의 기울기 방향과 얼마나 나란한지 측정한다. 값 자체를 꼭짓점에 두는 대신 기울기를 기준으로 셀 내부의 값을 만들기 때문에, 같은 격자 구조에서도 Value Noise와 다른 표면이 나온다.

```text
cornerContribution = dot(randomGradient(corner), point - corner)
value = interpolateFourCorners(cornerContribution, fade(localPosition))
```

개선된 Perlin Noise(Improved Perlin Noise)에서 사용하는 fade 함수는 $6t^5-15t^4+10t^3$이다. 양 끝에서 함수의 1차와 2차 미분이 0이 되므로, 셀 경계를 지날 때 값과 기울기가 더 부드럽게 이어지고 곡률의 급격한 변화도 줄어든다. 좌표 변위나 표면의 법선처럼 기울기의 변화가 결과에 드러나는 작업에서 유용하다. Improved Perlin Noise는 Perlin의 기존 격자 Gradient Noise를 다듬은 변형이며, 이 fade 곡선과 방향 선택 방법을 개선해 격자 경계에서 생길 수 있는 흔적을 줄인다. 라이브러리의 `noise()` 함수가 모두 같은 알고리즘이나 출력 범위를 뜻하지는 않으므로, 특정 구현이 필요할 때는 문서를 확인한다.

## 내적이 만드는 꼭짓점의 영향

각 꼭짓점의 방향 벡터는 그 주변에서 값이 증가하거나 감소하는 방향을 정한다. 입력점이 꼭짓점과 같은 위치에 놓이면 변위 벡터가 0이므로 내적도 0이다. 입력점이 방향 벡터가 향하는 쪽에 있으면 기여값은 양수가 되고, 반대쪽에 있으면 음수가 된다.

$$
\mathbf{d}\cdot\mathbf{r}=\|\mathbf{d}\|\,\|\mathbf{r}\|\cos\phi
$$

여기서 $\phi$는 방향 벡터와 꼭짓점에서 입력점으로 향하는 벡터 사이의 각도다. 방향 벡터를 단위 길이로 두면, 내적의 크기는 주로 거리와 방향 관계에서 나온다. Value Noise가 꼭짓점의 "높이"를 보간한다면, Gradient Noise는 꼭짓점 주변의 "기울어지는 방식"을 보간한다고 이해할 수 있다.

예를 들어 변위가 $\mathbf{r}=(0.25,0.4)$일 때, x축 양의 방향을 향하는 $\mathbf{d}=(1,0)$의 기여값은 0.25이고 y축 양의 방향을 향하는 $\mathbf{d}=(0,1)$의 기여값은 0.4다. 같은 입력점이라도 꼭짓점의 방향이 다르면 보간에 들어가는 값이 달라진다. 각 내적은 최종 노이즈값이 아니라 하나의 꼭짓점에서 온 기여값이다. 네 기여값을 셀 안에서의 위치에 따라 보간해 하나의 스칼라 값으로 만든다.

입력점이 격자 꼭짓점에 정확히 놓이면 해당 꼭짓점에서 입력점까지의 변위가 0이므로 그 꼭짓점 기여는 0이다. fade 보간은 그 위치에서 해당 꼭짓점의 기여를 선택하므로, 전형적인 Gradient Noise는 격자점에서 0을 지난다. Value Noise처럼 격자점마다 서로 다른 높이를 지정하는 방식이 아니라, 꼭짓점의 기울기가 격자 사이의 봉우리와 골을 만든다는 차이가 여기서도 드러난다.

2차원 셀 안의 계산을 숫자로 따라가 보자. 입력점의 셀 안 위치가 $(0.5,0.5)$이고 네 꼭짓점의 기울기가 각각

$$
\mathbf{d}_{00}=(1,0),\quad \mathbf{d}_{10}=(0,1),\quad
\mathbf{d}_{01}=(-1,0),\quad \mathbf{d}_{11}=(0,-1)
$$

라고 하자. 네 꼭짓점에서 입력점으로 향하는 변위는 각각 $(0.5,0.5)$, $(-0.5,0.5)$, $(0.5,-0.5)$, $(-0.5,-0.5)$이므로 내적 기여는 차례로 $0.5$, $0.5$, $-0.5$, $0.5$가 된다. 중앙에서는 fade 값이 양쪽 축 모두 $0.5$이므로 x방향으로 두 행을 각각 보간한 뒤 y방향으로 섞으면 이 예의 원시 결과는 $0.25$다. 실제 구현에서는 `outputScale`이 적용될 수 있다. 꼭짓점 방향을 바꾸면 내적과 최종값도 달라진다.

## 2차원 알고리즘의 순서

2차원 Gradient Noise는 Value Noise와 마찬가지로 입력점이 들어 있는 셀과 네 꼭짓점을 찾는다. 다른 점은 각 꼭짓점에서 해시값 하나를 얻는 대신 의사 난수 방향 벡터 하나를 얻는다는 점이다.

```text
cell = floor(point)
local = fract(point)

c00 = dot(gradientFromHash(cell + (0, 0)), local - (0, 0))
c10 = dot(gradientFromHash(cell + (1, 0)), local - (1, 0))
c01 = dot(gradientFromHash(cell + (0, 1)), local - (0, 1))
c11 = dot(gradientFromHash(cell + (1, 1)), local - (1, 1))

u = (fade(local.x), fade(local.y))
row0 = lerp(c00, c10, u.x)
row1 = lerp(c01, c11, u.x)
raw = lerp(row0, row1, u.y)
return outputScale * raw
```

마지막의 보간 구조는 Value Noise와 같다. x방향의 두 기여를 보간하고, 그 두 결과를 y방향으로 다시 보간한다. 다른 점은 보간에 들어가는 네 수가 꼭짓점의 고정 높이가 아니라 기울기와 변위의 내적이라는 것이다. `fade`는 셀 안의 위치 비율을 바꾸어 경계에서 보간 곡선의 기울기가 0이 되도록 한다. `outputScale`은 내적과 보간으로 얻은 원시값의 크기를 다루기 위한 계수다. 꼭짓점 방향이 이웃 셀에서도 같고 fade 함수가 경계에서 충분히 부드러우면, 셀 경계를 지나도 값과 기울기가 이어진다.

공유 꼭짓점은 어느 셀에서 계산하든 같은 방향 벡터를 가져야 한다. 따라서 방향은 현재 셀 안에서 임의로 다시 뽑기보다, 격자의 정수 꼭짓점 좌표와 시드처럼 셀 경계를 넘어도 유지되는 키로 결정한다. 꼭짓점 방향을 매 표본마다 새로 생성하면 같은 점을 다시 평가해도 다른 결과가 나오고 셀 경계의 양쪽도 일치하지 않는다. 좌표와 시드를 입력으로 받는 결정적 해시를 사용하면 모든 프레임과 표본에서 같은 방향을 재현할 수 있다.

## 방향 벡터의 선택

2차원에서는 꼭짓점마다 임의의 각도에서 만든 단위 벡터 $(\cos\theta,\sin\theta)$를 쓸 수 있다. 구현을 빠르게 하려면 미리 정한 몇 개의 방향 중 하나를 해시로 선택하기도 한다.

균일한 해시값에서 각도를 얻는 방법은 다음과 같다.

```text
h = hash(cornerId, seed)  # [0, 1)
angle = 2 * PI * h
gradient = vec2(cos(angle), sin(angle))
```

해시가 $[0,1)$에 고르게 분포하면 각도도 한 바퀴에 걸쳐 고르게 선택되고, 코사인과 사인으로 만든 벡터의 길이는 1이다. 방향의 길이를 일정하게 두면 위치마다 기울기의 크기가 달라지는 문제를 줄일 수 있다. 여기서 `cornerId`는 공유되는 격자 꼭짓점의 정수 좌표이며, 같은 꼭짓점과 시드는 항상 같은 방향을 돌려준다.

```text
index = hash(cornerId, seed) mod directionCount
gradient = predefinedDirections[index]
```

방향 선택에서도 해시에는 셀 번호가 아니라 꼭짓점 좌표를 사용해야 한다. 셀 번호만으로 방향을 고르면 같은 꼭짓점이 이웃 셀마다 다른 방향을 받을 수 있다. 방향의 수가 너무 적으면 반복적인 방향성이 드러날 수 있고, 방향 분포가 한쪽으로 치우치면 노이즈도 편향된다. 반대로 많은 방향을 정확히 만들려는 비용이 항상 필요한 것은 아니다. 화면에서 원하는 주파수와 해상도에 맞는지 확인하는 것이 더 중요하다.

미리 정한 방향 집합을 쓴다면 각 방향이 원 주위에 고르게 놓였는지 확인한다. 방향이 몇 개뿐이면 대각선이나 축을 따라 늘어진 무늬가 반복될 수 있다. 반면 매 꼭짓점마다 단위 원의 각도를 해시에서 얻는 방식은 방향을 연속적으로 선택하지만, 실제 해시의 분포가 고른지에 따라 작은 편향이 남을 수 있다. 결과를 확대해 격자 방향성이 눈에 띄는지 확인한다.

## Value Noise와의 차이

두 방식은 모두 격자와 해시, 보간을 사용한다. 차이는 격자에 저장하는 정보와 그 정보의 시각적 성질에 있다.

| 항목 | Value Noise | Gradient Noise / Perlin 계열 |
| --- | --- | --- |
| 꼭짓점의 정보 | 스칼라 난수값 | 방향 벡터 |
| 꼭짓점의 기여 | 값 자체 | 방향과 변위의 내적 |
| 주된 인상 | 완만한 봉우리와 골 | 더 자연스러운 방향 변화 |
| 구현 | 비교적 간단 | 방향 해시와 내적이 추가됨 |
| 활용 | 단순 질감, 학습, 마스크 | 지형, 변위, 흐름, 연속적 애니메이션 |

Gradient Noise가 언제나 Value Noise보다 좋다는 뜻은 아니다. 격자적인 인상이나 낮은 해상도 질감이 의도라면 Value Noise가 더 직접적일 수 있다. 두 방식 모두 여러 옥타브를 합치면 fBm의 재료가 되며, 최종적인 시각 성질은 주파수·진폭·색상 매핑에 크게 좌우된다.

## 범위와 정규화

Gradient Noise의 이론적 출력 범위는 차원, 방향 벡터의 선택, 보간 방식에 따라 달라질 수 있다. 따라서 어떤 구현이 정확히 $[-1,1]$을 보장한다고 가정하기보다, 실제 출력의 최소·최대와 평균을 확인한 뒤 필요한 범위로 매핑한다.

```text
raw = gradientNoise(p * frequency)
unitValue = clamp(raw * 0.5 + 0.5, 0, 1)
```

이 매핑은 출력이 대략 대칭 범위에 있을 때의 편리한 예다. 밝기, 마스크, 재질 파라미터에 연결하기 전에는 구현의 문서와 실제 결과를 함께 확인한다.

선형 매핑은 값의 순서를 유지하지만, 관찰한 범위의 양 끝을 정확히 채우거나 값 분포를 균등하게 만들지는 않는다. 특히 프레임마다 현재 장면의 최소·최대값을 다시 측정해 매핑하면 시간에 따라 전체 대비가 바뀔 수 있다. 고정된 노이즈 필드나 안정적인 애니메이션에서는 문서에 나온 범위 또는 한 번 정한 기준 범위를 사용하고, 화면에서 평균값과 대비가 원하는 수준인지 확인한다.

## 반복 가능한 Gradient Noise

반복 타일이 필요한 경우에는 격자 꼭짓점의 방향이 타일 경계 양쪽에서 같아야 한다. 셀 인덱스를 해시하기 전에 정해진 격자 주기로 감싸면, 경계에서 공유하는 꼭짓점이 같은 방향 벡터를 사용하게 할 수 있다.

```text
wrappedCorner = mod(cornerId, tilePeriod)
gradient = gradientFromHash(wrappedCorner, seed)
```

Value Noise와 마찬가지로 단순히 최종 출력에 `fract`를 적용하는 것은 매끄러운 반복을 만들지 않는다. 반복성은 꼭짓점 데이터 단계에서 설계해야 한다.

## 이 절의 핵심

Gradient Noise는 격자에 방향을 저장하고 내적을 보간한다. 값 노이즈보다 방향성 있는 부드러운 변화를 만들기 쉽다.
