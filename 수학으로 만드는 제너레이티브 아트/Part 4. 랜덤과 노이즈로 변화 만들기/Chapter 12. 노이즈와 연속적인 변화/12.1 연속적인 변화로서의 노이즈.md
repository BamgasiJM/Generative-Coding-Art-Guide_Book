# 12.1 연속적인 변화로서의 노이즈

노이즈는 좌표를 입력받아 값 하나를 돌려주는 함수다. $n(x)$는 1차원 변화, $n(x,y)$는 평면의 질감, $n(x,y,t)$는 시간에 따라 이어지는 변화를 만든다. 가까운 좌표에서 가까운 값을 내기 때문에, 결과를 색이나 위치에 연결해도 경계가 갑자기 튀지 않는다.

$$
v=n(f_x\,x,f_y\,y)
$$

$f_x$, $f_y$는 입력 좌표를 얼마나 촘촘히 읽을지 결정하는 주파수다. 값 자체를 확대하는 진폭과 혼동하지 않는다. 노이즈의 출력 범위도 구현마다 다르다. 일부 라이브러리는 $[0,1]$, GLSL의 많은 구현은 $[-1,1]$을 쓴다.

```text
value = noise(x * frequency, y * frequency)
brightness = remap(value, noiseMin, noiseMax, 0, 1)
```

노이즈 이미지는 무작위 사진처럼 보이지만, 실은 결정적인 함수의 표본이다. 따라서 확대, 이동, 시간 변화라는 입력 조작으로 결과의 성격을 예측하며 다룰 수 있다.

## 연속성과 매끄러움

연속적이라는 말은 가까운 입력의 출력이 갑자기 멀어지지 않는다는 뜻이다. 하지만 모든 연속 노이즈가 같은 정도로 매끄러운 것은 아니다. 값만 이어지는 노이즈는 셀 경계에서 변화의 방향이 꺾여 보일 수 있고, 변화율까지 부드럽게 이어지는 노이즈는 좌표 변위와 법선 계산에서도 자연스럽게 보인다.

```text
continuous:      n(p) is close to n(p + smallOffset)
smooth derivative: change of n also changes gradually
```

Value Noise, Gradient Noise, Simplex Noise는 모두 연속적인 변화를 만들지만, 격자 경계의 성질과 고차원에서의 계산 방식은 다르다. 이후 절에서는 같은 "부드러움"을 만드는 서로 다른 접근을 비교한다.

## 입력 차원은 변화의 축을 뜻한다

$n(x)$는 선 위를 따라 변하는 값이므로 시간 그래프, 1차원 파형, 한 줄의 도형 배치에 적합하다. $n(x,y)$는 평면에 얼룩이나 지형 같은 구조를 만들고, $n(x,y,t)$는 시간축을 추가해 프레임 간에도 이어지는 변화를 만든다.

$$
v(t)=n(t\omega),\qquad
v(x,y,t)=n(f_x\,x,f_y\,y,f_t\,t)
$$

시간을 난수 시드처럼 매 프레임 교체하지 않고 입력 축으로 넣는 것이 중요하다. 그래야 이전 프레임과 다음 프레임의 값이 연결되어 깜빡임 대신 흐름처럼 보인다. 시간 주파수 $f_t$를 낮추면 느리고 묵직한 변화가, 높이면 빠른 떨림이 생긴다.

## 결정성과 시드

절차적 노이즈는 보통 같은 좌표와 같은 설정에 항상 같은 값을 반환한다. 많은 구현은 내부 해시나 순열 테이블을 사용하며, 시드 또는 노이즈 시드를 바꾸면 같은 좌표에서도 다른 공간적 구조를 얻는다.

```text
setNoiseSeed(seed)
value = noise(position * frequency)
```

따라서 노이즈는 "무작위처럼 보이는 함수"이지, 호출할 때마다 새 값을 내는 일반 난수 함수가 아니다. 이 결정성 덕분에 카메라가 다시 그려도 질감이 유지되고, 마음에 드는 결과를 시드와 파라미터로 기록할 수 있다.

## 주파수와 표본화

입력 주파수를 높이면 노이즈의 특징 크기가 작아진다. 그러나 화면의 픽셀보다 훨씬 작은 변화는 충분히 표본화되지 못해 깜빡임과 거친 무늬를 만들 수 있다. 확대·축소되는 패턴에서는 노이즈 주파수와 출력 해상도를 함께 조절하고, 아주 높은 옥타브는 줄이거나 안티앨리어싱을 고려한다.

노이즈의 출력 범위를 정규화한 뒤 색·변위·마스크에 연결하는 습관도 중요하다. 같은 노이즈라도 밝기에는 작은 진폭이면 충분하지만, 좌표 변위에는 너무 큰 진폭이 도형을 알아보기 어렵게 만들 수 있다. 입력 주파수와 출력 진폭은 서로 다른 역할의 파라미터다.

## 이 절의 핵심

노이즈는 좌표에 대해 연속적인 값을 돌려주는 함수다. 출력 범위와 입력 주파수를 분리해서 다룬다.
