# 12.1 연속적인 변화로서의 노이즈

노이즈는 좌표를 입력받아 값 하나를 돌려주는 함수다. 그 값은 색 자체라기보다 밝기, 위치, 크기 같은 시각 속성을 조절하는 스칼라 필드의 표본으로 볼 수 있다. $n(x)$는 선을 따라 변하는 값, $n(x,y)$는 평면의 질감, $n(x,y,t)$는 시간축까지 포함한 변화를 만든다. 가까운 좌표에서 대체로 가까운 값을 내므로, 출력값을 색이나 위치에 연결해도 난수처럼 이웃한 지점 사이에서 변화가 갑자기 튀지 않는다.

$$
v=n(f_x\,x,f_y\,y)
$$

$f_x$, $f_y$는 입력 좌표를 얼마나 촘촘히 읽을지 결정하는 주파수다. 값 자체를 확대하는 진폭과 혼동하지 않는다. 노이즈의 출력 범위도 구현마다 다르다. 일부 라이브러리는 $[0,1]$, GLSL의 많은 구현은 $[-1,1]$을 쓴다.

```text
value = noise(x * frequency, y * frequency)
brightness = remap(value, noiseMin, noiseMax, 0, 1)
```

`noiseMin`과 `noiseMax`는 사용하는 노이즈 함수가 낼 수 있는 값의 범위에 맞춘다. 예를 들어 출력이 $[-1,1]$이면 0은 중간값이고 이를 $[0,1]$로 옮기면 밝기의 기준값으로 쓸 수 있다. 출력이 이미 $[0,1]$인 함수라면 같은 범위를 그대로 사용한다. 이처럼 노이즈의 출력값을 어느 속성으로 바꾸는지 정하는 단계와, 좌표를 노이즈 입력으로 바꾸는 단계는 구분해야 한다.

노이즈 이미지는 무작위 사진처럼 보이지만, 실은 결정적인 함수의 표본이다. 다음 의사 코드는 1차원 노이즈를 선을 따라 표본화해 그래프로 그린다.

```text
previousPoint = none
for i from 0 to sampleCount:
    x = i / sampleCount
    value = noise(x * frequency)
    height = remap(value, noiseMin, noiseMax, 0, amplitude)
    point = vec2(x * canvasWidth, baselineY - height)

    if previousPoint exists:
        drawLine(previousPoint, point)
    previousPoint = point
```

`x`는 노이즈 함수에 넣을 입력 위치를 0에서 1 사이로 정규화한 값이고, `frequency`는 그 구간에서 입력 좌표를 얼마나 늘릴지 정한다. `amplitude`는 표본값을 화면에서 세로로 얼마나 크게 나타낼지 정한다. 주파수를 바꾸면 가로축에서 지나가는 노이즈의 범위가 달라지고, 진폭을 바꾸면 그래프의 높이만 달라진다. 표본 수가 너무 적으면 이웃한 표본 사이의 세부 변화를 놓칠 수 있으므로, 그래프를 매끄럽게 관찰할 만큼 충분히 나눈다.

이처럼 좌표를 확대하거나 이동하고 시간 입력을 조금씩 바꾸면 노이즈가 만드는 결과도 예측 가능한 방식으로 달라진다.

## 연속성과 매끄러움

연속적이라는 말은 가까운 입력의 출력이 갑자기 멀어지지 않는다는 뜻이다. 하지만 모든 연속 노이즈가 같은 정도로 매끄러운 것은 아니다. 값만 이어지는 노이즈는 셀 경계에서 변화의 방향, 즉 기울기가 꺾여 보일 수 있다. 기울기까지 부드럽게 이어지는 노이즈는 좌표 변위의 흐름을 자연스럽게 만들고, 표면의 법선을 계산할 때도 유리하다. 법선은 주변 위치의 높이 변화에서 구하기 때문에, 값은 이어져도 기울기가 불연속이면 경계에 조명이나 방향의 흔적이 나타날 수 있다.

```text
continuous:      n(p) is close to n(p + smallOffset)
smooth derivative: change of n also changes gradually
```

Value Noise, Gradient Noise, Simplex Noise는 모두 연속적인 변화를 만들지만, 격자 경계의 성질과 고차원에서의 계산 방식은 다르다. 이후 절에서는 같은 "부드러움"을 만드는 서로 다른 접근을 비교한다.

## 입력 차원은 변화의 축을 뜻한다

$n(x)$는 선 위를 따라 변하는 값이므로 시간 그래프, 1차원 파형, 한 줄의 도형 배치에 적합하다. $n(x,y)$는 평면에 얼룩이나 지형 같은 구조를 만들고, $n(x,y,t)$는 시간축을 추가해 프레임 간에도 이어지는 변화를 만든다.

$$
v(t)=n(t\omega),\qquad
v(x,y,t)=n(f_x\,x,f_y\,y,f_t\,t)
$$

시간 좌표는 난수 시드처럼 매 프레임 교체하는 값이 아니라 노이즈 입력의 한 축으로 다룬다. 이전 프레임과 다음 프레임의 시간 입력이 가까우면 같은 위치의 값도 비슷하게 이어져 깜빡임 대신 흐름처럼 보인다. 시간 주파수 $f_t$를 낮추면 느리고 묵직한 변화가, 높이면 빠른 떨림이 생긴다. 프레임 번호보다 실제 경과 시간을 입력에 사용하면 프레임 속도가 달라져도 변화 속도가 프레임 수에 묶이지 않는다.

## 결정성과 시드

절차적 노이즈는 보통 같은 좌표와 같은 설정에 항상 같은 값을 반환한다. 많은 구현은 내부 해시나 순열 테이블을 사용한다. 사용자가 시드를 지정할 수 있는 구현에서는 시드를 바꾸면 같은 좌표에서도 다른 공간적 구조를 얻는다. 시드를 받지 않는 구현도 고정된 내부 규칙을 사용하므로, 같은 좌표를 다시 평가하면 같은 값이 나온다.

```text
setNoiseSeed(seed)
value = noise(position * frequency)
```

따라서 노이즈는 "무작위처럼 보이는 함수"이지, 호출할 때마다 새 값을 내는 일반 난수 함수가 아니다. 이 결정성 덕분에 카메라가 다시 그려도 같은 좌표의 질감이 유지되고, 마음에 드는 결과를 좌표와 파라미터, 지원되는 경우 시드로 다시 만들 수 있다. 시드가 바뀌면 같은 규칙과 좌표를 사용해도 다른 공간 패턴이 만들어진다.

## 주파수와 표본화

입력 주파수를 높이면 노이즈의 특징 크기가 작아진다. 화면 픽셀 좌표를 그대로 입력하면 캔버스 해상도를 바꿀 때 노이즈가 훑는 좌표 범위와 특징의 개수도 달라질 수 있다. 해상도와 관계없이 비슷한 규모를 유지하려면 좌표를 화면 크기나 작품의 기준 단위로 정규화한 뒤 주파수를 적용한다. 화면의 픽셀보다 훨씬 작은 변화는 충분히 표본화되지 못해 깜빡임과 거친 무늬를 만들 수 있다. 확대·축소되는 패턴에서는 노이즈 주파수와 출력 해상도를 함께 조절하고, 아주 높은 옥타브는 줄이거나 안티앨리어싱을 고려한다.

노이즈의 출력 범위를 정규화한 뒤 색·변위·마스크에 연결하는 습관도 중요하다. 색이나 마스크에 연결할 때는 필요한 값의 범위로 옮기고, 좌표 변위에 연결할 때는 노이즈가 기준 위치에서 어느 방향으로 얼마나 움직일지 정한다. 같은 노이즈라도 밝기에는 작은 진폭이면 충분하지만, 좌표 변위에는 너무 큰 진폭이 도형을 알아보기 어렵게 만들 수 있다. 입력 주파수는 특징의 공간적 크기를, 출력 진폭은 시각 속성의 변화 폭을 정하는 서로 다른 파라미터다.

## 이 절의 핵심

노이즈는 좌표를 연속적인 값으로 바꾸는 결정적 함수이며, 입력 주파수와 출력 진폭은 각각 특징의 크기와 변화 폭을 조절한다. 먼저 출력 범위를 확인하고, 노이즈값을 연결할 시각 속성과 그 속성의 허용 범위를 정한다.
