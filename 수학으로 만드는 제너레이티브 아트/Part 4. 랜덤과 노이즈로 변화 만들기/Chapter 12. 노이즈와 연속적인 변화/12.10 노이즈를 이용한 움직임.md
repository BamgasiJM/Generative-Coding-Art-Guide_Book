# 12.10 노이즈를 이용한 움직임

프레임마다 새 난수를 뽑아 위치를 정하면 점은 순간이동한다. 시간 $t$를 노이즈의 추가 입력으로 넣으면, 같은 객체가 부드럽게 방향과 속도를 바꾸는 움직임을 얻는다.

$$
x(t)=x_0+A\,n(s,t\omega)
$$

```text
for each particle:
    x = baseX + amplitude * noise(id, time * speed)
    y = baseY + amplitude * noise(id + 1000, time * speed)
```

`id`는 객체마다 다른 출발점을 만들고, `time * speed`는 변화 속도를 정한다. x와 y에 같은 노이즈를 사용하면 대각선 왕복처럼 보이기 쉬우므로 입력 오프셋을 나눈다. 밝기, 회전, 크기도 서로 다른 노이즈 채널에 연결하면 한 개체가 살아 있는 듯한 미세한 변화가 생긴다.

반복 애니메이션이 필요하다면 시간축을 직선으로 넣는 대신 원 위를 돈다. $n(x,y,\cos\theta,\sin\theta)$처럼 4차원 노이즈를 평가하면 시작 프레임과 끝 프레임이 이어질 수 있다. 구현이 어렵다면 미리 만든 주기 함수와 노이즈를 약하게 섞는 방법도 현실적이다.

## 위치를 직접 평가하는 움직임

위 예제는 시간에서 현재 위치를 직접 계산한다. 이전 프레임의 위치를 저장하지 않아도 되고, 임의의 시각 $t$에 곧바로 이동할 수 있으므로 부유하는 장식이나 루프 영상에 적합하다.

$$
\mathbf{p}(t)=\mathbf{p}_0+A\,\mathbf{n}(id,t)
$$

노이즈 구현이 $[0,1]$ 범위를 반환한다면, 위치 오프셋에는 $2n-1$처럼 0 중심 범위로 옮긴 값을 사용한다. 그렇지 않으면 모든 객체가 기준점의 한쪽으로 치우친다.

```text
offset = 2 * vectorNoise(id, time * speed) - 1
position = basePosition + offset * travelAmplitude
```

## 속도를 노이즈로 정하는 움직임

노이즈를 위치가 아니라 속도 또는 가속도에 연결할 수도 있다. 이 경우에는 이전 위치가 다음 위치에 영향을 주므로 상태를 저장하고 시간 간격으로 적분해야 한다.

$$
\mathbf{v}_{t+\Delta t}=A\,\mathbf{n}(\mathbf{p}_t,t),\qquad
\mathbf{p}_{t+\Delta t}=\mathbf{p}_t+\mathbf{v}_{t+\Delta t}\Delta t
$$

```text
direction = vectorNoise(particle.position * spatialFrequency,
                        time * temporalFrequency)
particle.velocity = normalize(direction) * speed
particle.position += particle.velocity * deltaTime
```

직접 위치 함수는 기준점 주변에서 움직임이 제한되지만, 속도 적분은 시간이 지나며 화면 멀리 이동할 수 있다. 흐름 필드와 입자 궤적에는 후자가 적합하며, 화면 경계에서 되돌리기·반복·제거·재생성 같은 규칙이 필요하다.

## 시간 주파수와 채널의 분리

시간 주파수가 낮으면 객체는 천천히 방향을 바꾸고, 높으면 진동과 떨림이 커진다. 공간 주파수가 낮은 벡터 노이즈는 가까운 객체가 비슷한 흐름을 공유하게 하고, 객체 ID 중심의 입력은 각 요소를 더 독립적으로 움직이게 한다.

```text
# 공통 흐름
flow = vectorNoise(position * lowSpatialFrequency, time * slowTime)

# 개체별 변화
individual = vectorNoise(id * idScale, time * slowTime)
```

위치, 크기, 회전, 밝기가 모두 같은 채널을 사용하면 한 리듬으로 변해 기계적으로 보일 수 있다. 입력 오프셋을 나누거나 일부 속성만 채널을 공유해, 독립성과 관계를 의도적으로 섞는다.

## 반복 루프의 시간 좌표

길이 $T$인 루프에서는 현재 시간을 각도 $\theta$로 바꾼다.

$$
\theta=2\pi\frac{t}{T}
$$

4D 노이즈를 사용할 수 있다면 원형 시간 좌표를 입력한다.

$$
v=n\left(\mathbf{p},r\cos\theta,r\sin\theta\right)
$$

```text
theta = TAU * frameIndex / totalFrames
value = noise4D(x, y, loopRadius * cos(theta), loopRadius * sin(theta))
```

이미지 시퀀스에서는 보통 프레임을 0부터 `totalFrames - 1`까지만 생성한다. $t=T$의 프레임은 첫 프레임과 같은 입력이므로 중복 저장하지 않는다.

## 출력 안정성과 Chapter 12의 마무리

처음에는 위치 오프셋만 점이나 선으로 표시해 범위와 속도를 확인한다. 시간 주파수, 진폭, 속성 연결을 한 번에 바꾸면 원인을 찾기 어려우므로 한 항목씩 추가한다. 속도를 적분할 때는 `deltaTime`을 곱하고, 위치를 시간 함수로 직접 계산할 때는 `elapsedTime`을 입력으로 쓴다.

Chapter 12에서 다룬 노이즈는 무작위 이미지를 만드는 버튼이 아니라, 좌표와 시간에서 연속적인 필드를 만드는 함수다. 다음 Chapter 13에서는 이 필드를 색, 거리, 방향, 밀도, 움직임의 공통 입력으로 다룬다.

## 이 절의 핵심

시간을 노이즈 입력에 포함하면 프레임 간 연속성이 생긴다. 객체 식별자와 채널 오프셋으로 각 객체의 움직임을 구분한다.
