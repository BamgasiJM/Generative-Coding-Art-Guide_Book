# 12.4 Simplex Noise

Simplex Noise는 Gradient Noise의 한 종류다. 직교 격자의 사각형이나 정육면체 대신, 삼각형·사면체처럼 꼭짓점 수가 적은 단순체(simplex)를 기본 셀로 사용한다. 2차원에서는 삼각형, 3차원에서는 사면체가 각 셀의 역할을 한다.

핵심은 입력점이 속한 단순체의 꼭짓점에서 기여값을 구하고, 가까운 꼭짓점의 기여를 부드럽게 더하는 것이다. 직교 격자 노이즈처럼 여러 방향으로 보간을 반복하지 않기 때문에 차원이 높아질수록 계산 구조가 유리해질 수 있다. 다만 좌표 변환과 해시, 그래디언트 계산이 필요하므로 모든 구현과 하드웨어에서 항상 더 빠른 것은 아니다.

Simplex Noise는 시간도 입력 좌표의 하나로 취급할 수 있다. 예를 들어 공간 위치와 시간을 함께 넣으면 프레임마다 새 난수를 뽑지 않고도 연속적으로 변하는 값을 얻는다.

```text
value = simplexNoise3D(x * spatialFrequency,
                       y * spatialFrequency,
                       time * temporalFrequency)
```

## 단순체가 줄이는 꼭짓점 수

$d$차원 단순체는 꼭짓점이 $d+1$개인 도형이다. 2차원에서는 세 꼭짓점을 가진 삼각형, 3차원에서는 네 꼭짓점을 가진 사면체가 된다. 반면 직교 격자의 한 셀은 각 축의 양 끝 조합을 모두 고려하므로 꼭짓점이 $2^d$개다.

| 차원 | 직교 격자 셀 | 단순체 셀 |
| --- | ---: | ---: |
| 2D | 4개 꼭짓점 | 3개 꼭짓점 |
| 3D | 8개 꼭짓점 | 4개 꼭짓점 |
| 4D | 16개 꼭짓점 | 5개 꼭짓점 |

2차원에서는 4개와 3개의 차이가 작아 보인다. 하지만 시간을 포함한 3차원, 또는 반복 애니메이션을 위한 4차원 노이즈에서는 한 표본에 필요한 꼭짓점 기여 수가 크게 달라진다. 이 개수는 Simplex Noise가 고차원에서 효율적인 이유 가운데 하나다. 실제 성능은 해시, 좌표 변환, 그래디언트 계산 비용에도 달려 있으므로 꼭짓점 수만으로 속도를 단정하지 않는다.

## 2차원에서 삼각형 셀 찾기

2차원 Simplex Noise는 평면을 삼각형들로 나눈다. 이 삼각 격자를 입력 좌표에서 바로 찾기보다는, 먼저 좌표를 비스듬히 기울이는 변환(skew)을 적용해 셀 인덱스를 구하고, 그 결과를 다시 원래 좌표계로 되돌리는 변환(unskew)을 사용한다. 이렇게 하면 삼각 격자의 셀을 정수 좌표로 다룰 수 있어, 현재 입력점이 속한 삼각형을 효율적으로 찾을 수 있다.

입력점이 $\mathbf{p}=(x,y)$일 때, skew 계수 $\alpha$를 사용해 다음처럼 격자 좌표를 구한다.

$$
\alpha=\frac{\sqrt{3}-1}{2},\qquad
i=\left\lfloor x+\alpha(x+y)\right\rfloor,\qquad
j=\left\lfloor y+\alpha(x+y)\right\rfloor
$$

그다음 unskew 계수 $\beta$로 셀의 원점을 원래 좌표계로 되돌린다.

$$
\beta=\frac{3-\sqrt{3}}{6},\qquad
\mathbf{o}=\left(i-(i+j)\beta,\ j-(i+j)\beta\right)
$$

여기서 $\mathbf{o}$는 현재 단순체를 찾기 위한 기준점이다. 입력점에서 이 기준점을 뺀 상대 위치 $\mathbf{l}=\mathbf{p}-\mathbf{o}$를 살펴보면 삼각형의 어느 쪽에 들어가는지 알 수 있다. 두 성분 중 어느 쪽이 큰지에 따라 중간 꼭짓점이 달라진다.

```text
unskewedPosition(I, J):
    shift = (I + J) * beta
    return (I - shift, J - shift)

skew = (x + y) * alpha
i = floor(x + skew)
j = floor(y + skew)

origin = unskewedPosition(i, j)
local = point - origin

if local.x > local.y:
    offsets = [(0, 0), (1, 0), (1, 1)]
else:
    offsets = [(0, 0), (0, 1), (1, 1)]

cornerIndices = [(i + dx, j + dy) for (dx, dy) in offsets]
```

`offsets`는 기울어진 격자에서 꼭짓점의 인덱스를 가리킨다. 예를 들어 `local.x > local.y`이면 중간 꼭짓점은 x축 쪽에 있고, 반대이면 y축 쪽에 있다. 이 비교가 사각형 한 칸을 두 삼각형 가운데 하나로 구분한다. 각 격자 꼭짓점을 원래 좌표계로 되돌려야 입력점과 꼭짓점 사이의 거리를 계산할 수 있다.

## 꼭짓점 기여를 감쇠해 더하기

Gradient Noise처럼 각 꼭짓점은 그래디언트 방향과 꼭짓점에서 입력점으로 향하는 변위의 내적으로 기여값을 만든다. Simplex Noise는 이 기여값을 단순한 선형 보간으로 섞는 대신, 꼭짓점 주변의 제한된 반경 안에서만 사용하고 거리에 따라 부드럽게 감쇠해 더한다.

```text
total = 0
for each of the simplex's corners:
    corner = unskewedPosition(cornerIndex.x, cornerIndex.y)
    offset = point - corner
    weight = max(0, supportRadiusSquared - dot(offset, offset))

    if weight > 0:
        gradientValue = dot(gradient(cornerIndex, seed), offset)
        total += weight^4 * gradientValue

return outputScale * total
```

`supportRadiusSquared`는 영향이 끝나는 거리의 제곱이다. 꼭짓점에서 멀어져 이 반경 바깥으로 나가면 `weight`가 0이 되어 해당 꼭짓점은 더 이상 결과에 기여하지 않는다. 양수인 가중치를 네 번 곱해 사용하면 기여가 경계에서 빠르게 줄어들어 이웃 단순체로 넘어갈 때 값이 부드럽게 이어진다. `gradient(cornerIndex, seed)`는 같은 격자 꼭짓점과 시드에 늘 같은 방향을 반환해야 이웃 단순체의 결과가 경계에서 이어진다. `outputScale`은 내부 합의 크기를 다루기 위한 계수이며, 반경이나 그래디언트 집합과 함께 구현에 따라 달라진다.

여기서 중요한 차이는 **영향을 받는 꼭짓점이 가까운 몇 개로 제한된다는 점**이다. 모든 꼭짓점의 값을 셀 전체에 걸쳐 보간하는 대신, 각 꼭짓점이 주변 영역에 국소적으로 기여한다. 2차원에서는 세 꼭짓점, 3차원에서는 네 꼭짓점의 기여가 기본이 된다.

## 3차원과 더 높은 차원

3차원에서는 단순체가 사면체이므로, 한 표본은 네 꼭짓점의 방향과 기여를 계산한다. 좌표 변환 후 상대 위치의 크기 순서를 이용해 현재 점이 속한 사면체의 꼭짓점 순서를 정한다. 4차원에서는 다섯 꼭짓점으로 같은 아이디어를 확장할 수 있다.

차원이 올라가도 핵심 단계는 같다.

1. 입력 좌표를 단순체 격자에 맞게 기울여 셀 인덱스를 찾는다.
2. 좌표를 되돌려 현재 셀의 상대 위치와 꼭짓점들을 정한다.
3. 가까운 각 꼭짓점의 그래디언트 기여를 거리 가중치로 감쇠한다.
4. 남은 기여를 더하고 구현의 출력 계수를 적용한다.

이 구조 덕분에 시간 좌표를 추가하는 것도 자연스럽다. 다만 차원이 높을수록 구현의 좌표 변환과 그래디언트 선택은 복잡해진다. 직접 구현이 목적이 아니라면 해당 차원을 지원하는 도구를 선택하고, 내부 알고리즘 전체보다 입력 차원·시드·출력 범위를 먼저 확인해도 충분하다.

## Perlin Noise와 비교하기

Simplex Noise와 Perlin Noise는 모두 꼭짓점 그래디언트와 내적을 사용하는 Gradient Noise다. 다른 점은 셀의 모양과 꼭짓점 기여를 합치는 방법이다.

| 항목 | 직교 격자 Gradient Noise | Simplex Noise |
| --- | --- | --- |
| 2차원 셀 | 사각형 | 삼각형 |
| 셀을 정하는 방법 | x·y 격자 구간을 각각 찾음 | skew·unskew로 단순체를 찾음 |
| 기여를 모으는 방법 | 셀 꼭짓점 값을 fade 보간 | 가까운 꼭짓점 기여를 감쇠해 합산 |
| 차원이 높을 때의 꼭짓점 수 | $2^d$ | $d+1$ |
| 구현에서 두드러지는 부분 | 보간 순서가 직관적 | 좌표 변환과 국소 감쇠가 필요 |

Simplex Noise는 사각 격자에 맞춰 반복되는 흔적을 줄이는 데 도움이 될 수 있지만, 모든 방향에서 완전히 같은 통계적 성질을 갖거나 방향성 흔적이 전혀 없는 것은 아니다. 그래디언트 선택과 구현에 따라 일정한 방향의 무늬가 보일 수 있다. Perlin Noise보다 언제나 더 자연스럽거나 빠른 것도 아니므로 목표 해상도와 입력 차원에서 실제 결과를 살펴 선택한다.

## 시간 입력과 반복 애니메이션

3차원 Simplex Noise의 세 번째 좌표를 시간으로 사용하면 위치와 시간이 하나의 연속 함수에 들어간다.

$$
v(x,y,t)=n(f_x\,x,\ f_y\,y,\ f_t\,t)
$$

$f_x$와 $f_y$는 공간에서 특징이 나타나는 크기, $f_t$는 시간에 따른 변화 속도를 조절한다. 프레임마다 무관한 난수를 새로 뽑는 방식과 달리, 시간이 조금 변하면 입력 좌표도 조금 이동하므로 출력도 점진적으로 바뀐다. 이 절에서는 노이즈의 입력 구조만 다루며, 움직임에 적용하는 구체적인 방법은 뒤의 움직임 절에서 다룬다.

일반적인 직선 시간 입력은 애니메이션의 시작과 끝에서 같은 값으로 돌아오지 않는다. 완전히 반복되는 루프가 필요하다면 시간을 원 위의 두 좌표로 바꾸고, 이를 공간 좌표와 함께 4차원 노이즈에 넣는다.

$$
\theta=2\pi\frac{t}{T},\qquad
v(x,y,t)=n\left(f_x\,x,\ f_y\,y,\ r\cos\theta,\ r\sin\theta\right)
$$

```text
theta = 2 * PI * time / loopDuration
value = simplexNoise4D(x * spatialFrequency,
                       y * spatialFrequency,
                       loopRadius * cos(theta),
                       loopRadius * sin(theta))
```

시간 $t=0$과 $t=T$에서 원 위의 입력 좌표가 같고 진행 방향도 이어지므로 노이즈값이 경계에서 자연스럽게 반복된다. 4차원 노이즈가 필요하고, 공간 좌표와 시간 좌표를 같은 반복 함수에 연결해야 한다. 단순히 애니메이션 마지막 프레임을 첫 프레임과 같게 강제하는 방법보다 경계에서 덜 끊기는 루프를 만들 수 있다.

## 사용할 때 확인할 점

Simplex Noise라는 이름만으로 구현의 세부 사항을 단정하지 않는다. 도구나 라이브러리를 사용할 때는 다음 항목을 확인한다.

- 입력으로 지원하는 차원과 시드 설정 방식
- 출력 범위와 값의 평균
- 타일처럼 반복되는 입력을 지원하는지
- 기울기나 도함수를 직접 반환하는지
- 목표 해상도와 하드웨어에서의 계산 비용

Simplex Noise 자체가 앨리어싱을 없애 주지는 않는다. 입력 주파수가 지나치게 높거나 fBm의 고주파 옥타브가 화면 픽셀보다 작으면, 어떤 연속 노이즈라도 깜빡이거나 무늬가 뭉개질 수 있다. 렌더링할 크기에서 표본을 확인하고 필요한 세부 수준을 조절한다.

또한 꼭짓점 수가 적다는 설명은 알고리즘의 구조를 비교하는 기준이지, 최종 실행 시간이 언제나 짧다는 보장은 아니다. 실제로 쓸 구현이 있는지, 출력 범위와 반복성이 작업에 맞는지, 최종 화면에서 원하는 질감이 나오는지를 함께 판단한다.

## 이 절의 핵심

Simplex Noise는 단순체의 적은 꼭짓점에서 나온 그래디언트 기여를 거리 가중치로 감쇠해 더한다. skew·unskew 좌표 변환으로 단순체를 찾으며, 이런 셀 구조는 특히 고차원 연속 노이즈에서 유용하다.
