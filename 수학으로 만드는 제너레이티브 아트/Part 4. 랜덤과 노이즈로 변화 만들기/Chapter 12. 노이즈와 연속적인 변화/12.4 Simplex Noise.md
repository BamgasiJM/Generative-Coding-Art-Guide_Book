# 12.4 Simplex Noise

Simplex Noise는 사각 격자 대신 삼각형, 3차원에서는 사면체 같은 단체(simplex)를 기반으로 한다. 2차원 사각 셀은 네 꼭짓점을 고려하지만, 단순체 셀에서는 필요한 꼭짓점 수가 더 적다. 차원이 올라갈수록 이 차이가 계산량과 방향성에 영향을 준다.

Simplex Noise의 장점은 고차원에서 비교적 효율적이고, 사각 격자에 정렬된 흔적이 덜 보인다는 점이다. 특히 3차원 노이즈 $n(x,y,t)$를 이용해 시간 변화를 만들 때 유용하다. 시간축을 독립 좌표로 넣으므로 프레임마다 난수를 다시 뽑는 방식보다 자연스럽게 이어진다.

```text
value = simplexNoise(x * frequency,
                     y * frequency,
                     time * temporalFrequency)
```

알고리즘을 직접 구현할 필요는 없다. 셰이더 유틸리티, DCC 도구의 노이즈 노드, 라이브러리 구현을 사용할 수 있다. 다만 라이선스, 출력 범위, 반복 가능 여부, 미분 가능성이 프로젝트에 맞는지 확인한다. 이름이 Simplex라고 해서 언제나 Perlin 계열보다 더 좋은 것은 아니다. 작은 2차원 텍스처에는 구현의 단순성과 원하는 시각적 성질이 더 중요하다.

## 단순체가 줄이는 꼭짓점 수

$d$차원의 단순체는 꼭짓점이 $d+1$개인 가장 단순한 다면체다. 2차원에서는 삼각형, 3차원에서는 사면체, 4차원에서는 5개의 꼭짓점을 가진 도형이 된다. 반면 직교 격자의 한 셀은 차원이 높아질수록 $2^d$개의 꼭짓점을 가진다.

| 차원 | 직교 격자 셀의 꼭짓점 | 단순체의 꼭짓점 |
| --- | ---: | ---: |
| 2D | 4 | 3 |
| 3D | 8 | 4 |
| 4D | 16 | 5 |

따라서 2D에서는 차이가 작아 보이지만, 시간까지 포함한 3D 또는 루프용 4D 노이즈에서는 한 표본을 계산할 때 고려해야 할 꼭짓점 수의 차이가 커진다. 이것이 Simplex Noise가 고차원 절차적 애니메이션에서 자주 언급되는 이유다.

## 기울기 기여와 감쇠

Simplex Noise도 Gradient Noise처럼 꼭짓점마다 의사 난수 방향 벡터를 두고, 입력점까지의 변위와 내적을 사용한다. 다만 각 꼭짓점의 기여는 단순히 보간되는 대신, 꼭짓점에서 일정 거리 안에서만 부드럽게 영향을 주도록 감쇠된다.

```text
for each simplex corner:
    offset = point - corner
    gradientContribution = dot(gradient(corner), offset)
    weight = max(0, supportRadius - dot(offset, offset))
    sum += weight^4 * gradientContribution
```

정확한 상수와 거듭제곱은 구현마다 다를 수 있지만, 핵심은 가까운 단순체 꼭짓점만 현재 점에 기여한다는 점이다. 입력 좌표를 단순체 격자에 맞게 기울이고(skew), 다시 원래 좌표계의 상대 위치를 찾는 과정이 포함되므로, 직접 구현은 Value Noise나 기본 Gradient Noise보다 길어진다.

## Gradient Noise와의 관계

Simplex Noise와 Perlin Noise는 모두 격자 꼭짓점의 방향 벡터와 내적을 사용한다는 점에서 Gradient Noise 계열이다. 차이는 값을 배치하는 격자의 구조와, 이웃 기여를 모으는 방식에 있다.

| 항목 | 직교 격자 Gradient Noise | Simplex Noise |
| --- | --- | --- |
| 기본 셀 | 사각형·정육면체 | 삼각형·사면체 등 단순체 |
| 고차원 꼭짓점 수 | $2^d$ | $d+1$ |
| 격자 축의 흔적 | 조건에 따라 보일 수 있음 | 상대적으로 덜 두드러짐 |
| 구현 난이도 | 비교적 직관적 | 좌표 skew/unskew가 추가됨 |

어떤 구현이 더 자연스럽게 보이는지는 주파수, 옥타브, 색상 매핑, 화면 해상도에도 좌우된다. 알고리즘 이름만 보고 선택하기보다, 목표 해상도와 움직임에서 실제 결과를 비교한다.

## 시간 변화와 루프

3D Simplex Noise에서 세 번째 입력을 시간으로 사용하면 공간과 시간이 같은 연속 함수 안에 들어간다.

$$
v(x,y,t)=n(f_x\,x,f_y\,y,f_t\,t)
$$

시간 축의 주파수 $f_t$는 공간 주파수와 독립적으로 조절한다. 큰 얼룩이 빠르게 변하거나, 미세한 결이 아주 천천히 움직이게 만들 수도 있다. 다만 일반적인 직선 시간 입력은 시작 시각과 끝 시각이 자동으로 이어지지 않는다.

반복 애니메이션이 필요하면 시간을 원 위의 두 좌표로 바꿔 4D 노이즈에 넣을 수 있다.

$$
v(x,y,t)=n\left(x,y,r\cos\theta,r\sin\theta\right),\qquad
\theta=2\pi\frac{t}{T}
$$

이 방식은 루프의 처음과 끝에서 같은 4차원 입력을 만들지만, 사용할 라이브러리가 4D 노이즈를 제공하는지 확인해야 한다.

## 사용할 때 확인할 점

라이브러리의 `simplexNoise`라는 이름만으로 구현 특성을 단정하지 않는다. 출력 범위가 $[-1,1]$인지 $[0,1]$인지, 시드를 설정할 수 있는지, 같은 입력에서 플랫폼마다 같은 결과가 나오는지, 주기 타일링을 지원하는지 확인한다. 특히 셰이더에서 가져온 공개 구현은 정밀도와 플랫폼에 따라 미세한 차이를 낼 수 있다.

또한 Simplex Noise 자체는 앨리어싱을 없애지 않는다. 아주 높은 입력 주파수나 많은 fBm 옥타브를 화면 픽셀보다 작게 만들면 어떤 노이즈 알고리즘도 깜빡일 수 있다. 원하는 시각적 특징 크기와 출력 해상도를 먼저 정하는 것이 우선이다.

## 이 절의 핵심

Simplex Noise는 단순체 격자를 사용해 고차원 연속 노이즈를 효율적으로 만든다. 시간까지 포함한 매끄러운 변화를 만들 때 특히 적합하다.
