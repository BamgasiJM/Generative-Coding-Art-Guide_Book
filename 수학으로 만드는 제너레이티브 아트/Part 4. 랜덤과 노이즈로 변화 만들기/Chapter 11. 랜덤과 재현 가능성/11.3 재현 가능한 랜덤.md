# 11.3 재현 가능한 랜덤

재현 가능성은 우연을 없애려는 요구가 아니다. 같은 결과를 다시 열고, 수정 전후를 비교하고, 이미지 한 장을 정확히 내보내기 위한 작업 조건이다. 시드 기반 의사 난수 생성기에서는 시드와 함께 난수 호출 순서도 결과에 영향을 준다.

다음 예시에서는 `enabled`가 참일 때만 두 번째 난수를 요청한다.

```text
value = random()
if enabled:
    accent = random()
```

같은 시드로 시작해도 `enabled`의 값이나 실행 경로가 달라지면 그 뒤의 요소들이 받는 난수는 달라질 수 있다. 순차 난수 생성기는 내부 상태를 한 단계씩 진행하므로, 중간에 난수 호출을 추가하거나 반복 순서를 바꾸면 이후 값의 배정도 밀린다. 시드만 기록하는 것으로 부족할 수 있는 이유다.

## 키 기반 해시로 값 고정하기

구조가 바뀌어도 각 요소의 값을 유지해야 한다면, 난수 수열의 다음 값을 꺼내는 대신 요소의 식별자를 입력으로 해시값을 계산할 수 있다. 전체 시드와 셀 좌표를 키로 삼는 경우는 다음처럼 나타낼 수 있다.

$$
u_{ij}=H(i,j,s)
$$

여기서 $i,j$는 셀의 정수 좌표이고 $s$는 시드다. $H$는 같은 입력 키에 항상 같은 $[0,1)$ 값을 반환하는 결정적 함수다. 이 방법은 생성기 상태를 바꾸지 않는다. 따라서 셀을 새로 추가하거나 순회 순서를 바꾸더라도, 기존 셀에 같은 키를 사용하면 그 셀의 값은 유지된다.

GPU 셰이더에서 자주 쓰이는 간단한 좌표 해시의 한 예는 다음과 같다.

```glsl
float hash31(vec3 key) {
  float h = dot(key, vec3(127.1, 311.7, 74.7));
  return fract(sin(h) * 43758.5453);
}

float value = hash31(vec3(cell, float(seed)));
```

`dot`은 셀 좌표와 시드를 가중합해 하나의 수 `h`로 섞는다. `sin`은 그 입력을 비선형적으로 변화시키고, 큰 상수를 곱한 뒤 `fract`를 취해 소수부를 $[0,1)$ 범위의 값으로 만든다. 여기서 상수는 입력 좌표가 단순한 규칙으로 반복되는 흔적을 줄이기 위한 선택값이다. 이런 식은 이해와 구현이 간단해 셀 장식값을 만드는 데 유용하지만, 출력이 완벽하게 균일하거나 서로 독립적이라는 보장은 없다.

색과 크기처럼 한 셀에서 여러 값을 만들 때는 셀 좌표와 시드 외에 속성 식별자도 키에 포함할 수 있다. 예를 들어 크기용 키와 색상용 키를 다르게 만들면 두 값이 똑같이 반복되는 일을 줄일 수 있다. 다만 서로 다른 키를 썼다고 통계적으로 완전히 독립인 값이 되는 것은 아니다. 해시가 만드는 상관과 분포 품질은 실제 결과를 살펴야 한다.

## 해시의 용도와 한계

해시는 각 셀이나 개체에 고정된 장식값을 배정할 때 적합하다. 반대로 시간에 따라 연속적으로 이어지는 값을 만들거나 확률 분포를 정확히 따르려면, 그 목적에 맞는 생성기나 변환이 필요하다. 해시만으로 점 사이의 최소 간격이나 균일한 공간 배치를 보장할 수도 없다. 분포의 모양은 11.5절에서, 격자와 셀 위의 배치는 11.6절에서 다룬다.

간단한 `sin` 기반 해시는 큰 좌표를 부동소수점으로 처리할 때 정밀도 한계가 드러나거나, 특정 입력 범위에서 반복 무늬가 보일 수 있다. GPU와 CPU의 수치 연산 차이 때문에 서로 다른 장치에서 결과가 비트 단위로 완전히 같지 않을 수도 있다. 작품의 작은 시각 변형에는 충분할 수 있지만, 품질과 이식성이 중요하다면 정수 연산 기반 해시나 검증된 라이브러리를 고려한다. 어떤 해시도 보안용 난수 생성기를 대신하지 않는다.

해시의 출력이 실제로 어떤 모양을 만드는지는 수치 목록만으로 판단하기 어렵다. 작은 격자에서 셀마다 색이나 원 크기를 표시하고, 이웃 셀 사이의 줄무늬·반복·군집이 눈에 띄는지 확인한다. 무작위 표본에서도 자연스러운 군집은 생길 수 있으므로, 한 번의 결과만 보고 해시의 결함이라고 단정하지 말고 여러 시드와 범위에서 비교한다.

## 이 절의 핵심

순차 난수 생성기는 시드와 호출 순서에 따라 값이 진행된다. 키 기반 해시는 셀 좌표와 시드 같은 식별자로 값을 직접 계산하므로 순회 순서가 바뀌어도 기존 요소의 값이 유지된다. 두 방식 모두 재현 가능하지만, 분포와 공간적 배치의 품질은 별도로 확인해야 한다.
