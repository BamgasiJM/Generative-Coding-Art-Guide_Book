# 11.3 재현 가능한 랜덤

재현 가능성은 우연을 없애려는 요구가 아니다. 같은 결과를 다시 열고, 수정 전후를 비교하고, 이미지 한 장을 정확히 내보내기 위한 작업 조건이다. 재현 가능한 작업은 시드뿐 아니라 난수 호출의 순서도 고정해야 한다.

다음 두 코드는 시드가 같아도 결과가 달라질 수 있다. 두 번째 코드가 조건에 따라 난수를 하나 더 소비하기 때문이다.

```text
value = random()
if enabled:
    accent = random()
```

따라서 구조 변화에 강한 방법은 항목별 시드를 만드는 것이다. 전체 시드와 셀 좌표를 해시해 각 셀의 값을 독립적으로 구하면, 다른 셀을 추가해도 기존 셀의 값이 밀리지 않는다.

$$
u_{ij}=H(i,j,s)
$$

여기서 $H$는 입력이 같으면 같은 $[0,1)$ 값을 돌려주는 해시 함수다. GPU 셰이더에서는 좌표 기반 해시가 특히 유용하다.

```glsl
float hash21(vec2 p) {
  return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
}
```

이런 간단한 해시는 통계적 난수 생성기보다 품질이 낮을 수 있지만, 반복 타일의 장식값처럼 지역적으로 고정된 변화를 만들 때는 충분하다.

## 이 절의 핵심

재현성은 시드와 호출 순서에 달려 있다. 독립적인 요소에는 좌표나 식별자 기반 해시를 사용하면 수정에도 결과가 안정적이다.
