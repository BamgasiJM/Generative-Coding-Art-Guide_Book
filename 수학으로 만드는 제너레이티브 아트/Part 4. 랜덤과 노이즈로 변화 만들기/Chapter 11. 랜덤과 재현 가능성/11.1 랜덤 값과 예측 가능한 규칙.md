# 11.1 랜덤 값과 예측 가능한 규칙

제너레이티브 아트에서 랜덤은 규칙의 부재가 아니다. 오히려 정해진 규칙이 선택할 수 있는 여러 결과 가운데 하나를 고르는 장치다. 난수 함수가 $[0,1)$의 값을 돌려준다면, 그 값 하나로 위치, 크기, 색, 방향처럼 서로 다른 속성을 만들 수 있다.

$$
x=x_{min}+(x_{max}-x_{min})u,\qquad u\in[0,1)
$$

이 식은 $u$를 원하는 범위로 옮긴다. $u=0$이면 $x_{min}$이 되고, $u$가 1에 가까워질수록 $x_{max}$에 가까워진다. 난수의 범위를 바꾸는 것과 값이 어느 쪽에 더 자주 모이게 할지를 정하는 것은 서로 다른 설계다. 전자는 범위 매핑이고, 후자는 분포 선택이며 뒤의 11.5절에서 다룬다.

완전히 예측할 수 없는 결과보다 중요한 것은 무엇을 랜덤하게 둘지 명확히 정하는 일이다. 예를 들어 점의 위치는 격자에 고정하고 밝기만 바꾸면 질서가 남는다. 반대로 위치와 크기와 색을 모두 독립적으로 뽑으면 밀도와 대비가 먼저 눈에 들어온다.

```text
for each cell:
    value = random(0, 1)
    drawCircle(cell.center, radius = map(value, 0, 1, 2, 10))
```

랜덤 값은 입력값이다. 따라서 범위, 분포, 시드, 다른 변수와의 상관관계를 설계해야 한다. 이 장에서는 매번 달라지는 결과를 다루되, 필요할 때는 같은 결과로 되돌아갈 수 있는 방법을 함께 다룬다.

특히 무엇을 고정할지도 랜덤하게 둘 항목만큼 중요하다. 격자 위치를 유지하고 반지름만 바꾸면 반복 구조가 먼저 보이고, 위치까지 흔들면 덩어리와 빈 공간이 생긴다. 위치·크기·색을 모두 바꾸는 선택도 가능하지만, 그때는 각 변화가 서로를 가리지 않는지 결과 화면에서 확인해야 한다.

하나의 난수값을 여러 속성에 재사용하면 그 속성들은 연결된다. 예를 들어 크기가 큰 요소일수록 밝은 색을 쓰도록 같은 값으로 둘 다 계산하면 의도된 상관관계가 생긴다. 크기와 색을 서로 독립적으로 변화시키고 싶다면 각각 별도의 값을 뽑는다.

```text
for each cell:
    sizeValue = random(0, 1)
    colorValue = random(0, 1)
    radius = map(sizeValue, 0, 1, 2, 10)
    color = palette(colorValue)
```

반대로 `color = palette(sizeValue)`처럼 색도 같은 값에서 계산하면 크기와 색이 함께 움직인다. 어느 쪽이 더 낫다는 뜻은 아니다. 속성 사이에 관계를 만들려는지, 각자 별도로 변화시키려는지를 먼저 정하면 결과를 조절하기 쉬워진다.

## 랜덤을 적용하는 단위

랜덤값 하나가 무엇에 대응하는지 먼저 정하면 규칙이 선명해진다. 프레임마다 새 값을 뽑으면 깜빡임이 생기고, 개체마다 한 번 뽑으면 각 개체의 성격이 되며, 셀 좌표에서 값을 만들면 공간에 고정된 질감이 된다. 같은 `random()` 호출도 적용 단위에 따라 전혀 다른 시간성과 구조를 만든다.

```text
per frame:  random value changes every update
per object: random value is stored at creation
per cell:   random value is derived from cell ID and seed
```

따라서 랜덤을 넣기 전에 변화가 시간에 붙어야 하는지, 개체에 붙어야 하는지, 공간에 붙어야 하는지를 결정한다.

개체에 한 번 부여한 값은 생성 시 저장해 두어야 매 프레임 같은 특성을 유지한다. 매 프레임 난수를 다시 뽑으면 개체의 성격이 아니라 시간에 따라 깜빡이는 변화가 된다. 셀에 고정된 랜덤도 셀 번호와 시드에서 값을 계산하거나 처음 생성할 때 저장해야 화면이 다시 그려질 때마다 위치가 바뀌지 않는다. 시드를 이용해 같은 랜덤 결과를 재현하는 방법은 11.2절에서 이어서 다룬다.

## 이 절의 핵심

랜덤은 규칙을 없애는 도구가 아니라 규칙 안에 선택 폭을 만든다. 무엇을 고정하고 무엇을 변화시킬지, 랜덤값을 어떤 단위로 유지할지, 여러 속성을 함께 움직일지 따로 움직일지 정하면 결과의 질서를 설계할 수 있다.
