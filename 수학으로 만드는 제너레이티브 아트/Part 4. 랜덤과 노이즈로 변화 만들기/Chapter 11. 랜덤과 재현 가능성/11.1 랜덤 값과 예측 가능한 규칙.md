# 11.1 랜덤 값과 예측 가능한 규칙

제너레이티브 아트에서 랜덤은 정해 둔 규칙이 허용하는 여러 결과 가운데 하나를 선택하는 방식이다. 난수 함수가 $[0,1)$의 값을 돌려준다면, 그 값을 위치·크기·색·방향처럼 서로 다른 시각 속성의 입력으로 쓸 수 있다.

$$
x=x_{min}+(x_{max}-x_{min})u,\qquad u\in[0,1)
$$

이 식은 $u$의 범위를 $x_{min}$에서 $x_{max}$ 사이로 선형 변환한다. $x_{min}<x_{max}$일 때 $u=0$이면 $x_{min}$이 되고, $u$가 1에 가까워질수록 $x_{max}$에 가까워진다. 입력 범위가 $[0,1)$이므로 출력 범위도 $[x_{min},x_{max})$이며, 최댓값은 포함되지 않는다. $x_{min}=x_{max}$라면 난수와 관계없이 결과는 그 한 값으로 고정된다. 이 선형 변환은 값의 범위를 정하지만, 입력값이 범위 안에서 어느 쪽에 더 자주 나타나는지는 바꾸지 않는다. 범위 매핑과 분포 선택은 별개의 설계이며, 분포는 뒤의 11.5절에서 다룬다.

먼저 어떤 속성을 랜덤하게 바꿀지 정하면 각 변화가 화면에 미치는 영향을 파악하기 쉽다. 점의 위치를 격자에 고정하고 밝기만 바꾸면 격자의 질서는 남는다. 위치·크기·색을 모두 따로 뽑으면 배치, 크기 차이, 대비가 한꺼번에 달라져 전체 밀도와 시각적 무게가 크게 변한다.

```text
for each cell:
    value = random(0, 1)
    drawCircle(cell.center, radius = map(value, 0, 1, 2, 10))
```

이 예시에서는 셀의 위치는 고정하고 반지름만 2에서 10 사이로 변화시킨다. 난수는 도형을 직접 그리는 명령이 아니라, 규칙에 전달하는 입력값이다. 따라서 어떤 범위와 분포를 쓸지, 값을 언제 다시 뽑을지, 다른 속성과 연결할지를 설계해야 한다. 이 장에서는 결과가 달라지는 방식을 살펴보고, 필요할 때 같은 결과를 다시 만드는 방법도 다룬다.

무엇을 고정할지도 랜덤하게 바꿀 항목만큼 중요하다. 격자 위치를 유지하고 반지름만 바꾸면 반복 구조가 먼저 보인다. 위치까지 흔들면 격자가 느슨해지고 덩어리와 빈 공간이 생길 수 있다. 위치·크기·색을 모두 바꾸는 방식도 가능하지만, 독립적으로 값을 뽑는다고 도형 사이의 간격이나 겹침이 자동으로 제어되지는 않는다. 겹침을 막거나 최소 간격을 유지하려면 랜덤 범위와 별도로 배치 조건을 정해야 한다.

하나의 난수 표본을 여러 속성에 재사용하면 그 속성들 사이에 정해진 관계가 생긴다. 예를 들어 같은 값으로 크기와 밝기를 계산하면 큰 요소일수록 밝게 만들 수 있다. 크기와 색을 별도로 변화시키려면 각각 별도의 난수 표본을 사용한다. 표본을 따로 뽑아도 작은 화면에서는 우연히 함께 변하는 것처럼 보일 수 있지만, 설계 단계에서 두 속성을 직접 연결하지 않은 상태가 된다.

```text
for each cell:
    sizeValue = random(0, 1)
    colorValue = random(0, 1)
    radius = map(sizeValue, 0, 1, 2, 10)
    color = palette(colorValue)
```

반대로 `color = palette(sizeValue)`처럼 색도 같은 값에서 계산하면 크기와 색이 함께 변한다. 속성 사이에 관계를 둘지 각각 다르게 변화시킬지 먼저 정하면, 의도한 시각적 구성을 조절하기 쉽다.

## 랜덤을 적용하는 단위

랜덤값 하나가 무엇에 대응하는지 먼저 정하면 규칙이 선명해진다. 프레임마다 새 값을 뽑으면 깜빡임이 생기고, 개체마다 한 번 뽑으면 각 개체의 성격이 되며, 셀 좌표에서 값을 만들면 공간에 고정된 질감이 된다. 같은 `random()` 호출도 적용 단위에 따라 전혀 다른 시간성과 구조를 만든다.

```text
per frame:  random value changes every update
per object: random value is stored at creation
per cell:   random value is derived from cell ID and seed
```

따라서 랜덤을 넣기 전에 변화가 시간에 붙어야 하는지, 개체에 붙어야 하는지, 공간에 붙어야 하는지를 결정한다.

개체에 한 번 부여한 값은 생성 시 저장해 두어야 매 프레임 같은 특성을 유지한다. 매 프레임 난수를 다시 뽑으면 개체의 성격이 아니라 시간에 따라 깜빡이는 변화가 된다. 셀에 고정된 랜덤도 셀 번호와 시드에서 값을 계산하거나 처음 생성할 때 저장해야 화면이 다시 그려질 때마다 위치가 바뀌지 않는다. 시드를 이용해 같은 랜덤 결과를 재현하는 방법은 11.2절에서 이어서 다룬다.

## 이 절의 핵심

랜덤은 규칙을 없애는 도구가 아니라 규칙 안에 선택 폭을 만든다. 무엇을 고정하고 무엇을 변화시킬지, 랜덤값을 어떤 단위로 유지할지, 여러 속성을 함께 움직일지 따로 움직일지 정하면 결과의 질서를 설계할 수 있다.
