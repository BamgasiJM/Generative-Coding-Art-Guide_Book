# 11.4 랜덤한 위치, 크기, 회전, 색

하나의 난수 $u$를 화면의 속성 범위로 옮기는 기본 방법은 선형 매핑이다. 그러나 모든 속성을 같은 방식으로 독립 추출하면 결과가 산만해질 수 있다. 화면의 역할에 따라 고정할 것과 흔들 것을 나눈다.

| 속성 | 흔히 쓰는 범위 | 설계 질문 |
| --- | --- | --- |
| 위치 | 화면 또는 셀 내부 | 가장자리와 중심의 밀도를 같게 할까 |
| 크기 | 최소값~최대값 | 작은 요소가 얼마나 많아야 할까 |
| 회전 | $0$~$2\pi$ | 방향성을 남길까 |
| 색 | 팔레트 또는 색상환 | 명도 대비를 제한할까 |

```text
position = randomPointInRect(bounds)
radius = lerp(minRadius, maxRadius, random())
angle = random(0, TAU)
color = palette[randomInteger(0, palette.length)]
```

모든 값을 독립적으로 뽑는 대신 하나의 공통값을 여러 속성에 연결할 수도 있다. 큰 원일수록 밝게 하고, 회전은 크기에 비례하게 하면 요소 사이에 읽을 수 있는 관계가 생긴다. 반대로 위치와 색을 독립으로 두면 표면의 질감이 강조된다.

색은 무작정 RGB 각 채널을 랜덤하게 고르기보다, 제한한 팔레트에서 선택하거나 HSL의 색상만 넓게 바꾸는 편이 조화롭다. 투명도까지 랜덤하게 할 때는 겹침이 어두워지는 합성 방식도 함께 확인한다.

## 이 절의 핵심

위치, 크기, 회전, 색은 각각 다른 시각적 기능을 가진다. 독립 난수와 공통 난수를 의도적으로 섞어 관계와 변화를 조절한다.
