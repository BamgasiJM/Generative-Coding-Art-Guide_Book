# 11.7 랜덤을 통제하는 파라미터

작품에서 랜덤을 조절하려면 난수 호출을 의미 있는 파라미터에 연결한다. 각 파라미터가 어떤 속성을 어느 범위에서 바꾸는지 정해 두면, 값을 조정했을 때 화면의 어떤 특성이 달라질지 예측하기 쉽다.

| 파라미터 | 역할 | 예 |
| --- | --- | --- |
| `seed` | 재현할 결과 선택 | 타일 배치 후보 중 하나를 고정 |
| `amount` | 요소의 수 또는 활성 비율 | 점의 개수, 켜지는 셀의 비율 |
| `spread` | 위치가 기준에서 벗어나는 폭 | 격자 중심 주변의 흔들림 |
| `variation` | 속성이 기준값에서 달라지는 폭 | 원의 반지름이나 색 밝기 범위 |
| `correlation` | 속성들이 함께 변하는 정도 | 큰 원일수록 밝게 만들기 |

## 파라미터별 사용 예

**`seed`: 마음에 드는 구성을 선택하고 다시 만들기**

격자마다 도형 하나를 놓는 작품에서 시드는 배치와 속성값을 결정하는 재료가 된다. 시드를 `12`에서 `13`으로 바꾸면 대개 다른 구성이 나오고, 같은 알고리즘과 입력값을 유지한 채 `12`로 되돌리면 같은 구성을 다시 얻는다. 여러 후보를 빠르게 살펴본 뒤 마음에 드는 시드와 나머지 파라미터 값을 함께 기록하면, 난수 채널을 배치와 색으로 나누어 둔 경우 색이나 크기만 바꾸면서 배치는 그대로 비교할 수 있다. 다만 같은 시드를 사용해도 알고리즘이나 난수 호출 순서가 바뀌면 순차 난수의 결과는 달라질 수 있고, 해시를 사용하는 경우에도 해시 구현을 바꾸면 결과가 달라질 수 있다. 시드는 변화량을 키우는 값이 아니라 재현할 결과를 고르는 값이다.

**`amount`: 얼마나 많이 나타나게 할지 정하기**

별이 흩어진 하늘을 만든다면 `amount`를 활성 확률로 해석할 수 있다. 각 셀에서 0 이상 1 미만의 해시값 `hash(cellId, seed)`가 `amount`보다 작은지 검사하고, `amount = 0.15`로 두면 셀의 약 15%가 별을 갖는다. 이는 기대 비율이므로 화면이 작거나 셀 수가 적으면 실제 별의 수는 달라질 수 있다. 정확히 별 80개가 필요하다면 후보 위치들 가운데 중복 없이 80개를 선택하거나, 후보 전체를 무작위 순서로 정한 뒤 앞에서 80개를 사용한다. 즉, 작품에서 `amount`가 비율인지 정확한 개수인지 먼저 정해야 한다.

**`spread`: 격자 규칙을 얼마나 흐트러뜨릴지 정하기**

도형을 셀 중심에 놓으면 정돈된 격자가 된다. 셀 크기를 `cellWidth`, `cellHeight`라고 할 때 위치 오프셋을 다음 범위에서 고를 수 있다.

```text
offsetX = (2 * randomX - 1) * spread * cellWidth
offsetY = (2 * randomY - 1) * spread * cellHeight
position = cellCenter + (offsetX, offsetY)
```

`randomX`와 `randomY`를 서로 독립적으로 0 이상 1 미만에서 뽑으면 오프셋은 각 축에서 `-spread`부터 `+spread` 셀 크기까지 움직인다. `spread = 0`이면 모든 도형이 셀 중심에 놓이고, `spread = 0.1`이면 중심 근처에서만 살짝 흔들린다. 이 값은 셀 크기에 대한 비율이므로, 실제 이동 거리는 셀의 가로·세로 크기에 따라 달라진다. 값을 크게 하면 이웃 셀로 넘어가거나 도형끼리 겹칠 수 있으므로, 흐트러짐 자체가 의도인지 격자 구조를 유지할 것인지에 맞춰 조절한다.

**`variation`: 기준값 주변의 변화 폭 정하기**

원의 반지름을 모두 같게 시작한 다음 조금씩 다르게 만들고 싶다고 하자. 균일 난수 `u`가 0 이상 1 미만일 때 다음 식은 `variation`으로 기준 반지름에서 벗어나는 최대 폭을 조절한다.

```text
radius = baseRadius + (2 * u - 1) * variation * maxDelta
```

예를 들어 `baseRadius = 14`, `maxDelta = 6`이면 `variation = 0`일 때 모든 반지름은 14다. `variation = 0.5`에서는 11에서 17 사이, `variation = 1`에서는 8에서 20 사이로 달라진다. `maxDelta`는 반지름 단위로 정한 최대 변화량이고, `variation`은 그중 실제로 사용할 비율이므로 보통 0에서 1 사이로 둔다. 반지름을 양수로 유지하려면 현재 설정에서 `baseRadius`를 실제 최대 편차(`variation * maxDelta`)보다 크게 잡아야 한다. 같은 방식으로 기준 밝기나 회전각에 적용할 수 있지만, 각 속성에 맞는 단위의 `maxDelta`를 따로 정해야 한다. `variation`은 크기와 밝기를 한꺼번에 바꾸기보다 각각의 시각 속성에 별도로 연결하는 편이 조절하기 쉽다.

**`correlation`: 속성들이 함께 변하게 만들기**

큰 원이 더 밝게 보이도록 하려면 크기와 밝기에 완전히 별개의 난수를 쓰는 대신, 크기를 정한 난수의 일부를 밝기에도 연결할 수 있다. 다음은 그 연결 정도를 0에서 1 사이로 조절하는 의사 코드다.

```text
uSize = hash(cellId, seed, 0)
uColor = hash(cellId, seed, 1)

sizeT = mix(0.5, uSize, variation)
colorIndependent = mix(0.5, uColor, variation)
colorT = mix(colorIndependent, sizeT, correlation)

size = lerp(8, 24, sizeT)
brightness = lerp(0.35, 0.9, colorT)
```

세 번째 인자는 크기와 색의 난수 채널을 구분하기 위한 표기다. 코드의 `mix(a, b, t)`는 $a$에서 $b$로 가는 선형 보간이므로, `variation = 0`이면 크기와 색 표본이 모두 중간값 0.5에 놓이고 `variation = 1`이면 해시가 만든 전체 범위를 사용한다. `correlation = 0`이면 색은 별도 채널에서 정한 값에 따르고 크기와 직접 연결되지 않는다. `correlation = 1`이면 크기가 큰 도형일수록 밝아지는 순서가 일치한다. 중간값은 별도 채널에서 얻은 색 표본과 크기값을 섞는다. 여기서 `correlation`은 두 값을 섞는 가중치이지 통계학의 상관계수를 정확히 지정하는 공식은 아니다. 서로 다른 해시 채널이 통계적으로 완전히 독립이라는 보장도 없으므로, 실제 상관 관계는 결과를 확인해야 한다. 큰 도형을 어둡게 하고 싶다면 `sizeT` 대신 `1 - sizeT`를 연결하면 된다.

파라미터를 조정할 때는 시드를 고정하고 한 번에 하나의 값만 바꾸면 효과를 읽기 쉽다. 예를 들어 `spread`를 비교하는 동안에는 `amount`와 `variation`을 그대로 두어야 위치 흔들림만 달라진 결과를 볼 수 있다.

## 이 절의 핵심

랜덤성은 결과 선택(`seed`), 요소 수나 비율(`amount`), 위치 범위(`spread`), 속성 변화 폭(`variation`), 속성 간 관계(`correlation`)로 나누어 제어한다. 각 파라미터가 한 가지 시각적 의미를 갖게 하고, 그 값이 실제 화면에서 어떤 차이를 만드는지 예시로 확인한다.
