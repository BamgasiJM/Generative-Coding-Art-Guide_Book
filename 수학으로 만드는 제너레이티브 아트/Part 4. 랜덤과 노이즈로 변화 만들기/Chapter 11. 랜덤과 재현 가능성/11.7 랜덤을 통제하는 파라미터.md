# 11.7 랜덤을 통제하는 파라미터

랜덤을 작품의 조절 가능한 재료로 만들려면 난수 함수를 화면 곳곳에 직접 흩어 놓지 않는다. 의미 있는 파라미터를 먼저 만들고, 각 속성이 그 파라미터를 통해 난수를 받게 한다.

| 파라미터 | 역할 | 예 |
| --- | --- | --- |
| `seed` | 결과 선택 | 같은 이미지를 다시 생성 |
| `amount` | 변화의 개수 | 점, 셀, 입자 수 |
| `spread` | 위치 흔들림 | 격자에서 벗어나는 정도 |
| `variation` | 속성 폭 | 크기나 밝기의 범위 |
| `correlation` | 속성 연결 | 큰 요소를 더 밝게 만듦 |

```text
base = hash(id, seed)
size = lerp(sizeMin, sizeMax, mix(0.5, base, variation))
angle = base * TAU * rotationRange
```

`variation=0`일 때 모든 요소가 기준값으로 수렴하게 만들면 비교가 쉬워진다. 파라미터가 커질수록 무엇이 얼마나 변하는지도 명확해야 한다. 예컨대 밀도와 크기를 동시에 높이면 결과는 크게 달라져도 어느 조절이 원인인지 알기 어렵다.

무작위 선택 자체도 확률 파라미터로 통제할 수 있다. `random() < 0.2`는 평균적으로 약 20%의 셀만 활성화한다. 화면의 규모가 작을 때는 실제 개수가 크게 흔들릴 수 있으므로, 정확한 개수가 필요하면 목록을 섞어 앞부분만 선택한다.

## 이 절의 핵심

랜덤성은 시드, 양, 범위, 연결 정도로 나누어 제어한다. 파라미터 하나가 한 가지 시각적 의미를 갖도록 설계한다.
