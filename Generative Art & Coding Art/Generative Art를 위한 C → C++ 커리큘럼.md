# C → C++ 하이브리드 커리큘럼

## 목적
- C의 저수준 개념을 빠르게 이해하고,
- C++의 객체지향과 현대 문법을 익힌 후,
- 그래픽스 프로그래밍(OpenGL, GLSL 등)에 효율적으로 진입하는 것

---

## 1단계: C 기초 (1~2주)

> ✅ **목표**: C++ 기반을 위한 C 문법과 저수준 개념 빠르게 익히기

| 주제 | 설명 | C++에서 필요 여부 |
|------|------|------------------|
| 기본 문법 (`if`, `while`, 함수 등) | 전체 문법의 뼈대 | ✅ 꼭 필요 |
| 포인터와 주소 연산자 (`*`, `&`) | 메모리 직접 제어 | ✅ 매우 중요 |
| 배열과 문자열 (`char[]`, `\0`) | C 문자열 개념 | ✅ 최소한 필요 |
| 구조체 (`struct`) | C++ 클래스 이해에 도움 | ✅ 필수 |
| 동적 메모리 (`malloc`, `free`) | `new/delete` 대비 | ✅ 기본만 |
| 헤더 구조 (`.h`, `#include`) | 컴파일 구조 이해 | ✅ 기본만 |
| 함수 포인터 | 함수 래핑 기법 | ❌ 초반에는 생략 가능 |

---

## 2단계: C++ 기초 문법 + 객체지향 개념 (2~3주)

> ✅ **목표**: 클래스와 객체지향 구조에 익숙해지기

- `cout`, `cin`, `std::` 네임스페이스
- 클래스와 객체, 생성자/소멸자
- 접근 제어자: `public`, `private`, `protected`
- 멤버 함수와 변수
- 참조자 (`&`)와 `const`
- 복사 생성자, `this` 포인터
- 연산자 오버로딩
- 동적 객체 생성 (`new`, `delete`)

---

## 3단계: Modern C++ 핵심 (3~4주)

> ✅ **목표**: 최신 문법 습득 및 메모리 안정성 강화

- 스마트 포인터 (`unique_ptr`, `shared_ptr`)
- STL: `vector`, `map`, `set`
- `auto`, `nullptr`, range-based for loop
- 람다 함수
- 템플릿 기초
- `enum class`, `override`, `final`
- 예외 처리 (`try`, `catch`)

---

## 4단계: C++ + OpenGL 그래픽스 기초 (4+ 주차)

> ✅ **목표**: C++로 그래픽스 프로그램 구조 만들기

- C++과 OpenGL 연동 (`glfw`, `glew`, `glad`)
- 구조체로 Vertex 데이터 설계
- 클래스 기반의 `Shader`, `Mesh`, `Texture` 구조화
- RAII 패턴 사용 (자원 할당/해제 자동화)
- 상태 관리와 이벤트 처리

---

## 요약 타임라인

|------|------|
| 1주차 | C 기본 문법, 포인터, 구조체 |

| 3~4주차 | 클래스, 객체지향, `new/delete` |

| 7주차~ | C++ 기반 OpenGL 렌더링 구조 설계 |
