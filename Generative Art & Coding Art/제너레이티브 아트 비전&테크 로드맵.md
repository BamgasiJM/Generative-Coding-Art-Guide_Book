# Generative Art Web Portfolio — 학습 로드맵

> **목표:** 제너레이티브 아트 기반의 인터랙티브 웹 포트폴리오를 직접 구축할 수 있는 기술 스택을 체계적으로 습득한다.
> **핵심 방향:** p5.js와 Three.js를 중심으로 실시간 렌더링, 셰이더 프로그래밍, GPU 기반 시뮬레이션까지 단계적으로 확장한다.

---

## 전체 학습 단계

- **<span style="color: #ffaa99">Phase 1</span>** — 기반 언어 & 브라우저
- **<span style="color: #ffaa99">Phase 2</span>**  — 제너레이티브 아트 핵심 라이브러리
- **<span style="color: #ffaa99">Phase 3</span>** — 인터랙티브 & 오디오비주얼
- **<span style="color: #ffaa99">Phase 4</span>** — 고급 렌더링 & GPU
- **<span style="color: #ffaa99">Phase 5</span>** — 풀스택 통합 & 배포


각 레이어는 이전 레이어를 전제로 하며, 레이어 내 항목은 병렬 학습이 가능하다.

# <span style="color: #ffaa99">Phase 1</span> 기반 언어 & 브라우저 API

> **기간 목표:** 0~4개월
> **핵심 질문:** "브라우저 위에서 코드가 어떻게 실행되는가?"

## 1-1. JavaScript 언어 심화

제너레이티브 아트 코드 전반은 JS 위에서 동작하므로, 언어 동작 원리를 명확하게 이해해야 한다.

| 주제 | 학습 내용 |
|---|---|
| 스코프와 클로저 | 렉시컬 스코프, 클로저를 활용한 상태 캡슐화 |
| 프로토타입 & 클래스 | 객체 모델 이해, 클래스 상속 패턴 |
| 비동기 처리 | Promise, async/await, 이벤트 루프 |
| 모듈 시스템 | ES Modules (import/export), 번들러 없이 동작하는 구조 |
| 구조 분해 & 스프레드 | 코드 간결화에 필수적인 문법 패턴 |

## 1-2. 브라우저 렌더링 API

브라우저가 그래픽을 어떻게 그리는지 직접 다루는 기반 API다.

| API | 학습 내용 |
|---|---|
| Canvas 2D API | `getContext('2d')`, 드로잉 루프, 변환 행렬, 픽셀 조작 |
| requestAnimationFrame | 60fps 루프 구조, 타이밍, delta time 처리 |
| Web Audio API | `AudioContext`, `AnalyserNode`, 주파수/시간 도메인 데이터 추출 |
| Pointer Events / Mouse Events | 인터랙션 인풋 처리 |
| ResizeObserver | 캔버스 반응형 처리 |
| Web Workers | 무거운 연산을 메인 스레드에서 분리 |

## 1-3. TypeScript 기초

Three.js 생태계와 대규모 프로젝트에서 타입 안전성을 확보하기 위해 필요하다.

- `interface`, `type alias`, `generic`
- 유니온 타입, 옵셔널 체이닝
- Three.js와 함께 사용할 때 중요한 `Vector3`, `Color`, `Material` 타입 확인
- strict 모드 운용

# <span style="color: #ffaa99">Phase 2</span> 제너레이티브 아트 핵심 라이브러리

> **기간 목표:** 3~8개월 (Layer 1과 일부 병렬 진행 가능)

## 2-1. p5.js — 제너레이티브 아트 입문 & 프로토타이핑

**역할:** 아이디어를 빠르게 시각화하는 스케치 도구. 알고리즘 기반 비주얼 아트의 기본 문법을 익히는 데 가장 적합하다.

```
p5.js
├── 핵심 함수: setup(), draw(), preload()
├── 드로잉: ellipse, rect, bezier, beginShape/endShape
├── 변환: translate, rotate, scale, push/pop
├── 색상: colorMode(HSB), fill, stroke, lerpColor
├── 수학: noise(), random(), map(), lerp(), dist()
├── 인터랙션: mouseX/Y, key events, touch events
└── 미디어: loadImage, loadSound, video
```

**주요 학습 프로젝트:**
- Perlin noise 기반 flow field
- 파티클 시스템 (birth/death/force)
- 프랙탈 트리, L-System
- Lissajous curves, 진동 패턴
- Mouse trail & 반응형 형태

**p5.js와 함께 사용하는 라이브러리:**

| 라이브러리 | 역할 | 연동 방식 |
|---|---|---|
| `p5.sound` | 오디오 로드, 재생, FFT 분석, 마이크 인풋 | p5.js 애드온 |
| `p5.serialport` | 아두이노 등 시리얼 디바이스 연결 | 별도 서버 필요 |
| `ml5.js` | TensorFlow.js 기반 ML (PoseNet, BodyPix, ImageClassifier) | p5.js와 공존 |
| `p5.dom` (내장) | HTML DOM 요소 생성, 슬라이더/버튼 UI | p5 내장 |

## 2-2. Three.js — 3D 실시간 렌더링

**역할:** WebGL 위에서 동작하는 3D 렌더링 엔진. p5.js로 2D 아이디어를 충분히 탐구한 후 진입한다.

```
Three.js 학습 단계
│
├── 기초
│   ├── Scene, Camera (PerspectiveCamera / OrthographicCamera)
│   ├── Renderer (WebGLRenderer), Canvas 연결
│   ├── Mesh = Geometry + Material
│   ├── Lights (Directional, Point, Ambient, Spot)
│   └── Animation Loop (requestAnimationFrame)
│
├── 중급
│   ├── BufferGeometry (직접 vertex 데이터 구성)
│   ├── Texture (로드, UV 매핑, 큐브맵)
│   ├── Raycasting (마우스 인터랙션)
│   ├── RenderTarget (오프스크린 렌더링)
│   ├── Post-Processing (EffectComposer)
│   └── Groups & Scene Graph
│
└── 고급
    ├── InstancedMesh (GPU Instancing)
    ├── Points & PointsMaterial (파티클 시스템)
    ├── ShaderMaterial / RawShaderMaterial (커스텀 GLSL)
    ├── DataTexture (GPU에 데이터 전달)
    └── Framebuffer 기법 (ping-pong buffer)
```

**Three.js와 함께 사용하는 라이브러리:**

| 라이브러리 | 역할 | 사용 국면 |
|---|---|---|
| `@react-three/fiber` | React 기반 Three.js 선언적 렌더링 | Next.js 통합 시 |
| `@react-three/drei` | 카메라 컨트롤, 텍스트, 로더 등 유틸리티 | R3F 사용 시 |
| `three/addons` | OrbitControls, GLTFLoader, DRACOLoader 등 공식 애드온 | Three.js와 함께 |
| `postprocessing` | 고성능 포스트프로세싱 파이프라인 (bloom, SSAO, DOF) | 고급 렌더링 |
| `troika-three-text` | Three.js 씬 안에서 고품질 텍스트 렌더링 | 타이포그래피 아트 |
| `three-custom-shader-material` | MeshStandardMaterial에 GLSL 덧씌우기 | PBR + 커스텀 셰이더 |

## 3-1. Tone.js — 오디오 합성 & 음악 생성

**역할:** Web Audio API 위에서 동작하는 오디오 프레임워크. 사운드를 생성하고 Three.js / p5.js 비주얼과 동기화한다.

```
Tone.js
├── 신호 흐름: Source → Effect → Destination
├── Oscillator, Synth, PolySynth
├── Sampler (샘플 기반 연주)
├── Transport (BPM, 시퀀서, 루프)
├── Analyser (FFT, Waveform — 비주얼 동기화에 사용)
└── Effect: Reverb, Delay, Distortion, Filter
```

**p5.js + Tone.js 연동 패턴:** `Tone.Analyser`로 주파수 데이터를 뽑아 `p5.draw()` 안에서 시각화.  
**Three.js + Tone.js 연동 패턴:** FFT 배열 값을 `DataTexture` 또는 `uniform`으로 셰이더에 전달.

# <span style="color: #ffaa99">Phase 4</span> 고급 렌더링 & GPU

## 4-1. GLSL — 셰이더 프로그래밍

Three.js의 `ShaderMaterial`과 직접 연결되는 핵심 기술이다.

```
GLSL 학습 경로
│
├── 기초
│   ├── 데이터 타입: float, vec2, vec3, vec4, mat4
│   ├── built-in 함수: mix, clamp, smoothstep, fract, mod
│   ├── vertex shader — position 변환
│   └── fragment shader — 색상 출력
│
├── 중급
│   ├── UV 기반 패턴 생성 (타일, 격자, 방사형)
│   ├── SDF (Signed Distance Function) 도형
│   ├── Noise 함수 (GLSL 내장 구현)
│   ├── uniforms (시간, 해상도, 마우스)
│   └── varying (vertex → fragment 데이터 전달)
│
└── 고급
    ├── Raymarching (볼류메트릭, 3D SDF)
    ├── Domain Warping
    ├── Fresnel, 반사/굴절
    ├── Ping-pong buffer (시뮬레이션)
    └── Feedback effect
```

**GLSL 학습에 도움이 되는 도구:**

| 도구 | 역할 |
|---|---|
| [Shadertoy](https://www.shadertoy.com) | GLSL fragment shader 실시간 편집 & 커뮤니티 |
| [The Book of Shaders](https://thebookofshaders.com) | GLSL 학습 교재 (필독) |
| `glslify` | GLSL 모듈 시스템 (import 가능하게 함) |

## 4-3. WebGPU (심화)

Three.js WebGPU 렌더러(`THREE.WebGPURenderer`)가 안정화된 시점에 진입한다.

```
WebGPU 학습 내용
├── GPUDevice, GPUAdapter 초기화
├── Compute Shader (WGSL)
│   ├── Storage Buffer — 파티클 시뮬레이션, 유체
│   └── Workgroup 단위 병렬 연산
├── Render Pipeline (WGSL vertex/fragment)
└── Three.js WebGPURenderer 전환
```

> Three.js는 현재 WebGPU 백엔드를 TSL(Three Shading Language)로 추상화하고 있다. 추상화 레이어를 먼저 사용하고, 이후 WGSL 원본을 탐구하는 순서를 권장한다.

## 5-1. React

Three.js와 React를 연결할 때 `useRef`, `useEffect`, `useCallback`의 역할이 핵심이다.

- **컴포넌트 아키텍처:** 캔버스, 오버레이 UI, 갤러리를 각각 분리된 컴포넌트로 구성
- **useRef:** Three.js 렌더러 인스턴스, 캔버스 DOM 접근
- **useEffect:** 씬 초기화, 이벤트 리스너 등록/해제
- **Context API:** 전역 상태 (오디오 컨텍스트, 씬 설정 등)
- **Suspense + lazy:** 대용량 3D 에셋 로딩

- 작품 메타데이터 관리 (제목, 설명, 태그, 제작일)
- 썸네일 자동 생성 (Three.js 씬에서 캡처)
- 관리자 대시보드
- 태깅 & 필터 시스템

## 5-5. Blender → 웹 파이프라인

```
Blender
 ├── glTF 2.0 / GLB 익스포트
 ├── DRACO 압축 (파일 크기 최대 90% 감소)
 ├── 텍스처 베이킹 (복잡한 셰이더를 텍스처로 변환)
 └── 애니메이션 익스포트 (Morph Target, Skeletal)
         ↓
Three.js (GLTFLoader + DRACOLoader)
 └── 인터랙티브 웹 경험
```
