[[블렌더 공부]]
### 🧩 소제목 구성 ( 실습 중심)

1. **블렌더에서 수학이 왜 필요할까?**
    
    - 3D 세계는 수학으로 움직인다: 위치, 방향, 회전도 다 숫자!
        
    - mathutils 소개
        
2. **Vector는 위치와 방향이다**
    
    - `Vector((x, y, z))`로 벡터 만들기
        
    - 벡터 시각화 예제: 큐브를 벡터 방향으로 이동시키기
        
3. **벡터의 크기와 방향을 눈으로 보기**
    
    - `.length`, `.normalized()` 설명
        
    - 벡터 정규화 실습: 방향만 유지하면서 거리 고정
        
4. **벡터 더하기와 빼기: 두 점 사이의 방향**
    
    - A → B 방향 벡터 만들기
        
    - 실습: 두 오브젝트 사이 연결선 만들기 (edge mesh 생성)
        
5. **내적(Dot Product)은 얼마나 같은 방향인가?**
    
    - 내적으로 각도 구하기 (`vec1.angle(vec2)`)
        
    - 실습: 각도에 따라 큐브 색 바꾸기
        
6. **외적(Cross Product)은 수직 방향이다**
    
    - 오른손 법칙과 회전 축
        
    - 실습: 두 벡터에서 수직 방향 구해서 그 방향으로 큐브 배치
        
7. **Matrix는 좌표계를 바꾸는 도구다**
    
    - 위치, 회전, 스케일을 담은 4x4 행렬
        
    - 실습: 오브젝트를 다른 오브젝트의 로컬 좌표계 기준으로 이동시키기
        
8. **Matrix와 Vector의 만남**
    
    - `vec @ mat` 또는 `mat @ vec`의 의미 설명
        
    - 실습: 로컬 공간 → 월드 공간 위치 계산
        
9. **실습 프로젝트: 큐브를 원형으로 배치하고 회전시키기**
    
    - 벡터와 행렬을 동시에 활용한 직관적 프로젝트
        
    - 원형 배열 + 각 큐브의 앞면이 중심을 향하게
        
10. **마무리: 수학은 어렵지 않아, Blender가 도와줄게!**
    
    - 시각적인 피드백이 수학 학습에 큰 도움
        
    - mathutils는 여러분의 수학 실험실!
