[[블렌더 공부]]
### 1. `Matrix.Scale(value, size, axis)`

`mathutils.Matrix.Scale()` 함수는 특정 축을 따라 객체를 스케일링하는 데 사용되는 **스케일링 행렬**을 생성합니다.

- **`value`**: 스케일링할 크기(배율)입니다. 예를 들어, `scale_x`는 X축으로 스케일링할 배율입니다.
    
- **`size`**: 생성될 행렬의 차원입니다. 3D 변환에서는 일반적으로 4x4 행렬을 사용합니다. 4x4 행렬은 3D 공간에서의 위치(이동), 회전, 스케일링을 모두 표현할 수 있는 표준적인 방법입니다.
    
- **`axis`**: 스케일링이 적용될 방향을 나타내는 벡터입니다.
    
    - `(1, 0, 0)`: X축 방향
        
    - `(0, 1, 0)`: Y축 방향
        
    - `(0, 0, 1)`: Z축 방향
        

**예시:** `Matrix.Scale(scale_x, 4, (1, 0, 0))` 이것은 `scale_x` 값만큼 X축을 따라 스케일링하는 4x4 행렬을 생성합니다. 다른 축(Y, Z)은 스케일링되지 않고 1배율을 유지합니다.

### 2. 세 개의 `Matrix.Scale` 호출

- `Matrix.Scale(scale_x, 4, (1, 0, 0))`: X축 스케일링 행렬을 생성합니다.
    
- `Matrix.Scale(scale_y, 4, (0, 1, 0))`: Y축 스케일링 행렬을 생성합니다.
    
- `Matrix.Scale(scale_z, 4, (0, 0, 1))`: Z축 스케일링 행렬을 생성합니다.
    

### 3. `@` 연산자 (행렬 곱셈)

파이썬 3.5부터 도입된 `@` 연산자는 **행렬 곱셈(Matrix Multiplication)**을 나타냅니다.

수학에서 행렬 곱셈은 여러 변환을 하나로 결합할 때 사용됩니다. 변환 행렬의 순서는 중요합니다. 이 경우, 세 개의 개별 스케일링 변환(X축, Y축, Z축)을 하나의 복합 스케일링 변환으로 결합하는 것입니다.

`A @ B @ C`는 `(A @ B) @ C`와 동일하며, 이는 행렬 `A`를 `B`에 곱하고 그 결과를 다시 `C`에 곱하는 것을 의미합니다. 결과적으로 `scale_matrix`는 어떤 점(벡터)에 곱해졌을 때, 해당 점을 `scale_x`, `scale_y`, `scale_z` 값으로 동시에 스케일링하는 단일 행렬이 됩니다.

### 왜 이렇게 결합하는가?

메쉬의 각 정점(`v.co`)은 3D 공간의 한 점을 나타내는 벡터입니다. 이 벡터에 `scale_matrix`를 곱하면(`v.co = scale_matrix @ v.co`), 해당 정점의 X, Y, Z 좌표가 각각 `scale_x`, `scale_y`, `scale_z`에 비례하여 조정됩니다.

이 방식은 `bpy.ops.object.transform_apply`를 호출하는 것보다 훨씬 효율적입니다. `bpy.ops`는 블렌더의 내부 시스템과 UI에 밀접하게 연결되어 있어 각 호출마다 오버헤드가 크지만, `mathutils.Matrix`를 사용한 `bmesh` 정점 조작은 순수 파이썬 및 블렌더의 저수준 데이터 구조를 직접 다루기 때문에 훨씬 빠릅니다.

요약하자면, 이 한 줄의 코드는 X, Y, Z축으로 각각 다른 비율로 스케일링하는 복합 변환 행렬을 효율적으로 생성하는 방법입니다.
