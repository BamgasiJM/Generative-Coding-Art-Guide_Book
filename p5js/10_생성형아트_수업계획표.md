| 주차       | 핵심 개념                                        | 이론적 틀 / 학습 내용                                | 주요 학습 목표                    |
| -------- | -------------------------------------------- | -------------------------------------------- | --------------------------- |
| **2주차**  | **랜덤(Randomness)**                           | 확률, 분포, 난수 발생 원리 (Gaussian, Perlin 등)        | 예측 불가능성을 조절하며 형태 생성하기       |
| **3주차**  | **반복(Iteration) & 규칙(Algorithmic Thinking)** | 루프, 재귀, 알고리즘적 사고                             | 단순 규칙의 반복으로 복잡한 패턴을 생성하기    |
| **4주차**  | **벡터(Vector)와 힘(Force)**                     | 벡터 연산, 물리적 움직임(속도·가속도)                       | 물리기반 움직임을 통해 자연스러운 형태 표현    |
| **5주차**  | **노이즈(Noise) 기반 패턴**                         | Perlin/Simplex Noise, 연속성 있는 랜덤              | 유기적이고 흐르는 듯한 패턴 생성          |
| **6주차**  | **시스템(System) & 에이전트(Agents)**               | 입자 시스템(Particle System), 군집(Fl flocking)     | 개별 요소의 단순 행동이 전체 패턴을 형성하는 법 |
| **7주차**  | **형태(Form) & 구조(Structure)**               | L-system | 자연의 성장 원리를 모방한 형태 생성        |
| **8주차**  | **혼돈에서 질서로**        |Diffusion-Limited Aggregation(DLA)    |     |
| **9주차**  | **진화적 알고리즘(Evolutionary Algorithms)**        | 유전 알고리즘(GA), 적응과 선택                          | 알고리즘을 통해 형태의 ‘진화’를 시뮬레이션    |
| **10주차** | **카오스(Chaos)와 질서(Order)**                    | 혼돈 시스템, 초기 조건 민감성                            | 무질서 속의 패턴 발견, 동적 균형 시각화     |
| **11주차** | **프랙탈(Fractal) & 자기유사성(Self-Similarity)**    | Mandelbrot, Julia Set, Recursive Patterns    | 자기유사성을 통한 복잡한 구조 시각화        |
| **12주차** | **셀룰러 오토마타(Cellular Automata)**              | Conway’s Game of Life, 규칙 기반 시스템             | 단순 규칙으로 복잡한 생명현상 구현         |
| **13주차** | **형태의 데이터화(Form as Data)**                   | Generative geometry, procedural modeling     | 수학적·데이터 기반으로 형태를 정의하고 제어    |
| **14주차** | **인터랙션(Interaction)과 시간성(Temporal Systems)** | 실시간 반응, 입력 데이터 기반 변화                         | 관객 참여형 생성 아트 제작 기초          |
